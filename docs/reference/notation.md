# 记号约定

本页列出本教程中统一使用的数学记号，方便读者查阅。

---

## 集合与映射

| 记号 | 含义 |
|------|------|
| $\mathbb{N}$ | 自然数集 $\{0, 1, 2, \ldots\}$ |
| $\mathbb{Z}$ | 整数环 |
| $\mathbb{Q}$ | 有理数域 |
| $\mathbb{R}$ | 实数域 |
| $\mathbb{C}$ | 复数域 |
| $\mathbb{F}_p$ | $p$ 元有限域（$p$ 为素数） |
| $\mathbb{F}_q$ | $q$ 元有限域（$q = p^n$） |
| $A \hookrightarrow B$ | 单射（嵌入） |
| $A \twoheadrightarrow B$ | 满射（商映射） |
| $A \xrightarrow{\sim} B$ | 同构映射 |
| $\ker \varphi$ | 同态 $\varphi$ 的核 |
| $\operatorname{im} \varphi$ | 同态 $\varphi$ 的像 |
| $\lvert G \rvert$ | 群 $G$ 的阶 |
| $[G : H]$ | 子群 $H$ 在 $G$ 中的指数 |

## 群论

| 记号 | 含义 |
|------|------|
| $H \leq G$ | $H$ 是 $G$ 的子群 |
| $H < G$ | $H$ 是 $G$ 的真子群 |
| $H \trianglelefteq G$ | $H$ 是 $G$ 的正规子群 |
| $G / N$ | $G$ 关于正规子群 $N$ 的商群 |
| $G \times H$ | 群的直积 |
| $S_n$ | $n$ 元对称群 |
| $A_n$ | $n$ 元交错群 |
| $C_n$ | $n$ 阶循环群 |
| $\operatorname{Aut}(G)$ | $G$ 的自同构群 |
| $\operatorname{Inn}(G)$ | $G$ 的内自同构群 |
| $Z(G)$ | 群 $G$ 的中心 |

## 环论

| 记号 | 含义 |
|------|------|
| $R[x]$ | 环 $R$ 上的多项式环 |
| $R[x_1, \ldots, x_n]$ | $R$ 上的 $n$ 元多项式环 |
| $I \trianglelefteq R$ | $I$ 是环 $R$ 的理想 |
| $R / I$ | $R$ 关于理想 $I$ 的商环 |
| $\deg f$ | 多项式 $f$ 的次数 |
| $R^{\times}$ | 环 $R$ 的可逆元群（单位群） |
| $\operatorname{char} R$ | 环 $R$ 的特征 |

## 域论

| 记号 | 含义 |
|------|------|
| $F \subseteq K$ | $K$ 是 $F$ 的扩张 |
| $[K : F]$ | 扩张 $K/F$ 的次数 |
| $F(\alpha)$ | 在 $F$ 上添加 $\alpha$ 得到的单扩张 |
| $F(S)$ | 在 $F$ 上添加集合 $S$ 中的元素得到的扩张 |
| $F^{\text{alg}}$ | $F$ 的代数闭包 |
| $\overline{F}$ | $F$ 的代数闭包（简记） |
| $\operatorname{Gal}(K/F)$ | 扩张 $K/F$ 的 Galois 群 |
| $K^G$ | 群 $G$ 作用在 $K$ 上的不变域 |
| $\min(F, \alpha)$ | $\alpha$ 在 $F$ 上的极小多项式 |
| $\mu_F(\alpha)$ | 同上（替代记号） |

## 逻辑与证明

| 记号 | 含义 |
|------|------|
| $\Rightarrow$ | 蕴含 |
| $\Leftrightarrow$ | 当且仅当 |
| $\forall$ | 对所有 |
| $\exists$ | 存在 |
| $:=$ | 定义为 |
| $\square$ | 证毕 |
