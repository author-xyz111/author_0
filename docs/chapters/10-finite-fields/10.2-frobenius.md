# §10.2 Frobenius 自同构与 Galois 理论 {#sec-frobenius}

::: tip 学习目标
1. 理解 Frobenius 自同构 $\alpha \mapsto \alpha^p$ 的代数本质。
2. 能对具体有限域（如 $\mathbb{F}_8$、$\mathbb{F}_9$、$\mathbb{F}_{27}$）显式计算 Frobenius 的轨道和不动域。
3. 掌握有限域 Galois 对应的完全显式形式。
4. 理解迹与范的定义、计算方法及其在编码理论中的应用。
5. 了解 Frobenius 特征值如何连接有限域与 Weil 猜想。
:::

::: intuition 最简单的 Galois 群
有限域之间的扩张提供了 Galois 理论最干净、最完整的范例：**每个有限域扩张都是 Galois 的**，Galois 群都是循环群，由 Frobenius 自同构生成。这里是 Galois 对应可以完全显式写出的**唯一**重要情况。

与数域的 Galois 群形成鲜明对比：$\operatorname{Gal}(\bar{\mathbb{Q}}/\mathbb{Q})$ 是一个极其复杂的 profinite 群，至今无人完全理解。而有限域的 Galois 群只是一些 $\mathbb{Z}/n\mathbb{Z}$，本质上只有"计数"一个参数。
:::

## Frobenius 自同构 {#frobenius}

::: definition Frobenius 自同构 {#def-frobenius}
设 $q = p^n$。**Frobenius 自同构**（Frobenius automorphism）定义为
$$
\operatorname{Frob}_q: \mathbb{F}_q \to \mathbb{F}_q, \quad \alpha \mapsto \alpha^q = \alpha^p.
$$
（第一个等式是因为 $\alpha^{p^n} = \alpha$，第二个等式是因为 $q = p^n$。）
:::

::: theorem Frobenius 的性质 {#thm-frobenius-properties}
**(i)** $\operatorname{Frob}_q$ 是域自同构。

**(ii)** $\operatorname{Frob}_q$ 的阶恰好为 $n$（即 $\operatorname{Frob}_q^n = \operatorname{id}$，$\operatorname{Frob}_q^k \neq \operatorname{id}$ 对 $1 \leq k < n$）。

**(iii)** $\operatorname{Frob}_q$ 的不动域为 $\mathbb{F}_p$（即 $\{x \in \mathbb{F}_q : x^p = x\} = \mathbb{F}_p$）。

**(iv)** $\operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p) = \langle \operatorname{Frob}_p \rangle \cong \mathbb{Z}/n\mathbb{Z}$。
:::

<ProofToggle>

**证明.**

**(i)** $\operatorname{Frob}_q(\alpha + \beta) = (\alpha + \beta)^p = \alpha^p + \beta^p$（在特征 $p$ 下的二项式展开）。$\operatorname{Frob}_q(\alpha\beta) = (\alpha\beta)^p = \alpha^p\beta^p$。$\operatorname{Frob}_q$ 是单射（域同态的核为 $\{0\}$），故是自同构（有限集合上的单射是双射）。

**(ii)** $\operatorname{Frob}_q^n = \operatorname{id}$ 等价于 $\alpha^{p^n} = \alpha$ 对所有 $\alpha \in \mathbb{F}_q$，这正是 $\mathbb{F}_q$ 的定义性质。

$\operatorname{Frob}_q^k \neq \operatorname{id}$ 对 $k < n$：若 $\alpha^{p^k} = \alpha$ 对所有 $\alpha$，则 $\mathbb{F}_q \subseteq \mathbb{F}_{p^k}$，但 $p^k < p^n$，矛盾（$|\mathbb{F}_{p^k}| < |\mathbb{F}_q|$）。

**(iii)** $\{x : x^p = x\}$ 恰好是 $x^p - x$ 的根的集合，即 $\mathbb{F}_p$。

**(iv)** 由 (i)-(iii)，$\langle \operatorname{Frob}_p \rangle \leq \operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p)$，$|\langle \operatorname{Frob}_p \rangle| = n = [\mathbb{F}_{p^n} : \mathbb{F}_p]$。由 {prop-galois-group-order}，$|\operatorname{Gal}| \leq n$。故 $\operatorname{Gal} = \langle \operatorname{Frob}_p \rangle \cong \mathbb{Z}/n\mathbb{Z}$。$\blacksquare$

</ProofToggle>

## Frobenius 的具体计算 {#frobenius-computations}

理解 Frobenius 最好的方法是亲手计算。以下例子展示了 Frobenius 轨道、不动域和 Galois 对应的完整运作。

::: example $\mathbb{F}_8$ 上的 Frobenius {#ex-frob-f8}
设 $\mathbb{F}_8 = \mathbb{F}_2(\alpha)$，其中 $\alpha$ 是 $X^3 + X + 1$（$\mathbb{F}_2$ 上不可约）的根。

$\operatorname{Frob}_2: x \mapsto x^2$ 生成 $\operatorname{Gal}(\mathbb{F}_8/\mathbb{F}_2) \cong \mathbb{Z}/3\mathbb{Z}$。

**轨道计算：**

$\operatorname{Frob}_2$ 作用在 $\mathbb{F}_8^\times = \{1, \alpha, \alpha^2, \alpha^3, \alpha^4, \alpha^5, \alpha^6\}$ 上：

- $\operatorname{Frob}_2(\alpha) = \alpha^2$
- $\operatorname{Frob}_2(\alpha^2) = \alpha^4$
- $\operatorname{Frob}_2(\alpha^4) = \alpha^8 = \alpha$（因为 $\alpha^7 = 1$）

所以 $\{\alpha, \alpha^2, \alpha^4\}$ 是一个 Frobenius 轨道。类似地：

- $\operatorname{Frob}_2(\alpha^3) = \alpha^6$，$\operatorname{Frob}_2(\alpha^6) = \alpha^{12} = \alpha^5$，$\operatorname{Frob}_2(\alpha^5) = \alpha^{10} = \alpha^3$。

所以 $\{\alpha^3, \alpha^5, \alpha^6\}$ 是另一个轨道。

**总结：** $\mathbb{F}_8^\times$ 被 $\operatorname{Frob}_2$ 划分为两个 3 元轨道和不动点 $1$。每个轨道恰好对应 $\mathbb{F}_2$ 上一个不可约三次多项式的三个根：$\{0\}$ 对应 $X$，$\{1\}$ 对应 $X+1$，$\{\alpha, \alpha^2, \alpha^4\}$ 对应 $X^3 + X + 1$，$\{\alpha^3, \alpha^5, \alpha^6\}$ 对应 $X^3 + X^2 + 1$。
:::

::: example $\mathbb{F}_{16}$ 的 Galois 对应 {#ex-frob-f16}
$\operatorname{Gal}(\mathbb{F}_{16}/\mathbb{F}_2) \cong \mathbb{Z}/4\mathbb{Z}$，生成元 $\operatorname{Frob}_2$。

子群格和中间域的对应：

| 子群 $H$ | 指数 | 不动域 $\mathbb{F}_{16}^H$ | 阶 |
|---|---|---|---|
| $\{0\}$ | 4 | $\mathbb{F}_{16}$ | $2^4 = 16$ |
| $\langle 2 \rangle \cong \mathbb{Z}/2\mathbb{Z}$ | 2 | $\mathbb{F}_{4}$ | $2^2 = 4$ |
| $\mathbb{Z}/4\mathbb{Z}$ | 1 | $\mathbb{F}_{2}$ | $2^1 = 2$ |

关键观察：$\mathbb{F}_{16}$ 中恰好有一个 $\mathbb{F}_4$（由 $x^4 = x$ 确定，即 $\mathbb{F}_4 = \{0, 1, \alpha^5, \alpha^{10}\}$，其中 $\alpha$ 是 $\mathbb{F}_{16}$ 的本原元）。$\operatorname{Frob}_2^2: x \mapsto x^4$ 的不动域恰好是 $\mathbb{F}_4$。
:::

::: example $\mathbb{F}_{27}$ 上的 Frobenius 与迹 {#ex-frob-f27}
设 $\mathbb{F}_{27} = \mathbb{F}_3(\alpha)$，其中 $\alpha$ 是 $X^3 - X + 1$（$\mathbb{F}_3$ 上不可约）的根。

$\operatorname{Frob}_3: x \mapsto x^3$，$\operatorname{Frob}_3^3 = \operatorname{id}$。$\operatorname{Gal}(\mathbb{F}_{27}/\mathbb{F}_3) \cong \mathbb{Z}/3\mathbb{Z}$。

**迹的计算：**

$$\operatorname{Tr}_{\mathbb{F}_{27}/\mathbb{F}_3}(\alpha) = \alpha + \alpha^3 + \alpha^9$$

由 $\alpha^3 = \alpha - 1$（极小多项式给出）：$\alpha^9 = (\alpha^3)^3 = (\alpha - 1)^3 = \alpha^3 - 1 = (\alpha - 1) - 1 = \alpha - 2 = \alpha + 1$（在 $\mathbb{F}_3$ 中）。

因此 $\operatorname{Tr}(\alpha) = \alpha + (\alpha - 1) + (\alpha + 1) = 3\alpha = 0 \in \mathbb{F}_3$。

**范的计算：**

$$\operatorname{N}_{\mathbb{F}_{27}/\mathbb{F}_3}(\alpha) = \alpha \cdot \alpha^3 \cdot \alpha^9 = \alpha \cdot (\alpha - 1) \cdot (\alpha + 1) = \alpha(\alpha^2 - 1) = \alpha^3 - \alpha = (\alpha - 1) - \alpha = -1 = 2 \in \mathbb{F}_3$$

这也等于 $(-1)^3 \cdot (1) = -1$（常数项的适当幂），符合极小多项式 $X^3 - X + 1$ 的常数项信息。
:::

::: warning Frobenius $\operatorname{Frob}_p$ vs $\operatorname{Frob}_q$ 的区别
符号 $\operatorname{Frob}_q$（$q = p^n$）和 $\operatorname{Frob}_p$ 有时造成混淆：

- $\operatorname{Frob}_p: \alpha \mapsto \alpha^p$ 是 $\mathbb{F}_q/\mathbb{F}_p$ 的 Galois 群的生成元，阶为 $n$。
- $\operatorname{Frob}_q: \alpha \mapsto \alpha^q = \alpha^{p^n}$ 是恒等映射（在 $\mathbb{F}_q$ 上）。

在代数几何中，"几何 Frobenius"指 $x \mapsto x^{1/q}$（逆映射），而"算术 Frobenius"指 $x \mapsto x^q$。不同文献可能采用不同约定。
:::

## 有限域扩张的 Galois 对应 {#finite-galois-correspondence}

::: theorem 有限域的 Galois 对应完全显式 {#thm-finite-galois-correspondence}
设 $q = p^n$，$m \mid n$。则：

**(i)** $\mathbb{F}_{p^m}$ 是 $\mathbb{F}_{p^n}$ 的唯一子域（阶为 $p^m$）。

**(ii)** $\operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_{p^m}) = \langle \operatorname{Frob}_p^{n/m} \rangle \cong \mathbb{Z}/(n/m)\mathbb{Z}$。

**(iii)** Galois 对应：$\operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p) \cong \mathbb{Z}/n\mathbb{Z}$ 的子群为 $k\mathbb{Z}/n\mathbb{Z}$（$k \mid n$），对应不动域 $\mathbb{F}_{p^{n/k}}$。
:::

<ProofToggle>

**证明.**

**(i)** 由 {thm-subfield}，$\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n}$ 当且仅当 $m \mid n$。唯一性：$\mathbb{F}_{p^m}$ 恰好是 $x^{p^m} - x$ 的根集，而此多项式的根集在 $\mathbb{F}_{p^n}$ 中是唯一确定的。

**(ii)** $\operatorname{Frob}_p^{n/m}$ 的不动域为 $\{x \in \mathbb{F}_{p^n} : x^{p^{n/m}} = x\} = \mathbb{F}_{p^{n/(n/m)}} = \mathbb{F}_{p^m}$。由 Artin 定理，$\operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_{p^m}) = \langle \operatorname{Frob}_p^{n/m} \rangle$。

**(iii)** $\mathbb{Z}/n\mathbb{Z}$ 的子群形如 $\langle k \rangle \cong \mathbb{Z}/(n/k)\mathbb{Z}$（其中 $k \mid n$）。对应的不动域为 $\mathbb{F}_{p^n}^{\langle \operatorname{Frob}_p^k \rangle} = \{x : x^{p^k} = x\} = \mathbb{F}_{p^k}$。注意 $\mathbb{F}_{p^n} / \mathbb{F}_{p^k}$ 的 Galois 群的阶为 $n/k$，与子群指数一致。$\blacksquare$

</ProofToggle>

::: example $\mathbb{F}_{p^6}$ 的 Galois 对应 {#ex-f6-galois}
$\operatorname{Gal}(\mathbb{F}_{p^6}/\mathbb{F}_p) \cong \mathbb{Z}/6\mathbb{Z}$。子群格和中间域：

```
子群                          中间域
──────────                    ──────────
{0}                           F_{p⁶}
⟨2⟩ ≅ Z/3Z                   F_{p³}
⟨3⟩ ≅ Z/2Z                   F_{p²}
Z/6Z                          F_p
```

这里 $\langle 2 \rangle = \{0, 2, 4\} \leq \mathbb{Z}/6\mathbb{Z}$ 的指数为 2，对应的不动域为 $\mathbb{F}_{p^3}$。$\langle 3 \rangle = \{0, 3\}$ 的指数为 3，对应 $\mathbb{F}_{p^2}$。
:::

## 迹与范 {#trace-norm}

::: definition 迹与范 {#def-trace-norm}
设 $L = \mathbb{F}_{q^n}$，$K = \mathbb{F}_q$。对 $\alpha \in L$，定义：

**迹**（trace）：$\operatorname{Tr}_{L/K}(\alpha) = \sum_{\sigma \in \operatorname{Gal}(L/K)} \sigma(\alpha) = \alpha + \alpha^q + \alpha^{q^2} + \cdots + \alpha^{q^{n-1}}$

**范**（norm）：$\operatorname{N}_{L/K}(\alpha) = \prod_{\sigma \in \operatorname{Gal}(L/K)} \sigma(\alpha) = \alpha \cdot \alpha^q \cdot \alpha^{q^2} \cdots \alpha^{q^{n-1}} = \alpha^{(q^n-1)/(q-1)}$
:::

::: proposition 迹与范的性质 {#prop-trace-norm}
**(i)** $\operatorname{Tr}_{L/K}: L \to K$ 是 $K$-线性映射（$\mathbb{F}_q$ 上的线性型），且是满射。

**(ii)** $\operatorname{N}_{L/K}: L^\times \to K^\times$ 是群同态，且是满射。

**(iii)** $\operatorname{Tr}_{L/K}$ 和 $\operatorname{N}_{L/K}$ 的值都在 $K = \mathbb{F}_q$ 中（因为它们是 Galois 群轨道的对称函数）。
:::

<ProofToggle>
<summary>**迹与范性质的证明**</summary>

**(i)** 线性：$\operatorname{Tr}(\alpha + \beta) = \sum_\sigma \sigma(\alpha + \beta) = \sum_\sigma (\sigma(\alpha) + \sigma(\beta)) = \operatorname{Tr}(\alpha) + \operatorname{Tr}(\beta)$。类似 $c \in K$ 时 $\operatorname{Tr}(c\alpha) = c\operatorname{Tr}(\alpha)$（因为 $\sigma$ 固定 $K$）。

满射：$K$-线性映射 $L \to K$ 若不为零则必满射。需证 $\operatorname{Tr} \not\equiv 0$。取 $L$ 的 $K$-基 $\{e_1, \ldots, e_n\}$。若 $\operatorname{Tr}(e_i) = 0$ 对所有 $i$，则 $\operatorname{Tr} \equiv 0$。但由 Dedekind 引理（不同自同构线性无关），不可能 $\sum_\sigma \sigma = 0$ 作为 $L \to K$ 上的函数。因此存在 $\alpha$ 使得 $\operatorname{Tr}(\alpha) \neq 0$。

**(ii)** 范是同态：$\operatorname{N}(\alpha\beta) = \prod_\sigma \sigma(\alpha\beta) = \prod_\sigma \sigma(\alpha) \cdot \prod_\sigma \sigma(\beta) = \operatorname{N}(\alpha)\operatorname{N}(\beta)$。

满射：$K^\times$ 是循环群（[§10.1](10.1-structure#thm-structure)），设 $g$ 为生成元。需找 $\alpha \in L^\times$ 使得 $\operatorname{N}(\alpha) = g$。考虑 $\operatorname{N}: L^\times \to K^\times$，其像为 $K^\times$ 的子群。设 $|\operatorname{im}(\operatorname{N})| = m$，$|K^\times| = q - 1$。由 Hilbert 定理 90 的有限域版本或直接计数（$|\ker(\operatorname{N})| = (q^n - 1)/(q - 1)$），$\operatorname{N}$ 是满射。

**(iii)** $\operatorname{Tr}(\alpha) = \sum_\sigma \sigma(\alpha)$ 是 Galois 轨道元素的和。每个 $\sigma(\alpha)$ 是 $\alpha$ 的共轭，它们是 $\min(K, \alpha)$ 的根。根的初等对称多项式在 $K$ 中（因为 $\min(K, \alpha) \in K[X]$），特别地和与积在 $K$ 中。

</ProofToggle>

::: example $\mathbb{F}_{27}$ 中迹为零的元素 {#ex-trace-zero}
在 $\mathbb{F}_{27}/\mathbb{F}_3$ 中，$\operatorname{Tr}(\alpha) = 0$（见上面的计算）。更一般地，$\operatorname{Tr}$ 的核（即迹零元素）构成 $\mathbb{F}_3$ 上的 2 维子空间。这是因为 $\operatorname{Tr}: \mathbb{F}_{27} \to \mathbb{F}_3$ 是满射线性映射，$\ker(\operatorname{Tr})$ 的维数为 $3 - 1 = 2$。

具体地，$\ker(\operatorname{Tr}) = \{x \in \mathbb{F}_{27} : x + x^3 + x^9 = 0\}$。可以验证 $\alpha$ 和 $\alpha^2$ 生成这个 2 维空间。
:::

::: example 编码理论中的迹 {#ex-trace-coding}
迹映射在编码理论中有重要应用。一个经典构造：$\mathbb{F}_{2^n}$ 上的**迹码**定义为 $\{(\operatorname{Tr}(\alpha))_{\alpha \in \mathbb{F}_{2^n}} : c \in \mathbb{F}_{2^n}\}$。

特别地，$\operatorname{Tr}: \mathbb{F}_{2^n} \to \mathbb{F}_2$ 给出一个 $\mathbb{F}_2$-线性码（1 维子空间的陪集代表），在 BCH 码和 Reed-Muller 码的构造中起核心作用。
:::

## Frobenius 作为线性算子的特征值 {#frobenius-eigenvalue}

将 $L = \mathbb{F}_{q^n}$ 视为 $K = \mathbb{F}_q$ 上的 $n$ 维向量空间，Frobenius $\varphi = \operatorname{Frob}_p$ 是 $K$-线性算子。研究其特征多项式和特征值揭示了深刻的算术-几何联系。

::: proposition Frobenius 的特征多项式 {#prop-frobenius-charpoly}
设 $\varphi: L \to L$，$x \mapsto x^q$，视为 $\mathbb{F}_q$-线性算子。则 $\varphi$ 的特征多项式为：
$$\chi_\varphi(t) = t^n - 1.$$
特别地，$\varphi$ 的所有特征值都是 $n$ 次单位根。
:::

<ProofToggle>

**证明.** $\varphi^n = \operatorname{id}$，故 $\varphi$ 满足 $t^n - 1 = 0$。因 $[L:K] = n$，$\chi_\varphi$ 的次数恰为 $n$。要证 $\chi_\varphi = t^n - 1$，只需证 $t^n - 1$ 无重因子（在特征 $p \nmid n$ 时确实如此，因为 $\gcd(t^n - 1, nt^{n-1}) = 1$）。故 $\chi_\varphi = t^n - 1$。$\blacksquare$

</ProofToggle>

::: theorem Weil 猜想（有限域上的 Riemann 假设） {#thm-weil-conjecture}
设 $X$ 是有限域 $\mathbb{F}_q$ 上的 $d$ 维光滑射影簇。则 $X$ 的 $\ell$-adic 上同调群 $H^i_{\text{ét}}(X_{\bar{\mathbb{F}}_q}, \mathbb{Q}_\ell)$ 上的几何 Frobenius 作用 $\operatorname{Frob}_q^*$ 的特征值 $\alpha_{ij}$ 满足：

**(i)** $\alpha_{ij}$ 是代数整数。

**(ii)** （Riemann 假设）$|\alpha_{ij}| = q^{j/2}$（复绝对值），其中 $j$ 是上同调次数。

**(iii)** 函数 $Z(X, t) = \exp\left(\sum_{m=1}^\infty \frac{|X(\mathbb{F}_{q^m})|}{m} t^m\right) = \prod_{j=0}^{2d} \det(1 - t \cdot \operatorname{Frob}_q^* \mid H^j)^{(-1)^{j+1}}$

是有理函数。

这个定理由 Deligne (1974) 证明，是 20 世纪代数几何最深刻的成就之一。有限域上 Frobenius 的**特征值决定计数**，将几何、算术和分析统一在同一个框架中。
:::

::: example 椭圆曲线的 Frobenius 特征值 {#ex-elliptic-frobenius}
设 $E/\mathbb{F}_q$ 是椭圆曲线。$E$ 的 zeta 函数为
$$Z(E, t) = \frac{1 - a t + q t^2}{(1-t)(1-qt)},$$
其中 $a = q + 1 - |E(\mathbb{F}_q)|$（**trace of Frobenius**）。分子 $1 - at + qt^2 = (1 - \alpha t)(1 - \beta t)$，其中 $\alpha, \beta$ 是 $\operatorname{Frob}_q^*$ 在 $H^1_{\text{ét}}(E_{\bar{\mathbb{F}}_q}, \mathbb{Q}_\ell)$ 上的特征值，满足 $|\alpha| = |\beta| = \sqrt{q}$（Weil 界）。

**Hasse 界**：$|a| \leq 2\sqrt{q}$，即 $||E(\mathbb{F}_q)| - (q+1)| \leq 2\sqrt{q}$。

这是 Galois 理论（Frobenius 自同构）、代数几何（上同调理论）和数论（点计数）三者交汇的经典例子。
:::

::: remark Frobenius 与算术几何
Frobenius 自同构的研究已远超有限域本身。在 Grothendieck 的框架中，$\ell$-adic 上同调上的 Frobenius 作用是连接几何与算术的核心工具。Frobenius 的特征值编码了簇的**所有**点计数信息，这是"Weil 上同调理论"公理体系的基石。在 Deligne 的工作中，Riemann 假设的证明使用了 **monodromy** 和 **Hard Lefschetz** 定理等代数几何的深层技术。

在现代 Langlands 纲领中，Frobenius 特征值（作为 Hecke 算子的特征值）对应于自守表示的 **L-函数**。这种 "local-global" 对应是当代数论的核心研究方向（见 [§12.1](/chapters/12-algebraic-closure/)）。
:::

## 本节总结 {#summary}

| 核心概念 | 描述 |
|---|---|
| Frobenius $\operatorname{Frob}_p$ | $\alpha \mapsto \alpha^p$，$\operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p)$ 的生成元 |
| Galois 群 | $\operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p) \cong \mathbb{Z}/n\mathbb{Z}$，循环群 |
| Galois 对应 | 子群 $\langle \operatorname{Frob}_p^k \rangle$ $\longleftrightarrow$ 中间域 $\mathbb{F}_{p^k}$（$k \mid n$） |
| 迹 $\operatorname{Tr}_{L/K}$ | $K$-线性满射 $L \to K$，$\alpha \mapsto \sum_\sigma \sigma(\alpha)$ |
| 范 $\operatorname{N}_{L/K}$ | 群同态满射 $L^\times \to K^\times$，$\alpha \mapsto \prod_\sigma \sigma(\alpha)$ |
| Weil 猜想 | Frobenius 特征值决定簇的点计数，$\|\alpha_{ij}\| = q^{j/2}$ |

::: details 自测问题
1. 计算 $\operatorname{Gal}(\mathbb{F}_{125}/\mathbb{F}_5)$ 和 $\operatorname{Frob}_5$ 的阶。$\mathbb{F}_{125}$ 有哪些子域？
2. 在 $\mathbb{F}_9 = \mathbb{F}_3(\alpha)$（$\alpha^2 + 1 = 0$）中，计算 $\operatorname{Frob}_3(\alpha)$ 和 $\operatorname{Frob}_3^2(\alpha)$。$\operatorname{Tr}_{\mathbb{F}_9/\mathbb{F}_3}(\alpha) = ?$ $\operatorname{N}_{\mathbb{F}_9/\mathbb{F}_3}(\alpha) = ?$
3. 为什么 $\operatorname{Tr}_{L/K}$ 的满射性对 Dedekind 引理的依赖是不可避免的？如果不使用 Dedekind 引理，能证明 $\operatorname{Tr} \not\equiv 0$ 吗？
4. 证明 $\mathbb{F}_{p^n}$ 中迹为零的元素恰好构成一个 $\mathbb{F}_p$ 上的 $(n-1)$ 维子空间。
5. 设 $E/\mathbb{F}_5$ 是椭圆曲线，$|E(\mathbb{F}_5)| = 9$。计算 trace of Frobenius $a$，并验证 Hasse 界。
