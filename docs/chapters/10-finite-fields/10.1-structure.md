# §10.1 有限域的结构 {#sec-finite-field-structure}

::: intuition 有限域的简洁美
有限域是 Galois 理论中最优美的对象之一。它们完全由一个素数 $p$ 和一个正整数 $n$ 决定——对每个 $(p, n)$ 恰好存在一个（同构意义下的）有限域 $\mathbb{F}_{p^n}$，其结构被 Frobenius 自同构严格控制。有限域在密码学、编码理论和代数几何中扮演核心角色。
:::

---

## 有限域的存在与唯一性 {#existence-uniqueness}

::: theorem 有限域的分类 {#thm-finite-field-classification}
**(i)** 有限域的阶必为 $p^n$（$p$ 为素数，$n \geq 1$）。

**(ii)** 对每个素数幂 $q = p^n$，恰好存在一个（同构意义下的）有限域，记为 $\mathbb{F}_q$ 或 $\operatorname{GF}(q)$（Galois 域）。

**(iii)** $\mathbb{F}_q$ 是多项式 $x^q - x$ 在 $\mathbb{F}_p$ 上的分裂域。
:::

<ProofToggle>

**证明.**

**(i)** 有限域 $F$ 的素子域同构于 $\mathbb{F}_p = \mathbb{Z}/p\mathbb{Z}$（$p = \operatorname{char} F$）。$F$ 作为 $\mathbb{F}_p$ 上的向量空间是有限维的，设维数为 $n$，则 $|F| = p^n$。

**(ii)** 设 $q = p^n$。多项式 $f(x) = x^q - x$ 的导数 $f'(x) = qx^{q-1} - 1 = -1$（在 $\mathbb{F}_p$ 中 $q = p^n \equiv 0$），故 $\gcd(f, f') = 1$，$f$ 是可分多项式。$f$ 恰好有 $q$ 个根（在代数闭包中）。

设 $L$ 为这 $q$ 个根的集合。$L$ 在加法和乘法下封闭（因为 $(\alpha+\beta)^q = \alpha^q + \beta^q = \alpha + \beta$，$(\alpha\beta)^q = \alpha^q\beta^q = \alpha\beta$）。因此 $L$ 构成一个域，$|L| = q$。

**唯一性：** 任意两个 $q$ 元域都是 $x^q - x$ 的分裂域，而分裂域在同构意义下唯一（{thm-splitting-field-unique}）。

**(iii)** 由构造，$\mathbb{F}_q$ 正是 $x^q - x$ 的分裂域。$\blacksquare$

</ProofToggle>

::: theorem 子域的刻画 {#thm-subfield}
$\mathbb{F}_{p^m}$ 是 $\mathbb{F}_{p^n}$ 的子域当且仅当 $m \mid n$。此时 $[\mathbb{F}_{p^n} : \mathbb{F}_{p^m}] = n/m$。
:::

<ProofToggle>

**证明.** 若 $\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n}$，则 $\mathbb{F}_{p^n}$ 是 $\mathbb{F}_{p^m}$ 上的向量空间，$|\mathbb{F}_{p^n}| = |\mathbb{F}_{p^m}|^{[\mathbb{F}_{p^n}:\mathbb{F}_{p^m}]}$，即 $p^n = (p^m)^{n/m}$，故 $m \mid n$。

反之，若 $m \mid n$，则 $x^{p^m} - x$ 的根都在 $\mathbb{F}_{p^n}$ 中（因为 $(x^{p^m} - x) \mid (x^{p^n} - x)$：若 $\alpha^{p^m} = \alpha$，则 $\alpha^{p^n} = \alpha^{(p^m)^{n/m}} = \alpha$）。故 $\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n}$。$\blacksquare$

</ProofToggle>

## 乘法群 {#multiplicative-group}

::: theorem 有限域的乘法群是循环群 {#thm-multiplicative-cyclic}
$\mathbb{F}_q^\times = \mathbb{F}_q \setminus \{0\}$ 关于乘法构成**循环群**，阶为 $q - 1$。
:::

<ProofToggle>

**证明.** $\mathbb{F}_q^\times$ 是阶 $q-1$ 的有限阿贝尔群。由有限阿贝尔群的结构定理，$\mathbb{F}_q^\times \cong \mathbb{Z}/d_1\mathbb{Z} \times \cdots \times \mathbb{Z}/d_r\mathbb{Z}$，$d_1 \mid d_2 \mid \cdots \mid d_r$。

方程 $x^{d_r} = 1$ 在 $\mathbb{F}_q$ 中至多有 $d_r$ 个根。但 $\mathbb{F}_q^\times$ 中每个元素都满足 $x^{d_r} = 1$（因为 $d_r$ 整除 $q-1$）。故 $q - 1 \leq d_r$。

但 $q - 1 = d_1 d_2 \cdots d_r \leq d_r^r$，且 $q - 1 \leq d_r$ 迫使 $r = 1$。故 $\mathbb{F}_q^\times \cong \mathbb{Z}/(q-1)\mathbb{Z}$，是循环群。$\blacksquare$

</ProofToggle>

::: definition 本原元 {#def-primitive-element-finite}
$\mathbb{F}_q^\times$ 的生成元称为 $\mathbb{F}_q$ 的**本原元**（primitive element）。本原元 $\alpha$ 满足 $\mathbb{F}_q = \mathbb{F}_p(\alpha)$。
:::

::: proposition 本原元的计数 {#prop-primitive-count}
$\mathbb{F}_q^\times$ 中恰有 $\varphi(q-1)$ 个本原元（其中 $\varphi$ 是 Euler 函数）。
:::

## 不可约多项式 {#irreducible-polynomials}

::: theorem $\mathbb{F}_q[x]$ 中的不可约多项式 {#thm-irreducible-count}
设 $N_q(n)$ 为 $\mathbb{F}_q[x]$ 中首一 $n$ 次不可约多项式的个数。则：
$$
N_q(n) = \frac{1}{n} \sum_{d \mid n} \mu(n/d) \cdot q^d,
$$
其中 $\mu$ 是 Möbius 函数。
:::

<ProofToggle>

**证明.** $x^{q^n} - x$ 恰好是 $\mathbb{F}_q$ 上所有首一不可约多项式 $f$ 的乘积，其中 $\deg f \mid n$。比较次数：
$$
q^n = \sum_{d \mid n} d \cdot N_q(d).
$$
由 Möbius 反演公式，$n \cdot N_q(n) = \sum_{d \mid n} \mu(n/d) q^d$。$\blacksquare$

</ProofToggle>

::: remark 渐近行为
由 Möbius 反演公式，$N_q(n) = \frac{q^n}{n} + O(q^{n/2}/n)$。特别地，$\mathbb{F}_q$ 上存在任意次数的不可约多项式，且高次不可约多项式非常多。
:::
