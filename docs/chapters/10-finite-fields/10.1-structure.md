# §10.1 有限域的结构 {#sec-finite-field-structure}

## 本节概要

::: tip 学习目标
1. 证明**有限域分类定理**：阶必为 $p^n$，对每个 $p^n$ 恰好存在一个（同构意义下）有限域 $\mathbb{F}_{p^n}$
2. 理解**子域格**：$\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n}$ 当且仅当 $m \mid n$
3. 掌握**乘法群的循环性**：$\mathbb{F}_q^\times \cong \mathbb{Z}/(q-1)\mathbb{Z}$，及其证明中的关键技巧
4. 学会计算有限域上**不可约多项式的个数**（Möbius 反演）
:::

---

## 动机 {#motivation}

有限域是 Galois 理论中最优美、最可计算的对象。它们是**唯一由阶数完全确定的域**——不像整数环 $\mathbb{Z}$ 的商 $\mathbb{Z}/n\mathbb{Z}$（$n$ 非素数时不是域），也不像代数数域（无穷多个不同构的二次扩张），有限域的世界是整齐划一的：

> 对每个素数幂 $q = p^n$，恰好存在一个 $q$ 元域 $\mathbb{F}_q$。

这种唯一性是 Galois 理论优美的体现：分裂域在同构意义下唯一（{thm-splitting-field-unique}），而 $\mathbb{F}_q$ 正是一个分裂域。有限域的结构被 Frobenius 自同构（{sec-frobenius}）严格控制，在密码学、编码理论和代数几何中有核心应用。

::: warning 非素数幂阶不存在有限域
一个有限域的阶**必须**是素数幂。$\mathbb{Z}/6\mathbb{Z}$ 不是域（$2 \cdot 3 = 0$，有零因子）。更一般地，$|F| = p^n$ 的原因在于：$F$ 的素子域必为 $\mathbb{F}_p$（因为 $F$ 的特征是某素数 $p$），而 $F$ 作为 $\mathbb{F}_p$ 上的向量空间必有有限维数 $n$。
:::

---

## §A. 有限域的存在与唯一性 {#existence-uniqueness}

::: theorem 有限域的分类 {#thm-finite-field-classification}
**(i)** 有限域的阶必为 $p^n$（$p$ 为素数，$n \geq 1$）。

**(ii)** 对每个素数幂 $q = p^n$，恰好存在一个（同构意义下的）有限域，记为 $\mathbb{F}_q$ 或 $\operatorname{GF}(q)$（Galois 域）。

**(iii)** $\mathbb{F}_q$ 是多项式 $x^q - x$ 在 $\mathbb{F}_p$ 上的分裂域。
:::

<ProofToggle>

**证明.**

**(i)** 设 $F$ 是有限域。$F$ 的特征 $\operatorname{char} F = p$（素数），因为有限整环的特征必为素数。素子域 $\mathbb{F}_p \cong \mathbb{Z}/p\mathbb{Z} \subseteq F$。$F$ 作为 $\mathbb{F}_p$-向量空间是有限维的（$|F|$ 有限），设维数为 $n$，则 $|F| = p^n$。

**(ii)** 设 $q = p^n$。定义 $f(x) = x^q - x \in \mathbb{F}_p[x]$。关键观察：

- **$f$ 是可分多项式：** $f'(x) = qx^{q-1} - 1 = -1$（因为 $q = p^n \equiv 0$ 在 $\mathbb{F}_p$ 中），故 $\gcd(f, f') = 1$。
- **$f$ 恰好有 $q$ 个根：** 由可分性，在代数闭包 $\overline{\mathbb{F}}_p$ 中，$f$ 恰好有 $q$ 个不同根。

设 $L = \{\alpha \in \overline{\mathbb{F}}_p : \alpha^q = \alpha\}$（$f$ 的根集）。则 $L$ 构成一个域：

- **加法封闭：** $(\alpha + \beta)^q = \alpha^q + \beta^q = \alpha + \beta$（利用特征 $p$ 下的 Frobenius 性质 $(a+b)^p = a^p + b^p$，进而 $(a+b)^{p^n} = a^{p^n} + b^{p^n}$）。
- **乘法封闭：** $(\alpha\beta)^q = \alpha^q \beta^q = \alpha\beta$。
- **含 $0, 1$：** $0^q = 0$，$1^q = 1$。
- **逆元：** 若 $\alpha \neq 0$，则 $(\alpha^{-1})^q = (\alpha^q)^{-1} = \alpha^{-1}$。

故 $L$ 是 $q$ 元域，$|L| = q$。

**唯一性：** 任意两个 $q$ 元域都是 $x^q - x$ 的分裂域（因为 $x^q - x$ 在每个 $q$ 元域中恰好有 $q$ 个根，恰好就是全部元素）。分裂域在同构意义下唯一（{thm-splitting-field-unique}）。

**(iii)** 由构造，$\mathbb{F}_q = L$ 正是 $x^q - x$ 在 $\mathbb{F}_p$ 上的分裂域。$\blacksquare$

</ProofToggle>

::: intuition 为什么 $x^q - x$ 是关键
$x^q - x$ 的美妙之处在于：它的根集**自动封闭**在域运算下。这来自特征 $p$ 的特殊性质 $(a+b)^p = a^p + b^p$——这在特征 $0$ 中不成立！

从 Galois 理论的视角，$x^q - x$ 的分裂域存在且唯一是分裂域一般理论（{thm-splitting-field-unique}）的直接推论。但有限域的特殊之处在于：**同一个多项式的分裂域对每个 $q$ 都恰好给出 $q$ 元域**。这种"完全分类"在数学中极为罕见。
:::

## §B. 子域格 {#subfield-lattice}

::: theorem 子域的刻画 {#thm-subfield}
$\mathbb{F}_{p^m}$ 是 $\mathbb{F}_{p^n}$ 的子域当且仅当 $m \mid n$。此时 $[\mathbb{F}_{p^n} : \mathbb{F}_{p^m}] = n/m$。
:::

<ProofToggle>

**证明.**

$(\Rightarrow)$ 若 $\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n}$，则 $\mathbb{F}_{p^n}$ 是 $\mathbb{F}_{p^m}$ 上的向量空间。设维数为 $d$，则 $|\mathbb{F}_{p^n}| = |\mathbb{F}_{p^m}|^d$，即 $p^n = (p^m)^d = p^{md}$，故 $n = md$，$m \mid n$。且 $d = n/m$。

$(\Leftarrow)$ 若 $m \mid n$，则 $x^{p^m} - x$ 的根都在 $\mathbb{F}_{p^n}$ 中：若 $\alpha^{p^m} = \alpha$，则

$$
\alpha^{p^n} = \alpha^{(p^m)^{n/m}} = \alpha.
$$

故 $x^{p^m} - x$ 整除 $x^{p^n} - x$（因为前者的根都是后者的根，且都是可分的）。故 $\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n}$。$\blacksquare$

</ProofToggle>

::: example 子域格 {#ex-subfield-lattice}
$\mathbb{F}_{p^{12}}$ 的子域格由 $12$ 的因子决定：

```
        F_{p^12}
       /   |    \
    F_{p^6} F_{p^4} F_{p^3}
       \   |   /
        F_{p^2}
          |
        F_{p}
```

$\mathbb{F}_{p^{12}}$ 有子域 $\mathbb{F}_{p^d}$（$d = 1, 2, 3, 4, 6, 12$）。子域格与 $12$ 的因子格**反序同构**：$d_1 \mid d_2 \iff \mathbb{F}_{p^{d_2}} \subseteq \mathbb{F}_{p^{d_1}}$。

特别地：$\mathbb{F}_{p^6}$ 和 $\mathbb{F}_{p^4}$ 都包含 $\mathbb{F}_{p^2}$（因为 $\gcd(6,4) = 2$），它们的交 $\mathbb{F}_{p^6} \cap \mathbb{F}_{p^4} = \mathbb{F}_{p^2}$。
:::

## §C. 乘法群的循环性 {#multiplicative-group}

这是有限域理论中最基本的结构性定理之一。

::: theorem 有限域的乘法群是循环群 {#thm-multiplicative-cyclic}
$\mathbb{F}_q^\times = \mathbb{F}_q \setminus \{0\}$ 关于乘法构成**循环群**，阶为 $q - 1$。
:::

<ProofToggle>

**证明.** $\mathbb{F}_q^\times$ 是阶 $q-1$ 的有限阿贝尔群。由有限阿贝尔群的结构定理，

$$
\mathbb{F}_q^\times \cong \mathbb{Z}/d_1\mathbb{Z} \times \cdots \times \mathbb{Z}/d_r\mathbb{Z}, \quad d_1 \mid d_2 \mid \cdots \mid d_r.
$$

我们证明 $r = 1$（即 $\mathbb{F}_q^\times$ 是循环群）。

**关键步骤：** 方程 $x^{d_r} = 1$ 在域 $\mathbb{F}_q$ 中至多有 $d_r$ 个根（因为 $x^{d_r} - 1$ 是 $d_r$ 次多项式）。但 $\mathbb{F}_q^\times$ 中**每个元素**都满足 $x^{d_r} = 1$（因为 $d_r$ 整除 $\operatorname{exp}(\mathbb{F}_q^\times)$，而 $\operatorname{exp}(\mathbb{F}_q^\times)$ 整除 $q-1$，且 $d_r$ 是 $\mathbb{Z}/d_r\mathbb{Z}$ 中元素的最大阶）。故

$$
q - 1 = |\mathbb{F}_q^\times| \leq d_r \quad (\text{根数上界}).
$$

但 $q - 1 = d_1 d_2 \cdots d_r$，且 $d_1 \mid d_2 \mid \cdots \mid d_r$ 故 $d_1 d_2 \cdots d_r \geq d_r$（当 $r \geq 1$ 时等号成立仅当 $r = 1$）。结合 $q-1 \leq d_r$，得 $d_1 d_2 \cdots d_r \leq d_r$，即 $d_1 \cdots d_{r-1} \leq 1$，故 $r = 1$。

因此 $\mathbb{F}_q^\times \cong \mathbb{Z}/(q-1)\mathbb{Z}$，是循环群。$\blacksquare$

</ProofToggle>

::: intuition 为什么乘法群必须是循环的
证明的核心是**域中方程根数的限制**：$n$ 次多项式在域中至多有 $n$ 个根。如果 $\mathbb{F}_q^\times$ 不是循环的，就会有"太多"元素满足同一个低次方程，与根数上界矛盾。

这个论证对**任何有限除环**也成立——结合 Wedderburn 小定理（有限除环是域），说明有限域是有限除环的唯一类型。
:::

::: definition 本原元 {#def-primitive-element-finite}
$\mathbb{F}_q^\times$ 的生成元称为 $\mathbb{F}_q$ 的**本原元**（primitive element）。本原元 $\alpha$ 满足 $\mathbb{F}_q = \mathbb{F}_p(\alpha)$。
:::

::: proposition 本原元的计数 {#prop-primitive-count}
$\mathbb{F}_q^\times$ 中恰有 $\varphi(q-1)$ 个本原元（其中 $\varphi$ 是 Euler 函数）。
:::

::: example 计算小有限域 {#ex-small-finite-fields}

**(i) $\mathbb{F}_4$：** $q = 4 = 2^2$。$\mathbb{F}_4 = \mathbb{F}_2[x]/(x^2+x+1)$（$x^2+x+1$ 是 $\mathbb{F}_2$ 上唯一的二次不可约多项式）。元素为 $\{0, 1, \alpha, \alpha+1\}$，其中 $\alpha^2 = \alpha + 1$（即 $\alpha$ 是 $x^2+x+1$ 的根）。

乘法群 $\mathbb{F}_4^\times = \{1, \alpha, \alpha+1\} \cong \mathbb{Z}/3\mathbb{Z}$（$\alpha$ 和 $\alpha+1$ 都是本原元）。$\varphi(3) = 2$，确实有两个本原元。

**验证域公理：** $(\alpha+1)^2 = \alpha^2 + 1 = \alpha$，$(\alpha+1) \cdot \alpha = \alpha^2 + \alpha = 1$。一切自洽。

**(ii) $\mathbb{F}_8$：** $q = 8 = 2^3$。$\mathbb{F}_8 = \mathbb{F}_2[x]/(x^3+x+1)$（$x^3+x+1$ 不可约于 $\mathbb{F}_2[x]$）。$\mathbb{F}_8^\times \cong \mathbb{Z}/7\mathbb{Z}$（7 阶循环群）。$\varphi(7) = 6$，每个非零非一元素都是本原元！

**(iii) $\mathbb{F}_9$：** $q = 9 = 3^2$。$\mathbb{F}_9 = \mathbb{F}_3[x]/(x^2+1)$（$x^2+1$ 不可约于 $\mathbb{F}_3[x]$，因为 $-1$ 不是 $\mathbb{F}_3$ 中的平方：$0^2 = 0$，$1^2 = 1$，$2^2 = 1$）。$\mathbb{F}_9^\times \cong \mathbb{Z}/8\mathbb{Z}$。$\varphi(8) = 4$，有 4 个本原元。
:::

## §D. 不可约多项式的计数 {#irreducible-polynomials}

::: theorem $\mathbb{F}_q[x]$ 中的不可约多项式 {#thm-irreducible-count}
设 $N_q(n)$ 为 $\mathbb{F}_q[x]$ 中首一 $n$ 次不可约多项式的个数。则：
$$
N_q(n) = \frac{1}{n} \sum_{d \mid n} \mu(n/d) \cdot q^d,
$$
其中 $\mu$ 是 Möbius 函数。
:::

<ProofToggle>

**证明.** 关键观察：$x^{q^n} - x$ 恰好是 $\mathbb{F}_q$ 上所有首一不可约多项式 $f$ 的乘积，其中 $\deg f \mid n$。

**为什么？** $\alpha$ 是 $x^{q^n} - x$ 的根 $\iff$ $\alpha^{q^n} = \alpha$ $\iff$ $\alpha \in \mathbb{F}_{q^n}$ $\iff$ $\alpha$ 的极小多项式 $m_\alpha(x)$ 在 $\mathbb{F}_q$ 上不可约且 $\deg m_\alpha \mid n$（因为 $\mathbb{F}_{q^n} = \mathbb{F}_{q^d}$ 其中 $d = [\mathbb{F}_q(\alpha):\mathbb{F}_q] = \deg m_\alpha$，且 $\mathbb{F}_{q^d} \subseteq \mathbb{F}_{q^n} \iff d \mid n$）。

比较次数：

$$
q^n = \sum_{d \mid n} d \cdot N_q(d).
$$

由 Möbius 反演公式（若 $g(n) = \sum_{d \mid n} f(d)$ 则 $f(n) = \sum_{d \mid n} \mu(n/d) g(d)$）：

$$
n \cdot N_q(n) = \sum_{d \mid n} \mu(n/d) \cdot q^d, \quad \text{即} \quad N_q(n) = \frac{1}{n} \sum_{d \mid n} \mu(n/d) q^d. \quad \blacksquare
$$

</ProofToggle>

::: example 具体计算 {#ex-irreducible-count}
**(i) $N_2(3)$：** $\mathbb{F}_2[x]$ 中三次不可约多项式的个数。

$$
N_2(3) = \frac{1}{3}(\mu(1) \cdot 2^3 + \mu(3) \cdot 2^1) = \frac{1}{3}(8 - 2) = 2.
$$

确实：$x^3 + x + 1$ 和 $x^3 + x^2 + 1$ 是 $\mathbb{F}_2[x]$ 中仅有的两个三次不可约多项式。

**(ii) $N_2(4)$：**

$$
N_2(4) = \frac{1}{4}(\mu(1) \cdot 2^4 + \mu(2) \cdot 2^2 + \mu(4) \cdot 2^1) = \frac{1}{4}(16 - 4 + 0) = 3.
$$

$\mathbb{F}_2[x]$ 中恰有 3 个四次不可约多项式：$x^4+x+1$，$x^4+x^3+1$，$x^4+x^3+x^2+x+1$。

**(iii) 渐近行为.** $N_q(n) = \frac{q^n}{n} + O(q^{n/2}/n)$。特别地，$\mathbb{F}_q$ 上存在任意次数的不可约多项式，且高次不可约多项式的比例趋于 $1/n$（在所有首一 $n$ 次多项式中）。
:::

::: intuition 不可约多项式"很多"
$N_q(n) \approx q^n/n$ 的含义是：在 $\mathbb{F}_q$ 上的 $q^n$ 个首一 $n$ 次多项式中，大约有 $1/n$ 的比例是不可约的。这与整数中素数的密度 $1/\log n$ 类比（虽然比例不同，但精神一致：不可约多项式在多项式环中的角色类似素数在整数环中的角色）。
:::

## §E. 本节总结 {#summary}

| 概念 | 核心内容 |
|:-----|:---------|
| **分类定理** | 阶必为 $p^n$，$\mathbb{F}_{p^n} \cong x^{p^n}-x$ 的分裂域，唯一 |
| **子域格** | $\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n} \iff m \mid n$，指数 $n/m$ |
| **乘法群** | $\mathbb{F}_q^\times \cong \mathbb{Z}/(q-1)\mathbb{Z}$（循环群），本原元 $\varphi(q-1)$ 个 |
| **不可约多项式** | $N_q(n) = \frac{1}{n}\sum_{d \mid n} \mu(n/d) q^d \approx q^n/n$ |

::: details 自测问题
1. 为什么 $x^q - x$ 的根集对加法和乘法封闭？这个论证在哪一步用到了特征 $p$？
2. $\mathbb{F}_{p^6}$ 有哪些子域？子域格的结构是什么？
3. 为什么 $\mathbb{F}_q^\times$ 是循环群？这个证明的关键步骤是什么？它对一般有限阿贝尔群有什么启示？
4. 计算 $N_3(4)$（$\mathbb{F}_3$ 上四次不可约多项式的个数）。
5. 为什么 $\mathbb{F}_4$ 不是 $\mathbb{Z}/4\mathbb{Z}$？它们有什么根本区别？
:::
