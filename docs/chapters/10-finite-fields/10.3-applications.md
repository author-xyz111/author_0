# §10.3 有限域的应用 {#sec-finite-field-applications}

::: intuition 从纯数学到应用
有限域虽然是纯粹的代数对象，但它们在现代信息科学中扮演核心角色。密码学、编码理论、组合设计、甚至量子计算都深度依赖有限域的结构。Galois 理论保证了这些应用的数学基础。
:::

---

## 纠错码 {#error-correcting-codes}

::: definition 循环码 {#def-cyclic-code}
$\mathbb{F}_q^n$ 的一个**线性码**（linear code）是一个 $\mathbb{F}_q$-子空间 $C \subseteq \mathbb{F}_q^n$。一个线性码是**循环码**（cyclic code），如果对 $(c_0, c_1, \ldots, c_{n-1}) \in C$，有 $(c_{n-1}, c_0, \ldots, c_{n-2}) \in C$。
:::

::: theorem 循环码与理想 {#thm-cyclic-code-ideal}
循环码与 $\mathbb{F}_q[x]/(x^n - 1)$ 的理想一一对应。每个循环码 $C$ 由一个唯一的首一多项式 $g(x) \mid (x^n - 1)$ 生成（$g$ 称为**生成多项式**）。
:::

<ProofToggle>

**证明.** 将码字 $(c_0, \ldots, c_{n-1})$ 与多项式 $c(x) = c_0 + c_1 x + \cdots + c_{n-1} x^{n-1}$ 对应。循环移位对应于乘以 $x$（模 $x^n - 1$）。循环码恰好是 $\mathbb{F}_q[x]/(x^n - 1)$ 中对乘以 $x$ 封闭的子空间，即理想。由于 $\mathbb{F}_q[x]$ 是主理想环，$\mathbb{F}_q[x]/(x^n-1)$ 的理想由 $x^n - 1$ 的因子生成。$\blacksquare$

</ProofToggle>

::: example Reed–Solomon 码 {#ex-reed-solomon}
设 $\alpha$ 是 $\mathbb{F}_q$ 的本原元。**Reed–Solomon 码** $\operatorname{RS}(k, n)$ 定义为：
$$
C = \{(f(\alpha^0), f(\alpha^1), \ldots, f(\alpha^{n-1})) : f \in \mathbb{F}_q[x],\, \deg f < k\}.
$$
$C$ 是 $[n, k, n-k+1]_q$ 码（长度 $n$，维数 $k$，最小距离 $n-k+1$），达到了 Singleton 界，是**最大距离可分码**（MDS 码）。

Reed–Solomon 码广泛用于 CD/DVD 纠错、QR 码、深空通信和 RAID 6 存储系统。
:::

## 密码学 {#cryptography}

::: theorem Diffie–Hellman 与离散对数 {#thm-diffie-hellman}
设 $G = \mathbb{F}_q^\times$（循环群，阶 $q - 1$），$g$ 为生成元。

**离散对数问题**（DLP）：给定 $g, h \in G$，找到 $x$ 使得 $g^x = h$。

**Diffie–Hellman 密钥交换：** Alice 选随机 $a$，发送 $g^a$；Bob 选随机 $b$，发送 $g^b$。共享密钥为 $g^{ab}$。安全性基于 **计算 Diffie–Hellman 假设**（CDH）：给定 $g, g^a, g^b$，计算 $g^{ab}$ 是困难的。
:::

::: remark 椭圆曲线与有限域
现代密码学（如 ECDSA、EdDSA）使用**有限域上的椭圆曲线**。椭圆曲线 $E(\mathbb{F}_q)$ 的点构成一个近似循环的阿贝尔群，其上的离散对数问题比 $\mathbb{F}_q^\times$ 上更难（需要亚指数或指数时间算法），因此可以用更短的密钥实现相同的安全级别。
:::

## 有限域上的代数几何 {#algebraic-geometry}

::: theorem Weil 猜想（有限域情形） {#thm-weil-conjectures}
设 $X$ 是 $\mathbb{F}_q$ 上的 $d$ 维光滑射影簇，$N_r = |X(\mathbb{F}_{q^r})|$ 为 $X$ 在 $\mathbb{F}_{q^r}$ 上的有理点个数。则：

**(i)** **有理性：** Zeta 函数 $Z(X, t) = \exp\Bigl(\sum_{r=1}^\infty \frac{N_r}{r} t^r\Bigr)$ 是有理函数。

**(ii)** **函数方程：** $Z(X, 1/q^d t) = \pm q^{d\chi/2} t^\chi \cdot Z(X, t)$（$\chi$ 为 Euler 示性数）。

**(iii)** **Riemann 假设：** $Z(X, t) = \frac{P_1(t) P_3(t) \cdots P_{2d-1}(t)}{P_0(t) P_2(t) \cdots P_{2d}(t)}$，其中 $P_i(t) = \prod_j (1 - \alpha_{ij} t)$，$|\alpha_{ij}| = q^{i/2}$。
:::

::: intuition Weil 猜想的意义
Weil 猜想是有限域上代数几何的基石。它们将有限域上簇的点计数与拓扑（上同调）联系起来。Deligne 于 1974 年证明了 Riemann 假设部分（获得 Fields 奖），建立了 **étale 上同调**理论——这正是现代代数几何和数论的支柱之一。
:::

## 分圆多项式与有限域 {#cyclotomic}

::: theorem 有限域上的分圆多项式 {#thm-cyclotomic-finite}
$n$ 次分圆多项式 $\Phi_n(x)$ 在 $\mathbb{F}_q$ 中的分解完全由 $q \bmod n$ 决定：

设 $q$ 模 $n$ 的阶为 $f$（即 $f = \min\{k > 0 : q^k \equiv 1 \pmod{n}\}$，假设 $\gcd(q, n) = 1$）。则 $\Phi_n(x)$ 在 $\mathbb{F}_q[x]$ 中分解为 $\varphi(n)/f$ 个互异的 $f$ 次不可约多项式。
:::

<ProofToggle>

**证明.** $\Phi_n$ 的根是 $n$ 次本原单位根。在 $\mathbb{F}_{q^f}$ 中，$n \mid (q^f - 1)$，故本原 $n$ 次单位根 $\zeta_n$ 存在。$\zeta_n$ 在 $\mathbb{F}_q$ 上的极小多项式次数为 $f$（因为 $\zeta_n, \zeta_n^q, \zeta_n^{q^2}, \ldots, \zeta_n^{q^{f-1}}$ 恰好给出 $f$ 个互异共轭）。$\Phi_n$ 的 $\varphi(n)$ 个根被分成 $\varphi(n)/f$ 个 Frobenius 轨道，每个轨道给出一个 $f$ 次不可约因子。$\blacksquare$

</ProofToggle>
