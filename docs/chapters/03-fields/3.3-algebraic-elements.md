# §3.3 代数元与极小多项式 {#sec-algebraic-elements}

::: tip 本节学习目标
1. 区分**代数元**与**超越元**，理解这对区分对 Galois 理论的根本重要性。
2. 掌握**极小多项式**的构造、唯一性和不可约性，能够对具体的 $\alpha$ 和 $K$ 计算 $m_{\alpha,K}$。
3. 理解极小多项式**依赖于基域**：同一个 $\alpha$ 在不同 $K$ 上可以有不同的极小多项式。
4. 掌握**代数单扩张的结构定理**：$K(\alpha) = K[\alpha] \cong K[X]/(m_\alpha)$，并能在具体例子中做计算。
5. 理解**共轭**的定义及其与域自同构（从而与 Galois 群）的联系。
6. 掌握**代数扩张的塔定理**。
:::

---

## 3.3.1 代数元与超越元 {#sec-algebraic-transcendental}

**定义 3.3.1** {#def-algebraic-element} 设 $L/K$ 是域扩张，$\alpha \in L$。
1. 若 $\alpha$ 是某个非零多项式 $f(X) \in K[X]$ 的根，即 $f(\alpha) = 0$，则称 $\alpha$ 在 $K$ 上是**代数的**（algebraic）。
2. 若 $\alpha$ 不在 $K$ 上代数，则称 $\alpha$ 在 $K$ 上是**超越的**（transcendental）。

::: example 代数元 {#ex-algebraic-elements}
- $\sqrt{2}$ 在 $\mathbb{Q}$ 上是代数的，因为它是 $x^2 - 2 \in \mathbb{Q}[x]$ 的根。
- $i = \sqrt{-1}$ 在 $\mathbb{R}$ 上是代数的，因为它是 $x^2 + 1 \in \mathbb{R}[x]$ 的根。
- $i$ 在 $\mathbb{Q}$ 上也是代数的——同一个多项式 $x^2 + 1 \in \mathbb{Q}[x]$。
- 任何 $\alpha \in K$ 在 $K$ 上都是代数的，因为它是 $x - \alpha \in K[x]$ 的根。
- $1 + \sqrt{2}$ 在 $\mathbb{Q}$ 上是代数的：$(1+\sqrt{2})^2 = 3 + 2\sqrt{2}$，所以 $(1+\sqrt{2})^2 - 2(1+\sqrt{2}) - 1 = 0$，即 $1+\sqrt{2}$ 是 $x^2 - 2x - 1$ 的根。
- $\sqrt{2} + \sqrt{3}$ 在 $\mathbb{Q}$ 上是代数的（见下面的例子）。
:::

::: example 超越元 {#ex-transcendental}
- $\pi$ 和 $e$ 在 $\mathbb{Q}$ 上是超越的。这是非常深刻的数学定理：$\pi$ 的超越性由 Lindemann 于 1882 年证明（由此推出"化圆为方"不可能，见 [§9.2](/chapters/09-solvability/9.2-constructibility)），$e$ 的超越性由 Hermite 于 1873 年证明。
- 设 $t$ 是未定元，则 $t$ 在 $K$ 上是超越的（根据 $K(t)$ 的定义）。
- $\pi^2$ 在 $\mathbb{Q}$ 上也是超越的（因为如果 $\pi^2$ 是代数的，$\pi$ 也是代数的——代数元的代数元仍是代数的）。
:::

::: intuition 代数元与超越元的区别
代数元满足某个多项式方程，因此它的"行为"被一个有限的代数关系所约束。超越元不满足任何多项式方程——它在代数意义上是"自由"的。

**信息论类比**：代数元可以被其极小多项式完全描述（有限信息），而超越元不能被任何有限代数关系捕获（无限信息量）。

这个区别对 Galois 理论至关重要：**Galois 理论完全建立在代数元之上**。超越扩张有自己的理论（超越基、超越次数），但不是本书的主题。
:::

::: warning 代数依赖于基域
"$\alpha$ 是代数的"这个说法**没有意义**——必须指定基域 $K$。例如：

- $\sqrt{2}$ 在 $\mathbb{Q}$ 上是代数的（极小多项式 $x^2 - 2$）。
- $\sqrt{2}$ 在 $\mathbb{R}$ 上也是代数的（极小多项式 $x - \sqrt{2}$）。
- $\sqrt{2}$ 在 $\mathbb{Q}(\sqrt{2})$ 上是代数的（极小多项式 $x - \sqrt{2}$）。

极小多项式（以及扩张次数）依赖于基域——这将是后续所有理论的基本出发点。
:::

## 3.3.2 代数扩张 {#sec-algebraic-extension}

**定义 3.3.2** {#def-algebraic-extension} 设 $L/K$ 是域扩张。若 $L$ 中的每个元素都在 $K$ 上是代数的，则称 $L/K$ 是**代数扩张**（algebraic extension）。

::: proposition {#prop-algebraic-extension-criteria}
设 $L/K$ 是域扩张。以下条件等价：
1. $L/K$ 是代数扩张。
2. $L$ 中每个元素的 $K$-极小多项式存在。
3. 对任意 $\alpha \in L$，单扩张 $K(\alpha)/K$ 是有限扩张。
:::

<ProofToggle>

**证明.** 

$(1) \Rightarrow (2)$：若 $\alpha \in L$ 在 $K$ 上代数，则它满足某个非零多项式。在所有满足的首一多项式中取次数最小的，即为极小多项式（{def-minimal-polynomial}）。

$(2) \Rightarrow (3)$：设 $m_\alpha(X)$ 是 $\alpha$ 在 $K$ 上的极小多项式，$\deg m_\alpha = n$。由 {thm-algebraic-simple-extension}，$[K(\alpha) : K] = n < \infty$。

$(3) \Rightarrow (1)$：若 $K(\alpha)/K$ 是有限扩张，则由 {thm-finite-implies-algebraic}，$\alpha$ 在 $K$ 上是代数的。 $\blacksquare$

</ProofToggle>

::: remark 有限扩张 vs 代数扩张
- 有限扩张 $\Rightarrow$ 代数扩张（{thm-finite-implies-algebraic}）。
- 代数扩张 $\not\Rightarrow$ 有限扩张。例如 $\bar{\mathbb{Q}}/\mathbb{Q}$（代数闭包，见 [§6.1](/chapters/06-algebraic-closure/6.1-algebraic-closure)）是代数扩张，但不是有限扩张。
- 有限扩张是"有限生成的代数扩张"（且是代数的）。
- 代数扩张可以是无限的，但**每个元素**各自只生成有限子扩张。

这个区分在 [第十一章](/chapters/11-infinite-galois/) 的无限 Galois 理论中将变得至关重要。
:::

## 3.3.3 极小多项式 {#sec-minimal-polynomial}

**定义 3.3.3** {#def-minimal-polynomial} 设 $L/K$ 是域扩张，$\alpha \in L$ 在 $K$ 上是代数的。定义 $\alpha$ 在 $K$ 上的**极小多项式**（minimal polynomial）$m_{\alpha, K}(X)$（或简记为 $m_\alpha(X)$）为满足以下条件的多项式：
1. $m_\alpha(X) \in K[X]$ 是首一的；
2. $m_\alpha(\alpha) = 0$；
3. 对任何 $f(X) \in K[X]$ 使得 $f(\alpha) = 0$，有 $m_\alpha(X) \mid f(X)$。

**定理 3.3.4** {#thm-minimal-polynomial} 设 $L/K$ 是域扩张，$\alpha \in L$ 在 $K$ 上代数。则：
1. 极小多项式 $m_\alpha(X)$ 存在且唯一。
2. $m_\alpha(X)$ 在 $K[X]$ 中不可约。
3. 若 $f(\alpha) = 0$（$f \in K[X]$），则 $m_\alpha(X) \mid f(X)$。
4. $m_\alpha(X)$ 是 $\{f \in K[X] \mid f(\alpha) = 0\}$ 的生成元（作为 $K[X]$ 的主理想）。

<ProofToggle>

**证明.**

**(1) 存在性**：因为 $\alpha$ 在 $K$ 上代数，集合 $I_\alpha := \{f \in K[X] \mid f(\alpha) = 0\}$ 非零。$I_\alpha$ 是 $K[X]$ 的理想（因为 $K[X]$ 是主理想整环，见 {thm-ideal-is-principal}），故 $I_\alpha = (g)$ 对某个 $g \in K[X]$。取 $m_\alpha$ 为 $g$ 的首一化（即除以首项系数），则 $m_\alpha$ 满足定义的三个条件。

**唯一性**：设 $m_1, m_2$ 都是极小多项式。则 $m_1 \mid m_2$ 且 $m_2 \mid m_1$。因为两者都是首一的，故 $m_1 = m_2$。

**(2)** 反设 $m_\alpha(X) = a(X) b(X)$，其中 $a, b \in K[X]$ 且 $\deg a, \deg b \geq 1$。则 $0 = m_\alpha(\alpha) = a(\alpha) b(\alpha)$。因为 $L$ 是域（从而是整环），$a(\alpha) = 0$ 或 $b(\alpha) = 0$。假设 $a(\alpha) = 0$，则 $a \in I_\alpha$，从而 $m_\alpha \mid a$。但 $\deg a < \deg m_\alpha$，矛盾。因此 $m_\alpha$ 不可约。

**(3)** 设 $f(\alpha) = 0$。由 $I_\alpha = (m_\alpha)$，有 $m_\alpha \mid f$。

**(4)** 由 (1) 的证明中 $I_\alpha = (m_\alpha)$ 已得。 $\blacksquare$

</ProofToggle>

::: example 具体的极小多项式计算 {#ex-minimal-poly-examples}

**例 1：$m_{\sqrt{2},\, \mathbb{Q}}$。** $\sqrt{2}$ 满足 $x^2 - 2$。$x^2 - 2$ 在 $\mathbb{Q}$ 上不可约（Eisenstein，$p = 2$）。因此 $m_{\sqrt{2},\, \mathbb{Q}} = x^2 - 2$。

**例 2：$m_{i,\, \mathbb{Q}}$。** $i$ 满足 $x^2 + 1$。$x^2 + 1$ 在 $\mathbb{Q}$ 上不可约（无有理根）。$m_{i,\, \mathbb{Q}} = x^2 + 1$。

**例 3：$m_{1+\sqrt{2},\, \mathbb{Q}}$。** 设 $\alpha = 1 + \sqrt{2}$。则 $\alpha - 1 = \sqrt{2}$，$(\alpha - 1)^2 = 2$，$\alpha^2 - 2\alpha - 1 = 0$。所以 $\alpha$ 是 $x^2 - 2x - 1$ 的根。验证不可约：判别式 $\Delta = 4 + 4 = 8$，$\sqrt{8} = 2\sqrt{2} \notin \mathbb{Q}$。$m_{1+\sqrt{2},\, \mathbb{Q}} = x^2 - 2x - 1$。

**例 4：$m_{\sqrt{2}+\sqrt{3},\, \mathbb{Q}}$。** 设 $\alpha = \sqrt{2} + \sqrt{3}$。

$$\alpha^2 = 5 + 2\sqrt{6}, \quad \alpha^2 - 5 = 2\sqrt{6}, \quad (\alpha^2 - 5)^2 = 24$$

$$\alpha^4 - 10\alpha^2 + 1 = 0$$

所以 $\alpha$ 是 $x^4 - 10x^2 + 1$ 的根。需要验证这是极小多项式（不可约）。在 $\mathbb{Q}[x]$ 中：没有有理根（$\pm 1$ 代入均不为零），且 $(x^2 - ax + b)(x^2 + ax + c) = x^4 + (c+b-a^2)x^2 + \ldots$ 要求 $c + b - a^2 = -10$，$bc = 1$，$a(c-b) = 0$。若 $a = 0$，$b + c = -10$，$bc = 1$，$b$ 和 $c$ 是 $t^2 + 10t + 1 = 0$ 的根 $= -5 \pm \sqrt{24}$，不在 $\mathbb{Q}$ 中。若 $c = b$，$b^2 = 1$，$b = \pm 1$，$2b - a^2 = -10$，$a^2 = 2b + 10 = 12$ 或 $8$，$a \notin \mathbb{Q}$。所以不可约。$m_{\sqrt{2}+\sqrt{3},\, \mathbb{Q}} = x^4 - 10x^2 + 1$。

**例 5：$m_{\sqrt{2},\, \mathbb{Q}(\sqrt{2})}$。** $\sqrt{2}$ 在 $\mathbb{Q}(\sqrt{2})$ 中满足 $x - \sqrt{2} \in \mathbb{Q}(\sqrt{2})[x]$。$m_{\sqrt{2},\, \mathbb{Q}(\sqrt{2})} = x - \sqrt{2}$。

**关键对比**：$m_{\sqrt{2},\, \mathbb{Q}} = x^2 - 2$（$2$ 次），$m_{\sqrt{2},\, \mathbb{Q}(\sqrt{2})} = x - \sqrt{2}$（$1$ 次）。极小多项式**依赖于基域**。
:::

### 计算极小多项式的方法 {#sec-compute-min-poly}

::: tip 实用计算技巧
给定 $\alpha \in L$ 和基域 $K$，计算 $m_{\alpha,K}$ 的步骤：

**方法 1（直接法）**：找到 $\alpha$ 满足的一个首一多项式 $f \in K[x]$，然后验证 $f$ 在 $K[x]$ 中不可约。如果不可约，则 $f = m_\alpha$。

**方法 2（线性代数法）**：计算 $1, \alpha, \alpha^2, \ldots$，直到找到线性相关的序列。设 $n$ 是使 $\{1, \alpha, \ldots, \alpha^n\}$ 线性相关的最小正整数，则 $m_\alpha = \alpha^n + c_{n-1}\alpha^{n-1} + \cdots + c_0$ 是线性关系给出的首一多项式。

**方法 3（共轭乘积法）**：如果知道 $\alpha$ 的所有 $K$-共轭 $\alpha = \alpha_1, \alpha_2, \ldots, \alpha_n$，则 $m_\alpha = \prod_{i=1}^n (x - \alpha_i)$。

**方法 4（矩阵法）**：对 $K(\alpha)/K$ 上的乘法映射 $\mu_\alpha: \beta \mapsto \alpha\beta$，其特征多项式等于 $m_\alpha$（如果 $[K(\alpha):K] = \deg m_\alpha$）。
:::

::: warning 常见误区

**误区 1**："找到一个满足的多项式就是极小多项式。" 错！必须验证不可约。例如 $x^4 - 4$ 满足 $\sqrt{2}$，但 $m_{\sqrt{2},\mathbb{Q}} = x^2 - 2$。

**误区 2**："极小多项式的次数等于 $\alpha$ 满足的最低次多项式的次数。" 不完全对——如果最低次的首一多项式可约，它可能不是极小多项式。需要的是最低次数的**不可约**首一多项式。

**误区 3**："$m_{\alpha,K}$ 的次数总等于 $m_\alpha$ 在代数闭包中的不同根的个数。" 这在特征 0 中成立，但在正特征中可能不成立——不可分元素的极小多项式有重根（见 [§4.3](/chapters/04-polynomials/4.3-separability)）。
:::

## 3.3.4 代数单扩张的结构 {#sec-simple-extension-structure}

**定理 3.3.5** {#thm-algebraic-simple-extension} 设 $K$ 是域，$\alpha$ 在 $K$ 上代数，$m_\alpha(X)$ 是其极小多项式，$n = \deg m_\alpha$。则：
1. $K(\alpha) = K[\alpha]$。
2. $[K(\alpha) : K] = n$。
3. $\{1, \alpha, \alpha^2, \ldots, \alpha^{n-1}\}$ 是 $K(\alpha)$ 在 $K$ 上的基。
4. $K(\alpha) \cong K[X]/(m_\alpha(X))$。

<ProofToggle>

**证明.** 

定义 $\varphi: K[X] \to K[\alpha]$ 为 $\varphi(f) = f(\alpha)$（求值同态）。$\varphi$ 是满的环同态，$\ker(\varphi) = I_\alpha = (m_\alpha)$。由第一同构定理（{thm-first-isomorphism}）：
$$
K[X]/(m_\alpha) \cong K[\alpha]
$$

因为 $m_\alpha$ 不可约，$(m_\alpha)$ 是 $K[X]$ 的极大理想（{prop-irreducible-implies-maximal}）。因此 $K[X]/(m_\alpha)$ 是域。从而 $K[\alpha]$ 是域。

$K[\alpha]$ 是包含 $K$ 和 $\alpha$ 的子域。$K(\alpha)$ 是包含 $K$ 和 $\alpha$ 的最小子域，故 $K(\alpha) \subseteq K[\alpha]$。但 $K[\alpha] \subseteq K(\alpha)$ 显然。因此 $K(\alpha) = K[\alpha]$。

由 $K[X]/(m_\alpha) \cong K[\alpha]$，每个元素可以唯一表示为 $\sum_{i=0}^{n-1} c_i \alpha^i$（$c_i \in K$），因此 $\{1, \alpha, \ldots, \alpha^{n-1}\}$ 是基，$[K(\alpha) : K] = n$。 $\blacksquare$

</ProofToggle>

::: intuition 定理 3.3.5 的意义
这个定理是 Galois 理论的**计算基础**。它告诉我们：

1. **代数扩张中的元素可以用多项式表示**：$K(\alpha)$ 中每个元素都是 $\alpha$ 的多项式，系数在 $K$ 中，次数 $< n$。这使得在扩张域中的运算变得具体可算。

2. **$K(\alpha) = K[\alpha]$ 是代数性的核心后果**：对超越元，$K(t) \neq K[t]$（例如 $1/t \in K(t)$ 但 $1/t \notin K[t]$）。代数性使得"多项式生成"和"域生成"重合。

3. **$K(\alpha) \cong K[X]/(m_\alpha)$**：扩张域可以用**多项式环的商**来构造。这是域扩张的存在性证明——不需要在更大的域中"找到"$\alpha$，只需要取商环。
:::

::: example 在 $\mathbb{Q}(\sqrt{2})$ 中做计算 {#ex-compute-in-extension}
由 {thm-algebraic-simple-extension}，$\mathbb{Q}(\sqrt{2})$ 的每个元素形如 $a + b\sqrt{2}$（$a, b \in \mathbb{Q}$）。

**乘法**：$(a + b\sqrt{2})(c + d\sqrt{2}) = (ac + 2bd) + (ad + bc)\sqrt{2}$。

**求逆**：$(a + b\sqrt{2})^{-1} = \frac{a - b\sqrt{2}}{a^2 - 2b^2}$（分母 $\neq 0$ 当 $a + b\sqrt{2} \neq 0$）。

**具体计算**：$\frac{1}{1 + \sqrt{2}} = \frac{1 - \sqrt{2}}{(1+\sqrt{2})(1-\sqrt{2})} = \frac{1-\sqrt{2}}{1-2} = \sqrt{2} - 1$。
:::

::: example 在 $\mathbb{Q}(\sqrt{2}+\sqrt{3})$ 中做计算 {#ex-compute-biquadratic}
$m_{\sqrt{2}+\sqrt{3},\, \mathbb{Q}} = x^4 - 10x^2 + 1$（$n = 4$）。

$\mathbb{Q}(\sqrt{2}+\sqrt{3})$ 的基：$\{1, \alpha, \alpha^2, \alpha^3\}$，其中 $\alpha = \sqrt{2} + \sqrt{3}$。

注意 $\alpha^2 = 5 + 2\sqrt{6}$，$\alpha^3 = \alpha \cdot \alpha^2 = (\sqrt{2}+\sqrt{3})(5+2\sqrt{6}) = 5\sqrt{2} + 5\sqrt{3} + 2\sqrt{12} + 2\sqrt{18} = 5\sqrt{2} + 5\sqrt{3} + 4\sqrt{3} + 6\sqrt{2} = 11\sqrt{2} + 9\sqrt{3}$。

**关键观察**：$\sqrt{2} = \frac{\alpha^3 - 9\alpha}{2}$，$\sqrt{3} = \frac{11\alpha - \alpha^3}{2}$。所以 $\mathbb{Q}(\sqrt{2}+\sqrt{3}) = \mathbb{Q}(\sqrt{2}, \sqrt{3})$——添加 $\sqrt{2} + \sqrt{3}$ 等于同时添加 $\sqrt{2}$ 和 $\sqrt{3}$！

$[\mathbb{Q}(\sqrt{2},\sqrt{3}) : \mathbb{Q}] = 4$（由 [§3.2](/chapters/03-fields/3.2-basic-extensions) 的复合扩张定理），与极小多项式的次数一致。
:::

::: warning $K[\alpha] = K(\alpha)$ 的前提
定理 $K(\alpha) = K[\alpha]$ **要求 $\alpha$ 是代数的**。对超越元不成立：

$K(t) \neq K[t]$。例如 $1/t \in K(t)$ 但 $1/t \notin K[t]$。$K[t]$ 只是 $K(t)$ 的子环（多项式环），不是域。
:::

## 3.3.5 共轭与域嵌入 {#sec-conjugate-roots}

**定义 3.3.6** {#def-conjugate} 设 $L/K$ 是域扩张，$\alpha, \beta \in L$ 都在 $K$ 上代数。若 $\alpha$ 和 $\beta$ 在 $K$ 上有相同的极小多项式，则称 $\alpha$ 和 $\beta$ 在 $K$ 上**共轭**（conjugate）。

**命题 3.3.7** {#prop-conjugate-criteria} 设 $f \in K[X]$ 是不可约多项式，$\alpha, \beta$ 是 $f$ 在某个扩张中的根。则 $\alpha$ 和 $\beta$ 在 $K$ 上共轭，且 $K(\alpha) \cong K(\beta)$。

<ProofToggle>

**证明.** 因为 $f$ 不可约且 $f(\alpha) = f(\beta) = 0$，$f$ 既是 $\alpha$ 也是 $\beta$ 的极小多项式（因为极小多项式整除任何满足的多项式，且不可约首一多项式的正因子只有自身）。因此 $\alpha$ 和 $\beta$ 共轭。

同构：由 {thm-algebraic-simple-extension}(4)，$K(\alpha) \cong K[X]/(m_\alpha)$ 且 $K(\beta) \cong K[X]/(m_\beta)$。因为 $m_\alpha = m_\beta = f$，得 $K(\alpha) \cong K(\beta)$。 $\blacksquare$

</ProofToggle>

::: example 共轭的具体计算 {#ex-conjugate-computation}
$x^3 - 2$ 在 $\mathbb{Q}$ 上不可约（Eisenstein，$p = 2$）。在 $\mathbb{C}$ 中有三个根：

$$\alpha_1 = \sqrt[3]{2}, \quad \alpha_2 = \omega \sqrt[3]{2}, \quad \alpha_3 = \omega^2 \sqrt[3]{2}$$

其中 $\omega = e^{2\pi i/3} = \frac{-1 + i\sqrt{3}}{2}$（三次本原单位根）。

- $\alpha_1, \alpha_2, \alpha_3$ 两两在 $\mathbb{Q}$ 上共轭。
- $\mathbb{Q}(\alpha_1) \cong \mathbb{Q}(\alpha_2) \cong \mathbb{Q}(\alpha_3)$（同构但作为 $\mathbb{C}$ 的子域不相同）。
- $\mathbb{Q}(\alpha_1) = \mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$。
- $\mathbb{Q}(\alpha_2) = \mathbb{Q}(\omega\sqrt[3]{2}) \not\subset \mathbb{R}$（包含虚数 $\omega$）。

**关键洞察**：三个共轭根产生三个同构但**不同的**域。域自同构（从而 Galois 群，见 [§7.1](/chapters/07-galois-groups/7.1-definition-and-examples)）的作用就是在这三个域之间互相转换。
:::

::: intuition 共轭根的意义
共轭根是"代数上无法区分"的元素。例如 $\sqrt{2}$ 和 $-\sqrt{2}$ 在 $\mathbb{Q}$ 上共轭——它们都是 $x^2 - 2$ 的根。Galois 理论的关键洞察之一是：**域扩张的自同构恰好将元素映射到其共轭**。这就是为什么 Galois 群捕获了多项式根之间的对称性。

更深层地看：如果 $K$ 是"对称群"作用的"基底"，那么共轭就是同一个 $K$-等价类中的元素。从 [§7.1](/chapters/07-galois-groups/7.1-definition-and-examples) 开始，我们将看到 $\operatorname{Gal}(L/K)$ 的每个元素恰好是将每个根映射到其某个共轭的 $K$-自同构。
:::

::: remark 共轭的个数与扩张次数
设 $m_\alpha$ 的次数为 $n$。在代数闭包 $\bar{K}$ 中，$m_\alpha$ 恰好有 $n$ 个根（计重数，在特征 0 中无重根）。因此 $\alpha$ 恰好有 $n$ 个不同的共轭（特征 0 中）。这与 $[K(\alpha) : K] = n$ 一致——$n$ 维扩张对应 $n$ 个"对称位置"。

在正特征中，情况更微妙：$m_\alpha$ 可能有重根（不可分元素），共轭的个数可能少于 $n$。这是 [§4.3 可分性](/chapters/04-polynomials/4.3-separability) 的主题。
:::

## 3.3.6 代数扩张的塔 {#sec-algebraic-tower}

**定理 3.3.8** {#thm-algebraic-tower} 设 $F \subseteq K \subseteq L$。若 $K/F$ 和 $L/K$ 都是代数扩张，则 $L/F$ 也是代数扩张。

<ProofToggle>

**证明.** 设 $\alpha \in L$。因为 $L/K$ 是代数的，$\alpha$ 满足某个 $K[X]$ 中的非零多项式：
$$
a_n \alpha^n + a_{n-1} \alpha^{n-1} + \cdots + a_1 \alpha + a_0 = 0, \quad a_i \in K
$$
因为 $K/F$ 是代数的，每个 $a_i$ 在 $F$ 上代数。令 $E = F(a_0, a_1, \ldots, a_n)$。则 $\alpha$ 在 $E$ 上代数。

由 {thm-algebraic-tower}（代数扩张的有限生成子扩张是有限的），$E/F$ 是有限的，$E(\alpha)/E$ 也是有限的。由塔定律 {thm-tower-law}：
$$
[E(\alpha) : F] = [E(\alpha) : E] \cdot [E : F] < \infty
$$
由 {thm-finite-implies-algebraic}，$\alpha$ 在 $F$ 上代数。 $\blacksquare$

</ProofToggle>

::: example 代数塔的具体验证 {#ex-algebraic-tower-compute}
设 $F = \mathbb{Q}$，$K = \mathbb{Q}(\sqrt{2})$，$L = \mathbb{Q}(\sqrt{2}, \sqrt{3})$。

- $K/F$：代数（$\sqrt{2}$ 的极小多项式 $x^2 - 2$）。
- $L/K$：代数（$\sqrt{3}$ 在 $\mathbb{Q}(\sqrt{2})$ 上的极小多项式是什么？）

需要找 $m_{\sqrt{3},\, \mathbb{Q}(\sqrt{2})}$。$\sqrt{3}$ 满足 $x^2 - 3 \in \mathbb{Q}(\sqrt{2})[x]$。是否不可约？假设 $x^2 - 3 = (x - a - b\sqrt{2})(x - c - d\sqrt{2})$（$a, b, c, d \in \mathbb{Q}$），则 $a + b\sqrt{2} + c + d\sqrt{2} = 0$（系数之和），$(a + b\sqrt{2})(c + d\sqrt{2}) = -3$。由第一个条件 $a + c = 0$, $b + d = 0$。第二个条件：$ac + 2bd + (ad+bc)\sqrt{2} = -3$。$ad + bc = 0$（无理部分为零），$ac + 2bd = -3$。$c = -a$, $d = -b$：$-a^2 - 2b^2 = -3$，$a^2 + 2b^2 = 3$。$a = 1, b = 1$：$1 + 2 = 3$。✓

所以 $\sqrt{3} = (1 + \sqrt{2})$？检验：$(1 + \sqrt{2})^2 = 3 + 2\sqrt{2} \neq 3$。矛盾！

实际上 $a + b\sqrt{2} = 1 + \sqrt{2}$ 不满足 $(a+b\sqrt{2})^2 = 3$。重新检查：需要 $(a+b\sqrt{2})^2 = 3$。$a^2 + 2b^2 + 2ab\sqrt{2} = 3$。$2ab = 0$，$a^2 + 2b^2 = 3$。$a = 0$：$2b^2 = 3$，$b^2 = 3/2$，$b \notin \mathbb{Q}$。$b = 0$：$a^2 = 3$，$a \notin \mathbb{Q}$。所以 $x^2 - 3$ 在 $\mathbb{Q}(\sqrt{2})[x]$ 中不可约。$m_{\sqrt{3},\, \mathbb{Q}(\sqrt{2})} = x^2 - 3$。

- $L/K = \mathbb{Q}(\sqrt{2},\sqrt{3})/\mathbb{Q}(\sqrt{2})$：代数，次数 $2$。
- $L/F$：由塔定律 $[L : \mathbb{Q}] = [L : K][K : \mathbb{Q}] = 2 \times 2 = 4$。代数，由 {thm-algebraic-tower}。
:::

::: tip 本节知识检验

**自测题：**

1. $\omega = e^{2\pi i/3}$（三次本原单位根）在 $\mathbb{Q}$ 上的极小多项式是什么？

2. 证明 $\mathbb{Q}(\sqrt[3]{2}) \neq \mathbb{Q}(\omega\sqrt[3]{2})$（作为 $\mathbb{C}$ 的子域）。

3. 设 $\alpha = 2 + \sqrt{3}$。计算 $\alpha^{-1}$ 在 $\mathbb{Q}$-基 $\{1, \sqrt{3}\}$ 下的坐标。

4. $\sqrt{2}$ 在 $\mathbb{Q}(\sqrt{3})$ 上的极小多项式是什么？

5. 解释为什么 $K(\alpha) = K[\alpha]$ 对超越元 $\alpha$ 不成立。

**答案要点：**

1. $\omega^2 + \omega + 1 = 0$（因为 $\omega^3 = 1$ 且 $\omega \neq 1$）。$x^2 + x + 1$ 在 $\mathbb{Q}$ 上不可约（无实根）。$m_{\omega,\mathbb{Q}} = x^2 + x + 1$。

2. $\mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$（因为 $\sqrt[3]{2} \in \mathbb{R}$）。$\omega\sqrt[3]{2} \notin \mathbb{R}$（因为 $\omega \notin \mathbb{R}$）。所以 $\mathbb{Q}(\omega\sqrt[3]{2}) \not\subset \mathbb{R}$。两个域不相等。

3. $\alpha^{-1} = (2+\sqrt{3})^{-1} = \frac{2-\sqrt{3}}{4-3} = 2 - \sqrt{3}$。在基 $\{1, \sqrt{3}\}$ 下的坐标：$(2, -1)$。

4. $x^2 - 2$ 在 $\mathbb{Q}(\sqrt{3})[x]$ 中不可约：假设 $\sqrt{2} = a + b\sqrt{3}$，则 $2 = a^2 + 3b^2 + 2ab\sqrt{3}$。$ab = 0$，$a^2 + 3b^2 = 2$。$a = 0$：$3b^2 = 2$，$b \notin \mathbb{Q}$。$b = 0$：$a^2 = 2$，$a \notin \mathbb{Q}$。不可约。$m_{\sqrt{2},\, \mathbb{Q}(\sqrt{3})} = x^2 - 2$。

5. 超越元 $\alpha$ 没有极小多项式，$K[\alpha] \cong K[x]$（多项式环，不是域）。$1/\alpha \in K(\alpha)$ 但 $1/\alpha \notin K[\alpha]$。
:::
