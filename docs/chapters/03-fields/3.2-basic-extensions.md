# §3.2 域的基本扩张 {#sec-field-extensions}

::: tip 本节学习目标
1. 理解**域扩张**的定义、记号和基本例子。
2. 掌握**扩张次数** $[L:K]$ 的含义——它是 $L$ 作为 $K$-向量空间的维数。
3. 掌握**塔定律** $[L:F] = [L:K][K:F]$ 及其具体计算应用。
4. 理解**有限扩张必为代数扩张**，反之不成立。
5. 掌握**单扩张** $K(\alpha)$ 的定义，区分 $K(\alpha)$ 和 $K[\alpha]$。
:::

---

## 3.2.1 域扩张 {#sec-extension-definition}

**定义 3.2.1** {#def-field-extension} 设 $K$ 和 $L$ 是域。若 $K \subseteq L$ 且 $K$ 的域运算与 $L$ 的限制一致，则称 $L$ 是 $K$ 的一个**扩张**（extension），记为 $L/K$。等价地，存在单的域同态 $\iota: K \hookrightarrow L$。

::: remark 记号约定
记号 $L/K$ 不表示"除法"，而是表示 $K$ 是 $L$ 的子域。在 Galois 理论中，$K$ 称为**基域**（base field），$L$ 称为**扩张域**（extension field）。

注意：这个记号 $L/K$ 与群论中的商群 $G/N$ 不同——这里不是商，而是"over"（在……之上）。
:::

::: intuition 为什么需要域扩张？
多项式方程的根往往不在我们"已有的"域中。例如 $x^2 - 2 = 0$ 在 $\mathbb{Q}$ 中无解，但在 $\mathbb{R}$ 中有解。域扩张的理论就是讨论如何系统地"扩大"域以容纳新的元素。

Galois 理论的核心问题可以重新表述为：**给定一个多项式 $f \in K[x]$，需要多大的域扩张 $L/K$ 才能包含 $f$ 的所有根？** 这个扩张的结构（它的对称群）编码了关于 $f$ 的根的深刻信息。
:::

---

## 3.2.2 基本例子 {#sec-extension-examples}

::: example $\mathbb{Q}(\sqrt{2})$ {#ex-q-sqrt2}
$\mathbb{Q}(\sqrt{2}) = \{a + b\sqrt{2} \mid a, b \in \mathbb{Q}\}$ 是 $\mathbb{Q}$ 的一个扩张。它是通过在 $\mathbb{Q}$ 中添加方程 $x^2 - 2 = 0$ 的一个根得到的。

**验证它是域**：对 $a + b\sqrt{2} \neq 0$，有
$$(a + b\sqrt{2})^{-1} = \frac{a - b\sqrt{2}}{a^2 - 2b^2}$$
分母 $a^2 - 2b^2 \neq 0$（因为 $\sqrt{2}$ 是无理数，$a^2 \neq 2b^2$ 对 $a,b \in \mathbb{Q}$ 不全为零时成立）。
:::

::: example 有理函数域 {#ex-rational-function}
设 $K$ 是域，$t$ 是一个未定元。则有理函数域 $K(t)$ 是 $K$ 的扩张。$t$ 在 $K$ 上是超越的（见 {def-transcendental-element}），因此 $K(t)/K$ 是超越扩张。
:::

::: example $\mathbb{R}/\mathbb{Q}$ {#ex-R-over-Q}
实数域 $\mathbb{R}$ 是有理数域 $\mathbb{Q}$ 的扩张。但这个扩张"太大"了——$\mathbb{R}$ 包含了太多 $\mathbb{Q}$ 上的超越元素（如 $\pi, e$）。Galois 理论主要关注的是**有限扩张**和**代数扩张**。
:::

::: example 有限域的扩张 {#ex-finite-field-extension}
设 $p$ 是素数，$\mathbb{F}_p = \mathbb{Z}/p\mathbb{Z}$。则：
- $\mathbb{F}_4 = \mathbb{F}_2(\alpha)$，其中 $\alpha$ 是 $x^2 + x + 1 \in \mathbb{F}_2[x]$ 的根。$[\mathbb{F}_4 : \mathbb{F}_2] = 2$。
- $\mathbb{F}_{p^n}$ 是 $\mathbb{F}_p$ 的 $n$ 次扩张（存在且唯一，见 [§10.1](/chapters/10-finite-fields/10.1-structure)）。

有限域的扩张是 Galois 理论最漂亮的应用之一——[第 10 章](/chapters/10-finite-fields/) 将深入讨论。
:::

::: example 分圆域 {#ex-cyclotomic-field}
设 $\zeta_n = e^{2\pi i/n}$ 是 $n$ 次本原单位根。则 $\mathbb{Q}(\zeta_n)/\mathbb{Q}$ 称为**分圆域**（cyclotomic field）。例如：
- $\mathbb{Q}(\zeta_3) = \mathbb{Q}(\omega)$，其中 $\omega = \frac{-1+i\sqrt{3}}{2}$。$[\mathbb{Q}(\omega):\mathbb{Q}] = 2$。
- $\mathbb{Q}(\zeta_5)$：$[\mathbb{Q}(\zeta_5):\mathbb{Q}] = \phi(5) = 4$。
- 一般地，$[\mathbb{Q}(\zeta_n):\mathbb{Q}] = \phi(n)$（Euler 函数）。

分圆域是 Galois 理论的经典例子（见 [§7.1](/chapters/07-galois-groups/7.1-definition-and-examples)），其 Galois 群同构于 $(\mathbb{Z}/n\mathbb{Z})^\times$。
:::

::: example $p$-进数域 {#ex-padic}
对每个素数 $p$，$p$-进数域 $\mathbb{Q}_p$ 是 $\mathbb{Q}$ 的完备化（关于 $p$-进绝对值）。$\mathbb{Q}_p/\mathbb{Q}$ 是无限扩张。$p$-进域的 Galois 理论是现代数论的核心工具之一（见 [§11 章](/chapters/11-infinite-galois/) 和 [§12 章](/chapters/12-algebraic-closure/)）。
:::

## 3.2.3 扩张次数 {#sec-extension-degree}

**定义 3.2.2** {#def-extension-degree} 设 $L/K$ 是域扩张。将 $L$ 视为 $K$ 上的向量空间（通过限制 $L$ 的加法和 $K$ 的标量乘法），定义 $L$ 在 $K$ 上的**次数**（degree）为
$$
[L : K] := \dim_K L
$$
若 $[L : K] < \infty$，则称 $L/K$ 是**有限扩张**（finite extension）；否则称 $L/K$ 是**无限扩张**。

::: intuition 扩张次数是向量空间维数
扩张次数 $[L : K]$ 就是 $L$ 作为 $K$-向量空间的维数。这意味着若 $[L : K] = n$，则存在 $L$ 中的元素 $\alpha_1, \ldots, \alpha_n$，使得 $L$ 中的每个元素都可以**唯一地**写成 $K$-线性组合：
$$
L = K\alpha_1 \oplus K\alpha_2 \oplus \cdots \oplus K\alpha_n
$$
这组 $\{\alpha_i\}$ 称为 $L$ 在 $K$ 上的**基**。

**为什么 $L$ 是 $K$-向量空间？** 因为 $L$ 是域，它有加法；$K \subseteq L$，所以 $K$ 的元素可以与 $L$ 的元素相乘。这给出了 $L$ 上的 $K$-标量乘法，使 $L$ 成为 $K$-向量空间。
:::

::: warning 扩张次数依赖于基域
$[L:K]$ 的值依赖于 $K$。同一个域 $L$ 对不同的基域 $K$ 有不同的扩张次数。例如：
- $[\mathbb{C}:\mathbb{R}] = 2$
- $[\mathbb{C}:\mathbb{Q}] = \infty$
- $[\mathbb{R}:\mathbb{Q}] = \infty$
:::

**命题 3.2.3** {#prop-degree-examples}
1. $[\mathbb{Q}(\sqrt{2}) : \mathbb{Q}] = 2$。
2. $[\mathbb{C} : \mathbb{R}] = 2$。
3. $[\mathbb{R} : \mathbb{Q}] = \infty$。

<ProofToggle>

**证明.**

**(1)** $\mathbb{Q}(\sqrt{2}) = \{a + b\sqrt{2} \mid a, b \in \mathbb{Q}\}$。集合 $\{1, \sqrt{2}\}$ 是 $\mathbb{Q}(\sqrt{2})$ 在 $\mathbb{Q}$ 上的基：任意 $a + b\sqrt{2} \in \mathbb{Q}(\sqrt{2})$ 可以唯一写成 $a \cdot 1 + b \cdot \sqrt{2}$。线性无关性：若 $a + b\sqrt{2} = 0$（$a, b \in \mathbb{Q}$），则 $\sqrt{2} = -a/b$（若 $b \neq 0$），矛盾于 $\sqrt{2}$ 是无理数。因此 $a = b = 0$。

**(2)** $\mathbb{C} = \{a + bi \mid a, b \in \mathbb{R}\}$，基为 $\{1, i\}$，故 $[\mathbb{C} : \mathbb{R}] = 2$。

**(3)** 因为 $\pi$ 在 $\mathbb{Q}$ 上是超越的（Lindemann-Weierstrass 定理），集合 $\{1, \pi, \pi^2, \ldots\}$ 在 $\mathbb{Q}$ 上线性无关，故 $[\mathbb{R} : \mathbb{Q}] = \infty$。 $\blacksquare$

</ProofToggle>

::: remark 次数为 1 的情形
$[L:K] = 1$ 当且仅当 $L = K$。这是因为 $L$ 作为 $K$-向量空间是一维的，$1$ 是基，$L = K \cdot 1 = K$。
:::

## 3.2.4 塔定律 {#sec-tower-law}

**定理 3.2.4** {#thm-tower-law}（塔定律 / Tower Law）设 $F \subseteq K \subseteq L$ 是域的包含链。则
$$
[L : F] = [L : K] \cdot [K : F]
$$
更精确地说，若 $\{a_i\}_{i \in I}$ 是 $K$ 在 $F$ 上的基，$\{b_j\}_{j \in J}$ 是 $L$ 在 $K$ 上的基，则 $\{a_i b_j\}_{(i,j) \in I \times J}$ 是 $L$ 在 $F$ 上的基。

<ProofToggle>

**证明.** 我们证明 $\{a_i b_j\}$ 构成 $L$ 在 $F$ 上的基。

**张成性**：设 $\ell \in L$。因为 $\{b_j\}$ 是 $L$ 在 $K$ 上的基，有 $\ell = \sum_j k_j b_j$，其中 $k_j \in K$，只有有限个非零。因为 $\{a_i\}$ 是 $K$ 在 $F$ 上的基，每个 $k_j = \sum_i f_{ij} a_i$，其中 $f_{ij} \in F$。代入得
$$
\ell = \sum_j \left(\sum_i f_{ij} a_i\right) b_j = \sum_{i,j} f_{ij} (a_i b_j)
$$
因此 $\{a_i b_j\}$ 张成 $L$ 作为 $F$-向量空间。

**线性无关性**：设 $\sum_{i,j} f_{ij} a_i b_j = 0$（$f_{ij} \in F$，只有有限个非零）。则
$$
\sum_j \left(\sum_i f_{ij} a_i\right) b_j = 0
$$
由 $\{b_j\}$ 在 $K$ 上的线性无关性，$\sum_i f_{ij} a_i = 0$ 对所有 $j$ 成立。由 $\{a_i\}$ 在 $F$ 上的线性无关性，$f_{ij} = 0$ 对所有 $i, j$ 成立。 $\blacksquare$

</ProofToggle>

**推论 3.2.5** {#cor-degree-divides} 设 $F \subseteq K \subseteq L$。则 $[K : F]$ 整除 $[L : F]$。

::: intuition 塔定律的几何直觉
可以把域扩张想象成"搭积木"。从 $\mathbb{Q}$ 到 $\mathbb{Q}(\sqrt{2}, \sqrt{3})$ 可以走两条路：
- $\mathbb{Q} \to \mathbb{Q}(\sqrt{2}) \to \mathbb{Q}(\sqrt{2}, \sqrt{3})$：先添 $\sqrt{2}$，再添 $\sqrt{3}$
- $\mathbb{Q} \to \mathbb{Q}(\sqrt{3}) \to \mathbb{Q}(\sqrt{2}, \sqrt{3})$：先添 $\sqrt{3}$，再添 $\sqrt{2}$

塔定律告诉我们，两条路的"步长乘积"相等：$2 \times 2 = 4$。

### 塔定律的计算应用 {#sec-tower-law-applications}

::: example 二元根式的扩张次数 {#ex-biquadratic-degree}
计算 $[\mathbb{Q}(\sqrt{2}, \sqrt{3}) : \mathbb{Q}]$。

**方法**：利用塔定律。

$$[\mathbb{Q}(\sqrt{2}, \sqrt{3}) : \mathbb{Q}] = [\mathbb{Q}(\sqrt{2}, \sqrt{3}) : \mathbb{Q}(\sqrt{2})] \cdot [\mathbb{Q}(\sqrt{2}) : \mathbb{Q}]$$

已知 $[\mathbb{Q}(\sqrt{2}) : \mathbb{Q}] = 2$。

需要求 $[\mathbb{Q}(\sqrt{2}, \sqrt{3}) : \mathbb{Q}(\sqrt{2})]$。因为 $\sqrt{3}$ 在 $\mathbb{Q}(\sqrt{2})$ 上的极小多项式是 $x^2 - 3$（在 $\mathbb{Q}(\sqrt{2})[x]$ 中不可约——否则 $\sqrt{3} = a + b\sqrt{2}$ 导致矛盾，见 [§3.3](/chapters/03-fields/3.3-algebraic-elements) 的自测题），$[\mathbb{Q}(\sqrt{2}, \sqrt{3}) : \mathbb{Q}(\sqrt{2})] = 2$。

$$[\mathbb{Q}(\sqrt{2}, \sqrt{3}) : \mathbb{Q}] = 2 \times 2 = 4$$

$\mathbb{Q}(\sqrt{2}, \sqrt{3})$ 在 $\mathbb{Q}$ 上的基是 $\{1, \sqrt{2}, \sqrt{3}, \sqrt{6}\}$。
:::

::: example 三次扩张的塔 {#ex-cubic-tower}
计算 $[\mathbb{Q}(\sqrt[3]{2}, \omega) : \mathbb{Q}]$，其中 $\omega = e^{2\pi i/3}$。

$[\mathbb{Q}(\sqrt[3]{2}) : \mathbb{Q}] = 3$（极小多项式 $x^3 - 2$，Eisenstein 不可约）。

$[\mathbb{Q}(\sqrt[3]{2}, \omega) : \mathbb{Q}(\sqrt[3]{2})] = 2$（$\omega$ 在 $\mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$ 上的极小多项式是 $x^2 + x + 1$，因为 $\omega \notin \mathbb{R}$）。

$$[\mathbb{Q}(\sqrt[3]{2}, \omega) : \mathbb{Q}] = 3 \times 2 = 6$$

这恰好等于 $x^3 - 2$ 的分裂域的次数（见 [§5.1](/chapters/05-splitting-fields/5.1-splitting-fields)）。$\mathbb{Q}(\sqrt[3]{2}, \omega)$ 包含 $x^3 - 2$ 的所有三个根 $\sqrt[3]{2}, \omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}$。
:::

::: example 更长的塔 {#ex-longer-tower}
计算 $[\mathbb{Q}(\sqrt{2}, \sqrt{3}, \sqrt{5}) : \mathbb{Q}]$。

逐次添加：
- $[\mathbb{Q}(\sqrt{2}) : \mathbb{Q}] = 2$
- $[\mathbb{Q}(\sqrt{2}, \sqrt{3}) : \mathbb{Q}(\sqrt{2})] = 2$（因为 $\sqrt{3} \notin \mathbb{Q}(\sqrt{2})$）
- $[\mathbb{Q}(\sqrt{2}, \sqrt{3}, \sqrt{5}) : \mathbb{Q}(\sqrt{2}, \sqrt{3})] = 2$（因为 $\sqrt{5} \notin \mathbb{Q}(\sqrt{2}, \sqrt{3})$）

所以 $[\mathbb{Q}(\sqrt{2}, \sqrt{3}, \sqrt{5}) : \mathbb{Q}] = 2 \times 2 \times 2 = 8$。

$\mathbb{Q}$-基：$\{1, \sqrt{2}, \sqrt{3}, \sqrt{5}, \sqrt{6}, \sqrt{10}, \sqrt{15}, \sqrt{30}\}$。

一般地，对不同的素数 $p_1, \ldots, p_n$，$[\mathbb{Q}(\sqrt{p_1}, \ldots, \sqrt{p_n}) : \mathbb{Q}] = 2^n$。
:::

::: warning 塔定律不告诉我们中间域的次数是多少
塔定律说 $[L:F] = [L:K][K:F]$。如果我们知道其中两个，可以求第三个。但如果只知道 $[L:F]$，不能唯一确定 $[L:K]$ 和 $[K:F]$——它们只是需要满足乘积关系。

例如 $[L:\mathbb{Q}] = 12$ 的扩张可以有 $[K:\mathbb{Q}] = 2, 3, 4, 6$ 的中间域，也可能没有某些次数的中间域。中间域的存在性和结构正是 **Galois 对应**（[§8.1](/chapters/08-galois-correspondence/8.1-fundamental-theorem)）要解决的问题。
:::

## 3.2.5 有限扩张的代数性 {#sec-finite-implies-algebraic}

**定理 3.2.6** {#thm-finite-implies-algebraic} 设 $L/K$ 是有限扩张。则 $L$ 中的每个元素都在 $K$ 上是代数的。

<ProofToggle>

**证明.** 设 $[L : K] = n$，取 $\alpha \in L$。考虑 $n+1$ 个元素 $1, \alpha, \alpha^2, \ldots, \alpha^n$。它们都在 $L$ 中，而 $L$ 作为 $K$-向量空间的维数是 $n$。因此这 $n+1$ 个元素在 $K$ 上线性相关：存在不全为零的 $a_0, a_1, \ldots, a_n \in K$ 使得
$$
a_0 + a_1 \alpha + a_2 \alpha^2 + \cdots + a_n \alpha^n = 0
$$
这说明 $\alpha$ 是非零多项式 $f(X) = a_0 + a_1 X + \cdots + a_n X^n \in K[X]$ 的根，因此 $\alpha$ 在 $K$ 上是代数的。 $\blacksquare$

</ProofToggle>

::: remark 证明的直觉
证明的核心思想是**鸽笼原理的线性代数版本**：在 $n$ 维空间中，$n+1$ 个向量必然线性相关。$\alpha$ 的幂 $1, \alpha, \alpha^2, \ldots, \alpha^n$ 提供了 $n+1$ 个向量，它们的线性关系给出了 $\alpha$ 满足的多项式。

这个证明是**非构造性的**——它告诉我们存在这样的多项式，但不一定给出最小的那个（极小多项式）。见 [§3.3](/chapters/03-fields/3.3-algebraic-elements)。
:::

::: warning 反之不成立
代数扩张不一定是有限扩张。例如 $\overline{\mathbb{Q}} := \{\alpha \in \mathbb{C} \mid \alpha \text{ 在 } \mathbb{Q} \text{ 上代数}\}$ 是 $\mathbb{Q}$ 的代数扩张，但 $[\overline{\mathbb{Q}} : \mathbb{Q}] = \infty$。

**直觉**：$\overline{\mathbb{Q}}$ 包含了所有代数数——$\sqrt{2}, \sqrt[3]{2}, \sqrt{2}+\sqrt{3}, \ldots$——有无穷多个"独立的"代数数，每个都在有限扩张中，但整体是无限的。

代数扩张与有限扩张的关系：
- 有限扩张 $\Rightarrow$ 代数扩张（本定理）
- 代数扩张 $\not\Rightarrow$ 有限扩张
- 有限生成的代数扩张 $\Rightarrow$ 有限扩张（命题 3.3.8 的推论）

这个区分在无限 Galois 理论（[§11 章](/chapters/11-infinite-galois/)）中至关重要。
:::

## 3.2.6 单扩张 {#sec-simple-extensions}

**定义 3.2.7** {#def-simple-extension} 设 $L/K$ 是域扩张，$\alpha \in L$。则 $K(\alpha)$ 表示 $L$ 中包含 $K$ 和 $\alpha$ 的最小子域，即由 $K$ 和 $\alpha$ 生成的 $L$ 的子域。$K(\alpha)/K$ 称为**单扩张**（simple extension）。

**定义 3.2.8** {#def-generated-ring} $K[\alpha] = \{f(\alpha) \mid f(X) \in K[X]\}$ 是由 $K$ 和 $\alpha$ 生成的子**环**（不是域）。

::: intuition $K(\alpha)$ 与 $K[\alpha]$ 的区别
- $K[\alpha]$：用 $\alpha$ 的多项式能构造出的所有元素。包含加、减、乘，但不一定包含除法。
- $K(\alpha)$：用 $K$ 和 $\alpha$ 经过四则运算能构造出的所有元素。包含加、减、乘、除。

**关键定理**（{thm-algebraic-simple-extension}，见 [§3.3](/chapters/03-fields/3.3-algebraic-elements)）：
- 当 $\alpha$ 在 $K$ 上**代数**时，$K(\alpha) = K[\alpha]$——多项式环已经是域。
- 当 $\alpha$ 在 $K$ 上**超越**时，$K(\alpha) \neq K[\alpha]$——$K[\alpha] \cong K[x]$（多项式环，不是域），$K(\alpha) \cong K(x)$（有理函数域）。
:::

::: example $K(\sqrt{2})$ {#ex-simple-sqrt2}
$\mathbb{Q}(\sqrt{2}) = \mathbb{Q}[\sqrt{2}] = \{a + b\sqrt{2} \mid a, b \in \mathbb{Q}\}$。因为 $\sqrt{2}$ 在 $\mathbb{Q}$ 上代数，$K(\alpha) = K[\alpha]$。每个元素都有唯一的表示 $a + b\sqrt{2}$。
:::

::: example $K(t)$ {#ex-simple-transcendental}
$\mathbb{Q}(t) \neq \mathbb{Q}[t]$。$\mathbb{Q}[t]$ 是多项式环（不是域），$\mathbb{Q}(t)$ 是有理函数域。$1/t \in \mathbb{Q}(t)$ 但 $1/t \notin \mathbb{Q}[t]$。
:::

::: example 多元生成 {#ex-multi-generated}
$K(\alpha, \beta)$ 表示由 $K$、$\alpha$、$\beta$ 生成的子域。它等于 $(K(\alpha))(\beta)$——先添加 $\alpha$，再添加 $\beta$。

例如 $\mathbb{Q}(\sqrt{2}, \sqrt{3}) = \mathbb{Q}(\sqrt{2})(\sqrt{3})$。先在 $\mathbb{Q}$ 中添加 $\sqrt{2}$ 得到 $\mathbb{Q}(\sqrt{2})$，再在 $\mathbb{Q}(\sqrt{2})$ 中添加 $\sqrt{3}$ 得到 $\mathbb{Q}(\sqrt{2}, \sqrt{3})$。
:::

::: warning 常见误区

**误区 1**：混淆 $K(\alpha)$ 和 $K[\alpha]$。
- $K(\alpha)$ 是域，$K[\alpha]$ 是环。
- 当 $\alpha$ 代数时两者相等，当 $\alpha$ 超越时不同。
- 不要在 $\alpha$ 超越时假设 $K(\alpha) = K[\alpha]$。

**误区 2**：以为 $[K(\alpha):K]$ 总等于 $\alpha$ 满足的某个多项式的次数。
- 实际上 $[K(\alpha):K] = \deg m_\alpha$（极小多项式的次数，见 [§3.3](/chapters/03-fields/3.3-algebraic-elements)）。
- $\alpha$ 可能满足次数更低的多项式，也可能满足更高的——关键是极小多项式。

**误区 3**：以为添加顺序影响最终结果。
- $K(\alpha, \beta) = K(\beta, \alpha)$——最终域与添加顺序无关。
- 但中间域可能不同：$K(\alpha)$ 和 $K(\beta)$ 一般不同。
:::

::: tip 本节知识检验

**自测题：**

1. 计算 $[\mathbb{Q}(\sqrt[3]{2}) : \mathbb{Q}]$。提示：$x^3 - 2$ 在 $\mathbb{Q}$ 上不可约。

2. 设 $[L:K] = 6$，$[M:K] = 4$，$K \subseteq M \subseteq L$。这可能吗？为什么？

3. $\mathbb{Q}(\sqrt{2})$ 和 $\mathbb{Q}(\sqrt{3})$ 是否相等？提示：$\sqrt{3} \notin \mathbb{Q}(\sqrt{2})$。

4. 计算 $[\mathbb{Q}(\sqrt{2}, i) : \mathbb{Q}]$。

5. 为什么 $[\mathbb{C} : \mathbb{Q}] = \infty$ 而 $[\mathbb{C} : \mathbb{R}] = 2$？这说明了什么？

**答案要点：**

1. $x^3 - 2$ 在 $\mathbb{Q}$ 上不可约（Eisenstein，$p = 2$）。$\{1, \sqrt[3]{2}, \sqrt[3]{4}\}$ 是 $\mathbb{Q}$-基。$[\mathbb{Q}(\sqrt[3]{2}) : \mathbb{Q}] = 3$。

2. 不可能。由塔定律 $[L:K] = [L:M][M:K]$。$6 = [L:M] \times 4$，$[L:M] = 6/4 = 3/2$，不是正整数，矛盾。

3. 不相等。$\sqrt{3} \notin \mathbb{Q}(\sqrt{2})$（否则 $\sqrt{3} = a + b\sqrt{2}$，$3 = a^2 + 2b^2 + 2ab\sqrt{2}$，$ab = 0$，$a^2 + 2b^2 = 3$，$a$ 或 $b$ 不是有理数，矛盾）。$\mathbb{Q}(\sqrt{2}) \neq \mathbb{Q}(\sqrt{3})$。

4. $[\mathbb{Q}(\sqrt{2}):\mathbb{Q}] = 2$。$i \notin \mathbb{Q}(\sqrt{2}) \subset \mathbb{R}$（$i$ 是虚数）。$[\mathbb{Q}(\sqrt{2},i):\mathbb{Q}(\sqrt{2})] = 2$。$[\mathbb{Q}(\sqrt{2},i):\mathbb{Q}] = 4$。

5. $\mathbb{C}$ 中有 $\pi, e$ 等超越数，$\{1, \pi, \pi^2, \ldots\}$ 在 $\mathbb{Q}$ 上线性无关。但 $\{1, i\}$ 就张成 $\mathbb{C}$ 作为 $\mathbb{R}$-空间。这说明同一个域对不同的基域可以有完全不同的扩张次数。
:::
