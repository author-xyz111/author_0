# §3.1 域的定义与基本性质 {#sec-field-definition}

::: tip 学习目标
1. 掌握域的公理化定义，理解域与整环、除环的关系。
2. 能判断给定的代数结构是否构成域。
3. 理解域的特征（characteristic）的概念及其两种可能取值。
4. 掌握素域（prime field）的概念，理解"每个域都建立在 $\mathbb{Q}$ 或 $\mathbb{F}_p$ 之上"。
5. 了解域的自同构群，为后续 Galois 理论做准备。
:::

## 从环到域

::: info 动机
我们在[第二章](/chapters/02-rings/)中看到，环是一个配备了加法和乘法的代数结构，但乘法不一定可逆。整环排除了零因子，但仍然不要求乘法可逆（例如 $\mathbb{Z}$ 中 $2$ 没有乘法逆元）。

**域**是"完美的算术世界"：加法和乘法都是群运算，加上分配律联系它们。域是线性代数、多项式理论和 Galois 理论的基本舞台。
:::

::: definition 域 {#def-field}
设 $K$ 是一个集合，配备两个二元运算 $+$（加法）和 $\cdot$（乘法）。称 $(K, +, \cdot)$ 为一个**域**（field），若以下公理成立：

**(F1) 加法群**：$(K, +)$ 是一个{Abel群}（见 {def-abelian-group}），其零元记为 $0$。

**(F2) 乘法群**：$(K \setminus \{0\}, \cdot)$ 是一个 Abel 群，其单位元记为 $1$（$1 \neq 0$）。

**(F3) 分配律**：对所有 $a, b, c \in K$，有
$$
a \cdot (b + c) = a \cdot b + a \cdot c
$$
:::

::: remark 域 vs. 除环
域要求乘法交换。若只要求 $(K \setminus \{0\}, \cdot)$ 是群（不一定交换），则 $(K, +, \cdot)$ 称为**除环**（division ring）或**体**（skew field）。最著名的非交换除环是**Hamilton 四元数** $\mathbb{H}$。

Galois 理论完全在交换域的框架内工作。非交换除环虽有独立的理论（如 Brauer 群），但不在本教程的范围内。
:::

::: warning $1 \neq 0$ 不是多余的！
条件 "$1 \neq 0$" 是域定义的一部分，不是推论。如果允许 $1 = 0$，则对任意 $a \in K$，有 $a = a \cdot 1 = a \cdot 0 = 0$，所以 $K = \{0\}$。这个只有一个元素的"域"是退化的，排除它是为了保证"非零元有逆元"这个条件有意义（$K \setminus \{0\}$ 非空才能谈"乘法群"）。

**注意**：整环的定义也要求 $1 \neq 0$（或等价地，$|K| > 1$），理由相同。
:::

## 域的基本性质

::: proposition {#prop-field-integral-domain}
每个域都是整环（见 {def-integral-domain}）。
:::

<ProofToggle>

**证明.** 设 $K$ 是域。由 (F2)，$K \setminus \{0\}$ 关于乘法封闭。设 $a, b \in K$ 且 $ab = 0$。若 $a \neq 0$，则 $a \in K \setminus \{0\}$，故 $a$ 有乘法逆元 $a^{-1}$。于是
$$
b = 1 \cdot b = (a^{-1} a) b = a^{-1}(ab) = a^{-1} \cdot 0 = 0
$$
因此 $K$ 无零因子，即 $K$ 是整环。 $\blacksquare$

</ProofToggle>

::: warning 反之不成立
整环不一定是域。例如 $\mathbb{Z}$ 是整环但不是域（$2$ 没有乘法逆元）。整环成为域的条件见 {thm-field-iff-maximal}。

一般地，整环 $R$ 是域当且仅当 $R$ 是**域**当且仅当 $R$ 作为整环满足"每个非零元可逆"。[§2.2](/chapters/02-rings/2.2-ideals) 中的定理告诉我们：$R$ 是域当且仅当 $R$ 的理想只有 $(0)$ 和 $R$ 自身。
:::

## 域的典型例子 {#sec-field-examples}

::: example 常见的域 {#ex-fields}

1. **有理数域** $\mathbb{Q}$：特征 0。这是最小的特征 0 域（即 $\mathbb{Q}$ 是所有特征 0 域的子域）。

2. **实数域** $\mathbb{R}$：特征 0。$\mathbb{Q} \subset \mathbb{R}$，但 $\mathbb{R}$ 比 $\mathbb{Q}$ 大得多（包含超越数如 $\pi$ 和 $e$）。

3. **复数域** $\mathbb{C}$：特征 0。$\mathbb{C} = \mathbb{R}(i)$，其中 $i = \sqrt{-1}$。代数基本定理告诉我们 $\mathbb{C}$ 是**代数闭域**——每个非常数多项式在 $\mathbb{C}$ 中都有根。

4. **有限域** $\mathbb{F}_p = \mathbb{Z}/p\mathbb{Z}$（$p$ 素数）：特征 $p$。例如 $\mathbb{F}_5 = \{0, 1, 2, 3, 4\}$，其中 $2^{-1} = 3$（因为 $2 \times 3 = 6 \equiv 1 \pmod{5}$）。

5. **有限域的扩张** $\mathbb{F}_{p^n}$（$n \geq 1$）：特征 $p$，$|\mathbb{F}_{p^n}| = p^n$。例如 $\mathbb{F}_4 = \{0, 1, \alpha, \alpha+1\}$，其中 $\alpha^2 + \alpha + 1 = 0$。详见[第十章](/chapters/10-finite-fields/)。

6. **有理函数域** $\mathbb{Q}(x)$：所有有理函数 $f(x)/g(x)$（$f, g \in \mathbb{Q}[x]$，$g \neq 0$）构成的域。特征 0。

7. **$p$-进数域** $\mathbb{Q}_p$：特征 0。这是 $\mathbb{Q}$ 的完备化（关于 $p$-进范数），在数论中有根本重要性。
:::

::: example 不是域的例子 {#ex-not-fields}

1. **整数环** $\mathbb{Z}$：是整环但不是域。$2$ 没有乘法逆元（$1/2 \notin \mathbb{Z}$）。

2. **多项式环** $\mathbb{Q}[x]$：是整环但不是域。$x$ 没有乘法逆元（$1/x \notin \mathbb{Q}[x]$）。但 $\mathbb{Q}[x]$ 的分式域是 $\mathbb{Q}(x)$。

3. **矩阵环** $M_2(\mathbb{R})$：不是域，甚至不是整环。$\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} = 0$，有零因子。

4. **$\mathbb{Z}/6\mathbb{Z}$**：不是域（不是整环）。$\overline{2} \cdot \overline{3} = \overline{0}$，有零因子。一般地，$\mathbb{Z}/n\mathbb{Z}$ 是域当且仅当 $n$ 是素数。

5. **Hamilton 四元数** $\mathbb{H}$：是除环（非零元都有逆）但不是域（乘法不交换：$ij = k \neq -k = ji$）。

6. **$\mathbb{R}[x]/(x^2+1)$**：这实际上是域！$\cong \mathbb{C}$，因为 $x^2+1$ 在 $\mathbb{R}$ 上不可约。但 $\mathbb{R}[x]/(x^2-1)$ 不是域，因为 $x^2-1 = (x-1)(x+1)$ 可约。
:::

::: info 域的构造方法
域通常不是从公理"凭空"构建的，而是从已有的代数结构构造：

1. **商环法**：$R/\mathfrak{m}$ 是域，当 $\mathfrak{m}$ 是整环 $R$ 的**极大理想**（{thm-field-iff-maximal}）。
2. **分式域法**：每个整环 $R$ 都可以嵌入其分式域 $\operatorname{Frac}(R)$（如 $\mathbb{Z} \to \mathbb{Q}$，$\mathbb{Q}[x] \to \mathbb{Q}(x)$）。
3. **多项式商法**：$K[x]/(f)$ 是域，当 $f$ 在 $K$ 上**不可约**（见 [§4.2 不可约性](/chapters/04-polynomials/4.2-irreducibility) 和 [§3.2 基本扩张](3.2-basic-extensions)）。
4. **分裂域法**：给定多项式 $f \in K[x]$，存在包含 $f$ 所有根的最小扩张域（见 [§5.1 分裂域](/chapters/05-splitting-fields/)）。
:::

## 域的特征 {#sec-characteristic}

::: definition 域的特征 {#def-characteristic}
设 $K$ 是域。定义**单位元的加法阶**为最小的正整数 $n$ 使得 $\underbrace{1 + 1 + \cdots + 1}_{n} = 0$。若这样的 $n$ 不存在，则定义 $K$ 的**特征**（characteristic）为 $\operatorname{char}(K) = 0$；否则 $\operatorname{char}(K) = n$。
:::

::: theorem 特征的性质 {#thm-characteristic}
设 $K$ 是域。则：
1. $\operatorname{char}(K)$ 要么是 $0$，要么是素数 $p$。
2. 若 $\operatorname{char}(K) = p > 0$，则对所有 $a \in K$，有 $\underbrace{a + a + \cdots + a}_{p} = p \cdot a = 0$。
3. 若 $\operatorname{char}(K) = 0$，则 $K$ 包含一个与 $\mathbb{Q}$ 同构的子域。
4. 若 $\operatorname{char}(K) = p$（$p$ 素数），则 $K$ 包含一个与 $\mathbb{F}_p$ 同构的子域。
:::

<ProofToggle>

**证明.**

**(1)** 设 $n = \operatorname{char}(K) > 0$，我们证明 $n$ 是素数。反设 $n = rs$，其中 $1 < r, s < n$。设 $e = 1_K$。则
$$
0 = ne = (rs)e = (re)(se)
$$
因为 $K$ 是域（从而是整环），故 $re = 0$ 或 $se = 0$。但 $1 < r < n$ 且 $1 < s < n$，这与 $n$ 是 $e$ 的最小正整数加法阶矛盾。因此 $n$ 必为素数。

**(2)** 设 $a \in K$。则
$$
pa = p(ea) = (pe)a = 0 \cdot a = 0
$$
这里 $pe = 0$ 由特征的定义保证。

**(3)** 定义 $\varphi: \mathbb{Z} \to K$ 为 $\varphi(n) = ne$。则 $\varphi$ 是环同态，$\ker(\varphi) = (p)$（若 $\operatorname{char}(K) = p$）或 $\ker(\varphi) = \{0\}$（若 $\operatorname{char}(K) = 0$）。在后一种情况下，$\varphi$ 是单射。因为 $K$ 的非零元可逆，$\varphi$ 可以扩展为 $\mathbb{Q} \to K$：$\varphi(m/n) = (me)(ne)^{-1}$。这个扩展是单的域同态，因此 $\mathbb{Q}$ 嵌入 $K$。

**(4)** 若 $\operatorname{char}(K) = p$，则 $\varphi$ 诱导 $\overline{\varphi}: \mathbb{Z}/p\mathbb{Z} \to K$，$n + p\mathbb{Z} \mapsto ne$。因为 $\mathbb{Z}/p\mathbb{Z}$ 是域且 $\overline{\varphi}$ 非零，$\overline{\varphi}$ 是单射。 $\blacksquare$

</ProofToggle>

::: info 证明中嵌入的关键论证
定理 (3) 和 (4) 的证明中有一个重要的构造：从环同态 $\varphi: \mathbb{Z} \to K$ 出发，利用"每个域都是整环"这个事实，推导出 $\varphi$ 要么是单射（char 0），要么核为 $(p)$（char $p$），然后利用域的"除法"性质把 $\mathbb{Z}$ 的分式域 $\mathbb{Q}$ 也嵌入 $K$。

这个论证的模式是：**先用环同态嵌入 $\mathbb{Z}$，再用域的性质扩展到 $\mathbb{Q}$ 或 $\mathbb{F}_p$**。这个模式在 Galois 理论中会反复出现。
:::

::: corollary 特征的判别 {#cor-char-criterion}
设 $K$ 是域。则：
- $\operatorname{char}(K) = 0$ 当且仅当 $K$ 包含 $\mathbb{Q}$ 的同构副本。
- $\operatorname{char}(K) = p$ 当且仅当 $K$ 中 $\underbrace{1 + 1 + \cdots + 1}_{p} = 0$。
- $\operatorname{char}(K) = p$ 当且仅当 $K$ 包含 $\mathbb{F}_p$ 的同构副本。
:::

::: example 特征的计算 {#ex-characteristic}

1. $\operatorname{char}(\mathbb{Q}) = 0$：无论加多少个 $1$，都得不到 $0$。
2. $\operatorname{char}(\mathbb{R}) = 0$，$\operatorname{char}(\mathbb{C}) = 0$。
3. $\operatorname{char}(\mathbb{F}_p) = p$：$\underbrace{1 + \cdots + 1}_{p} = p \equiv 0 \pmod{p}$。
4. $\operatorname{char}(\mathbb{F}_{p^n}) = p$：有限域 $\mathbb{F}_{p^n}$ 的特征总是 $p$（它包含 $\mathbb{F}_p$ 作为素域）。
5. $\operatorname{char}(\mathbb{Z}/n\mathbb{Z}) = ?$：当 $n$ 是素数 $p$ 时，$\operatorname{char}(\mathbb{F}_p) = p$。当 $n$ 不是素数时，$\mathbb{Z}/n\mathbb{Z}$ 不是域（有零因子），所以"特征"的概念不适用（特征只对域或整环定义）。
:::

::: warning 误区："特征可以是合数"
**在域的范畴中，特征只能是 0 或素数。** 这是定理 {thm-characteristic} 的核心结论。

对于一般的环，特征可以是合数。例如 $\mathbb{Z}/6\mathbb{Z}$ 作为环的特征是 6（$\underbrace{1 + \cdots + 1}_6 = 6 \equiv 0$），但 $\mathbb{Z}/6\mathbb{Z}$ 不是域。域的"无零因子"条件排除了特征为合数的可能。
:::

## 素域 {#sec-prime-fields}

::: definition 素域 {#def-prime-field}
域 $K$ 的**素域**（prime field）是 $K$ 的最小子域，即 $K$ 中所有子域的交。
:::

::: proposition {#prop-prime-field}
设 $K$ 是域。则 $K$ 的素域同构于 $\mathbb{Q}$（若 $\operatorname{char}(K) = 0$）或 $\mathbb{F}_p$（若 $\operatorname{char}(K) = p > 0$）。
:::

<ProofToggle>

**证明.** $K$ 的素域恰好是 $K$ 中包含 $1$ 的最小子域，即由 $1$ 生成的子域。由 {thm-characteristic}(3)(4)，这个子域同构于 $\mathbb{Q}$ 或 $\mathbb{F}_p$。 $\blacksquare$

</ProofToggle>

::: intuition 素域的意义
素域是一个域的"算术基底"。在素域之上的所有域结构都建立在相同的算术规则之上。特征 $0$ 的域继承了有理数的算术；特征 $p$ 的域继承了模 $p$ 算术的"唯一性"——这在有限域理论（[第十章](/chapters/10-finite-fields/)）中将起到关键作用。

素域的概念也是 Galois 理论的起点：当我们讨论"$K$-自同构"（即固定 $K$ 中所有元素的自同构）时，自同构总是自动固定素域中的所有元素（见下文 {prop-automorphism-fixes-prime-field}）。因此 "$\mathbb{Q}$-自同构"和"自同构"对特征 0 的域来说是同一件事。
:::

## 子域 {#subfields}

::: definition 子域 {#def-subfield}
设 $K$ 是域，$L \subseteq K$。称 $L$ 是 $K$ 的**子域**（subfield），若 $L$ 关于 $K$ 的加法和乘法自身构成域。
:::

::: proposition 子域判别 {#prop-subfield-criterion}
设 $K$ 是域，$L \subseteq K$ 满足 $0, 1 \in L$ 且 $L \neq \{0\}$。则 $L$ 是 $K$ 的子域当且仅当：
1. $L$ 关于加法封闭；
2. $L$ 关于乘法封闭；
3. 对每个 $a \in L \setminus \{0\}$，有 $a^{-1} \in L$。
:::

<ProofToggle>

**证明.** 
($\Rightarrow$) 若 $L$ 是子域，则条件由域的定义直接得到。

($\Leftarrow$) 条件 (1)(2) 保证 $L$ 关于 $K$ 的运算封闭。加法结合律、交换律、分配律等在 $K$ 中成立，自然在 $L$ 中也成立。条件 (3) 保证非零元有逆。零元 $0 \in L$，单位元 $1 \in L$。因此 $L$ 是域。 $\blacksquare$

</ProofToggle>

::: example 子域的例子 {#ex-subfields}

1. $\mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$。每个包含关系都是子域关系。

2. $\mathbb{Q}(\sqrt{2}) = \{a + b\sqrt{2} : a, b \in \mathbb{Q}\}$ 是 $\mathbb{R}$ 的子域。验证封闭性：$(a + b\sqrt{2})^{-1} = \frac{a - b\sqrt{2}}{a^2 - 2b^2} \in \mathbb{Q}(\sqrt{2})$（当 $a^2 - 2b^2 \neq 0$ 时）。这里 $\sqrt{2} \notin \mathbb{Q}$ 保证了 $\mathbb{Q}(\sqrt{2}) \neq \mathbb{Q}$。

3. $\mathbb{F}_p$ 是 $\mathbb{F}_{p^n}$ 的子域（也是素域）。更一般地，$\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n}$ 当且仅当 $m \mid n$。

4. $\mathbb{Q}(\pi) = \{f(\pi)/g(\pi) : f, g \in \mathbb{Q}[x], g(\pi) \neq 0\}$ 是 $\mathbb{R}$ 的子域。注意 $\pi$ 是超越数（不在任何 $\mathbb{Q}$ 上的代数方程中），所以 $\mathbb{Q}(\pi) \cong \mathbb{Q}(x)$（有理函数域）。
:::

::: info 子域的"生成"
给定域 $K$ 和子集 $S \subseteq K$，**由 $S$ 生成的子域** $K(S)$ 是 $K$ 中包含 $S$ 的最小子域（即所有包含 $S$ 的子域的交）。当 $S = \{\alpha\}$ 时，记 $K(\alpha)$。

- 若 $\alpha$ 是 $K$ 上的代数元素（满足某个 $K$ 上的多项式方程），则 $K(\alpha) \cong K[x]/(m_\alpha)$，其中 $m_\alpha$ 是 $\alpha$ 在 $K$ 上的极小多项式（见 [§3.3 代数元素](3.3-algebraic-elements)）。
- 若 $\alpha$ 是超越元素，则 $K(\alpha) \cong K(x)$（有理函数域）。
:::

## 域的自同构 {#sec-field-automorphisms}

::: definition 域的自同构 {#def-field-automorphism}
域 $K$ 的**自同构**（automorphism）是双射的域同态 $\sigma: K \to K$。$K$ 的所有自同构在复合运算下构成群，记为 $\operatorname{Aut}(K)$。
:::

::: proposition 自同构保持素域 {#prop-automorphism-fixes-prime-field}
设 $\sigma \in \operatorname{Aut}(K)$。则 $\sigma$ 固定 $K$ 的素域中的每个元素，即 $\sigma|_{\mathbb{P}} = \operatorname{id}_{\mathbb{P}}$，其中 $\mathbb{P}$ 是 $K$ 的素域。
:::

<ProofToggle>

**证明.** 
- $\sigma(0) = 0$（域同态保持零元）。
- $\sigma(1) = 1$（域同态保持单位元）。
- 由 $\sigma(1) = 1$ 和加法保持，$\sigma(n \cdot 1) = n \cdot 1$ 对所有 $n \in \mathbb{Z}$ 成立。
- 若 $\operatorname{char}(K) = 0$，则 $\sigma(m/n) = \sigma(m \cdot 1) \cdot (\sigma(n \cdot 1))^{-1} = (m \cdot 1)(n \cdot 1)^{-1} = m/n$。
- 若 $\operatorname{char}(K) = p$，则素域由 $\{0, 1, 2 \cdot 1, \ldots, (p-1) \cdot 1\}$ 组成，$\sigma$ 固定每个元素。 $\blacksquare$

</ProofToggle>

::: example 自同构的具体计算 {#ex-automorphisms}

1. $\operatorname{Aut}(\mathbb{Q}) = \{id\}$：因为 $\mathbb{Q}$ 是素域，自同构必须固定素域的每个元素，所以只有恒等映射。

2. $\operatorname{Aut}(\mathbb{R}) = \{id\}$：$\mathbb{R}$ 的自同构必须固定 $\mathbb{Q}$（素域），而且必须保持序关系（$a > 0 \Leftrightarrow a = b^2$ 对某 $b$），从而固定所有实数。但这个证明需要额外的论证。

3. $\operatorname{Aut}(\mathbb{C})$ 包含复共轭 $\sigma: z \mapsto \bar{z}$。事实上 $\operatorname{Aut}(\mathbb{C})$ 非常大（不可数），但连续的自同构只有 $id$ 和复共轭。这个微妙之处展示了抽象自同构和"几何自同构"的区别。

4. $\operatorname{Aut}(\mathbb{Q}(\sqrt{2})) = \{id, \sigma\}$，其中 $\sigma: a + b\sqrt{2} \mapsto a - b\sqrt{2}$。$\sigma$ 固定 $\mathbb{Q}$ 并将 $\sqrt{2}$ 映射为 $-\sqrt{2}$。$|\operatorname{Aut}(\mathbb{Q}(\sqrt{2}))| = [\mathbb{Q}(\sqrt{2}) : \mathbb{Q}] = 2$——这正是 Galois 理论核心定理的特例。

5. $\operatorname{Aut}(\mathbb{F}_4) = \{id, \phi\}$，其中 $\phi: x \mapsto x^2$（Frobenius 自同构）。$\phi$ 固定 $\mathbb{F}_2$ 并将 $\alpha$ 映射为 $\alpha^2 = \alpha + 1$。$|\operatorname{Aut}(\mathbb{F}_4)| = [\mathbb{F}_4 : \mathbb{F}_2] = 2$。详见 [§10.2 Frobenius](/chapters/10-finite-fields/10.2-frobenius)。
:::

::: info $K$-自同构
设 $K \subseteq L$ 是域扩张。$L$ 的**$K$-自同构**是固定 $K$ 中每个元素的自同构 $\sigma \in \operatorname{Aut}(L)$。所有 $K$-自同构构成 $\operatorname{Aut}(L)$ 的子群，记为 $\operatorname{Aut}_K(L)$ 或 $\operatorname{Aut}(L/K)$。

由 {prop-automorphism-fixes-prime-field}，自同构总是固定素域。因此：
- 对特征 0 的域，"$\mathbb{Q}$-自同构" = "自同构"。
- 对特征 $p$ 的域，"$\mathbb{F}_p$-自同构" = "自同构"。

当我们说"$K$-自同构"时，通常 $K$ 比素域大。例如 "$\mathbb{Q}(\sqrt{2})$-自同构"要求同时固定 $\sqrt{2}$。**Galois 群 $\operatorname{Gal}(L/K) = \operatorname{Aut}_K(L)$** 就是这样的 $K$-自同构群（见 [§7 Galois 群](/chapters/07-galois-groups/)）。
:::

::: intuition 自同构的直觉
域的自同构是"保持所有域结构的对称变换"。因为自同构必须固定素域，所以对 $\mathbb{Q}$ 上的域来说，自同构是"固定有理数的对称"。Galois 理论的核心洞察是：**域扩张的自同构群**（Galois 群）**编码了多项式根之间的对称关系**。

例如，$\mathbb{Q}(\sqrt{2})$ 有两个自同构：恒等和 $\sqrt{2} \mapsto -\sqrt{2}$。这两个自同构交换了多项式 $x^2 - 2$ 的两个根 $\sqrt{2}$ 和 $-\sqrt{2}$。Galois 群 $\operatorname{Gal}(\mathbb{Q}(\sqrt{2})/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z}$ 精确地记录了这种对称性。
:::

## 常见误区 {#misconceptions}

::: warning 误区一："域的特征可以是 6"
**错误！** 域的特征只能是 0 或素数。$\mathbb{Z}/6\mathbb{Z}$ 的"加法特征"是 6，但 $\mathbb{Z}/6\mathbb{Z}$ 不是域（$\overline{2} \cdot \overline{3} = \overline{0}$）。特征为合数的环一定有零因子，因此不可能是域。
:::

::: warning 误区二："$\operatorname{Aut}(\mathbb{R})$ 包含非平凡自同构"
**错误（在连续自同构的范畴中）。** $\operatorname{Aut}(\mathbb{R}) = \{id\}$。原因：自同构必须固定 $\mathbb{Q}$，且保持非负性（$a \geq 0 \Leftrightarrow a = b^2$ 对某 $b$），从而固定所有实数。

但注意：如果不要求连续性，利用选择公理可以构造 $\mathbb{R}$ 的非平凡自同构。不过这种自同构是"病态的"——它们不是可测函数。在代数语境中，$\operatorname{Aut}(\mathbb{R})$ 通常指连续自同构或有序自同构。
:::

::: warning 误区三："子域判别只需验证加法和乘法封闭"
**不完整！** 还需要验证逆元封闭。例如 $\mathbb{Z} \subset \mathbb{Q}$ 关于加法和乘法封闭，但 $\mathbb{Z}$ 不是 $\mathbb{Q}$ 的子域（$2^{-1} = 1/2 \notin \mathbb{Z}$）。

子域判别 {prop-subfield-criterion} 的三个条件缺一不可。
:::

::: warning 误区四："自同构不固定素域"
**错误！** 任何域自同构都固定素域的每个元素。这是 {prop-automorphism-fixes-prime-field} 的结论。特别地，"$\mathbb{Q}$-自同构"对特征 0 域来说就是"自同构"——没有额外的约束。
:::

## 自测问题 {#self-test}

::: question 自测
1. **域的判断**：判断以下集合是否构成域，并说明理由：
   - (a) $\mathbb{Z}[\sqrt{2}] = \{a + b\sqrt{2} : a, b \in \mathbb{Z}\}$
   - (b) $\mathbb{Q}(\sqrt{2}) = \{a + b\sqrt{2} : a, b \in \mathbb{Q}\}$
   - (c) $\{0, 1, 2\}$ 关于模 3 加法和乘法

2. **特征计算**：$\operatorname{char}(\mathbb{F}_9)$ 等于什么？（$\mathbb{F}_9$ 是 9 元有限域。）

3. **子域列举**：$\mathbb{Q}(\sqrt{2}, \sqrt{3})$ 的子域有哪些？（提示：这是一个 4 次扩张。）

4. **自同构计算**：$\operatorname{Aut}(\mathbb{Q}(\sqrt{2}, \sqrt{3}))$ 同构于什么群？

5. **概念辨析**：解释为什么 $\mathbb{Q}[x]/(x^2+1)$ 是域，但 $\mathbb{Q}[x]/(x^2-1)$ 不是域。
:::

::: details 答案
1. (a) **不是域**。$\mathbb{Z}[\sqrt{2}]$ 关于加法和乘法封闭，但不是每个非零元都有逆元。例如 $2^{-1} = 1/2 \notin \mathbb{Z}[\sqrt{2}]$。$\mathbb{Z}[\sqrt{2}]$ 是整环但不是域。(b) **是域**。$\mathbb{Q}(\sqrt{2})$ 是域——它是 $\mathbb{R}$ 的子域。(c) **是域**。$= \mathbb{F}_3$，因为 3 是素数。

2. $\operatorname{char}(\mathbb{F}_9) = 3$。所有 $\mathbb{F}_{3^n}$ 的特征都是 3。$\mathbb{F}_9 = \mathbb{F}_{3^2}$，素域是 $\mathbb{F}_3$。

3. $\mathbb{Q}(\sqrt{2}, \sqrt{3})$ 的子域（在 $\mathbb{Q}$ 之上）：$\mathbb{Q}$，$\mathbb{Q}(\sqrt{2})$，$\mathbb{Q}(\sqrt{3})$，$\mathbb{Q}(\sqrt{6})$，$\mathbb{Q}(\sqrt{2}, \sqrt{3})$。共 5 个。

4. $\operatorname{Aut}(\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$（Klein 四元群）。四个元素：$id$，$\sqrt{2} \mapsto -\sqrt{2}$，$\sqrt{3} \mapsto -\sqrt{3}$，两者同时变号。

5. $x^2+1$ 在 $\mathbb{Q}$ 上不可约（无有理根），所以 $\mathbb{Q}[x]/(x^2+1) \cong \mathbb{Q}(i)$ 是域。$x^2-1 = (x-1)(x+1)$ 在 $\mathbb{Q}$ 上可约，所以 $\mathbb{Q}[x]/(x^2-1) \cong \mathbb{Q} \times \mathbb{Q}$ 有零因子（$(x-1)(x+1) = 0$），不是域。
:::
