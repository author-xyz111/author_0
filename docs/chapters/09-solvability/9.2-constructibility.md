# §9.2 尺规作图 {#sec-constructibility}

::: tip 📖 学习目标
完成本节后，你应该能够：
1. 将尺规作图条件翻译为域扩张语言，给出可作图数的代数刻画
2. 用 Galois 理论证明三大古典问题（三等分角、倍立方、化圆为方）的不可能性
3. 陈述 Gauss–Wantzel 定理，并理解 Fermat 素数在正多边形可作图性中的角色
4. 解释为什么"扩张次数为 2 的幂"是可作图性的核心判据
:::

## 动机 {#motivation}

古希腊人提出了三个著名的尺规作图问题：
1. **三等分角**：能否用尺规将任意角三等分？
2. **倍立方**：能否用尺规构造体积为给定立方体两倍的立方体的边长？
3. **化圆为方**：能否用尺规构造面积等于给定圆的正方形的边长？

两千多年来，无数数学家试图解决这些问题。直到 19 世纪，代数和 Galois 理论的发展才最终证明了**三个都不可能**。这不仅是几何问题的解答，更是代数方法威力的完美展示：将几何条件翻译为域论条件，然后用代数工具（不可约性、扩张次数、超越性）一击致命。

::: intuition 核心直觉
尺规的每一步操作——画直线、画圆、求交点——在代数上只对应**至多二次**的方程求解。因此，经过 $n$ 步操作后能"到达"的数，其所在的域对 $\mathbb{Q}$ 的扩张次数最多是 $2^n$。如果一个数需要三次或更高次的扩张才能到达，那尺规就无能为力了。
:::

---

## 可作图数 {#constructible-numbers}

::: definition 可作图数 {#def-constructible-number}
实数 $\alpha \in \mathbb{R}$ 称为**可尺规作图**的（constructible），如果它可以从长度为 $1$ 的线段出发，通过有限次以下操作得到：
1. 过两点作直线；
2. 以已知点为圆心、已知距离为半径作圆；
3. 取两条直线的交点、直线与圆的交点、两个圆的交点。

可作图数的集合 $\mathcal{C} \subseteq \mathbb{R}$ 称为**可作图域**。
:::

::: proposition 可作图域的性质 {#prop-constructible-field}
$\mathcal{C}$ 是 $\mathbb{R}$ 的子域，且对 $\alpha > 0$，$\alpha \in \mathcal{C} \Rightarrow \sqrt{\alpha} \in \mathcal{C}$。
:::

<ProofToggle>

**证明.** 
- **加减乘除**：通过相似三角形和相交线构造。例如，已知 $a, b \in \mathcal{C}$，可以构造 $a+b$（直线段拼接）、$a-b$、$a \cdot b$（相似三角形）、$a/b$。
- **开平方**：已知 $a > 0$，可以构造 $\sqrt{a}$。经典方法：取线段 $AB = a + 1$，以 $AB$ 为直径作半圆。从 $AB$ 上距离一端为 $a$ 的点 $C$ 向半圆作垂线，垂线长度即为 $\sqrt{a}$（由射影定理：$AC \cdot CB = CD^2$）。

因此 $\mathcal{C}$ 在四则运算下封闭，且对正元素封闭开方，是 $\mathbb{R}$ 的子域。$\blacksquare$

</ProofToggle>

## 可作图数的代数刻画 {#algebraic-characterization}

::: theorem 可作图数的代数刻画 {#thm-constructible-characterization}
设 $\alpha \in \mathbb{R}$。$\alpha$ 可尺规作图当且仅当存在域塔：
$$
\mathbb{Q} = K_0 \subseteq K_1 \subseteq \cdots \subseteq K_n \subseteq \mathbb{R},
$$
其中 $\alpha \in K_n$，且对每个 $i = 0, 1, \ldots, n-1$，有 $K_{i+1} = K_i(\sqrt{a_i})$ 对某个 $a_i > 0$，$a_i \in K_i$。等价地，$[K_{i+1} : K_i] = 2$。

特别地，$[\mathbb{Q}(\alpha) : \mathbb{Q}]$ 是 $2$ 的幂。
:::

<ProofToggle>

**证明.**

**($\Leftarrow$)** 方向较简单：若 $\alpha \in K_n$，其中每个 $K_{i+1} = K_i(\sqrt{a_i})$，则每一步添加 $\sqrt{a_i}$ 都可以通过尺规完成（由 $\sqrt{a_i}$ 的几何构造），因此 $\alpha$ 可作图。

**($\Rightarrow$)** 方向的关键是：**尺规的每一步操作只产生至多二次扩张**。

具体地，设当前已知的点坐标都在域 $K \subseteq \mathbb{R}$ 中。
- 两条直线的交点：直线方程是线性的（系数在 $K$ 中），解线性方程组仍在 $K$ 中。**不产生扩张**。
- 直线与圆的交点：代入后得到一个二次方程。解在 $K(\sqrt{a})$ 中（$a \in K$，$a > 0$）。**至多二次扩张**。
- 两个圆的交点：两个圆的方程相减后化为直线与圆的交点问题。**至多二次扩张**。

因此，经过 $n$ 步操作后的域 $K_n$ 满足 $[K_n : \mathbb{Q}] = 2^m$（$m \leq n$），且 $\alpha \in K_n$。

最后，$\mathbb{Q}(\alpha) \subseteq K_n$，由塔定律 $[K_n : \mathbb{Q}] = [K_n : \mathbb{Q}(\alpha)] \cdot [\mathbb{Q}(\alpha) : \mathbb{Q}]$，故 $[\mathbb{Q}(\alpha) : \mathbb{Q}] \mid 2^m$，即 $[\mathbb{Q}(\alpha) : \mathbb{Q}]$ 是 $2$ 的幂。$\blacksquare$

</ProofToggle>

::: warning 逆命题不成立
$[\mathbb{Q}(\alpha) : \mathbb{Q}]$ 是 $2$ 的幂**不**保证 $\alpha$ 可作图。真正的条件是存在一个"全为二次"的域塔从 $\mathbb{Q}$ 到 $\alpha$，其中**每个中间域都是实数域**。例如，$x^4 - 2$ 的某个根 $\sqrt[4]{2}$ 满足 $[\mathbb{Q}(\sqrt[4]{2}) : \mathbb{Q}] = 4 = 2^2$，而且确实可作图（$\sqrt[4]{2} = \sqrt{\sqrt{2}}$）。

但如果一个四次扩张不能分解为两次二次扩张的链，那即使次数是 $4$，也可能不可作图。
:::

::: example 一个四次但不可作图的数 {#ex-not-constructible-quartic}
设 $\alpha$ 是 $f(x) = x^4 + x + 1 \in \mathbb{Q}[x]$ 的一个实根。$f$ 在 $\mathbb{Q}$ 上不可约（Eisenstein 不适用，但可以验证 $f$ 无有理根且无二次有理因子）。故 $[\mathbb{Q}(\alpha) : \mathbb{Q}] = 4 = 2^2$。

**$\alpha$ 不可尺规作图。** 原因：$\operatorname{Gal}(f/\mathbb{Q}) \cong S_4$（计算 discriminant $\Delta(f) = -283$ 不是完全平方）。$S_4$ 虽然有阶为 4 的子群，但 $S_4$ 不是 2-群（$|S_4| = 24$）。如果 $\alpha$ 可作图，则 $\operatorname{Gal}(f/\mathbb{Q})$ 的所有 Sylow 子群必须是 2-群——但这不成立。

更直接地说：可作图性要求存在 $\mathbb{Q} = K_0 \subset K_1 \subset K_2$ 满足 $[K_1:K_0] = [K_2:K_1] = 2$，但 $f$ 的分裂域不能以这种方式逐次逼近。
:::

::: warning "次数是 2 的幂"只是必要条件
$\alpha$ 可作图 $\Rightarrow$ $[\mathbb{Q}(\alpha):\mathbb{Q}]$ 是 $2$ 的幂。但反过来**不**成立。真正的充分必要条件是：存在 $\mathbb{Q}$ 到 $\mathbb{Q}(\alpha)$ 的全为二次扩张的域塔（并且每个中间域都是实域）。

这在 Galois 理论中的意义是：可作图性对应于 Galois 群是 2-群。
:::

## 三大古典问题的不可能性 {#three-problems}

::: theorem 三等分角的不可能性 {#thm-trisection}
$60°$ 角不能用尺规三等分。等价地，$\cos 20°$ 不可尺规作图。
:::

<ProofToggle>

**证明.** 三等分 $60°$ 等价于构造 $\cos 20°$。利用三倍角公式：
$$\cos 3\theta = 4\cos^3\theta - 3\cos\theta$$
令 $\theta = 20°$：
$$
\frac{1}{2} = \cos 60° = 4\cos^3 20° - 3\cos 20°.
$$
令 $\alpha = 2\cos 20°$，则：
$$
4 \cdot \left(\frac{\alpha}{2}\right)^3 - 3 \cdot \frac{\alpha}{2} = \frac{1}{2}
\quad\Longrightarrow\quad
\alpha^3 - 3\alpha - 1 = 0.
$$
因此 $\alpha$ 是 $f(x) = x^3 - 3x - 1$ 的根。

**$f$ 在 $\mathbb{Q}$ 上不可约**：由有理根定理，$f$ 的有理根只能是 $\pm 1$。但 $f(1) = -3 \neq 0$，$f(-1) = 1 \neq 0$。三次多项式无有理根即不可约。

因此 $[\mathbb{Q}(\alpha) : \mathbb{Q}] = 3$。但 $3$ 不是 $2$ 的幂，故 $\alpha$ 不可尺规作图。$\blacksquare$

</ProofToggle>

::: remark 不是所有角都不能三等分
注意定理说的是"$60°$ 角不能三等分"，不是"任意角都不能三等分"。例如 $90°$ 角可以三等分：$30°$ 的三角函数值都是代数数，且 $[\mathbb{Q}(\cos 30°) : \mathbb{Q}] = 2$。实际上，$180°$ 可三等分当且仅当 $4\cos^3\theta - 3\cos\theta = \cos 60°$ 对应的三次多项式在 $\mathbb{Q}$ 上可约——这对某些特殊的角是成立的。
:::

::: theorem 倍立方的不可能性 {#thm-doubling-cube}
不能用尺规构造体积为给定立方体两倍的立方体的边长。等价地，$\sqrt[3]{2}$ 不可尺规作图。
:::

<ProofToggle>

**证明.** 如果原立方体边长为 1，体积为 1，则体积为 2 的立方体边长为 $\sqrt[3]{2}$。$\sqrt[3]{2}$ 的极小多项式为 $x^3 - 2$（Eisenstein 判据，$p = 2$），故 $[\mathbb{Q}(\sqrt[3]{2}) : \mathbb{Q}] = 3$。$3$ 不是 $2$ 的幂。$\blacksquare$

</ProofToggle>

::: theorem 化圆为方的不可能性 {#thm-squaring-circle}
不能用尺规构造面积等于单位圆的正方形的边长。等价地，$\sqrt{\pi}$ 不可尺规作图。
:::

<ProofToggle>

**证明.** 单位圆面积为 $\pi$，故正方形边长为 $\sqrt{\pi}$。可作图数都是**代数数**（因为它们在 $\mathbb{Q}$ 的有限扩张中）。但 $\pi$ 是超越数（Lindemann, 1882），故 $\sqrt{\pi}$ 也是超越数。$\sqrt{\pi}$ 不在可作图域中。$\blacksquare$

</ProofToggle>

::: intuition 三个不可能性使用了三种不同的论证
- **三等分角**和**倍立方**：扩张次数是 3，不是 2 的幂。这是代数论证。
- **化圆为方**：$\pi$ 是超越数，根本不满足代数条件。这是超越数论证。

前两个只用到基本的不可约性和扩张次数，最后一个需要 Lindemann 深刻的超越性定理。
:::

## 正 $n$ 边形的可作图性 {#regular-gon}

::: theorem Gauss–Wantzel {#thm-gauss-wantzel}
正 $n$ 边形可用尺规作图当且仅当 $n = 2^k p_1 p_2 \cdots p_r$，其中 $k \geq 0$，$p_1, \ldots, p_r$ 是互异的 **Fermat 素数**（形如 $F_m = 2^{2^m} + 1$ 的素数）。

已知的 Fermat 素数只有 5 个：
$$
F_0 = 3, \quad F_1 = 5, \quad F_2 = 17, \quad F_3 = 257, \quad F_4 = 65537.
$$
对于 $5 \leq m \leq 32$，$F_m$ 都不是素数。是否还有其他 Fermat 素数是未解问题。
:::

<ProofToggle>

**证明.** 正 $n$ 边形可作图 $\iff$ $\cos(2\pi/n)$ 可作图。

**关键一步**：$e^{2\pi i/n} = \zeta_n$，$\cos(2\pi/n) = (\zeta_n + \zeta_n^{-1})/2$。因此 $\cos(2\pi/n)$ 可作图 $\iff$ $\zeta_n + \zeta_n^{-1}$ 可作图。

分圆多项式 $\Phi_n(x)$ 在 $\mathbb{Q}$ 上不可约（{thm-cyclotomic-irreducible}），$[\mathbb{Q}(\zeta_n) : \mathbb{Q}] = \varphi(n)$（Euler 函数）。$\zeta_n$ 满足 $\zeta_n + \zeta_n^{-1} = 2\cos(2\pi/n)$，故 $\mathbb{Q}(\zeta_n + \zeta_n^{-1})$ 是 $\mathbb{Q}(\zeta_n)$ 的"实部子域"，$[\mathbb{Q}(\zeta_n) : \mathbb{Q}(\zeta_n + \zeta_n^{-1})] = 2$（因为 $\zeta_n$ 满足 $x^2 - (\zeta_n + \zeta_n^{-1})x + 1 = 0$）。因此：
$$[\mathbb{Q}(\zeta_n + \zeta_n^{-1}) : \mathbb{Q}] = \varphi(n)/2.$$

**正 $n$ 边形可作图** $\iff$ $\varphi(n)/2$ 是 $2$ 的幂（从而 $\varphi(n)$ 是 $2$ 的幂），且存在从 $\mathbb{Q}$ 到 $\mathbb{Q}(\zeta_n + \zeta_n^{-1})$ 的全为二次扩张的域塔（这需要 $\operatorname{Gal}(\mathbb{Q}(\zeta_n)/\mathbb{Q}) \cong (\mathbb{Z}/n\mathbb{Z})^\times$ 是 2-群的正规列）。

$\varphi(n)$ 是 2 的幂 $\iff$ $n = 2^k p_1 \cdots p_r$，$p_i$ 是互异的 Fermat 素数（因为 $\varphi$ 是积性函数，$\varphi(p^a) = p^{a-1}(p-1)$，这对奇素数 $p$ 是 2 的幂 $\iff$ $a = 1$ 且 $p - 1$ 是 2 的幂 $\iff$ $p$ 是 Fermat 素数）。

反过来，当 $n$ 满足上述条件时，$(\mathbb{Z}/n\mathbb{Z})^\times$ 确实可以通过一系列指标为 2 的正规子群链降到平凡群（因为它是一个 2-群），对应的域塔全部是二次扩张，故 $\cos(2\pi/n)$ 可作图。$\blacksquare$

</ProofToggle>

::: example 已知的可作图正多边形
- $n = 3$（正三角形）：$\varphi(3) = 2 = 2^1$ ✓（$3 = F_0$）
- $n = 4$（正方形）：$\varphi(4) = 2 = 2^1$ ✓
- $n = 5$（正五边形）：$\varphi(5) = 4 = 2^2$ ✓（$5 = F_1$）
- $n = 6$：$6 = 2 \cdot 3$，$\varphi(6) = 2 = 2^1$ ✓
- $n = 15 = 3 \cdot 5$：$\varphi(15) = 8 = 2^3$ ✓
- $n = 17$：$\varphi(17) = 16 = 2^4$ ✓（$17 = F_2$，Gauss 在 1796 年 19 岁时发现了这一构造）

**不可作图**的例子：
- $n = 7$：$\varphi(7) = 6$，不是 2 的幂 ✗
- $n = 9$：$\varphi(9) = 6$，不是 2 的幂 ✗
- $n = 11$：$\varphi(11) = 10$，不是 2 的幂 ✗
:::

::: remark Gauss 与正 17 边形
Gauss 发现正 17 边形可尺规作图是他年轻时最重要的数学发现之一。他后来声称这一发现直接促使他选择了数学而非语言学作为职业。Gauss 还证明了正 $n$ 边形可作图的充分条件（Fermat 素数部分），而 Wantzel (1837) 证明了必要条件。
:::

| 问题 | 结论 | 核心论证 |
|:---|:---|:---|
| 三等分 60° 角 | 不可能 | $[\mathbb{Q}(2\cos 20°) : \mathbb{Q}] = 3$，不是 2 的幂 |

## 典型可作图数的构造 {#worked-examples}

::: example 完整的二次域塔：构造 $\sqrt{2 + \sqrt{3}}$ {#ex-quadratic-tower}
证明 $\sqrt{2 + \sqrt{3}}$ 可尺规作图，并给出完整的二次域塔。

**域塔：**

$$\mathbb{Q} \xrightarrow{\times 2} \mathbb{Q}(\sqrt{3}) \xrightarrow{\times 2} \mathbb{Q}(\sqrt{3}, \sqrt{2+\sqrt{3}}).$$

验证：$[\mathbb{Q}(\sqrt{3}):\mathbb{Q}] = 2$（$\sqrt{3}$ 的极小多项式是 $x^2 - 3$）。

下一步：设 $a_1 = 2 + \sqrt{3} \in \mathbb{Q}(\sqrt{3})$。$a_1 > 0$，故 $\sqrt{a_1} = \sqrt{2+\sqrt{3}} \in \mathbb{R}$。$[\mathbb{Q}(\sqrt{3}, \sqrt{2+\sqrt{3}}) : \mathbb{Q}(\sqrt{3})] = 2$（因为 $\sqrt{2+\sqrt{3}}$ 不在 $\mathbb{Q}(\sqrt{3})$ 中——可以验证 $2+\sqrt{3}$ 不是 $\mathbb{Q}(\sqrt{3})$ 中元素的平方）。

**几何构造：** 先构造 $\sqrt{3}$（直角三角形，直角边 1 和 $\sqrt{2}$，或直接用射影定理），再构造 $2+\sqrt{3}$（线段拼接），最后构造 $\sqrt{2+\sqrt{3}}$（射影定理）。
:::

::: remark 可作图数与可解群的关系
为什么尺规作图会出现在"可解群"这一节？因为可作图性本质上是一个**可解性**问题：

- $\alpha$ 可作图 $\iff$ $\mathbb{Q}(\alpha)$ 嵌入到一个 Galois 群为 $2$-群的扩张中。
- $2$-群是可解群的特例（ [§9.1](/chapters/09-solvability/9.1-solvable-groups) ）。
- 更一般地，$\alpha$ 可通过**根式**求解 $\iff$ $\alpha$ 的极小多项式的 Galois 群是可解群。

因此：**尺规作图 $\subseteq$ 根式求解 $\subseteq$ 可解 Galois 群**。

三等分角的不可能性和五次方程的不可解性本质上是同一个定理的两个应用：Galois 群不够"可解"。
:::

## 常见误区 {#misconceptions}

::: warning 误区一：三等分任意角不可能
不！$60°$ 角不能三等分，但 $90°$ 角可以（$30°$ 的三角函数值在二次扩张中）。一般 $120°$ 也可以。关键不是"角的大小"，而是三等分方程的 Galois 群是否为 2-群。
:::

::: warning 误区二：$\sqrt[3]{2}$ 不可作图是因为 $3$ 不是 2 的幂
严格来说，不可作图的**直接原因**是不存在从 $\mathbb{Q}$ 到 $\mathbb{Q}(\sqrt[3]{2})$ 的全为二次扩张的域塔。$[\mathbb{Q}(\sqrt[3]{2}):\mathbb{Q}]=3$（不是 2 的幂）只是这种不存在性的一个**推论**。

但在实际论证中，"次数不是 2 的幂"是一个非常方便的快速判据。
:::

::: warning 误区三：可作图数都是代数数
这是正确的！可作图数 $\subseteq$ 可作图域 $\subseteq$ $\mathbb{Q}$ 的代数扩张。因此化圆为方的不可能性源于 $\pi$ 是超越数——它根本不在代数的世界中。
:::

## 自测题 {#self-test}

1. **[基础]** 证明 $\sqrt{2 + \sqrt{3}}$ 可尺规作图。写出从 $\mathbb{Q}$ 出发的二次域塔。
2. **[理解]** 为什么"一般角的三等分"不可能，但某些特殊角（如 $180°$、$90°$）的三等分是可能的？用 Galois 理论的语言说明区别在哪里。
3. **[计算]** 利用 Gauss–Wantzel 定理，判定正 51 边形是否可尺规作图。（提示：$51 = 3 \times 17$。）
4. **[深入]** 设 $\alpha$ 是 $x^4 - x - 1 \in \mathbb{Q}[x]$ 的实根。$[\mathbb{Q}(\alpha) : \mathbb{Q}] = 4 = 2^2$。$\alpha$ 是否可尺规作图？为什么仅有"$[\mathbb{Q}(\alpha) : \mathbb{Q}]$ 是 2 的幂"不足以保证可作图性？
5. **[联系]** 在正 17 边形的 Gauss 构造中，需要用到 $\operatorname{Gal}(\mathbb{Q}(\zeta_{17})/\mathbb{Q}) \cong (\mathbb{Z}/17\mathbb{Z})^\times$ 的什么结构？为什么这个群是一个循环 2-群，从而允许我们通过逐次开方求解？
