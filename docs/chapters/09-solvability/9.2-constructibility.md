# §9.2 尺规作图 {#sec-constructibility}

::: intuition 古典问题的代数化
尺规作图是 Galois 理论最优雅的应用之一。通过将"尺规作图"翻译为域扩张语言，我们能够用 Galois 理论精确判定哪些几何问题可以尺规完成。核心结论是：**可尺规作图的数恰好构成 $\mathbb{Q}$ 的特定子域的元素**。
:::

---

## 可作图数 {#constructible-numbers}

::: definition 可作图数 {#def-constructible-number}
实数 $\alpha \in \mathbb{R}$ 称为**可尺规作图**的（constructible），如果它可以从长度为 $1$ 的线段出发，通过有限次直尺和圆规操作得到。

可作图数的集合 $\mathcal{C} \subseteq \mathbb{R}$ 称为**可作图域**。
:::

::: proposition 可作图域的性质 {#prop-constructible-field}
$\mathcal{C}$ 是 $\mathbb{R}$ 的子域，且对 $\alpha > 0$，$\alpha \in \mathcal{C} \Rightarrow \sqrt{\alpha} \in \mathcal{C}$。
:::

<ProofToggle>

**证明.** 尺规作图允许我们执行四则运算（加、减、乘、除）和开平方。四则运算通过相似三角形和相交线构造；开平方通过圆和直径的几何性质构造。因此 $\mathcal{C}$ 在四则运算下封闭，且对正元素封闭开方。$\blacksquare$

</ProofToggle>

::: theorem 可作图数的代数刻画 {#thm-constructible-characterization}
设 $\alpha \in \mathbb{R}$。$\alpha$ 可尺规作图当且仅当存在域塔：
$$
\mathbb{Q} = K_0 \subseteq K_1 \subseteq \cdots \subseteq K_n \subseteq \mathbb{R},
$$
其中 $\alpha \in K_n$，且对每个 $i$，$K_{i+1} = K_i(\sqrt{a_i})$ 对某个 $a_i > 0$，$a_i \in K_i$。等价地，$[K_{i+1} : K_i] = 2$。

因此 $[\mathbb{Q}(\alpha) : \mathbb{Q}]$ 是 $2$ 的幂。
:::

<ProofToggle>

**证明.** 每一步尺规作图操作只产生至多二次扩张（直线与直线交点、直线与圆交点、圆与圆交点的坐标满足至多二次方程）。故经过 $n$ 步操作后得到的域 $K_n$ 满足 $[K_n : \mathbb{Q}] = 2^n$。$\blacksquare$

</ProofToggle>

## 三大古典问题的不可能性 {#three-problems}

::: theorem 三等分角的不可能性 {#thm-trisection}
$60°$ 角不能用尺规三等分。等价地，$\cos 20°$ 不可尺规作图。
:::

<ProofToggle>

**证明.** 三等分 $60°$ 等价于构造 $\cos 20°$。利用三倍角公式 $\cos 3\theta = 4\cos^3\theta - 3\cos\theta$，令 $\theta = 20°$：
$$
\frac{1}{2} = \cos 60° = 4\cos^3 20° - 3\cos 20°.
$$
故 $\alpha = 2\cos 20°$ 是 $f(x) = x^3 - 3x - 1$ 的根。$f$ 在 $\mathbb{Q}$ 上不可约（有理根检验），故 $[\mathbb{Q}(\alpha) : \mathbb{Q}] = 3$。但 $3$ 不是 $2$ 的幂，故 $\alpha$ 不可尺规作图。$\blacksquare$

</ProofToggle>

::: theorem 倍立方的不可能性 {#thm-doubling-cube}
不能用尺规构造体积为给定立方体两倍的立方体的边长。等价地，$\sqrt[3]{2}$ 不可尺规作图。
:::

<ProofToggle>

**证明.** $\sqrt[3]{2}$ 的极小多项式为 $x^3 - 2$，在 $\mathbb{Q}$ 上不可约（Eisenstein，$p = 2$）。$[\mathbb{Q}(\sqrt[3]{2}) : \mathbb{Q}] = 3$，不是 $2$ 的幂。$\blacksquare$

</ProofToggle>

::: theorem 化圆为方的不可能性 {#thm-squaring-circle}
不能用尺规构造面积等于单位圆的正方形的边长。等价地，$\sqrt{\pi}$ 不可尺规作图。
:::

<ProofToggle>

**证明.** $\pi$ 是超越数（Lindemann, 1882），故 $\sqrt{\pi}$ 也是超越数。可作图数都是代数数。$\blacksquare$

</ProofToggle>

::: theorem 正 $n$ 边形的可作图性 {#thm-regular-gon}
正 $n$ 边形可用尺规作图当且仅当 $n = 2^k p_1 p_2 \cdots p_r$，其中 $k \geq 0$，$p_i$ 是互异的**Fermat 素数**（形如 $2^{2^m} + 1$ 的素数）。

已知的 Fermat 素数只有：$3, 5, 17, 257, 65537$。
:::

<ProofToggle>

**证明.** 正 $n$ 边形的可作图性等价于 $e^{2\pi i/n}$ 的实部 $\cos(2\pi/n)$ 可作图，即 $[\mathbb{Q}(\cos(2\pi/n)) : \mathbb{Q}]$ 是 $2$ 的幂。由于 $\operatorname{Gal}(\mathbb{Q}(\zeta_n)/\mathbb{Q}) \cong (\mathbb{Z}/n\mathbb{Z})^\times$，这是一个阿贝尔群。正 $n$ 边形可作图当且仅当 $(\mathbb{Z}/n\mathbb{Z})^\times$ 的阶是 $2$ 的幂，即 $\varphi(n)$ 是 $2$ 的幂。利用 Euler 函数的乘法性得到上述条件。$\blacksquare$

</ProofToggle>
