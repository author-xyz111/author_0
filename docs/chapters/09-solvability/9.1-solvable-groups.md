# §9.1 可解群与 Abel 群 {#sec-solvable-groups}

::: intuition 历史背景
Galois 理论的原初动机是理解多项式方程的**根式可解性**。Galois 的天才洞察是：一个多项式方程可以用根式求解，当且仅当其 Galois 群是"可解的"——即可以通过一系列阿贝尔商来逐步简化。这个结论优美地统一了"方程的代数性质"和"群的结构"这两个看似无关的概念。
:::

---

## 可解群 {#solvable-groups}

::: definition 可解群 {#def-solvable-group}
群 $G$ 称为**可解的**（solvable），如果存在正规子群列：
$$
G = G_0 \rhd G_1 \rhd G_2 \rhd \cdots \rhd G_n = \{e\},
$$
使得每个商 $G_i / G_{i+1}$ 是**阿贝尔群**。
:::

::: remark 可解群的多种等价刻画
**(i)** 可解群等价于**导出列终止于平凡群**的群：$G^{(0)} = G$，$G^{(i+1)} = [G^{(i)}, G^{(i)}]$（换位子子群），则 $G$ 可解 $\iff$ 存在 $n$ 使得 $G^{(n)} = \{e\}$。

**(i)** 有限可解群等价于**合成因子都是素数阶循环群**的群（即每个 $G_i/G_{i+1} \cong \mathbb{Z}/p_i\mathbb{Z}$）。
:::

::: example 常见可解群 {#ex-solvable-groups}
- 所有阿贝尔群都是可解的（取 $G_1 = \{e\}$）。
- 对称群 $S_3$：$S_3 \rhd A_3 \rhd \{e\}$，$S_3/A_3 \cong \mathbb{Z}/2\mathbb{Z}$，$A_3/\{e\} \cong \mathbb{Z}/3\mathbb{Z}$。可解。
- 对称群 $S_4$：$S_4 \rhd A_4 \rhd V_4 \rhd \{e\}$，$S_4/A_4 \cong \mathbb{Z}/2\mathbb{Z}$，$A_4/V_4 \cong \mathbb{Z}/3\mathbb{Z}$，$V_4/\{e\} \cong (\mathbb{Z}/2\mathbb{Z})^2$。可解。
:::

::: example 非可解群 {#ex-nonsolvable}
$S_5$ **不是可解的**：$S_5 \rhd A_5 \rhd \{e\}$，但 $A_5$ 是单群（无非平凡正规子群），且 $A_5$ 不是阿贝尔群。故 $A_5$ 不能进一步分解。$A_5$ 是最小的非可解群（阶 60）。
:::

::: theorem Burnside {#thm-burnside-solvable}
阶为 $p^a q^b$ 的有限群是可解的（其中 $p, q$ 是素数）。这是 Burnside (1904) 的经典结果，证明使用了表示论。
:::

## Abel–Ruffini 定理 {#abel-ruffini}

::: theorem Abel–Ruffini {#thm-abel-ruffini}
对 $n \geq 5$，一般 $n$ 次方程不是根式可解的。即存在 $n$ 次多项式 $f \in \mathbb{Q}(a_1, \ldots, a_n)[x]$（其中 $a_i$ 是独立的未定元），使得 $f = 0$ 的根不能用 $a_1, \ldots, a_n$ 的有理函数通过有限次四则运算和开方来表示。
:::

<ProofToggle>

**证明概要.** 考虑一般 $n$ 次方程 $x^n + a_1 x^{n-1} + \cdots + a_n = 0$，其 Galois 群为 $S_n$（可以证明）。若此方程根式可解，则 $S_n$ 必须是可解群。但 $n \geq 5$ 时 $S_n$ 不可解（因为 $A_n$ 是单群）。矛盾。$\blacksquare$

</ProofToggle>

::: remark Galois 群为 $S_5$ 的具体多项式
不仅一般五次方程不可根式求解，具体多项式也可以不是。例如：
$$f(x) = x^5 - 4x + 2 \in \mathbb{Q}[x].$$
$f$ 不可约（Eisenstein 判据，$p = 2$），恰好有 3 个实根和 2 个共轭复根，判别式不是平方元。故 $\operatorname{Gal}(f/\mathbb{Q}) \cong S_5$，不可解。
:::

## 根式扩张 {#radical-extensions}

::: definition 根式扩张 {#def-radical-extension}
域扩张 $L/K$ 称为**根式扩张**（radical extension），如果存在中间域链：
$$
K = K_0 \subseteq K_1 \subseteq \cdots \subseteq K_r = L,
$$
使得对每个 $i$，$K_{i+1} = K_i(\alpha_i)$，其中 $\alpha_i^{n_i} \in K_i$ 对某个正整数 $n_i$。
:::

::: theorem Galois 的根式可解判据 {#thm-galois-solvability-criterion}
设 $f \in K[x]$ 是可分多项式（$\operatorname{char} K = 0$），$L$ 是 $f$ 在 $K$ 上的分裂域。则：

$f = 0$ 根式可解 $\iff$ $\operatorname{Gal}(L/K)$ 是可解群。
:::

<ProofToggle>

**证明.** 设 $G = \operatorname{Gal}(L/K)$。

**($\Leftarrow$)** 若 $G$ 可解，则存在正规列 $G = G_0 \rhd G_1 \rhd \cdots \rhd G_n = \{e\}$，$G_i/G_{i+1}$ 循环。由 Galois 对应，$L^{G_i}$ 给出中间域链 $K = L^G \subseteq L^{G_1} \subseteq \cdots \subseteq L^{\{e\}} = L$，其中 $L^{G_{i+1}}/L^{G_i}$ 是循环 Galois 扩张。

关键：**素数阶循环扩张是根式扩张**（需要本原单位根，可通过添加适当单位根扩域来实现）。因此 $L$ 包含在某个根式扩张 $M/K$ 中，$f$ 的根可以用根式表示。

**($\Rightarrow$)** 若 $f$ 根式可解，则存在根式扩张 $M \supseteq L$ 使得 $M = K(\alpha_1^{1/n_1}, \ldots, \alpha_r^{1/n_r})$。$\operatorname{Gal}(M/K)$ 是可解群（因为根式扩张的 Galois 群逐层都是循环或阿贝尔的）。$G = \operatorname{Gal}(L/K)$ 是 $\operatorname{Gal}(M/K)$ 的商群，故也是可解的。$\blacksquare$

</ProofToggle>

## Kummer 理论与 Abel 扩张 {#kummer-theory}

::: definition Abel 扩张 {#def-abelian-extension}
Galois 扩张 $L/K$ 称为 **Abel 扩张**，如果 $\operatorname{Gal}(L/K)$ 是阿贝尔群。
:::

::: theorem Kummer 扩张 {#thm-kummer}
设 $K$ 包含 $n$ 次本原单位根 $\zeta_n$（即 $x^n - 1$ 在 $K$ 中完全分裂），$\operatorname{char} K \nmid n$。则 $K$ 上的阶为 $n$ 的 Abel 扩张与 $K^\times / (K^\times)^n$ 的子群一一对应。

具体地：$L = K(\sqrt[n]{a})$（$a \in K^\times$）是阶至多 $n$ 的 Abel 扩张，$\operatorname{Gal}(L/K) \hookrightarrow \mathbb{Z}/n\mathbb{Z}$。
:::

<ProofToggle>

**证明.** 我们分两部分证明。

**第一部分：$K(\sqrt[n]{a})$ 是 Abel 扩张。**

设 $L = K(\alpha)$，$\alpha^n = a \in K^\times$，$[L:K] = d$（$d \mid n$）。$L$ 是 $x^n - a$ 在 $K$ 上的分裂域的一部分。$\alpha$ 的极小多项式是 $x^d - b$（$b = \operatorname{N}_{K(\alpha)/K}(\alpha)$ 的某个幂）。$\operatorname{Gal}(L/K)$ 中的每个 $\sigma$ 由 $\sigma(\alpha)$ 完全决定。因为 $\sigma(\alpha)^n = \sigma(a) = a$，故 $\sigma(\alpha) = \zeta_n^k \alpha$ 对某个 $k$。因为 $\sigma$ 是 $K$-自同构，$\zeta_n^k$ 必须是 $\zeta_d^j$（因为 $\sigma(\alpha)^d = \sigma(\alpha^d) = \alpha^d$），故 $\sigma \mapsto k \pmod{d}$ 给出群同态 $\operatorname{Gal}(L/K) \hookrightarrow \mathbb{Z}/d\mathbb{Z}$，是**循环群的嵌入**，故 $\operatorname{Gal}(L/K)$ 是阿贝尔的。

**第二部分：每个 Abel 扩张是 Kummer 扩张（逆向对应）。**

设 $L/K$ 是有限 Abel 扩张，$\operatorname{Gal}(L/K) = G \cong A$（阿贝尔群），$|G| = n$，$\zeta_n \in K$。**关键断言**：$L$ 可以写成 $K(\sqrt[n]{a_1}, \ldots, \sqrt[n]{a_r})$ 对某 $a_i \in K^\times$。

由有限 Abel 群的结构定理，$G \cong \mathbb{Z}/d_1 \times \cdots \times \mathbb{Z}/d_r$（$d_i \mid d_{i+1}$）。由 Galois 对应，存在中间域 $K \subsetneq L_1 \subsetneq \cdots$ 使得每个 $L_i/K$ 是循环扩张。

对每个循环子扩张 $L_i/K$（阶 $d_i$），设 $\sigma$ 生成 $\operatorname{Gal}(L_i/K)$。考虑 **Lagrange 预解式**：
$$\beta = \alpha + \zeta_{d_i}^{-1} \sigma(\alpha) + \zeta_{d_i}^{-2} \sigma^2(\alpha) + \cdots + \zeta_{d_i}^{-(d_i-1)} \sigma^{d_i-1}(\alpha)$$
其中 $\alpha \in L_i$ 待定。$\sigma(\beta) = \zeta_{d_i} \beta$，故 $\beta^{d_i}$ 被 $\sigma$ 固定，即 $\beta^{d_i} = a \in K$。若 $\beta \neq 0$，则 $L_i = K(\beta) = K(\sqrt[d_i]{a})$。

**$\beta \neq 0$ 的存在性**由 Hilbert 定理 90 保证：若 $\operatorname{Gal}(L_i/K) = \langle \sigma \rangle$ 是 $d_i$ 阶循环群，$\zeta_{d_i} \in K$，则映射 $\wp: L_i^\times \to L_i^\times$，$x \mapsto x/\sigma(x)$ 的像恰好是 $\ker(\operatorname{N}_{L_i/K})$ 的乘法群。由 $\operatorname{N}_{L_i/K}(\zeta_{d_i}) = \zeta_{d_i}^{d_i} = 1$，存在 $\beta \in L_i^\times$ 使得 $\sigma(\beta) = \zeta_{d_i} \beta$。$\blacksquare$

</ProofToggle>

::: remark Artin–Schreier 理论
在特征 $p > 0$ 时，Kummer 理论不适用（因为 $x^p - a = (x - a^{1/p})^p$）。取而代之的是 **Artin–Schreier 理论**：$K$ 上的阶 $p$ 的 Abel 扩张形如 $K(\alpha)$，其中 $\alpha^p - \alpha = a \in K$。Artin–Schreier 映射 $\wp: x \mapsto x^p - x$ 取代了 Kummer 中的 $x \mapsto x^n$。
:::
