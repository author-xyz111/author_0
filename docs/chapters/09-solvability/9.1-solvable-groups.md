5. 掌握 Kummer 理论的基本框架：含有 $n$ 次本原单位根的域上，Abel 扩张与 $K^\times/(K^\times)^n$ 的子群一一对应

## 动机：为什么研究可解群？ {#motivation}

Galois 理论的原初动机是理解多项式方程的**根式可解性**。在 Galois 之前，数学家已经知道：
- 二次方程有求根公式（Bhaskara，约1150年）
- 三次方程有求根公式（Cardano，1545年）
- 四次方程有求根公式（Ferrari，1540年代）

但五次方程呢？Ruffini (1799) 和 Abel (1824) 分别证明了**一般五次方程没有根式解**。然而，这并没有回答一个更精细的问题：**哪些**五次方程可以用根式求解？比如 $x^5 - 1 = 0$ 显然可以。

Galois 的天才洞察是：一个多项式方程可以用根式求解，当且仅当其 Galois 群是"**可解的**"——即可以通过一系列阿贝尔商来逐步简化。这个结论优美地统一了"方程的代数性质"和"群的结构"这两个看似无关的概念。

::: intuition 核心直觉
根式求解的过程本质上是"逐步降低复杂度"：先用四则运算和开方提取部分信息，再用更深层的根式提取更多信息……每一步都是在对一个"更简单"的群做运算。可解群恰好是那些可以通过这种"逐步简化"走到平凡群的群。
:::

## 可解群 {#solvable-groups}

::: definition 可解群 {#def-solvable-group}
群 $G$ 称为**可解的**（solvable），如果存在正规子群列：
$$
G = G_0 \rhd G_1 \rhd G_2 \rhd \cdots \rhd G_n = \{e\},
$$
使得每个商 $G_i / G_{i+1}$ 是**阿贝尔群**。

这样的正规子群列称为**可解列**（solvable series）。
:::

::: remark 可解群的多种等价刻画
可解群有三种常用定义，它们互相等价：

**(i) 正规列定义**（上面的定义）：存在正规列使得每个商因子是阿贝尔的。

**(ii) 导出列定义**：定义 $G^{(0)} = G$，$G^{(i+1)} = [G^{(i)}, G^{(i)}]$（$G^{(i)}$ 的换位子子群）。则 $G$ 可解 $\iff$ 存在 $n$ 使得 $G^{(n)} = \{e\}$。

**(iii) 合成因子定义**（有限群情形）：$G$ 可解 $\iff$ $G$ 的每个合成因子（Jordan–Hölder 意义下）都是素数阶循环群。

**为什么 (i) $\Leftrightarrow$ (ii)**：

$(i) \Rightarrow (ii)$：若 $G = G_0 \rhd G_1 \rhd \cdots \rhd G_n = \{e\}$ 是可解列，则 $G_i/G_{i+1}$ 阿贝尔意味着 $[G_i, G_i] \subseteq G_{i+1}$，即 $G^{(i+1)} \subseteq G_{i+1}$。因此导出列下降得比正规列更快（或同样快），必在有限步到达 $\{e\}$。

$(ii) \Rightarrow (i)$：导出列 $G = G^{(0)} \rhd G^{(1)} \rhd \cdots \rhd G^{(n)} = \{e\}$ 本身就是一个可解列，因为 $G^{(i)} / G^{(i+1)} = G^{(i)} / [G^{(i)}, G^{(i)}]$ 是 $G^{(i)}$ 的 Abel 化，自然是阿贝尔群。
:::

### 可解群的例子与非例子 {#solvable-examples}

::: example 常见可解群 {#ex-solvable-groups}
1. **所有阿贝尔群**都是可解的：取 $G_1 = \{e\}$，则 $G/\{e\} \cong G$ 是阿贝尔群。

2. **对称群 $S_3$**（阶6）：取 $G_0 = S_3$，$G_1 = A_3 = \{e, (123), (132)\}$，$G_2 = \{e\}$。
   - $S_3 / A_3 \cong \mathbb{Z}/2\mathbb{Z}$（阿贝尔）
   - $A_3 / \{e\} \cong \mathbb{Z}/3\mathbb{Z}$（阿贝尔）
   
   这对应三次方程的根式可解性：三次方程的 Galois 群是 $S_3$ 的子群，故都是可解的。

3. **对称群 $S_4$**（阶24）：取 $G_0 = S_4$，$G_1 = A_4$，$G_2 = V_4 = \{e, (12)(34), (13)(24), (14)(23)\}$（Klein四元群），$G_3 = \{e\}$。
   - $S_4 / A_4 \cong \mathbb{Z}/2\mathbb{Z}$
   - $A_4 / V_4 \cong \mathbb{Z}/3\mathbb{Z}$
   - $V_4 / \{e\} \cong (\mathbb{Z}/2\mathbb{Z})^2$

   $V_4$ 是 $A_4$ 中唯一的非平凡正规子群——这一点并不显然，因为 $A_4$ 中有4个3-循环，它们生成的子群不是正规的。$V_4$ 之所以特殊，是因为它是 $A_4$ 中唯一的 Sylow 2-子群（$|A_4| = 12 = 2^2 \cdot 3$，$A_4$ 恰有1个 Sylow 2-子群）。

4. **所有 $p$-群**都是可解的：对 $|G| = p^n$，$G$ 有非平凡中心 $Z(G)$。对 $|G|$ 作归纳：$G/Z(G)$ 是更小的 $p$-群（故可解），$Z(G)$ 是阿贝尔群，故 $G$ 可解。

5. **阶为 $p^a q^b$ 的有限群**是可解的：这是 **Burnside 定理** (1904)，证明使用了表示论（特征标理论）。
:::

::: example 非可解群：$A_5$ {#ex-nonsolvable}
$A_5$（阶60）是最小的非可解群。原因是：

1. $A_5$ 是**单群**（simple group）——没有非平凡正规子群。
2. $A_5$ **不是**阿贝尔群（例如 $(123)$ 和 $(345)$ 不交换）。

由 (1)，$A_5$ 唯一的正规子群列是 $A_5 \rhd \{e\}$，唯一的商因子是 $A_5$ 自身。由 (2)，这个商因子不是阿贝尔的。因此 $A_5$ 不可解。

**$A_5$ 的单性**证明思路如下：设 $N \trianglelefteq A_5$，$N \neq \{e\}$。取 $\sigma \in N$，$\sigma \neq e$。

- 若 $\sigma$ 是3-循环，比如 $\sigma = (123)$。则对任意 $\tau \in A_5$，共轭 $\tau \sigma \tau^{-1} = (\tau(1)\tau(2)\tau(3))$ 也是3-循环。通过选择合适的 $\tau$，可以得到所有3-循环。因此所有3-循环 $\in N$。$A_5$ 有 $20$ 个3-循环，而 $|A_5| = 60$，故 $N$ 至少有 $21$ 个元素。由 Lagrange 定理，$|N|$ 整除 $60$，$|N| \geq 21$ 迫使 $|N| = 60$（因为 $60$ 的真因子只有 $1,2,3,4,5,6,10,12,15,20,30$），从而 $N = A_5$。

- 若 $\sigma$ 是5-循环，类似论证得到 $N$ 包含所有5-循环，故 $N = A_5$。

- 若 $\sigma$ 是两个不相交对换的乘积，如 $\sigma = (12)(34)$，共轭可得所有形如 $(ab)(cd)$ 的元素都在 $N$ 中。共有 $15$ 个这样的元素，$|N| \geq 16$，迫使 $|N| = 60$，$N = A_5$。

因此 $A_5$ 没有非平凡正规子群，即它是单群。$\blacksquare$

::: tip 更一般的事实
对 $n \geq 5$，$A_n$ 都是单群。证明的核心是：$n \geq 5$ 时有足够的"活动空间"——任意两个3-循环可以通过 $A_n$ 中的共轭互相转化，因为 $n \geq 5$ 时总能找到一个偶置换将一个3-循环的支撑集映射到另一个的支撑集。
:::
:::

::: warning 为什么 $n = 5$ 是分界线？
**$S_4$ 可解但 $S_5$ 不可解**。直觉上：
- $S_4$ 的商 $A_4$ 有 Klein 四元群 $V_4$ 作为正规子群，这提供了一个"缓冲层"。
- $A_5$ 是单群——没有这样的缓冲层，它是一个不可分割的"原子"。

更深入地，$n \leq 4$ 时 $A_n$ 不是单群（$A_3 \cong \mathbb{Z}/3\mathbb{Z}$ 是阿贝尔单群，$A_4$ 有 $V_4$ 作为正规子群），而 $n \geq 5$ 时 $A_n$ 恰好是"足够复杂"成为非阿贝尔单群。这正是为什么代数方程的根式可解性在四次和五次之间发生质变。
:::

### 可解群的基本性质 {#solvable-properties}

::: proposition 可解群对子群和商群封闭 {#prop-solvable-closed}
设 $G$ 是可解群。则：
1. $G$ 的任意子群 $H$ 是可解的。
2. $G$ 的任意商群 $G/N$（$N \trianglelefteq G$）是可解的。
3. 若 $N \trianglelefteq G$ 且 $N$、$G/N$ 都可解，则 $G$ 可解。
:::

<ProofToggle>

**证明.** 使用导出列刻画：$G$ 可解 $\iff G^{(n)} = \{e\}$ 对某个 $n$。

**(1)** 设 $H \leq G$。则 $H^{(i)} \leq G^{(i)}$（子群的换位子子群包含在大群的换位子子群中）。因此 $G^{(n)} = \{e\}$ 推出 $H^{(n)} = \{e\}$。

**(2)** $G$ 的 Abel 化 $G/[G,G]$ 映满 $(G/N)/[G/N, G/N]$。因此若 $G^{(n)} = \{e\}$，则 $(G/N)^{(n)} = \{e\}$。

**(3)** 这是三条中唯一非平凡的。设 $N^{(m)} = \{e\}$，$(G/N)^{(k)} = \{e\}$。考虑 $G$ 的导出列：$(G/N)^{(k)} = G^{(k)} N / N$（这是一个标准的群论等式）。$(G/N)^{(k)} = \{e\}$ 意味着 $G^{(k)} \subseteq N$。然后 $G^{(k+m)} = (G^{(k)})^{(m)} \subseteq N^{(m)} = \{e\}$。$\\blacksquare$

</ProofToggle>

::: warning 常见误区
可解群的**直积**也是可解的（因为 $(G \times H)^{(n)} = G^{(n)} \times H^{(n)}$）。但可解群的**扩张**不自动可解——条件 (3) 说的恰好是：若正规子群和商群都可解，则扩张可解。
:::

## Abel–Ruffini 定理 {#abel-ruffini}

::: theorem Abel–Ruffini {#thm-abel-ruffini}
对 $n \geq 5$，一般 $n$ 次方程不是根式可解的。

更精确地：设 $a_1, \ldots, a_n$ 是独立的未定元，$K = \mathbb{Q}(a_1, \ldots, a_n)$，$f(x) = x^n + a_1 x^{n-1} + \cdots + a_n \in K[x]$。则 $f$ 的根不能用 $a_1, \ldots, a_n$ 的有理函数通过有限次四则运算和开方来表示。
:::

<ProofToggle>

**证明.** 分三步完成。

**步骤1：$f$ 的 Galois 群是 $S_n$.**

$f$ 的分裂域 $L$ 是 $K(\alpha_1, \ldots, \alpha_n)$，其中 $\alpha_1, \ldots, \alpha_n$ 是 $f$ 的 $n$ 个根。$f$ 在 $K$ 上不可约（这是一个经典结果，利用 $a_i$ 的独立性可以证明）。因此 $\operatorname{Gal}(L/K)$ 是 $S_n$ 的一个**传递**子群（传递是因为 $f$ 不可约）。

进一步，通过"特殊化"论证：对于 $a_i$ 的几乎所有特殊化值（如整数值），$\operatorname{Gal}$ 只能**缩小**（特殊化不增加 Galois 群）。选择合适的特殊化使得得到的多项式有 Galois 群 $S_n$（这可以通过判别式不是完全平方、与辅助多项式的结式不等于零等条件保证）。因此原始 $f$ 的 Galois 群至少是 $S_n$。又因为 $\operatorname{Gal}(L/K) \leq S_n$，故 $\operatorname{Gal}(L/K) = S_n$。

**步骤2：根式可解 $\Rightarrow$ Galois 群可解.**

若 $f$ 的根可以用根式表示，则存在根式扩张 $K = K_0 \subseteq K_1 \subseteq \cdots \subseteq K_r$ 使得 $L \subseteq K_r$，其中 $K_{i+1} = K_i(\alpha_i)$，$\alpha_i^{n_i} \in K_i$。

对每个 $i$，考虑 $K_{i+1}/K_i$ 的正规闭包 $\tilde{K}_{i+1}$。则 $\operatorname{Gal}(\tilde{K}_{i+1}/K_i)$ 是循环群（因为 $\alpha_i$ 满足 $x^{n_i} - a = 0$）或循环群的扩张。根式扩张链给出 $\operatorname{Gal}(K_r/K)$ 的正规列，其商因子都是循环群。因此 $\operatorname{Gal}(K_r/K)$ 是可解群。

$G = \operatorname{Gal}(L/K)$ 是 $\operatorname{Gal}(K_r/K)$ 的商群（通过限制映射），可解群的商群可解，故 $G$ 可解。

**步骤3：$S_n$（$n \geq 5$）不可解.**

$S_n \rhd A_n$，$S_n/A_n \cong \mathbb{Z}/2\mathbb{Z}$。对 $n \geq 5$，$A_n$ 是非阿贝尔单群（见上文 $A_5$ 的证明及推广）。因此 $A_n$ 不能进一步分解，$S_n$ 不可解。

综合三个步骤：$f$ 的 Galois 群是 $S_n$（$n \geq 5$），不可解。若 $f$ 根式可解，则 Galois 群必可解。矛盾。$\\blacksquare$

</ProofToggle>

::: intuition Abel–Ruffini 的深层含义
这个定理不是说"五次方程没有公式"，而是说**不存在一个通用的、对所有五次方程都适用的根式公式**。某些特殊的五次方程（如 $x^5 - 1 = 0$，其 Galois 群是 $\mathbb{Z}/4\mathbb{Z}$）仍然可以用根式求解。
:::

::: remark Galois 群为 $S_5$ 的具体多项式
不仅一般五次方程不可根式求解，**具体**多项式也可以不是。例如：
$$f(x) = x^5 - 4x + 2 \in \mathbb{Q}[x].$$
- **不可约**：Eisenstein 判据（$p = 2$）。
- **恰好3个实根**：$f(-2) = -22 < 0$，$f(0) = 2 > 0$，$f(1) = -1 < 0$，$f(2) = 26 > 0$。由介值定理，$f$ 在 $(-2,0)$、$(0,1)$、$(1,2)$ 各有一个实根。另外 $f'(x) = 5x^4 - 4$ 只有两个实零点 $\pm (4/5)^{1/4}$，故 $f$ 至多有3个实根。因此恰有3个实根和2个共轭复根。
- **Galois 群 $\cong S_5$**：不可约 + 恰好3个实根 $\Rightarrow$ Galois 群含有一个2-循环（复共轭在两个复根上的作用）。不可约保证群是传递的。传递 + 含有2-循环 $\Rightarrow$ Galois 群 $\cong S_5$（这是一个群论引理：$S_n$ 的传递子群若含有一个2-循环则等于 $S_n$）。
:::

## 根式扩张 {#radical-extensions}

::: definition 根式扩张 {#def-radical-extension}
域扩张 $L/K$ 称为**根式扩张**（radical extension），如果存在中间域链：
$$
K = K_0 \subseteq K_1 \subseteq \cdots \subseteq K_r = L,
$$
使得对每个 $i$，$K_{i+1} = K_i(\alpha_i)$，其中 $\alpha_i^{n_i} \in K_i$ 对某个正整数 $n_i$。

等价地说，$L$ 是通过逐次添加**根**（$n_i$ 次根）得到的。
:::

::: example 具体的根式扩张
$\mathbb{Q}(\sqrt{2}, \sqrt[3]{2})$ 是 $\mathbb{Q}$ 上的根式扩张：
- $K_0 = \mathbb{Q}$
- $K_1 = \mathbb{Q}(\sqrt{2})$，$\sqrt{2}^2 = 2 \in K_0$
- $K_2 = K_1(\sqrt[3]{2}) = \mathbb{Q}(\sqrt{2}, \sqrt[3]{2})$，$\sqrt[3]{2}^3 = 2 \in K_1$

注意 $[K_1 : K_0] = 2$，$[K_2 : K_1] = 3$（因为 $x^3 - 2$ 在 $K_1$ 上仍然不可约——$\sqrt{2}$ 不帮助分解 $x^3 - 2$），故 $[K_2 : K_0] = 6$。
:::

## Galois 的根式可解判据 {#galois-criterion}

::: theorem Galois 的根式可解判据 {#thm-galois-solvability-criterion}
设 $f \in K[x]$ 是可分多项式（$\operatorname{char} K = 0$），$L$ 是 $f$ 在 $K$ 上的分裂域。则：

$$f = 0 \text{ 根式可解} \iff \operatorname{Gal}(L/K) \text{ 是可解群。}$$
:::

<ProofToggle>

**证明.** 设 $G = \operatorname{Gal}(L/K)$。

**($\Leftarrow$)** 方向——可解群 $\Rightarrow$ 根式可解：

设 $G$ 可解，有可解列 $G = G_0 \rhd G_1 \rhd \cdots \rhd G_n = \{e\}$，$G_i/G_{i+1}$ 循环。由 Galois 对应，这给出中间域链：
$$
K = L^{G_0} \subseteq L^{G_1} \subseteq \cdots \subseteq L^{G_n} = L
$$
其中 $L^{G_{i+1}} / L^{G_i}$ 是 Galois 扩张，$\operatorname{Gal}(L^{G_{i+1}}/L^{G_i}) \cong G_i/G_{i+1}$ 是**循环群**。

**关键断言**：若 $E/F$ 是素数阶 $p$ 的循环 Galois 扩张，且 $F$ 包含 $p$ 次本原单位根 $\zeta_p$，则 $E = F(\sqrt[p]{a})$ 对某个 $a \in F^\times$——即 $E/F$ 是根式扩张。

*证明*：设 $\sigma$ 生成 $\operatorname{Gal}(E/F)$。考虑 Lagrange 预解式 $\beta = \sum_{j=0}^{p-1} \zeta_p^{-j} \sigma^j(\alpha)$（其中 $\alpha \in E$ 待定）。则 $\sigma(\beta) = \zeta_p \beta$，故 $\beta^p$ 被 $\sigma$ 固定，$\beta^p \in F$。由 Hilbert 定理 90，可以选择 $\alpha$ 使得 $\beta \neq 0$，因此 $E = F(\beta) = F(\sqrt[p]{a})$。

若 $K$ 本身不包含所需的单位根，先将所有需要的单位根加入 $K$（这给出一个根式扩张 $K' = K(\zeta_{n!})/K$，其中 $n = |G|$）。在 $K'$ 上，上述断言对每个循环子扩张都成立，故 $L \subseteq$ 某个根式扩张 $M/K'$。$K'/K$ 本身也是根式扩张，故 $M/K$ 是根式扩张。

**($\Rightarrow$)** 方向——根式可解 $\Rightarrow$ 可解群：

设 $f$ 的根可以用根式表示。则存在根式扩张 $M \supseteq L$，$M = K(\alpha_1, \ldots, \alpha_r)$，$\alpha_i^{n_i} \in K(\alpha_1, \ldots, \alpha_{i-1})$。

设 $N = n_1 n_2 \cdots n_r$。考虑 $\tilde{K} = K(\zeta_N)$（添加所有需要的单位根）。在 $\tilde{K}$ 上，每个 $\alpha_i$ 满足 $x^{n_i} - a_i = 0$（$a_i \in \tilde{K}(\alpha_1, \ldots, \alpha_{i-1})$）。因此每个 $\tilde{K}(\alpha_1, \ldots, \alpha_i)/\tilde{K}(\alpha_1, \ldots, \alpha_{i-1})$ 的正规闭包的 Galois 群嵌入 $\mathbb{Z}/n_i\mathbb{Z} \rtimes (\mathbb{Z}/n_i\mathbb{Z})^\times$。特别地，$\operatorname{Gal}(\tilde{M}/\tilde{K})$ 有正规列，其商因子都是阿贝尔的，故可解。

$\operatorname{Gal}(L \tilde{K}/K)$ 是 $\operatorname{Gal}(\tilde{M}/\tilde{K})$ 的商群（通过限制），故可解。$G = \operatorname{Gal}(L/K)$ 又是 $\operatorname{Gal}(L\tilde{K}/K)$ 的商群，故也可解。$\\blacksquare$

</ProofToggle>

::: intuition 证明中每一步在做什么
- **($\Leftarrow$)** 方向的策略是：把可解群的正规列通过 Galois 对应翻译为域塔，再利用"循环扩张 = 根式扩张"来逐层用根号求解。单位根的添加是技术性步骤，但不改变可解性。
- **($\Rightarrow$)** 方向的策略是：根式扩张的 Galois 群结构受制于 $x^n - a$ 的 Galois 群结构——这些群都是可解的（半直积 $\mathbb{Z}/n\mathbb{Z} \rtimes (\mathbb{Z}/n\mathbb{Z})^\times$ 的正规列使商因子为循环群）。$G$ 作为商群也是可解的。
:::

::: warning 判据的条件不能去掉
Galois 判据要求 $\operatorname{char} K = 0$（或至少 $K$ 可分闭包存在）和 $f$ 可分。在正特征下，需要 Artin–Schreier 理论（见下文）来补充。
:::

## Kummer 理论与 Abel 扩张 {#kummer-theory}

::: definition Abel 扩张 {#def-abelian-extension}
Galois 扩张 $L/K$ 称为 **Abel 扩张**，如果 $\operatorname{Gal}(L/K)$ 是阿贝尔群。
:::

Abel 扩张是可解群理论的"最简单非平凡情况"——可解列只有一步，商因子本身是阿贝尔群。Kummer 理论给出了含有本原单位根的域上 Abel 扩张的**完整分类**。

::: theorem Kummer 扩张定理 {#thm-kummer}
设 $K$ 包含 $n$ 次本原单位根 $\zeta_n$（即 $x^n - 1$ 在 $K$ 中完全分裂），$\operatorname{char} K \nmid n$。则 $K$ 上的指数（exponent）整除 $n$ 的有限 Abel 扩张与 $K^\times / (K^\times)^n$ 的有限子群之间存在**包含反转的一一对应**：

$$\left\{\begin{array}{c} K \text{ 上指数整除 } n \text{ 的} \\ \text{有限 Abel 扩张 } L/K \end{array}\right\} \longleftrightarrow \left\{\begin{array}{c} K^\times/(K^\times)^n \text{ 的} \\ \text{有限子群 } \Delta \end{array}\right\}$$

具体对应：$\Delta \mapsto K(\sqrt[n]{\Delta})$（添加 $\Delta$ 中所有元素的 $n$ 次根）；$L \mapsto (L^{\times n} \cap K^\times) / (K^\times)^n$。子群 $\Delta_1 \subseteq \Delta_2$ 对应扩张 $L_2 \subseteq L_1$（包含反转）。
:::

<ProofToggle>

**证明.** 我们分两部分证明。

**第一部分：$K(\sqrt[n]{a})$ 是 Abel 扩张。**

设 $L = K(\alpha)$，$\alpha^n = a \in K^\times$，$[L:K] = d$（$d \mid n$）。$\operatorname{Gal}(L/K)$ 中的每个 $\sigma$ 由 $\sigma(\alpha)$ 完全决定。因为 $\sigma(\alpha)^n = \sigma(a) = a$，故 $\sigma(\alpha) = \zeta_n^k \alpha$ 对某个 $k$。因为 $\sigma$ 是 $K$-自同构，$\zeta_n^k$ 必须是 $\zeta_d^j$（因为 $\sigma(\alpha)^d = \sigma(\alpha^d) = \alpha^d$），故 $\sigma \mapsto k \pmod{d}$ 给出群同态 $\operatorname{Gal}(L/K) \hookrightarrow \mathbb{Z}/d\mathbb{Z}$，是**循环群的嵌入**，故 $\operatorname{Gal}(L/K)$ 是阿贝尔的。

多个元素的 $n$ 次根的复合：$K(\sqrt[n]{a_1}, \ldots, \sqrt[n]{a_r})$ 的 Galois 群嵌入 $(\mathbb{Z}/n\mathbb{Z})^r$，故是阿贝尔的。

**第二部分：每个指数整除 $n$ 的 Abel 扩张是 Kummer 扩张（逆向对应）。**

设 $L/K$ 是有限 Abel 扩张，$G = \operatorname{Gal}(L/K)$ 指数整除 $n$（即 $g^n = e$ 对所有 $g \in G$），$\zeta_n \in K$。

由有限 Abel 群的结构定理，$G \cong \mathbb{Z}/d_1 \times \cdots \times \mathbb{Z}/d_r$（$d_i \mid d_{i+1}$，所有 $d_i \mid n$）。对每个循环因子 $L_i/K$（阶 $d_i$），设 $\sigma$ 生成 $\operatorname{Gal}(L_i/K)$。

考虑 **Lagrange 预解式**：
$$\beta = \alpha + \zeta_{d_i}^{-1} \sigma(\alpha) + \zeta_{d_i}^{-2} \sigma^2(\alpha) + \cdots + \zeta_{d_i}^{-(d_i-1)} \sigma^{d_i-1}(\alpha)$$
其中 $\alpha \in L_i$ 待定。直接计算 $\sigma(\beta) = \zeta_{d_i} \beta$，故 $\beta^{d_i}$ 被 $\sigma$ 固定，即 $\beta^{d_i} = a \in K$。

**$\beta \neq 0$ 的存在性**由 Hilbert 定理 90 保证：

> **Hilbert 定理 90（乘法形式）**：设 $E/F$ 是 $d$ 阶循环 Galois 扩张，$\sigma$ 生成 $\operatorname{Gal}(E/F)$。则 $\{x \in E^\times \mid \operatorname{N}_{E/F}(x) = 1\} = \{y/\sigma(y) \mid y \in E^\times\}$。等价地，映射 $\wp: E^\times \to E^\times$，$y \mapsto y/\sigma(y)$ 的像恰好是范数为 1 的元素。

取 $y$ 使得 $\beta = y/\sigma^{-1}(y)$，则 $\sigma(\beta) = \sigma(y)/y = \beta^{-1} \cdot \beta \sigma(\beta)$……更直接地，因为 $\operatorname{N}_{L_i/K}(\zeta_{d_i}) = \zeta_{d_i}^{d_i} = 1$，Hilbert 90 给出 $\beta \in L_i^\times$ 使得 $\sigma(\beta) = \zeta_{d_i} \beta$。若 $\beta \neq 0$（确实如此），则 $L_i = K(\beta) = K(\sqrt[d_i]{a})$。$\\blacksquare$

</ProofToggle>

::: example Kummer 扩张的具体计算
设 $K = \mathbb{Q}(\zeta_3)$（$\zeta_3 = e^{2\pi i/3}$），$n = 3$。$K^\times / (K^\times)^3$ 的子群一一对应于 $K$ 上的指数整除 3 的 Abel 扩张。

取 $\Delta = \{1, 2, 4\} \cdot (K^\times)^3 / (K^\times)^3 = \langle 2 \rangle \subseteq K^\times/(K^\times)^3$。则对应的扩张是 $L = K(\sqrt[3]{2}) = \mathbb{Q}(\zeta_3, \sqrt[3]{2})$。

$\operatorname{Gal}(L/K) \cong \mathbb{Z}/3\mathbb{Z}$：每个 $\sigma$ 由 $\sigma(\sqrt[3]{2}) = \zeta_3^k \sqrt[3]{2}$ 决定。

注意 $L = \mathbb{Q}(\zeta_3, \sqrt[3]{2})$ 实际上也是 $x^3 - 2$ 在 $\mathbb{Q}$ 上的分裂域。$\operatorname{Gal}(L/\mathbb{Q}) \cong S_3$（不是阿贝尔的），但 $\operatorname{Gal}(L/\mathbb{Q}(\zeta_3)) \cong \mathbb{Z}/3\mathbb{Z}$（阿贝尔的）。这体现了 Kummer 理论的前提：只在**含有足够单位根**的基域上，Abel 扩张才有这种简洁的 $n$ 次根表示。
:::

## Artin–Schreier 理论 {#artin-schreier}

::: remark 正特征下的替代理论
在特征 $p > 0$ 时，Kummer 理论不适用（因为 $x^p - a = (x - a^{1/p})^p$——没有真正的 $p$ 次根）。取而代之的是 **Artin–Schreier 理论**。

$K$ 上的阶 $p$ 的循环扩张形如 $K(\alpha)$，其中 $\alpha^p - \alpha = a \in K$（**Artin–Schreier 方程**）。Artin–Schreier 映射 $\wp: x \mapsto x^p - x$ 取代了 Kummer 中的 $x \mapsto x^n$。

$K$ 上指数整除 $p$ 的 Abel 扩张与 $K / \wp(K)$ 的有限子群一一对应（类似 Kummer 对应，用加法群替代乘法群）。

**为什么 $x^p - a$ 不行？** 在特征 $p$ 下，$x^p - a$ 要么不可约（如 $x^p - t$ 在 $\mathbb{F}_p(t)$ 上），要么完全分裂（当 $a = b^p$ 时）。但即使不可约，它的分裂域也**不是** Galois 的（因为 $x^p - a = (x - \alpha)^p$ 只有一个根 $\alpha$，重数为 $p$）——换句话说，$x^p - a$ 不可分，不满足 Galois 理论的基本要求。
:::

| 概念 | 核心内容 |
|:---|:---|
| 可解群 | 正规列的商因子都是阿贝尔群；等价于导出列终止于 $\{e\}$ |

| Artin–Schreier | 正特征 $p$ 下的 Kummer 理论替代品：$\wp(x) = x^p - x$ |
