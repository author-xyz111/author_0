# §8.1 基本 Galois 对应 {#sec-fundamental-galois-correspondence}

::: tip 📖 学习目标
完成本节后，你应该能够：
1. 陈述基本 Galois 对应定理的四个部分，并解释"反序双射"的含义
2. 给出 $\operatorname{Gal}(L/K)$ 与中间域格之间的完整对应表（至少对 $V_4$ 和 $S_3$ 的情形）
3. 解释正规子群对应正规扩张的直觉，并给出反例
4. 理解 Artin 引理在证明中的核心角色
5. 将 Galois 对应应用于具体多项式的根式求解
:::

::: intuition 核心思想
Galois 理论最深刻的洞察是：**域扩张的内部结构（中间域）与群的外部结构（子群）之间存在完美的反序一一对应**。这是"对偶性"的一个范例——两个看似不同的数学对象之间的结构完全镜像彼此。

这个对应之所以强大，是因为：
- **群论比域论好算**：子群的分类是纯群论问题，可以用 Lagrange 定理、Sylow 定理等工具。
- **域论问题可以通过群论解决**：例如"多项式是否根式可解"可以转化为"Galois 群是否可解"。
- **结构完全镜像**：正规子群 ↔ 正规扩张，商群 ↔ 限制 Galois 群，指数 ↔ 扩张次数。
:::

---

## 中间域 {#intermediate-fields}

::: definition 中间域 {#def-intermediate-field}
设 $L/K$ 为域扩张。一个**中间域**（intermediate field）是满足 $K \subseteq M \subseteq L$ 的域 $M$。
:::

::: warning 中间域可能很复杂
即使 $L/K$ 是"简单的"（如 $L = \mathbb{Q}(\sqrt[4]{2}, i)$），中间域的数量和结构也可能出人意料地丰富。$[L:\mathbb{Q}] = 8$ 的扩张可能有 6 个真中间域。Galois 对应的威力就在于将中间域的分类完全转化为子群的分类。
:::

::: example 具体的中间域 {#ex-intermediate}
考虑 $L = \mathbb{Q}(\sqrt[4]{2}, i)$，$K = \mathbb{Q}$，$[L:\mathbb{Q}] = 8$。中间域包括：
- $\mathbb{Q}(\sqrt{2})$（二次扩张）
- $\mathbb{Q}(i)$（二次扩张）
- $\mathbb{Q}(\sqrt[4]{2})$（四次扩张）
- $\mathbb{Q}(\sqrt{2}, i)$（四次扩张）
- $\mathbb{Q}(i\sqrt{2})$（二次扩张）

共 6 个真中间域，对应 $\operatorname{Gal}(L/\mathbb{Q}) \cong D_4$ 的 6 个非平凡子群。
:::

## 正规子群与正规扩张 {#normal-subgroups-extensions}

::: definition 正规扩张 {#def-normal-extension}
域扩张 $L/K$ 称为**正规扩张**（normal extension），如果 $L$ 是 $K$ 上某个多项式族的分裂域。等价地（有限情形下）：$L/K$ 是正规的当且仅当每个 $K$-不可约多项式 $p \in K[x]$，若在 $L$ 中有一个根，则在 $L$ 中完全分裂。
:::

::: theorem 正规扩张的 Galois 群刻画 {#thm-normal-characterization}
设 $L/K$ 是有限 Galois 扩张，$M$ 是中间域（$K \subseteq M \subseteq L$）。则：

$M/K$ 是正规扩张 $\iff$ $\operatorname{Gal}(L/M)$ 是 $\operatorname{Gal}(L/K)$ 的**正规子群**。
:::

<ProofToggle>

**证明.**

**($\Rightarrow$)** 设 $M/K$ 是正规扩张。设 $\sigma \in \operatorname{Gal}(L/K)$，$\tau \in \operatorname{Gal}(L/M)$。对 $m \in M$，需证 $\sigma\tau\sigma^{-1}(m) = m$。

因 $\sigma^{-1}(m) \in M$（因为 $M/K$ 正规：$\sigma^{-1}$ 固定 $K$，$\sigma^{-1}(m)$ 与 $m$ 有相同的 $K$-极小多项式，而 $M$ 包含该多项式的全部根），且 $\tau$ 固定 $M$，故 $\tau(\sigma^{-1}(m)) = \sigma^{-1}(m)$。故 $\sigma\tau\sigma^{-1}(m) = \sigma(\sigma^{-1}(m)) = m$。$\sigma\tau\sigma^{-1} \in \operatorname{Gal}(L/M)$。

**($\Leftarrow$)** 设 $H = \operatorname{Gal}(L/M) \trianglelefteq G = \operatorname{Gal}(L/K)$。设 $m \in M$，$\sigma \in G$。需证 $\sigma(m) \in M$，即 $\sigma(m)$ 被 $H$ 中所有元素固定。

对 $\tau \in H$：$\tau(\sigma(m)) = (\tau\sigma)(m) = (\sigma\sigma^{-1}\tau\sigma)(m)$。因 $H \trianglelefteq G$，$\sigma^{-1}\tau\sigma \in H$，故 $\sigma^{-1}\tau\sigma$ 固定 $m$，于是 $\tau\sigma(m) = \sigma(m)$。故 $\sigma(m) \in M$。$\blacksquare$

</ProofToggle>

::: warning 非正规中间域的例子
考虑 $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$（$x^3 - 2$ 的分裂域），$K = \mathbb{Q}$。中间域 $M = \mathbb{Q}(\sqrt[3]{2})$ 满足 $[M:\mathbb{Q}] = 3$，但 $M/\mathbb{Q}$ **不是**正规扩张：$x^3 - 2$ 在 $\mathbb{Q}$ 上不可约且有根 $\sqrt[3]{2} \in M$，但 $x^3 - 2$ 的另外两个根 $\omega\sqrt[3]{2}$ 和 $\omega^2\sqrt[3]{2}$ 不在 $M$ 中（它们是复数，$M \subset \mathbb{R}$）。

在 Galois 对应中，这意味着 $\operatorname{Gal}(L/M)$ 是 $\operatorname{Gal}(L/\mathbb{Q}) \cong S_3$ 的子群但**不是**正规子群——它是 $S_3$ 的某个 2 阶子群。
:::

## 基本 Galois 对应定理 {#fundamental-theorem}

::: definition 不动域（固定域） {#def-fixed-field}
设 $L$ 为域，$H \leq \operatorname{Aut}(L)$ 为 $L$ 的自同构群的子群。集合
$$
L^H = \{a \in L \mid \sigma(a) = a \text{ 对所有 } \sigma \in H\}
$$
是 $L$ 的子域，称为 $H$ 的**不动域**（fixed field）。
:::

::: definition Galois 对应 {#def-galois-correspondence}
设 $L/K$ 是有限 Galois 扩张，$G = \operatorname{Gal}(L/K)$。映射
$$
M \mapsto \operatorname{Gal}(L/M), \quad H \mapsto L^H
$$
建立了中间域与子群之间的反序双射，称为 **Galois 对应**（Galois correspondence）。详见 {thm-galois-correspondence}。
:::

::: theorem Galois 对应 {#thm-galois-correspondence}
设 $L/K$ 是有限 Galois 扩张，$G = \operatorname{Gal}(L/K)$。定义两个映射：

$$
\Phi: \{\text{中间域 } K \subseteq M \subseteq L\} \to \{\text{子群 } H \leq G\}, \quad M \mapsto \operatorname{Gal}(L/M),
$$

$$
\Psi: \{\text{子群 } H \leq G\} \to \{\text{中间域 } K \subseteq M \subseteq L\}, \quad H \mapsto L^H.
$$

则：

**(i)** $\Phi$ 和 $\Psi$ 是**互逆的反序双射**（Galois 连接）：$\Psi \circ \Phi = \operatorname{id}$，$\Phi \circ \Psi = \operatorname{id}$。

**(ii)** **指数等于扩张次数：** $[M : K] = [G : H]$，$[L : M] = |H|$，其中 $H = \operatorname{Gal}(L/M)$。

**(iii)** **正规子群对应正规扩张：** $\operatorname{Gal}(L/M) \trianglelefteq G$ $\iff$ $M/K$ 是正规扩张。

**(iv)** **商群对应限制 Galois 群：** 若 $M/K$ 正规，则 $\operatorname{Gal}(M/K) \cong G/\operatorname{Gal}(L/M)$。
:::

::: intuition 定理四部分的层次
- **(i)** 是对应的存在性：映射确实建立了双射。
- **(ii)** 是量的匹配：子群的指数恰好等于域扩张的次数。
- **(iii)** 是结构的匹配：群的正规性对应域的正规性。
- **(iv)** 是约化：商群给出了"底层"Galois 群，可以从更大的 Galois 群中"除掉"已知部分得到。

(i) 和 (ii) 是基本工具；(iii) 和 (iv) 是结构定理，直接用于分类和计算。
:::

<ProofToggle>

**证明.** 证明分为几个关键步骤。

**步骤 1：$\Psi \circ \Phi = \operatorname{id}$。**

设 $M$ 为中间域，$H = \operatorname{Gal}(L/M)$。需证 $L^H = M$。

$M \subseteq L^H$ 是显然的（$H$ 中的元素固定 $M$）。

反过来，设 $\alpha \in L \setminus M$。$\alpha$ 在 $M$ 上的极小多项式 $m_\alpha^M(x)$ 的次数 $\geq 2$。由 {lem-embedding-extension}（应用于 $L/M$ 上的嵌入），存在 $\sigma \in \operatorname{Gal}(L/M)$ 使得 $\sigma(\alpha) \neq \alpha$（因为 $m_\alpha^M$ 在 $L$ 中有多个根，而 $L/M$ 是 Galois 的，故 $M$-自同构可将 $\alpha$ 映到 $m_\alpha^M$ 的任何根）。故 $\alpha \notin L^H$。故 $L^H = M$。

::: remark 步骤 1 的关键洞察
步骤 1 的核心论据是：如果 $\alpha \notin M$，则 $\alpha$ 在 $M$ 上的极小多项式有多个不同的根（因为 $L/M$ 是可分的），而 Galois 群可以把 $\alpha$ 移到其他根上。这说明 Galois 群**足以区分**$M$ 和 $L \setminus M$ 中的元素。
:::

**步骤 2：$\Phi \circ \Psi = \operatorname{id}$。**

设 $H \leq G$，$M = L^H$。需证 $\operatorname{Gal}(L/M) = H$。

$H \subseteq \operatorname{Gal}(L/M)$ 由定义显然。

反包含由 **Artin 引理**（{thm-artin}）完成：对有限群 $H \leq \operatorname{Aut}(L)$，$[L : L^H] = |H|$。

应用于 $H \leq \operatorname{Gal}(L/M) = \operatorname{Aut}(L/M)$：$[L : M] = [L : L^H] = |H|$。同时 $[L : M] = |\operatorname{Gal}(L/M)|$（因为 $L/M$ 是 Galois 的）。故 $|H| = |\operatorname{Gal}(L/M)|$。因 $H \subseteq \operatorname{Gal}(L/M)$，得 $H = \operatorname{Gal}(L/M)$。

**Artin 引理的证明：**

对有限群 $H \leq \operatorname{Aut}(L)$，证明 $[L : L^H] = |H|$。

**（$[L:L^H] \leq |H|$）：** 设 $H = \{\sigma_1, \ldots, \sigma_n\}$（$\sigma_1 = \operatorname{id}$），$n = |H|$。设 $[L:L^H] > n$，取 $L^H$-线性无关的 $\alpha_1, \ldots, \alpha_{n+1} \in L$。考虑方程组 $\sum_{j=1}^{n+1} \sigma_i(\alpha_j) x_j = 0$（$i = 1, \ldots, n$）。这是 $n$ 个方程 $n+1$ 个未知数的齐次线性方程组，有非零解 $(c_1, \ldots, c_{n+1}) \in L^{n+1}$。取满足条件的解使得非零分量个数最少，经置换后可设 $c_1, \ldots, c_{n+1}$ 中前 $r$ 个非零（$r \geq 1$）。

对任意 $\tau \in H$，将方程用 $\tau$ 作用得 $\sum_j \tau\sigma_i(\alpha_j) \tau(c_j) = \sum_j \sigma_k(\alpha_j) \tau(c_j) = 0$（重排指标），故 $(\tau(c_1), \ldots, \tau(c_{n+1}))$ 也是解。从而 $(c_1 - \tau(c_1), \ldots, c_{n+1} - \tau(c_{n+1}))$ 也是解。但 $c_1 \in L^H$（因为 $c_1 \neq 0$ 且可以归一化使 $c_1 = 1 \in L^H$），故 $c_1 - \tau(c_1) = 0$，新解的非零分量个数 $< r$，与 $r$ 的最小性矛盾。

**（$[L:L^H] \geq |H|$）：** 由定义 $L^H \subseteq L^{\operatorname{Gal}(L/L^H)}$，故 $\operatorname{Gal}(L/L^H) \supseteq H$。由上面的不等式，$|\operatorname{Gal}(L/L^H)| \leq [L : L^{\operatorname{Gal}(L/L^H)}] \leq [L : L^H]$。故 $|H| \leq |\operatorname{Gal}(L/L^H)| \leq [L : L^H]$。$\blacksquare$

::: remark Artin 引理的地位
Artin 引理是整个 Galois 理论的基石。它说的是：**如果你有一群自同构作用在域上，那这个域对固定子域的扩张次数恰好等于群的阶**。这是"群的大小等于域的大小"这一 Galois 精神的精确数学表述。没有 Artin 引理，基本对应定理就无法证明。
:::

**步骤 3：正规子群与正规扩张的对应。**

已在 {thm-normal-characterization} 中证明。

**步骤 4：商群同构。**

设 $H = \operatorname{Gal}(L/M) \trianglelefteq G$，$M/K$ 正规。考虑限制映射：
$$
\varphi: G = \operatorname{Gal}(L/K) \to \operatorname{Gal}(M/K), \quad \sigma \mapsto \sigma|_M.
$$
因 $M/K$ 正规，$\sigma(M) = M$，故 $\sigma|_M$ 是良定义的 $\operatorname{Gal}(M/K)$ 的元素。$\varphi$ 是群同态，$\ker\varphi = \{\sigma \in G : \sigma|_M = \operatorname{id}_M\} = \operatorname{Gal}(L/M) = H$。

$\varphi$ 是满射：设 $\tau \in \operatorname{Gal}(M/K)$。由嵌入扩张引理（{lem-embedding-extension}），$\tau$ 可提升为 $\tilde{\tau} \in \operatorname{Gal}(L/K)$，满足 $\tilde{\tau}|_M = \tau$。故 $\varphi(\tilde{\tau}) = \tau$。

由第一同构定理：$\operatorname{Gal}(M/K) \cong G/H$。$\blacksquare$

</ProofToggle>

::: remark Galois 对应的范畴论表述
Galois 对应可以视为**反变等价**：有限 Galois 扩张 $L/K$ 的中间域范畴（态射为域嵌入）与 $\operatorname{Gal}(L/K)$ 的子群范畴（态射为群包含）之间存在反变等价。这个观点在无限 Galois 理论中推广为 profinite 群的闭子群与 Galois 范畴之间的反变等价（[第十一章](/chapters/11-infinite-galois/)）。
:::

## 完整的 Galois 对应示例 {#examples}

### 示例 1：$V_4$ 情形 {#ex-v4}

::: example $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ 的 Galois 对应 {#ex-galois-sqrt2-sqrt3}
$L = \mathbb{Q}(\sqrt{2}, \sqrt{3})$，$[L:\mathbb{Q}] = 4$。$\operatorname{Gal}(L/\mathbb{Q}) \cong V_4 = \{e, \sigma, \tau, \sigma\tau\}$，其中：
- $\sigma: \sqrt{2} \mapsto -\sqrt{2},\; \sqrt{3} \mapsto \sqrt{3}$
- $\tau: \sqrt{2} \mapsto \sqrt{2},\; \sqrt{3} \mapsto -\sqrt{3}$

Galois 对应（反序）：

```
中间域                           子群                     阶
───────────                    ──────────               ───
L = Q(√2,√3)                    {e}                      1
   |                           ↗  |  ↗
Q(√2)    Q(√3)    Q(√6)     ⟨σ⟩ ⟨στ⟩ ⟨τ⟩             2
   ↘      |      ↗            ↘   |   ↗
       Q                         V₄                      4
```

注意：
- $V_4$ 有 3 个 2 阶子群，全部是正规子群（因为 $V_4$ 是阿贝尔群），对应 3 个二次扩张——它们**都是**正规扩张。
- 无 2 阶中间域对应 $V_4$ 的 2 阶子群的商，也是 $\mathbb{Z}/2\mathbb{Z}$。
- 全部对称：$V_4$ 的子群格与中间域格**同构**（反序）。
:::

### 示例 2：$S_3$ 情形——正规与非正规的对比 {#ex-s3-galois-correspondence}

::: example $x^3 - 2$ 的 Galois 对应 {#ex-galois-x3-2}
$f(x) = x^3 - 2$ 的分裂域为 $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$（$\omega = e^{2\pi i/3}$），$[L:\mathbb{Q}] = 6$。$\operatorname{Gal}(L/\mathbb{Q}) \cong S_3$。

生成元：
$$\sigma: \sqrt[3]{2} \mapsto \omega\sqrt[3]{2} \mapsto \omega^2\sqrt[3]{2} \mapsto \sqrt[3]{2}, \quad \omega \mapsto \omega$$
$$\tau: \sqrt[3]{2} \mapsto \sqrt[3]{2}, \quad \omega \mapsto \omega^2$$

$S_3 = \{e, \sigma, \sigma^2, \tau, \sigma\tau, \sigma^2\tau\}$，阶为 6。

$S_3$ 的子群：
| 子群 | 阶 | 类型 | 正规？ |
|:---|:---|:---|:---|
| $\{e\}$ | 1 | 平凡 | ✓ |
| $\langle \tau \rangle = \{e, \tau\}$ | 2 | 2 阶 | ✗ |
| $\langle \sigma\tau \rangle = \{e, \sigma\tau\}$ | 2 | 2 阶 | ✗ |
| $\langle \sigma^2\tau \rangle = \{e, \sigma^2\tau\}$ | 2 | 2 阶 | ✗ |
| $\langle \sigma \rangle = \{e, \sigma, \sigma^2\}$ | 3 | 循环 3 阶 | ✓（指数 2） |
| $S_3$ | 6 | 全群 | ✓ |

Galois 对应：
| 子群 $H$ | 固定域 $L^H$ | $[L^H : \mathbb{Q}]$ | $L^H/\mathbb{Q}$ 正规？ |
|:---|:---|:---|:---|
| $\{e\}$ | $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$ | 6 | ✓ |
| $\langle \tau \rangle$ | $\mathbb{Q}(\sqrt[3]{2})$ | 3 | **✗** |
| $\langle \sigma\tau \rangle$ | $\mathbb{Q}(\omega^2\sqrt[3]{2})$ | 3 | **✗** |
| $\langle \sigma^2\tau \rangle$ | $\mathbb{Q}(\omega\sqrt[3]{2})$ | 3 | **✗** |
| $\langle \sigma \rangle$ | $\mathbb{Q}(\omega)$ | 2 | ✓ |
| $S_3$ | $\mathbb{Q}$ | 1 | ✓ |

**关键观察：**
1. $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ **不是**正规扩张（$x^3 - 2$ 的其他两个根不在 $\mathbb{Q}(\sqrt[3]{2})$ 中），对应 $\langle \tau \rangle$ **不是** $S_3$ 的正规子群。
2. $\mathbb{Q}(\omega)/\mathbb{Q}$ **是**正规扩张（$x^2 + x + 1$ 在 $\mathbb{Q}(\omega)$ 中完全分裂），对应 $\langle \sigma \rangle \trianglelefteq S_3$。
3. $\operatorname{Gal}(\mathbb{Q}(\omega)/\mathbb{Q}) \cong S_3/\langle \sigma \rangle \cong \mathbb{Z}/2\mathbb{Z}$——这就是定理 (iv) 的具体体现。
4. 三个 2 阶子群都不是正规的，它们互为共轭——恰好对应 $\sqrt[3]{2}$、$\omega\sqrt[3]{2}$、$\omega^2\sqrt[3]{2}$ 在 $\mathbb{Q}$ 上的"对称地位"。

这个例子完美展示了 Galois 对应如何同时揭示：
- 哪些中间域是"好的"（正规的）
- 哪些中间域有"隐秘的对称性"（Galois 群大 vs. 中间域小）
- 为什么某些方程"找不到根式解的单一表达式"
:::

### 示例 3：$D_4$ 情形——完整的子群格 {#ex-d4}

::: example $x^4 - 2$ 的 Galois 对应 {#ex-galois-x4-2}
$f(x) = x^4 - 2$ 的分裂域 $L = \mathbb{Q}(\sqrt[4]{2}, i)$，$[L:\mathbb{Q}] = 8$。$\operatorname{Gal}(L/\mathbb{Q}) \cong D_4$。

$D_4$ 有 10 个子群（$\{e\}$，5 个 2 阶子群，2 个 4 阶子群，$D_4$ 自身），其中 3 个是正规子群（$\{e\}$，$\langle \sigma^2 \rangle$（旋转 180°），$\langle \sigma \rangle \cong \mathbb{Z}/4\mathbb{Z}$，以及 $D_4$ 自身；更精确地，$D_4$ 的正规子群为 $\{e\}$，$\langle \sigma^2 \rangle$，$\langle \sigma \rangle$，$\langle \sigma^2, \tau \rangle$，$\langle \sigma^2, \sigma\tau \rangle$，和 $D_4$）。

对应 10 个中间域，其中正规子群对应的中间域在 $\mathbb{Q}$ 上是正规扩张。完整的对应表需要较仔细的计算——这正是 Galois 理论将**代数问题**转化为**群论问题**的威力。
:::

## Galois 对应与根式求解 {#resolvability}

::: remark 为什么 Galois 对应重要
Galois 对应的最深刻应用是**多项式的根式可解性判据**。其逻辑链如下：

1. 多项式 $f$ 的根式可解 $\iff$ 存在"根式域塔"从 $\mathbb{Q}$ 到 $f$ 的分裂域。
2. 根式域塔 $\iff$ Galois 群有"正规列，每个商都是循环群"。
3. 这个群论条件就是**可解群**的定义（[§9.1](/chapters/09-solvability/9.1-solvable-groups)）。

因此 Galois 对应将"能否用根号写出解"转化为"Galois 群是否可解"——一个纯粹的群论问题。这就是为什么 Abel 和 Galois 的理论如此强大：它将一个两千年的计算问题变成了一个结构分类问题。
:::

## 常见误区 {#misconceptions}

::: warning 误区一：反序双射对任何扩张都成立
基本 Galois 对应要求 $L/K$ 是**有限 Galois 扩张**。如果 $L/K$ 不是 Galois 的，对应可能失败：
- 不正规的情形：$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 只有一个中间域（$\mathbb{Q}$ 和自身），但 $\operatorname{Gal}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}) = \{id\}$ 也只有一个子群。碰巧对应，但这是巧合。
- 关键条件是 $|\operatorname{Gal}(L/K)| = [L:K]$（Galois 扩张），此时对应才是完美的反序双射。
:::

::: warning 误区二：正规子群 ↔ 正规扩张的对应方向容易混淆
"$\operatorname{Gal}(L/M) \trianglelefteq \operatorname{Gal}(L/K)$ ⟺ $M/K$ 正规"是正确的。但**不能反过来说**"$M/K$ 正规 ⟹ $M$ 是某个 Galois 扩张的中间域"。正规扩张本身不一定是 Galois 的（还需要可分性）。

此外，$L/M$ 总是 Galois 的（因为它就是 $\operatorname{Gal}(L/M)$ 的不动域），但 $M/K$ 不一定是。
:::

::: warning 误区三：共轭子群 ↔ 共轭中间域，但"共轭"的含义不同
$\operatorname{Gal}$ 中的共轭子群 $H$ 和 $\sigma H \sigma^{-1}$ 对应域论侧的**共轭域** $\sigma(M)$（即对 $M$ 的元素作用 $\sigma$ 得到的像域）。这里"共轭"在两个不同的范畴中有不同的具体含义：
- 群论：$\sigma H \sigma^{-1}$
- 域论：$\sigma(M) = \{\sigma(m) \mid m \in M\}$

理解这一点对 [§9.1 可解性](/chapters/09-solvability/9.1-solvable-groups) 至关重要：根式求解对应的是正规列（不是任意子群列），而正规列对应的是正规域塔。
:::

## 本节小结 {#summary}

| 对应部分 | 群论侧 | 域论侧 |
|:---|:---|:---|
| (i) 反序双射 | 子群 $H \leq G$ | 中间域 $K \subseteq M \subseteq L$ |
| (ii) 阶数匹配 | $[G : H]$ | $[M : K]$ |
| (iii) 结构匹配 | $H \trianglelefteq G$ | $M/K$ 正规 |
| (iv) 约化 | $G/H$ | $\operatorname{Gal}(M/K)$ |

## 自测题 {#self-test}

1. **[基础]** 设 $L = \mathbb{Q}(\sqrt{2}, \sqrt{3}, \sqrt{5})$。$[L:\mathbb{Q}]$ 是多少？$\operatorname{Gal}(L/\mathbb{Q})$ 同构于什么群？列出所有中间域与子群的对应。
2. **[理解]** 为什么 $\operatorname{Gal}(L/M) \trianglelefteq G$ 不一定意味着 $M/K$ 是正规扩张？什么额外假设（即 $L/K$ 是 Galois 扩张）使得这个蕴含成立？
3. **[计算]** 设 $f(x) = x^3 - 3x - 1$。$f$ 在 $\mathbb{Q}$ 上不可约（由有理根定理验证）。$f$ 的判别式为 $\Delta = -4(-3)^3 - 27(-1)^2 = 108 - 27 = 81 = 9^2$，是完全平方。由此推断 $\operatorname{Gal}(f/\mathbb{Q})$ 同构于 $S_3$ 还是 $A_3 \cong \mathbb{Z}/3\mathbb{Z}$？
4. **[深入]** 在 $x^3 - 2$ 的 Galois 对应中，三个 2 阶子群 $\langle \tau \rangle$、$\langle \sigma\tau \rangle$、$\langle \sigma^2\tau \rangle$ 是 $S_3$ 中互相共轭的。在域论侧，这对应于什么现象？（提示：三个域 $\mathbb{Q}(\sqrt[3]{2})$、$\mathbb{Q}(\omega\sqrt[3]{2})$、$\mathbb{Q}(\omega^2\sqrt[3]{2})$ 之间有什么关系？）
5. **[应用]** 利用 Galois 对应，解释为什么"一般的四次方程"的根可以用根式表达（$\operatorname{Gal} \cong S_4$ 是可解群），但"一般的五次方程"不行（$\operatorname{Gal} \cong S_5$ 不是可解群）。
