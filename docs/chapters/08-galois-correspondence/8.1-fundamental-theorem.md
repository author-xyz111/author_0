# §8.1 基本 Galois 对应 {#sec-fundamental-galois-correspondence}

::: intuition 核心思想
Galois 理论最深刻的洞察是：**域扩张的内部结构（中间域）与群的外部结构（子群）之间存在完美的反序一一对应**。这是"对偶性"的一个范例——两个看似不同的数学对象之间的结构完全镜像彼此。

Galois 对应不仅仅是技术性的工具；它从根本上改变了我们理解多项式方程、域扩张和群论之间关系的方式。
:::

---

## 中间域 {#intermediate-fields}

::: definition 中间域 {#def-intermediate-field}
设 $L/K$ 为域扩张。一个**中间域**（intermediate field）是满足 $K \subseteq M \subseteq L$ 的域 $M$。
:::

::: example 具体的中间域 {#ex-intermediate}
考虑 $L = \mathbb{Q}(\sqrt[4]{2}, i)$，$K = \mathbb{Q}$，$[L:\mathbb{Q}] = 8$。中间域包括：
- $\mathbb{Q}(\sqrt{2})$（二次扩张）
- $\mathbb{Q}(i)$（二次扩张）
- $\mathbb{Q}(\sqrt[4]{2})$（四次扩张）
- $\mathbb{Q}(\sqrt{2}, i)$（四次扩张）
- $\mathbb{Q}(i\sqrt{2})$（二次扩张）

共 6 个真中间域，对应 $\operatorname{Gal}(L/\mathbb{Q}) \cong D_4$ 的 6 个非平凡子群。
:::

---

## 正规子群与正规扩张 {#normal-subgroups-extensions}

::: definition 正规扩张 {#def-normal-extension}
域扩张 $L/K$ 称为**正规扩张**（normal extension），如果 $L$ 是 $K$ 上某个多项式族的分裂域。等价地（有限情形下）：$L/K$ 是正规的当且仅当每个 $K$-不可约多项式 $p \in K[x]$，若在 $L$ 中有一个根，则在 $L$ 中完全分裂。
:::

::: theorem 正规扩张的 Galois 群刻画 {#thm-normal-characterization}
设 $L/K$ 是有限 Galois 扩张，$M$ 是中间域（$K \subseteq M \subseteq L$）。则：

$M/K$ 是正规扩张 $\iff$ $\operatorname{Gal}(L/M)$ 是 $\operatorname{Gal}(L/K)$ 的**正规子群**。
:::

<ProofToggle>

**证明.**

**($\Rightarrow$)** 设 $M/K$ 是正规扩张。设 $\sigma \in \operatorname{Gal}(L/K)$，$\tau \in \operatorname{Gal}(L/M)$。对 $m \in M$，需证 $\sigma\tau\sigma^{-1}(m) = m$。

因 $\sigma^{-1}(m) \in M$（因为 $M/K$ 正规：$\sigma^{-1}$ 固定 $K$，$\sigma^{-1}(m)$ 与 $m$ 有相同的 $K$-极小多项式，而 $M$ 包含该多项式的全部根），且 $\tau$ 固定 $M$，故 $\tau(\sigma^{-1}(m)) = \sigma^{-1}(m)$。故 $\sigma\tau\sigma^{-1}(m) = \sigma(\sigma^{-1}(m)) = m$。$\sigma\tau\sigma^{-1} \in \operatorname{Gal}(L/M)$。

**($\Leftarrow$)** 设 $H = \operatorname{Gal}(L/M) \trianglelefteq G = \operatorname{Gal}(L/K)$。设 $m \in M$，$\sigma \in G$。需证 $\sigma(m) \in M$，即 $\sigma(m)$ 被 $H$ 中所有元素固定。

对 $\tau \in H$：$\tau(\sigma(m)) = (\tau\sigma)(m) = (\sigma\sigma^{-1}\tau\sigma)(m)$。因 $H \trianglelefteq G$，$\sigma^{-1}\tau\sigma \in H$，故 $\sigma^{-1}\tau\sigma$ 固定 $m$，于是 $\tau\sigma(m) = \sigma(m)$。故 $\sigma(m) \in M$。$\blacksquare$

</ProofToggle>

## 基本 Galois 对应定理 {#fundamental-theorem}

::: theorem Galois 对应 {#thm-galois-correspondence}
设 $L/K$ 是有限 Galois 扩张，$G = \operatorname{Gal}(L/K)$。定义两个映射：

$$
\Phi: \{\text{中间域 } K \subseteq M \subseteq L\} \to \{\text{子群 } H \leq G\}, \quad M \mapsto \operatorname{Gal}(L/M),
$$

$$
\Psi: \{\text{子群 } H \leq G\} \to \{\text{中间域 } K \subseteq M \subseteq L\}, \quad H \mapsto L^H.
$$

则：

**(i)** $\Phi$ 和 $\Psi$ 是**互逆的反序双射**（Galois 连接）：$\Psi \circ \Phi = \operatorname{id}$，$\Phi \circ \Psi = \operatorname{id}$。

**(ii)** **指数等于扩张次数：** $[M : K] = [G : H]$，$[L : M] = |H|$，其中 $H = \operatorname{Gal}(L/M)$。

**(iii)** **正规子群对应正规扩张：** $\operatorname{Gal}(L/M) \trianglelefteq G$ $\iff$ $M/K$ 是正规扩张。

**(iv)** **商群对应限制 Galois 群：** 若 $M/K$ 正规，则 $\operatorname{Gal}(M/K) \cong G/\operatorname{Gal}(L/M)$。
:::

<ProofToggle>

**证明.** 证明分为几个关键步骤。

**步骤 1：$\Psi \circ \Phi = \operatorname{id}$。**

设 $M$ 为中间域，$H = \operatorname{Gal}(L/M)$。需证 $L^H = M$。

$M \subseteq L^H$ 是显然的（$H$ 中的元素固定 $M$）。

反过来，设 $\alpha \in L \setminus M$。由本原元定理（{thm-primitive-element}），$M(\alpha) = M(\beta)$ 对某 $\beta$。$\alpha$ 在 $M$ 上的极小多项式 $m_\alpha^M(x)$ 的次数 $\geq 2$。由 {lem-embedding-extension}（应用于 $L/M$ 上的嵌入），存在 $\sigma \in \operatorname{Gal}(L/M)$ 使得 $\sigma(\alpha) \neq \alpha$（因为 $m_\alpha^M$ 在 $L$ 中有多个根，而 $L/M$ 是 Galois 的，故 $M$-自同构可将 $\alpha$ 映到 $m_\alpha^M$ 的任何根）。故 $\alpha \notin L^H$。故 $L^H = M$。

**步骤 2：$\Phi \circ \Psi = \operatorname{id}$。**

设 $H \leq G$，$M = L^H$。需证 $\operatorname{Gal}(L/M) = H$。

$H \subseteq \operatorname{Gal}(L/M)$ 由定义显然。

设 $\sigma \in \operatorname{Gal}(L/M)$。需证 $\sigma \in H$。设 $H = \{h_1, \ldots, h_r\}$。$M = L^H$ 中的元素被所有 $h_i$ 固定。对 $\alpha \in L$，设 $m_\alpha^M$ 是 $\alpha$ 在 $M$ 上的极小多项式。$\sigma(\alpha)$ 也是 $m_\alpha^M$ 的根。$m_\alpha^M$ 的根为 $\{h_1(\alpha), \ldots, h_r(\alpha)\}$（可能是 $H$ 的一个子集上重复的轨道）。故 $\sigma(\alpha) = h_i(\alpha)$ 对某个 $i$。

要证明 $\sigma$ 本身在 $H$ 中，我们需要一个关键的论证：对每个 $\alpha \in L$，令 $H_\alpha = \{\sigma \in \operatorname{Gal}(L/M) : \sigma(\alpha) = \alpha\}$。则 $\operatorname{Gal}(L/M) / H_\alpha$ 双射于 $\{\sigma(\alpha) : \sigma \in \operatorname{Gal}(L/M)\}$。但 $|\{\sigma(\alpha) : \sigma \in \operatorname{Gal}(L/M)\}| = [M(\alpha) : M]$ 的极小多项式次数。由 Artin 引理（步骤 1 的逆向论证），$[L : L^{\operatorname{Gal}(L/M)}] = |\operatorname{Gal}(L/M)|$。因 $L^{\operatorname{Gal}(L/M)} = M$，得 $|\operatorname{Gal}(L/M)| = [L : M]$。但 $|H| = [L : M]$（由 Artin 引理直接应用于 $H$），故 $H = \operatorname{Gal}(L/M)$。

**Artin 引理（{lem-artin}）：** 对有限群 $H \leq \operatorname{Aut}(L)$，$[L : L^H] = |H|$。

*证明.* **（$[L:L^H] \leq |H|$）：** 设 $H = \{\sigma_1, \ldots, \sigma_n\}$（$\sigma_1 = \operatorname{id}$），$n = |H|$。设 $[L:L^H] > n$，取 $L^H$-线性无关的 $\alpha_1, \ldots, \alpha_{n+1} \in L$。考虑方程组 $\sum_{j=1}^{n+1} \sigma_i(\alpha_j) x_j = 0$（$i = 1, \ldots, n$）。这是 $n$ 个方程 $n+1$ 个未知数的齐次线性方程组，有非零解 $(c_1, \ldots, c_{n+1}) \in L^{n+1}$。取满足条件的解使得非零分量个数最少，经置换后可设 $c_1, \ldots, c_{n+1}$ 中前 $r$ 个非零（$r \geq 1$）。

对任意 $\tau \in H$，将方程用 $\tau$ 作用得 $\sum_j \tau\sigma_i(\alpha_j) \tau(c_j) = \sum_j \sigma_k(\alpha_j) \tau(c_j) = 0$（重排指标），故 $(\tau(c_1), \ldots, \tau(c_{n+1}))$ 也是解。从而 $(c_1 - \tau(c_1), \ldots, c_{n+1} - \tau(c_{n+1}))$ 也是解。但 $c_1 \in L^H$（因为 $c_1 \neq 0$ 且可以归一化使 $c_1 = 1 \in L^H$），故 $c_1 - \tau(c_1) = 0$，新解的非零分量个数 $< r$，与 $r$ 的最小性矛盾。

**（$[L:L^H] \geq |H|$）：** 步骤 1 中已证 $L^H \subseteq L^{\operatorname{Gal}(L/L^H)}$。对 $L/L^H$ 的 Galois 群 $\operatorname{Gal}(L/L^H)$，有 $|\operatorname{Gal}(L/L^H)| \leq [L:L^H]$（因为 $|\operatorname{Gal}(L/L^H)|$ 可用上面的不等式）。但 $H \subseteq \operatorname{Gal}(L/L^H)$，故 $|H| \leq |\operatorname{Gal}(L/L^H)| \leq [L:L^H]$。$\blacksquare$

**步骤 3：正规子群与正规扩张的对应。**

已在 {thm-normal-characterization} 中证明。

**步骤 4：商群同构。**

设 $H = \operatorname{Gal}(L/M) \trianglelefteq G$，$M/K$ 正规。考虑限制映射：
$$
\varphi: G = \operatorname{Gal}(L/K) \to \operatorname{Gal}(M/K), \quad \sigma \mapsto \sigma|_M.
$$
因 $M/K$ 正规，$\sigma(M) = M$，故 $\sigma|_M$ 是良定义的 $\operatorname{Gal}(M/K)$ 的元素。$\varphi$ 是群同态，$\ker\varphi = \{\sigma \in G : \sigma|_M = \operatorname{id}_M\} = \operatorname{Gal}(L/M) = H$。

$\varphi$ 是满射：设 $\tau \in \operatorname{Gal}(M/K)$。由嵌入扩张引理（{lem-embedding-extension}），$\tau$ 可提升为 $\tilde{\tau} \in \operatorname{Gal}(L/K)$，满足 $\tilde{\tau}|_M = \tau$。故 $\varphi(\tilde{\tau}) = \tau$。

由第一同构定理：$\operatorname{Gal}(M/K) \cong G/H$。$\blacksquare$

</ProofToggle>

::: remark Galois 对应的范畴论表述
Galois 对应可以视为**反变等价**：有限 Galois 扩张 $L/K$ 的中间域范畴（态射为域嵌入）与 $\operatorname{Gal}(L/K)$ 的子群范畴（态射为群包含）之间存在反变等价。这个观点在无限 Galois 理论中推广为 profinite 群的闭子群与 Galois 范畴之间的反变等价（[第十一章](/chapters/11-infinite-galois/)）。
:::

## Galois 对应的图示 {#galois-diagram}

::: example $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ 的 Galois 对应 {#ex-galois-sqrt2-sqrt3}
$L = \mathbb{Q}(\sqrt{2}, \sqrt{3})$，$[L:\mathbb{Q}] = 4$。$\operatorname{Gal}(L/\mathbb{Q}) \cong V_4 = \{e, \sigma, \tau, \sigma\tau\}$，其中：
- $\sigma: \sqrt{2} \mapsto -\sqrt{2},\; \sqrt{3} \mapsto \sqrt{3}$
- $\tau: \sqrt{2} \mapsto \sqrt{2},\; \sqrt{3} \mapsto -\sqrt{3}$

Galois 对应（反序）：

```
中间域                      子群
─────────                  ─────────
L = Q(√2,√3)               {e}
   |                     ↗
Q(√2)   Q(√3)   Q(√6)   ⟨σ⟩  ⟨τ⟩  ⟨στ⟩
   ↘     |     ↗          ↘  |  ↗
      Q                      V₄
```

注意反序：域越大，对应的子群越小。
:::
