# §8.2 Galois 扩张的刻画 {#sec-galois-extensions-characterization}

::: intuition 多重等价刻画
Galois 扩张的核心特征是"对称性足够丰富"。下面给出五种等价刻画，每一种从不同角度揭示了 Galois 扩张的本质。
:::

---

## 五重等价刻画 {#five-characterizations}

::: theorem Galois 扩张的等价条件 {#thm-galois-equivalent}
设 $L/K$ 是有限扩张。以下条件等价：

**(G1)** $L/K$ 是**正规且可分**的。

**(G2)** $|\operatorname{Gal}(L/K)| = [L : K]$。

**(G3)** $L$ 是 $K$ 上某个**可分多项式**的分裂域。

**(G4)** $L^{\operatorname{Gal}(L/K)} = K$（$K$ 恰好是 Galois 群的不动域）。

**(G5)** $L$ 中每个元素的极小多项式在 $L$ 中完全分裂为互异的线性因子。
:::

<ProofToggle>

**证明.** 我们证明循环 (G1) $\Rightarrow$ (G3) $\Rightarrow$ (G5) $\Rightarrow$ (G1) 以及 (G2) $\Leftrightarrow$ (G4)。

**(G1) $\Rightarrow$ (G3):** 设 $L/K$ 正规且可分。由本原元定理（可分扩张版本），$L = K(\alpha)$。设 $f$ 为 $\alpha$ 在 $K$ 上的极小多项式。因 $\alpha$ 可分，$f$ 无重根。因 $L/K$ 正规，$f$ 的所有根都在 $L$ 中。故 $L$ 是 $f$ 的分裂域，$f$ 是可分多项式。

**(G3) $\Rightarrow$ (G5):** 设 $L$ 是可分多项式 $f \in K[x]$ 的分裂域。设 $\alpha \in L$，$g$ 为 $\alpha$ 在 $K$ 上的极小多项式。则 $g \mid f$（因为 $g(\alpha) = 0$ 且 $g$ 是极小的），$g$ 也是可分的（因为 $f$ 的因子可分）。$g$ 的根都是 $f$ 的根的 $\operatorname{Gal}(L/K)$-轨道（因为 Galois 群传递地作用在不可约多项式的根上），故 $g$ 的所有根都在 $L$ 中，且互不相同。

**(G5) $\Rightarrow$ (G1):** $L/K$ 正规（因为每个 $\alpha \in L$ 的极小多项式在 $L$ 中完全分裂）。$L/K$ 可分（因为极小多项式无重根）。

**(G2) $\Leftrightarrow$ (G4):** 设 $G = \operatorname{Gal}(L/K)$，$F = L^G$。则 $K \subseteq F \subseteq L$。由 Artin 引理，$[L : F] = |G|$。因此 $[L : K] = [L : F] \cdot [F : K] = |G| \cdot [F : K]$。

$|G| = [L : K]$ $\iff$ $[F : K] = 1$ $\iff$ $F = K$。

$\blacksquare$

</ProofToggle>

::: remark Galois 扩张的名字
历史上，正规 + 可分的扩张在 Artin 和 van der Waerden 之前并没有统一的名字。"Galois 扩张"这个术语在 Artin 的经典讲义 "Galois Theory" (1942) 之后普及。条件 (G4) 是 Artin 自己偏好的定义方式。
:::

---

## 分裂域上的 Artin 定理 {#artin-theorem}

::: theorem Artin {#thm-artin}
设 $L$ 是域，$G$ 是 $\operatorname{Aut}(L)$ 的有限子群。设 $K = L^G$（不动域）。则 $L/K$ 是 Galois 扩张，且 $\operatorname{Gal}(L/K) = G$。
:::

<ProofToggle>

**证明.** 由 Artin 引理，$[L : K] = |G|$，故 $L/K$ 是有限扩张。$G \subseteq \operatorname{Gal}(L/K)$（$G$ 中元素都固定 $K$）。由 {prop-galois-group-order}，$|\operatorname{Gal}(L/K)| \leq [L : K] = |G|$。故 $|\operatorname{Gal}(L/K)| = |G|$，$\operatorname{Gal}(L/K) = G$，且 $[L : K] = |\operatorname{Gal}(L/K)|$。由 (G2) $\Leftrightarrow$ (G4)，$L/K$ 是 Galois 扩张。$\blacksquare$

</ProofToggle>

## Galois 扩张的性质 {#galois-properties}

::: proposition Galois 扩张的传递性 {#prop-galois-transitivity}
设 $L/K$ 和 $M/L$ 都是有限 Galois 扩张。

**(i)** $M/K$ 是 Galois 扩张当且仅当 $\operatorname{Gal}(L/K)$ 的每个自同构可以提升为 $\operatorname{Gal}(M/K)$ 的元素。

**(ii)** 若 $M/K$ 是 Galois 的，则存在正合列：
$$
1 \to \operatorname{Gal}(M/L) \to \operatorname{Gal}(M/K) \xrightarrow{\operatorname{res}} \operatorname{Gal}(L/K) \to 1.
$$
其中 $\operatorname{res}$ 是限制映射。因此 $\operatorname{Gal}(M/L) \trianglelefteq \operatorname{Gal}(M/K)$，且 $\operatorname{Gal}(M/K)/\operatorname{Gal}(M/L) \cong \operatorname{Gal}(L/K)$。
:::

<ProofToggle>

**证明.** **(ii)** 限制映射 $\operatorname{res}: \operatorname{Gal}(M/K) \to \operatorname{Gal}(L/K)$ 是良定义的（因为 $M/K$ 正规，$\sigma(L) = L$）。$\ker(\operatorname{res}) = \operatorname{Gal}(M/L)$ 由定义。$\operatorname{res}$ 是满射的证明需要嵌入扩张引理。正合列直接翻译为商群同构。$\blacksquare$

</ProofToggle>

::: example 正合列不总分裂 {#ex-extension-not-split}
设 $L = \mathbb{Q}(\sqrt[3]{2})$，$M = \mathbb{Q}(\sqrt[3]{2}, \omega)$（$f(x) = x^3 - 2$ 的分裂域）。则 $\operatorname{Gal}(M/\mathbb{Q}) \cong S_3$，$\operatorname{Gal}(M/L) \cong \mathbb{Z}/3\mathbb{Z}$（正规子群），$\operatorname{Gal}(L/\mathbb{Q}) = \{\operatorname{id}\}$（因为 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 不是 Galois 的）。

此时正合列为 $1 \to \mathbb{Z}/3\mathbb{Z} \to S_3 \to \{\operatorname{id}\} \to 1$，这是一个平凡的情形。
:::

## Galois 扩张的判据 {#criteria}

::: theorem Galois 扩张的判据 {#thm-galois-criteria}
**(i)** 设 $K$ 是特征零域，$f \in K[x]$ 不可约。则 $f$ 的分裂域是 $K$ 上的 Galois 扩张。

**(ii)** 若 $\operatorname{char} K = p > 0$，结论不一定成立——不可分现象可能出现。

**(iii)** 有限域 $\mathbb{F}_q$ 的任何有限扩张都是 Galois 扩张。
:::

<ProofToggle>

**证明.**

**(i)** 特征零域上的多项式总是可分的（{prop-char0-separable}）。故不可约多项式 $f$ 的分裂域是正规且可分的。

**(iii)** 设 $L/\mathbb{F}_q$ 是有限扩张，则 $L = \mathbb{F}_{q^n}$ 对某个 $n$。由 Frobenius 自同构 $x \mapsto x^q$ 生成的群 $\langle \operatorname{Frob}_q \rangle$ 的阶为 $n$（因为 $\operatorname{Frob}_q^n = \operatorname{id}$，$\operatorname{Frob}_q^k \neq \operatorname{id}$ 对 $k < n$）。不动域为 $\{x \in L : x^q = x\} = \mathbb{F}_q$。由 Artin 定理，$L/\mathbb{F}_q$ 是 Galois 扩张。$\blacksquare$

</ProofToggle>
