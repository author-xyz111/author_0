# §8.2 Galois 扩张的刻画 {#sec-galois-extensions-characterization}

::: tip 📖 学习目标
完成本节后，你应该能够：
1. 陈述并解释 Galois 扩张的五种等价刻画 (G1)–(G5)，并说明每种刻画的"视角"
2. 对给定的具体扩张（如 $\mathbb{Q}(\sqrt{2})/\mathbb{Q}$ 或 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$），逐一验证 (G1)–(G5)
3. 运用 Artin 定理构造 Galois 扩张（从自同构群出发，而非从多项式出发）
4. 证明 Galois 扩张在复合、交、塔等操作下保持 Galois 性质
5. 区分特征零与特征 $p$ 的关键差异，解释"可分"假设的不可或缺性
:::

## 为什么需要 Galois 扩张？ {#motivation}

在 §8.1 中，我们看到基本 Galois 对应的核心定理需要假设 $L/K$ 是 Galois 扩张。现在自然要问：

1. **什么是 Galois 扩张？**——这个问题有多种等价回答，每一种从不同角度看问题。
2. **哪些扩张是 Galois 的？**——能否给出实用的判据？
3. **Galois 扩张有什么"好的性质"？**——它们在复合、交、塔等操作下是否封闭？

本节回答这三个问题。五种等价刻画 (G1)–(G5) 分别从**结构性**（正规+可分）、**计数性**（阶=次数）、**构造性**（分裂域）、**对偶性**（不动域）和**元素级**（极小多项式完全分裂）的角度刻画 Galois 扩张。理解这五种视角的转换，是掌握 Galois 理论的关键。

---

::: definition Galois 扩张 {#def-galois-extension}
域扩张 $L/K$ 称为 **Galois 扩张**（Galois extension），若 $L/K$ 既是正规扩张（{def-normal-extension}）又是可分扩张（{def-separable-extension}）。等价条件见 {thm-galois-equivalent}。
:::

## 五重等价刻画 {#five-characterizations}

::: theorem Galois 扩张的等价条件 {#thm-galois-equivalent}
设 $L/K$ 是有限扩张。以下条件等价：

**(G1)** $L/K$ 是**正规且可分**的。

**(G2)** $|\operatorname{Gal}(L/K)| = [L : K]$。

**(G3)** $L$ 是 $K$ 上某个**可分多项式**的分裂域。

**(G4)** $L^{\operatorname{Gal}(L/K)} = K$（$K$ 恰好是 Galois 群的不动域）。

**(G5)** $L$ 中每个元素的极小多项式在 $L$ 中完全分裂为互异的线性因子。
:::

::: intuition 五种视角
每个条件提供一种"看到 Galois 性"的方式：

- **(G1)** 是**教科书定义**：正规性确保根不逃逸，可分性确保根不重合。
- **(G2)** 是**计数判据**：Galois 群"够大"——$L$ 的每一个维度都对应一个独立的对称性。
- **(G3)** 是**构造性判据**：$L$ 可以由"让某个多项式完全分裂"而得到。
- **(G4)** 是**对偶性判据**：$K$ 恰好被 Galois 群"筛出来"——没有比 $K$ 更大的域被全部固定。这等价于说 Galois 群**足以区分** $K$ 和 $L$。
- **(G5)** 是**元素级判据**：$L$ 对极小多项式是"封闭的"——每个元素的所有共轭都在 $L$ 中。
:::

<ProofToggle>

**证明.** 我们证明循环 (G1) $\Rightarrow$ (G3) $\Rightarrow$ (G5) $\Rightarrow$ (G1) 以及 (G2) $\Leftrightarrow$ (G4)。

**(G1) $\Rightarrow$ (G3):** 设 $L/K$ 正规且可分。由本原元定理（可分有限扩张必为单扩张），$L = K(\alpha)$。设 $f$ 为 $\alpha$ 在 $K$ 上的极小多项式。因 $\alpha$ 可分，$f$ 无重根。因 $L/K$ 正规，$f$ 的所有根都在 $L$ 中。故 $L$ 是 $f$ 的分裂域，$f$ 是可分多项式。

::: warning 本原元定理的作用
(G1) $\Rightarrow$ (G3) 的证明中，本原元定理是关键一步：它将"正规且可分"转化为"单扩张"，从而将问题归结为单个极小多项式。如果没有可分性假设，本原元定理不成立，这个推理就无法进行。
:::

**(G3) $\Rightarrow$ (G5):** 设 $L$ 是可分多项式 $f \in K[x]$ 的分裂域。设 $\alpha \in L$，$g$ 为 $\alpha$ 在 $K$ 上的极小多项式。则 $g \mid f$（因为 $g(\alpha) = 0$ 且 $g$ 是极小的），$g$ 也是可分的（因为 $f$ 的因子可分）。$g$ 的根都是 $f$ 的根的 $\operatorname{Gal}(L/K)$-轨道（因为 Galois 群传递地作用在不可约多项式的根上——见 [§7.1 命题 {prop-transitive-action}](/chapters/07-galois-groups/7.1-definition-and-examples#prop-transitive-action)），故 $g$ 的所有根都在 $L$ 中，且互不相同。

**(G5) $\Rightarrow$ (G1):** $L/K$ 正规（因为每个 $\alpha \in L$ 的极小多项式在 $L$ 中完全分裂）。$L/K$ 可分（因为极小多项式无重根）。

**(G2) $\Leftrightarrow$ (G4):** 设 $G = \operatorname{Gal}(L/K)$，$F = L^G$。则 $K \subseteq F \subseteq L$。由 Artin 引理（[§8.1 {thm-artin}](8.1-fundamental-theorem#lem-artin)），$[L : F] = |G|$。因此 $[L : K] = [L : F] \cdot [F : K] = |G| \cdot [F : K]$。

$|G| = [L : K]$ $\iff$ $[F : K] = 1$ $\iff$ $F = K$。

$\blacksquare$

</ProofToggle>

## 逐条验证：Galois 的例子 {#example-galois}

::: example $\mathbb{Q}(\sqrt{2})/\mathbb{Q}$——逐一检查 (G1)–(G5) {#ex-galois-check}
设 $L = \mathbb{Q}(\sqrt{2})$，$K = \mathbb{Q}$。$[L:K] = 2$。

| 条件 | 验证 | 结果 |
|:---|:---|:---:|
| (G1) 正规+可分 | $\sqrt{2}$ 的极小多项式 $x^2 - 2$ 的两个根 $\pm\sqrt{2}$ 都在 $L$ 中 ✓；特征零故可分 ✓ | ✓ |
| (G2) $\lvert\operatorname{Gal}\rvert = [L:K]$ | $\operatorname{Gal} = \{\operatorname{id}, \sigma\}$（$\sigma(\sqrt{2}) = -\sqrt{2}$），$\lvert\operatorname{Gal}\rvert = 2 = [L:K]$ | ✓ |
| (G3) 可分多项式的分裂域 | $L$ 是 $x^2 - 2$ 的分裂域，$x^2 - 2$ 可分 | ✓ |
| (G4) $L^{\operatorname{Gal}} = K$ | $\sigma(a + b\sqrt{2}) = a - b\sqrt{2}$。若 $a + b\sqrt{2}$ 被 $\sigma$ 固定，则 $b = 0$，故 $L^{\operatorname{Gal}} = \mathbb{Q}$ | ✓ |
| (G5) 极小多项式完全分裂 | $\sqrt{2}$ 的极小多项式 $x^2 - 2 = (x - \sqrt{2})(x + \sqrt{2})$ 在 $L$ 中完全分裂 ✓；$a + b\sqrt{2}$（$b \neq 0$）的极小多项式是二次，在 $L$ 中分裂 ✓ | ✓ |

五个条件全部满足。$\mathbb{Q}(\sqrt{2})/\mathbb{Q}$ 是 Galois 扩张。
:::

## 逐条验证：非 Galois 的例子 {#example-not-galois}

::: example $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$——每个条件都失败 {#ex-not-galois-check}
设 $L = \mathbb{Q}(\sqrt[3]{2})$，$K = \mathbb{Q}$。$[L:K] = 3$。

| 条件 | 验证 | 结果 |
|:---|:---|:---:|
| (G1) 正规+可分 | 可分 ✓（特征零），但**不正规**：$x^3 - 2$ 在 $L$ 中有根 $\sqrt[3]{2}$，但另外两个根 $\omega\sqrt[3]{2}, \omega^2\sqrt[3]{2} \notin L$（因为 $L \subset \mathbb{R}$） | ✗ |
| (G2) $\lvert\operatorname{Gal}\rvert = [L:K]$ | $\operatorname{Gal}(L/\mathbb{Q}) = \{\operatorname{id}\}$（唯一的 $\mathbb{Q}$-自同构），$1 \neq 3$ | ✗ |
| (G3) 可分多项式的分裂域 | $L$ 不是 $x^3 - 2$ 的分裂域（缺根）。$L$ 也不是任何其他可分多项式的分裂域——因为如果 $L$ 是某个 $g$ 的分裂域，则 $L/\mathbb{Q}$ 正规，但我们已经看到它不正规 | ✗ |
| (G4) $L^{\operatorname{Gal}} = K$ | $\operatorname{Gal} = \{\operatorname{id}\}$，故 $L^{\operatorname{Gal}} = L \neq \mathbb{Q}$——**太大的**不动域 | ✗ |
| (G5) 极小多项式完全分裂 | $\sqrt[3]{2}$ 的极小多项式 $x^3 - 2$ 在 $L$ 中只有一根，不完全分裂 | ✗ |

五个条件全部失败。这个例子说明**一个扩张可以同时不满足所有五种刻画**——失败不是偶然的，而是反映了 $L$ 的"内在缺陷"：它太小了，无法容纳 $x^3 - 2$ 的全部对称性。

**修复方法：** 需要扩大到 $L' = \mathbb{Q}(\sqrt[3]{2}, \omega)$（$x^3 - 2$ 的完整分裂域），此时 $[L':K] = 6 = |\operatorname{Gal}(L'/K)|$，$L'/K$ 是 Galois 的。
:::

::: warning "太小"的域是 Galois 理论失败的根源
$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 的 Galois 群是平凡的——域"太小"，只有一个自同构。这不是因为对称性不存在，而是因为 $L$ 无法"看到"对称性。$\sqrt[3]{2}$ 的另外两个共轭根在 $L$ 之外，导致任何非平凡置换都会把 $\sqrt[3]{2}$ 送到 $L$ 外面，无法定义为 $L$ 的自同构。

Galois 扩张的定义正是排除了这种"信息丢失"的情况。
:::

## 五种刻画的综合对照表 {#comparison-table}

| 条件 | 视角 | 典型用途 | 失败时的含义 |
|:---|:---|:---|:---|
| (G1) 正规+可分 | 结构性 | 定义 Galois 理论的基本假设 | 正规性失败→根逃逸；可分性失败→根重合 |
| (G2) $\lvert\operatorname{Gal}\rvert = [L:K]$ | 计数性 | 快速判别：计算 Galois 群的阶并与扩张次数比较 | 群太小→"隐藏对称性" |
| (G3) 可分多项式的分裂域 | 构造性 | 构造 Galois 扩张：取多项式的分裂域 | $L$ 不是任何多项式的"完整解空间" |
| (G4) $L^{\operatorname{Gal}} = K$ | 对偶性 | Galois 对应的起点 | $L^{\operatorname{Gal}} \supsetneq K$→Galois 群无法"筛出" $K$ |
| (G5) 极小多项式封闭 | 元素级 | 验证单个元素是否满足 Galois 性 | 存在元素的共轭不在 $L$ 中 |

## 历史注记 {#history}

::: remark Galois 扩张的名字
历史上，正规 + 可分的扩张在 Artin 和 van der Waerden 之前并没有统一的名字。"Galois 扩张"这个术语在 Artin 的经典讲义 "Galois Theory" (1942) 之后普及。条件 (G4) 是 Artin 自己偏好的定义方式——它最直接地体现了"Galois 群完全决定基域"的精神。
:::

## 分裂域上的 Artin 定理 {#artin-theorem}

Artin 定理是 (G4) 的一个深刻应用：它告诉你如何**从自同构群出发**构造 Galois 扩张，而不需要先找到多项式。

::: theorem Artin {#thm-artin}
设 $L$ 是域，$G$ 是 $\operatorname{Aut}(L)$ 的有限子群。设 $K = L^G$（不动域）。则 $L/K$ 是 Galois 扩张，且 $\operatorname{Gal}(L/K) = G$。
:::

<ProofToggle>

**证明.** 由 Artin 引理，$[L : K] = |G|$，故 $L/K$ 是有限扩张。$G \subseteq \operatorname{Gal}(L/K)$（$G$ 中元素都固定 $K$）。由 [§7.1 命题 {prop-galois-group-order}](/chapters/07-galois-groups/7.1-definition-and-examples#prop-galois-group-order)，$|\operatorname{Gal}(L/K)| \leq [L : K] = |G|$。故 $|\operatorname{Gal}(L/K)| = |G|$，$\operatorname{Gal}(L/K) = G$，且 $[L : K] = |\operatorname{Gal}(L/K)|$。由 (G2) $\Leftrightarrow$ (G4)，$L/K$ 是 Galois 扩张。$\blacksquare$

</ProofToggle>

::: intuition Artin 定理的含义
Artin 定理说的是：**给定一群自同构 $G$ 作用在域 $L$ 上，不动域 $L^G$ 自动与 $L$ 构成 Galois 扩张，且 Galois 群恰好就是 $G$**。

这可以视为 Galois 理论的"逆向构造"：
- **正向**（基本定理 §8.1）：给定 Galois 扩张 $L/K$，其 Galois 群 $\operatorname{Gal}(L/K)$ 的不动域就是 $K$。
- **逆向**（Artin 定理）：给定 $G \leq \operatorname{Aut}(L)$，不动域 $L^G$ 自动给出 Galois 扩张。

两个方向合在一起，说明"子群"和"中间域"之间的对应是**完美的**——没有遗漏，没有多余。
:::

::: example 通过 Artin 定理确认 $\mathbb{C}/\mathbb{R}$ 是 Galois 的 {#ex-artin-c-r}
设 $L = \mathbb{C}$，$G = \{\operatorname{id}, \sigma\}$ 其中 $\sigma$ 是复共轭（$\sigma(a + bi) = a - bi$）。$G$ 是 $\operatorname{Aut}(\mathbb{C})$ 的子群（实际上不是，因为 $\mathbb{C}$ 有很多自同构——但 $\sigma$ 是唯一的**连续** $\mathbb{R}$-自同构；不过对 $\mathbb{C}$ 作为 $\mathbb{R}$-代数，$G = \operatorname{Gal}(\mathbb{C}/\mathbb{R})$ 确实成立）。

$L^G = \{z \in \mathbb{C} : \bar{z} = z\} = \mathbb{R}$。由 Artin 定理，$\mathbb{C}/\mathbb{R}$ 是 Galois 扩张，$\operatorname{Gal}(\mathbb{C}/\mathbb{R}) = G \cong \mathbb{Z}/2\mathbb{Z}$。
:::

::: example 有限域的 Galois 群 {#ex-artin-finite-field}
设 $L = \mathbb{F}_{p^n}$，$\sigma = \operatorname{Frob}_p$（Frobenius 自同构 $x \mapsto x^p$）。$G = \langle \sigma \rangle$ 的阶为 $n$（因为 $\sigma^n = \operatorname{id}$，$\sigma^k \neq \operatorname{id}$ 对 $0 < k < n$——见 [§10.2](/chapters/10-finite-fields/10.2-frobenius)）。

$L^G = \{x \in \mathbb{F}_{p^n} : x^p = x\} = \mathbb{F}_p$。由 Artin 定理，$\mathbb{F}_{p^n}/\mathbb{F}_p$ 是 Galois 扩张，$\operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p) = \langle \operatorname{Frob}_p \rangle \cong \mathbb{Z}/n\mathbb{Z}$。

**这解释了为什么有限域的任何有限扩张都是 Galois 的**——Frobenius 自同构生成了足够大的群。
:::

## Galois 扩张的性质 {#galois-properties}

Galois 扩张有一个极其重要的性质：它们在多种自然操作下保持 Galois 性。这使得我们可以从简单的 Galois 扩张出发，构建更复杂的 Galois 扩张。

### 塔的正合列 {#transitivity}

::: proposition Galois 扩张的传递性 {#prop-galois-transitivity}
设 $K \subseteq L \subseteq M$ 是域的塔。若 $M/K$ 是有限 Galois 扩张，则：

**(i)** $M/L$ 是 Galois 扩张。

**(ii)** $\operatorname{Gal}(M/L) \trianglelefteq \operatorname{Gal}(M/K)$ 当且仅当 $L/K$ 是 Galois 扩张。

**(iii)** 若 $L/K$ 也是 Galois 的，则存在正合列：
$$
1 \to \operatorname{Gal}(M/L) \to \operatorname{Gal}(M/K) \xrightarrow{\operatorname{res}} \operatorname{Gal}(L/K) \to 1.
$$
因此 $\operatorname{Gal}(M/K)/\operatorname{Gal}(M/L) \cong \operatorname{Gal}(L/K)$。
:::

<ProofToggle>

**证明.**

**(i)** $M/K$ Galois $\Rightarrow$ $M/K$ 正规且可分 $\Rightarrow$ $M/L$ 正规且可分（正规性和可分性在塔的中间扩张上保持） $\Rightarrow$ $M/L$ Galois。

**(ii)** 限制映射 $\operatorname{res}: \operatorname{Gal}(M/K) \to \operatorname{Aut}(L)$，$\sigma \mapsto \sigma|_L$ 是群同态。若 $L/K$ 正规，则 $\sigma(L) = L$ 对所有 $\sigma \in \operatorname{Gal}(M/K)$（因为 $L$ 是 $K$ 上某个多项式的分裂域的一部分），故 $\operatorname{res}$ 的像包含于 $\operatorname{Gal}(L/K)$。核为 $\operatorname{Gal}(M/L)$。正规子群的判据给出 $\operatorname{Gal}(M/L) \trianglelefteq \operatorname{Gal}(M/K)$。

反之若 $\operatorname{Gal}(M/L) \trianglelefteq \operatorname{Gal}(M/K)$，可以用 Galois 对应证明 $L/K$ 正规。

**(iii)** $\operatorname{res}$ 的满射性需要嵌入扩张引理。正合列直接翻译为商群同构。$\blacksquare$

</ProofToggle>

::: intuition 正合列的含义
这个正合列说的是：
- $\operatorname{Gal}(M/L)$ 是 $\operatorname{Gal}(M/K)$ 中"只移动 $L$ 以上的元素、不动 $L$"的那些自同构——它是"纤维方向"的对称性。
- 商群 $\operatorname{Gal}(M/K)/\operatorname{Gal}(M/L)$ 恰好是 $\operatorname{Gal}(L/K)$——"基底方向"的对称性。
- 整体对称性 = 纤维对称性 ⋊ 基底对称性（半直积，但正合列不一定分裂）。
:::

### 正合列不总是分裂

::: example $S_3$ 的正合列 {#ex-non-split-extension}
设 $K = \mathbb{Q}$，$L = \mathbb{Q}(\omega)$（$\omega = e^{2\pi i/3}$），$M = \mathbb{Q}(\sqrt[3]{2}, \omega)$（$x^3 - 2$ 的分裂域）。

$M/\mathbb{Q}$ 是 Galois 的，$\operatorname{Gal}(M/\mathbb{Q}) \cong S_3$。

$L/\mathbb{Q}$ 是 Galois 的（二次扩张），$\operatorname{Gal}(L/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z}$。

$M/L$ 是 Galois 的，$\operatorname{Gal}(M/L) = \langle \sigma \rangle \cong \mathbb{Z}/3\mathbb{Z}$（$\sigma: \sqrt[3]{2} \mapsto \omega\sqrt[3]{2}$）。

正合列：$1 \to \mathbb{Z}/3\mathbb{Z} \to S_3 \to \mathbb{Z}/2\mathbb{Z} \to 1$。

这个正合列**分裂**：$S_3 \cong \mathbb{Z}/3\mathbb{Z} \rtimes \mathbb{Z}/2\mathbb{Z}$（半直积）。分裂映射将 $\mathbb{Z}/2\mathbb{Z}$ 的生成元映到复共轭 $\tau$（$\tau: \omega \mapsto \omega^2, \sqrt[3]{2} \mapsto \sqrt[3]{2}$）。

**但并非所有正合列都分裂。** 例如 $1 \to \mathbb{Z}/2\mathbb{Z} \to \mathbb{Z}/4\mathbb{Z} \to \mathbb{Z}/2\mathbb{Z} \to 1$ 不分裂——这对应于 $\mathbb{Q}(\sqrt[4]{2})/\mathbb{Q}$ 的某种情形。
:::

### Galois 扩张的复合与交 {#compositum}

::: corollary Galois 扩张的复合 {#cor-compositum-galois}
设 $L_1/K$ 和 $L_2/K$ 都是有限 Galois 扩张（在某个公共扩域中）。则复合 $L_1 L_2/K$ 也是 Galois 扩张，且
$$
\operatorname{Gal}(L_1 L_2/K) \hookrightarrow \operatorname{Gal}(L_1/K) \times \operatorname{Gal}(L_2/K),
$$
嵌入由 $\sigma \mapsto (\sigma|_{L_1}, \sigma|_{L_2})$ 给出。特别地，若 $L_1 \cap L_2 = K$，则此嵌入是同构：
$$
\operatorname{Gal}(L_1 L_2/K) \cong \operatorname{Gal}(L_1/K) \times \operatorname{Gal}(L_2/K).
$$
:::

<ProofToggle>

**证明.** $L_1$ 是某个可分多项式 $f_1$ 的分裂域，$L_2$ 是 $f_2$ 的分裂域。$L_1 L_2$ 是 $f_1 f_2$ 的分裂域，故 $L_1 L_2/K$ 是 Galois 的（由 (G3)）。

限制映射 $\sigma \mapsto (\sigma|_{L_1}, \sigma|_{L_2})$ 是单射（因为 $L_1 L_2$ 由 $L_1$ 和 $L_2$ 生成）。

若 $L_1 \cap L_2 = K$，则 $\sigma|_{L_1}$ 和 $\sigma|_{L_2}$ 可以独立选择（由嵌入扩张引理），故映射是满射。$\blacksquare$

</ProofToggle>

::: example 复合域的 Galois 群 {#ex-compositum}
设 $L_1 = \mathbb{Q}(\sqrt{2})$，$L_2 = \mathbb{Q}(\sqrt{3})$。$L_1 \cap L_2 = \mathbb{Q}$（因为 $\sqrt{2} \notin \mathbb{Q}(\sqrt{3})$——否则 $\sqrt{2} = a + b\sqrt{3}$ 对某 $a, b \in \mathbb{Q}$，平方后比较有理和无理部分可得矛盾）。

故 $\operatorname{Gal}(\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z} = V_4$。

**对比：** 若 $L_1 = L_2 = \mathbb{Q}(\sqrt{2})$，则 $L_1 L_2 = L_1$，$\operatorname{Gal} \cong \mathbb{Z}/2\mathbb{Z}$——嵌入不是满射，因为 $L_1 \cap L_2 = L_1 \neq \mathbb{Q}$。
:::

::: corollary Galois 扩张的交 {#cor-intersection-galois}
设 $L_1/K$ 和 $L_2/K$ 都是有限 Galois 扩张。则 $L_1 \cap L_2/K$ 也是 Galois 扩张。
:::

<ProofToggle>

**证明.** $L_1 \cap L_2$ 是 $L_1$ 的子域。$L_1/K$ 正规 $\Rightarrow$ $L_1 \cap L_2/K$ 正规（正规扩张的中间域在正规性下封闭？——不对，这需要验证。实际上，$L_1 \cap L_2$ 是 $L_1$ 的子域且 $L_1/K$ Galois。$L_1 \cap L_2/K$ 正规：若 $f \in K[x]$ 不可约且有根 $\alpha \in L_1 \cap L_2$，则 $f$ 在 $L_1$ 中完全分裂（$L_1/K$ 正规）。$f$ 的每个根也在 $L_2$ 中（同样因 $L_2/K$ 正规），故 $f$ 在 $L_1 \cap L_2$ 中完全分裂。$L_1 \cap L_2/K$ 可分：从 $L_1/K$ 可分继承。故 $L_1 \cap L_2/K$ Galois。$\blacksquare$

</ProofToggle>

::: corollary Galois 性在塔中的传递 {#cor-tower-galois}
设 $K \subseteq M \subseteq L$，$L/K$ Galois。

**(i)** $L/M$ 总是 Galois 的。

**(ii)** $M/K$ 是 Galois 的当且仅当 $\operatorname{Gal}(M/K)$ 是 $\operatorname{Gal}(L/K)$ 的正规子群（由 {thm-normal-characterization}）。
:::

::: warning $M/K$ 未必 Galois
即使 $L/K$ 是 Galois 扩张，中间域 $M$ 的扩张 $M/K$ **不一定**是 Galois 的。经典反例：$L = \mathbb{Q}(\sqrt[3]{2}, \omega)$（Galois over $\mathbb{Q}$），$M = \mathbb{Q}(\sqrt[3]{2})$（**不** Galois over $\mathbb{Q}$）。这对应于 $S_3$ 的非正规 2 阶子群。

Galois 对应（§8.1 {thm-normal-characterization}）说的就是：$M/K$ 正规 $\iff$ $\operatorname{Gal}(L/M) \trianglelefteq \operatorname{Gal}(L/K)$。
:::

## Galois 扩张的判据 {#criteria}

::: theorem 特征零的 Galois 判据 {#thm-galois-criteria}
**(i)** 设 $K$ 是**特征零**域，$f \in K[x]$ 不可约。则 $f$ 的分裂域是 $K$ 上的 Galois 扩张。

**(ii)** 等价地：在特征零上，**有限正规扩张** $\Rightarrow$ **Galois 扩张**（因为可分性自动满足）。

**(iii)** 有限域 $\mathbb{F}_q$ 的任何有限扩张都是 Galois 扩张。
:::

<ProofToggle>

**证明.**

**(i)** 特征零域上，不可约多项式总是可分的（无重根——因为 $f$ 和 $f'$ 互素）。故 $f$ 的分裂域是正规且可分的。

**(ii)** 正规扩张中每个元素的极小多项式在 $L$ 中完全分裂。在特征零上极小多项式可分，故完全分裂为互异线性因子。由 (G5)，$L/K$ Galois。

**(iii)** 设 $L = \mathbb{F}_{q^n}$，$K = \mathbb{F}_q$。Frobenius $\operatorname{Frob}_q: x \mapsto x^q$ 生成阶为 $n$ 的循环群 $\langle \operatorname{Frob}_q \rangle$。不动域为 $\{x : x^q = x\} = \mathbb{F}_q = K$。由 Artin 定理，$L/K$ Galois，$\operatorname{Gal}(L/K) \cong \mathbb{Z}/n\mathbb{Z}$。$\blacksquare$

</ProofToggle>

### 特征 $p$ 的反例：纯不可分扩张 {#inseparable-counterexample}

::: example 纯不可分扩张——可分性失败 {#ex-purely-inseparable}
设 $K = \mathbb{F}_p(t)$（$t$ 是超越元），$L = K(t^{1/p}) = \mathbb{F}_p(t^{1/p})$。则 $[L:K] = p$（因为 $t^{1/p}$ 的极小多项式是 $x^p - t$）。

但 $\operatorname{Gal}(L/K) = \{\operatorname{id}\}$！原因：任何 $K$-自同构 $\sigma$ 必须满足 $\sigma(t^{1/p})^p = \sigma(t) = t$。在特征 $p$ 中，$x^p - t = (x - t^{1/p})^p$（只有**一个**根！）。故 $\sigma(t^{1/p}) = t^{1/p}$，$\sigma = \operatorname{id}$。

因此：
- (G2) 失败：$|\operatorname{Gal}| = 1 \neq p = [L:K]$。
- (G1) 失败：$L/K$ 不可分（$x^p - t$ 有重根）。
- (G4) 失败：$L^{\operatorname{Gal}} = L \neq K$。
- (G5) 失败：$t^{1/p}$ 的极小多项式 $(x - t^{1/p})^p$ 有重根。

这是一个**纯不可分扩张**（purely inseparable extension）——它完全没有自同构，是 Galois 理论的"最坏情况"。这个例子说明**可分性假设在特征 $p > 0$ 中是不可省略的**。
:::

::: remark 完美域
一个域 $K$ 称为**完美域**（perfect），如果 $K$ 上的每个不可约多项式都是可分的。等价地：
- 特征零的域都是完美的。
- 特征 $p$ 的域 $K$ 是完美的当且仅当 $K = K^p$（Frobenius 是满射）。

完美域上的有限扩张自动可分，从而"正规 $\Leftrightarrow$ Galois"。有限域和代数闭域都是完美的。非完美的域的例子：$\mathbb{F}_p(t)$。
:::

## 一个综合例子：$\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ {#comprehensive-example}

::: example 从多个角度验证 Galois 性 {#ex-comprehensive}
$L = \mathbb{Q}(\sqrt{2}, \sqrt{3})$，$K = \mathbb{Q}$。

**第一步：维度。** $[L:K] = 4$（因为 $\sqrt{3} \notin \mathbb{Q}(\sqrt{2})$——否则 $\sqrt{3} = a + b\sqrt{2}$，平方后可得矛盾）。

**第二步：Galois 群。** 每个 $\sigma \in \operatorname{Gal}(L/K)$ 由 $\sigma(\sqrt{2})$ 和 $\sigma(\sqrt{3})$ 决定。$\sigma(\sqrt{2}) \in \{\pm\sqrt{2}\}$，$\sigma(\sqrt{3}) \in \{\pm\sqrt{3}\}$。四个选择都是合法的自同构（验证：$\sigma$ 保持加法和乘法），故 $|\operatorname{Gal}| = 4 = [L:K]$。

由 (G2)，$L/K$ 是 Galois 的。$\operatorname{Gal} \cong V_4 = \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$。

**第三步：从 (G3) 的角度。** $L$ 是 $f(x) = (x^2 - 2)(x^2 - 3)$ 的分裂域。$f$ 是可分多项式（无重根）。✓

**第四步：从 (G4) 的角度。** $\operatorname{Gal} = \{\operatorname{id}, \sigma, \tau, \sigma\tau\}$（$\sigma: \sqrt{2} \mapsto -\sqrt{2}$，$\tau: \sqrt{3} \mapsto -\sqrt{3}$）。$L^{\operatorname{Gal}} = \mathbb{Q}$——验证：$a + b\sqrt{2} + c\sqrt{3} + d\sqrt{6}$ 被所有四个自同构固定 $\Rightarrow$ $b = c = d = 0$ $\Rightarrow$ 该元素属于 $\mathbb{Q}$。✓

**第五步：从 (G5) 的角度。** 每个 $\alpha \in L$ 的极小多项式在 $L$ 中完全分裂：$\sqrt{2}$ 的极小多项式 $x^2 - 2 = (x - \sqrt{2})(x + \sqrt{2})$ ✓；$\sqrt{3}$ 类似 ✓；$\sqrt{6}$ 的极小多项式 $x^2 - 6 = (x - \sqrt{6})(x + \sqrt{6})$ ✓。

五种验证一致。
:::

## 本节小结 {#summary}

| 刻画 | 等价条件 | 核心思想 |
|:---|:---|:---|
| (G1) | 正规 + 可分 | 结构完整：根不逃逸、根不重合 |
| (G2) | $\lvert\operatorname{Gal}\rvert = [L:K]$ | 对称性满：每个维度对应一个独立对称性 |
| (G3) | 可分多项式的分裂域 | 可构造：$L$ 是某个多项式的"完整解空间" |
| (G4) | $L^{\operatorname{Gal}} = K$ | 对偶完美：Galois 群恰好筛出基域 |
| (G5) | 极小多项式封闭 | 元素自足：每个元素的全部共轭都在 $L$ 中 |

**关键性质：**
- Galois 扩张的复合是 Galois 的。
- Galois 扩张的交是 Galois 的。
- $M \subseteq L$，$L/K$ Galois $\Rightarrow$ $L/M$ Galois；$M/K$ Galois $\iff$ $\operatorname{Gal}(L/M) \trianglelefteq \operatorname{Gal}(L/K)$。
- 特征零上：不可约多项式的分裂域自动 Galois；有限域上：任何有限扩张自动 Galois。

## 常见误区 {#misconceptions}

::: warning 误区一：把 (G2) 当作 Galois 扩张的定义
虽然 $|\operatorname{Gal}(L/K)| = [L:K]$ 是最实用的判据之一，但它**不是定义**。Galois 扩张的标准定义是 (G1)——正规且可分。(G2) 是一个等价刻画，适用于**有限扩张**。在无限 Galois 理论中（[第十一章](/chapters/11-infinite-galois/)），(G2) 不再有意义（$|\operatorname{Gal}|$ 可能是无穷大），但 (G1) 和 (G4) 的推广版本仍然适用。
:::

::: warning 误区二："特征零 ⟹ 任何扩张都是 Galois 的"
特征零确实意味着所有不可约多项式都是可分的（[§4.3 可分性](/chapters/04-polynomials/4.3-separability)），所以**代数扩张自动可分**。但正规性不是自动的！
- $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 是可分的（特征零），但不是正规的（$x^3 - 2$ 的另外两个根不在 $\mathbb{Q}(\sqrt[3]{2})$ 中）。
- 所以它不是 Galois 扩张，尽管在特征零上。

特征零上的正确陈述是：**不可约多项式的分裂域**自动是 Galois 扩张。不是任何扩张都是 Galois 的。
:::

::: warning 误区三：Galois 扩张的"中间扩张"都是 Galois 的
设 $L/K$ 是 Galois 的，$K \subseteq M \subseteq L$。则：
- $L/M$ **总是** Galois 的（$\operatorname{Gal}(L/M)$ 的不动域就是 $M$）。
- $M/K$ **不一定** Galois 的。

$M/K$ 是 Galois 的 ⟺ $\operatorname{Gal}(L/M) \trianglelefteq \operatorname{Gal}(L/K)$（[§8.1](8.1-fundamental-theorem#thm-galois-correspondence)）。这个条件不是自动满足的——例如 $x^4 - 2$ 的分裂域中，某些中间域就不是正规的。
:::

## 自测题 {#self-test}

1. **[基础]** 判断以下扩张是否为 Galois 的，并说明理由：
   - (a) $\mathbb{Q}(\sqrt{5})/\mathbb{Q}$
   - (b) $\mathbb{Q}(\sqrt[4]{2})/\mathbb{Q}$
   - (c) $\mathbb{Q}(\sqrt[3]{2}, \omega)/\mathbb{Q}$
   - (d) $\mathbb{F}_{25}/\mathbb{F}_5$

2. **[理解]** 设 $L = \mathbb{Q}(\sqrt{1+\sqrt{2}})$。$[L:\mathbb{Q}] = 4$。验证 $L/\mathbb{Q}$ 是否是 Galois 扩张。（提示：$L$ 是 $x^4 - 2x^2 - 1$ 的根域。$x^4 - 2x^2 - 1$ 的四个根是什么？它们是否都在 $L$ 中？）

3. **[计算]** 设 $f(x) = x^4 - 10x^2 + 1 \in \mathbb{Q}[x]$。证明 $f$ 的分裂域是 $\mathbb{Q}(\sqrt{2}, \sqrt{3})$。（提示：$f$ 的根是 $\pm\sqrt{2} \pm \sqrt{3}$ 的某种组合。）由此验证 $\operatorname{Gal}(f/\mathbb{Q}) \cong V_4$。

4. **[深入]** 设 $K = \mathbb{F}_p(t)$，$L = K(\alpha)$ 其中 $\alpha^p = t$（$t$ 不是 $K$ 中的 $p$ 次幂）。证明：
   - (a) $[L:K] = p$
   - (b) $|\operatorname{Gal}(L/K)| = 1$
   - (c) $L$ 不是任何可分多项式的分裂域
   - (d) $L^{\operatorname{Gal}(L/K)} = L$

5. **[证明]** 设 $L_1/K$ 和 $L_2/K$ 是有限 Galois 扩张，$L_1 \cap L_2 = K$。利用 Artin 定理和限制映射证明 $\operatorname{Gal}(L_1 L_2/K) \cong \operatorname{Gal}(L_1/K) \times \operatorname{Gal}(L_2/K)$。
