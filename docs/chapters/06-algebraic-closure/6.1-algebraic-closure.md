# 第六章 · 代数闭包

::: tip 本章学习目标
1. 理解**代数闭域**的定义及其等价刻画（四种等价条件）。
2. 理解**代数闭包**为什么存在（Zorn 引理）且在同构意义下唯一（嵌入扩张引理）。
3. 理解代数基本定理的代数证明思路：$[\mathbb{C}:\mathbb{R}]=2$ + 奇数次多项式有实根。
4. 掌握代数闭包与分裂域、正规扩张之间的关系。
5. 理解为什么固定一个代数闭包是 Galois 理论的起点。
:::

::: intuition
一个域 $K$ 的**代数闭包** $\bar{K}$ 是一个包含 $K$ 的代数扩张，其中每个非常数多项式都有根。直觉上，代数闭包就是把 $K$ "缺的根" 全部补上之后得到的最小的代数扩张。

代数闭包的存在性需要 **Zorn 引理**（等价于选择公理），这是整个代数理论中为数不多使用选择公理的地方。一旦有了代数闭包，Galois 理论的核心对象——Galois 群——就可以被精确定义。
:::

---

## 6.1 代数闭域

::: definition {#def-algebraically-closed}
**定义 6.1.1**（代数闭域）

设 $K$ 为域。若每个非常数多项式 $f \in K[x]$ 在 $K$ 中至少有一个根（即 $\exists \alpha \in K, f(\alpha) = 0$），则称 $K$ 为**代数闭域**（algebraically closed field）。
:::

::: intuition 代数闭域是什么意思？
代数闭域是一个"什么都不缺"的域——多项式方程在里面总能找到解。

想象一个域 $K$，你不断构造新的扩域来"补根"：$x^2+1$ 在 $\mathbb{R}$ 中没根，补一个 $i$ 得到 $\mathbb{C}$。$\mathbb{C}$ 里还需要再补根吗？不需要——这就是代数闭域的含义。
:::

::: theorem {#thm-equiv-algebraically-closed}
**定理 6.1.2**（代数闭域的等价刻画）

设 $K$ 为域。以下条件等价：

**(i)** $K$ 是代数闭域。

**(ii)** $K[x]$ 中每个不可约多项式都是 $1$ 次的。

**(iii)** $K[x]$ 中每个非常数多项式都可以分解为一次因式的乘积。

**(iv)** $K$ 没有真代数扩张（即 $K$ 的每个代数扩张 $L$ 都满足 $L = K$）。
:::

<ProofToggle>

**证明.**

**(i) $\Rightarrow$ (ii):** 设 $p(x) \in K[x]$ 不可约且 $\deg p \geq 1$。由于 $K$ 代数闭，$p$ 在 $K$ 中有根 $\alpha$。由 {lem:factor-theorem}，$p(x) = (x - \alpha) q(x)$。因为 $p$ 不可约，$q$ 必须是常数，故 $\deg p = 1$。

**(ii) $\Rightarrow$ (iii):** 设 $f \in K[x]$ 为非常数多项式。对 $f$ 的次数进行归纳。$\deg f = 1$ 时显然。设 $\deg f = n > 1$。$f$ 在 $K[x]$ 中有不可约因式 $p(x)$。由条件 (ii)，$\deg p = 1$，即 $p(x) = x - \alpha$ 对某个 $\alpha \in K$。于是 $f(x) = (x - \alpha) g(x)$，$\deg g = n - 1$。由归纳假设 $g$ 可分解为一次因式之积，故 $f$ 亦然。

**(iii) $\Rightarrow$ (iv):** 设 $L / K$ 为代数扩张。任取 $\alpha \in L$，设其极小多项式为 $m_\alpha(x) \in K[x]$。由条件 (iii)，$m_\alpha$ 在 $K[x]$ 中完全分解为一次因式之积。因 $m_\alpha$ 不可约（ {def:minimal-polynomial} ），故 $\deg m_\alpha = 1$，即 $\alpha \in K$。故 $L = K$。

**(iv) $\Rightarrow$ (i):** 设 $f \in K[x]$ 为非常数多项式。取 $f$ 的分裂域 $L$（ {thm-splitting-field-exist} ），$L / K$ 是代数扩张。由条件 (iv)，$L = K$。因 $f$ 在分裂域 $L$ 中完全分解，故 $f$ 在 $K$ 中有根。$\blacksquare$
:::

</ProofToggle>

::: remark 条件 (iv) 的深层含义
条件 (iv) 说"代数闭域没有真代数扩张"——这意味着代数闭域是代数扩张的"天花板"。你不可能通过添加代数元来得到比代数闭域更大的域。

这和 [§5.2](/chapters/05-splitting-fields/5.2-normal-extensions) 中正规扩张的概念有深刻联系：正规扩张是那些"包含某个不可约多项式所有根"的扩张，代数闭域则是"包含**所有**多项式所有根"的扩张——它是正规性的极致。
:::

::: example 代数闭域与非代数闭域 {#ex-algebraically-closed}
**代数闭域：**

- $\mathbb{C}$ 是代数闭域——这正是**代数基本定理**（ {thm:fundamental-theorem-of-algebra} ）。每个多项式 $a_n z^n + \cdots + a_0 \in \mathbb{C}[z]$ 都有 $n$ 个根（计重数）。
- $\overline{\mathbb{Q}}$（代数数的全体）是代数闭域。它是 $\mathbb{Q}$ 的代数闭包。

**非代数闭域：**

- $\mathbb{R}$ 不是代数闭域：$x^2 + 1 \in \mathbb{R}[x]$ 在 $\mathbb{R}$ 中无根。$\mathbb{R}$ 的代数闭包是 $\mathbb{C}$。
- $\mathbb{Q}$ 不是代数闭域：$x^2 - 2 \in \mathbb{Q}[x]$ 在 $\mathbb{Q}$ 中无根。$\mathbb{Q}$ 的代数闭包是 $\overline{\mathbb{Q}}$。
- 有限域 $\mathbb{F}_p$ 不是代数闭域：可证 $x^p - x - 1$ 在 $\mathbb{F}_p$ 中无根（因为它在 $\mathbb{F}_p$ 中不被 $x^p - x$ 整除）。$\mathbb{F}_p$ 的代数闭包是 $\overline{\mathbb{F}_p} = \bigcup_{n \geq 1} \mathbb{F}_{p^n}$。
- $K(x)$（有理函数域）不是代数闭域：$y^2 - x$ 在 $K(x)$ 中无根。
:::

::: warning 代数闭域 vs 完备域 vs 完美域
这三个概念容易混淆：

| 概念 | 含义 | 例子 |
|------|------|------|
| **代数闭域** | 每个非常数多项式都有根 | $\mathbb{C}$, $\overline{\mathbb{Q}}$, $\overline{\mathbb{F}_p}$ |
| **完备域**（complete field） | 关于某个绝对值完备 | $\mathbb{R}$, $\mathbb{Q}_p$, $\mathbb{C}$ |
| **完美域**（perfect field） | 每个不可约多项式可分 | 特征 $0$ 的域, 有限域 |

$\mathbb{R}$ 是完备域但不是代数闭域。$\overline{\mathbb{Q}}$ 是代数闭域但不是完备域（关于通常绝对值）。$\mathbb{C}$ 三者都是。
:::

## 6.2 代数闭包的定义与存在性

::: definition {#def-algebraic-closure}
**定义 6.2.1**（代数闭包）

域 $K$ 的**代数闭包**（algebraic closure）是指一个域 $\bar{K}$，满足：

**(i)** $\bar{K} \supseteq K$（$\bar{K}$ 包含 $K$ 作为子域）；

**(ii)** $\bar{K} / K$ 是代数扩张（即 $\bar{K}$ 的每个元素都是 $K$ 上的代数元）；

**(iii)** $\bar{K}$ 是代数闭域。
:::

::: intuition 代数闭包 vs 分裂域
**分裂域**是"刚好够用"的扩张：$K$ 上某族多项式的分裂域只包含这些多项式的根。

**代数闭包**是"全部都要"的扩张：$\bar{K}$ 包含 $K$ 上**所有**多项式的所有根。

**类比**：分裂域像是一间只放了你买的家具的房间；代数闭包像是把全世界的家具都搬进去的仓库。
:::

::: warning 代数闭包 ≠ 某个特定多项式的分裂域
常见误解：以为代数闭包是某个"万能多项式"的分裂域。不——代数闭包是 $K$ 上**所有**多项式的分裂域的"并集"。

单个多项式的分裂域是有限扩张，但代数闭包一般是无限扩张（除非 $K$ 本身代数闭）。
:::

::: theorem {#thm-algebraic-closure-exist}
**定理 6.2.2**（代数闭包的存在性）

每个域 $K$ 都存在代数闭包。
:::

<ProofToggle>

**证明.**

证明分为三步。核心思想是先构造一个**极大代数扩张**，然后证明它是代数闭的。

**步骤 1：构造极大代数扩张。**

令 $\mathcal{S}$ 为所有代数扩张 $L / K$ 的等价类构成的集合。对于两个代数扩张 $L_1 / K$ 和 $L_2 / K$，定义 $L_1 \leq L_2$ 当且仅当存在 $K$-嵌入 $\sigma: L_1 \hookrightarrow L_2$。

（更精确地：考虑所有二元组 $(L, \iota)$，其中 $L$ 是域，$\iota: K \hookrightarrow L$ 是域嵌入，且 $L$ 在 $\iota(K)$ 上是代数的。两个二元组 $(L_1, \iota_1)$ 和 $(L_2, \iota_2)$ 等价当且仅当存在域同构 $\phi: L_1 \xrightarrow{\sim} L_2$ 满足 $\phi \circ \iota_1 = \iota_2$。）

我们在 $\mathcal{S}$ 上定义偏序：$(L_1, \iota_1) \preceq (L_2, \iota_2)$ 当且仅当存在 $K$-嵌入 $\sigma: L_1 \hookrightarrow L_2$（即 $\sigma$ 是域单同态且 $\sigma \circ \iota_1 = \iota_2 \big|_{\iota_1(K)}$，更准确地 $\sigma \circ \iota_1 = \iota_2$）。

设 $\{(L_i, \iota_i)\}_{i \in I}$ 为 $\mathcal{S}$ 中的全序链。构造**并集**（direct limit）

$$\bar{L} = \varinjlim_{i \in I} L_i$$

确切地说，$\bar{L}$ 是各 $L_i$ 的不交并对等价关系 $x \sim \sigma_{ij}(x)$（$\sigma_{ij}: L_i \hookrightarrow L_j$ 为链中的嵌入）取商。$\bar{L}$ 自然地成为一个域，且每个 $L_i$ 都 $K$-嵌入到 $\bar{L}$ 中。

$\bar{L} / K$ 是代数的：$\bar{L}$ 中的每个元素 $\alpha$ 来自某个 $L_i$，而 $L_i / K$ 是代数扩张，故 $\alpha$ 是 $K$-代数元。

因此 $\bar{L}$ 是链的一个上界。由 **Zorn 引理**，$\mathcal{S}$ 中存在极大元 $(\bar{K}, \iota)$。

**步骤 2：极大元是代数闭的。**

设 $\bar{K}$ 为 $\mathcal{S}$ 的极大元。我们要证明 $\bar{K}$ 是代数闭域。

反证法。设 $f(x) \in \bar{K}[x]$ 为非常数多项式，且在 $\bar{K}$ 中无根。设 $p(x)$ 为 $f$ 的一个不可约因式。由 {thm-splitting-field-exist}，存在 $p(x)$ 在 $\bar{K}$ 上的分裂域 $L$。

因为 $p$ 不可约且 $\deg p \geq 2$（否则 $p$ 在 $\bar{K}$ 中有根），$L / \bar{K}$ 是非平凡的代数扩张（ {thm-algebraic-tower} ）。从而 $L / K$ 也是代数扩张：

$$K \subseteq \bar{K} \subseteq L, \quad [L : K] = [L : \bar{K}][\bar{K} : K] < \infty \text{ (或至少是代数的)}$$

具体地：$L / \bar{K}$ 代数且 $\bar{K} / K$ 代数，由 {thm-algebraic-tower}，$L / K$ 代数。

于是 $(L, \iota_L) \in \mathcal{S}$ 且 $(L, \iota_L) \supsetneq (\bar{K}, \iota)$，与 $\bar{K}$ 的极大性矛盾。

**步骤 3：结论。**

$\bar{K}$ 是 $K$ 的代数扩张（由构造），且是代数闭域（由步骤 2），故 $\bar{K}$ 是 $K$ 的代数闭包。$\blacksquare$
:::

</ProofToggle>

::: remark 证明中的关键策略
证明的策略是**"先找极大，再证封闭"**：

1. **Zorn 引理**保证极大代数扩张存在。
2. **反证法**证明极大元不能接受任何进一步的代数扩张，否则与极大性矛盾。
3. 不能接受进一步代数扩张 $\Leftrightarrow$ 代数闭（由 {thm-equiv-algebraically-closed} 的条件 (iv)）。

这是代数中使用 Zorn 引理的经典模式：先构造"最大的对象"，再证明它满足所需性质。
:::

::: remark
**注 6.2.3**（Zorn 引理的必要性）

代数闭包的存在性**本质上依赖选择公理**（Zorn 引理）。事实上，在 ZF（不含选择公理的集合论）中，可以构造模型使得 $\mathbb{R}$ 不存在代数闭包。这说明代数闭包的存在性不是纯粹的构造性结果。

另一方面，如果 $K$ 是可数域（例如 $K = \mathbb{Q}$），则可以通过逐步添加多项式的根来**显式构造**代数闭包，无需选择公理。方法：枚举 $K[x]$ 中的多项式 $f_1, f_2, f_3, \ldots$，逐步构造 $K = K_0 \subseteq K_1 \subseteq K_2 \subseteq \cdots$，其中 $K_{n+1}$ 是 $f_{n+1}$ 在 $K_n$ 上的分裂域。取 $\bar{K} = \bigcup_{n=0}^{\infty} K_n$。
:::

## 6.3 代数闭包的唯一性

::: theorem {#thm-algebraic-closure-unique}
**定理 6.3.1**（代数闭包的唯一性）

设 $\bar{K}_1$ 和 $\bar{K}_2$ 都是域 $K$ 的代数闭包。则存在 $K$-同构 $\sigma: \bar{K}_1 \xrightarrow{\sim} \bar{K}_2$（即 $\sigma$ 是域同构，且 $\sigma\big|_K = \mathrm{id}_K$）。
:::

<ProofToggle>

**证明.**

证明使用 {lem-embedding-extension} 的核心工具。思路是先在 $\bar{K}_1$ 和 $\bar{K}_2$ 之间构造一个 $K$-嵌入，然后利用代数闭性证明它是满射。

**步骤 1：构造 $K$-嵌入。**

由 {lem-embedding-extension}：因 $\bar{K}_1 / K$ 是代数扩张且 $\bar{K}_2$ 是代数闭域，存在 $K$-嵌入

$$\sigma: \bar{K}_1 \hookrightarrow \bar{K}_2.$$

**步骤 2：证明 $\sigma$ 是满射。**

设 $\beta \in \bar{K}_2$。因 $\bar{K}_2 / K$ 是代数扩张，$\beta$ 在 $K$ 上的极小多项式 $m_\beta(x) \in K[x]$ 满足 $\deg m_\beta = n \geq 1$。

设 $m_\beta$ 在 $\bar{K}_1$ 中的根为 $\alpha_1, \ldots, \alpha_n$（因 $\bar{K}_1$ 代数闭，$m_\beta$ 在 $\bar{K}_1$ 中完全分解）。则

$$m_\beta(x) = \prod_{i=1}^{n} (x - \alpha_i) \quad \text{在 } \bar{K}_1[x] \text{ 中}.$$

应用 $\sigma$（在多项式上逐系数作用）：

$$m_\beta(x) = \sigma(m_\beta(x)) = \prod_{i=1}^{n} (x - \sigma(\alpha_i)) \quad \text{在 } \bar{K}_2[x] \text{ 中}.$$

注意 $m_\beta$ 的系数都在 $K$ 中，$\sigma\big|_K = \mathrm{id}$，故 $\sigma(m_\beta) = m_\beta$。

因此 $\sigma(\alpha_1), \ldots, \sigma(\alpha_n)$ 是 $m_\beta$ 在 $\bar{K}_2$ 中的全部根。但 $\beta$ 也是 $m_\beta$ 在 $\bar{K}_2$ 中的根，故 $\beta = \sigma(\alpha_i)$ 对某个 $i$。

故 $\beta \in \sigma(\bar{K}_1)$，即 $\sigma$ 是满射。$\blacksquare$
:::

</ProofToggle>

::: remark 证明中的关键步骤
**为什么 $\sigma$ 是满射？** 因为 $\bar{K}_1$ 代数闭，所以每个 $\beta \in \bar{K}_2$ 的极小多项式在 $\bar{K}_1$ 中完全分解。$\sigma$ 把这些根映射到 $\bar{K}_2$ 中，而 $\bar{K}_2$ 中 $m_\beta$ 的根恰好就是 $\sigma(\alpha_i)$。所以 $\beta$ 一定被 $\sigma$ 覆盖。

**类比**：想象 $\bar{K}_1$ 和 $\bar{K}_2$ 是两栋"内容相同但布局不同"的大楼。$\sigma$ 是一个搬家映射，把 $\bar{K}_1$ 的每个"家具"（代数元）搬到 $\bar{K}_2$ 的对应位置。唯一性说的是：不管你怎么搬，都能搬完（满射），而且不丢东西（单射）。
:::

::: remark
**注 6.3.2**（唯一性的精确含义）

定理说的"唯一"是指**在同构意义下唯一**：两个代数闭包之间至少存在一个 $K$-同构，但一般不止一个。实际上，$K$-同构的集合构成了一个**自然的群**——这正是 Galois 群的前身。

当我们固定一个代数闭包 $\bar{K} / K$ 之后，就可以定义 $K$ 的绝对 Galois 群：

$$\mathrm{Gal}(\bar{K}/K) = \{\sigma: \bar{K} \to \bar{K} \mid \sigma \text{ 是 } K\text{-自同构}\}.$$

这将是第七章的核心对象。

**具体例子**：$\overline{\mathbb{Q}}/\mathbb{Q}$ 的 $K$-自同构远不止一个。例如，$\sigma: \overline{\mathbb{Q}} \to \overline{\mathbb{Q}}$ 可以由 $\sqrt{2} \mapsto -\sqrt{2}$ 唯一确定（通过 {lem-embedding-extension}）。$\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$ 是一个不可数 profinite 群，其有限商群对应有限 Galois 扩张的 Galois 群。
:::

## 6.4 代数闭包与分裂域的关系 {#sec-closure-splitting}

::: proposition 代数闭包包含所有分裂域 {#prop-closure-contains-splitting}
设 $\bar{K}$ 是 $K$ 的代数闭包，$f \in K[x]$。则 $f$ 的分裂域 $L_f$ 可以（作为 $\bar{K}$ 的子域）实现为 $L_f \subseteq \bar{K}$。

特别地，$K$ 的**每个有限正规扩张**都包含在 $\bar{K}$ 中。
:::

::: intuition 这为什么重要？
代数闭包是所有有限分裂域的"母空间"。当我们固定 $\bar{K}$ 后，$K$ 上的每个多项式的根都已经"存在"于 $\bar{K}$ 中。我们不需要为每个多项式单独构造分裂域——$\bar{K}$ 统一包含了所有可能的根。

这为 Galois 理论提供了统一的舞台：所有有限 Galois 扩张都是 $\bar{K}$ 的子域，所有 Galois 群都是 $\operatorname{Gal}(\bar{K}/K)$ 的商群。
:::

::: corollary {#cor-algebraic-elements-in-closure}
设 $\bar{K}$ 是 $K$ 的代数闭包，$\alpha \in \bar{K}$。则 $\alpha$ 的极小多项式 $m_\alpha \in K[x]$ 在 $\bar{K}$ 中完全分解。因此 $\bar{K}$ 包含 $m_\alpha$ 的分裂域。
:::

## 6.5 代数基本定理

作为代数闭包理论的一个精彩应用，我们证明**代数基本定理**——$\mathbb{C}$ 是代数闭域。

::: theorem {#thm:fundamental-theorem-of-algebra}
**定理 6.5.1**（代数基本定理）

复数域 $\mathbb{C}$ 是代数闭域。等价地，每个非常数多项式 $f(z) \in \mathbb{C}[z]$ 在 $\mathbb{C}$ 中至少有一个根。
:::

::: remark 代数基本定理的多种证明
代数基本定理有多种证明方法，各有特色：

1. **复分析证明**（最简洁）：用 Liouville 定理——有界整函数是常数。
2. **拓扑证明**：用环绕数或度数理论。
3. **代数证明**（我们给出的）：仅需 $\mathbb{R}$ 的序性质和域扩张理论。
4. **构造性证明**：对低次多项式有效，但对一般情况不可行。

我们的代数证明展示了域扩张理论的威力：知道 $[\mathbb{C}:\mathbb{R}]=2$ 和奇数次多项式有实根，就能推出 $\mathbb{C}$ 代数闭。
:::

<ProofToggle>

**证明.**

证明分两步：先利用分析证明每个奇数次实系数多项式在 $\mathbb{R}$ 中有根，然后利用域扩张理论推出 $\mathbb{C}$ 代数闭。

**步骤 1：$\mathbb{R}$ 上奇数次多项式必有实根。**

设 $f(x) = a_n x^n + \cdots + a_0 \in \mathbb{R}[x]$，$n$ 为奇数，$a_n > 0$。当 $x \to +\infty$ 时 $f(x) \to +\infty$，当 $x \to -\infty$ 时 $f(x) \to -\infty$。因 $f$ 连续（$\mathbb{R}$ 上多项式的连续性），由**中值定理**（$\mathbb{R}$ 的完备性），$f$ 在 $\mathbb{R}$ 中必有零点。

**步骤 2：$[\mathbb{C} : \mathbb{R}] = 2$ 蕴含 $\mathbb{C}$ 代数闭。**

首先注意 $\mathbb{C} = \mathbb{R}(i)$，其中 $i$ 是 $x^2 + 1$ 的根。故 $[\mathbb{C} : \mathbb{R}] = 2$。

**关键引理：** $\mathbb{C}$ 没有 $2$ 次扩张。

*证明.* 设 $L / \mathbb{C}$ 为二次扩张。取 $\alpha \in L \setminus \mathbb{C}$，设其极小多项式为 $x^2 + bx + c \in \mathbb{C}[x]$。判别式为 $\Delta = b^2 - 4c \in \mathbb{C}$。

我们断言 $\Delta$ 在 $\mathbb{C}$ 中有平方根。写 $\Delta = re^{i\theta}$（$r \geq 0$），则 $\sqrt{r} e^{i\theta/2}$ 就是 $\Delta$ 的平方根。

故 $x^2 + bx + c = (x - \alpha_1)(x - \alpha_2)$ 其中 $\alpha_1, \alpha_2 = \frac{-b \pm \sqrt{\Delta}}{2} \in \mathbb{C}$，矛盾于 $x^2 + bx + c$ 不可约。$\square$

现在设 $f(z) \in \mathbb{C}[z]$ 为非常数多项式。$f$ 的分裂域 $L$ 是 $\mathbb{C}$ 的有限扩张。因 $\mathbb{C} = \mathbb{R}(i)$，$L / \mathbb{R}$ 也是有限扩张。由 {thm-primitive-element}（在特征 $0$ 上成立），$L = \mathbb{R}(\alpha)$ 对某个 $\alpha$。设 $[\mathbb{R}(\alpha) : \mathbb{R}] = m$。

**断言：$m$ 必须是 $2$ 的幂。**

设 $p$ 是 $m$ 的奇素因子。由 [§3.2 塔定律](/chapters/03-fields/3.2-basic-extensions)，$L / \mathbb{R}$ 有中间域 $\mathbb{R} \subseteq E \subseteq L$ 满足 $[E:\mathbb{R}] = p$。取 $\beta \in E \setminus \mathbb{R}$，其极小多项式 $g(x) \in \mathbb{R}[x]$ 的次数为 $p$（奇数）。由步骤 1，$g$ 在 $\mathbb{R}$ 中有根。但 $g$ 不可约且 $\deg g = p > 1$，矛盾。所以 $m$ 没有奇素因子，即 $m = 2^k$。

因 $[\mathbb{C}:\mathbb{R}] = 2$，$[L:\mathbb{C}] = 2^{k-1}$。若 $k \geq 2$，则 $[L:\mathbb{C}] \geq 2$，$L$ 包含 $\mathbb{C}$ 的二次扩张——但由上面的关键引理，$\mathbb{C}$ 没有二次扩张。

故 $k = 1$，$[L:\mathbb{C}] = 1$，即 $L = \mathbb{C}$。故 $f$ 的所有根都在 $\mathbb{C}$ 中。$\blacksquare$
:::

</ProofToggle>

::: remark 证明的结构
证明的核心是一个**双层论证**：

1. **分析层**（步骤 1）：利用 $\mathbb{R}$ 的序性质和完备性，证明奇数次实多项式有实根。
2. **代数层**（步骤 2）：利用 $[\mathbb{C}:\mathbb{R}]=2$ 和域扩张理论，将 $\mathbb{C}$ 的代数闭性归结为"没有偶数次扩张"，进而归结为"没有二次扩张"。

这体现了代数与分析的深刻互动：代数基本定理虽然陈述的是代数事实，但其证明不可避免地使用了分析（$\mathbb{R}$ 的完备性）。
:::

## 6.6 代数闭包的基数 {#sec-cardinality}

::: proposition {#prop-algebraic-closure-cardinality}
**命题 6.6.1**

设 $K$ 为无限域。则 $K$ 的代数闭包 $\bar{K}$ 满足 $|\bar{K}| = |K|$。

特别地，$|\overline{\mathbb{Q}}| = \aleph_0$（可数），$|\bar{\mathbb{R}}| = |\mathbb{C}| = 2^{\aleph_0}$（连续统）。
:::

<ProofToggle>

**证明.**

$K[x]$ 是可数个多项式的集合。若 $K$ 可数，则 $K[x]$ 也可数，$K[x]$ 中的每个多项式有有限个根，故 $K$ 的代数闭包是可数个有限集的并，仍可数。故 $|\bar{K}| \leq \aleph_0 = |K|$。

若 $K$ 不可数，令 $\kappa = |K|$。则 $|K[x]| = \kappa$（多项式个数等于基数），每个多项式最多 $\deg f$ 个根，故 $|\bar{K}| \leq \kappa \cdot \aleph_0 = \kappa = |K|$。

另一方面 $\bar{K} \supseteq K$，故 $|\bar{K}| \geq |K|$。$\blacksquare$
:::

</ProofToggle>

::: remark
**注 6.6.2**（$\bar{\mathbb{Q}}$ 的特殊地位）

$\overline{\mathbb{Q}}$ 是 $\mathbb{Q}$ 的代数闭包，它是**可数**的，且是代数数（即 $\mathbb{Q}$ 上代数元）的全体。$\overline{\mathbb{Q}} \cap \mathbb{R}$ 是**实代数数**的集合。这两个域在代数数论中有核心地位。

注意 $\overline{\mathbb{Q}} \subsetneq \mathbb{C}$（因为 $\pi, e \in \mathbb{C}$ 但 $\pi, e \notin \overline{\mathbb{Q}}$——它们是超越数），但 $\mathbb{C}$ 是 $\overline{\mathbb{Q}}$ 的超越扩张。

**具体例子**：$\overline{\mathbb{Q}}$ 包含：
- 所有有理数 $\mathbb{Q}$
- $\sqrt{2}, \sqrt{3}, \sqrt{5}, \ldots$（二次代数数）
- $\sqrt[3]{2}$（三次代数数）
- 黄金比例 $\varphi = \frac{1+\sqrt{5}}{2}$（二次代数数）
- $\zeta_n = e^{2\pi i/n}$（$n$ 次单位根，分圆多项式的根）
- $\sqrt{2} + \sqrt{3}$（极小多项式 $X^4 - 10X^2 + 1$ 的根）

但 $\overline{\mathbb{Q}}$ **不**包含 $\pi, e, \ln 2, 2^{\sqrt{2}}$ 等超越数。
:::

## 常见误区 {#misconceptions}

::: warning 误区一：代数闭包是有限扩张
$\overline{\mathbb{Q}}/\mathbb{Q}$ 是**无限**代数扩张。$[\overline{\mathbb{Q}} : \mathbb{Q}] = \infty$。

代数闭包虽然是代数扩张（每个元素都是代数元），但一般不是有限扩张。只有代数闭域自身的代数闭包才是有限扩张（即自身）。
:::

::: warning 误区二：代数闭包的构造是唯一的
定理 6.3.1 说的是代数闭包在**同构意义下**唯一，不是作为集合唯一。

例如，$\mathbb{C}$ 和 $\overline{\mathbb{Q}} \cup \{\text{超越数}\}$ 都是 $\mathbb{R}$ 的代数闭包（$\mathbb{C}$ 是）。但 $\mathbb{Q}$ 的代数闭包 $\overline{\mathbb{Q}}$ 和另一个实现 $\overline{\mathbb{Q}}'$ 之间可能有多个 $K$-同构——这些同构构成了 Galois 群。
:::

::: warning 误区三：代数闭域一定是不可数的
$\overline{\mathbb{F}_p}$（$\mathbb{F}_p$ 的代数闭包）是**可数**的。它是 $\bigcup_{n \geq 1} \mathbb{F}_{p^n}$，每个 $\mathbb{F}_{p^n}$ 是有限集，可数个有限集的并仍可数。

事实上，无限域的代数闭包的基数等于原域的基数（命题 6.6.1）。
:::

::: warning 误区四：代数闭包 = 所有多项式的分裂域
严格来说，代数闭包不是某个多项式的分裂域（它是**所有**多项式的分裂域的"并集"）。

但可以说：代数闭包是 $K$ 上所有多项式分裂域的**正向极限**（direct limit）。这个极限不是有限扩张。
:::

::: tip 本章知识检验

**自测题：**

1. 用四种等价条件分别说明为什么 $\mathbb{R}$ 不是代数闭域。

2. 设 $\bar{\mathbb{Q}}$ 是 $\mathbb{Q}$ 的代数闭包。证明 $\bar{\mathbb{Q}} \cap \mathbb{R}$（实代数数的集合）不是代数闭域。

3. 证明：若 $L/K$ 是有限扩张且 $L$ 是代数闭域，则 $K$ 也是代数闭域，且 $L = K$。

4. 设 $\bar{K}$ 是 $K$ 的代数闭包，$L/K$ 是有限扩张。证明存在 $K$-嵌入 $L \hookrightarrow \bar{K}$。

5. 解释为什么代数基本定理的证明不能避免使用分析（$\mathbb{R}$ 的完备性）。

**答案要点：**

1. (i) $x^2+1$ 在 $\mathbb{R}$ 中无根。(ii) $x^2+1$ 在 $\mathbb{R}[x]$ 中不可约且 $\deg = 2 > 1$。(iii) $x^2+1$ 不能分解为一次因式。(iv) $\mathbb{C}/\mathbb{R}$ 是 $\mathbb{R}$ 的真代数扩张。

2. $x^2 + 1 \in (\bar{\mathbb{Q}} \cap \mathbb{R})[x]$ 有根 $i$，但 $i \notin \mathbb{R}$。

3. $K$ 有真代数扩张 $L$，则 $L$ 中有不在 $K$ 中的元素 $\alpha$。$\alpha$ 的极小多项式 $f \in K[x]$ 在 $L$ 中有根 $\alpha$。$f$ 不可约，$\deg f \geq 2$（否则 $\alpha \in K$）。所以 $K$ 有不可约多项式次数 $> 1$，$K$ 不代数闭。但 $L$ 代数闭，$L/K$ 代数，由条件 (iv) $L = K$。

4. 由 {lem-embedding-extension}：$L/K$ 代数且 $\bar{K}$ 代数闭，故存在 $K$-嵌入 $L \hookrightarrow \bar{K}$。

5. 纯代数论证只能处理代数扩张。$[\mathbb{C}:\mathbb{R}]=2$ 是代数事实，但"奇数次实多项式有实根"需要 $\mathbb{R}$ 的完备性（中值定理）。在不完备的有序域（如 $\mathbb{Q}$）中，奇数次多项式不一定有根。
:::
