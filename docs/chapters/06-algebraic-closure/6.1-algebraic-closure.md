# 第六章 · 代数闭包

::: intuition
一个域 $K$ 的**代数闭包** $\bar{K}$ 是一个包含 $K$ 的代数扩张，其中每个非常数多项式都有根。直觉上，代数闭包就是把 $K$ "缺的根" 全部补上之后得到的最小的代数扩张。

代数闭包的存在性需要 **Zorn 引理**（等价于选择公理），这是整个代数理论中为数不多使用选择公理的地方。一旦有了代数闭包，Galois 理论的核心对象——Galois 群——就可以被精确定义。
:::

---

## 6.1 代数闭域

::: definition {#def-algebraically-closed}
**定义 6.1.1**（代数闭域）

设 $K$ 为域。若每个非常数多项式 $f \in K[x]$ 在 $K$ 中至少有一个根（即 $\exists \alpha \in K, f(\alpha) = 0$），则称 $K$ 为**代数闭域**（algebraically closed field）。
:::

::: theorem {#thm-equiv-algebraically-closed}
**定理 6.1.2**（代数闭域的等价刻画）

设 $K$ 为域。以下条件等价：

**(i)** $K$ 是代数闭域。

**(ii)** $K[x]$ 中每个不可约多项式都是 $1$ 次的。

**(iii)** $K[x]$ 中每个非常数多项式都可以分解为一次因式的乘积。

**(iv)** $K$ 没有真代数扩张（即 $K$ 的每个代数扩张 $L$ 都满足 $L = K$）。
:::

<ProofToggle>

**证明.**

**(i) $\Rightarrow$ (ii):** 设 $p(x) \in K[x]$ 不可约且 $\deg p \geq 1$。由于 $K$ 代数闭，$p$ 在 $K$ 中有根 $\alpha$。由 {lem:factor-theorem}，$p(x) = (x - \alpha) q(x)$。因为 $p$ 不可约，$q$ 必须是常数，故 $\deg p = 1$。

**(ii) $\Rightarrow$ (iii):** 设 $f \in K[x]$ 为非常数多项式。对 $f$ 的次数进行归纳。$\deg f = 1$ 时显然。设 $\deg f = n > 1$。$f$ 在 $K[x]$ 中有不可约因式 $p(x)$。由条件 (ii)，$\deg p = 1$，即 $p(x) = x - \alpha$ 对某个 $\alpha \in K$。于是 $f(x) = (x - \alpha) g(x)$，$\deg g = n - 1$。由归纳假设 $g$ 可分解为一次因式之积，故 $f$ 亦然。

**(iii) $\Rightarrow$ (iv):** 设 $L / K$ 为代数扩张。任取 $\alpha \in L$，设其极小多项式为 $m_\alpha(x) \in K[x]$。由条件 (iii)，$m_\alpha$ 在 $K[x]$ 中完全分解为一次因式之积。因 $m_\alpha$ 不可约（ {def:minimal-polynomial} ），故 $\deg m_\alpha = 1$，即 $\alpha \in K$。故 $L = K$。

**(iv) $\Rightarrow$ (i):** 设 $f \in K[x]$ 为非常数多项式。取 $f$ 的分裂域 $L$（ {thm-splitting-field-exist} ），$L / K$ 是代数扩张。由条件 (iv)，$L = K$。因 $f$ 在分裂域 $L$ 中完全分解，故 $f$ 在 $K$ 中有根。$\blacksquare$
:::

</ProofToggle>

::: example {#ex-algebraically-closed}
**例 6.1.3**

- $\mathbb{C}$ 是代数闭域——这正是**代数基本定理**（ {thm:fundamental-theorem-of-algebra} ）。
- $\mathbb{R}$ 不是代数闭域：多项式 $x^2 + 1 \in \mathbb{R}[x]$ 在 $\mathbb{R}$ 中无根。
- 有限域 $\mathbb{F}_p$ 不是代数闭域：可证 $x^p - x - 1$ 在 $\mathbb{F}_p$ 中无根（因为它在 $\mathbb{F}_p$ 中不被 $x^p - x$ 整除）。
:::

## 6.2 代数闭包的定义与存在性

::: definition {#def-algebraic-closure}
**定义 6.2.1**（代数闭包）

域 $K$ 的**代数闭包**（algebraic closure）是指一个域 $\bar{K}$，满足：

**(i)** $\bar{K} \supseteq K$（$\bar{K}$ 包含 $K$ 作为子域）；

**(ii)** $\bar{K} / K$ 是代数扩张（即 $\bar{K}$ 的每个元素都是 $K$ 上的代数元）；

**(iii)** $\bar{K}$ 是代数闭域。
:::

::: theorem {#thm-algebraic-closure-exist}
**定理 6.2.2**（代数闭包的存在性）

每个域 $K$ 都存在代数闭包。
:::

<ProofToggle>

**证明.**

证明分为三步。核心思想是先构造一个**极大代数扩张**，然后证明它是代数闭的。

**步骤 1：构造极大代数扩张。**

令 $\mathcal{S}$ 为所有代数扩张 $L / K$ 的等价类构成的集合。对于两个代数扩张 $L_1 / K$ 和 $L_2 / K$，定义 $L_1 \leq L_2$ 当且仅当存在 $K$-嵌入 $\sigma: L_1 \hookrightarrow L_2$。

（更精确地：考虑所有二元组 $(L, \iota)$，其中 $L$ 是域，$\iota: K \hookrightarrow L$ 是域嵌入，且 $L$ 在 $\iota(K)$ 上是代数的。两个二元组 $(L_1, \iota_1)$ 和 $(L_2, \iota_2)$ 等价当且仅当存在域同构 $\phi: L_1 \xrightarrow{\sim} L_2$ 满足 $\phi \circ \iota_1 = \iota_2$。）

我们在 $\mathcal{S}$ 上定义偏序：$(L_1, \iota_1) \preceq (L_2, \iota_2)$ 当且仅当存在 $K$-嵌入 $\sigma: L_1 \hookrightarrow L_2$（即 $\sigma$ 是域单同态且 $\sigma \circ \iota_1 = \iota_2 \big|_{\iota_1(K)}$，更准确地 $\sigma \circ \iota_1 = \iota_2$）。

设 $\{(L_i, \iota_i)\}_{i \in I}$ 为 $\mathcal{S}$ 中的全序链。构造**并集**（direct limit）

$$\bar{L} = \varinjlim_{i \in I} L_i$$

确切地说，$\bar{L}$ 是各 $L_i$ 的不交并对等价关系 $x \sim \sigma_{ij}(x)$（$\sigma_{ij}: L_i \hookrightarrow L_j$ 为链中的嵌入）取商。$\bar{L}$ 自然地成为一个域，且每个 $L_i$ 都 $K$-嵌入到 $\bar{L}$ 中。

$\bar{L} / K$ 是代数的：$\bar{L}$ 中的每个元素 $\alpha$ 来自某个 $L_i$，而 $L_i / K$ 是代数扩张，故 $\alpha$ 是 $K$-代数元。

因此 $\bar{L}$ 是链的一个上界。由 **Zorn 引理**，$\mathcal{S}$ 中存在极大元 $(\bar{K}, \iota)$。

**步骤 2：极大元是代数闭的。**

设 $\bar{K}$ 为 $\mathcal{S}$ 的极大元。我们要证明 $\bar{K}$ 是代数闭域。

反证法。设 $f(x) \in \bar{K}[x]$ 为非常数多项式，且在 $\bar{K}$ 中无根。设 $p(x)$ 为 $f$ 的一个不可约因式。由 {thm-splitting-field-exist}，存在 $p(x)$ 在 $\bar{K}$ 上的分裂域 $L$。

因为 $p$ 不可约且 $\deg p \geq 2$（否则 $p$ 在 $\bar{K}$ 中有根），$L / \bar{K}$ 是非平凡的代数扩张（ {thm-algebraic-tower} ）。从而 $L / K$ 也是代数扩张：

$$K \subseteq \bar{K} \subseteq L, \quad [L : K] = [L : \bar{K}][\bar{K} : K] < \infty \text{ (或至少是代数的)}$$

具体地：$L / \bar{K}$ 代数且 $\bar{K} / K$ 代数，由 {thm-algebraic-tower}，$L / K$ 代数。

于是 $(L, \iota_L) \in \mathcal{S}$ 且 $(L, \iota_L) \supsetneq (\bar{K}, \iota)$，与 $\bar{K}$ 的极大性矛盾。

**步骤 3：结论。**

$\bar{K}$ 是 $K$ 的代数扩张（由构造），且是代数闭域（由步骤 2），故 $\bar{K}$ 是 $K$ 的代数闭包。$\blacksquare$
:::

</ProofToggle>

::: remark
**注 6.2.3**（Zorn 引理的必要性）

代数闭包的存在性**本质上依赖选择公理**（Zorn 引理）。事实上，在 ZF（不含选择公理的集合论）中，可以构造模型使得 $\mathbb{R}$ 不存在代数闭包。这说明代数闭包的存在性不是纯粹的构造性结果。

另一方面，如果 $K$ 是可数域（例如 $K = \mathbb{Q}$），则可以通过逐步添加多项式的根来**显式构造**代数闭包，无需选择公理。
:::

## 6.3 代数闭包的唯一性

::: theorem {#thm-algebraic-closure-unique}
**定理 6.3.1**（代数闭包的唯一性）

设 $\bar{K}_1$ 和 $\bar{K}_2$ 都是域 $K$ 的代数闭包。则存在 $K$-同构 $\sigma: \bar{K}_1 \xrightarrow{\sim} \bar{K}_2$（即 $\sigma$ 是域同构，且 $\sigma\big|_K = \mathrm{id}_K$）。
:::

<ProofToggle>

**证明.**

证明使用 {lem-embedding-extension} 的核心工具。思路是先在 $\bar{K}_1$ 和 $\bar{K}_2$ 之间构造一个 $K$-嵌入，然后利用代数闭性证明它是满射。

**步骤 1：构造 $K$-嵌入。**

由 {lem-embedding-extension}：因 $\bar{K}_1 / K$ 是代数扩张且 $\bar{K}_2$ 是代数闭域，存在 $K$-嵌入

$$\sigma: \bar{K}_1 \hookrightarrow \bar{K}_2.$$

**步骤 2：证明 $\sigma$ 是满射。**

设 $\beta \in \bar{K}_2$。因 $\bar{K}_2 / K$ 是代数扩张，$\beta$ 在 $K$ 上的极小多项式 $m_\beta(x) \in K[x]$ 满足 $\deg m_\beta = n \geq 1$。

设 $m_\beta$ 在 $\bar{K}_1$ 中的根为 $\alpha_1, \ldots, \alpha_n$（因 $\bar{K}_1$ 代数闭，$m_\beta$ 在 $\bar{K}_1$ 中完全分解）。则

$$m_\beta(x) = \prod_{i=1}^{n} (x - \alpha_i) \quad \text{在 } \bar{K}_1[x] \text{ 中}.$$

应用 $\sigma$（在多项式上逐系数作用）：

$$m_\beta(x) = \sigma(m_\beta(x)) = \prod_{i=1}^{n} (x - \sigma(\alpha_i)) \quad \text{在 } \bar{K}_2[x] \text{ 中}.$$

注意 $m_\beta$ 的系数都在 $K$ 中，$\sigma\big|_K = \mathrm{id}$，故 $\sigma(m_\beta) = m_\beta$。

因此 $\sigma(\alpha_1), \ldots, \sigma(\alpha_n)$ 是 $m_\beta$ 在 $\bar{K}_2$ 中的全部根。但 $\beta$ 也是 $m_\beta$ 在 $\bar{K}_2$ 中的根，故 $\beta = \sigma(\alpha_i)$ 对某个 $i$。

故 $\beta \in \sigma(\bar{K}_1)$，即 $\sigma$ 是满射。$\blacksquare$
:::

</ProofToggle>

::: remark
**注 6.3.2**（唯一性的精确含义）

定理说的"唯一"是指**在同构意义下唯一**：两个代数闭包之间至少存在一个 $K$-同构，但一般不止一个。实际上，$K$-同构的集合构成了一个**自然的群**——这正是 Galois 群的前身。

当我们固定一个代数闭包 $\bar{K} / K$ 之后，就可以定义 $K$ 的绝对 Galois 群：

$$\mathrm{Gal}(\bar{K}/K) = \{\sigma: \bar{K} \to \bar{K} \mid \sigma \text{ 是 } K\text{-自同构}\}.$$

这将是第七章的核心对象。
:::

## 6.4 代数基本定理

作为代数闭包理论的一个精彩应用，我们证明**代数基本定理**——$\mathbb{C}$ 是代数闭域。这里给出一个纯代数的证明（仅需 $\mathbb{R}$ 的序性质和 $\mathbb{C}$ 的基本性质）。

::: theorem {#thm:fundamental-theorem-of-algebra}
**定理 6.4.1**（代数基本定理）

复数域 $\mathbb{C}$ 是代数闭域。等价地，每个非常数多项式 $f(z) \in \mathbb{C}[z]$ 在 $\mathbb{C}$ 中至少有一个根。
:::

<ProofToggle>

**证明.**

证明分两步：先利用分析证明每个奇数次实系数多项式在 $\mathbb{R}$ 中有根，然后利用域扩张理论推出 $\mathbb{C}$ 代数闭。

**步骤 1：$\mathbb{R}$ 上奇数次多项式必有实根。**

设 $f(x) = a_n x^n + \cdots + a_0 \in \mathbb{R}[x]$，$n$ 为奇数，$a_n > 0$。当 $x \to +\infty$ 时 $f(x) \to +\infty$，当 $x \to -\infty$ 时 $f(x) \to -\infty$。因 $f$ 连续（$\mathbb{R}$ 上多项式的连续性），由**中值定理**（$\mathbb{R}$ 的完备性），$f$ 在 $\mathbb{R}$ 中必有零点。

**步骤 2：$[\mathbb{C} : \mathbb{R}] = 2$ 蕴含 $\mathbb{C}$ 代数闭。**

首先注意 $\mathbb{C} = \mathbb{R}(i)$，其中 $i$ 是 $x^2 + 1$ 的根。故 $[\mathbb{C} : \mathbb{R}] = 2$。

**关键引理：** $\mathbb{C}$ 没有 $2$ 次扩张。

*证明.* 设 $L / \mathbb{C}$ 为二次扩张。取 $\alpha \in L \setminus \mathbb{C}$，设其极小多项式为 $x^2 + bx + c \in \mathbb{C}[x]$。判别式为 $\Delta = b^2 - 4c \in \mathbb{C}$。

我们断言 $\Delta$ 在 $\mathbb{C}$ 中有平方根。写 $\Delta = re^{i\theta}$（$r \geq 0$），则 $\sqrt{r} e^{i\theta/2}$ 就是 $\Delta$ 的平方根。

故 $x^2 + bx + c = (x - \alpha_1)(x - \alpha_2)$ 其中 $\alpha_1, \alpha_2 = \frac{-b \pm \sqrt{\Delta}}{2} \in \mathbb{C}$，矛盾于 $x^2 + bx + c$ 不可约。$\square$

现在设 $f(z) \in \mathbb{C}[z]$ 为非常数多项式。考虑 $g(z) = f(z) \overline{f(\bar{z})}$（其中 $\overline{f(\bar{z})}$ 表示对 $f$ 取共轭系数再代入 $\bar{z}$）。

$g$ 的系数是实的（因为 $\overline{g(\bar{z})} = g(z)$）。将 $g$ 视为 $\mathbb{R}$ 上的多项式，$g$ 的次数为 $2 \deg f$（偶数）。

但我们换一种方式。由步骤 1，$g$ 的次数如果是奇数就在 $\mathbb{R}$ 中有根。$g$ 的次数是偶数，不能直接应用。

改用以下论证：

设 $f(z) \in \mathbb{C}[z]$ 为非常数多项式。$f$ 的分裂域 $L$ 是 $\mathbb{C}$ 的有限扩张。$[L : \mathbb{C}]$ 整除 $[\mathbb{C}:\mathbb{R}]$ 的某个幂次？不——$L / \mathbb{C}$ 不一定经过 $\mathbb{R}$。

用更直接的方式：$L / \mathbb{C}$ 是有限扩张。因 $\mathbb{C} = \mathbb{R}(i)$，$L / \mathbb{R}$ 也是有限扩张。由 {thm-primitive-element}（在特征 $0$ 上成立），$L = \mathbb{R}(\alpha)$ 对某个 $\alpha$。设 $[\mathbb{R}(\alpha) : \mathbb{R}] = m$。$m$ 的素因子分解中若含有奇素数 $p$，则存在 $p$ 次子扩张，该子扩张上的元素 $\beta$ 的极小多项式是 $\mathbb{R}$ 上 $p$ 次多项式——由步骤 1，$p$ 次多项式在 $\mathbb{R}$ 中有根，故 $\beta \in \mathbb{R}$，矛盾。

因此 $m = 2^k$。因 $[\mathbb{C}:\mathbb{R}] = 2$，$[L:\mathbb{C}] = 2^{k-1}$。若 $k \geq 2$，则 $[L:\mathbb{C}] \geq 2$，$L$ 包含 $\mathbb{C}$ 的二次扩张——但由上面的关键引理，$\mathbb{C}$ 没有二次扩张。

故 $k = 1$，$[L:\mathbb{C}] = 1$，即 $L = \mathbb{C}$。故 $f$ 的所有根都在 $\mathbb{C}$ 中。$\blacksquare$
:::

</ProofToggle>

## 6.5 不可数代数闭域与基数

::: proposition {#prop-algebraic-closure-cardinality}
**命题 6.5.1**

设 $K$ 为无限域。则 $K$ 的代数闭包 $\bar{K}$ 满足 $|\bar{K}| = |K|$。

特别地，$|\overline{\mathbb{Q}}| = \aleph_0$（可数），$|\bar{\mathbb{R}}| = |\mathbb{C}| = 2^{\aleph_0}$（连续统）。
:::

<ProofToggle>

**证明.**

$K[x]$ 是可数个多项式的集合。若 $K$ 可数，则 $K[x]$ 也可数，$K[x]$ 中的每个多项式有有限个根，故 $K$ 的代数闭包是可数个有限集的并，仍可数。故 $|\bar{K}| \leq \aleph_0 = |K|$。

若 $K$ 不可数，令 $\kappa = |K|$。则 $|K[x]| = \kappa$（多项式个数等于基数），每个多项式最多 $\deg f$ 个根，故 $|\bar{K}| \leq \kappa \cdot \aleph_0 = \kappa = |K|$。

另一方面 $\bar{K} \supseteq K$，故 $|\bar{K}| \geq |K|$。$\blacksquare$
:::

</ProofToggle>

::: remark
**注 6.5.2**（$\bar{\mathbb{Q}}$ 的特殊地位）

$\overline{\mathbb{Q}}$ 是 $\mathbb{Q}$ 的代数闭包，它是**可数**的，且是代数数（即 $\mathbb{Q}$ 上代数元）的全体。$\overline{\mathbb{Q}} \cap \mathbb{R}$ 是**实代数数**的集合。这两个域在代数数论中有核心地位。

注意 $\overline{\mathbb{Q}} \subsetneq \mathbb{C}$（因为 $\pi, e \in \mathbb{C}$ 但 $\pi, e \notin \overline{\mathbb{Q}}$——它们是超越数），但 $\mathbb{C}$ 是 $\overline{\mathbb{Q}}$ 的超越扩张。
:::

## 本章要点

1. **代数闭域**等价于没有真代数扩张的域，等价于 $K[x]$ 中每个不可约多项式都是一次。
2. **代数闭包的存在性**依赖 Zorn 引理：取极大代数扩张，证明它是代数闭的。
3. **代数闭包的唯一性**（在同构意义下）依赖嵌入扩张引理和代数闭性。
4. **代数基本定理**是代数闭包理论的精彩应用：$\mathbb{C}$ 是 $\mathbb{R}$ 的代数闭包（同构意义下）。
5. 代数闭包是 Galois 理论的基础对象——Galois 群 $\mathrm{Gal}(\bar{K}/K)$ 的定义需要先固定一个代数闭包。
