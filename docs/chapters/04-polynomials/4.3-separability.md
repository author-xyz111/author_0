# §4.3 根的重数与可分性 {#sec-4-3-separability}

## 学习目标 {#learning-goals}

通过本节学习，你应该能够：

1. 理解形式导数的纯代数本质，能正确计算 $\mathbb{Q}[X]$ 和 $\mathbb{F}_p[X]$ 中多项式的形式导数。
2. 利用 $\gcd(f, f')$ 判别法判断多项式是否有重根，并正确计算根的重数。
3. 理解"不可约多项式在特征零上总是可分的"这一事实的证明逻辑。
4. 在正特征域中构造不可分多项式，并计算可分次数与不可分次数。
5. 理解可分性对 Galois 理论的根本重要性：Galois 对应要求扩张是可分的。

::: intuition 核心思想
[§4.1](/chapters/04-polynomials/4.1-general-theory#thm-root-bound) 告诉我们 $n$ 次多项式至多有 $n$ 个根。但如果某个根"重复出现"呢？就像 $(X - 1)^3 = 0$ 中，$1$ 是三重根。本节引入**形式导数**来精确刻画根的重数，并引出**可分多项式**的概念——它在 [Galois 理论](/chapters/07-galois-groups/) 中扮演核心角色。
:::

## 4.3.1 形式导数 {#formal-derivative}

**定义 4.3.1** {#def-formal-derivative} 设 $K$ 为域，$f(X) = \sum_{i=0}^n a_i X^i \in K[X]$。$f$ 的**形式导数（formal derivative）**定义为：

$$f'(X) = \sum_{i=1}^n i \cdot a_i X^{i-1} = a_1 + 2a_2 X + 3a_3 X^2 + \cdots + n a_n X^{n-1}$$

其中 $i \cdot a_i$ 表示 $a_i$ 在 $K$ 中自加 $i$ 次（即 $\underbrace{a_i + a_i + \cdots + a_i}_{i \text{ 个}}$）。

::: warning 不是微积分中的导数
虽然名字叫"导数"且符号相同，但形式导数是**纯代数定义**，不涉及极限或分析。它是一个纯粹的环运算 $K[X] \to K[X]$。之所以叫"导数"，是因为它满足与微积分中导数完全相同的代数规则。
:::

**命题 4.3.2** {#prop-derivative-rules} 形式导数满足以下代数规则：

**(i)** 线性：$(af + bg)' = af' + bg'$（$a, b \in K$）。

**(ii)** Leibniz 法则：$(fg)' = f'g + fg'$。

**(iii)** 幂法则：$(f^n)' = n f^{n-1} f'$。

<ProofToggle>
<summary>**证明**</summary>

**(i)** 直接由定义，$(\sum a_i X^i + \sum b_i X^i)' = \sum i(a_i + b_i) X^{i-1} = \sum i a_i X^{i-1} + \sum i b_i X^{i-1}$。

**(ii)** 设 $f = \sum a_i X^i$，$g = \sum b_j X^j$。则 $fg = \sum_k c_k X^k$，$c_k = \sum_{i+j=k} a_i b_j$。

$(fg)' = \sum_k k c_k X^{k-1} = \sum_k k \left(\sum_{i+j=k} a_i b_j\right) X^{k-1}$

$f'g + fg' = \left(\sum_i i a_i X^{i-1}\right)\left(\sum_j b_j X^j\right) + \left(\sum_i a_i X^i\right)\left(\sum_j j b_j X^{j-1}\right)$

$= \sum_{i,j} i a_i b_j X^{i+j-1} + \sum_{i,j} j a_i b_j X^{i+j-1} = \sum_{i,j} (i+j) a_i b_j X^{i+j-1}$

$= \sum_k \left(\sum_{i+j=k} (i+j) a_i b_j\right) X^{k-1} = \sum_k k \left(\sum_{i+j=k} a_i b_j\right) X^{k-1}$

两者相等。

**(iii)** 对 $n$ 归纳。$n = 1$ 时 $f' = f'$（显然）。$n \geq 2$ 时：$(f^n)' = (f^{n-1} \cdot f)' = (f^{n-1})' f + f^{n-1} f' = (n-1)f^{n-2} f' \cdot f + f^{n-1} f' = (n-1)f^{n-1} f' + f^{n-1} f' = n f^{n-1} f'$。 $\square$

</ProofToggle>

**引理 4.3.3** {#lem-derivative-cyclotomic} 设 $n \geq 1$，$\operatorname{char}(K) = 0$ 或 $\operatorname{char}(K) \nmid n$。则 $(X^n - 1)' = n X^{n-1} \neq 0$。

<ProofToggle>
<summary>**证明**</summary>

$(X^n - 1)' = n X^{n-1} - 0 = n X^{n-1}$。由条件 $n \cdot 1_K \neq 0$（因为 $\operatorname{char}(K) = 0$ 或 $\operatorname{char}(K) \nmid n$），所以 $n X^{n-1} \neq 0$。 $\square$

</ProofToggle>

## 4.3.2 根的重数 {#multiplicity}

**定义 4.3.4** {#def-multiplicity} 设 $f \in K[X]$，$\alpha$ 是 $f$ 的一个根（在某个扩域中）。$\alpha$ 的**重数（multiplicity）**是最大的正整数 $m$ 使得 $(X - \alpha)^m \mid f$。

- 若 $m = 1$，称 $\alpha$ 是**单根（simple root）**；
- 若 $m \geq 2$，称 $\alpha$ 是**重根（multiple root）**。

**定理 4.3.5**（重根判别准则）{#thm-multiple-root-criterion} 设 $f \in K[X]$，$\deg(f) \geq 1$，$\alpha$ 是 $f$ 的根（在某个代数闭包 $\bar{K}$ 中）。设 $\alpha$ 的重数为 $m$。则：

**(i)** $f(X) = (X - \alpha)^m g(X)$，$g(\alpha) \neq 0$。

**(ii)** $f'(X) = m(X - \alpha)^{m-1} g(X) + (X - \alpha)^m g'(X)$。

**(iii)** 若 $\operatorname{char}(K) = 0$ 或 $\operatorname{char}(K) \nmid m$，则 $\alpha$ 是 $f'$ 的重数为 $m-1$ 的根。

**(iv)** $\alpha$ 是 $f$ 的重根 $\Leftrightarrow$ $f(\alpha) = 0$ 且 $f'(\alpha) = 0$（假设 $\operatorname{char}(K) = 0$）。

<ProofToggle>
<summary>**证明（完整）**</summary>

**(i)** 由重数定义直接得到。

**(ii)** 对 (i) 的 $f(X) = (X - \alpha)^m g(X)$ 应用 Leibniz 法则（{prop-derivative-rules}(ii)）：

$$f'(X) = m(X - \alpha)^{m-1} g(X) + (X - \alpha)^m g'(X)$$

**(iii)** 由 (ii)：$f'(X) = (X - \alpha)^{m-1} [mg(X) + (X - \alpha) g'(X)]$。令 $h(X) = mg(X) + (X - \alpha) g'(X)$，则 $f' = (X - \alpha)^{m-1} h$。需要验证 $h(\alpha) \neq 0$：

$h(\alpha) = m \cdot g(\alpha) + 0 \cdot g'(\alpha) = m \cdot g(\alpha)$

由假设 $\operatorname{char}(K) \nmid m$，故 $m \neq 0$ in $K$。由 (i) $g(\alpha) \neq 0$。因此 $h(\alpha) = m \cdot g(\alpha) \neq 0$。

这说明 $(X - \alpha)^{m-1}$ 恰好整除 $f'$（不多不少），即 $\alpha$ 是 $f'$ 的重数为 $m-1$ 的根。

**(iv)** ($\Rightarrow$) $\alpha$ 重根意味着 $m \geq 2$。由 (iii)，$\alpha$ 是 $f'$ 的重数为 $m - 1 \geq 1$ 的根，即 $f'(\alpha) = 0$。

($\Leftarrow$) $f(\alpha) = 0$ 表明 $\alpha$ 是 $f$ 的根，设重数为 $m \geq 1$。若 $m = 1$（单根），由 (iii)（取 $m = 1$）$\alpha$ 不是 $f'$ 的根（$h(\alpha) = 1 \cdot g(\alpha) \neq 0$），与 $f'(\alpha) = 0$ 矛盾。因此 $m \geq 2$。 $\square$

</ProofToggle>

::: important 可分性的直觉
{thm-multiple-root-criterion}(iv) 给出了一个实用的判别法：在特征零域上，$\alpha$ 是重根当且仅当 $f$ 和 $f'$ **同时** 在 $\alpha$ 处为零。这等价于说：$f$ 和 $f'$ 有公共根，即 $\gcd(f, f') \neq 1$。这个判别法在实际计算中非常有用，因为 $\gcd(f, f')$ 可以通过 [Euclid 算法](/chapters/04-polynomials/4.1-general-theory#thm-division-algorithm) 高效计算。
:::

**例 4.3.6** {#ex-multiplicity} 考虑 $f(X) = X^3 - 3X + 2 \in \mathbb{Q}[X]$。

$f'(X) = 3X^2 - 3 = 3(X-1)(X+1)$

$f(1) = 1 - 3 + 2 = 0$，$f'(1) = 0$。所以 $1$ 是重根。实际分解：$f(X) = (X - 1)^2(X + 2)$，$1$ 是二重根。

$\gcd(f, f') = \gcd(X^3 - 3X + 2, 3X^2 - 3)$。用 Euclid 算法：$X^3 - 3X + 2 = \frac{X}{3}(3X^2 - 3) + (-2X + 2)$，$3X^2 - 3 = \frac{-3X}{2}(-2X + 2) + (-3X + 3)$，$\ldots$ 最终 $\gcd = X - 1$（首一化后）。$X - 1$ 正好对应了重根 $1$。

::: example 在 $\mathbb{F}_p$ 上计算 gcd {#ex-gcd-charp}
考虑 $f(X) = X^4 + 1 \in \mathbb{F}_2[X]$。

$f'(X) = 4X^3 = 0$（因为 $\operatorname{char}(\mathbb{F}_2) = 2$，$4 = 0$）。

因此 $\gcd(f, f') = \gcd(f, 0) = f$，判别法告诉我们 $f$ 有重根（在其分裂域中）。

实际分解：在 $\mathbb{F}_2[X]$ 中 $X^4 + 1 = (X^2 + 1)^2 = (X + 1)^4$，所以 $1$ 是四重根。
:::

::: example 无重根的判别 {#ex-no-multiple-root}
考虑 $f(X) = X^3 - 2 \in \mathbb{Q}[X]$。

$f'(X) = 3X^2$。$\gcd(X^3 - 2, 3X^2) = 1$（因为 $3X^2$ 的根只有 $0$，而 $f(0) = -2 \neq 0$）。

因此 $f$ 无重根。这与我们知道 $X^3 - 2$ 的三个根 $\sqrt[3]{2}, \omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}$（其中 $\omega$ 是三次单位根）互不相同一致。
:::

::: warning "f' = 0" 不意味着多项式不可分 {#warn-fprime-zero}
注意一个重要区别：

- **不可约**多项式 $f$ 满足 $f' = 0$ $\Longrightarrow$ $f$ 不可分（由 {thm-separable-polynomial}(ii)）。
- **可约**多项式 $f$ 满足 $f' = 0$ $\Longrightarrow$ $f$ 的某个不可约因子不可分，但 $f$ 本身可能是若干个可分不可约多项式的"乘积的 $p$ 次幂"。

例如 $f(X) = (X^2 + X + 1)^3 \in \mathbb{F}_3[X]$。则 $f' = 3(X^2+X+1)^2(2X+1) = 0$。但 $X^2 + X + 1$ 在 $\mathbb{F}_3$ 上不可约且可分（可验证 $f'(X) = 2X + 1 \neq 0$），所以 $f$ 的唯一不可约因子 $X^2 + X + 1$ 是可分的。$f$ 本身可分，尽管 $f' = 0$。
:::

## 4.3.3 可分多项式 {#separable-polynomial}

**定义 4.3.7** {#def-separable-polynomial} 设 $f \in K[X]$ 是不可约多项式。

- 称 $f$ 是**可分的（separable）**：如果 $f$ 在其分裂域中的所有根都是单根。
- 称 $f$ 是**不可分的（inseparable）**：如果 $f$ 在其分裂域中至少有一个重根。

对一般的多项式 $f$（不必不可约），称 $f$ **可分**如果 $f$ 的每个不可约因子都可分。

**定理 4.3.8** {#thm-separable-polynomial} 设 $K$ 为域，$f \in K[X]$ 不可约。

**(i)** 若 $\operatorname{char}(K) = 0$，则 $f$ 总是可分的。

**(ii)** 若 $\operatorname{char}(K) = p > 0$，则 $f$ 不可分 $\Leftrightarrow$ $f(X) = g(X^p)$ 对某个 $g \in K[X]$。

<ProofToggle>
<summary>**证明（完整）**</summary>

**(i)** 设 $\operatorname{char}(K) = 0$，$f$ 不可约，$\deg(f) = n \geq 1$。$f' \neq 0$（因为 $f'$ 的首项系数是 $n \cdot a_n \neq 0$ 在特征零中）。因此 $\deg(f') = n - 1 < n = \deg(f)$。因为 $f$ 不可约，$f$ 的只有平凡因子。$\gcd(f, f')$ 整除 $f$，所以 $\gcd(f, f') = 1$ 或 $\gcd(f, f') = f$（的相伴元）。但 $\gcd(f, f') \mid f'$ 且 $\deg(f') < \deg(f)$，故 $\gcd(f, f') = 1$。

由 {thm-multiple-root-criterion}(iv) 的推广（$f$ 与 $f'$ 互素当且仅当 $f$ 无重根），$f$ 的所有根都是单根。

**(ii)** ($\Leftarrow$) 设 $f(X) = g(X^p)$，$g(Y) = \sum_{i=0}^m b_i Y^i$，$f(X) = \sum_{i=0}^m b_i X^{pi}$。则 $f'(X) = \sum_{i=1}^m (pi) b_i X^{pi - 1} = 0$（因为 $\operatorname{char}(K) = p$，$pi = 0$ in $K$）。由于 $f' = 0$，$\gcd(f, f') = f \neq 1$，故 $f$ 有重根。

($\Rightarrow$) 设 $f$ 不可分。由 ($\Leftarrow$) 的逆否，需证 $f(X) = g(X^p)$。设 $f(X) = \sum_{i=0}^n a_i X^i$，$f'(X) = \sum_{i=1}^n i a_i X^{i-1} = 0$。这意味着 $i \cdot a_i = 0$ 对所有 $i \geq 1$。因此：对所有 $i$ 不被 $p$ 整除，$a_i = 0$。即 $f(X) = \sum_{j=0}^m a_{pj} X^{pj}$，取 $g(Y) = \sum_{j=0}^m a_{pj} Y^j$。 $\square$

</ProofToggle>

::: important 完美域与不完美域
{thm-separable-polynomial}(i) 表明**特征零域上的不可约多项式总是可分的**。这是为什么在经典 Galois 理论（处理 $\mathbb{Q}$ 和 $\mathbb{C}$）中可分性问题可以忽略。

但在正特征下，不可分多项式确实存在：例如在 $\mathbb{F}_p(T)$ 上，$X^p - T$ 不可约（由 Eisenstein 判据或直接验证）但不可分（$f'(X) = pX^{p-1} = 0$）。

一个域 $K$ 称为**完美域（perfect field）**，如果 $K[X]$ 中每个不可约多项式都是可分的。特征零的域总是完美的；特征 $p$ 的域 $K$ 是完美的当且仅当 $K^p = K$（即 Frobenius 映射是满射）。$\mathbb{F}_q$（有限域）总是完美的。
:::

::: proposition 不可分不可约的判据 {#prop-inseparable-criterion}
设 $K$ 为特征 $p > 0$ 的域，$a \in K$。若 $a \notin K^p$（即 $a$ 在 $K$ 中没有 $p$ 次根），则 $f(X) = X^p - a$ 在 $K[X]$ 中不可约。

**证明思路**：设 $\alpha$ 是 $f$ 在某个扩域中的根，则 $\alpha^p = a$，从而 $f(X) = X^p - \alpha^p = (X - \alpha)^p$。若 $f = gh$ 是 $K[X]$ 中的非平凡分解，则在分裂域中 $g = (X - \alpha)^r$，$h = (X - \alpha)^{p-r}$，$0 < r < p$。但 $g \in K[X]$ 意味着 $g$ 的系数都在 $K$ 中。特别地，$g$ 的首项系数为 $1$，常数项为 $(-\alpha)^r \in K$。由 $\gcd(r, p) = 1$（$p$ 是素数，$0 < r < p$），存在 $s, t$ 使得 $rs + pt = 1$，从而 $\alpha = \alpha^{rs+pt} = (\alpha^r)^s \cdot (\alpha^p)^t = ((-\alpha)^r \cdot (-1)^r)^s \cdot a^t \in K$。但这意味着 $a = \alpha^p \in K^p$，矛盾。 $\square$
:::

::: remark
在特征零中，每个不可约多项式都是可分的（{thm-separable-polynomial}(i)）。因此"不可分不可约"现象只在正特征中出现。上面的命题给出了一类典型的不可分不可约多项式：$X^p - a$（$a \notin K^p$）。这类多项式在 Galois 理论中反复出现——例如 Artin–Schreier 理论（见 [§9.1](/chapters/09-solvability/9.1-solvable-groups)）。
:::

::: example 不可分多项式的构造 {#ex-inseparable}
考虑 $K = \mathbb{F}_2(T)$（$T$ 为超越元），$f(X) = X^2 - T \in K[X]$。

**不可约性**：$f$ 在 $K[X]$ 中不可约。为什么？若 $f$ 可约，则有根 $\alpha \in K$ 使得 $\alpha^2 = T$。但 $K = \mathbb{F}_2(T)$ 的元素是有理函数 $p(T)/q(T)$，其平方为 $p(T)^2/q(T)^2$。由于 $\mathbb{F}_2$ 上 $a^2 = a$，分子分母的各项幂次都翻倍，不可能等于 $T$（奇次幂项不存在）。因此 $f$ 不可约。

**不可分性**：$f'(X) = 2X = 0$（$\operatorname{char} = 2$）。由 {thm-separable-polynomial}(ii)，$f$ 不可分。

**直觉**：$f(X) = X^2 - T = X^2 + T = (X + T^{1/2})^2$（在分裂域中），所以 $T^{1/2}$ 是重根。不可分的本质是"$p$ 次扩张的 $p$ 个根全部坍缩为一个"。

**Galois 群的退化**：$L = K(T^{1/2})$ 的 $K$-自同构 $\sigma$ 必须满足 $\sigma(T^{1/2})^2 = \sigma(T) = T$，即 $\sigma(T^{1/2}) = T^{1/2}$（唯一解，因为 $(\pm T^{1/2})^2 = T$ 在特征 2 中 $\pm$ 无意义）。因此 $\operatorname{Gal}(L/K) = \{1\}$。$[L:K] = 2$ 但 $|\operatorname{Gal}(L/K)| = 1$，度数与 Galois 群阶不等。**这正是不可分扩张的根本困难**（见 [§5.2](/chapters/05-splitting-fields/5.2-normal-extensions) 和 [§8.2](/chapters/08-galois-correspondence/8.2-galois-extensions)）。
:::

::: example 不可分次数的计算 {#ex-insep-degree}
考虑 $K = \mathbb{F}_2(T)$，$f(X) = X^4 + T \in K[X]$。

$f(X) = (X^2)^2 + T = (X^2)^2 + T$。注意 $f(X) = g(X^2)$，$g(Y) = Y^2 + T$。$g'(Y) = 2Y = 0$，所以 $g$ 也不可分。进一步 $g(Y) = h(Y^2)$，$h(Z) = Z + T$。

因此 $f(X) = h(X^4) = X^4 + T$，其中 $h(Z) = Z + T$ 是可分的（$\deg = 1$，单根）。

由 {def-separable-degree}：$f = h(X^{2^2})$，$e = 2$，$p^e = 4$。

- **不可分次数** $p^e = 4$
- **可分次数** $\deg(h) = 1$
- $f$ 有一个根 $\alpha = T^{1/4}$，它是四重根（在分裂域中）

检验：$T^{1/4}$ 的极小多项式是 $X^4 + T$。$[K(T^{1/4}):K] = 4$，但可分闭包（等于 $K$ 本身，因为 $h$ 已经分裂）只贡献了度 1。
:::

::: example 正特征下可分与不可分的对比 {#ex-charp-comparison}
对比以下三个多项式在 $\mathbb{F}_2(T)$ 上的行为：

| 多项式 | $f'$ | 不可约？ | 可分？ | 理由 |
|---|---|---|---|---|
| $X^2 + X + 1$ | $1$ | $\mathbb{F}_2$ 上不可约 | 可分 | $f' = 1 \neq 0$ |
| $X^2 + T$ | $0$ | $\mathbb{F}_2(T)$ 上不可约 | **不可分** | $f' = 0$ |
| $(X^2 + X + 1)^2$ | $0$ | 可约 | **可分**（每个不可约因子可分） | 不可约因子 $X^2+X+1$ 的导数为 $1$ |

第三行说明：可约多项式 $f' = 0$ 不蕴含 $f$ 不可分，只说明 $f$ 的某个不可约因子**可能**不可分——但如果所有不可约因子都可分，$f$ 仍可分。
:::

## 4.3.4 可分扩张 {#separable-extensions}

**定义 4.3.9** {#def-separable-element} 设 $L/K$ 是[域扩张](/chapters/03-fields/3.2-basic-extensions#def-extension)，$\alpha \in L$ 是代数元。称 $\alpha$ 在 $K$ 上**可分**，如果 $\alpha$ 的[极小多项式](/chapters/03-fields/3.3-algebraic-elements#def-minimal-polynomial) $\min(K, \alpha)$ 是可分多项式。

**定义 4.3.10** {#def-separable-extension} 称域扩张 $L/K$ 是**可分扩张**，如果 $L$ 中每个元素在 $K$ 上都是可分的。

**定理 4.3.11** {#thm-char0-separable} 若 $\operatorname{char}(K) = 0$，则每个代数扩张都是可分扩张。

<ProofToggle>
<summary>**证明**</summary>

设 $\alpha \in L$ 是代数元。则 $\min(K, \alpha)$ 是 $K[X]$ 中的不可约多项式。由 {thm-separable-polynomial}(i)，在特征零上不可约多项式总是可分的。因此 $\alpha$ 在 $K$ 上可分。由于 $\alpha$ 是任意的，$L/K$ 可分。 $\square$

</ProofToggle>

::: warning 正特征的情况
{thm-char0-separable} 对正特征域不成立。例如 $K = \mathbb{F}_p(T)$，$L = K(T^{1/p})$。$T^{1/p}$ 的极小多项式是 $X^p - T$，它不可分（$f' = 0$）。因此 $L/K$ 是不可分扩张。这种现象在 [Galois 理论](/chapters/07-galois-groups/) 中需要特殊处理。
:::

**命题 4.3.12** {#prop-separable-tower} 设 $L/M/K$ 是域扩张的塔。若 $L/M$ 和 $M/K$ 都可分，则 $L/K$ 可分。

<ProofToggle>
<summary>**证明**</summary>

设 $\alpha \in L$。$\alpha$ 在 $M$ 上的极小多项式 $g(X) = \min(M, \alpha)$ 可分。设 $g(X) = \sum_{i=0}^d c_i X^i$，$c_i \in M$。令 $F = K(c_0, c_1, \ldots, c_d) \subseteq M$。

$g(X) \in F[X]$，且 $g$ 仍然是 $\alpha$ 在 $F$ 上的极小多项式（因为 $F \subseteq M$，$\min(F, \alpha) \mid g$，但 $g$ 不可约于 $M[X]$ 也蕴含它不可约于 $F[X]$——因为 $g$ 的任何 $F[X]$ 中的非平凡分解也会给出 $M[X]$ 中的非平凡分解）。

因为 $M/K$ 可分，每个 $c_i$ 在 $K$ 上可分。由此 $F/K$ 是有限可分扩张。$\alpha$ 在 $F$ 上可分。由可分性的传递性质，$\alpha$ 在 $K$ 上可分。 $\square$

</ProofToggle>

## 4.3.5 本原元素定理（预告） {#primitive-element-preview}

::: important 前瞻
可分性的最重要推论之一是**本原元素定理**：

> 设 $L/K$ 是**有限可分扩张**。则存在 $\alpha \in L$ 使得 $L = K(\alpha)$。

即 $L$ 可以由**单个元素**生成。证明需要利用可分性来避免根的"碰撞"，完整证明将在 [§5.1](/chapters/05-splitting-fields/5.1-splitting-fields) 给出。

本原元素定理大大简化了 Galois 理论：有限可分扩张可以表示为 $K[X]/(f)$ 的形式，其中 $f$ 是不可约可分多项式。
:::

## 4.3.6 不可分性的结构 {#inseparability-structure}

**命题 4.3.13** {#prop-pure-inseparable} 设 $\operatorname{char}(K) = p > 0$，$f \in K[X]$ 不可约且不可分。则 $f(X) = h(X^{p^e})$，其中 $h \in K[X]$ 是**可分**不可约多项式，$e \geq 1$ 是**不可分次数**。

<ProofToggle>
<summary>**证明**</summary>

由 {thm-separable-polynomial}(ii)，$f(X) = g(X^p)$ 对某个 $g \in K[X]$。$g$ 是不可约的（否则 $f$ 可约）。若 $g$ 可分，则取 $h = g$，$e = 1$ 即可。若 $g$ 不可分，递归应用：$g(X) = g_1(X^p)$，$f(X) = g_1(X^{p^2})$。因为 $\deg$ 每次除以 $p$，这个过程必在有限步终止。 $\square$

</ProofToggle>

**定义 4.3.14** {#def-separable-degree} 设 $\alpha$ 是 $K$ 上的代数元，$\min(K, \alpha) = h(X^{p^e})$（$h$ 可分，$e \geq 0$）。称 $p^e$ 为 $\alpha$ 的**不可分次数（inseparability degree）**，$\deg(h)$ 为 $\alpha$ 的**可分次数（separable degree）**。

::: important 关键区分
可分性理论中有多组概念容易混淆，必须严格区分：

| 概念 | 对象 | 含义 |
|---|---|---|
| **可分多项式** | $f \in K[X]$ 不可约 | $f$ 在分裂域中所有根互异 |
| **可分元素** | $\alpha \in L$ 代数元 | $\min(K, \alpha)$ 是可分多项式 |
| **可分扩张** | $L/K$ | $L$ 中**每个**元素都在 $K$ 上可分 |
| **完美域** | $K$ | $K[X]$ 中**每个**不可约多项式都可分 |

它们之间的关系：
- $K$ 是完美域 $\Leftrightarrow$ $K$ 上**每个**代数扩张都是可分扩张。
- $L/K$ 可分 $\Leftarrow$ $L/K$ 的**每个**中间域都是完美域（但逆不成立）。
- 特征零的域**自动**完美，正特征域**可能**不完美。
:::

::: example 分圆多项式的可分性 {#ex-cyclotomic-separable}
分圆多项式 $\Phi_n(X)$ 在 $\mathbb{Q}$ 上总是可分的（因为 $\mathbb{Q}$ 特征零，所有不可约多项式可分）。但 $\Phi_n$ 在 $\mathbb{F}_p$ 上的行为取决于 $p$ 和 $n$ 的关系：

- 若 $p \nmid n$，则 $\Phi_n$ 在 $\mathbb{F}_p$ 上也无重根（可分的）。
- 若 $p \mid n$，则 $\Phi_n$ 在 $\mathbb{F}_p$ 上可能有重根。

例如 $\Phi_2(X) = X + 1$ 在 $\mathbb{F}_2$ 上：$\Phi_2(1) = 1 + 1 = 0$，$\Phi_2'(X) = 1 \neq 0$，所以 $1$ 是单根。但 $\Phi_4(X) = X^2 + 1$ 在 $\mathbb{F}_2$ 上：$\Phi_4(1) = 0$，$\Phi_4'(X) = 2X = 0$，所以 $1$ 是重根（实际分解：$X^2 + 1 = (X+1)^2$）。
:::

::: warning 可分性是关于多项式的，不是关于域的
一个常见误区是说"域 $K$ 是可分的"。严格来说，可分性是关于**扩张**或**多项式**的属性，不是关于单个域的。正确的说法是：

- "扩张 $L/K$ 是可分的" ✓
- "多项式 $f$ 在 $K$ 上是可分的" ✓
- "域 $K$ 是可分的" ✗（应该说"$K$ 是完美域"）
:::

::: important 可分性对 Galois 理论的根本重要性
为什么我们要在第 4 章就详细讨论可分性？因为它直接决定了 Galois 理论是否可行：

**Galois 对应的核心假设**：$L/K$ 是**有限 Galois 扩张**，即 $L/K$ 既正规又可分。只有在可分条件下，才有：

$$|\operatorname{Gal}(L/K)| = [L:K]$$

如果没有可分性，Galois 群的阶会**严格小于**扩张度数（如 {ex-inseparable} 中 $|\operatorname{Gal}(L/K)| = 1$ 但 $[L:K] = 2$），Galois 对应就会坍缩。

因此，**可分性不是技术条件，而是 Galois 对应的生命线**。详细讨论见 [§8.2](/chapters/08-galois-correspondence/8.2-galois-extensions)。
:::

::: tip 本节知识检验
**自测题：**

1. 计算 $f(X) = X^5 - 5X^3 + 4X \in \mathbb{Q}[X]$ 的 $f'$ 和 $\gcd(f, f')$。$f$ 有重根吗？

2. 在 $\mathbb{F}_3[X]$ 中，$f(X) = X^9 - X$。计算 $f'$，并说明 $f$ 是否可分。

3. 设 $K = \mathbb{F}_2(T)$，$f(X) = X^8 + T$。写出 $f = h(X^{2^e})$ 的形式，并给出可分次数和不可分次数。

4. 判断正误："$X^3 + X + 1 \in \mathbb{F}_2[X]$ 不可约，所以它是可分的。"

5. 为什么 $[L:K] = |\operatorname{Gal}(L/K)|$ 在 $L/K$ 不可分时可能不成立？

**答案要点：**

1. $f' = 5X^4 - 15X^2 + 4$。$f = X(X^4 - 5X^2 + 4) = X(X^2-1)(X^2-4) = X(X-1)(X+1)(X-2)(X+2)$。所有根互异，$\gcd(f, f') = 1$，无重根。

2. $f' = 9X^8 - 1 = -1 = 2 \neq 0$（因为 $9 = 0$ in $\mathbb{F}_3$）。$f = X^9 - X = X(X^8 - 1)$。$X^8 - 1$ 的导数为 $8X^7 = 2X^7 \neq 0$。$f$ 可分（所有不可约因子可分）。

3. $f(X) = X^8 + T = (X^2)^4 + T$。令 $g(Y) = Y^4 + T$，$g(Y) = (Y^2)^2 + T$，$h(Z) = Z^2 + T$。所以 $f = h(X^8) = h(X^{2^3})$。可分次数 $= \deg(h) = 2$，不可分次数 $= 2^3 = 8$。

4. **正确**。$\mathbb{F}_2$ 是有限域，因此是完美域。完美域上所有不可约多项式都可分。

5. 因为不可分扩张中，$\operatorname{Gal}(L/K)$ 中的自同构不足以"看到"所有嵌入——不可分根坍缩为一个，无法通过自同构区分。
:::
