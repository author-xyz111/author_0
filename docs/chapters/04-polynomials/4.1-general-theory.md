# §4.1 多项式的一般理论 {#sec-4-1-general-theory}

::: intuition 核心思想
多项式环 $K[X]$ 是从域 $K$ 出发，通过引入一个"形式变元" $X$ 构造的新环。它的美妙之处在于：$K[X]$ 继承了 $K$ 的许多好性质（整环、Euclid 整环、PID、UFD），同时引入了代数结构的核心概念——不可约分解。多项式的不可约分解就是"算术基本定理"在任意域上的推广。
:::

## 4.1.1 多项式环的构造 {#def-polynomial-ring}

在[§2.3](/chapters/02-rings/2.3-polynomial-rings)中，我们已经定义了环上的多项式环。现在我们回顾并深化这个构造。

<ProofToggle>
<summary>**回顾：多项式环的严格构造**</summary>

给定一个交换环 $R$，多项式环 $R[X]$ 定义为**系数在 $R$ 中、只有有限多项非零的序列**的集合：

$$R[X] = \{(a_0, a_1, a_2, \ldots) \mid a_i \in R,\ a_i = 0 \text{ 对几乎所有 } i\}$$

加法按分量定义：

$$(a_0, a_1, \ldots) + (b_0, b_1, \ldots) = (a_0 + b_0, a_1 + b_1, \ldots)$$

乘法定义为 **Cauchy 乘积**：

$$(a_0, a_1, \ldots) \cdot (b_0, b_1, \ldots) = (c_0, c_1, \ldots), \quad c_n = \sum_{i+j=n} a_i b_j$$

我们用 $X$ 表示序列 $(0, 1, 0, 0, \ldots)$，用 $X^n$ 表示 $(0, \ldots, 0, 1, 0, \ldots)$（第 $n$ 位为 $1$）。于是每个多项式可唯一地写为：

$$f = a_n X^n + a_{n-1} X^{n-1} + \cdots + a_1 X + a_0 = \sum_{i=0}^{n} a_i X^i$$

其中 $a_i \in R$。

</ProofToggle>

::: tip 记号约定
本书中，$K$ 始终表示一个**域**。$K[X]$ 表示 $K$ 上关于单变元 $X$ 的多项式环。对于 $f \in K[X] \setminus \{0\}$，我们用以下记号：
- $\deg(f)$：$f$ 的**次数**（最高次非零项的指数）
- $\operatorname{lc}(f)$：$f$ 的**首项系数**（最高次项的系数）
- $f$ 是**首一的（monic）**：如果 $\operatorname{lc}(f) = 1$
:::

## 4.1.2 次数的基本性质 {#deg-properties}

**命题 4.1.1** {#prop-degree} 设 $f, g \in K[X]$。则：

**(i)** $\deg(fg) = \deg(f) + \deg(g)$。

**(ii)** $\deg(f + g) \leq \max(\deg(f), \deg(g))$，等号在 $\deg(f) \neq \deg(g)$ 时成立。

<ProofToggle>
<summary>**证明**</summary>

**(i)** 设 $f = a_m X^m + \cdots + a_0$（$a_m \neq 0$，$\deg f = m$），$g = b_n X^n + \cdots + b_0$（$b_n \neq 0$，$\deg g = n$）。则 $fg$ 的最高次项为 $a_m b_n X^{m+n}$。由于 $K$ 是域（从而是整环），$a_m \neq 0$ 且 $b_n \neq 0$ 推出 $a_m b_n \neq 0$。因此 $\deg(fg) = m + n$。

**(ii)** $f + g$ 的第 $i$ 项系数为 $a_i + b_i$。当 $i > \max(m, n)$ 时 $a_i + b_i = 0$，因此 $\deg(f + g) \leq \max(m, n)$。当 $m \neq n$ 时，不妨设 $m > n$，则 $f + g$ 的第 $m$ 项系数为 $a_m + 0 = a_m \neq 0$，故 $\deg(f + g) = m = \max(m, n)$。 $\square$

</ProofToggle>

**推论 4.1.2** {#cor-integral-domain} $K[X]$ 是整环。

<ProofToggle>
<summary>**证明**</summary>

设 $f, g \in K[X]$ 且 $fg = 0$。若 $f \neq 0$ 且 $g \neq 0$，则由 {prop-degree}(i)：$\deg(fg) = \deg(f) + \deg(g) \geq 0$，即 $fg \neq 0$，矛盾。因此 $f = 0$ 或 $g = 0$。 $\square$

</ProofToggle>

## 4.1.3 带余除法（Euclid 算法） {#division-algorithm}

**定理 4.1.3**（带余除法）{#thm-division-algorithm} 设 $K$ 为域，$f, g \in K[X]$，$g \neq 0$。则存在**唯一的** $q, r \in K[X]$ 使得：

$$f = qg + r, \quad \deg(r) < \deg(g) \text{ 或 } r = 0.$$

<ProofToggle>
<summary>**证明（完整）**</summary>

**存在性.** 对 $\deg(f)$ 进行**强归纳法**。

**基始.** 若 $\deg(f) < \deg(g)$，取 $q = 0$，$r = f$ 即可。

**归纳步.** 设 $\deg(f) \geq \deg(g)$。令 $\deg(f) = m$，$\deg(g) = n$，$m \geq n$。记 $\operatorname{lc}(f) = a_m$，$\operatorname{lc}(g) = b_n$。

构造多项式：
$$f_1 = f - \frac{a_m}{b_n} X^{m-n} \cdot g$$

因为 $\frac{a_m}{b_n} X^{m-n} \cdot g$ 的首项为 $\frac{a_m}{b_n} \cdot b_n X^m = a_m X^m$，与 $f$ 的首项抵消，所以 $\deg(f_1) < m$。

由归纳假设，存在 $q_1, r \in K[X]$ 使得 $f_1 = q_1 g + r$，其中 $\deg(r) < \deg(g)$ 或 $r = 0$。

于是 $f = f_1 + \frac{a_m}{b_n} X^{m-n} g = \left(q_1 + \frac{a_m}{b_n} X^{m-n}\right) g + r$，取 $q = q_1 + \frac{a_m}{b_n} X^{m-n}$ 即可。

**唯一性.** 设 $f = q_1 g + r_1 = q_2 g + r_2$，则 $(q_1 - q_2)g = r_2 - r_1$。若 $q_1 \neq q_2$，则 $\deg((q_1 - q_2)g) = \deg(q_1 - q_2) + \deg(g) \geq \deg(g)$，但 $\deg(r_2 - r_1) < \deg(g)$，矛盾。故 $q_1 = q_2$，从而 $r_1 = r_2$。 $\square$

</ProofToggle>

**定义 4.1.4** {#def-divisibility} 设 $f, g \in K[X]$。
- 称 $g$ **整除** $f$（记 $g \mid f$）：如果存在 $q \in K[X]$ 使得 $f = qg$。
- 称 $f$ 是 $g$ 的**倍式**，$g$ 是 $f$ 的**因式（因子）**。

**推论 4.1.5** {#cor-root-factor} 设 $f \in K[X]$，$\alpha \in K$。则 $f(\alpha) = 0$ 当且仅当 $(X - \alpha) \mid f$。

<ProofToggle>
<summary>**证明**</summary>

对 $f$ 除以 $(X - \alpha)$：$f = q(X - \alpha) + r$，其中 $r \in K$（因为 $\deg(r) < 1$）。代入 $X = \alpha$：$f(\alpha) = q(\alpha) \cdot 0 + r = r$。因此 $f(\alpha) = 0 \Leftrightarrow r = 0 \Leftrightarrow (X - \alpha) \mid f$。 $\square$

</ProofToggle>

## 4.1.4 最大公因子与 Euclid 环 {#gcd}

**定义 4.1.6** {#def-gcd} 设 $f, g \in K[X]$ 不全为零。$f$ 与 $g$ 的**最大公因子（GCD）**是一个首一多项式 $d \in K[X]$，满足：
1. $d \mid f$ 且 $d \mid g$；
2. 若 $e \mid f$ 且 $e \mid g$，则 $e \mid d$。

**定理 4.1.7**（GCD 的存在性与 Bézout 恒等式）{#thm-gcd-bezout} 设 $f, g \in K[X]$ 不全为零。则：
**(i)** 最大公因子 $\gcd(f, g)$ 存在且唯一。
**(ii)** 存在 $u, v \in K[X]$ 使得：

$$uf + vg = \gcd(f, g).$$

<ProofToggle>
<summary>**证明（完整）**</summary>

**存在性.** 考虑集合 $S = \{af + bg \mid a, b \in K[X],\ af + bg \neq 0\}$。$S \neq \emptyset$（取 $a = 1$，$b = 0$ 时 $f \in S$，或 $a = 0$，$b = 1$ 时 $g \in S$）。

在 $S$ 中取一个**次数最小**的多项式 $d = u_0 f + v_0 g$。

**断言.** $d \mid f$ 且 $d \mid g$。

对 $f$ 除以 $d$：$f = qd + r$，$\deg(r) < \deg(d)$ 或 $r = 0$。则 $r = f - qd = f - q(u_0 f + v_0 g) = (1 - qu_0)f + (-qv_0)g$。若 $r \neq 0$，则 $r \in S$ 且 $\deg(r) < \deg(d)$，与 $d$ 是 $S$ 中次数最小者矛盾。因此 $r = 0$，即 $d \mid f$。同理 $d \mid g$。

**断言.** $d$ 满足 GCD 的极大性条件。

设 $e \mid f$ 且 $e \mid g$。则 $e \mid (u_0 f + v_0 g) = d$。

因此 $d$ 就是一个 GCD。令 $c = \operatorname{lc}(d)$，则 $\gcd(f, g) = c^{-1}d = c^{-1}u_0 f + c^{-1}v_0 g$，取 $u = c^{-1}u_0$，$v = c^{-1}v_0$。

**唯一性.** 设 $d_1, d_2$ 都是首一的 GCD。则 $d_1 \mid d_2$ 且 $d_2 \mid d_1$，故 $d_1 = \alpha d_2$（$\alpha \in K^*$）。因为两者都首一，$\alpha = 1$。 $\square$

</ProofToggle>

::: tip Bézout 恒等式的意义
{thm-gcd-bezout}(ii) 的 Bézout 恒等式 $uf + vg = \gcd(f,g)$ 在域论中至关重要：
- 它保证了多项式之间的"线性组合"可以精确表达公因子；
- 它在证明[极小多项式](/chapters/03-fields/3.3-algebraic-elements#def-minimal-polynomial)的唯一性时起关键作用；
- 它是 $K[X]$ 是 **主理想整环（PID）** 的核心工具。
:::

**定义 4.1.8** {#def-coprime} 称 $f, g \in K[X]$ **互素（coprime）**，如果 $\gcd(f, g) = 1$。

**推论 4.1.9** {#cor-coprime-bezout} $f, g$ 互素当且仅当存在 $u, v \in K[X]$ 使得 $uf + vg = 1$。

## 4.1.5 不可约多项式与唯一分解 {#irreducible-UFD}

**定义 4.1.10** {#def-irreducible} 设 $f \in K[X]$，$\deg(f) \geq 1$。称 $f$ 在 $K[X]$ 中**不可约（irreducible）**，如果不存在 $g, h \in K[X]$ 使得 $f = gh$，$\deg(g) \geq 1$，$\deg(h) \geq 1$。

等价地：$f$ 不可约当且仅当 $f$ 的因式只有 $K^*$ 中的元素（$f$ 的"平凡因式"）和 $f$ 的相伴元。

::: warning 注意
不可约性是**相对于基域 $K$ 而言**的。多项式 $X^2 + 1$ 在 $\mathbb{R}[X]$ 中不可约，但在 $\mathbb{C}[X]$ 中可约：$X^2 + 1 = (X + i)(X - i)$。
:::

**引理 4.1.11**（Euclid 引理）{#lem-euclid-lemma} 设 $p \in K[X]$ 不可约，$f, g \in K[X]$。若 $p \mid fg$，则 $p \mid f$ 或 $p \mid g$。

<ProofToggle>
<summary>**证明**</summary>

假设 $p \nmid f$。由于 $p$ 不可约，$\gcd(p, f) = 1$。由 {thm-gcd-bezout}，存在 $u, v \in K[X]$ 使得 $up + vf = 1$。

两边乘 $g$：$ugp + vfg = g$。

由于 $p \mid fg$，设 $fg = ph$，则 $g = ugp + vph = p(ug + vh)$，即 $p \mid g$。 $\square$

</ProofToggle>

**推论 4.1.12** {#cor-prime-divides-product} 设 $p \in K[X]$ 不可约，$f_1, \ldots, f_r \in K[X]$。若 $p \mid f_1 \cdots f_r$，则 $p \mid f_i$ 对某个 $i$。

<ProofToggle>
<summary>**证明**</summary>

对 $r$ 归纳。$r = 1$ 时平凡。$r \geq 2$ 时：$p \mid f_1 \cdot (f_2 \cdots f_r)$，由 {lem-euclid-lemma}，$p \mid f_1$ 或 $p \mid (f_2 \cdots f_r)$。后者由归纳假设推出 $p \mid f_i$（某个 $i \geq 2$）。 $\square$

</ProofToggle>

**定理 4.1.13**（唯一分解定理）{#thm-ufd} 设 $K$ 为域，$f \in K[X]$，$\deg(f) \geq 1$。则 $f$ 可以写成：

$$f = c \cdot p_1^{e_1} p_2^{e_2} \cdots p_r^{e_r}$$

其中 $c \in K^*$，$p_1, \ldots, p_r$ 是互不相伴的首一不可约多项式，$e_i \geq 1$。这种分解在以下意义下**唯一**：若

$$f = d \cdot q_1^{f_1} q_2^{f_2} \cdots q_s^{f_s}$$

是另一种这样的分解，则 $c = d$，$r = s$，且在适当重排后 $p_i = q_i$，$e_i = f_i$。

<ProofToggle>
<summary>**证明（完整）**</summary>

**存在性.** 对 $\deg(f)$ 进行强归纳。

若 $f$ 不可约，则 $f = \operatorname{lc}(f) \cdot (\operatorname{lc}(f)^{-1} f)$ 就是分解。

若 $f$ 可约，设 $f = gh$，$\deg(g), \deg(h) < \deg(f)$。由归纳假设，$g$ 和 $h$ 都有不可约分解。将它们合起来就得到 $f$ 的不可约分解。

**唯一性.** 设

$$c \cdot p_1^{e_1} \cdots p_r^{e_r} = d \cdot q_1^{f_1} \cdots q_s^{f_s}$$

是两种首一不可约分解。比较首项系数：$c = d$。

于是 $p_1 \mid q_1^{f_1} \cdots q_s^{f_s}$。由 {cor-prime-divides-product}，$p_1 \mid q_j$ 对某个 $j$。因为 $q_j$ 不可约且 $p_1$ 不是单位，$p_1$ 与 $q_j$ 相伴。由于两者都首一，$p_1 = q_j$。重排使 $j = 1$。

比较 $p_1$ 的指数：设 $e_1 \leq f_1$（否则交换），消去 $p_1^{e_1}$ 得：

$$p_2^{e_2} \cdots p_r^{e_r} = p_1^{f_1 - e_1} q_2^{f_2} \cdots q_s^{f_s}$$

若 $f_1 > e_1$，则 $p_1 \mid p_2^{e_2} \cdots p_r^{e_r}$，同理推出 $p_1 = p_j$（某个 $j \geq 2$），与 $p_1, \ldots, p_r$ 互不相伴矛盾。因此 $e_1 = f_1$，消去后得到更短的等式，由归纳完成。 $\square$

</ProofToggle>

**推论 4.1.14** {#cor-pid-ufd} $K[X]$ 是**主理想整环（PID）**，从而是唯一分解整环（UFD）。

<ProofToggle>
<summary>**证明**</summary>

设 $I$ 是 $K[X]$ 的非零理想。在 $I \setminus \{0\}$ 中取一个次数最小的多项式 $d$。对任意 $f \in I$，由带余除法 $f = qd + r$，$\deg(r) < \deg(d)$ 或 $r = 0$。因为 $r = f - qd \in I$ 且 $\deg(r) < \deg(d)$，由 $d$ 的选择必有 $r = 0$。因此 $I = (d)$。

$K[X]$ 是 PID 推出它是 UFD（PID $\Rightarrow$ UFD 是一般环论的结果，参见[§2.2](/chapters/02-rings/2.2-ideals#sec-pid-ufd)）。但此处我们已独立证明了 $K[X]$ 的唯一分解（{thm-ufd}），所以实际上两个方向都成立。 $\square$

</ProofToggle>

::: warning PID 但不是 Euclid 整环的一般环
虽然 $K[X]$ 是 Euclid 整环（从而是 PID），但反过来不成立：存在是 PID 但不是 Euclid 整环的环，例如 $\mathbb{Z}\left[\frac{1+\sqrt{-19}}{2}\right]$。$K[X]$ 的 Euclid 函数就是 $\deg$。
:::

## 4.1.6 多项式的求值与根 {#evaluation}

**定理 4.1.15**（余数定理）{#thm-remainder-theorem} 设 $f \in K[X]$，$\alpha \in K$。则 $f(X) = (X - \alpha) q(X) + f(\alpha)$，其中 $q \in K[X]$。

<ProofToggle>
<summary>**证明**</summary>

这不过是 {thm-division-algorithm} 的直接应用。对 $f$ 除以 $(X - \alpha)$：

$$f(X) = q(X)(X - \alpha) + r$$

其中 $r \in K$（因为 $\deg(r) < \deg(X - \alpha) = 1$）。代入 $X = \alpha$：

$$f(\alpha) = q(\alpha) \cdot 0 + r = r$$

因此 $r = f(\alpha)$。 $\square$

</ProofToggle>

**定理 4.1.16**（根的个数上界）{#thm-root-bound} 设 $f \in K[X]$，$\deg(f) = n \geq 0$。则 $f$ 在 $K$ 中至多有 $n$ 个不同的根。

<ProofToggle>
<summary>**证明**</summary>

对 $n$ 归纳。$n = 0$ 时 $f$ 是非零常数，没有根。

设 $n \geq 1$。若 $f$ 在 $K$ 中没有根，结论成立。否则设 $\alpha \in K$ 是根。由 {cor-root-factor}：

$$f(X) = (X - \alpha) g(X), \quad \deg(g) = n - 1$$

$f$ 的任何不同于 $\alpha$ 的根 $\beta$ 必须满足 $(\beta - \alpha) g(\beta) = 0$。由于 $\beta \neq \alpha$，$\beta - \alpha \neq 0$（$K$ 是域），所以 $g(\beta) = 0$。

由归纳假设，$g$ 至多有 $n - 1$ 个根。因此 $f$ 至多有 $1 + (n - 1) = n$ 个根。 $\square$

</ProofToggle>

::: warning 应用
{thm-root-bound} 有深远的应用：
- 它给出了[域扩张](/chapters/03-fields/3.2-basic-extensions#thm-degree-bounds-automorphisms)中 $\operatorname{Aut}(L/K) \leq [L:K]$ 的证明关键步骤；
- 它是有限域 $\mathbb{F}_q$ 中所有元素都是 $X^q - X$ 的根这一事实的基础（见[§4.2](/chapters/04-polynomials/4.2-irreducibility)）；
- 它暗示了多项式的"对称性"——根的置换——正是 [Galois 理论](/chapters/07-galois-groups/)的起点。
:::

::: warning "无根" ≠ "不可约"
{thm-root-bound} 说的是 $f$ 在 $K$ 中至多有 $\deg(f)$ 个根。但**没有根并不意味着不可约**！例如 $X^4 + 2X^2 + 1 = (X^2 + 1)^2$ 在 $\mathbb{R}[X]$ 中没有实根，但它是可约的。根的个数上界只排除了"过多的线性因子"，并不能排除非线性因子的分解。
:::

::: tip 根的个数达到上界的条件
{thm-root-bound} 是**上界**而非**等式**。根的个数恰好为 $n$（计重数）的充要条件是 $f$ 在 $K[X]$ 中完全分裂为线性因子：

$$f = c \cdot (X - \alpha_1) \cdots (X - \alpha_n)$$

这正是**分裂域**理论（[§5.1](/chapters/05-splitting-fields/5.1-splitting-fields)）研究的问题：并非所有多项式在基域中都能达到这个上界，但总存在一个扩域使之成立。
:::

**例 4.1.17** 根的计数。

**(i)** $f = X^3 - 1 \in \mathbb{Q}[X]$。在 $\mathbb{Q}$ 中只有一个根 $\alpha = 1$（因为 $X^3 - 1 = (X - 1)(X^2 + X + 1)$，而 $X^2 + X + 1$ 在 $\mathbb{Q}$ 中不可约——其判别式 $\Delta = 1 - 4 = -3 < 0$）。在 $\mathbb{C}$ 中，$f$ 有三个根：$1, \omega, \omega^2$，其中 $\omega = e^{2\pi i/3}$。

**(ii)** $f = X^p - X \in \mathbb{F}_p[X]$。由 Fermat 小定理，$a^p = a$ 对所有 $a \in \mathbb{F}_p$ 成立，所以 $f$ 有**恰好 $p$ 个不同的根**（即 $\mathbb{F}_p$ 的所有元素）。$f$ 的根恰好达到上界 $p$，因此：

$$X^p - X = \prod_{a \in \mathbb{F}_p} (X - a)$$

这是有限域理论的一个基本恒等式，见 [§10.1](/chapters/10-finite-fields/10.1-structure)。

**(iii)** $f = X^q - X \in \mathbb{F}_q[X]$，其中 $q = p^n$ 是素数的幂。类似地，$\mathbb{F}_q$ 的所有 $q$ 个元素都是 $f$ 的根，因此 $X^q - X$ 在 $\mathbb{F}_q[X]$ 中完全分裂。这个恒等式是**有限域的构造定理**的核心（[定理 10.1.1](/chapters/10-finite-fields/10.1-structure#thm-finite-field-existence)）。

## 4.1.7 总结与前后呼应 {#sec-4-1-summary}

**本节核心结论速览：**

| 结论 | 陈述 | 关键用途 |
|------|------|----------|
| 带余除法 | $\deg(r) < \deg(d)$ 或 $r = 0$ | [Euclid 算法](#gcd-euclid)、PID |
| GCD 存在唯一 | $\gcd(f, g)$ 存在、首一、唯一 | 因式分解的基础 |
| Bézout 等式 | $\gcd(f, g) = uf + vg$ | [Euclid 引理](#lem-euclid-lemma)、[互素判据](#cor-coprime-bezout) |
| 不可约 $\Rightarrow$ 素元 | $p \mid fg \Rightarrow p \mid f$ 或 $p \mid g$ | 唯一分解定理 |
| 唯一分解 | $f = c \cdot p_1^{e_1} \cdots p_r^{e_r}$ | [不可约性判据](/chapters/04-polynomials/4.2-irreducibility)的动机 |
| $K[X]$ 是 PID | 任何理想都是主理想 | 环论应用 |
| 根的上界 | $f$ 在 $K$ 中至多有 $\deg(f)$ 个根 | [Galois 理论](/chapters/07-galois-groups/)的起点 |

**与后续章节的关键联系：**

- $K[X]$ 的唯一分解保证了**最小多项式的唯一性**（[§3.3](/chapters/03-fields/3.3-algebraic-elements)），进而保证代数扩张的良定义性。
- 不可约多项式的**分裂域**总是存在的（[§5.1](/chapters/05-splitting-fields/5.1-splitting-fields)），这是一个非平凡的存在性定理。
- 根的个数上界引出了**自同构的个数上界** $\operatorname{Aut}(L/K) \leq [L:K]$（[§3.2](/chapters/03-fields/3.2-basic-extensions#thm-degree-bounds-automorphisms)），这是 Galois 理论的种子。
- 不可约多项式"在更大的域中变得可约"这一现象，是**分裂域**和**正规扩张**理论的直接动机。

**自测问题：**

1. 用 Euclid 算法计算 $\gcd(X^3 - 1, X^2 - 1) \in \mathbb{Q}[X]$。
2. 为什么 $\mathbb{Z}[X]$ 不是 PID？它是否仍然是 UFD？
3. $X^4 + 4$ 在 $\mathbb{Q}[X]$ 中是否不可约？（提示：Sophie Germain 恒等式。）
4. 设 $f \in \mathbb{F}_2[X]$，$\deg(f) = 3$。$f$ 不可约当且仅当 $f$ 在 $\mathbb{F}_2$ 中没有根。这对 $\deg(f) = 4$ 还成立吗？

<details><summary>**答案**</summary>

1. $X^3 - 1 = (X - 1)(X^2 + X + 1)$，$X^2 - 1 = (X - 1)(X + 1)$。$\gcd = X - 1$（首一化）。
2. $\mathbb{Z}[X]$ 中的理想 $(2, X)$ 不是主理想（可以证明不存在 $d \in \mathbb{Z}[X]$ 使得 $(2, X) = (d)$）。但 $\mathbb{Z}[X]$ 仍然是 UFD，因为 $\mathbb{Z}$ 是 UFD 且高斯引理成立（[§2.3](/chapters/02-rings/2.3-polynomial-rings)）。
3. $X^4 + 4 = (X^2 + 2X + 2)(X^2 - 2X + 2)$（Sophie Germain 恒等式：$a^4 + 4b^4 = (a^2 + 2ab + 2b^2)(a^2 - 2ab + 2b^2)$），所以**可约**。
4. 对 $\deg = 3$：成立，因为三次多项式若可约必有线性因子（$\deg = 1 + 2$ 或 $1 + 1 + 1$）。对 $\deg = 4$：**不成立**！例如 $f = (X^2 + X + 1)^2 = X^4 + X^2 + 1 \in \mathbb{F}_2[X]$ 在 $\mathbb{F}_2$ 中没有根（$f(0) = 1, f(1) = 1$），但它是可约的。正确的判据需要检查所有次数 $\leq 2$ 的不可约因子（[§4.2](/chapters/04-polynomials/4.2-irreducibility)）。

</details>
