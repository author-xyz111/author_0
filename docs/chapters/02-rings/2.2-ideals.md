# §2.2 理想与商环 {#sec-ideals-quotients}

::: tip 学习目标
1. 理解理想的定义及其与正规子群的类比关系。
2. 掌握商环的构造，理解"为什么需要理想而不是子环"来构造商环。
3. 掌握环同态基本定理及其应用。
4. 了解理想的运算（交、和、积），理解互素理想的概念。
5. 区分极大理想和素理想，理解它们与域和整环的对应关系。
:::

## 动机

在 [第一章](/chapters/01-groups/) 中，{def-normal-subgroup} 告诉我们：当子群 $N \trianglelefteq G$ 与群结构"兼容"时，商集 $G/N$ 自然继承群结构。环的类比是**理想**——它同时是加法子群，又与乘法兼容。理想是环论中构造商环、研究环同态的关键概念。

::: info 为什么需要理想而不是子环？
在群论中，我们可以对正规子群取商 $G/N$。在环论中，为什么不能对"子环"取商？

**原因**：设 $S \subseteq R$ 是子环（包含 1 的乘法子半群和加法子群）。要定义 $(a + S)(b + S) = ab + S$，需要对任意 $s \in S$，$(a + s)(b + s') = ab + \text{something in } S$。但 $(a + s)(b + s') = ab + as' + sb + ss'$。要使 $as' + sb + ss' \in S$，我们需要 $R$ 中**任意**元素乘以 $S$ 中元素仍在 $S$ 中——这正是理想的条件！

所以：**子环不足以保证乘法良定义，理想才行。** 这就是为什么环论中起作用的是理想而非子环。
:::

## 理想的定义

::: definition 理想 {#def-ideal}
环 $R$ 的非空子集 $I$ 称为 $R$ 的一个**理想**（记为 $I \trianglelefteq R$），如果：

**(I1)** $(I, +)$ 是 $(R, +)$ 的子群。

**(I2)** 对所有 $a \in I$，$r \in R$，有 $ra \in I$ 且 $ar \in I$。
:::

::: remark
对于交换环（本教程默认），条件 (I2) 简化为：$a \in I$，$r \in R$ 蕴含 $ra \in I$。注意理想一般不是子环——它不含单位元（除非 $I = R$）。
:::

::: example 理想的基本例子 {#ex-ideals}

1. **平凡理想**：$\{0\}$ 和 $R$ 总是 $R$ 的理想。
2. **主理想**：$aR = (a) = \{ar : r \in R\}$ 是由元素 $a$ 生成的理想。在 $\mathbb{Z}$ 中，每个理想都是主理想：$(n) = n\mathbb{Z}$。
3. $2\mathbb{Z} = \{0, \pm 2, \pm 4, \ldots\}$ 是 $\mathbb{Z}$ 的理想，是偶数的集合。
4. $I = \{f \in \mathbb{R}[x] : f(0) = 0\}$ 是 $\mathbb{R}[x]$ 的理想（事实上 $I = (x)$）。
5. **多项式环的主理想**：$(x^2 + 1) = \{(x^2 + 1)g(x) : g(x) \in \mathbb{R}[x]\}$ 是 $\mathbb{R}[x]$ 的理想，由 $x^2 + 1$ 生成。
6. **非主理想的例子**：在 $\mathbb{Z}[x]$ 中，$I = (2, x) = \{2f(x) + xg(x) : f, g \in \mathbb{Z}[x]\}$ 是理想，但不是主理想（因为 2 和 $x$ 没有公因子，但它们生成的理想包含所有常数项为偶数的多项式）。
7. **$\mathbb{Z}$ 的理想结构**：$\mathbb{Z}$ 的**每个**理想都是主理想 $(n)$（$n \geq 0$）。$\mathbb{Z}$ 的理想格：$(0) \supset (1) = \mathbb{Z}$，$(2) \supset (4) \supset (8) \supset \cdots$，$(2) \supset (6) \supset (12) \supset \cdots$。包含关系 $(a) \subseteq (b)$ 当且仅当 $b \mid a$。
:::

::: definition 主理想 {#def-principal-ideal}
设 $R$ 为环，$a \in R$。集合 $aR = (a) = \{ar : r \in R\}$ 是 $R$ 的理想，称为由 $a$ 生成的**主理想**（principal ideal）。若环的每个理想都是主理想，则称该环为**主理想环**。
:::

::: remark 理想 vs 子环
**理想不是子环。** $2\mathbb{Z}$ 是 $\mathbb{Z}$ 的理想但不是子环（不含 1）。$\mathbb{Z}$ 的子环只有 $\mathbb{Z}$ 本身（因为含 1 的加法子群必含所有整数）。

区分：
- **子环**：对加法和乘法封闭，包含 1。
- **理想**：对加法封闭，对任意元素的乘法封闭，但一般不含 1。
:::

::: definition 商环 {#def-quotient-ring}
设 $I$ 是环 $R$ 的理想。商集 $R/I = \{a + I : a \in R\}$ 在自然加法和乘法下构成环，称为 $R$ 模 $I$ 的**商环**（quotient ring）。详见 {thm-quotient-ring}。
:::

## 商环

::: theorem 商环的存在性 {#thm-quotient-ring}
设 $I$ 是环 $R$ 的理想。则商集 $R/I = \{a + I : a \in R\}$ 在以下运算下构成环：

$$(a + I) + (b + I) = (a + b) + I$$
$$(a + I)(b + I) = ab + I$$

单位元为 $1 + I$，零元为 $0 + I = I$。
:::

<ProofToggle>

::: proof
**加法群**：$I$ 是 $(R, +)$ 的子群，故 $R/I$ 是加法商群（{thm-first-isomorphism} 应用于加法群同态 $R \to R/I$）。

**乘法良定义**：设 $a + I = a' + I$，$b + I = b' + I$，即 $a' - a \in I$，$b' - b \in I$。则 $a'b' - ab = a'(b' - b) + (a' - a)b \in I$（因 $I$ 是理想，$b' - b \in I$ 推出 $a'(b' - b) \in I$；$a' - a \in I$ 推出 $(a' - a)b \in I$）。故 $a'b' + I = ab + I$。✓

**结合律**：由 $R$ 中乘法结合律继承。✓

**分配律**：类似地由 $R$ 的分配律继承。✓

**单位元**：$(1 + I)(a + I) = 1 \cdot a + I = a + I$。✓
:::

</ProofToggle>

::: example 商环的计算 {#ex-quotient-rings}

1. **$\mathbb{Z}/n\mathbb{Z}$**：$\mathbb{Z}/(n) = \mathbb{Z}/n\mathbb{Z}$，这是最熟悉的商环。$n = 0$ 时 $\mathbb{Z}/(0) \cong \mathbb{Z}$（不压缩）。$n$ 是素数时 $\mathbb{Z}/n\mathbb{Z}$ 是域（见 {thm-maximal-field}）。

2. **$\mathbb{R}[x]/(x^2 + 1) \cong \mathbb{C}$**：在 $\mathbb{R}[x]$ 中模掉 $x^2 + 1$ 相当于强制 $x^2 = -1$，即把 $x$ 变成虚数单位 $i$。映射 $\varphi \colon \mathbb{R}[x] \to \mathbb{C}$，$\varphi(f(x)) = f(i)$ 是满同态，$\ker\varphi = (x^2 + 1)$（由 {thm-ring-first-isomorphism}）。所以 $\mathbb{R}[x]/(x^2 + 1) \cong \mathbb{C}$。

3. **$\mathbb{Q}[x]/(x^2 - 2) \cong \mathbb{Q}(\sqrt{2})$**：模掉 $x^2 - 2$ 相当于强制 $x^2 = 2$，即把 $x$ 变成 $\sqrt{2}$。商环中元素形如 $a + bx$（$a, b \in \mathbb{Q}$），其中 $x^2 = 2$。

4. **$\mathbb{Z}[x]/(x) \cong \mathbb{Z}$**：模掉 $x$ 相当于令 $x = 0$，所有多项式被求值为常数项。$\ker(\text{求值映射 } f \mapsto f(0)) = (x)$。

5. **$\mathbb{Z}[i]/(2+i) \cong \mathbb{Z}/5\mathbb{Z}$**：$(2+i)$ 是 $\mathbb{Z}[i]$ 中的极大理想，因为 $N(2+i) = 5$ 是 $\mathbb{Z}$ 中的素数。$\mathbb{Z}[i]/(2+i) \cong \mathbb{Z}/5\mathbb{Z}$（高斯整数模去一个 5 的素因子）。
:::

::: warning 误区："商环中 $1 + I = 0 + I$ 意味着 $1 = 0$"
**不是！** $1 + I = 0 + I$ 当且仅当 $1 \in I$，当且仅当 $I = R$。在非平凡商环 $R/I$（$I \neq R$）中，$1 + I \neq 0 + I$。特别地，在 $R/I$ 是域的情况下，$1 + I$ 是乘法单位元，$0 + I$ 是零元，它们不相等。
:::

## 环同态

::: definition 环同态 {#def-ring-homomorphism}
环 $R$ 到环 $S$ 的映射 $\varphi \colon R \to S$ 称为**环同态**，如果对所有 $a, b \in R$：

1. $\varphi(a + b) = \varphi(a) + \varphi(b)$
2. $\varphi(ab) = \varphi(a)\varphi(b)$
3. $\varphi(1_R) = 1_S$

$\varphi$ 的**核** $\ker \varphi = \{r \in R : \varphi(r) = 0_S\}$。
:::

::: example 环同态的典型例子 {#ex-ring-homomorphisms}

1. **包含映射** $\iota \colon \mathbb{Z} \hookrightarrow \mathbb{Q}$。单同态，$\ker\iota = (0)$。

2. **求值映射** $\operatorname{ev}_a \colon R[x] \to R$，$f(x) \mapsto f(a)$。$\ker(\operatorname{ev}_a) = (x - a)$。由第一同构定理，$R[x]/(x-a) \cong R$。

3. **自然投射** $\pi \colon R \to R/I$，$r \mapsto r + I$。$\ker\pi = I$。这是构造商环的基本方法。

4. **复共轭** $\sigma \colon \mathbb{C} \to \mathbb{C}$，$z \mapsto \overline{z}$。自同构，$\ker\sigma = (0)$。$\sigma$ 在 [Galois 理论](/chapters/07-galois-groups/) 中扮演核心角色：$\operatorname{Gal}(\mathbb{C}/\mathbb{R}) = \{id, \sigma\} \cong \mathbb{Z}/2\mathbb{Z}$。

5. **模 $n$ 投射** $\pi \colon \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$，$k \mapsto \overline{k}$。$\ker\pi = n\mathbb{Z}$。

6. **$\mathbb{Z}[x] \to \mathbb{Z}/p\mathbb{Z}$**，$f(x) \mapsto \overline{f(0)}$（先模 $p$ 再求值于 0）。$\ker = (p, x) = p\mathbb{Z} + x\mathbb{Z}[x]$。
:::

::: lemma {#lem-ring-kernel-is-ideal}
环同态的核是理想。
:::

<ProofToggle>

::: proof
$\ker \varphi$ 是 $(R, +)$ 的子群（因为 $\varphi$ 是加法群同态）。若 $a \in \ker \varphi$，$r \in R$，则 $\varphi(ra) = \varphi(r)\varphi(a) = \varphi(r) \cdot 0 = 0$，故 $ra \in \ker \varphi$。类似地 $ar \in \ker \varphi$。故 $\ker \varphi$ 是理想。
:::

</ProofToggle>

::: info 正规子群 ↔ 理想：类比总结

| 群论 | 环论 |
|------|------|
| 子群 $H \leq G$ | 子环 $S \subseteq R$ |
| **正规子群** $N \trianglelefteq G$ | **理想** $I \trianglelefteq R$ |
| 商群 $G/N$ | 商环 $R/I$ |
| 同态的核 $\ker\varphi \trianglelefteq G$ | 同态的核 $\ker\varphi \trianglelefteq R$ |
| 第一同构定理：$G/\ker\varphi \cong \operatorname{im}\varphi$ | 环第一同构定理：$R/\ker\varphi \cong \operatorname{im}\varphi$ |
| 对应定理 | [中国剩余定理](/chapters/02-rings/2.4-crt) |

关键区别：群的正规子群条件（$gNg^{-1} = N$）看起来是"共轭不变"，而环的理想条件（$rI \subseteq I$）是"乘法吸收"。两者都是保证商结构良定义的条件。
:::

::: theorem 环同态基本定理 {#thm-ring-first-isomorphism}
设 $\varphi \colon R \to S$ 是环同态。则

$$R/\ker\varphi \cong \operatorname{im}\varphi$$

更精确地，$\overline{\varphi}(r + \ker\varphi) = \varphi(r)$ 是环同构。
:::

<ProofToggle>

::: proof
$\overline{\varphi}$ 是良定义的加法群同构（{thm-first-isomorphism}）。还需验证乘法：$\overline{\varphi}((a + K)(b + K)) = \overline{\varphi}(ab + K) = \varphi(ab) = \varphi(a)\varphi(b) = \overline{\varphi}(a + K)\overline{\varphi}(b + K)$，其中 $K = \ker\varphi$。故 $\overline{\varphi}$ 是环同构。
:::

</ProofToggle>

::: example 应用环同态基本定理 {#ex-ring-first-iso}

1. **$\mathbb{R}[x]/(x^2 + 1) \cong \mathbb{C}$**：求值映射 $\operatorname{ev}_i \colon \mathbb{R}[x] \to \mathbb{C}$，$f(x) \mapsto f(i)$。$\ker(\operatorname{ev}_i) = (x^2 + 1)$（最小多项式）。$\operatorname{ev}_i$ 满射（$a + bi = \operatorname{ev}_i(a + bx)$）。由 {thm-ring-first-isomorphism}，$\mathbb{R}[x]/(x^2 + 1) \cong \mathbb{C}$。

2. **$\mathbb{Z}[x]/(x-3) \cong \mathbb{Z}$**：求值映射 $\operatorname{ev}_3 \colon \mathbb{Z}[x] \to \mathbb{Z}$，$f(x) \mapsto f(3)$。$\ker(\operatorname{ev}_3) = (x - 3)$。满射（$n = \operatorname{ev}_3(n)$）。

3. **$\mathbb{Z}[i]/(1+i) \cong \mathbb{Z}/2\mathbb{Z}$**：$\varphi \colon \mathbb{Z}[i] \to \mathbb{Z}/2\mathbb{Z}$，$\varphi(a + bi) = \overline{a + b} \pmod{2}$。$\ker\varphi = (1+i)$（因为 $N(1+i) = 2$）。

4. 这些例子展示了 **Galois 理论的核心模式**：域扩张 $K(\alpha) \cong K[x]/(f(x))$，其中 $f$ 是 $\alpha$ 的最小多项式（不可约）。商环构造给出了域扩张的代数实现。
:::

## 理想的运算

::: proposition 理想的交与和 {#prop-ideal-operations}
设 $I$，$J$ 是环 $R$ 的理想。则：

1. $I \cap J$ 是 $R$ 的理想。
2. $I + J = \{a + b : a \in I, b \in J\}$ 是 $R$ 的理想。
3. $IJ = \left\{\sum_{i=1}^{n} a_i b_i : a_i \in I, b_i \in J, n \geq 1\right\}$ 是 $R$ 的理想。
4. $IJ \subseteq I \cap J \subseteq I + J$。
:::

<ProofToggle>

::: proof
**(1)** 对 $a, b \in I \cap J$，$a - b \in I \cap J$。对 $r \in R$，$a \in I \cap J$，$ra \in I$（因 $I$ 是理想）且 $ra \in J$（因 $J$ 是理想），故 $ra \in I \cap J$。

**(2)** 对 $a_1 + b_1, a_2 + b_2 \in I + J$，$(a_1 + b_1) - (a_2 + b_2) = (a_1 - a_2) + (b_1 - b_2) \in I + J$。对 $r \in R$，$r(a + b) = ra + rb \in I + J$。

**(3)** 对 $IJ$ 中元素的和与 $r \in R$ 的乘积仍形如有限和 $\sum a_i b_i$（$a_i \in I$，$b_i \in J$），属于 $IJ$。

**(4)** 对 $ab \in IJ$（$a \in I, b \in J$），$ab \in I$（因 $I$ 是理想）且 $ab \in J$（因 $J$ 是理想），故 $ab \in I \cap J$。$I \cap J \subseteq I + J$：对 $c \in I \cap J$，$c = c + 0 \in I + J$。
:::

</ProofToggle>

::: example 理想运算的计算 {#ex-ideal-operations}

1. **$\mathbb{Z}$ 中**：$I = 2\mathbb{Z}$，$J = 3\mathbb{Z}$。
   - $I \cap J = 6\mathbb{Z}$（同时被 2 和 3 整除 = 被 6 整除）
   - $I + J = \mathbb{Z}$（因为 $3 - 2 = 1 \in I + J$，$1$ 生成整个 $\mathbb{Z}$）
   - $IJ = 6\mathbb{Z}$（因为 $IJ \subseteq I \cap J$，且 $6 = 2 \cdot 3 \in IJ$，故 $6\mathbb{Z} \subseteq IJ$）
   - **注意**：$I + J = \mathbb{Z}$，所以 $I$ 和 $J$ 互素。

2. **$\mathbb{Z}$ 中**：$I = 4\mathbb{Z}$，$J = 6\mathbb{Z}$。
   - $I \cap J = 12\mathbb{Z}$（$\text{lcm}(4, 6) = 12$）
   - $I + J = 2\mathbb{Z}$（因为 $6 - 4 = 2 \in I + J$，$2 \mid 4$ 和 $2 \mid 6$）
   - $IJ = 24\mathbb{Z}$（$4 \cdot 6 = 24$）
   - **注意**：$IJ = 24\mathbb{Z} \subsetneq I \cap J = 12\mathbb{Z}$。严格包含！

3. **$\mathbb{Z}$ 中一般公式**：$a\mathbb{Z} \cap b\mathbb{Z} = \text{lcm}(a,b)\mathbb{Z}$，$a\mathbb{Z} + b\mathbb{Z} = \gcd(a,b)\mathbb{Z}$。

4. **多项式环中**：$I = (x)$，$J = (x-1)$ 在 $\mathbb{Q}[x]$ 中。$I \cap J = (x(x-1))$，$I + J = \mathbb{Q}[x]$（$\gcd(x, x-1) = 1$）。互素！
:::

::: warning 误区："$IJ = I \cap J$"
**不一定！** 一般只有 $IJ \subseteq I \cap J$，严格包含可能发生。在 $\mathbb{Z}$ 中，$4\mathbb{Z} \cdot 6\mathbb{Z} = 24\mathbb{Z} \subsetneq 12\mathbb{Z} = 4\mathbb{Z} \cap 6\mathbb{Z}$。

$IJ = I \cap J$ 的充分条件是 $I + J = R$（互素）。这在 [§2.4 中国剩余定理](/chapters/02-rings/2.4-crt) 中有精确表述。
:::

::: remark
当 $I + J = R$ 时，称 $I$ 和 $J$ **互素**。互素理想的性质是 [§2.4 中国剩余定理](/chapters/02-rings/2.4-crt) 的核心。
:::

## 极大理想与素理想

::: definition 极大理想 {#def-maximal-ideal}
环 $R$ 的真理想 $\mathfrak{m}$（即 $\mathfrak{m} \neq R$）称为**极大理想**，如果不存在真理想 $I$ 使得 $\mathfrak{m} \subsetneq I \subsetneq R$。
:::

::: definition 素理想 {#def-prime-ideal}
环 $R$ 的真理想 $\mathfrak{p}$ 称为**素理想**，如果 $ab \in \mathfrak{p}$ 蕴含 $a \in \mathfrak{p}$ 或 $b \in \mathfrak{p}$。
:::

::: theorem 商环是域当且仅当理想极大 {#thm-maximal-field}
设 $R$ 是含幺交换环，$I$ 是 $R$ 的理想。则：

$$R/I \text{ 是域} \iff I \text{ 是极大理想}$$
:::

<ProofToggle>

::: proof
($\Rightarrow$) 设 $R/I$ 是域。设 $I \subseteq J \subseteq R$，$J$ 是理想。若 $I \neq J$，取 $a \in J \setminus I$，则 $a + I \neq 0$ 在 $R/I$ 中。因 $R/I$ 是域，存在 $b + I$ 使 $(a + I)(b + I) = 1 + I$，即 $ab - 1 \in I \subseteq J$。故 $1 = ab - (ab - 1) \in J$（因 $a \in J$ 且 $ab - 1 \in J$），从而 $J = R$。

($\Leftarrow$) 设 $I$ 是极大理想。对 $a + I \neq 0$（$a \notin I$），理想 $(I, a) = I + Ra$ 严格包含 $I$（因 $a \notin I$），由极大性 $I + Ra = R$。故存在 $b \in R$，$i \in I$ 使得 $ab + i = 1$，即 $ab \equiv 1 \pmod{I}$，$(a + I)(b + I) = 1 + I$。故 $a + I$ 可逆。
:::

</ProofToggle>

::: theorem 商环是整环当且仅当理想素 {#thm-prime-integral-domain}
设 $R$ 是含幺交换环，$I$ 是 $R$ 的理想。则：

$$R/I \text{ 是整环} \iff I \text{ 是素理想}$$
:::

<ProofToggle>

::: proof
$R/I$ 是整环 $\iff$ $R/I$ 无零因子 $\iff$ $(a + I)(b + I) = 0 + I$ 蕴含 $a + I = 0$ 或 $b + I = 0$ $\iff$ $ab \in I$ 蕴含 $a \in I$ 或 $b \in I$ $\iff$ $I$ 是素理想。
:::

</ProofToggle>

::: corollary {#cor-maximal-implies-prime}
极大理想必是素理想。即：域必是整环。
:::

<ProofToggle>

::: proof
若 $\mathfrak{m}$ 极大，$R/\mathfrak{m}$ 是域。域中 $ab = 0$ 且 $a \neq 0$ 推出 $b = a^{-1} \cdot 0 = 0$，故 $R/\mathfrak{m}$ 无零因子，是整环。由 {thm-prime-integral-domain}，$\mathfrak{m}$ 是素理想。
:::

</ProofToggle>

::: warning 误区："素理想必是极大理想"
**不成立！** {cor-maximal-implies-prime} 只有单方向。反例：

1. $(0)$ 在 $\mathbb{Z}$ 中是素理想（$\mathbb{Z}/(0) \cong \mathbb{Z}$ 是整环），但不是极大理想（$(0) \subsetneq (2) \subsetneq \mathbb{Z}$）。

2. $(x)$ 在 $\mathbb{Z}[x]$ 中是素理想（$\mathbb{Z}[x]/(x) \cong \mathbb{Z}$ 是整环），但不是极大理想（$(x) \subsetneq (2, x)$，而 $\mathbb{Z}[x]/(2, x) \cong \mathbb{Z}/2\mathbb{Z}$ 才是域）。

**直觉**：素理想保证商环"没有零因子"，但可能"不够大"，商环可能还不是域。极大理想保证商环"已经尽可能压缩"，到达域。
:::

::: example 极大理想与素理想的分类 {#ex-maximal-prime}

1. **$\mathbb{Z}$ 中**：
   - 极大理想：$(p)$，$p$ 为素数。
   - 素理想：$(p)$（$p$ 为素数）和 $(0)$。
   - 既不是：$(6) = 2\mathbb{Z} \cap 3\mathbb{Z}$（因为 $6 = 2 \cdot 3 \in (6)$，但 $2 \notin (6)$）。

2. **$\mathbb{R}[x]$ 中**：
   - 极大理想：$(f(x))$，$f$ 不可约。因为 $\mathbb{R}[x]$ 是 PID，不可约元生成极大理想。
   - 素理想：$(f(x))$，$f$ 不可约，和 $(0)$。
   - $(x^2 + 1)$ 极大（$x^2 + 1$ 在 $\mathbb{R}$ 上不可约），$\mathbb{R}[x]/(x^2 + 1) \cong \mathbb{C}$。
   - $(x^2 - 1) = (x-1)(x+1)$ 既不是素理想也不是极大理想（有零因子）。

3. **$\mathbb{Q}[x]$ 中**：
   - $(x^2 - 2)$ 极大（$x^2 - 2$ 在 $\mathbb{Q}$ 上不可约），$\mathbb{Q}[x]/(x^2 - 2) \cong \mathbb{Q}(\sqrt{2})$。
   - $(x^2 - 4) = (x-2)(x+2)$ 不是素理想。

4. **一般域 $K$ 上的多项式环 $K[x]$**：在 PID $K[x]$ 中，极大理想 = 素理想 = $(f(x))$，$f$ 不可约。这就是 [§4 不可约多项式](/chapters/04-polynomials/4.2-irreducibility) 的核心意义。
:::

::: intuition
{thm-maximal-field} 和 {thm-prime-integral-domain} 的结构是 Galois 理论的基石。在 [§5 分裂域与正规扩张](/chapters/05-splitting-fields/) 中，域扩张 $K(\alpha) \cong K[x]/(f(x))$ 正是取多项式环模去不可约多项式的理想——不可约性保证极大性，从而商环是域。

更深层地，这个模式是：
- **不可约多项式** $\to$ **极大理想** $\to$ **域** $\to$ **域扩张**
- 这是代数数论和代数几何的基础构造。
:::

## 常见误区 {#misconceptions}

::: warning 误区一："$R/I$ 中 $I$ 是零元的"别名"
更准确地说，$I$ 作为 $R/I$ 的元素就是零元 $0 + I$。$R/I$ 中的零不是 $R$ 中的 $0$，而是等价类 $0 + I = I$。这是一个集合（理想），在 $R/I$ 中扮演零的角色。
:::

::: warning 误区二："每个环都有极大理想"
在**含幺**交换环中，这由 Zorn 引理保证。但不含单位元的环可能没有极大理想（平凡环 $R = \{0\}$ 没有真理想）。本教程中所有环都含幺，所以极大理想总是存在。
:::

::: warning 误区三："理想一定不含 1"
只有当 $I \neq R$ 时，$I$ 不含 1。$R$ 自身也是理想（平凡理想），它当然含 1。更精确的表述是：**真理想**不含 1。
:::

## 自测问题 {#self-test}

::: question 自测
1. **理想的判定**：以下哪些是 $\mathbb{Z}[x]$ 的理想？
   - (a) $I = \{f \in \mathbb{Z}[x] : f(0) = 0\}$
   - (b) $J = \{f \in \mathbb{Z}[x] : f \text{ 的所有系数为偶数}\}$
   - (c) $K = \{f \in \mathbb{Z}[x] : f \text{ 的次数} \leq 2\}$

2. **商环的元素**：$\mathbb{Z}[x]/(x^2 + 1, 3)$ 有多少个元素？（提示：先模 3，再模 $x^2 + 1$。）

3. **极大理想**：$\mathbb{Z}[x]$ 中的理想 $(2, x)$ 是极大理想吗？（提示：$\mathbb{Z}[x]/(2, x) \cong \mathbb{Z}/2\mathbb{Z}$。）

4. **理想运算**：在 $\mathbb{Z}$ 中，计算 $12\mathbb{Z} + 18\mathbb{Z}$，$12\mathbb{Z} \cap 18\mathbb{Z}$，$12\mathbb{Z} \cdot 18\mathbb{Z}$。

5. **概念辨析**：为什么 $2\mathbb{Z}$ 是 $\mathbb{Z}$ 的理想但不是子环？
:::

::: details 答案
1. (a) 是理想。(b) 是理想（偶数系数多项式集，在 $\mathbb{Z}[x]$ 中吸收乘法）。(c) **不是理想**——$x \in K$，但 $x \cdot x = x^2$ 的次数为 2，还在 $K$ 中；但 $x \cdot x^3 = x^4$ 的次数为 4，不在 $K$ 中。更直接地，$1 \in \mathbb{Z}[x]$，$1 \cdot x^3 = x^3 \notin K$（$x^3$ 不在 $K$ 中），但关键是 $x^2 \in K$，$x \in \mathbb{Z}[x]$，$x \cdot x^2 = x^3 \notin K$。

2. $\mathbb{Z}[x]/(2, x) \cong \mathbb{Z}/2\mathbb{Z}$ 有 2 个元素。$\mathbb{Z}[x]/(3, x^2+1)$：先模 3 得 $(\mathbb{Z}/3\mathbb{Z})[x]$，再模 $x^2 + 1$。$x^2 + 1$ 在 $\mathbb{Z}/3\mathbb{Z}$ 上是否不可约？$0^2 + 1 = 1$，$1^2 + 1 = 2$，$2^2 + 1 = 5 = 2$。无根，故不可约（二次多项式）。$\mathbb{Z}[x]/(3, x^2+1) \cong \mathbb{F}_9$，有 9 个元素。

3. $\mathbb{Z}[x]/(2, x) \cong \mathbb{Z}/2\mathbb{Z}$（将 2 和 $x$ 都设为 0），$\mathbb{Z}/2\mathbb{Z}$ 是域，所以 $(2, x)$ 是极大理想。✓

4. $12\mathbb{Z} + 18\mathbb{Z} = \gcd(12,18)\mathbb{Z} = 6\mathbb{Z}$。$12\mathbb{Z} \cap 18\mathbb{Z} = \text{lcm}(12,18)\mathbb{Z} = 36\mathbb{Z}$。$12\mathbb{Z} \cdot 18\mathbb{Z} = 216\mathbb{Z}$（$12 \cdot 18 = 216$）。注意 $IJ = 216\mathbb{Z} \subsetneq I \cap J = 36\mathbb{Z}$。

5. $2\mathbb{Z}$ 不含 $1$。$2\mathbb{Z}$ 对加法和乘法封闭（$2a \cdot 2b = 4ab \in 2\mathbb{Z}$），但不是子环，因为子环要求包含 $1$，而 $1 \notin 2\mathbb{Z}$。
:::
