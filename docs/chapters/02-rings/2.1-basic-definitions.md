# 2.1 环的定义与基本性质

## 动机

群是具有一个运算的代数结构。但在数学中，我们经常遇到两个运算的结构：整数有加法和乘法，多项式也有加法和乘法，域的自同构可以做加法和乘法。环（Ring）正是这种"双运算"结构的抽象。

::: definition 环 {#def-ring}
一个**环**是一个三元组 $(R, +, \cdot)$，其中 $R$ 是非空集合，$+$ 和 $\cdot$ 是 $R$ 上的二元运算（分别称为**加法**和**乘法**），满足以下公理：

**(R1)** $(R, +)$ 是交换群（单位元记为 $0$，称为**零元**；$a$ 的加法逆元记为 $-a$）。

**(R2)** 乘法结合律：$(ab)c = a(bc)$ 对所有 $a, b, c \in R$。

**(R3)** 分配律：$a(b + c) = ab + ac$ 和 $(b + c)a = ba + ca$ 对所有 $a, b, c \in R$。
:::

::: convention
- 若乘法还满足交换律，则称 $R$ 为**交换环**。
- 若存在元素 $1 \in R$ 使得 $1 \cdot a = a \cdot 1 = a$ 对所有 $a$ 成立，则 $1$ 称为 $R$ 的**单位元**（或**恒等元**），$(R, +, \cdot, 1)$ 称为**含幺环**。
- 本教程默认所有环都是含幺交换环，除非特别说明。
:::

::: example 环的基本例子 {#ex-ring-examples}

1. **整数环** $(\mathbb{Z}, +, \cdot)$：最经典的环，单位元为 1。
2. **多项式环** $R[x]$：系数在环 $R$ 中的多项式的集合，按通常的多项式加法和乘法构成环。这是 Galois 理论中最重要的环之一。
3. **整数模 $n$** $\mathbb{Z}/n\mathbb{Z}$：陪集集合 $\{\overline{0}, \overline{1}, \ldots, \overline{n-1}\}$，模 $n$ 的加法和乘法。当 $n$ 是素数时，这是一个域。
4. **域上的矩阵环** $M_n(F)$：非交换的典型例子（当 $n \geq 2$），单位元为单位矩阵 $I_n$。
5. **连续函数环** $C[0,1]$：区间 $[0,1]$ 上实值连续函数的逐点加法和乘法。零元是零函数，单位元是常函数 $f(x) \equiv 1$。
:::

## 零因子与整环

::: definition 零因子 {#def-zero-divisor}
设 $R$ 为环。元素 $a \in R$，$a \neq 0$，称为 $R$ 的一个**零因子**，如果存在 $b \in R$，$b \neq 0$，使得 $ab = 0$。
:::

::: definition 整环 {#def-integral-domain}
一个**整环**是含幺交换环，且没有零因子（即 $ab = 0$ 蕴含 $a = 0$ 或 $b = 0$）。
:::

::: example 整环与非整环 {#ex-integral-domain}

1. $\mathbb{Z}$ 是整环。
2. $\mathbb{Q}$，$\mathbb{R}$，$\mathbb{C}$ 都是整环（事实上都是域）。
3. $\mathbb{Z}/6\mathbb{Z}$ 不是整环：$\overline{2} \cdot \overline{3} = \overline{0}$，$\overline{2}$ 和 $\overline{3}$ 都是零因子。
4. $\mathbb{Z}/p\mathbb{Z}$（$p$ 素数）是整环（事实上是域）。
5. $R[x]$ 是整环当且仅当 $R$ 是整环。
:::

## 单位与可逆元

::: definition 单位 {#def-unit}
环 $R$ 中的元素 $u$ 称为**单位**（或**可逆元**），如果存在 $v \in R$ 使得 $uv = 1$。所有单位的集合记为 $R^*$ 或 $R^\times$。
:::

::: proposition {#prop-units-form-group}
对任意含幺环 $R$，$(R^*, \cdot)$ 构成一个群，称为 $R$ 的**单位群**。
:::

<ProofToggle>

::: proof
- $1 \in R^*$（因 $1 \cdot 1 = 1$）。
- 若 $u, v \in R^*$，则 $(uv)(v^{-1}u^{-1}) = 1$，故 $uv \in R^*$。
- 若 $u \in R^*$ 有逆 $u^{-1}$，则 $(u^{-1})^{-1} = u \in R^*$。
- 乘法结合律继承自 $R$。
:::

</ProofToggle>

::: example 单位群 {#ex-unit-groups}

1. $\mathbb{Z}^* = \{-1, 1\} \cong \mathbb{Z}/2\mathbb{Z}$。
2. $\mathbb{Q}^* = \mathbb{Q} \setminus \{0\}$（域中每个非零元素都可逆）。
3. $(\mathbb{Z}/n\mathbb{Z})^* = \{\overline{a} : \gcd(a,n) = 1\}$，$|(\mathbb{Z}/n\mathbb{Z})^*| = \varphi(n)$（Euler 函数）。
:::

---

::: tip 本节要点
1. 环是具有加法和乘法的代数结构，加法构成交换群，乘法满足结合律和分配律。
2. 整环是没有零因子的含幺交换环。
3. 单位群 $R^*$ 由所有可逆元组成。
4. 域是每个非零元素都有逆的整环。
:::
