# §2.1 环的定义与基本性质 {#sec-ring-definition}

::: tip 学习目标
1. 理解环作为"双运算"代数结构的公理化定义。
2. 能区分零因子、单位、幂零元等容易混淆的概念。
3. 掌握整环的定义及其在 Galois 理论中的核心作用。
4. 计算常见环的单位群。
5. 理解"含幺交换环"约定的原因和影响。
:::

## 动机

群是具有一个运算的代数结构。但在数学中，我们经常遇到两个运算的结构：整数有加法和乘法，多项式也有加法和乘法，域的自同构可以做加法和乘法。环（Ring）正是这种"双运算"结构的抽象。

::: info 从群到环的思维跳跃
在群论中，我们只关注一个运算。但在域扩张理论中，我们需要同时处理"加法结构"和"乘法结构"。例如，$\mathbb{Q}(\sqrt{2})$ 中的元素可以做加法（$a + b\sqrt{2}$）也可以做乘法（$(a+b\sqrt{2})(c+d\sqrt{2}) = (ac+2bd)+(ad+bc)\sqrt{2}$）。环论就是为这种"双运算"场景提供的统一语言。

更重要的是，**多项式环** $F[x]$ 是连接环论和域论的桥梁。域扩张的构造（分裂域、代数闭包）都依赖于多项式环的性质。理解环的基本结构，是理解 Galois 理论代数基础的前提。
:::

## 环的公理

::: definition 环 {#def-ring}
一个**环**是一个三元组 $(R, +, \cdot)$，其中 $R$ 是非空集合，$+$ 和 $\cdot$ 是 $R$ 上的二元运算（分别称为**加法**和**乘法**），满足以下公理：

**(R1)** $(R, +)$ 是交换群（单位元记为 $0$，称为**零元**；$a$ 的加法逆元记为 $-a$）。

**(R2)** 乘法结合律：$(ab)c = a(bc)$ 对所有 $a, b, c \in R$。

**(R3)** 分配律：$a(b + c) = ab + ac$ 和 $(b + c)a = ba + ca$ 对所有 $a, b, c \in R$。
:::

::: tip 直觉
环的公理并**不要求**乘法有单位元、交换律或消去律。这是一个非常宽松的定义。实际使用中，我们会根据需要施加额外条件。
:::

::: example 环的基本例子 {#ex-ring-examples}

1. **整数环** $(\mathbb{Z}, +, \cdot)$：最经典的环，单位元为 1。
2. **多项式环** $R[x]$：系数在环 $R$ 中的多项式的集合，按通常的多项式加法和乘法构成环。这是 Galois 理论中最重要的环之一。
3. **整数模 $n$** $\mathbb{Z}/n\mathbb{Z}$：陪集集合 $\{\overline{0}, \overline{1}, \ldots, \overline{n-1}\}$，模 $n$ 的加法和乘法。当 $n$ 是素数时，这是一个域。
4. **域上的矩阵环** $M_n(F)$：非交换的典型例子（当 $n \geq 2$），单位元为单位矩阵 $I_n$。
5. **连续函数环** $C[0,1]$：区间 $[0,1]$ 上实值连续函数的逐点加法和乘法。零元是零函数，单位元是常函数 $f(x) \equiv 1$。
6. **偶数环** $2\mathbb{Z}$：**不含幺**的环。乘法结合律和分配律都满足，但不存在 $e \in 2\mathbb{Z}$ 使得 $e \cdot 2 = 2$（因为 $1 \notin 2\mathbb{Z}$）。这个例子说明，环的公理确实允许不含单位元的结构存在。
7. **$n \times n$ 上三角矩阵环**：所有上三角矩阵的集合，按矩阵加法和乘法构成非交换环。单位元为 $I_n$。
:::

::: info 例子 6 的意义
$2\mathbb{Z}$ 是一个不含单位元的环，但它在代数中确实出现（例如在代数数论中，代数整数环的某些子结构可能不含单位元）。这提醒我们：虽然本教程默认使用含幺交换环，但**不含幺的环也有其数学意义**，不应该被遗忘。
:::

## 约定

::: notation
- 若乘法还满足交换律，则称 $R$ 为**交换环**。
- 若存在元素 $1 \in R$ 使得 $1 \cdot a = a \cdot 1 = a$ 对所有 $a$ 成立，则 $1$ 称为 $R$ 的**单位元**（或**恒等元**），$(R, +, \cdot, 1)$ 称为**含幺环**。
- 本教程默认所有环都是含幺交换环，除非特别说明。
:::

::: info 为什么默认"含幺交换"？
这不是任意的约定。原因有三：

1. **Galois 理论的核心对象**：域、多项式环、代数整数环都是含幺交换环。默认这个约定可以避免在每句话后面加"假设 $R$ 是含幺交换的"。
2. **范畴论的一致性**：含幺环之间的同态要求保持单位元（$f(1) = 1$），这使得环的范畴具有更好的性质。
3. **"无零因子"才有意义**：消去律 $ab = ac \Rightarrow b = c$ 只在无零因子的环中成立，而这与整环的定义紧密相连。

如果你在其它文献中读到"环"，需要注意作者是否假定含幺、交换。
:::

## 零因子与整环

::: definition 零因子 {#def-zero-divisor}
设 $R$ 为环。元素 $a \in R$，$a \neq 0$，称为 $R$ 的一个**零因子**，如果存在 $b \in R$，$b \neq 0$，使得 $ab = 0$。
:::

::: definition 整环 {#def-integral-domain}
一个**整环**是含幺交换环，且没有零因子（即 $ab = 0$ 蕴含 $a = 0$ 或 $b = 0$）。
:::

::: info 为什么叫"整环"？
"整"来自"整数"（integral），"环"就是 ring。"整环"的字面意思是"像整数一样好的环"——整数环 $\mathbb{Z}$ 中，$ab = 0$ 当且仅当 $a = 0$ 或 $b = 0$。整环就是满足这个"好"性质的环。
:::

::: example 整环与非整环 {#ex-integral-domain}

1. $\mathbb{Z}$ 是整环。
2. $\mathbb{Q}$，$\mathbb{R}$，$\mathbb{C}$ 都是整环（事实上都是域）。
3. $\mathbb{Z}/6\mathbb{Z}$ 不是整环：$\overline{2} \cdot \overline{3} = \overline{0}$，$\overline{2}$ 和 $\overline{3}$ 都是零因子。
4. $\mathbb{Z}/p\mathbb{Z}$（$p$ 素数）是整环（事实上是域）。
5. $R[x]$ 是整环当且仅当 $R$ 是整环。
6. $\mathbb{Z}/4\mathbb{Z}$ 不是整环：$\overline{2} \cdot \overline{2} = \overline{0}$，$\overline{2}$ 是零因子。
7. $M_2(\mathbb{R})$ 不是整环（而且不是交换环）：$\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$。
:::

::: info 更多零因子的计算
在 $\mathbb{Z}/12\mathbb{Z}$ 中，哪些元素是零因子？

- $\overline{2} \cdot \overline{6} = \overline{0}$，所以 $\overline{2}$ 和 $\overline{6}$ 是零因子。
- $\overline{3} \cdot \overline{4} = \overline{0}$，所以 $\overline{3}$ 和 $\overline{4}$ 是零因子。
- $\overline{8} \cdot \overline{3} = \overline{0}$，所以 $\overline{8}$ 是零因子。
- 事实上，$\overline{a}$ 是零因子当且仅当 $\gcd(a, 12) > 1$。

一般地，在 $\mathbb{Z}/n\mathbb{Z}$ 中，$\overline{a}$ 是零因子当且仅当 $\gcd(a, n) > 1$。$\overline{a}$ 是单位当且仅当 $\gcd(a, n) = 1$。**每个元素要么是零因子，要么是单位，要么是零**（因为 $\mathbb{Z}/n\mathbb{Z}$ 是主理想环的商）。
:::

::: theorem 整环中的消去律 {#thm-cancellation}
设 $R$ 是整环，$a, b, c \in R$，$a \neq 0$。若 $ab = ac$，则 $b = c$。
:::

<ProofToggle>

::: proof
$ab = ac$ 蕴含 $a(b - c) = 0$。因为 $R$ 是整环且 $a \neq 0$，所以 $b - c = 0$，即 $b = c$。
:::

</ProofToggle>

::: info 消去律的意义
消去律是整环最重要的性质之一。它说明在整环中，我们可以像在 $\mathbb{Z}$ 中一样进行"约分"。在非整环中（如 $\mathbb{Z}/6\mathbb{Z}$），$\overline{2} \cdot \overline{1} = \overline{2} \cdot \overline{4}$ 但 $\overline{1} \neq \overline{4}$，消去律失效。

**消去律等价于无零因子**（对含幺交换环）：若消去律成立且 $ab = 0$，$a \neq 0$，则 $ab = a \cdot 0$，由消去律得 $b = 0$。
:::

## 单位与可逆元

::: definition 单位 {#def-unit}
环 $R$ 中的元素 $u$ 称为**单位**（或**可逆元**），如果存在 $v \in R$ 使得 $uv = 1$。所有单位的集合记为 $R^*$ 或 $R^\times$。
:::

::: proposition {#prop-units-form-group}
对任意含幺环 $R$，$(R^*, \cdot)$ 构成一个群，称为 $R$ 的**单位群**。
:::

<ProofToggle>

::: proof
- $1 \in R^*$（因 $1 \cdot 1 = 1$）。
- 若 $u, v \in R^*$，则 $(uv)(v^{-1}u^{-1}) = 1$，故 $uv \in R^*$。
- 若 $u \in R^*$ 有逆 $u^{-1}$，则 $(u^{-1})^{-1} = u \in R^*$。
- 乘法结合律继承自 $R$。
:::

</ProofToggle>

::: example 单位群 {#ex-unit-groups}

1. $\mathbb{Z}^* = \{-1, 1\} \cong \mathbb{Z}/2\mathbb{Z}$。
2. $\mathbb{Q}^* = \mathbb{Q} \setminus \{0\}$（域中每个非零元素都可逆）。
3. $(\mathbb{Z}/n\mathbb{Z})^* = \{\overline{a} : \gcd(a,n) = 1\}$，$|(\mathbb{Z}/n\mathbb{Z})^*| = \varphi(n)$（Euler 函数）。
4. $F[x]^* = F^*$（多项式环中的单位恰好是常数多项式中的非零常数）。这是因为 $\deg(fg) = \deg f + \deg g$，若 $fg = 1$ 则 $\deg f = \deg g = 0$。
5. $M_n(F)^* = GL_n(F)$：矩阵环的单位群就是一般线性群，即可逆矩阵的集合。
:::

::: warning 零因子 ≠ 幂零元 ≠ 非单位
这三个概念容易混淆，必须区分：

| 概念 | 定义 | 例子（在 $\mathbb{Z}/8\mathbb{Z}$ 中） |
|------|------|------|
| **零因子** | $a \neq 0$，$\exists b \neq 0$，$ab = 0$ | $\overline{2}, \overline{4}, \overline{6}$ |
| **幂零元** | $\exists n > 0$，$a^n = 0$ | $\overline{2}$（$2^3 = 8 \equiv 0$），$\overline{4}$（$4^2 = 16 \equiv 0$） |
| **非单位** | $a$ 没有乘法逆元 | $\overline{0}, \overline{2}, \overline{4}, \overline{6}$ |

关系：幂零元 $\Rightarrow$ 零因子 $\Rightarrow$ 非单位，但反过来都不成立。
- $\overline{6}$ 在 $\mathbb{Z}/8\mathbb{Z}$ 中是零因子（$6 \cdot 4 = 24 \equiv 0$）但不是幂零元（$6^n \equiv 0 \pmod{8}$ 无解，因为 $6^2 = 36 \equiv 4$，$6^3 \equiv 0$... 等等，$6^3 = 216 = 27 \times 8$，所以 $\overline{6}^3 = \overline{0}$。实际上 $\overline{6}$ 也是幂零元）。
- 在 $\mathbb{Z}/12\mathbb{Z}$ 中，$\overline{6}$ 是零因子（$6 \cdot 2 = 12 \equiv 0$）但不是幂零元（$6^2 = 36 \equiv 0 \pmod{12}$... $36 = 3 \times 12$，所以 $\overline{6}^2 = \overline{0}$。也是幂零元）。
- 更好的例子：在 $\mathbb{Z}/6\mathbb{Z}$ 中，$\overline{2}$ 是零因子但不是幂零元（$2^n \mod 6$ 循环：$2, 4, 2, 4, \ldots$，永远不为 $0$）。
:::

::: info 域：零因子数为零的极端情况
域是整环的"极致"：不仅没有零因子，而且每个非零元素都是单位。整环到域的过渡，正是 Galois 理论的核心主题之一。我们将在第三章系统讨论域的结构。
:::

## 零环与平凡环

::: definition 零环 {#def-zero-ring}
只有一个元素的环 $R = \{0\}$（加法和乘法都平凡）称为**零环**。零环是含幺环（$1 = 0$），但**不是整环**（按本教程的约定，整环要求 $1 \neq 0$）。
:::

::: info 为什么排除零环？
如果允许 $1 = 0$，则 $R = \{0\}$，每个元素都是零。这个环太"平凡"了，几乎没有有用的性质。例如，在零环中，$R^* = \emptyset$（因为 $0 = 1$ 意味着 $0$ 是单位，但 $0$ 的"逆元"也是 $0$，这导致 $R^* = \{0\}$，但 $0$ 通常不被视为可逆元）。为了避免这种退化情况，**整环要求 $1 \neq 0$**。

在域的定义中，$1 \neq 0$ 也是隐含的假设。
:::

## 子环

::: definition 子环 {#def-subring}
设 $R$ 是环。$R$ 的非空子集 $S$ 称为 $R$ 的**子环**，如果 $S$ 对加法、乘法和取负封闭，且包含 $R$ 的单位元 $1$。
:::

::: example 子环

1. $\mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$：整数环是 $\mathbb{Q}$ 的子环，$\mathbb{Q}$ 是 $\mathbb{R}$ 的子环，以此类推。
2. $\mathbb{Z}[i] = \{a + bi : a, b \in \mathbb{Z}\}$（Gauss 整数环）是 $\mathbb{C}$ 的子环。
3. $\mathbb{Z}[\sqrt{2}] = \{a + b\sqrt{2} : a, b \in \mathbb{Z}\}$ 是 $\mathbb{R}$ 的子环。
4. $2\mathbb{Z}$ 不是 $\mathbb{Z}$ 的子环（按本教程的约定），因为它不含 $1$。
:::

::: info 子环检验
$S$ 是 $R$ 的子环当且仅当：$1 \in S$，且对所有 $a, b \in S$，$a - b \in S$ 和 $ab \in S$。这比验证所有环公理更方便。
:::

## 从环到域的阶梯

::: info 概念层级
理解环的各种"好"性质之间的层级关系，是学习代数的基础：

$$\text{环} \supset \text{含幺环} \supset \text{含幺交换环} \supset \text{整环} \supset \text{唯一分解整环 (UFD)} \supset \text{主理想整环 (PID)} \supset \text{欧几里得整环} \supset \text{域}$$

- **域**：每个非零元素都有逆。例如 $\mathbb{Q}$，$\mathbb{R}$，$\mathbb{Z}/p\mathbb{Z}$。
- **欧几里得整环**：可以做"带余除法"。例如 $\mathbb{Z}$，$F[x]$。
- **主理想整环 (PID)**：每个理想都是主理想。例如 $\mathbb{Z}$，$F[x]$。
- **唯一分解整环 (UFD)**：元素可以唯一分解为不可约元的乘积。例如 $\mathbb{Z}$，$F[x]$，$\mathbb{Z}[x]$（$\mathbb{Z}[x]$ 是 UFD 但不是 PID）。

在 Galois 理论中，最常用的环是 $F[x]$（多项式环）和 $\mathbb{Z}$（整数环）。它们都是欧几里得整环，因此也是 PID 和 UFD。这些性质保证了不可约分解的唯一性和理想的良好结构。

详见：[§2.3 多项式环](/chapters/02-rings/2.3-polynomial-rings)、[§4.1 多项式的一般理论](/chapters/04-polynomials/4.1-general-theory)。
:::

## 环同态的初步

::: info 预告
环之间的映射（环同态）将在 [§2.2 理想与商环](/chapters/02-rings/2.2-ideals) 中系统讨论。这里只给出定义，为后续内容做准备。
:::

::: definition 环同态 {#def-ring-homomorphism-preview}
设 $R$，$S$ 是含幺环。映射 $\varphi: R \to S$ 称为**环同态**，如果对所有 $a, b \in R$：
- $\varphi(a + b) = \varphi(a) + \varphi(b)$
- $\varphi(ab) = \varphi(a)\varphi(b)$
- $\varphi(1_R) = 1_S$

**注意**：第三个条件（保持单位元）是本教程的约定。有些文献不要求环同态保持单位元。
:::

::: example 环同态

1. 包含映射 $\mathbb{Z} \hookrightarrow \mathbb{Q}$ 是环同态。
2. 模 $n$ 投影 $\mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$，$a \mapsto \overline{a}$，是环同态（核为 $n\mathbb{Z}$）。
3. 求值映射 $F[x] \to F$，$f(x) \mapsto f(\alpha)$（对固定 $\alpha \in F$）是环同态。
4. 复共轭 $\mathbb{C} \to \mathbb{C}$，$z \mapsto \overline{z}$，是环同态。
:::

## 常见误区 {#misconceptions}

::: warning 误区一：整环一定有限
**错误！** $\mathbb{Z}$，$\mathbb{Q}$，$\mathbb{R}$，$\mathbb{Z}[x]$ 都是整环，都是无限的。有限整环一定是域（因为有限整环中每个非零元素都是单位——可通过考虑 $a, a^2, a^3, \ldots$ 的有限性来证明），但整环本身不必有限。
:::

::: warning 误区二：环的乘法必须交换
**在一般环中不需要！** 矩阵环 $M_n(F)$（$n \geq 2$）是典型的非交换环。本教程默认交换，但 Galois 理论中偶尔会遇到非交换的情况（例如，Galois 群本身可以嵌入矩阵群）。
:::

::: warning 误区三：含幺环中 $0$ 和 $1$ 一定不同
**在整环和域中，$0 \neq 1$ 是定义的一部分。** 但在一般的含幺环中，$1 = 0$ 是可能的——此时环是零环 $\{0\}$。零环虽然"无聊"，但它在技术上满足含幺环的所有公理。
:::

::: warning 误区四：单位群一定是有限群
**错误！** $\mathbb{Q}^* = \mathbb{Q} \setminus \{0\}$ 是无限群。$F[x]^* = F^*$ 是有限的当且仅当 $F$ 是有限域。一般地，域的单位群就是域本身的乘法群，可以是无限的。
:::

## 自测问题 {#self-test}

::: exercise 自测
1. **零因子检验**：在 $\mathbb{Z}/15\mathbb{Z}$ 中，列出所有零因子和所有单位。验证你的答案。

2. **整环判定**：$\mathbb{Z}[x]/(x^2 + 1)$ 是否是整环？（提示：$\mathbb{Z}[x]/(x^2 + 1) \cong \mathbb{Z}[i]$。）

3. **单位群计算**：计算 $(\mathbb{Z}/7\mathbb{Z})^*$ 的阶和结构。它同构于什么群？

4. **消去律应用**：在 $\mathbb{Z}/12\mathbb{Z}$ 中，$\overline{3} \cdot \overline{4} = \overline{3} \cdot \overline{8}$。为什么不能消去 $\overline{3}$ 得到 $\overline{4} = \overline{8}$？

5. **概念辨析**：解释为什么"无零因子"和"每个非零元素可逆"是不同的条件。给出一个是整环但不是域的例子。
:::

::: details 答案
1. $\mathbb{Z}/15\mathbb{Z}$ 中，$\gcd(a, 15) > 1$ 的元素是零因子：$\overline{3}, \overline{5}, \overline{6}, \overline{9}, \overline{10}, \overline{12}$。单位是 $\gcd(a, 15) = 1$ 的元素：$\overline{1}, \overline{2}, \overline{4}, \overline{7}, \overline{8}, \overline{11}, \overline{13}, \overline{14}$。$|(\mathbb{Z}/15\mathbb{Z})^*| = \varphi(15) = 8$。

2. 是整环。$\mathbb{Z}[x]/(x^2 + 1) \cong \mathbb{Z}[i]$（Gauss 整数环），这是 $\mathbb{C}$ 的子环，因此没有零因子。

3. $|(\mathbb{Z}/7\mathbb{Z})^*| = \varphi(7) = 6$。因为 $7$ 是素数，$(\mathbb{Z}/7\mathbb{Z})^* \cong \mathbb{Z}/6\mathbb{Z}$（循环群）。事实上，$\overline{3}$ 是一个生成元：$3^1 = 3, 3^2 = 2, 3^3 = 6, 3^4 = 4, 3^5 = 5, 3^6 = 1$。

4. $\overline{3}$ 是零因子（$3 \cdot 5 = 15 \equiv 0$），所以消去律不适用。$3 \cdot 4 = 12 \equiv 0$，$3 \cdot 8 = 24 \equiv 0$，所以 $\overline{3} \cdot \overline{4} = \overline{3} \cdot \overline{8} = \overline{0}$，但 $\overline{4} \neq \overline{8}$。

5. 整环中每个非零元素**可以消去**（消去律），但不一定**可以求逆**。例如 $\mathbb{Z}$ 中，$2 \neq 0$ 且 $2$ 不是零因子，但 $2$ 没有乘法逆元（$\frac{1}{2} \notin \mathbb{Z}$）。所以 $\mathbb{Z}$ 是整环但不是域。
:::
