# 2.4 中国剩余定理

## 动机

在 [§2.2](/chapters/02-rings/2.2-ideals) 中，我们看到互素理想的定义：$I + J = R$。中国剩余定理（Chinese Remainder Theorem, CRT）是互素理想性质的深刻体现——它告诉我们，当理想的成对互素条件满足时，环模它们的交同构于各个商环的直积。用一句话概括：**在互素条件下，局部信息的直积等价于全局信息**。

这个定理在数论（整数模同余）、代数几何（粘合概形层）和计算机科学（高效算术）中都有核心应用。

## 互素理想的回顾

::: definition 互素理想 {#def-coprime-ideals}
环 $R$ 的两个理想 $I, J$ 称为**互素**的（coprime），如果 $I + J = R$。等价地，存在 $a \in I, b \in J$ 使得 $a + b = 1$。
:::

::: remark
互素理想的条件比 $I \cap J = \{0\}$ 强得多。对于 $R = \mathbb{Z}$，理想 $m\mathbb{Z}$ 和 $n\mathbb{Z}$ 互素当且仅当 $\gcd(m, n) = 1$。
:::

## 中国剩余定理（两个理想的情形）

::: theorem 中国剩余定理（CRT） {#thm-crt}
设 $I, J$ 是交换环 $R$ 的两个互素理想。则：

**(1)** $I \cap J = IJ$

**(2)** 自然环同态
$$\varphi: R \to R/I \times R/J, \quad r \mapsto (r + I, r + J)$$
的核为 $I \cap J$，且 $\varphi$ 是满射。因此
$$R/(I \cap J) \cong R/I \times R/J$$

更精确地，$\ker\varphi = I \cap J = IJ$，故 $R/IJ \cong R/I \times R/J$。
:::

<ProofToggle>

**证明**

**(1)** 一般总有 $IJ \subseteq I \cap J$（因为 $I$ 和 $J$ 都是理想）。反过来，设 $c \in I \cap J$。由于 $I + J = R$，存在 $a \in I, b \in J$ 使得 $a + b = 1$。于是
$$c = c \cdot 1 = ca + cb.$$
其中 $ca \in J$（因为 $c \in J$）且 $ca \in I$（因为 $a \in I$），即 $ca \in IJ$。类似地 $cb \in IJ$（因为 $c \in I, b \in J$）。因此 $c = ca + cb \in IJ$。

**(2)** 核的计算：$\ker\varphi = \{r \in R : r \in I \text{ 且 } r \in J\} = I \cap J$。

满射性：给定 $(r_1 + I, r_2 + J) \in R/I \times R/J$，由 $I + J = R$ 知存在 $a \in I, b \in J$ 使得 $a + b = 1$。令 $r = r_2 a + r_1 b$，则：
- $r - r_1 = r_2 a + r_1 b - r_1 = r_2 a + r_1(b - 1) = r_2 a - r_1 a = (r_2 - r_1)a \in I$（因为 $a \in I$），故 $r + I = r_1 + I$。
- $r - r_2 = r_2 a + r_1 b - r_2 = r_2(a - 1) + r_1 b = -r_2 b + r_1 b = (r_1 - r_2)b \in J$（因为 $b \in J$），故 $r + J = r_2 + J$。

由 {thm-first-isomorphism}（环同态基本定理），$R/\ker\varphi \cong \operatorname{im}\varphi = R/I \times R/J$。$\square$

</ProofToggle>

## 中国剩余定理（一般形式）

::: theorem 中国剩余定理（一般形式） {#thm-crt-general}
设 $I_1, I_2, \ldots, I_n$ 是交换环 $R$ 的**两两互素**理想（即 $I_i + I_j = R$ 对所有 $i \neq j$）。则：

**(1)** $I_1 \cap I_2 \cap \cdots \cap I_n = I_1 I_2 \cdots I_n$

**(2)** 自然环同态
$$\varphi: R \to R/I_1 \times R/I_2 \times \cdots \times R/I_n, \quad r \mapsto (r + I_1, \ldots, r + I_n)$$
是满射，其核为 $I_1 \cap \cdots \cap I_n$。因此
$$R/(I_1 \cap \cdots \cap I_n) \cong R/I_1 \times R/I_2 \times \cdots \times R/I_n$$
:::

<ProofToggle>

**证明** 对 $n$ 进行归纳。

**基础** $n = 2$ 即 {thm-crt}。

**归纳步骤**：假设结论对 $n - 1$ 成立。令 $J = I_1 \cap \cdots \cap I_{n-1}$，则归纳假设给出 $R/J \cong R/I_1 \times \cdots \times R/I_{n-1}$。

现在只需证明 $J + I_n = R$，然后对 $J$ 和 $I_n$ 应用 $n = 2$ 的情形。

对每个 $i < n$，由 $I_i + I_n = R$，存在 $a_i \in I_i, b_i \in I_n$ 使得 $a_i + b_i = 1$，即 $a_i = 1 - b_i \in I_i + I_n$ 且 $a_i \equiv 1 \pmod{I_n}$。

令 $a = a_1 a_2 \cdots a_{n-1}$。则：
- 对每个 $i < n$：$a \equiv 0 \pmod{I_i}$（因为 $a_i \in I_i$ 是乘积的一个因子），故 $a \in I_1 \cap \cdots \cap I_{n-1} = J$。
- $a \equiv 1 \pmod{I_n}$（因为每个 $a_i \equiv 1 \pmod{I_n}$）。

因此 $a \in J$ 且 $1 - a \in I_n$，即 $1 = a + (1 - a) \in J + I_n$，所以 $J + I_n = R$。

对 $J$ 和 $I_n$ 应用 {thm-crt}：$R/J \cap I_n \cong R/J \times R/I_n \cong R/I_1 \times \cdots \times R/I_n$。$\square$

</ProofToggle>

## 经典例子

### 整数环

::: example 整数环中的 CRT {#ex-crt-integers}
取 $R = \mathbb{Z}$，理想 $m_1 \mathbb{Z}, \ldots, m_n \mathbb{Z}$ 两两互素当且仅当 $m_1, \ldots, m_n$ 两两互质。此时：

$$\mathbb{Z}/(m_1 \cdots m_n)\mathbb{Z} \cong \mathbb{Z}/m_1\mathbb{Z} \times \cdots \times \mathbb{Z}/m_n\mathbb{Z}$$

这是经典的数论 CRT：同余方程组
$$x \equiv a_1 \pmod{m_1}, \quad \ldots, \quad x \equiv a_n \pmod{m_n}$$
在 $\mathbb{Z}/(m_1 \cdots m_n)\mathbb{Z}$ 中有唯一解。

**具体数值**：取 $m_1 = 3, m_2 = 5, m_3 = 7$。则
$$\mathbb{Z}/105\mathbb{Z} \cong \mathbb{Z}/3\mathbb{Z} \times \mathbb{Z}/5\mathbb{Z} \times \mathbb{Z}/7\mathbb{Z}$$

给定同余方程组 $x \equiv 2 \pmod{3}$, $x \equiv 3 \pmod{5}$, $x \equiv 4 \pmod{7}$，CRT 保证解存在且在 $\mathbb{Z}/105\mathbb{Z}$ 中唯一。逐一构造可得 $x = 53$。
:::

### 多项式环

::: example 多项式环中的 CRT {#ex-crt-polynomials}
取 $R = F[x]$，$F$ 为域。设 $f_1, \ldots, f_n \in F[x]$ 两两互素（即 $\gcd(f_i, f_j) = 1$ 对 $i \neq j$）。则

$$F[x]/(f_1 \cdots f_n) \cong F[x]/(f_1) \times \cdots \times F[x]/(f_n)$$

这是**多项式插值**的抽象表述。特别地，取 $f_i = x - a_i$（$a_i$ 两两不同），则 $F[x]/(x - a_i) \cong F$，CRT 给出：

$$F[x]/\prod_{i=1}^n (x - a_i) \cong F^n$$

这正是 Lagrange 插值定理：给定 $n$ 个点 $(a_i, b_i)$，存在唯一的次数 $< n$ 的多项式通过所有这些点。
:::

### 与域扩张的联系

::: remark CRT 与域扩张 {#rem-crt-field-extensions}
设 $f(x) = f_1(x) \cdots f_n(x) \in F[x]$，其中 $f_i$ 是不同的不可约多项式。则

$$F[x]/(f) \cong F[x]/(f_1) \times \cdots \times F[x]/(f_n)$$

每个 $F[x]/(f_i)$ 都是 $F$ 的域扩张（由 [§2.3](/chapters/02-rings/2.3-polynomial-rings) 中的 {thm-irreducible-maximal}）。因此 CRT 告诉我们：**模一个可约多项式的环，等于模各个不可约因子的域扩张的直积**。

这在 [分裂域](/chapters/05-splitting-fields/) 理论中有重要作用：当多项式在 $F$ 上可分解为互素因子时，域的结构可以逐因子分析。
:::

## 进一步应用

### 局部化

::: remark CRT 与局部化 {#rem-crt-localization}
CRT 是代数几何中**粘合**（gluing）技术的代数原型。给定仿射概形 $X = \operatorname{Spec} R$，理想 $I_1, \ldots, I_n$ 两两互素意味着对应的闭子集 $V(I_j)$ 在某种意义上"覆盖"了 $X$。CRT 告诉我们，$R$ 的结构可以由各 $R/I_j$ 的信息"粘合"而成。
:::

### 中国剩余定理的推广

::: remark 推广方向 {#rem-crt-generalizations}
1. **模论版本**：设 $M$ 是 $R$-模，$I_1, \ldots, I_n$ 两两互素理想。则 $M/(I_1 \cdots I_n M) \cong M/I_1 M \times \cdots \times M/I_n M$。证明与环的情形完全类似。

2. **Hensel 引理**：CRT 可以视为 $p$-adic 分析中 Hensel 引理的离散版本。Hensel 引理说，如果多项式模 $p$ 有单根，则它在 $\mathbb{Z}_p$ 中有精确提升——这是"逐素数分解"思想的完备化版本。

3. **带余除法视角**：在 $F[x]$ 中，CRT 等价于带余除法（Euclidean algorithm）：除以 $f_1 f_2$ 的余数由除以 $f_1$ 和除以 $f_2$ 的余数唯一确定。
:::
