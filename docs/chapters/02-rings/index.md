# 第二章 · 环与理想

环论是连接群论和域论的桥梁。本章从带两种运算的代数结构出发，建立环、理想、商环和多项式环的完整理论。多项式环 $F[x]$ 的特殊地位在于：它是构造域扩张的基本工具——不可约多项式给出极大理想，极大理想给出域扩张，而域扩张正是 Galois 理论的舞台。

::: tip 与前后章的联系
- **从群到环**：域的乘法群 $(F^*, \cdot)$ 和加法群 $(F, +)$ 都是交换群，通过分配律联系（{def-abelian}）。
- **从环到域**：域是没有非零零因子的交换环，且每个非零元素都有逆。整环的分式域构造给出了从环到域的标准方法。
- **从环到 Galois 理论**：不可约多项式 $f(x) \in F[x]$ 生成极大理想 $(f)$，从而 $F[x]/(f)$ 是一个域——这正是构造域扩张的基本方法，见 [§3 域论基础](/chapters/03-fields/) 和 [§5 分裂域](/chapters/05-splitting-fields/)。
:::
