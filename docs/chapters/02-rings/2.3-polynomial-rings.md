# §2.3 多项式环 {#sec-polynomial-rings}

## 学习目标

::: tip 本节目标
通过本节学习，你应该能够：
1. **定义**多项式环 $R[x]$，区分多项式作为"形式表达式"与作为"函数"的根本差异。
2. **证明**域上多项式环 $F[x]$ 是主理想整环（PID），并理解带余除法在此证明中的核心作用。
3. **判断**一个多项式在给定域上是否不可约，并运用不可约多项式与极大理想的关系构造域扩张。
4. **陈述**并**应用**唯一分解定理和 Gauss 引理。
5. **解释**为什么不可约多项式是构造域扩张的基本工具。
:::

## 动机

多项式环 $R[x]$ 是代数的核心。域扩张的构造、极小多项式的确定、分裂域的存在性——所有这些 Galois 理论的基本构件都依赖于多项式环的性质。本节建立多项式环的严格基础，为 [第四章 多项式](/chapters/04-polynomials/) 和 [第五章 分裂域与正规扩张](/chapters/05-splitting-fields/) 做准备。

## 形式多项式与函数：一个关键区分 {#formal-vs-function}

在进入正式定义之前，必须厘清一个贯穿代数学的根本区别。

::: warning 形式多项式 ≠ 函数
在微积分中，"多项式"通常指一个函数 $f(x) = a_0 + a_1 x + \cdots + a_n x^n$，其意义由"代入值、算结果"决定。但在代数中，**多项式是形式表达式**——它不依赖于任何特定的"代入"操作。

这个区分为什么重要？考虑 $\mathbb{F}_p$ 上的多项式 $f(x) = x^p - x$。作为函数，$f$ 在 $\mathbb{F}_p$ 的每个元素处取值为零（由 Fermat 小定理），所以 $f$ "看起来像是"零函数。但作为形式多项式，$f(x) = x^p - x$ **不是零多项式**——它的首项系数是 $1$，次数是 $p$。这个区分在 Galois 理论中至关重要：形式多项式的次数、不可约性、因式分解等概念，不能通过函数值来判断。
:::

**形式定义的核心思想**：一个多项式 $f(x) = \sum_{i=0}^{n} a_i x^i$ 只是一个**系数序列** $(a_0, a_1, \ldots, a_n, 0, 0, \ldots)$，其中只有有限项非零。不定元 $x$ 不是一个"变量"，而是一个标记位置的符号。

## 多项式的定义

::: definition 多项式环 {#def-polynomial-ring}
设 $R$ 是含幺交换环。$R$ 上的**多项式环** $R[x]$ 定义为所有形式表达式

$$f(x) = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n = \sum_{i=0}^{n} a_i x^i$$

的集合，其中 $n \geq 0$，$a_i \in R$。$x$ 是一个**不定元**（或称**形式变量**）。

**加法**和**乘法**按通常方式定义：
$$\left(\sum_i a_i x^i\right) + \left(\sum_i b_i x^i\right) = \sum_i (a_i + b_i) x^i$$
$$\left(\sum_i a_i x^i\right) \cdot \left(\sum_j b_j x^j\right) = \sum_k \left(\sum_{i+j=k} a_i b_j\right) x^k$$
:::

::: remark 为什么 $R[x]$ 本身是环
多项式环 $R[x]$ 在上述加法和乘法下构成含幺交换环。验证关键公理：

- **加法交换群**：逐项相加满足交换律、结合律，零多项式 $0 = \sum 0 \cdot x^i$ 是加法单位元。
- **乘法结合律**：需要计算 $(\sum a_i x^i)(\sum b_j x^j)(\sum c_k x^k)$ 的两种括号方式，比较 $x^n$ 项系数——由 $R$ 的结合律和分配律保证。
- **乘法单位元**：常数多项式 $1 = 1 + 0 \cdot x + 0 \cdot x^2 + \cdots$。
- **分配律**：由 $R$ 的分配律逐项推出。

注意我们只要求 $R$ 是含幺交换环——这对一般的 $R[x]$ 性质是足够的。
:::

::: definition 次数 {#def-degree}
设 $f(x) = \sum_{i=0}^n a_i x^i \in R[x]$，$a_n \neq 0$，$a_i = 0$ 对 $i > n$。则：

- $n$ 称为 $f$ 的**次数**，记为 $\deg f$。
- $a_n$ 称为 $f$ 的**首项系数**。
- 若首项系数为 1，称 $f$ 为**首一多项式**。
- 规定 $\deg 0 = -\infty$（约定 $-\infty + n = -\infty$，$-\infty < n$ 对所有 $n \in \mathbb{Z}$）。
:::

::: remark $\deg 0 = -\infty$ 的约定
为什么规定 $\deg 0 = -\infty$ 而非 $\deg 0 = 0$？因为我们需要公式 $\deg(fg) = \deg f + \deg g$ 对所有多项式成立，包括零多项式。若 $\deg 0 = 0$，则 $\deg(0 \cdot g) = 0$，但 $0 \cdot g = 0$，$\deg 0 = 0$——表面上可以。但若同时要求 $\deg(f + g) \leq \max(\deg f, \deg g)$，则 $\deg(0 + g) \leq \max(0, \deg g) = \deg g$，而 $\deg(0 + g) = \deg g$——也成立。

问题出在更微妙的地方：$\deg 0 = -\infty$ 保证了 $-\infty < n$ 对所有整数 $n$，使得"$\deg r < \deg g$"这一带余除法的条件即使在 $r = 0$ 时也能正确陈述（$-\infty < \deg g$ 总是成立）。这是数学中一种标准的"约定使得定理不需要分情况"的做法。
:::

::: proposition 次数的性质 {#prop-degree-polynomial}
对 $R[x]$ 中的多项式 $f, g \neq 0$：

1. $\deg(fg) = \deg f + \deg g$。
2. $\deg(f + g) \leq \max(\deg f, \deg g)$。
3. 若 $R$ 是整环，则 $fg \neq 0$；因此 $R[x]$ 是整环当且仅当 $R$ 是整环。
:::

<ProofToggle>

::: proof
**(1)** 设 $\deg f = m$，$\deg g = n$。则 $fg$ 的 $x^{m+n}$ 项的系数是 $a_m b_n$（来自 $i = m, j = n$ 的唯一贡献），且 $a_m b_n \neq 0$（因 $R$ 是含幺环且 $a_m, b_n \neq 0$——对一般环需要 $R$ 是整环保证这一点）。故 $\deg(fg) = m + n$。

**(2)** $(f + g)$ 的 $x^i$ 项系数为 $a_i + b_i$，故 $\deg(f + g) \leq \max(\deg f, \deg g)$。

**(3)** 由 (1)，$f \neq 0$，$g \neq 0$ 推出 $\deg(fg) = \deg f + \deg g \geq 0$，故 $fg \neq 0$。
:::

</ProofToggle>

::: warning 为什么需要"整环"条件
在一般含幺交换环 $R$ 上，$R[x]$ 不一定满足 $\deg(fg) = \deg f + \deg g$！例如取 $R = \mathbb{Z}/4\mathbb{Z}$，令 $f(x) = 2x + 1$，$g(x) = 2x + 1$。则：

$$fg = (2x+1)^2 = 4x^2 + 4x + 1 = 1 \quad (\text{在 } \mathbb{Z}/4\mathbb{Z}[x] \text{ 中})$$

所以 $\deg f = 1$，$\deg g = 1$，但 $\deg(fg) = 0 \neq 2$。这里的关键是 $\mathbb{Z}/4\mathbb{Z}$ 有零因子（$2 \cdot 2 = 0$），首项系数的乘积为零。

**Galois 理论的启示**：我们总是在域 $F$ 上工作，$F$ 是整环，所以 $F[x]$ 也一定是整环。这个"一直向上的链条"（域 $\Rightarrow$ 整环 $\Rightarrow$ 多项式环是整环）是 Galois 理论的基础。
:::

### 例子

::: example 具体的多项式环
1. $\mathbb{Z}[x]$：系数为整数的多项式。$3x^2 - 2x + 7 \in \mathbb{Z}[x]$。
2. $\mathbb{Q}[x]$：系数为有理数的多项式。$\frac{1}{2}x^3 + \sqrt{2}$ 不在 $\mathbb{Q}[x]$ 中（$\sqrt{2} \notin \mathbb{Q}$）。
3. $\mathbb{F}_5[x]$：系数在 $\{0,1,2,3,4\}$ 中的多项式。$x^2 + 2x + 3 \in \mathbb{F}_5[x]$。
4. $\mathbb{R}[x, y]$（多元多项式环）：含两个不定元 $x, y$ 的多项式，如 $x^2 + xy + y^2$。但本节只讨论单变量情况。
:::

## 带余除法

带余除法是多项式环理论的**技术核心**。它使得 $F[x]$ 获得了与 $\mathbb{Z}$ 类似的"除法结构"——这正是后续 PID、UFD 等结论的根基。

::: theorem 带余除法（多项式） {#thm-polynomial-division}
设 $F$ 是域，$f(x), g(x) \in F[x]$，$g(x) \neq 0$。则存在**唯一**的 $q(x), r(x) \in F[x]$ 使得

$$f(x) = g(x) q(x) + r(x), \quad \deg r < \deg g$$
:::

<ProofToggle>

::: proof
**存在性**：对 $\deg f$ 进行强归纳。

若 $\deg f < \deg g$，取 $q = 0$，$r = f$。

设 $\deg f \geq \deg g$。设 $f = a_m x^m + \cdots$，$g = b_n x^n + \cdots$（$a_m \neq 0$，$b_n \neq 0$，$m \geq n$）。令

$$f_1(x) = f(x) - a_m b_n^{-1} x^{m-n} g(x)$$

则 $\deg f_1 < \deg f$。由归纳假设，存在 $q_1, r$ 使得 $f_1 = g q_1 + r$，$\deg r < \deg g$。故

$$f = g(q_1 + a_m b_n^{-1} x^{m-n}) + r$$

取 $q = q_1 + a_m b_n^{-1} x^{m-n}$。

**唯一性**：设 $f = gq_1 + r_1 = gq_2 + r_2$，$\deg r_1, \deg r_2 < \deg g$。则 $g(q_1 - q_2) = r_2 - r_1$。若 $q_1 \neq q_2$，左边次数 $\geq \deg g$，右边次数 $< \deg g$，矛盾。故 $q_1 = q_2$，$r_1 = r_2$。
:::

</ProofToggle>

::: remark
{thm-polynomial-division} 要求 $F$ 是域（或至少 $g$ 的首项系数在 $R^*$ 中）。在 $\mathbb{Z}[x]$ 中，带余除法一般不成立：例如 $x + 1$ 不能除 $2x + 1$。
:::

### 工作实例

::: example 带余除法的计算 {#ex-polynomial-division}
在 $\mathbb{Q}[x]$ 中计算 $f(x) = x^4 + 2x^3 - x + 1$ 除以 $g(x) = x^2 + 1$。

**长除法**：

$$\begin{aligned}
f(x) &= x^4 + 2x^3 + 0 \cdot x^2 - x + 1 \\
&= (x^2 + 1) \cdot \underbrace{(x^2 + 2x - 1)}_{q(x)} + \underbrace{(-3x + 2)}_{r(x)}
\end{aligned}$$

验证：$(x^2 + 1)(x^2 + 2x - 1) = x^4 + 2x^3 - x^2 + x^2 + 2x - 1 = x^4 + 2x^3 + 2x - 1$。

加余数 $r = -3x + 2$：$x^4 + 2x^3 + 2x - 1 + (-3x + 2) = x^4 + 2x^3 - x + 1$。✓

故 $f(x) = (x^2 + 1)(x^2 + 2x - 1) + (-3x + 2)$，$\deg r = 1 < 2 = \deg g$。
:::

::: example 在有限域上的带余除法 {#ex-division-finite-field}
在 $\mathbb{F}_3[x]$ 中计算 $f(x) = x^3 + 2x^2 + 1$ 除以 $g(x) = x + 1$。

注意在 $\mathbb{F}_3$ 中，$-1 = 2$。

$$x^3 + 2x^2 + 1 = (x + 1)(x^2 + x + 2) + 2$$

验证（在 $\mathbb{F}_3$ 中）：$(x + 1)(x^2 + x + 2) = x^3 + x^2 + 2x + x^2 + x + 2 = x^3 + 2x^2 + 0 \cdot x + 2$。

加余数 $2$：$x^3 + 2x^2 + 2 + 2 = x^3 + 2x^2 + 4 = x^3 + 2x^2 + 1$（在 $\mathbb{F}_3$ 中 $4 = 1$）。✓
:::

## 不可约多项式

::: definition 不可约多项式 {#def-irreducible-polynomial}
设 $F$ 是域。$F[x]$ 中次数 $\geq 1$ 的多项式 $f(x)$ 称为在 $F$ 上**不可约**，如果 $f$ 不能写成两个次数更低的多项式的乘积：即 $f = gh$ 蕴含 $\deg g = 0$ 或 $\deg h = 0$。
:::

::: intuition
不可约多项式在域论中的地位类似于素数在整数论中的地位。就像每个整数可以唯一分解为素数乘积，每个域上的多项式可以唯一分解为不可约多项式的乘积。更关键的是，不可约多项式直接给出域扩张：若 $f(x)$ 在 $K$ 上不可约，则 $K[x]/(f(x))$ 是一个域（{thm-maximal-field}），包含了 $f$ 的一个根。
:::

### 不可约性依赖于基域

::: example 不可约多项式 {#ex-irreducible}

1. $x^2 + 1$ 在 $\mathbb{R}$ 上不可约（无实根）。
2. $x^2 + 1$ 在 $\mathbb{C}$ 上可约：$x^2 + 1 = (x + i)(x - i)$。
3. $x^2 - 2$ 在 $\mathbb{Q}$ 上不可约（{thm-eisenstein}，取 $p = 2$）。
4. $x^2 - 2$ 在 $\mathbb{R}$ 上可约：$(x - \sqrt{2})(x + \sqrt{2})$。
5. $x^p - x$ 在 $\mathbb{F}_p$ 上完全可约：$x^p - x = \prod_{a \in \mathbb{F}_p}(x - a)$。
:::

::: warning "不可约"不是多项式的内在属性
一个多项式是否不可约，取决于它在**哪个域**上考虑。这正是 Galois 理论的核心来源：同一个多项式在不同域上具有不同的分解行为，这些差异编码了域之间的代数关系。

具体例子：$x^4 - 2$ 在 $\mathbb{Q}$ 上不可约，但在 $\mathbb{R}$ 上分解为 $(x^2 - \sqrt{2})(x^2 + \sqrt{2})$，在 $\mathbb{C}$ 上完全分解为 $(x - \sqrt[4]{2})(x + \sqrt[4]{2})(x - i\sqrt[4]{2})(x + i\sqrt[4]{2})$。
:::

### 次数 2 和 3 的不可约性判据

::: proposition 低次多项式的不可约判据 {#prop-low-degree-irreducible}
设 $F$ 是域。

1. $\deg f = 2$ 或 $3$ 的多项式 $f \in F[x]$ 在 $F$ 上不可约 $\iff$ $f$ 在 $F$ 中没有根。
2. 特别地，$\deg f = 2$ 或 $3$ 的多项式 $f$ 在代数闭域上**一定可约**（若 $\deg f \geq 2$）。
:::

<ProofToggle>

::: proof
$(\Rightarrow)$：若 $f$ 有根 $\alpha \in F$，则 $(x - α) \mid f$，故 $f$ 可约（当 $\deg f \geq 2$ 时）。

$(\Leftarrow)$：设 $f$ 可约，$f = gh$，$\deg g, \deg h \geq 1$。因 $\deg f = \deg g + \deg h$ 且 $\deg f \leq 3$，必有 $\deg g = 1$ 或 $\deg h = 1$。若 $\deg g = 1$，设 $g = ax + b$，则 $g(-b/a) = 0$，即 $-b/a$ 是 $f$ 的根。
:::

</ProofToggle>

::: remark 高次多项式没有简单的根检验
对 $\deg f \geq 4$，"没有根"不等于"不可约"。例如 $f(x) = (x^2 + 1)^2 = x^4 + 2x^2 + 1$ 在 $\mathbb{R}$ 上没有根，但在 $\mathbb{R}$ 上可约（$f = (x^2 + 1)(x^2 + 1)$）。因此对高次多项式，需要更精巧的不可约性判据——见 [§4.2 不可约性判据](/chapters/04-polynomials/4.2-irreducibility)。
:::

## PID 与不可约元的极大性

::: theorem {#thm-ideal-is-principal}
设 $F$ 是域。则 $F[x]$ 是**主理想整环**（PID）：每个理想都是主理想。
:::

<ProofToggle>

::: proof
设 $I$ 是 $F[x]$ 的理想，$I \neq \{0\}$。取 $I$ 中次数最低的非零多项式 $g$（良序原理）。对任意 $f \in I$，由 {thm-polynomial-division}，$f = gq + r$，$\deg r < \deg g$。因 $r = f - gq \in I$ 且 $\deg r < \deg g$，$g$ 的选取推出 $r = 0$。故 $f \in (g)$，即 $I = (g)$。
:::

</ProofToggle>

::: intuition PID 结构的核心地位
这个定理说明 $F[x]$ 的理想结构极为简单——每个理想由一个多项式生成。这个结论来自带余除法，而带余除法又来自 $F$ 是域（可以"除以首项系数"）。

PID 结构的深远后果：
- **不可约元 $\Leftrightarrow$ 素元**：在 PID 中这两个概念等价。
- **极大理想判据**：$(f)$ 极大 $\iff$ $f$ 不可约（见下文）。
- **构造域扩张**：不可约多项式给出极大理想，商环是域。
:::

::: corollary {#cor-irreducible-maximal} {#prop-irreducible-implies-maximal}
在 $F[x]$（$F$ 是域）中，$(f(x))$ 是极大理想 $\iff$ $f(x)$ 不可约。
:::

<ProofToggle>

::: proof
$(\Rightarrow)$：设 $(f)$ 是极大理想但 $f = gh$，$\deg g < \deg f$，$\deg h < \deg f$。则 $(f) \subseteq (g) \subseteq F[x]$，由极大性 $(g) = F[x]$ 或 $(g) = (f)$。前者推出 $g$ 是单位（$\deg g = 0$）；后者推出 $f | g$（即 $\deg f \leq \deg g$），矛盾。

($\Leftarrow)$：设 $f$ 不可约。设 $(f) \subseteq (g) \subseteq F[x]$，$g \in I$。由 $f \in (g)$，$f = gh$。因 $f$ 不可约，$g$ 或 $h$ 是单位。若 $g$ 是单位，$(g) = F[x]$；若 $h$ 是单位，$g = fh^{-1}$，$(g) = (f)$。
:::

</ProofToggle>

::: remark 从不可约多项式到域扩张的桥梁
{cor-irreducible-maximal} 的实际意义可以浓缩为一条"一句话定理"：

> **$f$ 不可约 $\Rightarrow$ $F[x]/(f)$ 是域。**

这就是构造域扩张的标准方法。例如：
- $x^2 + 1$ 在 $\mathbb{R}$ 上不可约，故 $\mathbb{R}[x]/(x^2 + 1) \cong \mathbb{C}$——"发明虚数单位 $i$"的严格实现。
- $x^2 - 2$ 在 $\mathbb{Q}$ 上不可约，故 $\mathbb{Q}[x]/(x^2 - 2) \cong \mathbb{Q}(\sqrt{2})$——"添加 $\sqrt{2}$"的严格实现。

这个构造将在 [§3.2 域的基本扩张](/chapters/03-fields/3.2-basic-extensions) 和 [§5.1 分裂域](/chapters/05-splitting-fields/5.1-splitting-fields) 中反复使用。
:::

## 唯一分解与 Gauss 引理 {#ufd-gauss}

::: theorem 唯一分解定理（$F[x]$） {#thm-ufd-polynomial}
设 $F$ 是域。则 $F[x]$ 是**唯一分解整环**（UFD）：每个非常数多项式 $f \in F[x]$ 可以写成
$$f = c \cdot p_1(x) p_2(x) \cdots p_r(x),$$
其中 $c \in F^\times$ 是首项系数，$p_i$ 是首一不可约多项式。这个分解在不计排列顺序的意义下是唯一的。
:::

<ProofToggle>

**证明.** **存在性**：对 $\deg f$ 归纳。若 $f$ 不可约，取 $c$ 为首项系数，$f/c$ 为首一不可约多项式。否则 $f = gh$，$1 \leq \deg g, \deg h < \deg f$，对 $g, h$ 分别应用归纳。

**唯一性**：设 $c \cdot p_1 \cdots p_r = c' \cdot q_1 \cdots q_s$（$p_i, q_j$ 首一不可约）。比较首项系数得 $c = c'$。对 $r$ 归纳：$p_1 \mid q_1 \cdots q_s$。因 $F[x]$ 是 PID（{thm-ideal-is-principal}），不可约元等价于素元，故 $p_1 \mid q_j$ 对某个 $j$。因 $q_j$ 首一不可约，$p_1 = q_j$。约去后对 $r - 1$ 归纳。$\blacksquare$

</ProofToggle>

::: example 唯一分解的具体计算 {#ex-ufd}
在 $\mathbb{Q}[x]$ 中分解 $f(x) = 6x^3 - 5x^2 - 2x + 1$。

使用有理根定理，$f$ 的有理根只能是 $\pm 1, \pm \frac{1}{2}, \pm \frac{1}{3}, \pm \frac{1}{6}$。代入得 $f(1) = 0$，故 $(x - 1) \mid f$。

带余除法得 $f(x) = (x - 1)(6x^2 + x - 1)$。

再分解 $6x^2 + x - 1 = (2x + 1)(3x - 1)$。

故 $f(x) = 6 \cdot (x - 1)(x + \tfrac{1}{2})(x - \tfrac{1}{3}) = 6 \cdot (x - 1) \cdot \frac{1}{2}(2x + 1) \cdot \frac{1}{3}(3x - 1)$。

首一化：$f(x) = 6 \cdot (x - 1)(x + \tfrac{1}{2})(x - \tfrac{1}{3})$。

注意 $6 = 2 \cdot 3$，首项系数中的整数分解与多项式的不可约分解是独立的。
:::

### Gauss 引理

Gauss 引理是连接 $R[x]$（$R$ 是 UFD）和 $F[x]$（$F = \operatorname{Frac}(R)$）的桥梁。它的实际意义是：**在 $\mathbb{Q}$ 上检验不可约性，可以先在 $\mathbb{Z}$ 上检验**。

::: definition 本原多项式 {#def-primitive}
设 $R$ 是 UFD，$F = \operatorname{Frac}(R)$。多项式 $f = \sum a_i x^i \in R[x]$ 称为**本原的**，如果 $a_i$ 的最大公因子（在 $R$ 中）是单位，即没有 $R$ 中的非单位素元整除所有系数。
:::

::: lemma Gauss 引理 {#lem-gauss-ufd}
设 $R$ 是 UFD，$F = \operatorname{Frac}(R)$。若 $f \in R[x]$ 在 $F[x]$ 中可约（即 $f = gh$，$g, h \in F[x]$，$\deg g, \deg h \geq 1$），则 $f$ 在 $R[x]$ 中也可约（即存在 $g_0, h_0 \in R[x]$，$f = g_0 h_0$，$\deg g_0 = \deg g$，$\deg h_0 = \deg h$）。
:::

<ProofToggle>

**证明.** 将 $g, h$ 乘以适当的 $F^\times$ 元素使得 $g, h \in R[x]$ 且各项系数的最大公因子为 $1$（本原多项式）。设 $f = c_f \cdot f^*$（$c_f$ 为 $f$ 的系数的 GCD，$f^*$ 本原），$g = c_g \cdot g^*$，$h = c_h \cdot h^*$。则 $c_f f^* = c_g c_h g^* h^*$。

**关键断言**：本原多项式的乘积仍是本原的。否则存在 $R$ 的素元 $p$ 整除乘积的所有系数，但 $p$ 不整除 $g^*$ 的某个系数 $a_i$ 也不整除 $h^*$ 的某个系数 $b_j$。取满足条件的最小 $i, j$，则乘积中 $x^{i+j}$ 的系数 $\sum_{k+l=i+j} a_k b_l$ 中 $a_i b_j$ 不被 $p$ 整除而其余项都被 $p$ 整除，矛盾。

故 $g^* h^*$ 本原，比较得 $c_f = c_g c_h \cdot u$（$u$ 为 $R$ 的单位）。故 $f = (c_g u) g^* \cdot h^*$，即 $f$ 在 $R[x]$ 中可约。$\blacksquare$

</ProofToggle>

::: corollary Eisenstein 的代数基础 {#cor-eisenstein-algebraic}
Gauss 引理是 Eisenstein 判据（{thm-eisenstein}）的代数基础。它将 $\mathbb{Z}[x]$（UFD）上的因式分解问题转化为 $\mathbb{Q}[x]$（PID）上的问题，是连接整数环和多项式环的桥梁。
:::

::: corollary 整数系数多项式的有理根检验 {#cor-rational-root}
设 $f(x) = a_n x^n + \cdots + a_1 x + a_0 \in \mathbb{Z}[x]$，$a_n \neq 0$，$a_0 \neq 0$。若 $\frac{p}{q} \in \mathbb{Q}$（$\gcd(p, q) = 1$）是 $f$ 的根，则 $p \mid a_0$ 且 $q \mid a_n$。

特别地，若 $f$ 是首一多项式（$a_n = 1$），则 $f$ 的所有有理根都是整数且整除 $a_0$。
:::

<ProofToggle>

::: proof
$f(p/q) = 0$ 给出 $a_n p^n + a_{n-1} p^{n-1} q + \cdots + a_0 q^n = 0$。因 $q$ 整除除第一项外的所有项，$q \mid a_n p^n$。由 $\gcd(p, q) = 1$，$q \mid a_n$。类似地，$p \mid a_0 q^n$，由 $\gcd(p, q) = 1$，$p \mid a_0$。
:::

</ProofToggle>

::: remark $\mathbb{Z}[x]$ 是 UFD 但不是 PID
$\mathbb{Z}[x]$ 是 UFD（由 Gauss 引理），但不是 PID：理想 $(2, x)$ 不是主理想（若 $(2, x) = (f)$，则 $f \mid 2$ 且 $f \mid x$，故 $f$ 是 $\mathbb{Z}$ 中的单位，$(f) = \mathbb{Z}[x]$，但 $(2, x) \neq \mathbb{Z}[x]$）。这个例子说明 UFD $\not\Rightarrow$ PID。
:::

## 常见误区

::: warning 误区 1：带余除法在所有环上成立
**错误**：以为 $R[x]$ 中总有带余除法。

**正解**：带余除法要求被除式 $g$ 的首项系数在 $R$ 中**可逆**。在域 $F[x]$ 中，所有非零多项式的首项系数都可逆（因为 $F^\times$ 的每个元素都可逆），所以带余除法总成立。但在 $\mathbb{Z}[x]$ 中，$g(x) = 2x + 1$ 的首项系数 $2$ 不是 $\mathbb{Z}$ 的单位，所以不能做带余除法。
:::

::: warning 误区 2："不可约"与"没有根"混淆
**错误**：以为多项式在 $F$ 上不可约当且仅当它在 $F$ 中没有根。

**正解**："$\deg 2$ 或 $3$ 的多项式没有根 $\Rightarrow$ 不可约"（{prop-low-degree-irreducible}）。但对 $\deg \geq 4$，"没有根"只是必要条件，不是充分条件。例如 $(x^2 + 1)(x^2 + 4) \in \mathbb{R}[x]$ 没有实根，但在 $\mathbb{R}$ 上可约。
:::

::: warning 误区 3：Gauss 引理的正确表述
**错误表述**："$f \in R[x]$ 在 $R[x]$ 中可约 $\Rightarrow$ $f$ 在 $F[x]$ 中可约"。这是平凡的（$R[x] \subseteq F[x]$）。

**正确表述**：Gauss 引理说的是**逆方向**——$f$（本原的）在 $F[x]$ 中可约 $\Rightarrow$ $f$ 在 $R[x]$ 中可约。这才是非平凡的结论。
:::

## 本节要点

::: tip 总结
1. 多项式环 $R[x$ 中，次数满足 $\deg(fg) = \deg f + \deg g$；$R[x]$ 是整环 $\iff$ $R$ 是整环。
2. 域 $F$ 上的多项式环 $F[x]$ 支持带余除法，是主理想整环。
3. 不可约多项式生成极大理想：$f$ 不可约 $\iff$ $(f)$ 极大 $\iff$ $F[x]/(f)$ 是域。
4. $F[x]$ 是唯一分解整环；Gauss 引理将 $R[x]$（$R$ 是 UFD）上的因式分解归结为 $F = \operatorname{Frac}(R)$ 上的问题。
5. 这正是构造域扩张的基本方法：$F[x]/(f(x)) \cong F(\alpha)$（$\alpha$ 是 $f$ 的根）。
:::

## 自测题

::: details 自测题（点击展开）

**1.** 在 $\mathbb{F}_2[x]$ 中，列出所有次数 $\leq 3$ 的不可约多项式。

**答案**：$\deg 1$：$x$，$x + 1$。$\deg 2$：$x^2 + x + 1$（$x^2 + 1 = (x+1)^2$ 可约）。$\deg 3$：$x^3 + x + 1$，$x^3 + x^2 + 1$（其余 $\deg 3$ 多项式在 $\mathbb{F}_2$ 中有根或可约）。

**2.** 为什么 $f(x) = x^4 + x^2 + 1$ 在 $\mathbb{Q}$ 上虽然没有有理根，却是可约的？

**答案**：$f(x) = (x^2 + x + 1)(x^2 - x + 1)$。这说明对 $\deg \geq 4$，"没有根 $\neq$ 不可约"。

**3.** 利用 Gauss 引理，证明 $f(x) = x^3 - 2$ 在 $\mathbb{Q}$ 上不可约。

**答案**：$f \in \mathbb{Z}[x]$ 是本原的（系数为 $1, 0, 0, -2$，GCD 为 1）。在 $\mathbb{Z}$ 中检验有理根：$f(\pm 1) \neq 0$，$f(\pm 2) \neq 0$。由有理根定理，$f$ 的有理根只能是 $\pm 1, \pm 2$，均不是根，故 $f$ 在 $\mathbb{Q}$ 中无根。因 $\deg f = 3$，无根即不可约。

**4.** 设 $R = \mathbb{Z}[i]$（Gauss 整数环）。$R[x]$ 是 PID 吗？UFD 吗？

**答案**：$R$ 是 PID（因而也是 UFD）。$R[x]$ 是 UFD（因 $R$ 是 UFD，由 Gauss 引理），但 $R[x]$ **不是** PID。这与 $\mathbb{Z}[x]$ 的情况类似。

**5.** 为什么带余除法的唯一性证明中，"$\deg g(q_1 - q_2) \geq \deg g$"需要 $g \neq 0$？

**答案**：若 $g = 0$，则 $g(q_1 - q_2) = 0$，$\deg 0 = -\infty$，这不满足 $\geq \deg g$（$\deg g = -\infty$，而 $-\infty \geq -\infty$ 成立）。但此时 $r_2 - r_1 = 0$ 不一定能推出 $q_1 = q_2$——事实上 $q$ 可以是任意多项式。所以定理的条件 $g \neq 0$ 是必要的。
:::
