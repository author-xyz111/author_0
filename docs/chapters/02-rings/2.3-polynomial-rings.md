# 2.3 多项式环

## 动机

多项式环 $R[x]$ 是代数的核心。域扩张的构造、极小多项式的确定、分裂域的存在性——所有这些 Galois 理论的基本构件都依赖于多项式环的性质。本节建立多项式环的严格基础，为 [第四章 多项式](/chapters/04-polynomials/) 和 [第五章 分裂域与正规扩张](/chapters/05-splitting-fields/) 做准备。

## 多项式的定义

::: definition 多项式环 {#def-polynomial-ring}
设 $R$ 是含幺交换环。$R$ 上的**多项式环** $R[x]$ 定义为所有形式表达式

$$f(x) = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n = \sum_{i=0}^{n} a_i x^i$$

的集合，其中 $n \geq 0$，$a_i \in R$。$x$ 是一个**不定元**（或称**形式变量**）。

**加法**和**乘法**按通常方式定义：
$$\left(\sum_i a_i x^i\right) + \left(\sum_i b_i x^i\right) = \sum_i (a_i + b_i) x^i$$
$$\left(\sum_i a_i x^i\right) \cdot \left(\sum_j b_j x^j\right) = \sum_k \left(\sum_{i+j=k} a_i b_j\right) x^k$$
:::

::: definition 次数 {#def-degree}
设 $f(x) = \sum_{i=0}^n a_i x^i \in R[x]$，$a_n \neq 0$，$a_i = 0$ 对 $i > n$。则：

- $n$ 称为 $f$ 的**次数**，记为 $\deg f$。
- $a_n$ 称为 $f$ 的**首项系数**。
- 若首项系数为 1，称 $f$ 为**首一多项式**。
- 规定 $\deg 0 = -\infty$（约定 $-\infty + n = -\infty$，$-\infty < n$ 对所有 $n \in \mathbb{Z}$）。
:::

::: proposition 次数的性质 {#prop-degree}
对 $R[x]$ 中的多项式 $f, g \neq 0$：

1. $\deg(fg) = \deg f + \deg g$。
2. $\deg(f + g) \leq \max(\deg f, \deg g)$。
3. 若 $R$ 是整环，则 $fg \neq 0$；因此 $R[x]$ 是整环当且仅当 $R$ 是整环。
:::

<ProofToggle>

::: proof
**(1)** 设 $\deg f = m$，$\deg g = n$。则 $fg$ 的 $x^{m+n}$ 项的系数是 $a_m b_n$（来自 $i = m, j = n$ 的唯一贡献），且 $a_m b_n \neq 0$（因 $R$ 是含幺环且 $a_m, b_n \neq 0$——对一般环需要 $R$ 是整环保证这一点）。故 $\deg(fg) = m + n$。

**(2)** $(f + g)$ 的 $x^i$ 项系数为 $a_i + b_i$，故 $\deg(f + g) \leq \max(\deg f, \deg g)$。

**(3)** 由 (1)，$f \neq 0$，$g \neq 0$ 推出 $\deg(fg) = \deg f + \deg g \geq 0$，故 $fg \neq 0$。
:::

</ProofToggle>

## 带余除法

::: theorem 带余除法（多项式） {#thm-polynomial-division}
设 $F$ 是域，$f(x), g(x) \in F[x]$，$g(x) \neq 0$。则存在**唯一**的 $q(x), r(x) \in F[x]$ 使得

$$f(x) = g(x) q(x) + r(x), \quad \deg r < \deg g$$
:::

<ProofToggle>

::: proof
**存在性**：对 $\deg f$ 进行强归纳。

若 $\deg f < \deg g$，取 $q = 0$，$r = f$。

设 $\deg f \geq \deg g$。设 $f = a_m x^m + \cdots$，$g = b_n x^n + \cdots$（$a_m \neq 0$，$b_n \neq 0$，$m \geq n$）。令

$$f_1(x) = f(x) - a_m b_n^{-1} x^{m-n} g(x)$$

则 $\deg f_1 < \deg f$。由归纳假设，存在 $q_1, r$ 使得 $f_1 = g q_1 + r$，$\deg r < \deg g$。故

$$f = g(q_1 + a_m b_n^{-1} x^{m-n}) + r$$

取 $q = q_1 + a_m b_n^{-1} x^{m-n}$。

**唯一性**：设 $f = gq_1 + r_1 = gq_2 + r_2$，$\deg r_1, \deg r_2 < \deg g$。则 $g(q_1 - q_2) = r_2 - r_1$。若 $q_1 \neq q_2$，左边次数 $\geq \deg g$，右边次数 $< \deg g$，矛盾。故 $q_1 = q_2$，$r_1 = r_2$。
:::

</ProofToggle>

::: remark
{thm-polynomial-division} 要求 $F$ 是域（或至少 $g$ 的首项系数在 $R^*$ 中）。在 $\mathbb{Z}[x]$ 中，带余除法一般不成立：例如 $x + 1$ 不能除 $2x + 1$。
:::

## 不可约多项式

::: definition 不可约多项式 {#def-irreducible-polynomial}
设 $F$ 是域。$F[x]$ 中次数 $\geq 1$ 的多项式 $f(x)$ 称为在 $F$ 上**不可约**，如果 $f$ 不能写成两个次数更低的多项式的乘积：即 $f = gh$ 蕴含 $\deg g = 0$ 或 $\deg h = 0$。
:::

::: example 不可约多项式 {#ex-irreducible}

1. $x^2 + 1$ 在 $\mathbb{R}$ 上不可约（无实根）。
2. $x^2 + 1$ 在 $\mathbb{C}$ 上可约：$x^2 + 1 = (x + i)(x - i)$。
3. $x^2 - 2$ 在 $\mathbb{Q}$ 上不可约（{thm-eisenstein}，取 $p = 2$）。
4. $x^2 - 2$ 在 $\mathbb{R}$ 上可约：$(x - \sqrt{2})(x + \sqrt{2})$。
5. $x^p - x$ 在 $\mathbb{F}_p$ 上完全可约：$x^p - x = \prod_{a \in \mathbb{F}_p}(x - a)$。
:::

::: intuition
不可约多项式在域论中的地位类似于素数在整数论中的地位。就像每个整数可以唯一分解为素数乘积，每个域上的多项式可以唯一分解为不可约多项式的乘积。更关键的是，不可约多项式直接给出域扩张：若 $f(x)$ 在 $K$ 上不可约，则 $K[x]/(f(x))$ 是一个域（{thm-maximal-field}），包含了 $f$ 的一个根。
:::

::: theorem {#thm-ideal-is-principal}
设 $F$ 是域。则 $F[x]$ 是**主理想整环**（PID）：每个理想都是主理想。
:::

<ProofToggle>

::: proof
设 $I$ 是 $F[x]$ 的理想，$I \neq \{0\}$。取 $I$ 中次数最低的非零多项式 $g$（良序原理）。对任意 $f \in I$，由 {thm-polynomial-division}，$f = gq + r$，$\deg r < \deg g$。因 $r = f - gq \in I$ 且 $\deg r < \deg g$，$g$ 的选取推出 $r = 0$。故 $f \in (g)$，即 $I = (g)$。
:::

</ProofToggle>

::: corollary {#cor-irreducible-maximal}
在 $F[x]$（$F$ 是域）中，$(f(x))$ 是极大理想 $\iff$ $f(x)$ 不可约。
:::

<ProofToggle>

::: proof
$(\Rightarrow)$：设 $(f)$ 是极大理想但 $f = gh$，$\deg g < \deg f$，$\deg h < \deg f$。则 $(f) \subseteq (g) \subseteq F[x]$，由极大性 $(g) = F[x]$ 或 $(g) = (f)$。前者推出 $g$ 是单位（$\deg g = 0$）；后者推出 $f | g$（即 $\deg f \leq \deg g$），矛盾。

($\Leftarrow)$：设 $f$ 不可约。设 $(f) \subseteq (g) \subseteq F[x]$，$g \in I$。由 $f \in (g)$，$f = gh$。因 $f$ 不可约，$g$ 或 $h$ 是单位。若 $g$ 是单位，$(g) = F[x]$；若 $h$ 是单位，$g = fh^{-1}$，$(g) = (f)$。
:::

</ProofToggle>

## 唯一分解与 Gauss 引理 {#ufd-gauss}

::: theorem 唯一分解定理（$F[x]$） {#thm-ufd-polynomial}
设 $F$ 是域。则 $F[x]$ 是**唯一分解整环**（UFD）：每个非常数多项式 $f \in F[x]$ 可以写成
$$f = c \cdot p_1(x) p_2(x) \cdots p_r(x),$$
其中 $c \in F^\times$ 是首项系数，$p_i$ 是首一不可约多项式。这个分解在不计排列顺序的意义下是唯一的。
:::

<ProofToggle>

**证明.** **存在性**：对 $\deg f$ 归纳。若 $f$ 不可约，取 $c$ 为首项系数，$f/c$ 为首一不可约多项式。否则 $f = gh$，$1 \leq \deg g, \deg h < \deg f$，对 $g, h$ 分别应用归纳。

**唯一性**：设 $c \cdot p_1 \cdots p_r = c' \cdot q_1 \cdots q_s$（$p_i, q_j$ 首一不可约）。比较首项系数得 $c = c'$。对 $r$ 归纳：$p_1 \mid q_1 \cdots q_s$。因 $F[x]$ 是 PID（{thm-ideal-is-principal}），不可约元等价于素元，故 $p_1 \mid q_j$ 对某个 $j$。因 $q_j$ 首一不可约，$p_1 = q_j$。约去后对 $r - 1$ 归纳。$\blacksquare$

</ProofToggle>

::: lemma Gauss 引理 {#lem-gauss}
设 $R$ 是 UFD，$F = \operatorname{Frac}(R)$。若 $f \in R[x]$ 在 $F[x]$ 中可约（即 $f = gh$，$g, h \in F[x]$，$\deg g, \deg h \geq 1$），则 $f$ 在 $R[x]$ 中也可约（即存在 $g_0, h_0 \in R[x]$，$f = g_0 h_0$，$\deg g_0 = \deg g$，$\deg h_0 = \deg h$）。
:::

<ProofToggle>

**证明.** 将 $g, h$ 乘以适当的 $F^\times$ 元素使得 $g, h \in R[x]$ 且各项系数的最大公因子为 $1$（本原多项式）。设 $f = c_f \cdot f^*$（$c_f$ 为 $f$ 的系数的 GCD，$f^*$ 本原），$g = c_g \cdot g^*$，$h = c_h \cdot h^*$。则 $c_f f^* = c_g c_h g^* h^*$。

**关键断言**：本原多项式的乘积仍是本原的。否则存在 $R$ 的素元 $p$ 整除乘积的所有系数，但 $p$ 不整除 $g^*$ 的某个系数 $a_i$ 也不整除 $h^*$ 的某个系数 $b_j$。取满足条件的最小 $i, j$，则乘积中 $x^{i+j}$ 的系数 $\sum_{k+l=i+j} a_k b_l$ 中 $a_i b_j$ 不被 $p$ 整除而其余项都被 $p$ 整除，矛盾。

故 $g^* h^*$ 本原，比较得 $c_f = c_g c_h \cdot u$（$u$ 为 $R$ 的单位）。故 $f = (c_g u) g^* \cdot h^*$，即 $f$ 在 $R[x]$ 中可约。$\blacksquare$

</ProofToggle>

::: corollary Eisenstein 的代数基础 {#cor-eisenstein-algebraic}
Gauss 引理是 Eisenstein 判据（{thm-eisenstein}）的代数基础。它将 $\mathbb{Z}[x]$（UFD）上的因式分解问题转化为 $\mathbb{Q}[x]$（PID）上的问题，是连接整数环和多项式环的桥梁。
:::

::: remark $\mathbb{Z}[x]$ 是 UFD 但不是 PID
$\mathbb{Z}[x]$ 是 UFD（由 Gauss 引理），但不是 PID：理想 $(2, x)$ 不是主理想（若 $(2, x) = (f)$，则 $f \mid 2$ 且 $f \mid x$，故 $f$ 是 $\mathbb{Z}$ 中的单位，$(f) = \mathbb{Z}[x]$，但 $(2, x) \neq \mathbb{Z}[x]$）。这个例子说明 UFD $\not\Rightarrow$ PID。
:::

---

::: tip 本节要点
1. 多项式环 $R[x]$ 中，次数满足 $\deg(fg) = \deg f + \deg g$；$R[x]$ 是整环 $\iff$ $R$ 是整环。
2. 域 $F$ 上的多项式环 $F[x]$ 支持带余除法，是主理想整环。
3. 不可约多项式生成极大理想：$f$ 不可约 $\iff$ $(f)$ 极大 $\iff$ $F[x]/(f)$ 是域。
4. $F[x]$ 是唯一分解整环；Gauss 引理将 $R[x]$（$R$ 是 UFD）上的因式分解归结为 $F = \operatorname{Frac}(R)$ 上的问题。
5. 这正是构造域扩张的基本方法：$F[x]/(f(x)) \cong F(\alpha)$（$\alpha$ 是 $f$ 的根）。
:::
