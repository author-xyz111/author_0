# §11.2 无穷 Galois 对应 {#sec-infinite-galois-correspondence}

::: intuition 核心直觉
有限 Galois 对应是"中间域 $\leftrightarrow$ 子群"的一一对应。无穷 Galois 对应需要修正：不是所有子群都对应中间域——只有**闭子群**才能。这是 Krull 拓扑的核心意义：它使得 Galois 对应成为闭子格之间的反序同构。

另一个关键概念是 **Galois 下降**：给定一个 Galois 扩张 $L/K$，$L$ 上的代数结构（向量空间、代数、Galois 表示等）如果带有兼容的 $\operatorname{Gal}(L/K)$ 作用，则可以"下降"到 $K$ 上。这是 Galois 理论在现代代数几何中的核心应用。
:::

---

## 无穷 Galois 对应定理 {#infinite-correspondence}

::: theorem 无穷 Galois 对应 {#thm-infinite-galois-correspondence}
设 $L/K$ 是 Galois 扩张（可能无限），$G = \operatorname{Gal}(L/K)$ 赋予 Krull 拓扑。则存在反序双射
$$
\left\{\begin{array}{c} K \text{ 与 } L \text{ 之间的} \\ \text{中间域 } E \end{array}\right\} \longleftrightarrow \left\{\begin{array}{c} G \text{ 的} \\ \text{闭子群 } H \end{array}\right\}
$$
$$E \mapsto \operatorname{Gal}(L/E), \qquad H \mapsto L^H.$$

满足：
**(i)** $L^{\operatorname{Gal}(L/E)} = E$，$\operatorname{Gal}(L/L^H) = H$（对闭子群 $H$）。
**(ii)** $E/K$ 是有限扩张 $\iff$ $\operatorname{Gal}(L/E)$ 是开子群。
**(iii)** $E/K$ 是 Galois 扩张 $\iff$ $\operatorname{Gal}(L/E) \unlhd G$（正规闭子群）。此时 $\operatorname{Gal}(E/K) \cong G/\operatorname{Gal}(L/E)$。
:::

<ProofToggle>

**证明.**

**(i)** 对中间域 $E$：显然 $E \subseteq L^{\operatorname{Gal}(L/E)}$。反包含需要证明若 $\alpha \in L$ 被 $\operatorname{Gal}(L/E)$ 的所有元素固定，则 $\alpha \in E$。这等价于 $L/E$ 是 Galois 扩张（由定义）。由于 $L/K$ Galois $\implies$ $L/E$ Galois，结论成立。

对闭子群 $H$：$\operatorname{Gal}(L/L^H)$ 总是闭子群，且 $H \subseteq \operatorname{Gal}(L/L^H)$。反包含由 $H$ 的闭性给出：$H = \overline{H} = \operatorname{Gal}(L/L^H)$（闭子群的核心性质）。

**(ii)** $E/K$ 有限 $\iff$ $[L:E] = [L:K]/[E:K]$ 仍有限（因为 $[L:K]$ 可能无限），但这要求 $[L:K]$ 的某个有限子扩张包含 $E$。更精确地：$E/K$ 有限 $\iff$ $E \subseteq M$ 对某个有限 Galois 子扩张 $M/K$ $\iff$ $\operatorname{Gal}(L/E) \supseteq \operatorname{Gal}(L/M) = N_M$ $\iff$ $\operatorname{Gal}(L/E)$ 是开子群。

**(iii)** $E/K$ 正规 $\iff$ 对每个 $\sigma \in G$，$\sigma(E) = E$ $\iff$ 对每个 $\sigma \in G$，$\sigma \operatorname{Gal}(L/E) \sigma^{-1} = \operatorname{Gal}(L/\sigma(E)) = \operatorname{Gal}(L/E)$ $\iff$ $\operatorname{Gal}(L/E) \unlhd G$。

$\operatorname{Gal}(E/K) = \{\sigma|_E : \sigma \in G\}$。当 $E/K$ 是 Galois 时，限制映射 $G \to \operatorname{Gal}(E/K)$ 连续满射，核为 $\operatorname{Gal}(L/E)$，由拓扑群同态定理，$\operatorname{Gal}(E/K) \cong G/\operatorname{Gal}(L/E)$（有限离散群）。$\blacksquare$

</ProofToggle>

## Galois 下降 {#galois-descent}

::: theorem Galois 下降（向量空间版本） {#thm-galois-descent-vector-space}
设 $L/K$ 是有限 Galois 扩张，$G = \operatorname{Gal}(L/K)$。设 $V$ 是 $L$-向量空间，带有 $G$ 的**半线性作用**（即 $\sigma(av) = \sigma(a)\sigma(v)$）。则
$$
V^G := \{v \in V : \sigma(v) = v \text{ 对所有 } \sigma \in G\}
$$
是 $K$-向量空间，且自然映射
$$V^G \otimes_K L \xrightarrow{\sim} V$$
是 $L$-向量空间同构。反之，$W \otimes_K L$ 带有 $G$ 的自然半线性作用（$\sigma(w \otimes a) = w \otimes \sigma(a)$），且 $(W \otimes_K L)^G = W$。
:::

<ProofToggle>

**证明.** **存在性.** 设 $n = [L:K]$，$G = \{\sigma_1, \ldots, \sigma_n\}$。定义 $K$-线性映射
$$\theta: V \to V, \quad v \mapsto \sum_{i=1}^n \sigma_i(v).$$
则对任意 $\tau \in G$，$\tau(\theta(v)) = \sum_i \tau\sigma_i(v) = \sum_j \sigma_j(v) = \theta(v)$（重排），故 $\theta(v) \in V^G$。进一步，若 $v \in V^G$，则 $\theta(v) = nv$，故 $\theta/n$ 是 $V^G$ 上的恒等映射。

**张量积映射的单射性.** 设 $\{e_1, \ldots, e_m\}$ 是 $V^G$ 的 $K$-基，$\{f_1, \ldots, f_n\}$ 是 $L/K$ 的基。则 $\{e_i \otimes f_j\}$ 是 $V^G \otimes_K L$ 的 $L$-基。要证明它们在 $V$ 中 $L$-线性无关：若 $\sum_{i,j} a_{ij} e_i \otimes f_j \mapsto \sum_{i,j} a_{ij} f_j e_i = 0$（$a_{ij} \in L$），用 $\sigma_k$ 作用并利用 Cramer 求解（或更简洁地，用判别式矩阵的非退化性）可得所有 $a_{ij} = 0$。

**满射性.** 对任意 $v \in V$，取 $v' = \sum_i \sigma_i(v) / n \in V^G$（当 $\operatorname{char}(K) \nmid n$ 时），则 $v' \otimes 1$ 映射到 $v$。（在一般情形下，用 trace 的满射性。）$\blacksquare$

</ProofToggle>

::: remark Grothendieck 的 Galois 范畴
Galois 下降的范畴化推广是 **Grothendieck 的 Galois 范畴**（{def-galois-category}）。它给出了无穷 Galois 理论最抽象也最本质的形式：Galois 群是"有限平展覆盖"范畴的自同构群。这是代数几何中平展基本群理论的起点（{sec-etale-fundamental-group}）。
:::

## 应用：绝对 Galois 群 {#absolute-galois-group}

::: definition 绝对 Galois 群 {#def-absolute-galois-group}
域 $K$ 的**绝对 Galois 群**定义为
$$G_K := \operatorname{Gal}(\overline{K}/K),$$
其中 $\overline{K}$ 是 $K$ 的代数闭包。这是 $K$ 的代数数论中最核心的对象。
:::

::: example $\mathbb{Q}$ 的绝对 Galois 群 {#ex-absolute-galois-q}
$G_\mathbb{Q} = \operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$ 是一个极其复杂的 profinite 群。已知的事实：
- $G_\mathbb{Q}$ 是**不可数的**（因为 $[\overline{\mathbb{Q}}:\mathbb{Q}]$ 无限）。
- $G_\mathbb{Q}$ 的每个有限群都可以作为某个有限扩张的 Galois 群（**逆 Galois 问题**，已对可解群和许多单群验证，{sec-inverse-galois}）。
- $G_\mathbb{Q}$ 的 **Frattini 子群**是平凡的（Neukirch 定理）。
- $G_\mathbb{Q}$ 的连续表示（$\ell$-adic 表示）是 **Langlands 纲领**的核心研究对象（{sec-langlands}）。
:::

::: example 有限域的绝对 Galois 群 {#ex-absolute-galois-finite}
$\operatorname{Gal}(\overline{\mathbb{F}}_p / \mathbb{F}_p)$ 由 **Frobenius 自同构** $\operatorname{Frob}_p: x \mapsto x^p$ 拓扑生成：
$$\operatorname{Gal}(\overline{\mathbb{F}}_p / \mathbb{F}_p) \cong \hat{\mathbb{Z}} = \varprojlim_n \mathbb{Z}/n\mathbb{Z}.$$

这是**Abelian** profinite 群，$\operatorname{Frob}_p$ 生成一个在 $\hat{\mathbb{Z}}$ 中稠密的子群。这个简洁的结构是有限域上类域论的完整答案。
:::
