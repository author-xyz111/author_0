# §11.2 无穷 Galois 对应 {#sec-infinite-galois-correspondence}

## 本节概要

::: tip 学习目标
1. 理解**无穷 Galois 对应**定理：中间域与**闭子群**之间的反序双射
2. 掌握**闭子群**与**开子群**在无限 Galois 理论中的不同角色
3. 学会计算绝对 Galois 群 $G_{\mathbb{F}_q}$ 和 $G_\mathbb{Q}$
4. 理解 **Galois 下降**的基本原理：$L$-结构加上 $G$-对称性等于 $K$-结构
:::

---

## 动机：为什么需要"闭"子群 {#motivation}

在 [§11.1](11.1-krull-topology) 中，我们看到有限 Galois 对应的直接推广**失效**了：取 $\mathbb{Z} \leq \hat{\mathbb{Z}} = \operatorname{Gal}(\overline{\mathbb{F}}_p/\mathbb{F}_p)$，则 $\mathbb{Z}$ 的不动域是 $\mathbb{F}_p$，但 $\operatorname{Gal}(\overline{\mathbb{F}}_p/\mathbb{F}_p) = \hat{\mathbb{Z}} \neq \mathbb{Z}$。恢复定理 $\operatorname{Gal}(L/L^H) = H$ 对非闭子群失效了。

Krull 拓扑给出了正确的修正：在无限 Galois 理论中，"正确的"子群是**闭子群**。

::: intuition 为什么是闭子群？
直觉上，闭子群 $H$ 恰好是那些"完全捕获了它应该捕获的信息"的子群。非闭子群（如 $\mathbb{Z} \leq \hat{\mathbb{Z}}$）的问题在于：它在每个有限商上都能"覆盖"整个群（因为它是稠密的），但实际上并不等于整个群。它遗漏了"极限处"的信息——而闭性恰好补上了这个缺口。

更技术性地说：闭子群 $H$ 满足 $H = \bigcap_M HN_M$（交遍历所有有限 Galois 子扩张 $M$），即 $H$ 完全由它在每个有限商上的像决定。
:::

## §A. 无穷 Galois 对应定理 {#galois-correspondence}

::: theorem 无穷 Galois 对应 {#thm-infinite-galois-correspondence}
设 $L/K$ 是 Galois 扩张（可能无限），$G = \operatorname{Gal}(L/K)$（配备 Krull 拓扑）。则存在**反序双射**：

$$
\boxed{\{\text{中间域 } K \subseteq E \subseteq L\} \xleftrightarrow{1:1} \{\text{闭子群 } H \leq_{\text{cl}} G\}}
$$

由以下映射给出：
- $E \mapsto \operatorname{Gal}(L/E)$（不动自同构群）
- $H \mapsto L^H$（不动域）

满足以下性质：

**(i) 恢复定理：**
- $L^{\operatorname{Gal}(L/E)} = E$（中间域可以从闭子群恢复）
- $\operatorname{Gal}(L/L^H) = H$（闭子群可以从不动域恢复——**必须是闭的**！）

**(ii) 指标关系：**
- $[\operatorname{Gal}(L/K) : \operatorname{Gal}(L/E)] = [E : K]$（当 $E/K$ 有限时）
- 特别地：$E/K$ 有限 $\iff$ $\operatorname{Gal}(L/E)$ 是**开**子群（指数有限的闭子群）

**(iii) 正规子群与 Galois 扩张：**
- $H \unlhd_{\text{cl}} G$（闭正规子群）$\iff$ $L^H / K$ 是 Galois 扩张
- 当 $H \unlhd_{\text{cl}} G$ 时，$\operatorname{Gal}(L^H / K) \cong G/H$（商群）

**(iv) 有限 Galois 子扩张的恢复：**
- $\operatorname{Gal}(M/K)$ 是 $G$ 的有限商，其中 $M$ 是 $L/K$ 的有限 Galois 子扩张
:::

<ProofToggle>

**证明.**

**(i) 恢复定理.**

$\bullet$ **$L^{\operatorname{Gal}(L/E)} = E$：** 由定义 $E \subseteq L^{\operatorname{Gal}(L/E)}$。反过来，设 $\alpha \in L^{\operatorname{Gal}(L/E)} \setminus E$。则 $\alpha$ 在 $E$ 上是代数的（因为 $L/K$ 代数），且存在 $\sigma \in \operatorname{Gal}(L/E)$ 使 $\sigma(\alpha) \neq \alpha$（因为 $L/E$ 是 Galois 扩张——它正规且可分——所以 $\alpha$ 的所有共轭都在 $L$ 中，且自同构群作用传递）。故 $\alpha \notin L^{\operatorname{Gal}(L/E)}$，矛盾。

$\bullet$ **$\operatorname{Gal}(L/L^H) = H$（核心难点）：** 由定义 $H \subseteq \operatorname{Gal}(L/L^H)$。反过来，设 $\sigma \in \operatorname{Gal}(L/L^H)$。对每个有限 Galois 子扩张 $M/K$，考虑 $\sigma$ 在 $M$ 上的限制 $\sigma|_M \in \operatorname{Gal}(M/K)$。设 $M_H := M \cap L^H$（$H$ 在 $M$ 中的不动域）。则 $H|_M \leq \operatorname{Gal}(M/M_H)$。

由有限 Galois 对应，$L^H \cap M$ 是 $M$ 的子域，且 $\operatorname{Gal}(M/M \cap L^H) = \overline{H|_M}$（$H|_M$ 在 $\operatorname{Gal}(M/K)$ 中的闭包）。由于 $\sigma$ 在 $L^H$ 上平凡，$\sigma|_{M \cap L^H} = \operatorname{id}$。故 $\sigma|_M \in \operatorname{Gal}(M/M \cap L^H)$。

关键步骤：因为 $H$ 是**闭子群**，$\sigma$ 属于 $H$ 在 $G$ 中的闭包 $\overline{H}$，而 $H = \overline{H}$。故对每个 $N_M$，存在 $\tau \in H$ 使得 $\sigma \equiv \tau \pmod{N_M}$。即 $\sigma|_M = \tau|_M \in H|_M$。这对所有 $M$ 成立，故 $\sigma \in \overline{H} = H$。

$\bullet$ **非闭子群失效的机制：** 若 $H$ 非闭，则 $\overline{H} \supsetneq H$。上面的论证给出 $\operatorname{Gal}(L/L^H) = \overline{H} \neq H$。

**(ii)-(iv)** 由有限 Galois 对应逐子扩张应用，再通过 Krull 拓扑取极限得到。$\blacksquare$

</ProofToggle>

::: warning 非闭子群不对应中间域
无穷 Galois 对应中，**只有闭子群**才对应中间域。非闭子群（如 $\mathbb{Z} \leq \hat{\mathbb{Z}}$）不对应任何中间域，因为它"太稀疏"——它在每个有限商上都是满射（稠密），但它遗漏了逆极限中"在无穷远处"的信息。
:::

::: remark 有限 Galois 理论作为特殊情形
当 $L/K$ 是**有限** Galois 扩张时，$\operatorname{Gal}(L/K)$ 是有限群（离散拓扑），**每个子群都是闭的**。此时无穷 Galois 对应退化为有限 Galois 对应（{thm-galois-correspondence}）。

这验证了 Krull 拓扑是"正确的"推广：有限理论是它的特殊情形，不需要做任何修正。
:::

## §B. 开子群与有限扩张 {#open-subgroups}

::: proposition 开子群对应有限扩张 {#prop-open-subgroups}
设 $L/K$ 是无限 Galois 扩张，$G = \operatorname{Gal}(L/K)$。则：

$H \leq G$ 是**开子群** $\iff$ $[L^H : K] < \infty$（$L^H/K$ 是有限扩张）

且此时 $[G : H] = [L^H : K]$。
:::

<ProofToggle>

**证明.**

$(\Rightarrow)$ 若 $H$ 开，则 $H \supseteq N_M$ 对某个有限 Galois 子扩张 $M/K$。故 $L^H \subseteq L^{N_M} = M$，从而 $[L^H : K] \leq [M : K] < \infty$。

$(\Leftarrow)$ 若 $[L^H : K] < \infty$，设 $M$ 为 $L^H$ 在 $L/K$ 中的正规闭包（即 $M$ 是包含 $L^H$ 的最小有限 Galois 子扩张）。则 $H \supseteq \operatorname{Gal}(L/M) = N_M$，故 $H$ 是开子群（因为 $N_M$ 是开集）。

**指数关系：** $[G : H] = [G : N_M] / [H : N_M] = [M : K] / [\operatorname{Gal}(L/M) : H \cap \operatorname{Gal}(L/M)]$。由有限 Galois 对应，$[M : K] = |\operatorname{Gal}(M/K)|$ 且 $H$ 在 $M$ 上的限制对应 $L^H$，故 $[G : H] = [L^H : K]$。$\blacksquare$

</ProofToggle>

::: intuition 开子群 = 有限信息
在 profinite 群中，开子群是"有限信息"的载体。开子群 $H$ 对应一个有限中间域 $L^H$，而 $H$ 的陪集 $G/H$ 精确编码了 $L^H$ 在 $L$ 中的"位置"。这与有限 Galois 理论完全类比，只是现在子群必须是开（因而闭）的。
:::

## §C. 绝对 Galois 群 {#absolute-galois}

::: definition 绝对 Galois 群 {#def-absolute-galois-group}
域 $K$ 的**绝对 Galois 群**定义为：
$$
G_K := \operatorname{Gal}(\overline{K}/K)
$$
其中 $\overline{K}$ 是 $K$ 的代数闭包。$G_K$ 是 profinite 群，其结构编码了 $K$ 的全部算术信息。
:::

::: example 有限域的绝对 Galois 群 {#ex-galois-finite-field}
$G_{\mathbb{F}_q} = \operatorname{Gal}(\overline{\mathbb{F}}_q/\mathbb{F}_q) \cong \hat{\mathbb{Z}}$。

证明. 有限子扩张为 $\mathbb{F}_{q^n}$（$n = 1, 2, 3, \ldots$），$\operatorname{Gal}(\mathbb{F}_{q^n}/\mathbb{F}_q) \cong \mathbb{Z}/n\mathbb{Z}$（由 Frobenius $\operatorname{Frob}_q: x \mapsto x^q$ 生成）。过渡映射 $(\mathbb{Z}/mn\mathbb{Z}) \to (\mathbb{Z}/n\mathbb{Z})$ 为模 $n$ 约化。故

$$
G_{\mathbb{F}_q} \cong \varprojlim_n \mathbb{Z}/n\mathbb{Z} = \hat{\mathbb{Z}}.
$$

$\hat{\mathbb{Z}}$ 的闭子群形如 $n\hat{\mathbb{Z}}$（$n \geq 0$）。Galois 对应为：
$$
n\hat{\mathbb{Z}} \leftrightarrow \mathbb{F}_{q^n}.
$$
$\blacksquare$

::: intuition $G_{\mathbb{F}_q} \cong \hat{\mathbb{Z}}$ 的含义
$\hat{\mathbb{Z}}$ 由**单个拓扑生成元**（Frobenius）生成。这意味着**有限域的全部算术信息**可以由一个变换 $x \mapsto x^q$ 编码。所有有限扩张 $\mathbb{F}_{q^n}/\mathbb{F}_q$ 都是循环的，Galois 群的结构极其简单。

这是 Galois 理论中最干净的例子。与 $G_\mathbb{Q}$ 的复杂性形成鲜明对比。
:::

:::

::: example 有理数域的绝对 Galois 群 {#ex-galois-rational}
$G_\mathbb{Q} = \operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$ 是数学中最核心也最神秘的 profinite 群之一。

- **大小：** $G_\mathbb{Q}$ 不可数（因为 $\overline{\mathbb{Q}}/\mathbb{Q}$ 有不可数多个不同的有限 Galois 扩张）。
- **已知性质：** $G_\mathbb{Q}$ 有丰富的有限商（包括所有有限群——逆 Galois 问题，对可解群已证），其结构极其复杂。
- **与数论的联系：** $G_\mathbb{Q}$ 的有限维连续表示（$\ell$-进表示）是现代数论的核心工具，连接了 Galois 理论、模形式、椭圆曲线和 Langlands 纲领。

$G_\mathbb{Q}$ 的闭子群精确对应 $\overline{\mathbb{Q}}$ 的中间域，因而编码了**所有数域**的 Galois 理论。
:::

::: remark 绝对 Galois 群的局部版本
对每个素数 $p$，$p$-进域 $\mathbb{Q}_p$ 和有限域 $\mathbb{F}_p$ 也有绝对 Galois 群 $G_{\mathbb{Q}_p}$ 和 $G_{\mathbb{F}_p}$。$G_{\mathbb{Q}_p}$ 的结构介于 $G_{\mathbb{F}_p} \cong \hat{\mathbb{Z}}$（极其简单）和 $G_\mathbb{Q}$（极其复杂）之间。

**类域论**（{thm-class-field-theory}）的核心成就之一是：通过局部-整体原理，将 $G_\mathbb{Q}$ 的**阿贝尔商** $G_\mathbb{Q}^{\text{ab}}$ 用 idele 类群精确描述。这是 Langlands 纲领（{sec-langlands}）的起点。
:::

## §D. Galois 下降 {#galois-descent}

Galois 下降是无限 Galois 理论最优雅的应用之一：它告诉我们，$L$-向量空间加上"对称性"（$G$-作用）等价于 $K$-向量空间。

::: theorem 向量空间的 Galois 下降 {#thm-galois-descent-vector-space}
设 $L/K$ 是 Galois 扩张（可能无限），$G = \operatorname{Gal}(L/K)$。设 $V$ 是 $L$-向量空间。则：

**$K$-结构**（即 $V$ 上存在一个 $K$-子空间 $V_0$ 使得 $V \cong V_0 \otimes_K L$）$\iff$ **$G$-半线性作用**（即 $G$ 在 $V$ 上有连续半线性作用 $\sigma(v) = \sigma \otimes v$ 在张量分解下）。

更精确地：函子 $V_0 \mapsto V_0 \otimes_K L$（附加自然的 $G$-作用）诱导了范畴等价：
$$
\{K\text{-向量空间}\} \xrightarrow{\sim} \{L\text{-向量空间} + G\text{-半线性作用}\}.
$$
:::

<ProofToggle>

**证明思路.**

$(\Leftarrow)$ 给定 $V$ 带 $G$-半线性作用。定义 $V^G := \{v \in V : \sigma(v) = v \text{ 对所有 } \sigma \in G\}$（不动点集）。则 $V^G$ 是 $K$-向量空间，自然映射 $V^G \otimes_K L \to V$（$v \otimes \lambda \mapsto \lambda v$）是同构。

**单射**由 $L$-线性性得到。**满射**的关键步骤：对任意 $v \in V$，需要找到 $v_0 \in V^G$ 和 $\lambda_i \in L$ 使得 $v = \sum v_0 \otimes \lambda_i$。对有限维情形，这通过选择基和取平均得到。对无限 Galois 扩张，利用 $G$ 的紧性和 $V$ 上的连续性假设。

$(\Rightarrow)$ 给定 $K$-结构 $V_0$，则 $V = V_0 \otimes_K L$ 带自然的 $G$-作用：$\sigma(v_0 \otimes \lambda) = v_0 \otimes \sigma(\lambda)$。

$\blacksquare$

</ProofToggle>

::: intuition Galois 下降的含义
Galois 下降说的是：

> **$L$-结构 + $G$-对称性 = $K$-结构**

这是一个极其深刻的原理，贯穿现代数学：

- **代数几何：** 概形的下降（从基变换 $X \times_K L$ 和 $G$-作用恢复 $X$）
- **数论：** 从 $\ell$-进表示（$G_\mathbb{Q}$ 在 $L$-向量空间上的作用）恢复算术信息
- **表示论：** 从基域扩张后的表示和自同构作用恢复原始表示
:::

::: example Galois 下降的具体计算 {#ex-descent-computation}
设 $K = \mathbb{Q}$，$L = \mathbb{Q}(\sqrt{2})$，$G = \{1, \sigma\} \cong \mathbb{Z}/2\mathbb{Z}$（$\sigma(\sqrt{2}) = -\sqrt{2}$）。

设 $V = L$（一维 $L$-向量空间）。$G$-半线性作用为 $\sigma(a + b\sqrt{2}) = a - b\sqrt{2}$。

$V^G = \{a + b\sqrt{2} : a - b\sqrt{2} = a + b\sqrt{2}\} = \{a : b = 0\} = \mathbb{Q} = K$。

故 $V^G \otimes_K L = \mathbb{Q} \otimes_\mathbb{Q} \mathbb{Q}(\sqrt{2}) \cong \mathbb{Q}(\sqrt{2}) = V$。Galois 下降恢复了 $K$-结构。

更有趣的情形：设 $W = M_2(L)$（$2 \times 2$ 矩阵，$L$-系数）。$G$-作用为 $\sigma(A) = \overline{A}$（对每个矩阵元素取共轭）。则 $W^G = M_2(K)$。"$L$ 上的矩阵 + 共轭对称性 = $K$ 上的矩阵"。
:::

## §E. 非闭子群的反例（详解） {#non-closed-subgroups}

::: example 非闭子群不对应中间域 {#ex-non-closed-subgroup}
这是无限 Galois 理论中最重要的反例。

**设定：** $K = \mathbb{F}_p$，$L = \overline{\mathbb{F}}_p$，$G = \operatorname{Gal}(L/K) \cong \hat{\mathbb{Z}}$。

**子群：** 设 $H = \mathbb{Z} \cdot 1 = \mathbb{Z}$（由 Frobenius $\operatorname{Frob}_p$ 生成的子群，通过 $n \mapsto \operatorname{Frob}_p^n$ 嵌入 $\hat{\mathbb{Z}}$）。

**关键事实：** $H = \mathbb{Z}$ 在 $\hat{\mathbb{Z}}$ 中**稠密但不闭**。

**为什么稠密？** 对每个开子群 $n\hat{\mathbb{Z}}$（$n \geq 1$），$H + n\hat{\mathbb{Z}} = \mathbb{Z} + n\hat{\mathbb{Z}} = \hat{\mathbb{Z}}$（因为 $\mathbb{Z}$ 在 $\hat{\mathbb{Z}}$ 中的像覆盖每个剩余类 $\mathbb{Z}/n\mathbb{Z}$）。故 $H$ 与每个开集相交，即 $H$ 稠密。

**为什么 $\operatorname{Gal}(L/L^H) \neq H$？** 由密度判据（{thm-profinite-structure}），$H$ 稠密 $\iff$ $L^H = L^{\overline{H}} = L^{\hat{\mathbb{Z}}} = \mathbb{F}_p$。故 $\operatorname{Gal}(L/L^H) = \operatorname{Gal}(L/\mathbb{F}_p) = \hat{\mathbb{Z}} \neq H = \mathbb{Z}$。

**总结：** $H = \mathbb{Z}$ 不对应任何中间域（除了 $\mathbb{F}_p$ 和 $\overline{\mathbb{F}}_p$）。它是"太稀疏"的子群——在每个有限商上都是满射（稠密），但遗漏了逆极限中"在无穷远处"的信息。
:::

## §F. Galois 对应的计算策略 {#computation-strategy}

::: remark 计算无穷 Galois 对应的步骤
给定 Galois 扩张 $L/K$：

1. **写出逆系统：** 确定所有有限 Galois 子扩张 $M/K$ 和限制映射 $\operatorname{Gal}(M'/K) \to \operatorname{Gal}(M/K)$（$M \subseteq M'$）。

2. **计算逆极限：** $G = \varprojlim_M \operatorname{Gal}(M/K)$。识别 $G$ 为已知的 profinite 群。

3. **列出闭子群：** 闭子群 $H$ 对应中间域 $L^H$。判据：
   - $H$ 开 $\iff$ $[L^H : K] < \infty$（有限中间域）
   - $H$ 闭正规 $\iff$ $L^H/K$ Galois，此时 $\operatorname{Gal}(L^H/K) \cong G/H$

4. **利用结构定理：** 若 $G$ 有明确的结构（如 $\hat{\mathbb{Z}}$、$\mathbb{Z}_p^\times$），可以直接写出所有闭子群。
:::

::: warning 常见错误
- **忘记"闭"条件：** 直接把有限 Galois 对应的陈述搬到无限情形，不加"闭"字。这是最常见的错误。
- **混淆开子群与闭子群：** 开子群一定是闭的，但反之不成立。例如 $\{1\}$ 在 $\hat{\mathbb{Z}}$ 中是闭的但不是开的。
- **忽略拓扑：** 无限 Galois 群上必须有 Krull 拓扑。不指定拓扑就谈论"Galois 对应"是无意义的。
:::

## §G. 本节总结 {#summary}

| 概念 | 核心内容 |
|:-----|:---------|
| **无穷 Galois 对应** | 中间域 ↔ 闭子群（反序双射） |
| **恢复定理** | $\operatorname{Gal}(L/L^H) = H$（**$H$ 必须闭**！） |
| **开子群** | $\iff$ 指数有限 $\iff$ 对应有限中间域 |
| **绝对 Galois 群** | $G_K = \operatorname{Gal}(\overline{K}/K)$，$G_{\mathbb{F}_q} \cong \hat{\mathbb{Z}}$，$G_\mathbb{Q}$ 极复杂 |
| **Galois 下降** | $L$-结构 + $G$-对称性 = $K$-结构 |

::: details 自测问题
1. 为什么无穷 Galois 对应中"闭"条件是必需的？$\mathbb{Z} \leq \hat{\mathbb{Z}}$ 的例子说明了什么？
2. 开子群和闭子群有什么关系？为什么有限指数的闭子群一定是开的？
3. $\operatorname{Gal}(\overline{\mathbb{F}}_p/\mathbb{F}_p) \cong \hat{\mathbb{Z}}$ 的闭子群有哪些？它们对应哪些中间域？
4. Galois 下降中"紧性"条件为什么是必需的？
:::
