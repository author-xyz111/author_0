# §11.1 Krull 拓扑 {#sec-krull-topology}

## 本节概要

::: tip 学习目标
1. 理解**逆极限**的构造，以及它如何将有限对象"组装"成无限对象
2. 掌握 **profinite 群**的三种等价定义：逆极限、紧+完全不连通+Hausdorff、有限群的极限
3. 理解 **Krull 拓扑**如何从域扩张结构中自然涌现，使无限 Galois 群成为 profinite 群
4. 认识 profinite 群的基本例子：$p$-进整数 $\mathbb{Z}_p$、profinite 完成 $\hat{\mathbb{Z}}$、绝对 Galois 群
:::

## 动机：从有限到无限 {#motivation}

在有限 Galois 理论中，一切都很"干净"：$\operatorname{Gal}(L/K)$ 是有限群，中间域与子群一一对应。但当我们试图把理论推广到无限扩张时，会遇到一个根本性的问题。

设 $L/K$ 是无限 Galois 扩张（例如 $L = \overline{\mathbb{F}}_p$，$K = \mathbb{F}_p$）。则 $\operatorname{Gal}(L/K)$ 是无限群。在有限理论中，Galois 对应依赖于以下事实：

$$
H \leq \operatorname{Gal}(L/K) \implies L^H \text{ 是中间域}, \quad \operatorname{Gal}(L/L^H) = H.
$$

但在无限情形下，$\operatorname{Gal}(L/L^H) = H$ **未必成立**——即使对某些看起来"自然"的子群。问题出在哪里？

::: details 具体的反例
取 $L = \overline{\mathbb{F}}_p$，$K = \mathbb{F}_p$。则 $\operatorname{Gal}(L/K) \cong \hat{\mathbb{Z}}$（profinite 完成整数环），由 Frobenius $\operatorname{Frob}_p: x \mapsto x^p$ 拓扑生成。

考虑子群 $\mathbb{Z} \leq \hat{\mathbb{Z}}$（由 $1 \mapsto \operatorname{Frob}_p$ 生成的循环子群）。则：

- $\mathbb{Z}$ 的不动域是 $L^{\mathbb{Z}} = \{x \in \overline{\mathbb{F}}_p : \operatorname{Frob}_p^n(x) = x \text{ 对所有 } n \in \mathbb{Z}\}$。但 $\operatorname{Frob}_p$ 生成的群在 $\hat{\mathbb{Z}}$ 中**稠密**（因为它在每个有限商 $\mathbb{Z}/n\mathbb{Z}$ 上都是满射）。故 $L^{\mathbb{Z}} = L^{\hat{\mathbb{Z}}} = \mathbb{F}_p$。
- 但 $\operatorname{Gal}(L/\mathbb{F}_p) = \hat{\mathbb{Z}} \neq \mathbb{Z}$。

即：$\operatorname{Gal}(L/L^{\mathbb{Z}}) = \hat{\mathbb{Z}} \supsetneq \mathbb{Z}$。有限理论中的恢复定理（$\operatorname{Gal}(L/L^H) = H$）对非闭子群失效了。
:::

Krull 的解决办法是：给 Galois 群赋予一种**拓扑**——由域扩张本身的结构自然决定——使得"正确的"子群恰好是**闭子群**。

## §A. 背景：逆系统与逆极限 {#inverse-limits}

在正式进入 Krull 拓扑之前，我们需要回顾逆极限这一基本构造。逆极限是将一族有限对象"组装"成无限（profinite）对象的标准工具。

::: definition 逆系统 {#def-inverse-system}
一个**逆系统**（inverse system）由以下数据组成：
- 一个有向集 $(I, \leq)$（即对任意 $i, j \in I$，存在 $k \in I$ 使得 $i \leq k$，$j \leq k$）
- 对每个 $i \in I$，一个对象 $G_i$（群、环、集合等）
- 对每对 $i \leq j$，一个态射 $\varphi_{ij}: G_j \to G_i$（过渡映射）

满足**相容性条件**：
- $\varphi_{ii} = \operatorname{id}_{G_i}$
- 若 $i \leq j \leq k$，则 $\varphi_{ik} = \varphi_{ij} \circ \varphi_{jk}$

记作 $\{G_i, \varphi_{ij}\}_{i \in I}$。
:::

::: intuition 逆系统的直觉
逆系统是一族对象，它们之间的过渡映射方向是"向后"的（$\varphi_{ij}: G_j \to G_i$，$i \leq j$）。直觉上，$G_j$ 是"更精细"的对象，$\varphi_{ij}$ 是"投影"或"遗忘"映射——丢掉 $G_j$ 中超出 $G_i$ 范围的信息。

典型例子：
- $G_n = \mathbb{Z}/p^n\mathbb{Z}$，过渡映射 $\varphi_{mn}: \mathbb{Z}/p^n\mathbb{Z} \to \mathbb{Z}/p^m\mathbb{Z}$（模 $p^m$ 约化，$m \leq n$）
- $G_F = \operatorname{Gal}(F/K)$（$F$ 为有限 Galois 子扩张），过渡映射 $\varphi_{FF'}: \operatorname{Gal}(F'/K) \to \operatorname{Gal}(F/K)$（限制映射，$F \subseteq F'$）
:::

::: definition 逆极限 {#def-inverse-limit}
逆系统 $\{G_i, \varphi_{ij}\}$ 的**逆极限**（inverse limit）定义为：

$$
\varprojlim_i G_i := \left\{(g_i)_{i \in I} \in \prod_{i \in I} G_i : \varphi_{ij}(g_j) = g_i \text{ 对所有 } i \leq j\right\}.
$$

即逆极限由所有**兼容族**（compatible family）组成——在每个投影下保持一致的元素族。

当 $G_i$ 是拓扑群（取离散拓扑）时，$\varprojlim_i G_i$ 配备乘积拓扑的子空间拓扑。
:::

::: example $p$-进整数 {#ex-p-adic-integers}
取 $G_n = \mathbb{Z}/p^n\mathbb{Z}$，过渡映射为模 $p^m$ 约化。则：

$$
\mathbb{Z}_p := \varprojlim_n \mathbb{Z}/p^n\mathbb{Z} = \{(a_1, a_2, a_3, \ldots) : a_n \in \mathbb{Z}/p^n\mathbb{Z},\; a_{n+1} \equiv a_n \pmod{p^n}\}.
$$

这是 **$p$-进整数环**。元素可以写成 $p$-进展开 $a_0 + a_1 p + a_2 p^2 + \cdots$（$0 \leq a_i < p$）。$\mathbb{Z}_p$ 是一个紧的、完全不连通的拓扑环。

注意：$\mathbb{Z}$ 通过 $n \mapsto (n \bmod p, n \bmod p^2, \ldots)$ 嵌入 $\mathbb{Z}_p$，像在 $\mathbb{Z}_p$ 中稠密但不等于 $\mathbb{Z}_p$。
:::

## §B. Profinite 群 {#profinite-groups}

::: definition Profinite 群 {#def-profinite-group}
一个**profinite 群**（profinite group）是满足以下**等价条件之一**的拓扑群 $G$：

**(i) 逆极限刻画：** $G$ 同构于有限离散群的逆极限：
$$
G \cong \varprojlim_i G_i, \quad G_i \text{ 为有限群}.
$$

**(ii) 拓扑刻画：** $G$ 是**紧的、Hausdorff 的、完全不连通的**拓扑群。

**(iii) 满逆极限刻画：** $G$ 同构于有限群的逆极限，且所有过渡映射 $\varphi_{ij}$ 都是满同态。
:::

::: intuition 三种定义的含义
这三种定义给出同一个概念的不同侧面：

- **(i)** 是构造性的：profinite 群"来自"有限群的极限，是将有限信息组装成无限对象的过程。
- **(ii)** 是拓扑性的：profinite 群在拓扑上有一个很强的约束——完全不连通。这意味着它没有"连续"的部分（没有曲线、没有流形结构），只有"离散的碎片"通过极限粘合在一起。
- **(iii)** 是技术性的：满射条件保证逆极限"不丢失信息"——每个 $G_i$ 都能从 $G$ 通过商映射恢复。
:::

::: theorem 等价性的证明思路 {#proof-profinite-equivalence}
**(i) $\Rightarrow$ (ii)：** 有限离散群的乘积是紧的（Tychonoff 定理）、Hausdorff 的、完全不连通的。逆极限是乘积中的闭子集，因此保持这三个性质。

**(ii) $\Rightarrow$ (i)：** 紧 Hausdorff 完全不连通群 $G$ 的单位元邻域基由开正规子群 $\{N_i\}$ 给出。$G/N_i$ 是有限群（因为 $G$ 紧且 $N_i$ 开），且 $G \cong \varprojlim_i G/N_i$。

**(iii) $\Rightarrow$ (i)：** 显然（条件更强）。

**(i) $\Rightarrow$ (iii)：** 可以通过修正逆系统（取所有有限商）来实现过渡映射满射。
:::

::: example 基本 profinite 群 {#ex-profinite-basic}

**(i) $p$-进整数.** $\mathbb{Z}_p = \varprojlim_n \mathbb{Z}/p^n\mathbb{Z}$ 是 profinite 加法群。$p$-进拓扑由理想 $(p^n)$ 决定，与逆极限拓扑一致。

**(ii) Profinite 完成.** $\hat{\mathbb{Z}} = \varprojlim_n \mathbb{Z}/n\mathbb{Z}$ 是整数环的 profinite 完成。由中国剩余定理 $\hat{\mathbb{Z}} \cong \prod_p \mathbb{Z}_p$（所有素数的 $p$-进整数的积）。

**(iii) 有限群.** 任何有限群 $G$（离散拓扑）是 profinite 的——它是"逆极限的退化情形"（只有自身一个对象的逆系统）。

**(iv) 绝对 Galois 群.** $\operatorname{Gal}(\overline{\mathbb{F}}_p/\mathbb{F}_p) \cong \hat{\mathbb{Z}}$（由 Frobenius 拓扑生成），$\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$（$\mathbb{Q}$ 的绝对 Galois 群——数论中最核心的对象之一）。

**(v) 有限群的直积.** $\prod_{i \in I} G_i$（$G_i$ 有限，乘积拓扑）是 profinite 群。特别地，$(\mathbb{Z}/2\mathbb{Z})^{\mathbb{N}}$（Cantor 空间的群结构）是 profinite 的。
:::

::: remark $\hat{\mathbb{Z}}$ 的结构
$\hat{\mathbb{Z}} = \prod_p \mathbb{Z}_p$ 的结构揭示了一个深刻的算术事实：**整数的所有素数信息可以独立编码**。每个 $\mathbb{Z}_p$ 捕获了"在素数 $p$ 处"的全部信息，而 $\hat{\mathbb{Z}}$ 将它们统一起来。这正是类域论（{thm-class-field-theory}）中 idele 类群结构的起点。
:::

## §C. Krull 拓扑的定义 {#krull-definition}

现在我们可以定义 Krull 拓扑了。设 $L/K$ 是（可能无限的）Galois 扩张。对每个有限 Galois 子扩张 $M/K$（即 $K \subseteq M \subseteq L$，$M/K$ 有限 Galois），定义
$$
N_M := \operatorname{Gal}(L/M) = \{\sigma \in \operatorname{Gal}(L/K) : \sigma|_M = \operatorname{id}_M\}.
$$

每个 $N_M$ 是 $\operatorname{Gal}(L/K)$ 的正规子群（因为 $M/K$ Galois $\implies$ $M$ 是 $\sigma M$ 的子域的正规闭包，$N_M$ 正规于 $\operatorname{Gal}(L/K)$）。

::: definition Krull 拓扑 {#def-krull-topology}
$\operatorname{Gal}(L/K)$ 上的 **Krull 拓扑**以 $\{N_M : M/K \text{ 有限 Galois}\}$ 为单位元 $e$ 的基本邻域系。即 $U \subseteq \operatorname{Gal}(L/K)$ 是开集当且仅当对每个 $\sigma \in U$，存在有限 Galois 子扩张 $M/K$ 使得 $\sigma N_M \subseteq U$。

等价地，$\operatorname{Gal}(L/K)$ 是逆极限 $\varprojlim_{M} \operatorname{Gal}(M/K)$ 上的**逆极限拓扑**（乘积拓扑诱导的子空间拓扑）。
:::

::: intuition Krull 拓扑为什么是"正确的"
Krull 拓扑不是人为添加的额外结构，而是从域扩张本身**自然涌现**的。它的含义极其直观：

> 两个自同构 $\sigma, \tau \in \operatorname{Gal}(L/K)$ **接近**，当且仅当它们在某个有限子扩张 $M/K$ 上的限制**相同**。

换句话说：$\sigma$ 和 $\tau$ 在 $M$ 上无法区分 $\implies$ 它们在 Krull 拓扑下接近。

这完全类比于 $p$-进拓扑：两个整数 $a, b$ 在 $p$-进拓扑下接近 $\iff$ $a \equiv b \pmod{p^n}$ 对某个大 $n$。
:::

::: remark 等价定义的验证
"$\{N_M\}$ 作为邻域基"确实定义了一个拓扑群结构：

- **每个 $N_M$ 是子群：** 因为 $\sigma, \tau \in N_M \implies \sigma|_M = \tau|_M = \operatorname{id}_M \implies (\sigma\tau^{-1})|_M = \operatorname{id}_M$。
- **$N_M$ 正规于 $\operatorname{Gal}(L/K)$：** 对任意 $\sigma \in \operatorname{Gal}(L/K)$ 和 $\tau \in N_M$，$(\sigma\tau\sigma^{-1})|_M = \sigma|_M \circ \tau|_M \circ \sigma^{-1}|_M = \sigma|_M \circ \operatorname{id} \circ (\sigma|_M)^{-1} = \operatorname{id}_M$。
- **邻域基条件：** 对 $N_M, N_{M'}$，取 $M''$ 为 $M$ 和 $M'$ 在 $L/K$ 中的合成域（compositum），则 $M''/K$ 仍为有限 Galois，且 $N_{M''} \subseteq N_M \cap N_{M'}$。
:::

## §D. Krull 拓扑的基本性质 {#krull-properties}

::: theorem Krull 拓扑的性质 {#thm-krull-properties}
设 $L/K$ 是 Galois 扩张（可能无限）。则：

**(i)** $\operatorname{Gal}(L/K)$ 在 Krull 拓扑下是 **profinite 群**。

**(ii)** $\operatorname{Gal}(L/K) \cong \varprojlim_{M} \operatorname{Gal}(M/K)$，其中极限遍历所有有限 Galois 子扩张 $M/K$。

**(iii)** $\operatorname{Gal}(L/K)$ 是**紧的、Hausdorff 的、完全不连通的**。

**(iv)** 限制映射 $\pi_M: \operatorname{Gal}(L/K) \twoheadrightarrow \operatorname{Gal}(M/K)$（$\sigma \mapsto \sigma|_M$）是连续满同态，核为 $N_M$。

**(v)** 当 $L/K$ 是有限 Galois 扩张时，Krull 拓扑退化为**离散拓扑**，回归经典有限理论。
:::

<ProofToggle>

**证明.**

**(i)-(ii)** 设 $L/K = \bigcup_M M$（并集遍历所有有限 Galois 子扩张）。定义映射

$$
\Phi: \operatorname{Gal}(L/K) \to \varprojlim_M \operatorname{Gal}(M/K), \quad \sigma \mapsto (\sigma|_M)_M.
$$

- **良定义：** 若 $M \subseteq M'$，则 $\sigma|_{M'}|_M = \sigma|_M$，故族 $(\sigma|_M)_M$ 确实是兼容的。
- **单射：** 若 $\sigma|_M = \operatorname{id}_M$ 对所有 $M$，则 $\sigma|_L = \operatorname{id}_L$（因为 $L = \bigcup_M M$），故 $\sigma = \operatorname{id}$。
- **满射：** 设 $(\sigma_M)_M$ 是兼容族。对任意 $\alpha \in L$，$\alpha \in M$ 对某个有限 Galois 子扩张 $M$。定义 $\sigma(\alpha) = \sigma_M(\alpha)$。兼容性保证定义与 $M$ 的选择无关。
- **连续：** 投影 $\operatorname{pr}_M \circ \Phi = \pi_M$ 连续，故 $\Phi$ 在乘积拓扑下连续。逆映射 $\Phi^{-1}$ 也连续（因为 $\{N_M\}$ 正好给出逆极限拓扑的邻域基）。故 $\Phi$ 是同胚。

**(iii)** 有限离散群的乘积 $\prod_M \operatorname{Gal}(M/K)$ 是紧的（Tychonoff 定理）和 Hausdorff 的。$\operatorname{Gal}(L/K)$ 是该乘积中满足兼容条件的**闭子集**（相容性条件是闭条件），故紧性和 Hausdorff 性保持。完全不连通：对任意 $N_M$，$\operatorname{Gal}(L/K)/N_M \cong \operatorname{Gal}(M/K)$ 是有限离散群，故 $N_M$ 既开又闭。每个点的任意邻域包含一个既开又闭的邻域，故连通分支是单点集。

**(iv)** 限制映射 $\pi_M$ 连续由 Krull 拓扑定义直接得到（$N_M$ 是开集）。满射由嵌入扩张引理（{lem-embedding-extension}）保证。核为 $N_M$ 由定义得到。

**(v)** 当 $L/K$ 有限时，$L$ 本身是有限 Galois 子扩张，$N_L = \{\operatorname{id}\}$。故 $\{\operatorname{id}\}$ 是开集，拓扑离散。$\blacksquare$

</ProofToggle>

::: intuition 紧性的深刻含义
$\operatorname{Gal}(L/K)$ 的**紧性**是 Krull 拓扑最重要的性质之一。它意味着：

1. **有限商决定一切：** $G = \varprojlim_M G/N_M$。一个连续自同构 $\sigma \in G$ 完全由它在每个有限商 $\operatorname{Gal}(M/K)$ 上的限制决定。这就是"profinite"的含义——"关于有限的"。

2. **近似性质：** 紧性保证了有限信息到无限信息的"收敛"——如果我们知道 $\sigma$ 在越来越大的有限子扩张 $M$ 上的限制，这些限制唯一决定 $\sigma$。

3. **无限理论的有限化：** 紧性使得很多关于无限 Galois 群的问题可以"逐有限子扩张验证"。这是类域论（{thm-class-field-theory}）中局部-整体原理的拓扑基础。
:::

## §E. Krull 拓扑的具体计算 {#krull-computations}

::: example 有限域的绝对 Galois 群 {#ex-krull-finite-field}
设 $L = \overline{\mathbb{F}}_p$，$K = \mathbb{F}_p$。

有限 Galois 子扩张正好是 $\mathbb{F}_{p^n}$（$n = 1, 2, 3, \ldots$），且 $\operatorname{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p) \cong \mathbb{Z}/n\mathbb{Z}$（由 $\operatorname{Frob}_p: x \mapsto x^p$ 生成）。

逆系统为：
$$
\mathbb{Z}/n\mathbb{Z} \xleftarrow{\text{模 } n \text{ 约化}} \mathbb{Z}/mn\mathbb{Z} \xleftarrow{} \cdots
$$

故
$$
\operatorname{Gal}(\overline{\mathbb{F}}_p/\mathbb{F}_p) \cong \varprojlim_n \mathbb{Z}/n\mathbb{Z} = \hat{\mathbb{Z}}.
$$

$\hat{\mathbb{Z}}$ 的闭子群形如 $n\hat{\mathbb{Z}}$（$n \geq 0$），对应不动域 $\mathbb{F}_{p^n}$。这是 Krull 拓扑下一个具体可算的 Galois 对应。
:::

::: example $p$-进分圆扩张 {#ex-krull-cyclotomic}
设 $K = \mathbb{Q}$，$L = \mathbb{Q}(\zeta_{p^\infty}) = \bigcup_n \mathbb{Q}(\zeta_{p^n})$（所有 $p$ 幂次单位根生成的域）。

有限 Galois 子扩张为 $\mathbb{Q}(\zeta_{p^n})$，且
$$
\operatorname{Gal}(\mathbb{Q}(\zeta_{p^n})/\mathbb{Q}) \cong (\mathbb{Z}/p^n\mathbb{Z})^\times
$$
（通过 $\sigma_a(\zeta_{p^n}) = \zeta_{p^n}^a$ 给出同构，$a \in (\mathbb{Z}/p^n\mathbb{Z})^\times$）。

过渡映射 $(\mathbb{Z}/p^n\mathbb{Z})^\times \to (\mathbb{Z}/p^m\mathbb{Z})^\times$（$m \leq n$）是自然约化。

故
$$
\operatorname{Gal}(\mathbb{Q}(\zeta_{p^\infty})/\mathbb{Q}) \cong \varprojlim_n (\mathbb{Z}/p^n\mathbb{Z})^\times = \mathbb{Z}_p^\times
$$
（$p$-进单位群）。对奇素数 $p$，$\mathbb{Z}_p^\times \cong (\mathbb{Z}/p\mathbb{Z})^\times \times \mathbb{Z}_p$（作为拓扑群）。

这是 Krull 拓扑的一个具体应用：$\mathbb{Z}_p^\times$ 的闭子群精确对应 $\mathbb{Q}(\zeta_{p^\infty})$ 的中间域。
:::

::: example 实数域的 Galois 群 {#ex-krull-real}
设 $K = \mathbb{R}$，$L = \mathbb{C}$（代数闭包）。

$\mathbb{C}/\mathbb{R}$ 是有限 Galois 扩张，$\operatorname{Gal}(\mathbb{C}/\mathbb{R}) = \{1, \sigma\} \cong \mathbb{Z}/2\mathbb{Z}$（$\sigma$ 为复共轭）。

Krull 拓扑退化为离散拓扑（因为 $L/K$ 有限），回归经典理论。两个子群 $\{1\}$ 和 $\{1, \sigma\}$ 分别对应中间域 $\mathbb{C}$ 和 $\mathbb{R}$。
:::

## §F. Prof 理群的结构定理 {#profinite-structure}

::: theorem Profinite 群的结构 {#thm-profinite-structure}
设 $G = \varprojlim_i G_i$ 是 profinite 群。则：

**(i) 开正规子群与有限商：** 连续群同态 $f: G \to H$（$H$ 有限离散）的核是**开正规子群**。反之，每个开正规子群 $N$ 给出连续满同态 $G \to G/N$（$G/N$ 有限）。

**(ii) 完全由有限商决定：** $G = \varprojlim_{N \unlhd_o G} G/N$，其中 $N$ 跑遍所有开正规子群。

**(iii) 稠密子集的判据：** 子集 $U \subseteq G$ 是**稠密的**当且仅当它在每个有限商 $G/N$ 下的像是满射。
:::

<ProofToggle>

**证明.**

**(i)** 若 $H$ 有限离散，则 $f^{-1}(e_H)$ 既是核又是 $e$ 的开邻域（因为 $f$ 连续且 $H$ 离散）。反之，若 $N$ 是开正规子群，则 $G/N$ 有限（因为 $G$ 紧且 $N$ 开，$G/N$ 是紧离散空间从而有限），且投影 $G \to G/N$ 连续。

**(ii)** 设 $G = \varprojlim_i G_i$，则每个 $N_i = \ker(G \to G_i)$ 是开正规子群，且 $G_i \cong G/N_i$。由逆极限的万有性质，$G \cong \varprojlim_i G/N_i$。而 $\{N_i\}$ 包含了所有开正规子群（因为 $N$ 开 $\implies$ $N \supseteq N_i$ 对某个 $i$），故 $\varprojlim_{N} G/N \cong G$。

**(iii)** $U$ 稠密 $\iff$ $\overline{U} = G$ $\iff$ 对每个开正规子群 $N$，$U$ 在 $G/N$ 下的像覆盖整个 $G/N$（因为开正规子群构成 $G$ 的邻域基）。$\blacksquare$

</ProofToggle>

::: intuition 密度判据的意义
判据 (iii) 在实践中非常有用。例如：

- $\mathbb{Z}$ 在 $\hat{\mathbb{Z}}$ 中稠密，因为对每个 $n$，$\mathbb{Z} \twoheadrightarrow \mathbb{Z}/n\mathbb{Z}$ 是满射。
- $\operatorname{Frob}_p$ 在 $\operatorname{Gal}(\overline{\mathbb{F}}_p/\mathbb{F}_p) \cong \hat{\mathbb{Z}}$ 中生成一个稠密子群（它在每个有限商 $\mathbb{Z}/n\mathbb{Z}$ 上的像都是生成元）。

密度判据告诉我们：一个 profinite 群可以被一个看起来很小的子群"控制"——只要它在每个有限商上都是满射。
:::

## 常见误区 {#misconceptions}

::: warning 误区一：profinite 群就是有限群的直积
逆极限 $\varprojlim G_i$ 是直积 $\prod G_i$ 的**闭子群**，由兼容性条件定义。直积中的元素可以任意选取各分量，而逆极限中的元素必须满足投影映射的兼容性。

例如：$\hat{\mathbb{Z}} = \varprojlim \mathbb{Z}/n\mathbb{Z}$ 是 $\prod_{n \geq 1} \mathbb{Z}/n\mathbb{Z}$ 的一个很小的子集——只有那些在不同模数之间一致的元素。直积 $\prod_{n \geq 1} \mathbb{Z}/n\mathbb{Z}$ 的基数远大于 $\hat{\mathbb{Z}}$。
:::

::: warning 误区二：profinite 群可以是可数无穷的
**错误！** 无穷 profinite 群一定是**不可数**的。

证明思路：设 $G = \varprojlim G_i$，各 $G_i$ 有限且投影满射。若 $|G_i|$ 无界，则 $|G| \geq |G_i|$ 对所有 $i$，故 $|G|$ 不可数。若 $|G_i|$ 有界，则 $G_i$ 最终稳定，$G$ 有限。

所以 profinite 群只有两种：有限的，或不可数的。$\hat{\mathbb{Z}}$ 和 $\mathbb{Z}_p$ 都是不可数的。
:::

::: warning 误区三：Krull 拓扑只是"一种方便的拓扑"
Krull 拓扑不是人为选择的，它**唯一地**由域扩张结构决定。具体地说：

- 邻域基 $\{N_M = \operatorname{Gal}(L/M)\}$ 直接来自中间域 $M$。
- 这个拓扑使 $\operatorname{Gal}(L/K)$ 成为 profinite 群，从而恢复了有限 Galois 对应。
- 换一个拓扑（比如离散拓扑或度量拓扑），Galois 对应就失效了。

Krull 拓扑的"自然性"在于：它把域论的代数结构（中间域）转化为群论的拓扑结构（邻域基）。
:::

::: warning 误区四："闭"和"开"在 profinite 群中没有区别
在 profinite 群中，开子群一定是闭的（因为它的补集是其他陪集的并，每个陪集也是开的），但闭子群不一定是开的。

典型例子：在 $\hat{\mathbb{Z}}$ 中，$\{0\}$ 是闭的（Hausdorff 空间中的单点集总是闭的），但不是开的（$\{0\}$ 不包含任何 $n\hat{\mathbb{Z}}$）。

在 $\mathbb{Z}_p$ 中，$p\mathbb{Z}_p$ 是开的（指数为 $p$），$\{0\}$ 是闭的但不是开的，$p^2\mathbb{Z}_p$ 是开的且是 $p\mathbb{Z}_p$ 的真子群。
:::

## §G. 本节总结 {#summary}

| 概念 | 核心内容 |
|:-----|:---------|
| **逆极限** | $\varprojlim G_i$ = 兼容族构成的子群，将有限对象组装为无限对象 |
| **Profinite 群** | 紧 + Hausdorff + 完全不连通 = 有限群的逆极限 |
| **Krull 拓扑** | $N_M = \operatorname{Gal}(L/M)$（$M/K$ 有限 Galois）构成邻域基 |
| **基本性质** | $\operatorname{Gal}(L/K)$ 是 profinite 群，$\cong \varprojlim_M \operatorname{Gal}(M/K)$ |
| **有限退化** | $L/K$ 有限 $\implies$ Krull 拓扑离散，回归经典理论 |

::: details 自测问题
1. 为什么 profinite 群一定是紧的？它与有限群的直积有什么关系？
2. $p$-进整数 $\mathbb{Z}_p$ 和 profinite 完成 $\hat{\mathbb{Z}}$ 有什么区别和联系？
3. 为什么 Krull 拓扑需要以"有限 Galois 子扩张"而不是"所有有限子扩张"为索引？
4. 若 $L/K$ 是无限 Galois 扩张，$\operatorname{Gal}(L/K)$ 的子群 $\mathbb{Z}$（在某个元素生成的循环群嵌入下）为什么不是闭的？
:::
