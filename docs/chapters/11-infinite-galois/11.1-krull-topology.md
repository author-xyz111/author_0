# §11.1 Krull 拓扑 {#sec-krull-topology}

::: intuition 核心直觉
有限 Galois 理论的基石是 Galois 群与中间域之间的一一对应。但当扩张是无限时，Galois 群不再有自然的离散拓扑，一一对应也失效。Kronecker 的解决办法是给 Galois 群赋予一种**自然的拓扑**——Krull 拓扑——使得它成为**紧的、完全不连通的拓扑群**。在这个拓扑下，无穷 Galois 对应成为闭子群与中间域之间的反序一一对应。

这个拓扑不是人为构造，而是从域扩张本身的结构中**涌现**出来的：两个自同构"接近"当且仅当它们在某个有限子扩张上的限制相同。
:::

---

## Krull 拓扑的定义 {#krull-definition}

设 $L/K$ 是（可能无限的）Galois 扩张。对每个有限 Galois 子扩张 $M/K$（即 $K \subseteq M \subseteq L$，$M/K$ 有限 Galois），定义
$$
N_M := \operatorname{Gal}(L/M) = \{\sigma \in \operatorname{Gal}(L/K) : \sigma|_M = \operatorname{id}_M\}.
$$

::: definition Krull 拓扑 {#def-krull-topology}
$\operatorname{Gal}(L/K)$ 上的 **Krull 拓扑**以 $\{N_M : M/K \text{ 有限 Galois}\}$ 为单位元 $1$ 的基本邻域系。即 $U \subseteq \operatorname{Gal}(L/K)$ 是开集当且仅当对每个 $\sigma \in U$，存在有限 Galois 子扩张 $M/K$ 使得 $\sigma N_M \subseteq U$。

等价地，$\operatorname{Gal}(L/K)$ 是逆极限 $\varprojlim_{M} \operatorname{Gal}(M/K)$ 上的**逆极限拓扑**（乘积拓扑诱导的子空间拓扑）。
:::

::: theorem Krull 拓扑的性质 {#thm-krull-properties}
设 $L/K$ 是 Galois 扩张（可能无限）。则：

**(i)** $\operatorname{Gal}(L/K)$ 在 Krull 拓扑下是**紧的 Hausdorff 拓扑群**。

**(ii)** $\operatorname{Gal}(L/K)$ 是**完全不连通**的（即连通分支都是单点集）。

**(iii)** $\operatorname{Gal}(L/K)$ 是**profinite 群**：同构于有限群的逆极限
$$\operatorname{Gal}(L/K) \cong \varprojlim_{M} \operatorname{Gal}(M/K),$$
其中 $M$ 跑遍所有有限 Galois 子扩张。

**(iv)** 同态 $\sigma \mapsto \sigma|_M$ 给出连续满同态 $\operatorname{Gal}(L/K) \twoheadrightarrow \operatorname{Gal}(M/K)$，核为 $N_M$。
:::

<ProofToggle>

**证明.**

**(i) Hausdorff.** 对 $\sigma \neq \tau$，存在 $a \in L$ 使得 $\sigma(a) \neq \tau(a)$。取有限 Galois 子扩张 $M \ni a$，则 $\sigma|_M \neq \tau|_M$，故 $\sigma N_M \cap \tau N_M = \varnothing$。

**紧性.** 由 Tychonoff 定理，有限群的乘积 $\prod_M \operatorname{Gal}(M/K)$ 是紧的。$\operatorname{Gal}(L/K)$ 同构于该乘积中满足兼容条件的闭子集，闭子集 of 紧空间是紧的。

**(ii)** 因为 $N_M$ 既开又闭（是陪集 $1 \cdot N_M$，既开又闭），每个点的任意邻域包含一个既开又闭的邻域，故连通分支是单点集。

**(iii)** 直接由紧性和逆极限的拓扑定义得到。逆极限中的元素正好是兼容族 $(\sigma_M)_M$，其中 $\sigma_M \in \operatorname{Gal}(M/K)$ 且当 $M \subseteq M'$ 时 $\sigma_{M'}|_M = \sigma_M$。

**(iv)** 限制映射 $\pi_M: \operatorname{Gal}(L/K) \to \operatorname{Gal}(M/K)$ 连续（由拓扑定义直接得到），满射（由嵌入扩张引理，{lem-embedding-extension}），核为 $N_M$。$\blacksquare$

</ProofToggle>

::: remark 与 p-进整数的类比
最简单的 profinite 群的例子是 $p$-进整数 $\mathbb{Z}_p = \varprojlim_n \mathbb{Z}/p^n\mathbb{Z}$。类似地，$\operatorname{Gal}(\overline{\mathbb{F}}_p / \mathbb{F}_p) \cong \hat{\mathbb{Z}} = \varprojlim_n \mathbb{Z}/n\mathbb{Z}$，即全体整数的 profinite 完成。
:::

## Krull 拓扑与子群结构 {#krull-subgroup}

::: proposition 闭子群对应中间域 {#prop-closed-subgroup-correspondence}
设 $L/K$ 是 Galois 扩张。

**(i)** $H \leq \operatorname{Gal}(L/K)$ 是**闭子群** $\iff$ $H = \operatorname{Gal}(L/L^H)$（$L^H$ 是 $H$ 的固定域）。

**(ii)** 对中间域 $K \subseteq E \subseteq L$，$\operatorname{Gal}(L/E)$ 是**闭子群**。

**(iii)** 对闭子群 $H$，$\operatorname{Gal}(L^H / K) \cong \overline{\operatorname{Gal}(L/K) / H}$（商群的 profinite 完成，当 $H$ 正规时）。
:::

## profinite 群的一般理论 {#profinite-groups}

::: definition profinite 群 {#def-profinite-group}
**profinite 群**是有限离散群的非空逆极限。等价地，它是紧的、Hausdorff 的、完全不连通的拓扑群。
:::

::: example 基本 profinite 群 {#ex-profinite-basic}
**(i)** $p$-进整数 $\mathbb{Z}_p = \varprojlim \mathbb{Z}/p^n\mathbb{Z}$（加法群）。

**(ii)** $\hat{\mathbb{Z}} = \varprojlim \mathbb{Z}/n\mathbb{Z} = \prod_p \mathbb{Z}_p$（全体素数处的积）。

**(iii)** 有限群 $G$（离散拓扑）。

**(iv)** $\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$——绝对 Galois 群，代数数论中最核心的对象。
:::

::: theorem profinite 群的结构 {#thm-profinite-structure}
设 $G = \varprojlim G_i$ 是 profinite 群。则：

**(i)** 连续群同态 $f: G \to H$（$H$ 有限离散）的核是**开正规子群**。反之，每个开正规子群 $N$ 给出连续满同态 $G \to G/N$（$G/N$ 有限）。

**(ii)** $G$ 的**表示**完全由其有限商决定：$G = \varprojlim_{N \unlhd_o G} G/N$，其中 $N$ 跑遍开正规子群。

**(iii)** 子集 $U \subseteq G$ 是**稠密的**当且仅当它在每个有限商 $G/N$ 下的像是满射。
:::
