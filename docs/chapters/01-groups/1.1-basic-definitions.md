# §1.1 群的定义与基本性质 {#sec-group-definition}

## 动机

对称性是数学中最深刻的概念之一。一个正三角形的旋转对称、一个多项式根的置换、一个几何图形的自同构——这些表面不同的现象共享同一个代数结构：**群**。群的本质是将"变换的组合"抽象为公理系统。

本节建立群的公理体系，并证明最基本的结构性质：单位元与逆元的唯一性、消去律、对称群与 Cayley 定理。这些结果虽看似简单，却是整个 Galois 理论的基石——从 {def-group} 出发，经由 {def-subgroup}、{def-normal-subgroup}，最终抵达 [§8 Galois 对应](/chapters/08-galois-correspondence/) 中子群与中间域的深刻对偶。

## 定义 1.1.1 · 群 {#def-group}

::: definition 群 (Group) {#def-group}
设 $G$ 是一个非空集合，$\cdot \colon G \times G \to G$ 是 $G$ 上的一个二元运算。称 $(G, \cdot)$ 为一个**群**，如果满足以下三条公理：

**(G1) 结合律**：对所有 $a, b, c \in G$，

$$(a \cdot b) \cdot c = a \cdot (b \cdot c)$$

**(G2) 单位元存在**：存在 $e \in G$，使得对所有 $a \in G$，

$$e \cdot a = a \cdot e = a$$

**(G3) 逆元存在**：对每个 $a \in G$，存在 $a^{-1} \in G$，使得

$$a \cdot a^{-1} = a^{-1} \cdot a = e$$
:::

::: notation
在不引起歧义时，我们通常省略运算符号，将 $a \cdot b$ 简写为 $ab$。群 $G$ 的运算常称为**乘法**（即使 $G$ 不是数的集合）。当群的运算用加号 $+$ 表示时，单位元记为 $0$，逆元记为 $-a$。
:::

::: remark
仅满足 (G1) 和 (G2) 的代数结构称为**幺半群** (monoid)；仅满足 (G1) 的称为**半群** (semigroup)。群的特殊之处在于每个元素都可逆——这赋予了群"对称性"的本质特征。
:::

### 单位元和逆元的唯一性

公理只断言单位元和逆元的**存在**，但我们马上可以证明它们实际上是**唯一**的。这是典型的"公理弱但结论强"的例子。

::: lemma 单位元的唯一性 {#lem-identity-unique}
群 $(G, \cdot)$ 的单位元是唯一的。
:::

::: proof
设 $e$ 和 $e'$ 都是 $G$ 的单位元。则：

$$e = e \cdot e' = e'$$

第一个等号利用 $e'$ 是右单位元，第二个等号利用 $e$ 是左单位元。故 $e = e'$。
:::

::: lemma 逆元的唯一性 {#lem-inverse-unique}
设 $G$ 为群，$a \in G$。则 $a$ 的逆元唯一。
:::

::: proof
设 $b$ 和 $c$ 都是 $a$ 的逆元，即 $ab = ba = e$，$ac = ca = e$。则：

$$b = be = b(ac) = (ba)c = ec = c$$

第一个等号用 $e$ 是单位元，第二个用 $ac = e$，第三个用结合律，第四个用 $ba = e$，第五个用 $e$ 是单位元。故逆元唯一。
:::

::: notation
唯一确定的单位元通常记为 $e$（或 $1_G$），元素 $a$ 的唯一逆元记为 $a^{-1}$。
:::

### 交换群

::: definition 交换群 (Abelian Group) {#def-abelian}
若群 $(G, \cdot)$ 还满足**交换律**：对所有 $a, b \in G$，$ab = ba$，则称 $G$ 为**交换群**或 **Abel 群**。
:::

::: remark
Abel 群的运算通常用加号 $+$ 表示，此时交换律变为 $a + b = b + a$。我们需要注意区分乘法记号群和加法记号群的约定——在加法记号下，$2a$ 表示 $a + a$ 而非 $a$ 的平方。
:::

## 基本性质

::: lemma 幂运算律 {#lem-power-laws}
设 $G$ 为群，$a \in G$，$m, n \in \mathbb{Z}$。则：

1. $a^m \cdot a^n = a^{m+n}$
2. $(a^m)^n = a^{mn}$
3. $(a^{-1})^{-1} = a$
:::

<ProofToggle>

::: proof
**(1)** 对 $n \geq 0$，对 $n$ 归纳：$a^m \cdot a^0 = a^m \cdot e = a^m = a^{m+0}$，归纳步骤 $a^m \cdot a^{n+1} = a^m \cdot a^n \cdot a = a^{m+n} \cdot a = a^{m+n+1}$。对 $n < 0$，令 $n = -k$，$k > 0$：

$$a^m \cdot a^{-k} = a^m \cdot (a^k)^{-1} = a^{m-k}$$

这是因为 $a^m = a^{m-k} \cdot a^k$（由正指数情况），从而 $a^m \cdot (a^k)^{-1} = a^{m-k}$。

**(2)** 对 $n \geq 0$ 归纳，方法类似。

**(3)** 由逆元的定义直接得到：$a^{-1} \cdot (a^{-1})^{-1} = e$ 且 $a^{-1} \cdot a = e$，由 {lem:inverse-unique} 知 $(a^{-1})^{-1} = a$。
:::

</ProofToggle>

::: lemma 消去律 {#lem-cancellation}
设 $G$ 为群，$a, b, c \in G$。

1. (**左消去**) 若 $ab = ac$，则 $b = c$。
2. (**右消去**) 若 $ba = ca$，则 $b = c$。
:::

<ProofToggle>

::: proof
在 $ab = ac$ 两边左乘 $a^{-1}$：$a^{-1}(ab) = a^{-1}(ac)$，由结合律 $(a^{-1}a)b = (a^{-1}a)c$，即 $eb = ec$，故 $b = c$。右消去类似。
:::

</ProofToggle>

::: lemma 方程解 {#lem-equation-solve}
设 $G$ 为群，$a, b \in G$。则方程 $ax = b$ 和 $ya = b$ 在 $G$ 中各有**唯一**解，分别为 $x = a^{-1}b$ 和 $y = ba^{-1}$。
:::

<ProofToggle>

::: proof
对 $ax = b$：若 $x$ 满足方程，则 $a^{-1}(ax) = a^{-1}b$，即 $x = a^{-1}b$。反过来，$a(a^{-1}b) = (aa^{-1})b = eb = b$。唯一性和存在性均得证。另一方程类似。
:::

</ProofToggle>

## 对称群

::: definition 置换 {#def-permutation}
设 $X$ 为非空集合。$X$ 到自身的**双射** $\sigma \colon X \to X$ 称为 $X$ 的一个**置换**。
:::

::: theorem 对称群 {#thm-symmetric-group}
设 $X$ 为非空集合。$X$ 的所有置换在映射复合下构成一个群 $\operatorname{Sym}(X)$，称为 $X$ 的**对称群**。当 $|X| = n$（有限集）时，记 $S_n = \operatorname{Sym}(X)$，其阶为 $|S_n| = n!$。
:::

<ProofToggle>

::: proof
我们验证群公理：

**(G1) 结合律**：映射的复合天然满足结合律。若 $\sigma, \tau, \rho$ 都是 $X$ 的置换，则对任意 $x \in X$：

$$((\sigma \circ \tau) \circ \rho)(x) = (\sigma \circ \tau)(\rho(x)) = \sigma(\tau(\rho(x))) = \sigma((\tau \circ \rho)(x)) = (\sigma \circ (\tau \circ \rho))(x)$$

**(G2) 单位元**：恒等映射 $\operatorname{id}_X \colon x \mapsto x$ 是双射，且 $\sigma \circ \operatorname{id} = \operatorname{id} \circ \sigma = \sigma$。

**(G3) 逆元**：双射 $\sigma$ 的逆映射 $\sigma^{-1}$ 也是双射（因为双射的逆仍是双射），且 $\sigma \circ \sigma^{-1} = \sigma^{-1} \circ \sigma = \operatorname{id}$。

最后，$|X| = n$ 时，双射的个数恰好是从 $n$ 个元素中选排列的个数，即 $n!$。
:::

</ProofToggle>

::: remark
对称群 $S_n$ 是所有有限群的"母体"。下面的 Cayley 定理 ({thm:cayley}) 将表明，每一个有限群都可以看作某个 $S_n$ 的子群。
:::

### 例子

::: example $S_3$ 的结构 {#ex-s3}
$S_3$ 是最小的非交换群，它有 $3! = 6$ 个元素。用轮换记号表示：

$$S_3 = \{e, (12), (13), (23), (123), (132)\}$$

其中 $(123)$ 表示 $1 \mapsto 2 \mapsto 3 \mapsto 1$ 的轮换。注意 $(12)(13) = (132) \neq (123) = (13)(12)$，这说明 $S_3$ 非交换。
:::

<SubgroupLattice group="S3" />

::: example 循环群 $\mathbb{Z}/n\mathbb{Z}$ {#ex-cyclic}
设 $n \geq 1$。整数模 $n$ 的剩余类集合 $\mathbb{Z}/n\mathbb{Z} = \{\overline{0}, \overline{1}, \ldots, \overline{n-1}\}$ 在模 $n$ 加法下构成交换群。单位元是 $\overline{0}$，$\overline{k}$ 的逆元是 $\overline{n - k}$。
:::

::: example 四元数群 $Q_8$ {#ex-quaternion}
四元数群 $Q_8 = \{\pm 1, \pm i, \pm j, \pm k\}$ 满足 $i^2 = j^2 = k^2 = ijk = -1$。$Q_8$ 是 8 阶非交换群，与二面体群 $D_4$ 同阶但不同构（$Q_8$ 中只有 $-1$ 的阶为 2，而 $D_4$ 有多个 2 阶元素）。详见 {ex:quaternion}。
:::

## Cayley 定理

::: theorem Cayley 定理 {#thm-cayley}
每个群 $G$ 都同构于某个对称群 $\operatorname{Sym}(G)$ 的子群。特别地，每个 $n$ 阶有限群都同构于 $S_n$ 的某个子群。
:::

<ProofToggle>

::: proof
对每个 $a \in G$，定义**左平移映射** $\lambda_a \colon G \to G$ 为 $\lambda_a(x) = ax$。

**断言 1**：$\lambda_a$ 是 $G$ 上的双射。

- **单射**：若 $\lambda_a(x) = \lambda_a(y)$，即 $ax = ay$，由 {lem:cancellation}（左消去律），$x = y$。
- **满射**：对任意 $y \in G$，取 $x = a^{-1}y$，则 $\lambda_a(x) = a(a^{-1}y) = y$。

**断言 2**：映射 $\varphi \colon G \to \operatorname{Sym}(G)$，$\varphi(a) = \lambda_a$ 是群同态。

$$(\lambda_a \circ \lambda_b)(x) = \lambda_a(\lambda_b(x)) = \lambda_a(bx) = a(bx) = (ab)x = \lambda_{ab}(x)$$

故 $\lambda_a \circ \lambda_b = \lambda_{ab}$，即 $\varphi(ab) = \varphi(a) \circ \varphi(b)$。

**断言 3**：$\varphi$ 是单射。

若 $\varphi(a) = \varphi(b)$，即 $\lambda_a = \lambda_b$，则 $\lambda_a(e) = \lambda_b(e)$，即 $ae = be$，故 $a = b$。

因此 $\varphi$ 将 $G$ 嵌入 $\operatorname{Sym}(G)$ 为子群，即 $G \cong \varphi(G) \leq \operatorname{Sym}(G)$。当 $|G| = n$ 时，$\operatorname{Sym}(G) \cong S_n$。
:::

</ProofToggle>

::: intuition
Cayley 定理的意义在于：群的抽象公理实际上完全刻画了"对称变换"的本质。每个群元素都可以被理解为在某个对象集合上的一个变换——这就是**群作用**的观点，也是后续 [§7 Galois 群](/chapters/07-galois-groups/) 中 Galois 群作为域自同构群的核心思想。
:::

## 元素的阶

::: definition 元素的阶 {#def-order}
设 $G$ 为群，$a \in G$。若存在最小的正整数 $n$ 使得 $a^n = e$，则称 $a$ 的**阶**为 $n$，记为 $|a| = n$ 或 $\operatorname{ord}(a) = n$。若不存在这样的正整数，称 $a$ 的阶为无穷。
:::

::: lemma 阶的性质 {#lem-order-properties}
设 $G$ 为群，$a \in G$ 的阶为 $n < \infty$。

1. $a^m = e$ 当且仅当 $n \mid m$。
2. $|a^k| = \dfrac{n}{\gcd(n, k)}$。
:::

<ProofToggle>

::: proof
**(1)** 设 $m = qn + r$，$0 \leq r < n$。则 $a^m = a^{qn + r} = (a^n)^q \cdot a^r = e \cdot a^r = a^r$。故 $a^m = e$ 当且仅当 $a^r = e$。由 $n$ 的最小性，$r = 0$，即 $n \mid m$。

**(2)** 令 $d = \gcd(n, k)$，$n' = n/d$，$k' = k/d$。则 $|a^k|$ 是使得 $(a^k)^t = e$ 的最小正整数 $t$，即 $a^{kt} = e$。由 (1)，$n \mid kt$，即 $n'd \mid k'dt$，等价于 $n' \mid k't$。由于 $\gcd(n', k') = 1$，这等价于 $n' \mid t$。最小的这样的正整数为 $t = n' = n/d$。
:::

</ProofToggle>

## 子群生成

::: definition 生成子群 {#def-generated-subgroup}
设 $S$ 是群 $G$ 的子集。$G$ 中包含 $S$ 的最小子群称为由 $S$ **生成的子群**，记为 $\langle S \rangle$。等价地：

$$\langle S \rangle = \bigcap_{H \leq G,\, S \subseteq H} H$$
:::

::: proposition 生成子群的显式描述 {#prop-generated-subgroup}
设 $S$ 是群 $G$ 的子集。则：

$$\langle S \rangle = \{s_1^{\epsilon_1} s_2^{\epsilon_2} \cdots s_k^{\epsilon_k} : k \geq 0,\, s_i \in S,\, \epsilon_i \in \{1, -1\}\}$$

特别地，若 $G$ 交换（用加法记号），则：

$$\langle S \rangle = \left\{\sum_{i=1}^{k} n_i s_i : k \geq 0,\, n_i \in \mathbb{Z},\, s_i \in S\right\}$$
:::

<ProofToggle>

::: proof
记右端为 $H$。首先 $H \leq G$（直接验证封闭性、包含 $e$、对逆元封闭）。其次 $S \subseteq H$（取 $k = 1$, $\epsilon_1 = 1$）。最后，若 $K \leq G$ 且 $S \subseteq K$，则 $K$ 对运算和求逆封闭，从而包含 $H$ 的所有元素。故 $H = \langle S \rangle$。
:::

</ProofToggle>

::: definition 循环群 {#def-cyclic-group}
若群 $G = \langle a \rangle$ 由单个元素 $a$ 生成，称 $G$ 为**循环群**，$a$ 为 $G$ 的**生成元**。
:::

::: theorem 循环群的分类 {#thm-cyclic-classification}
设 $G = \langle a \rangle$ 为循环群。

1. 若 $|a| = \infty$，则 $G \cong (\mathbb{Z}, +)$。
2. 若 $|a| = n < \infty$，则 $G \cong \mathbb{Z}/n\mathbb{Z}$。
:::

<ProofToggle>

::: proof
**(1)** 映射 $\varphi \colon \mathbb{Z} \to G$，$\varphi(k) = a^k$ 是满射（因 $G = \langle a \rangle$）。若 $a^m = a^n$ 且 $m \neq n$，不妨设 $m > n$，则 $a^{m-n} = e$，与 $|a| = \infty$ 矛盾。故 $\varphi$ 是单射。又 $\varphi(m + n) = a^{m+n} = a^m \cdot a^n = \varphi(m) \cdot \varphi(n)$，故 $\varphi$ 是同构。

**(2)** 映射 $\varphi \colon \mathbb{Z}/n\mathbb{Z} \to G$，$\varphi(\overline{k}) = a^k$ 是良定义的（若 $\overline{m} = \overline{k}$，则 $n \mid (m - k)$，由 {lem:order-properties}(1)，$a^m = a^k$）。同 (1) 证明单满射和同态性。
:::

</ProofToggle>

## 与其他结构的联系

::: remark
群的概念将贯穿本教程的每一章。以下是关键的下游应用：

- **正规子群与商群** ({def-normal-subgroup}, {def-quotient-group})：当子群 $N$ 满足 $gNg^{-1} = N$ 对所有 $g \in G$，则可构造商群 $G/N$。
- **群同态基本定理** ({thm-first-isomorphism})：同态的核是正规子群，像同构于商群。
- **域扩张的 Galois 群** ({def-galois-group})：域扩张 $L/K$ 的 Galois 群 $\operatorname{Gal}(L/K)$ 由保持 $K$ 不变的 $L$ 的自同构构成——这正是 Cayley 定理"群即变换"思想的极致体现。
- **有限域的乘法群** ({thm-multiplicative-cyclic})：有限域 $\mathbb{F}_q$ 的非零元素在乘法下构成交换群，且该群是循环群。
:::

---

::: tip 本节要点
1. 群由结合律、单位元、逆元三条公理定义，单位元和逆元均唯一。
2. 消去律和方程可解性是群的直接推论。
3. 对称群 $S_n$ 是所有 $n$ 元置换在复合下构成的群，$|S_n| = n!$。
4. Cayley 定理：每个群都可以嵌入某个对称群——群本质上就是对称变换。
5. 循环群只有两种：$\mathbb{Z}$（无穷阶）和 $\mathbb{Z}/n\mathbb{Z}$（$n$ 阶有限）。
:::
