# 1.3 正规子群与商群

::: tip 学习目标
1. 理解正规子群的定义及其多种等价刻画。
2. 能判断给定子群是否为正规子群。
3. 理解商群的构造及其"良定义性"问题的本质。
4. 掌握自然投射的性质及其与同态核的联系。
5. 理解单群的概念及其在 Galois 理论中的核心作用。
:::

## 动机

我们已经看到，陪集 $aH$ 不一定等于 $Ha$。当 $H$ 足够"对称"时（即对所有 $a$，$aH = Ha$），陪集集合上可以定义自然的群结构——这就是正规子群和商群的核心思想。商群是"忽略 $H$ 内部细节，只看 $H$ 的宏观模式"的精确数学化。

::: info 为什么正规子群如此重要？
正规子群在代数学中具有多重角色：

1. **商群的构造**：只有正规子群才能定义商群。这是因为商群的运算 $(aN)(bN) = (ab)N$ 需要"良定义性"，而正规性正是保证这一点的条件。
2. **同态的核**：每个群同态 $\varphi: G \to H$ 的核 $\ker \varphi$ 都是 $G$ 的正规子群。反过来，每个正规子群都是某个同态的核（自然投射）。
3. **Galois 对应**：在 Galois 理论中，正规子群对应于 [正规扩张](/chapters/05-splitting-fields/)，商群对应于 Galois 群的商——这种对应是 [§8 Galois 对应](/chapters/08-galois-correspondence/) 的核心。
4. **可解性**：[§9 可解群](/chapters/09-solvability/) 的定义依赖于正规子群链，而五次方程不可根式求解的证明正是基于 $A_5$ 的单性。
:::

## 正规子群

::: definition 正规子群 {#def-normal-subgroup}
设 $N \leq G$。若对所有 $g \in G$，$gNg^{-1} = N$（等价地，$gN = Ng$ 对所有 $g \in G$），则称 $N$ 为 $G$ 的**正规子群**，记为 $N \trianglelefteq G$。
:::

::: remark
条件 $gNg^{-1} = N$ 等价于：对每个 $n \in N$，$gng^{-1} \in N$。注意我们不需要 $gng^{-1} = n$（这将是中心的条件），只需共轭仍在 $N$ 中。正规性是一个**集合层面**的条件，不是**元素层面**的条件。
:::

::: lemma 正规子群的等价条件 {#lem-normal-criteria}
设 $N \leq G$。以下条件等价：

1. $gNg^{-1} = N$ 对所有 $g \in G$。
2. $gNg^{-1} \subseteq N$ 对所有 $g \in G$。
3. $gN = Ng$ 对所有 $g \in G$（左陪集 = 右陪集）。
4. $N$ 中每个元素的共轭类都包含在 $N$ 中。
:::

<ProofToggle>

::: proof
**(1) $\Leftrightarrow$ (2)**：(1) $\Rightarrow$ (2) 显然。反之，若 $gNg^{-1} \subseteq N$，则 $N = g^{-1}(gNg^{-1})g \subseteq g^{-1}Ng$。将 $g$ 换为 $g^{-1}$ 得 $g^{-1}Ng \subseteq N$，故 $gNg^{-1} = N$。

**关键观察**：从 $gNg^{-1} \subseteq N$ 推出 $gNg^{-1} = N$，这个技巧依赖于 $g \mapsto g^{-1}$ 的对称性。如果只要求对**某些** $g$ 成立，条件就弱得多。

**(1) $\Leftrightarrow$ (3)**：$gN = Ng$ 即 $\{gn : n \in N\} = \{ng : n \in N\}$。对 $gn \in gN$，有 $gn = (gng^{-1})g \in Ng$（因 $gng^{-1} \in N$）。反之类似。

**(1) $\Leftrightarrow$ (4)**：由定义直接得到。
:::

</ProofToggle>

::: info 条件 (2) 为什么只需要"单边"？
证明中，从 $gNg^{-1} \subseteq N$ 推出 $N \subseteq gNg^{-1}$ 的关键步骤是：将 $g$ 替换为 $g^{-1}$，得到 $g^{-1}Ng \subseteq N$，两边左乘 $g$ 右乘 $g^{-1}$ 得 $N \subseteq gNg^{-1}$。这个技巧的核心是**$g^{-1}$ 也是 $G$ 中的元素**。如果我们考虑的不是整个群 $G$ 而是某个子集，这个论证就失效了。
:::

::: example 正规子群的例子 {#ex-normal-subgroups}

1. $\{e\}$ 和 $G$ 总是 $G$ 的正规子群，称为**平凡正规子群**。
2. 交换群的任何子群都是正规子群（因 $gng^{-1} = gg^{-1}n = n$）。例如 $\mathbb{Z}/6\mathbb{Z}$ 的所有子群都正规。
3. $A_n \trianglelefteq S_n$。这是因为 $\operatorname{sgn}(\sigma\tau\sigma^{-1}) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\tau)\operatorname{sgn}(\sigma)^{-1} = \operatorname{sgn}(\tau)$，所以共轭不改变置换的奇偶性。
4. $Z(G) \trianglelefteq G$。中心元素与所有元素交换，故共轭是恒等。
5. 指数为 2 的子群必正规：若 $[G : H] = 2$，则左陪集 $\{H, gH\}$ 等于右陪集 $\{H, Hg\}$（因为 $G \setminus H$ 同时是唯一的非平凡左陪集和唯一的非平凡右陪集）。
6. $D_4$ 中，旋转子群 $\{e, r, r^2, r^3\} \trianglelefteq D_4$（指数为 2）。但反射子群 $\{e, s\}$ 不正规。
:::

::: example 非正规子群的验证 {#ex-non-normal}

在 $S_3$ 中，$H = \{e, (12)\}$ 不是正规子群。验证：

取 $g = (13)$，则 $gHg^{-1} = (13)\{e, (12)\}(13)^{-1} = \{e, (13)(12)(13)\} = \{e, (23)\} \neq H$。

**关键点**：不需要检查所有 $g \in G$，只要找到一个反例就够了。正规性是一个"对所有 $g$"的条件，否定它只需要一个反例。

**一般规律**：在 $S_3$ 中，$\{e, (12)\}$，$\{e, (13)\}$，$\{e, (23)\}$ 都不是正规子群。正规子群只有 $\{e\}$，$A_3 = \{e, (123), (132)\}$，和 $S_3$ 自身。
:::

::: info $S_3$ 的正规子群结构
$S_3$ 的正规子群只有三个：$\{e\}$，$A_3 \cong \mathbb{Z}/3\mathbb{Z}$，和 $S_3$。这告诉我们：

1. $S_3$ 不是单群（有非平凡正规子群 $A_3$）。
2. $S_3/A_3 \cong \mathbb{Z}/2\mathbb{Z}$（商群）。
3. $A_3$ 是 $S_3$ 唯一的非平凡正规子群。

在 [§7 Galois 群](/chapters/07-galois-groups/) 中，我们会看到 $S_3$ 可以作为某个三次多项式的 Galois 群，此时正规子群 $A_3$ 对应于一个正规的中间域扩张。
:::

::: remark
非正规子群确实存在。例如在 $S_3$ 中，$H = \{e, (12)\}$ 不是正规子群：$(13)H(13)^{-1} = \{e, (23)\} \neq H$。在下方的子群格交互图中，非正规子群以不同颜色标注。
:::

::: info 共轭子群的几何直觉
$gNg^{-1}$ 是 $N$ 的"共轭"——它把 $N$ 中的每个元素通过 $g$ 做了一次"坐标变换"。如果 $N$ 是正规的，说明 $N$ 在所有"坐标变换"下都不变——这是非常强的对称性。

类比：在 $\mathbb{R}^3$ 中，考虑旋转群 $SO(3)$ 的子群。$z$ 轴的旋转子群不是正规的（绕 $x$ 轴旋转会把它变成 $y$ 轴的旋转子群），但整个 $SO(3)$ 的中心 $\{I\}$ 是正规的。
:::

## 商群

::: theorem 商群 {#thm-quotient-group}
设 $N \trianglelefteq G$。定义陪集集合 $G/N = \{gN : g \in G\}$ 上的运算为

$$(aN)(bN) = (ab)N$$

则 $(G/N, \cdot)$ 构成一个群，称为 $G$ 模 $N$ 的**商群**。$|G/N| = [G : N]$。
:::

<ProofToggle>

::: proof
**良定义性**：这是关键——我们必须证明运算不依赖于陪集代表元的选取。设 $aN = a'N$，$bN = b'N$。则 $a' = an_1$，$b' = bn_2$ 对某 $n_1, n_2 \in N$。故

$$a'b' = an_1 \cdot bn_2 = a(n_1 b)n_2 = a(b \cdot b^{-1}n_1 b)n_2 = ab \cdot (b^{-1}n_1 b)n_2$$

由 $N$ 的正规性，$b^{-1}n_1 b \in N$，故 $(b^{-1}n_1 b)n_2 \in N$。因此 $a'b' \in (ab)N$，即 $a'b'N = abN$。✓

**关键步骤**：$n_1 b = b(b^{-1}n_1 b)$ 这一步把 $n_1$ "移到"了 $b$ 的右边，代价是产生了共轭 $b^{-1}n_1 b$。正规性保证这个共轭仍在 $N$ 中。这就是为什么**只有正规子群才能定义商群**。

**群公理**：

- **结合律**：$(aN \cdot bN) \cdot cN = (ab)N \cdot cN = (abc)N = aN \cdot (bc)N = aN \cdot (bN \cdot cN)$。
- **单位元**：$eN = N$ 是单位元：$(aN)(eN) = (ae)N = aN$。
- **逆元**：$(aN)^{-1} = a^{-1}N$：$(aN)(a^{-1}N) = (aa^{-1})N = eN = N$。

$|G/N|$ 等于陪集个数 $[G:N]$，由定义。
:::

</ProofToggle>

::: info 良定义性：为什么这么重要？
商群的运算 $(aN)(bN) = (ab)N$ 看起来很简单，但它有一个隐藏的问题：同一个陪集可以用不同的代表元表示。例如在 $\mathbb{Z}/6\mathbb{Z}$ 中，$\overline{2} = \overline{8}$。如果定义乘法时选 $\overline{2}$ 和另一个选 $\overline{8}$ 得到不同的结果，运算就不是良定义的。

正规性正是排除这种"代表元依赖"的条件。对于非正规子群，陪集运算**一定**不是良定义的。
:::

::: example 商群的计算 {#ex-quotient-groups}

1. **$\mathbb{Z}/n\mathbb{Z}$**：这是 $\mathbb{Z}$ 模正规子群 $n\mathbb{Z}$ 的商群。$\mathbb{Z}/6\mathbb{Z} = \{\overline{0}, \overline{1}, \overline{2}, \overline{3}, \overline{4}, \overline{5}\}$，$|\mathbb{Z}/6\mathbb{Z}| = 6$。

2. **$S_3/A_3 \cong \mathbb{Z}/2\mathbb{Z}$**：$A_3 = \{e, (123), (132)\}$ 是 $S_3$ 的正规子群。$S_3/A_3有两个陪集：$A_3$（偶置换）和 $(12)A_3$（奇置换）。商群 $\cong \mathbb{Z}/2\mathbb{Z}$，由 $\operatorname{sgn}: S_3 \to \{-1, 1\}$ 给出。

3. **$D_4/\langle r \rangle \cong \mathbb{Z}/2\mathbb{Z}$**：$D_4$ 的旋转子群 $\langle r \rangle = \{e, r, r^2, r^3\}$ 的指数为 2，因此正规。商群有两个元素：旋转陪集和反射陪集。

4. **$\mathbb{Z}/4\mathbb{Z}$ 模 $\{\overline{0}, \overline{2}\}$**：$\{\overline{0}, \overline{2}\} \trianglelefteq \mathbb{Z}/4\mathbb{Z}$（交换群的子群都正规）。商群 $(\mathbb{Z}/4\mathbb{Z})/\{\overline{0}, \overline{2}\} \cong \mathbb{Z}/2\mathbb{Z}$。这是"忽略 $\mathbb{Z}/4\mathbb{Z}$ 中的 $2$-扭元素"的构造。
:::

::: intuition
商群 $G/N$ 是将 $N$ 中所有元素"坍缩"为一个单位元后的群结构。就像将一张纸上的每个等价类压成一个点——保持了群运算，但抹去了 $N$ 内部的结构细节。这是"局部化"的代数版本，也是 [环的商环](/chapters/02-rings/) 和 [分裂域与正规扩张](/chapters/05-splitting-fields/) 中类似构造的原型。

类比：在 $\mathbb{Z}/12\mathbb{Z}$ 中，$12\mathbb{Z} = \{\ldots, -12, 0, 12, 24, \ldots\}$ 被"坍缩"为一个元素 $\overline{0}$。整数环 $\mathbb{Z}$ 的"周期结构"被商群捕捉为有限群 $\mathbb{Z}/12\mathbb{Z}$。
:::

## 自然同态

::: definition 自然投射 {#def-natural-projection}
设 $N \trianglelefteq G$。映射

$$\pi \colon G \to G/N, \quad \pi(g) = gN$$

称为 $G$ 到 $G/N$ 的**自然投射**（或**典范满同态**）。
:::

::: proposition {#prop-natural-projection-is-hom}
自然投射 $\pi \colon G \to G/N$ 是满同态，且 $\ker \pi = N$。
:::

<ProofToggle>

::: proof
**同态性**：$\pi(ab) = (ab)N = (aN)(bN) = \pi(a)\pi(b)$。**满射**：对任意 $gN \in G/N$，$\pi(g) = gN$。**核**：$\ker \pi = \{g \in G : gN = N\} = \{g \in G : g \in N\} = N$。
:::

</ProofToggle>

::: remark
{prop-natural-projection-is-hom} 与 {thm-first-isomorphism} 结合，告诉我们：**每个正规子群都是某个同态的核，每个同态的核都是正规子群**。正规子群与同态的核是同一概念的两面。

具体地，对任意同态 $\varphi: G \to H$：
- $\ker \varphi \trianglelefteq G$（核是正规子群）。
- $G/\ker \varphi \cong \operatorname{im} \varphi$（第一同构定理）。

这个对应关系在 Galois 理论中至关重要：[§8.1 基本定理](/chapters/08-galois-correspondence/8.1-fundamental-theorem) 的核心就是 Galois 群的正规子群与正规中间域之间的对应。
:::

## 单群

::: definition 单群 {#def-simple-group}
若群 $G \neq \{e\}$ 且 $G$ 没有非平凡的正规子群（即 $G$ 的正规子群只有 $\{e\}$ 和 $G$ 自身），则称 $G$ 为**单群**。
:::

::: example 单群的例子 {#ex-simple-groups}

1. 素数阶循环群 $\mathbb{Z}/p\mathbb{Z}$ 是单群（因为其子群只有 $\{\overline{0}\}$ 和自身，由 {cor:prime-order}，子群阶必整除 $p$）。
2. $A_n$ 在 $n \geq 5$ 时是单群。这是 Galois 理论的核心定理之一——正是这一事实导致了一般五次方程不可根式求解（{thm-unsolvability-quintic}）。
3. $A_4$ 不是单群，因为 Klein 四元群 $V_4 = \{e, (12)(34), (13)(24), (14)(23)\} \trianglelefteq A_4$。
4. $A_5$ 是单群，$|A_5| = 60$。这是最小的非交换单群。
5. $S_3$ 不是单群（$A_3 \trianglelefteq S_3$）。
6. $S_n$ 在 $n \geq 3$ 时不是单群（$A_n$ 是非平凡正规子群）。
:::

::: info 为什么 $A_5$ 的单性如此重要？
$A_5$ 的单性意味着它不能被"分解"为更简单的群的商。在 [§9 可解群](/chapters/09-solvability/) 中，我们将看到：

- 可解群的定义要求存在正规子群链，使得每个商群都是交换群。
- $A_5$ 是单群且非交换，所以它不是可解群。
- $S_5$ 包含 $A_5$ 作为子群，因此 $S_5$ 也不是可解群。
- 五次方程的 Galois 群可以是 $S_5$，因此五次方程不能根式求解。

这就是 Galois 理论的巅峰结论：**代数的不可解性源于群的不可分解性**。
:::

::: intuition
单群之于群论，正如素数之于数论。Jordan–Hölder 定理表明，每个有限群都有唯一的"素因子分解"——分解为单群的组合（通过半直积和群扩张）。有限单群的分类是 20 世纪数学最宏伟的成就之一。

有限单群的分类定理（1981年完成）指出，每个有限单群属于以下四类之一：
1. **循环群** $\mathbb{Z}/p\mathbb{Z}$（$p$ 素数）
2. **交错群** $A_n$（$n \geq 5$）
3. **Lie 型单群**（包括典型群、例外群等）
4. **26 个散在单群**（sporadic groups），包括最大的"魔群"（Monster group），阶约 $8 \times 10^{53}$。
:::

## 非正规子群的系统判断

::: info 实用判据
判断 $N \leq G$ 是否正规，有以下实用策略：

1. **指数 2 判据**：若 $[G : N] = 2$，则 $N \trianglelefteq G$。这是最常用的判据。
2. **交换群判据**：若 $G$ 是交换群，则 $G$ 的所有子群都正规。
3. **中心判据**：$Z(G) \trianglelefteq G$ 总是成立。
4. **共轭类判据**：$N \trianglelefteq G$ 当且仅当 $N$ 是若干共轭类的并集（加上单位元）。
5. **反例法**：找一个 $g \in G$ 使得 $gNg^{-1} \neq N$，即证 $N$ 不正规。
:::

::: example 共轭类判据的应用
在 $S_4$ 中，共轭类（按循环类型分）为：

| 循环类型 | 代表元 | 共轭类大小 |
|------|------|------|
| $(1)$ | $e$ | 1 |
| $(2)$ | $(12)$ | 6 |
| $(2,2)$ | $(12)(34)$ | 3 |
| $(3)$ | $(123)$ | 8 |
| $(4)$ | $(1234)$ | 6 |

$A_4 = \{e\} \cup \{(12)(34), (13)(24), (14)(23)\} \cup \{(123), (132), (124), (142), (134), (143), (234), (243)\}$
$= \{e\}$（大小 1）$\cup$ 类型 $(2,2)$（大小 3）$\cup$ 类型 $(3)$（大小 8）$= 1 + 3 + 8 = 12$。✓

所以 $A_4$ 确实是正规子群（是完整共轭类的并）。

而 $V_4 = \{e, (12)(34), (13)(24), (14)(23)\} = \{e\} \cup$ 类型 $(2,2)$，也是完整共轭类的并，$|V_4| = 4$。所以 $V_4 \trianglelefteq S_4$。
:::

## 常见误区 {#misconceptions}

::: warning 误区一："所有子群都正规"
**错误！** 只有交换群的所有子群才都正规。在非交换群中，非正规子群是常见的。例如 $S_3$ 中的 $\{e, (12)\}$ 不正规。

事实上，"所有子群都正规"的群称为 **Dedekind 群**。交换群是 Dedekind 群，但非交换的 Dedekind 群也存在（称为 **Hamilton 群**，例如四元数群 $Q_8$）。
:::

::: warning 误区二："$gNg^{-1} = N$ 意味着 $gng^{-1} = n$"
**错误！** $gNg^{-1} = N$ 是集合层面的等式，意思是 $gNg^{-1}$ 和 $N$ 是同一个集合。这**不要求**对每个 $n \in N$ 都有 $gng^{-1} = n$。后者是中心的条件（$g$ 与所有 $n \in N$ 交换），远强于正规性。

例如在 $S_3$ 中，$A_3 \trianglelefteq S_3$，但 $(12)(123)(12)^{-1} = (132) \neq (123)$。正规性允许元素被"移动"，只要仍在集合 $N$ 内即可。
:::

::: warning 误区三："指数 3 的子群也一定正规"
**错误！** 只有指数 2 的子群保证正规。指数 3 的子群不一定正规。

反例：在 $S_3$ 中，$H = \{e, (12)\}$ 的指数为 3，但 $H$ 不是正规子群。更一般地，$S_n$ 中的稳定化子 $\operatorname{Stab}(n) \cong S_{n-1}$ 有指数 $n$，但一般不正规。
:::

::: warning 误区四："商群 $G/N$ 一定比 $G$ 小"
**严格来说，$|G/N| = [G : N] \leq |G|$。** 当 $N = \{e\}$ 时，$G/N \cong G$（大小不变）。当 $N = G$ 时，$G/N = \{e\}$（塌缩为平凡群）。只有当 $N$ 是非平凡正规子群时，商群才"严格小于"$G$。
:::

## 自测问题 {#self-test}

::: question 自测
1. **正规性判断**：在 $D_4$（正方形的对称群）中，判断以下子群是否正规：
   - (a) 旋转子群 $\{e, r, r^2, r^3\}$
   - (b) $\{e, r^2\}$
   - (c) $\{e, s\}$（$s$ 为某个反射）

2. **商群计算**：$S_4/V_4$ 同构于什么群？（$V_4 = \{e, (12)(34), (13)(24), (14)(23)\}$。提示：$|S_4/V_4| = 24/4 = 6$。）

3. **概念辨析**：解释为什么"正规子群的子群不一定是正规子群"。给出一个例子。

4. **单群验证**：证明 $\mathbb{Z}/p\mathbb{Z}$（$p$ 素数）是单群。（用 Lagrange 定理。）

5. **Galois 预备**：为什么 $A_5$ 的单性意味着五次方程不能用根式求解？简述论证思路。
:::

::: details 答案
1. (a) **正规**（指数为 2）。(b) **正规**（$r^2$ 与所有元素交换，实际上 $r^2 \in Z(D_4)$，所以 $\{e, r^2\}$ 在中心中，当然正规）。(c) **不正规**：$r\{e, s\}r^{-1} = \{e, rsr^{-1}\} = \{e, sr^2\} \neq \{e, s\}$。

2. $S_4/V_4 \cong S_3$。这是因为 $V_4$ 是 $S_4$ 的核（对应于 $S_4$ 在 $\{1,2,3,4\}$ 的 2+2 分拆上的作用），商群 $S_4/V_4$ 作用于三个 2-元子集对，得到 $S_3$。

3. 设 $G = S_4$，$N = V_4 \trianglelefteq S_4$，$H = \{e, (12)\} \leq V_4$... 不对，$\{e, (12)\} \not\leq V_4$。更好的例子：$G = D_4$，$N = \{e, r, r^2, r^3\} \trianglelefteq D_4$，$H = \{e, r^2\} \leq N$。$H$ 也是 $D_4$ 的正规子群（因为 $H \leq Z(D_4)$）。再找：$G = S_3 \times \mathbb{Z}/2\mathbb{Z}$，$N = A_3 \times \mathbb{Z}/2\mathbb{Z} \trianglelefteq G$，$H = A_3 \times \{0\} \leq N$。$H$ 是 $N$ 的正规子群（$N$ 是交换的），但 $H$ 不一定是 $G$ 的正规子群... 实际上 $A_3 \trianglelefteq S_3$，所以 $H \trianglelefteq G$。更难的例子需要更大的群。

4. $\mathbb{Z}/p\mathbb{Z}$ 的子群阶必整除 $p$（Lagrange 定理）。因为 $p$ 是素数，子群阶只能是 1 或 $p$，即子群只有 $\{\overline{0}\}$ 和 $\mathbb{Z}/p\mathbb{Z}$ 自身。$\mathbb{Z}/p\mathbb{Z} \neq \{\overline{0}\}$，所以 $\mathbb{Z}/p\mathbb{Z}$ 是单群。

5. 简述：(1) 五次方程的 Galois 群可以是 $S_5$。(2) 若 $S_5$ 可解，则五次方程可根式求解。(3) $S_5$ 包含 $A_5$ 作为指数 2 的正规子群。(4) 若 $S_5$ 可解，则 $A_5$ 也可解。(5) 可解群的商群仍是可解群，所以 $A_5$ 的商群（如果是非交换单群，则商群只能是 $\{e\}$ 或 $A_5$ 自身）必须是交换的。(6) 但 $A_5$ 是非交换单群，矛盾。
:::
