# 1.3 正规子群与商群

## 动机

我们已经看到，陪集 $aH$ 不一定等于 $Ha$。当 $H$ 足够"对称"时（即对所有 $a$，$aH = Ha$），陪集集合上可以定义自然的群结构——这就是正规子群和商群的核心思想。商群是"忽略 $H$ 内部细节，只看 $H$ 的宏观模式"的精确数学化。

在 Galois 理论中，正规子群对应于 [正规扩张](/chapters/06-splitting-fields/)，商群对应于 Galois 群的商——这种对应是 [§8 Galois 对应](/chapters/08-galois-correspondence/) 的核心。

## 正规子群

::: definition 正规子群 {#def-normal-subgroup}
设 $N \leq G$。若对所有 $g \in G$，$gNg^{-1} = N$（等价地，$gN = Ng$ 对所有 $g \in G$），则称 $N$ 为 $G$ 的**正规子群**，记为 $N \trianglelefteq G$。
:::

::: remark
条件 $gNg^{-1} = N$ 等价于：对每个 $n \in N$，$gng^{-1} \in N$。注意我们不需要 $gng^{-1} = n$（这将是中心的条件），只需共轭仍在 $N$ 中。
:::

::: lemma 正规子群的等价条件 {#lem-normal-criteria}
设 $N \leq G$。以下条件等价：

1. $gNg^{-1} = N$ 对所有 $g \in G$。
2. $gNg^{-1} \subseteq N$ 对所有 $g \in G$。
3. $gN = Ng$ 对所有 $g \in G$（左陪集 = 右陪集）。
4. $N$ 中每个元素的共轭类都包含在 $N$ 中。
:::

<ProofToggle>

::: proof
**(1) $\Leftrightarrow$ (2)**：(1) $\Rightarrow$ (2) 显然。反之，若 $gNg^{-1} \subseteq N$，则 $N = g^{-1}(gNg^{-1})g \subseteq g^{-1}Ng$。将 $g$ 换为 $g^{-1}$ 得 $g^{-1}Ng \subseteq N$，故 $gNg^{-1} = N$。

**(1) $\Leftrightarrow$ (3)**：$gN = Ng$ 即 $\{gn : n \in N\} = \{ng : n \in N\}$。对 $gn \in gN$，有 $gn = (gng^{-1})g \in Ng$（因 $gng^{-1} \in N$）。反之类似。

**(1) $\Leftrightarrow$ (4)**：由定义直接得到。
:::

</ProofToggle>

::: example 正规子群的例子 {#ex-normal-subgroups}

1. $\{e\}$ 和 $G$ 总是 $G$ 的正规子群，称为**平凡正规子群**。
2. 交换群的任何子群都是正规子群（因 $gng^{-1} = gg^{-1}n = n$）。
3. $A_n \trianglelefteq S_n$。这是因为 $\operatorname{sgn}(\sigma\tau\sigma^{-1}) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\tau)\operatorname{sgn}(\sigma)^{-1} = \operatorname{sgn}(\tau)$，所以共轭不改变置换的奇偶性。
4. $Z(G) \trianglelefteq G$。中心元素与所有元素交换，故共轭是恒等。
5. 指数为 2 的子群必正规：若 $[G : H] = 2$，则左陪集 $\{H, gH\}$ 等于右陪集 $\{H, Hg\}$（因为 $G \setminus H$ 同时是唯一的非平凡左陪集和唯一的非平凡右陪集）。
:::

::: remark
非正规子群确实存在。例如在 $S_3$ 中，$H = \{e, (12)\}$ 不是正规子群：$(13)H(13)^{-1} = \{e, (23)\} \neq H$。在下方的子群格交互图中，非正规子群以不同颜色标注。
:::

## 商群

::: theorem 商群 {#thm-quotient-group}
设 $N \trianglelefteq G$。定义陪集集合 $G/N = \{gN : g \in G\}$ 上的运算为

$$(aN)(bN) = (ab)N$$

则 $(G/N, \cdot)$ 构成一个群，称为 $G$ 模 $N$ 的**商群**。$|G/N| = [G : N]$。
:::

<ProofToggle>

::: proof
**良定义性**：这是关键——我们必须证明运算不依赖于陪集代表元的选取。设 $aN = a'N$，$bN = b'N$。则 $a' = an_1$，$b' = bn_2$ 对某 $n_1, n_2 \in N$。故

$$a'b' = an_1 \cdot bn_2 = a(n_1 b)n_2 = a(b \cdot b^{-1}n_1 b)n_2 = ab \cdot (b^{-1}n_1 b)n_2$$

由 $N$ 的正规性，$b^{-1}n_1 b \in N$，故 $(b^{-1}n_1 b)n_2 \in N$。因此 $a'b' \in (ab)N$，即 $a'b'N = abN$。✓

**群公理**：

- **结合律**：$(aN \cdot bN) \cdot cN = (ab)N \cdot cN = (abc)N = aN \cdot (bc)N = aN \cdot (bN \cdot cN)$。
- **单位元**：$eN = N$ 是单位元：$(aN)(eN) = (ae)N = aN$。
- **逆元**：$(aN)^{-1} = a^{-1}N$：$(aN)(a^{-1}N) = (aa^{-1})N = eN = N$。

$|G/N|$ 等于陪集个数 $[G:N]$，由定义。
:::

</ProofToggle>

::: intuition
商群 $G/N$ 是将 $N$ 中所有元素"坍缩"为一个单位元后的群结构。就像将一张纸上的每个等价类压成一个点——保持了群运算，但抹去了 $N$ 内部的结构细节。这是"局部化"的代数版本，也是 [环的商环](/chapters/02-rings/) 和 [域扩张](/chapters/05-field-extensions/) 中类似构造的原型。
:::

## 自然同态

::: definition 自然投射 {#def-natural-projection}
设 $N \trianglelefteq G$。映射

$$\pi \colon G \to G/N, \quad \pi(g) = gN$$

称为 $G$ 到 $G/N$ 的**自然投射**（或**典范满同态**）。
:::

::: proposition {#prop-natural-projection-is-hom}
自然投射 $\pi \colon G \to G/N$ 是满同态，且 $\ker \pi = N$。
:::

<ProofToggle>

::: proof
**同态性**：$\pi(ab) = (ab)N = (aN)(bN) = \pi(a)\pi(b)$。**满射**：对任意 $gN \in G/N$，$\pi(g) = gN$。**核**：$\ker \pi = \{g \in G : gN = N\} = \{g \in G : g \in N\} = N$。
:::

</ProofToggle>

::: remark
{prop-natural-projection-is-hom} 与 {thm-first-isomorphism} 结合，告诉我们：**每个正规子群都是某个同态的核，每个同态的核都是正规子群**。正规子群与同态的核是同一概念的两面。
:::

## 单群

::: definition 单群 {#def-simple-group}
若群 $G \neq \{e\}$ 且 $G$ 没有非平凡的正规子群（即 $G$ 的正规子群只有 $\{e\}$ 和 $G$ 自身），则称 $G$ 为**单群**。
:::

::: example 单群的例子 {#ex-simple-groups}

1. 素数阶循环群 $\mathbb{Z}/p\mathbb{Z}$ 是单群（因为其子群只有 $\{\overline{0}\}$ 和自身，由 {cor:prime-order}，子群阶必整除 $p$）。
2. $A_n$ 在 $n \geq 5$ 时是单群。这是 Galois 理论的核心定理之一——正是这一事实导致了一般五次方程不可根式求解（{thm-unsolvability-quintic}）。
3. $A_4$ 不是单群，因为 Klein 四元群 $V_4 = \{e, (12)(34), (13)(24), (14)(23)\} \trianglelefteq A_4$。
:::

::: intuition
单群之于群论，正如素数之于数论。Jordan–Hölder 定理表明，每个有限群都有唯一的"素因子分解"——分解为单群的组合（通过半直积和群扩张）。有限单群的分类是 20 世纪数学最宏伟的成就之一。
:::

---

::: tip 本节要点
1. 正规子群 $N \trianglelefteq G$ 的本质特征是左右陪集相等：$gN = Ng$。
2. 商群 $G/N$ 的运算 $aN \cdot bN = (ab)N$ 是良定义的，当且仅当 $N$ 正规。
3. 自然投射 $\pi \colon G \to G/N$ 是满同态，$\ker \pi = N$。
4. 单群是没有非平凡正规子群的群，是群的"素数"。
5. $A_n$（$n \geq 5$）的单性是 Galois 理论的关键支柱。
:::
