# 1.2 子群与 Lagrange 定理

## 子群

::: definition 子群 {#def-subgroup}
设 $(G, \cdot)$ 为群，$H \subseteq G$。若 $H$ 在 $G$ 的运算下自身也构成一个群，则称 $H$ 为 $G$ 的**子群**，记为 $H \leq G$。
:::

::: remark
子群关系 $\leq$ 是偏序关系（自反、反对称、传递）。$G$ 的所有子群在 $\leq$ 下构成一个格——称为**子群格**。对于 $S_3$，其子群格见下方交互图。
:::

::: lemma 子群判据 {#lem-subgroup-criterion}
设 $G$ 为群，$H \subseteq G$ 非空。则 $H \leq G$ 当且仅当以下任一条件成立：

1. **二步判据**：对所有 $a, b \in H$，$ab \in H$（封闭性）；对所有 $a \in H$，$a^{-1} \in H$（逆元封闭）。
2. **一步判据**：对所有 $a, b \in H$，$ab^{-1} \in H$。
:::

<ProofToggle>

::: proof
**(1) 的必要性**：由群公理直接得到。**充分性**：封闭性保证运算是 $H$ 上的二元运算，结合律继承自 $G$。取 $a \in H$（$H \neq \varnothing$），则 $e = a a^{-1} \in H$。单位元和逆元公理满足。

**(2) 的充分性**：取 $a \in H$，则 $e = a a^{-1} \in H$。再由 $e, a \in H$，$a^{-1} = e a^{-1} \in H$。最后 $a, b \in H$ 则 $b^{-1} \in H$，$a(b^{-1})^{-1} = ab \in H$。归结为 (1)。
:::

</ProofToggle>

::: example 子群的例子 {#ex-subgroups}

1. $\{e\}$ 和 $G$ 自身总是 $G$ 的子群，称为**平凡子群**。
2. $n\mathbb{Z} = \{nk : k \in \mathbb{Z}\}$ 是 $(\mathbb{Z}, +)$ 的子群。
3. $A_n = \{\sigma \in S_n : \operatorname{sgn}(\sigma) = 1\}$（偶置换的集合）是 $S_n$ 的子群，称为 $n$ 次**交错群**。
4. $\operatorname{SL}_n(F) = \{A \in \operatorname{GL}_n(F) : \det(A) = 1\}$ 是 $\operatorname{GL}_n(F)$ 的子群。
:::

## 陪集与 Lagrange 定理

::: definition 左陪集 {#def-left-coset}
设 $H \leq G$，$a \in G$。集合

$$aH = \{ah : h \in H\}$$

称为 $H$ 在 $G$ 中含 $a$ 的**左陪集**。类似定义右陪集 $Ha = \{ha : h \in H\}$。
:::

::: lemma 陪集的性质 {#lem-coset-properties}
设 $H \leq G$，$a, b \in G$。则：

1. $aH = bH$ 当且仅当 $a^{-1}b \in H$。
2. 两个左陪集要么相等，要么不交。
3. $|aH| = |H|$ 对所有 $a \in G$ 成立。
:::

<ProofToggle>

::: proof
**(1)** ($\Rightarrow$) 若 $aH = bH$，则 $b = be \in bH = aH$，故 $b = ah$ 对某 $h \in H$，$a^{-1}b = h \in H$。

($\Leftarrow$) 若 $a^{-1}b = h \in H$，则 $b = ah$。对任意 $bh' \in bH$（$h' \in H$），$bh' = a(hh') \in aH$（因 $hh' \in H$）。故 $bH \subseteq aH$。对称地 $aH \subseteq bH$。

**(2)** 设 $aH \cap bH \neq \varnothing$，取 $c \in aH \cap bH$。则 $c = ah_1 = bh_2$，$a^{-1}b = h_1 h_2^{-1} \in H$。由 (1)，$aH = bH$。

**(3)** 映射 $H \to aH$，$h \mapsto ah$ 是双射（$a^{-1}$ 给出其逆映射）。
:::

</ProofToggle>

::: definition 指数 {#def-index}
$H$ 在 $G$ 中的**指数** $[G : H]$ 定义为 $H$ 在 $G$ 中左陪集的个数。
:::

::: theorem Lagrange 定理 {#thm-lagrange}
设 $G$ 为有限群，$H \leq G$。则

$$|G| = [G : H] \cdot |H|$$

特别地，$|H|$ 整除 $|G|$，$[G : H]$ 整除 $|G|$。
:::

<ProofToggle>

::: proof
由 {lem:coset-properties}(2)，$G$ 被 $H$ 的左陪集划分为不交并。设不同的左陪集为 $a_1 H, a_2 H, \ldots, a_r H$，其中 $r = [G : H]$。则：

$$G = a_1 H \sqcup a_2 H \sqcup \cdots \sqcup a_r H$$

由 {lem:coset-properties}(3)，$|a_i H| = |H|$。故

$$|G| = \sum_{i=1}^{r} |a_i H| = r \cdot |H| = [G : H] \cdot |H|$$
:::

</ProofToggle>

::: intuition
Lagrange 定理告诉我们：子群的阶只能"恰好切分"群的阶。这就像一个拼图——子群是基本图案，群由整数个这样的图案（陪集）拼成。这是群论中"除法"的本质。

逆命题不成立：$A_4$（12 阶）有 6 阶子群的指数为 2，但 $A_4$ 没有 6 阶子群。这说明 Sylow 定理 ({thm-sylow-first}) 才是研究子群存在性的正确工具。
:::

::: corollary {#cor-order-divides}
设 $G$ 为有限群，$a \in G$。则 $|a|$ 整除 $|G|$，从而 $a^{|G|} = e$。
:::

<ProofToggle>

::: proof
$\langle a \rangle$ 是 $G$ 的子群，$|\langle a \rangle| = |a|$。由 Lagrange 定理，$|a| \mid |G|$。设 $|G| = n|a|$，则 $a^{|G|} = (a^{|a|})^n = e^n = e$。
:::

</ProofToggle>

::: corollary 素数阶群是循环群 {#cor-prime-order}
设 $|G| = p$ 为素数。则 $G$ 是循环群，且对任何 $a \neq e$，$G = \langle a \rangle$。
:::

<ProofToggle>

::: proof
取 $a \in G$，$a \neq e$。则 $|\langle a \rangle| > 1$，且 $|\langle a \rangle|$ 整除 $p$。由 $p$ 是素数，$|\langle a \rangle| = p$，故 $\langle a \rangle = G$。
:::

</ProofToggle>

::: corollary Fermat 小定理 {#cor-fermat}
对素数 $p$ 和所有 $a \not\equiv 0 \pmod{p}$，$a^{p-1} \equiv 1 \pmod{p}$。
:::

<ProofToggle>

::: proof
$(\mathbb{Z}/p\mathbb{Z})^* = \{1, 2, \ldots, p-1\}$ 在乘法下构成 $p - 1$ 阶群。由 {cor:order-divides}，$a^{p-1} = 1$。
:::

</ProofToggle>

::: remark
Fermat 小定理是数论中最基本的结果之一。它在 [§10 有限域](/chapters/10-finite-fields/) 的理论中有更深层的解释：有限域 $\mathbb{F}_p$ 的乘法群是 $p-1$ 阶循环群（{thm-finite-field-multiplicative}），Fermat 小定理不过是该群中元素阶整除群阶的特例。
:::

## 正规化子与中心化子

::: definition 中心与中心化子 {#def-center}
设 $G$ 为群。

1. $G$ 的**中心** $Z(G) = \{z \in G : zg = gz \text{ 对所有 } g \in G\}$。
2. 对 $a \in G$，$a$ 的**中心化子** $C_G(a) = \{g \in G : ga = ag\}$。
3. 对子集 $S \subseteq G$，$S$ 的**中心化子** $C_G(S) = \{g \in G : gs = sg \text{ 对所有 } s \in S\}$。
:::

::: lemma {#lem-center-is-subgroup}
$Z(G) \leq G$，且 $Z(G)$ 是交换群。$C_G(a) \leq G$。
:::

<ProofToggle>

::: proof
对 $Z(G)$：取 $z_1, z_2 \in Z(G)$。对任意 $g \in G$，$(z_1 z_2)g = z_1(z_2 g) = z_1(gz_2) = (z_1 g)z_2 = (gz_1)z_2 = g(z_1 z_2)$。故 $z_1 z_2 \in Z(G)$。又 $z^{-1}g = z^{-1}(gz)z^{-1} = (z^{-1}z)(gz^{-1}) = gz^{-1}$，故 $z^{-1} \in Z(G)$。由 {lem:subgroup-criterion}(1)，$Z(G) \leq G$。交换性由定义直接得到。$C_G(a)$ 类似。
:::

</ProofToggle>

::: definition 正规化子 {#def-normalizer}
设 $H \leq G$。$H$ 在 $G$ 中的**正规化子**定义为

$$N_G(H) = \{g \in G : gHg^{-1} = H\}$$

等价地，$N_G(H) = \{g \in G : gH = Hg\}$。显然 $H \leq N_G(H) \leq G$。
:::

::: remark
正规化子 $N_G(H)$ 是使 $H$ 成为其正规子群的最大子群：$H \trianglelefteq N_G(H)$。这个概念在 [§8 Galois 对应](/chapters/08-galois-correspondence/) 中将扮演重要角色，因为 Galois 对应的正规扩张条件对应于子群的正规性。
:::

::: proposition 共轭类方程 {#prop-class-equation}
设 $G$ 为有限群。则

$$|G| = |Z(G)| + \sum_{i=1}^{r} [G : C_G(a_i)]$$

其中 $a_1, \ldots, a_r$ 是 $G$ 的非中心共轭类的代表元。
:::

<ProofToggle>

::: proof
$G$ 上的**共轭关系** $a \sim b \Leftrightarrow b = gag^{-1}$ 是等价关系。等价类称为**共轭类**。元素 $a$ 的共轭类大小等于 $[G : C_G(a)]$（因为共轭类与左陪集 $gC_G(a)$ 一一对应）。中心元素的共轭类大小为 1。将所有共轭类的大小求和即得。
:::

</ProofToggle>

::: example $S_3$ 的共轭类
在 $S_3$ 中，$Z(S_3) = \{e\}$。三个对换 $(12), (13), (23)$ 构成一个共轭类（大小 3 = $[S_3 : C_{S_3}((12))] = 6/2$），两个 3-轮换 $(123), (132)$ 构成另一个共轭类（大小 2 = $[S_3 : C_{S_3}((123))] = 6/3$）。验证：$1 + 3 + 2 = 6 = |S_3|$。
:::

---

::: tip 本节要点
1. 子群判据提供检验子群的两种高效方法。
2. 陪集将群划分为等大小的"块"，Lagrange 定理是群论最重要的计数工具之一。
3. 元素的阶整除群的阶；素数阶群必循环。
4. Fermat 小定理是 Lagrange 定理的直接应用。
5. 中心和中心化子是分析群结构的基本工具。
6. 正规化子是连接子群与正规性的桥梁。
:::
