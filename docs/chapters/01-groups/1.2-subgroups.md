# §1.2 子群与 Lagrange 定理 {#sec-subgroups}

::: tip 学习目标
1. 掌握子群的定义和子群判据（一步判据和二步判据）。
2. 理解陪集的概念和性质，理解"陪集划分"的思想。
3. 掌握 Lagrange 定理及其推论（元素阶整除群阶、素数阶群循环、Fermat 小定理）。
4. 理解指数、正规化子、中心和中心化子的概念及其在群结构分析中的作用。
5. 了解 Lagrange 定理的逆命题不成立（Sylow 定理的动机）。
:::

## 子群

::: definition 子群 {#def-subgroup}
设 $(G, \cdot)$ 为群，$H \subseteq G$。若 $H$ 在 $G$ 的运算下自身也构成一个群，则称 $H$ 为 $G$ 的**子群**，记为 $H \leq G$。
:::

::: remark
子群关系 $\leq$ 是偏序关系（自反、反对称、传递）。$G$ 的所有子群在 $\leq$ 下构成一个格——称为**子群格**。对于 $S_3$，其子群格见下方交互图。
:::

::: lemma 子群判据 {#lem-subgroup-criterion}
设 $G$ 为群，$H \subseteq G$ 非空。则 $H \leq G$ 当且仅当以下任一条件成立：

1. **二步判据**：对所有 $a, b \in H$，$ab \in H$（封闭性）；对所有 $a \in H$，$a^{-1} \in H$（逆元封闭）。
2. **一步判据**：对所有 $a, b \in H$，$ab^{-1} \in H$。
:::

<ProofToggle>

::: proof
**(1) 的必要性**：由群公理直接得到。**充分性**：封闭性保证运算是 $H$ 上的二元运算，结合律继承自 $G$。取 $a \in H$（$H \neq \varnothing$），则 $e = a a^{-1} \in H$。单位元和逆元公理满足。

**(2) 的充分性**：取 $a \in H$，则 $e = a a^{-1} \in H$。再由 $e, a \in H$，$a^{-1} = e a^{-1} \in H$。最后 $a, b \in H$ 则 $b^{-1} \in H$，$a(b^{-1})^{-1} = ab \in H$。归结为 (1)。
:::

</ProofToggle>

::: example 子群的例子 {#ex-subgroups}

1. $\{e\}$ 和 $G$ 自身总是 $G$ 的子群，称为**平凡子群**。
2. $n\mathbb{Z} = \{nk : k \in \mathbb{Z}\}$ 是 $(\mathbb{Z}, +)$ 的子群。
3. $A_n = \{\sigma \in S_n : \operatorname{sgn}(\sigma) = 1\}$（偶置换的集合）是 $S_n$ 的子群，称为 $n$ 次**交错群**。
4. $\operatorname{SL}_n(F) = \{A \in \operatorname{GL}_n(F) : \det(A) = 1\}$ 是 $\operatorname{GL}_n(F)$ 的子群。
5. **循环子群**：$\langle a \rangle = \{a^n : n \in \mathbb{Z}\}$ 是 $G$ 中由 $a$ 生成的子群。$|a| = |\langle a \rangle|$。
6. **$S_3$ 的子群**：$\{e\}$，$S_3$，$\langle (12) \rangle = \{e, (12)\}$，$\langle (13) \rangle = \{e, (13)\}$，$\langle (23) \rangle = \{e, (23)\}$，$\langle (123) \rangle = A_3 = \{e, (123), (132)\}$。
:::

::: example 用二步判据验证 $n\mathbb{Z} \leq \mathbb{Z}$ {#ex-worked-criterion}
取 $H = 6\mathbb{Z} = \{0, \pm 6, \pm 12, \ldots\}$。
- $H \neq \varnothing$（$0 \in H$）。
- 封闭性：$6a + 6b = 6(a+b) \in H$。✓
- 逆元：$-(6a) = 6(-a) \in H$。✓

由 {lem:subgroup-criterion}(1)，$6\mathbb{Z} \leq \mathbb{Z}$。
:::

::: example 用一步判据验证 {#ex-one-step-worked}
取 $G = \operatorname{GL}_2(\mathbb{R})$，$H = \left\{\begin{pmatrix} a & b \\ 0 & d \end{pmatrix} : a, d \neq 0\right\}$（上三角可逆矩阵）。

验证一步判据：$A, B \in H$，设 $A = \begin{pmatrix} a & b \\ 0 & d \end{pmatrix}$，$B = \begin{pmatrix} a' & b' \\ 0 & d' \end{pmatrix}$。则 $B^{-1} = \frac{1}{a'd'}\begin{pmatrix} d' & -b' \\ 0 & a' \end{pmatrix}$。$AB^{-1} = \frac{1}{a'd'}\begin{pmatrix} ad' & -ab' + bd' \\ 0 & da' \end{pmatrix}$，仍是上三角。✓ 故 $H \leq \operatorname{GL}_2(\mathbb{R})$。
:::

::: warning 误区："子集对乘法封闭就是子群"
**不够！** 还需要逆元封闭。反例：$\mathbb{N} = \{0, 1, 2, \ldots\}$ 对加法封闭，$(\mathbb{N}, +)$ 不是 $(\mathbb{Z}, +)$ 的子群——因为负数的逆元不在 $\mathbb{N}$ 中。

同样，在 $\operatorname{GL}_2(\mathbb{R})$ 中，$\left\{\begin{pmatrix} a & 0 \\ 0 & d \end{pmatrix} : a, d > 0\right\}$ 对乘法封闭，但不含逆元（$\begin{pmatrix} 2 & 0 \\ 0 & 1 \end{pmatrix}^{-1} = \begin{pmatrix} 1/2 & 0 \\ 0 & 1 \end{pmatrix}$，对角元为正，所以这个例子恰好是子群）。更准确的反例：$\left\{\begin{pmatrix} a & 0 \\ 0 & d \end{pmatrix} : ad \neq 0, a + d > 0\right\}$——迹为正的对角矩阵对乘法封闭但逆元可能有负迹。
:::

## 陪集与 Lagrange 定理

::: definition 左陪集 {#def-left-coset}
设 $H \leq G$，$a \in G$。集合

$$aH = \{ah : h \in H\}$$

称为 $H$ 在 $G$ 中含 $a$ 的**左陪集**。类似定义右陪集 $Ha = \{ha : h \in H\}$。
:::

::: example 陪集的计算 {#ex-cosets}

1. **$\mathbb{Z}/3\mathbb{Z}$**：$H = 3\mathbb{Z}$ 在 $\mathbb{Z}$ 中的陪集是 $0 + 3\mathbb{Z} = \{\ldots, -3, 0, 3, 6, \ldots\}$，$1 + 3\mathbb{Z} = \{\ldots, -2, 1, 4, 7, \ldots\}$，$2 + 3\mathbb{Z} = \{\ldots, -1, 2, 5, 8, \ldots\}$。共 3 个陪集，$[\mathbb{Z} : 3\mathbb{Z}] = 3$。

2. **$S_3$ 中 $H = \langle (12) \rangle = \{e, (12)\}$ 的陪集**：
   - $eH = (12)H = \{e, (12)\}$
   - $(13)H = \{(13), (132)\}$
   - $(23)H = \{(23), (123)\}$
   - 共 3 个陪集，$[S_3 : H] = 3$。

3. **陪集不是子群**：$(13)H = \{(13), (132)\}$ 不含 $e$，不是子群。陪集一般不含单位元。

4. **左右陪集可能不同**：在 $S_3$ 中，$H(13) = \{(13), (123)\}$，但 $(13)H = \{(13), (132)\}$。$H(13) \neq (13)H$！这说明 $H$ 不是正规子群（{def-normal-subgroup}）。
:::

::: lemma 陪集的性质 {#lem-coset-properties}
设 $H \leq G$，$a, b \in G$。则：

1. $aH = bH$ 当且仅当 $a^{-1}b \in H$。
2. 两个左陪集要么相等，要么不交。
3. $|aH| = |H|$ 对所有 $a \in G$ 成立。
:::

<ProofToggle>

::: proof
**(1)** ($\Rightarrow$) 若 $aH = bH$，则 $b = be \in bH = aH$，故 $b = ah$ 对某 $h \in H$，$a^{-1}b = h \in H$。

($\Leftarrow$) 若 $a^{-1}b = h \in H$，则 $b = ah$。对任意 $bh' \in bH$（$h' \in H$），$bh' = a(hh') \in aH$（因 $hh' \in H$）。故 $bH \subseteq aH$。对称地 $aH \subseteq bH$。

**(2)** 设 $aH \cap bH \neq \varnothing$，取 $c \in aH \cap bH$。则 $c = ah_1 = bh_2$，$a^{-1}b = h_1 h_2^{-1} \in H$。由 (1)，$aH = bH$。

**(3)** 映射 $H \to aH$，$h \mapsto ah$ 是双射（$a^{-1}$ 给出其逆映射）。
:::

</ProofToggle>

::: definition 指数 {#def-index}
$H$ 在 $G$ 中的**指数** $[G : H]$ 定义为 $H$ 在 $G$ 中左陪集的个数。
:::

::: theorem Lagrange 定理 {#thm-lagrange}
设 $G$ 为有限群，$H \leq G$。则

$$|G| = [G : H] \cdot |H|$$

特别地，$|H|$ 整除 $|G|$，$[G : H]$ 整除 $|G|$。
:::

<ProofToggle>

::: proof
由 {lem:coset-properties}(2)，$G$ 被 $H$ 的左陪集划分为不交并。设不同的左陪集为 $a_1 H, a_2 H, \ldots, a_r H$，其中 $r = [G : H]$。则：

$$G = a_1 H \sqcup a_2 H \sqcup \cdots \sqcup a_r H$$

由 {lem:coset-properties}(3)，$|a_i H| = |H|$。故

$$|G| = \sum_{i=1}^{r} |a_i H| = r \cdot |H| = [G : H] \cdot |H|$$
:::

</ProofToggle>

::: intuition
Lagrange 定理告诉我们：子群的阶只能"恰好切分"群的阶。这就像一个拼图——子群是基本图案，群由整数个这样的图案（陪集）拼成。这是群论中"除法"的本质。

逆命题不成立：$A_4$（12 阶）有 6 阶子群的指数为 2，但 $A_4$ 没有 6 阶子群。这说明 Sylow 定理才是研究子群存在性的正确工具。
:::

::: corollary {#cor-order-divides}
设 $G$ 为有限群，$a \in G$。则 $|a|$ 整除 $|G|$，从而 $a^{|G|} = e$。
:::

<ProofToggle>

::: proof
$\langle a \rangle$ 是 $G$ 的子群，$|\langle a \rangle| = |a|$。由 Lagrange 定理，$|a| \mid |G|$。设 $|G| = n|a|$，则 $a^{|G|} = (a^{|a|})^n = e^n = e$。
:::

</ProofToggle>

::: corollary 素数阶群是循环群 {#cor-prime-order}
设 $|G| = p$ 为素数。则 $G$ 是循环群，且对任何 $a \neq e$，$G = \langle a \rangle$。
:::

<ProofToggle>

::: proof
取 $a \in G$，$a \neq e$。则 $|\langle a \rangle| > 1$，且 $|\langle a \rangle|$ 整除 $p$。由 $p$ 是素数，$|\langle a \rangle| = p$，故 $\langle a \rangle = G$。
:::

</ProofToggle>

::: corollary Fermat 小定理 {#cor-fermat}
对素数 $p$ 和所有 $a \not\equiv 0 \pmod{p}$，$a^{p-1} \equiv 1 \pmod{p}$。
:::

<ProofToggle>

::: proof
$(\mathbb{Z}/p\mathbb{Z})^* = \{1, 2, \ldots, p-1\}$ 在乘法下构成 $p - 1$ 阶群。由 {cor:order-divides}，$a^{p-1} = 1$。
:::

</ProofToggle>

::: remark
Fermat 小定理是数论中最基本的结果之一。它在 [§10 有限域](/chapters/10-finite-fields/) 的理论中有更深层的解释：有限域 $\mathbb{F}_p$ 的乘法群是 $p-1$ 阶循环群（{thm-multiplicative-cyclic}），Fermat 小定理不过是该群中元素阶整除群阶的特例。
:::

::: example Lagrange 定理的应用 {#ex-lagrange-applications}

1. **$S_3$ 的子群阶**：$|S_3| = 6$，故子群的阶只能是 $1, 2, 3, 6$。不能有 4 阶或 5 阶子群。

2. **$\mathbb{Z}/6\mathbb{Z}$ 的子群**：$\mathbb{Z}/6\mathbb{Z}$ 有子群 $\{0\}$（1 阶），$\{0, 3\}$（2 阶），$\{0, 2, 4\}$（3 阶），$\mathbb{Z}/6\mathbb{Z}$（6 阶）。对应阶数为 6 的因数。

3. **$A_4$ 没有 6 阶子群**：虽然 6 整除 12 = $|A_4|$，但 $A_4$ 没有 6 阶子群（可以验证 $A_4$ 中不存在 6 个元素对乘法封闭且含逆元的子集）。这说明 Lagrange 定理的逆命题不成立！

4. **Euler 定理**：$\gcd(a, n) = 1$ 蕴含 $a^{\phi(n)} \equiv 1 \pmod{n}$，其中 $\phi(n) = |(\mathbb{Z}/n\mathbb{Z})^*|$。这是 {cor:order-divides} 应用于群 $(\mathbb{Z}/n\mathbb{Z})^*$ 的结果，是 Fermat 小定理的推广。
:::

::: warning 误区："如果 $d \mid |G|$，则 $G$ 有 $d$ 阶子群"
**不成立！** Lagrange 定理只给出 $|H|$ 整除 $|G|$（子群存在 $\to$ 整除），不给出逆命题（整除 $\to$ 子群存在）。

反例：$A_4$（12 阶）没有 6 阶子群。

正确的方向由 Sylow 定理给出：如果 $p^k \mid |G|$（$p$ 是素数），则 $G$ 有 $p^k$ 阶子群。
:::

## 正规化子与中心化子

::: definition 中心与中心化子 {#def-center}
设 $G$ 为群。

1. $G$ 的**中心** $Z(G) = \{z \in G : zg = gz \text{ 对所有 } g \in G\}$。
2. 对 $a \in G$，$a$ 的**中心化子** $C_G(a) = \{g \in G : ga = ag\}$。
3. 对子集 $S \subseteq G$，$S$ 的**中心化子** $C_G(S) = \{g \in G : gs = sg \text{ 对所有 } s \in S\}$。
:::

::: lemma {#lem-center-is-subgroup}
$Z(G) \leq G$，且 $Z(G)$ 是交换群。$C_G(a) \leq G$。
:::

<ProofToggle>

::: proof
对 $Z(G)$：取 $z_1, z_2 \in Z(G)$。对任意 $g \in G$，$(z_1 z_2)g = z_1(z_2 g) = z_1(gz_2) = (z_1 g)z_2 = (gz_1)z_2 = g(z_1 z_2)$。故 $z_1 z_2 \in Z(G)$。又 $z^{-1}g = z^{-1}(gz)z^{-1} = (z^{-1}z)(gz^{-1}) = gz^{-1}$，故 $z^{-1} \in Z(G)$。由 {lem:subgroup-criterion}(1)，$Z(G) \leq G$。交换性由定义直接得到。$C_G(a)$ 类似。
:::

</ProofToggle>

::: example 中心的计算 {#ex-centers}

1. **交换群**：若 $G$ 是交换群，则 $Z(G) = G$。

2. **$S_3$ 的中心**：$Z(S_3) = \{e\}$。验证：$(12)(13) = (132) \neq (123) = (13)(12)$，所以 $(12) \notin Z(S_3)$。

3. **$\operatorname{GL}_n(F)$ 的中心**：$Z(\operatorname{GL}_n(F)) = \{aI_n : a \in F^\times\}$（标量矩阵）。验证：若 $A$ 与所有可逆矩阵交换，取 $A$ 与初等矩阵 $E_{ij}$ 交换，推出 $A$ 是对角矩阵且对角元相等。

4. **$D_4$ 的中心**：$Z(D_4) = \{e, r^2\}$（$r^2$ 是 180° 旋转，与所有元素交换）。
:::

::: definition 正规化子 {#def-normalizer}
设 $H \leq G$。$H$ 在 $G$ 中的**正规化子**定义为

$$N_G(H) = \{g \in G : gHg^{-1} = H\}$$

等价地，$N_G(H) = \{g \in G : gH = Hg\}$。显然 $H \leq N_G(H) \leq G$。
:::

::: remark
正规化子 $N_G(H)$ 是使 $H$ 成为其正规子群的最大子群：$H \trianglelefteq N_G(H)$。这个概念在 [§8 Galois 对应](/chapters/08-galois-correspondence/) 中将扮演重要角色，因为 Galois 对应的正规扩张条件对应于子群的正规性。
:::

::: example 正规化子的计算 {#ex-normalizer}

1. **$S_3$ 中 $\langle (12) \rangle$ 的正规化子**：$N_{S_3}(\langle (12) \rangle) = \langle (12) \rangle$（因为 $(13)(12)(13)^{-1} = (23) \notin \langle (12) \rangle$）。所以 $\langle (12) \rangle$ 不是正规子群。

2. **$S_3$ 中 $A_3$ 的正规化子**：$N_{S_3}(A_3) = S_3$（$A_3$ 是正规子群）。

3. **一般规律**：$H \trianglelefteq G$ 当且仅当 $N_G(H) = G$。
:::

::: proposition 共轭类方程 {#prop-class-equation}
设 $G$ 为有限群。则

$$|G| = |Z(G)| + \sum_{i=1}^{r} [G : C_G(a_i)]$$

其中 $a_1, \ldots, a_r$ 是 $G$ 的非中心共轭类的代表元。
:::

<ProofToggle>

::: proof
$G$ 上的**共轭关系** $a \sim b \Leftrightarrow b = gag^{-1}$ 是等价关系。等价类称为**共轭类**。元素 $a$ 的共轭类大小等于 $[G : C_G(a)]$（因为共轭类与左陪集 $gC_G(a)$ 一一对应）。中心元素的共轭类大小为 1。将所有共轭类的大小求和即得。
:::

</ProofToggle>

::: example $S_3$ 的共轭类
在 $S_3$ 中，$Z(S_3) = \{e\}$。三个对换 $(12), (13), (23)$ 构成一个共轭类（大小 3 = $[S_3 : C_{S_3}((12))] = 6/2$），两个 3-轮换 $(123), (132)$ 构成另一个共轭类（大小 2 = $[S_3 : C_{S_3}((123))] = 6/3$）。验证：$1 + 3 + 2 = 6 = |S_3|$。
:::

## 常见误区 {#misconceptions}

::: warning 误区一："$\langle a \rangle = \{a, a^2, a^3, \ldots\}$"
对有限阶群，$\langle a \rangle = \{e, a, a^2, \ldots, a^{|a|-1}\}$，因为 $a^{|a|} = e$。不要忘记单位元 $e$ 在其中。

对无限阶群，$\langle a \rangle = \{\ldots, a^{-2}, a^{-1}, e, a, a^2, \ldots\}$，包含所有 $a$ 的正幂和负幂。
:::

::: warning 误区二："子群的并也是子群"
**一般不是！** $H \cup K$ 对运算封闭当且仅当 $H \subseteq K$ 或 $K \subseteq H$。反例：$\langle (12) \rangle = \{e, (12)\}$ 和 $\langle (13) \rangle = \{e, (13)\}$ 的并 $\{e, (12), (13)\}$ 对乘法不封闭（$(12)(13) = (132) \notin \{e, (12), (13)\}$）。

正确的构造是 $H$ 和 $K$ 生成的子群 $\langle H, K \rangle$。
:::

::: warning 误区三："$[G : H] = |G|/|H|$ 只对有限群成立"
对无限群，指数 $[G : H]$ 可能是无穷大。例如 $[\mathbb{Z} : 2\mathbb{Z}] = 2$（有限），但 $[\mathbb{Q} : \mathbb{Z}] = \infty$（$\mathbb{Q}$ 关于 $\mathbb{Z}$ 有无穷多个陪集）。Lagrange 定理的乘法公式 $|G| = [G : H] \cdot |H|$ 要求 $|G|$ 有限。
:::

## 自测问题 {#self-test}

::: exercise 自测
1. **子群判定**：$\mathbb{Z}$ 中，$S = \{0, 3, 6, 9\}$ 在加法下是 $\mathbb{Z}/12\mathbb{Z}$ 的子群吗？$\mathbb{Z}/12\mathbb{Z}$ 的所有子群有哪些？

2. **Lagrange 定理应用**：$|G| = 35$。$G$ 中可能有哪些阶的元素？$G$ 是否一定是循环群？

3. **中心**：证明 $p$-群（$|G| = p^n$）的中心 $Z(G) \neq \{e\}$。（提示：使用共轭类方程 {prop:class-equation}。）

4. **正规化子**：在 $D_4$ 中，计算 $\langle r \rangle$（旋转子群）的正规化子。

5. **Fermat 小定理应用**：计算 $2^{100} \pmod{11}$。
:::

::: details 答案
1. $S = \{0, 3, 6, 9\}$ 在 $\mathbb{Z}/12\mathbb{Z}$ 中：$3 + 3 = 6$，$3 + 6 = 9$，$3 + 9 = 0$，$6 + 6 = 0$，$9 + 9 = 6$。✓ 封闭，逆元（$3^{-1} = 9$，$6^{-1} = 6$，$9^{-1} = 3$）。是子群。$\mathbb{Z}/12\mathbb{Z}$ 的子群：$\{0\}$，$\{0, 6\}$，$\{0, 4, 8\}$，$\{0, 3, 6, 9\}$，$\mathbb{Z}/12\mathbb{Z}$（对应 $12$ 的因数 1, 2, 3, 4, 6, 12）。

2. $35 = 5 \times 7$。元素阶整除 35，可能是 1, 5, 7, 35。若 $|a| = 35$，则 $G = \langle a \rangle$ 是循环群。实际上 $|G| = 35$ 的群必是循环群（因为 5 不整除 $7 - 1 = 6$，由 Sylow 定理，5-Sylow 和 7-Sylow 子群都是正规的，$G \cong \mathbb{Z}/5\mathbb{Z} \times \mathbb{Z}/7\mathbb{Z} \cong \mathbb{Z}/35\mathbb{Z}$）。

3. 共轭类方程：$|G| = |Z(G)| + \sum [G : C_G(a_i)]$。每个 $[G : C_G(a_i)]$ 整除 $|G| = p^n$ 且 $> 1$，所以是 $p$ 的倍数。$|Z(G)| = |G| - \sum [G : C_G(a_i)] \equiv p^n \equiv 0 \pmod{p}$。$|Z(G)| \geq 1$（$e \in Z(G)$），$p \mid |Z(G)|$，故 $|Z(G)| \geq p > 1$。✓

4. $D_4 = \langle r, s : r^4 = s^2 = e, srs = r^{-1} \rangle$，$\langle r \rangle = \{e, r, r^2, r^3\}$（4 阶）。$N_{D_4}(\langle r \rangle)$：$srs^{-1} = r^{-1} \in \langle r \rangle$，所以 $s \in N_{D_4}(\langle r \rangle)$。$N_{D_4}(\langle r \rangle) = D_4$（$\langle r \rangle$ 是 $D_4$ 的正规子群，指数 2）。

5. $2^{10} \equiv 1 \pmod{11}$（Fermat）。$100 = 10 \times 10$，$2^{100} = (2^{10})^{10} \equiv 1^{10} = 1 \pmod{11}$。
:::
