# 1.4 群同态基本定理

## 群同态

::: definition 群同态 {#def-group-homomorphism}
设 $(G, \cdot)$ 和 $(H, *)$ 为群。映射 $\varphi \colon G \to H$ 称为**群同态**，如果对所有 $a, b \in G$，

$$\varphi(ab) = \varphi(a) * \varphi(b)$$

若 $\varphi$ 还是双射，则称 $\varphi$ 为**群同构**，记为 $G \cong H$。
:::

::: remark
同态是保持群运算的映射。在范畴论语言中，群同态是群范畴 $\mathbf{Grp}$ 中的态射。同构是范畴等价——$G \cong H$ 意味着 $G$ 和 $H$ 作为群没有本质区别。
:::

::: lemma 同态的基本性质 {#lem-hom-properties}
设 $\varphi \colon G \to H$ 为群同态。则：

1. $\varphi(e_G) = e_H$。
2. $\varphi(a^{-1}) = \varphi(a)^{-1}$。
3. 若 $a \in G$ 的阶为 $n < \infty$，则 $|\varphi(a)|$ 整除 $n$。
4. 若 $K \leq G$，则 $\varphi(K) \leq H$。
5. 若 $L \leq H$，则 $\varphi^{-1}(L) \leq G$。
:::

<ProofToggle>

::: proof
**(1)** $\varphi(e_G) = \varphi(e_G \cdot e_G) = \varphi(e_G) * \varphi(e_G)$。由 {lem:cancellation}（$H$ 中的消去律），$\varphi(e_G) = e_H$。

**(2)** $\varphi(a) * \varphi(a^{-1}) = \varphi(aa^{-1}) = \varphi(e_G) = e_H$。由 {lem:inverse-unique}，$\varphi(a^{-1}) = \varphi(a)^{-1}$。

**(3)** $\varphi(a)^n = \varphi(a^n) = \varphi(e_G) = e_H$。由 {lem:order-properties}(1)，$|\varphi(a)| \mid n$。

**(4)** 对 $\varphi(a), \varphi(b) \in \varphi(K)$，$\varphi(a)\varphi(b)^{-1} = \varphi(ab^{-1}) \in \varphi(K)$（因 $ab^{-1} \in K$）。由 {lem:subgroup-criterion}(2)，$\varphi(K) \leq H$。

**(5)** 对 $a, b \in \varphi^{-1}(L)$，$\varphi(ab^{-1}) = \varphi(a)\varphi(b)^{-1} \in L$（因 $\varphi(a), \varphi(b) \in L$）。故 $ab^{-1} \in \varphi^{-1}(L)$。
:::

</ProofToggle>

## 核与像

::: definition 核与像 {#def-kernel-image}
设 $\varphi \colon G \to H$ 为群同态。

1. $\varphi$ 的**核** $\ker \varphi = \{g \in G : \varphi(g) = e_H\}$。
2. $\varphi$ 的**像** $\operatorname{im} \varphi = \varphi(G) = \{\varphi(g) : g \in G\}$。
:::

::: proposition 核是正规子群 {#prop-kernel-normal}
设 $\varphi \colon G \to H$ 为群同态。则 $\ker \varphi \trianglelefteq G$。
:::

<ProofToggle>

::: proof
由 {lem:hom-properties}(5)，$\ker \varphi = \varphi^{-1}(\{e_H\}) \leq G$。

正规性：对 $k \in \ker \varphi$，$g \in G$，

$$\varphi(gkg^{-1}) = \varphi(g)\varphi(k)\varphi(g)^{-1} = \varphi(g) \cdot e_H \cdot \varphi(g)^{-1} = e_H$$

故 $gkg^{-1} \in \ker \varphi$。由 {lem:normal-criteria}(2)，$\ker \varphi \trianglelefteq G$。
:::

</ProofToggle>

::: lemma 单射判据 {#lem-injective-criterion}
群同态 $\varphi \colon G \to H$ 是单射当且仅当 $\ker \varphi = \{e_G\}$。
:::

<ProofToggle>

::: proof
($\Rightarrow$) 若 $\varphi$ 单射，$\varphi(k) = e_H = \varphi(e_G)$ 推出 $k = e_G$。

($\Leftarrow$) 若 $\varphi(a) = \varphi(b)$，则 $\varphi(ab^{-1}) = \varphi(a)\varphi(b)^{-1} = e_H$，故 $ab^{-1} \in \ker \varphi = \{e_G\}$，即 $a = b$。
:::

</ProofToggle>

## 群同态基本定理

::: theorem 群同态基本定理（第一同构定理） {#thm-first-isomorphism}
设 $\varphi \colon G \to H$ 为群同态。则

$$G / \ker \varphi \cong \operatorname{im} \varphi$$

具体地，映射 $\overline{\varphi} \colon G/\ker \varphi \to \operatorname{im} \varphi$，$\overline{\varphi}(g \ker \varphi) = \varphi(g)$ 是良定义的群同构。
:::

<ProofToggle>

::: proof
记 $K = \ker \varphi$。

**良定义性**：设 $gK = g'K$，即 $g^{-1}g' \in K$。则 $\varphi(g^{-1}g') = e_H$，即 $\varphi(g)^{-1}\varphi(g') = e_H$，故 $\varphi(g) = \varphi(g')$。✓

**同态性**：$\overline{\varphi}(gK \cdot g'K) = \overline{\varphi}(gg'K) = \varphi(gg') = \varphi(g)\varphi(g') = \overline{\varphi}(gK) \cdot \overline{\varphi}(g'K)$。✓

**满射**：对 $h \in \operatorname{im} \varphi$，存在 $g \in G$ 使 $\varphi(g) = h$，故 $\overline{\varphi}(gK) = h$。✓

**单射**：若 $\overline{\varphi}(gK) = e_H$，则 $\varphi(g) = e_H$，$g \in K$，$gK = K$（$G/K$ 的单位元）。由 {lem:injective-criterion}（应用于 $\overline{\varphi}$），$\overline{\varphi}$ 单射。✓
:::

</ProofToggle>

::: intuition
这个定理是整个 Galois 理论的原型模式：**同态的像同构于定义域模去核**。在域论中，域同态总是单射（因为域没有非平凡理想），所以群同态基本定理将在 [环同态基本定理](/chapters/02-rings/) 中找到更精确的类比，而 Galois 对应本身就是将群论同态基本定理反复应用于域的自同构群。
:::

## 第二和第三同构定理

::: theorem 第二同构定理（钻石同构定理） {#thm-second-isomorphism}
设 $H \leq G$，$N \trianglelefteq G$。则 $HN = \{hn : h \in H, n \in N\} \leq G$，$H \cap N \trianglelefteq H$，且

$$H / (H \cap N) \cong HN / N$$
:::

<ProofToggle>

::: proof
**$HN \leq G$**：对 $h_1 n_1, h_2 n_2 \in HN$，$(h_1 n_1)(h_2 n_2)^{-1} = h_1 n_1 n_2^{-1} h_2^{-1}$。由 $N$ 正规，$h_2^{-1} N = N h_2^{-1}$，故 $n_1 n_2^{-1} h_2^{-1} = h_2^{-1} n'$ 对某 $n' \in N$。故原式 $= h_1 h_2^{-1} n' \in HN$。由 {lem:subgroup-criterion}(2)，$HN \leq G$。

**$H \cap N \trianglelefteq H$**：对 $h \in H$，$k \in H \cap N$，$hkh^{-1} \in H$（因 $h, k \in H$）且 $hkh^{-1} \in N$（因 $N \trianglelefteq G$）。故 $hkh^{-1} \in H \cap N$。

**同构**：定义 $\varphi \colon H \to HN/N$，$\varphi(h) = hN$。$\varphi$ 是同态（$\varphi(h_1 h_2) = h_1 h_2 N = (h_1 N)(h_2 N)$）。$\varphi$ 满射（$HN$ 中元素为 $hn$，$hnN = hN = \varphi(h)$）。$\ker \varphi = \{h \in H : hN = N\} = \{h \in H : h \in N\} = H \cap N$。由 {thm-first-isomorphism}，$H/(H \cap N) \cong HN/N$。
:::

</ProofToggle>

::: theorem 第三同构定理 {#thm-third-isomorphism}
设 $N \trianglelefteq G$，$K \trianglelefteq G$，$N \subseteq K$。则 $K/N \trianglelefteq G/N$，且

$$(G/N) / (K/N) \cong G/K$$
:::

<ProofToggle>

::: proof
定义 $\varphi \colon G/N \to G/K$，$\varphi(gN) = gK$。这是良定义的（$gN = g'N \Rightarrow g^{-1}g' \in N \subseteq K \Rightarrow gK = g'K$），是满同态，$\ker \varphi = \{gN : g \in K\} = K/N$。由 {thm-first-isomorphism}，$(G/N)/(K/N) \cong G/K$。
:::

</ProofToggle>

## 对应定理

::: theorem 子群对应定理 {#thm-correspondence}
设 $N \trianglelefteq G$，$\pi \colon G \to G/N$ 为自然投射。则映射

$$H \mapsto H/N$$

建立了 $\{H \leq G : N \subseteq H\}$ 与 $\{H' \leq G/N\}$ 之间的一一对应。此对应保持包含关系、正规性，且指数 $[G : H] = [G/N : H/N]$。
:::

<ProofToggle>

::: proof
$\pi$ 诱导的子群对应（子群的原像和像互为逆映射）是标准的集合论事实。保持包含关系由原像/像的单调性得到。保持正规性：$H \trianglelefteq G$ 当且仅当 $gHg^{-1} = H$ 对所有 $g$，这等价于 $(gN)(H/N)(gN)^{-1} = H/N$ 对所有 $gN$。指数：$[G:H]$ 是 $G$ 到 $H$ 的陪集数，等于 $G/N$ 到 $H/N$ 的陪集数 $[G/N : H/N]$。
:::

</ProofToggle>

::: remark
对应定理是 Galois 对应的直接原型。在 [§8 Galois 对应](/chapters/08-galois-correspondence/) 中，$G = \operatorname{Gal}(L/K)$，$N = \operatorname{Gal}(L/L)$ = $\{e\}$ 时，子群对应恰好给出中间域与子群之间的反序一一对应。更一般地，无穷 Galois 理论中的 Krull 拓扑 ({def-krull-topology}) 将这个对应推广到无穷 Galois 群。
:::

---

::: tip 本节要点
1. 群同态的核总是正规子群；单射等价于核平凡。
2. **群同态基本定理**：$G/\ker\varphi \cong \operatorname{im}\varphi$——这是同态理论的核心。
3. 第二同构定理：$H/(H \cap N) \cong HN/N$，描述子群和正规子群的"交与积"。
4. 第三同构定理：$(G/N)/(K/N) \cong G/K$，商群的商群仍是商群。
5. 子群对应定理：$G$ 中包含 $N$ 的子群与 $G/N$ 的子群一一对应——这是 Galois 对应的原型。
:::
