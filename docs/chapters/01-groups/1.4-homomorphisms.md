# 1.4 群同态基本定理

::: tip 学习目标
1. 理解群同态的定义和基本性质，认识同态如何"保持群结构"。
2. 掌握核（kernel）和像（image）的概念，理解"核是正规子群"和"单射判据"。
3. 掌握第一同构定理（群同态基本定理），能熟练应用于具体群的同态。
4. 了解第二、第三同构定理的陈述和应用场景。
5. 理解子群对应定理，认识它作为 Galois 对应原型的意义。
:::

## 为什么要研究同态？

::: info 动机
在 [§1.2](1.2-subgroups) 和 [§1.3](1.3-normal-subgroups) 中，我们研究了群的"内部结构"——子群、正规子群、商群。现在我们转向"群之间的关系"——同态。

**同态是"保持群运算的映射"。** 它们的重要性在于：
1. **比较群的结构**：两个群是否有"相同的结构"？通过同态（特别是同构），我们可以精确地回答这个问题。
2. **简化群**：同态的核告诉我们哪些元素被"压缩"到单位元——商群 $G/\ker\varphi$ 就是简化后的群。
3. **Galois 理论的基础**：域扩张的 Galois 群本身就是自同构的集合，而同态定理是分析这些群的基本工具。
:::

## 群同态

::: definition 群同态 {#def-group-homomorphism}
设 $(G, \cdot)$ 和 $(H, *)$ 为群。映射 $\varphi \colon G \to H$ 称为**群同态**，如果对所有 $a, b \in G$，

$$\varphi(ab) = \varphi(a) * \varphi(b)$$

若 $\varphi$ 还是双射，则称 $\varphi$ 为**群同构**，记为 $G \cong H$。
:::

::: remark
同态是保持群运算的映射。在范畴论语言中，群同态是群范畴 $\mathbf{Grp}$ 中的态射。同构是范畴等价——$G \cong H$ 意味着 $G$ 和 $H$ 作为群没有本质区别。
:::

::: example 同态的典型例子 {#ex-homomorphisms}

1. **符号同态** $\operatorname{sgn} \colon S_n \to \{1, -1\} \cong \mathbb{Z}/2\mathbb{Z}$。偶置换映到 $1$，奇置换映到 $-1$。验证：$\operatorname{sgn}(\sigma\tau) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\tau)$。$\ker(\operatorname{sgn}) = A_n$（交错群）。由第一同构定理，$S_n/A_n \cong \mathbb{Z}/2\mathbb{Z}$。

2. **行列式** $\det \colon GL_n(\mathbb{R}) \to \mathbb{R}^*$。$\det(AB) = \det(A)\det(B)$。$\ker(\det) = SL_n(\mathbb{R})$（特殊线性群）。由第一同构定理，$GL_n(\mathbb{R})/SL_n(\mathbb{R}) \cong \mathbb{R}^*$。

3. **幂同态** $\varphi \colon \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$，$k \mapsto \overline{k}$。这是自然投射，$\ker\varphi = n\mathbb{Z}$。由第一同构定理，$\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}/n\mathbb{Z}$（平凡但重要！）。更一般地，$\mathbb{Z}$ 的每个商群都同构于某个 $\mathbb{Z}/n\mathbb{Z}$ 或 $\mathbb{Z}$ 本身。

4. **交换化映射** $ab \colon G \to G/[G,G]$，$g \mapsto g[G,G]$。$[G,G]$ 是 $G$ 的换位子群。$G/[G,G]$ 是 $G$ 的最大交换商群（abelianization）。$S_n$ 的换位子群 $[S_n, S_n] = A_n$（$n \geq 5$），所以 $S_n^{\text{ab}} \cong \mathbb{Z}/2\mathbb{Z}$。

5. **嵌入** $\iota \colon H \hookrightarrow G$（$H \leq G$）。包含映射总是单同态，$\ker\iota = \{e\}$。

6. **平凡同态** $\varphi \colon G \to H$，$\varphi(g) = e_H$ 对所有 $g$。$\ker\varphi = G$，$\operatorname{im}\varphi = \{e_H\}$。
:::

## 同态的基本性质

::: lemma 同态的基本性质 {#lem-hom-properties}
设 $\varphi \colon G \to H$ 为群同态。则：

1. $\varphi(e_G) = e_H$。
2. $\varphi(a^{-1}) = \varphi(a)^{-1}$。
3. 若 $a \in G$ 的阶为 $n < \infty$，则 $|\varphi(a)|$ 整除 $n$。
4. 若 $K \leq G$，则 $\varphi(K) \leq H$。
5. 若 $L \leq H$，则 $\varphi^{-1}(L) \leq G$。
:::

<ProofToggle>

::: proof
**(1)** $\varphi(e_G) = \varphi(e_G \cdot e_G) = \varphi(e_G) * \varphi(e_G)$。由 {lem:cancellation}（$H$ 中的消去律），$\varphi(e_G) = e_H$。

**(2)** $\varphi(a) * \varphi(a^{-1}) = \varphi(aa^{-1}) = \varphi(e_G) = e_H$。由 {lem:inverse-unique}，$\varphi(a^{-1}) = \varphi(a)^{-1}$。

**(3)** $\varphi(a)^n = \varphi(a^n) = \varphi(e_G) = e_H$。由 {lem:order-properties}(1)，$|\varphi(a)| \mid n$。

**(4)** 对 $\varphi(a), \varphi(b) \in \varphi(K)$，$\varphi(a)\varphi(b)^{-1} = \varphi(ab^{-1}) \in \varphi(K)$（因 $ab^{-1} \in K$）。由 {lem:subgroup-criterion}(2)，$\varphi(K) \leq H$。

**(5)** 对 $a, b \in \varphi^{-1}(L)$，$\varphi(ab^{-1}) = \varphi(a)\varphi(b)^{-1} \in L$（因 $\varphi(a), \varphi(b) \in L$）。故 $ab^{-1} \in \varphi^{-1}(L)$。
:::

</ProofToggle>

::: warning 误区："同态是满射"
**不一定！** 同态不一定满射。例如包含映射 $\iota \colon \mathbb{Z} \hookrightarrow \mathbb{Q}$（加法群）是同态但不是满射。$\operatorname{im}\iota = \mathbb{Z} \subsetneq \mathbb{Q}$。

满同态（epimorphism）是满射的同态。只有满同态的第一同构定理形式才是 $G/\ker\varphi \cong H$（而不是 $\cong \operatorname{im}\varphi$）。
:::

::: remark 性质 (3) 的精确化
注意 {lem-hom-properties}(3) 说 $|\varphi(a)|$ **整除** $|a|$，而不是等于。例如 $\varphi \colon \mathbb{Z}/6\mathbb{Z} \to \mathbb{Z}/3\mathbb{Z}$，$\varphi(\overline{k}) = \overline{k}$。$\overline{2} \in \mathbb{Z}/6\mathbb{Z}$ 的阶是 3，但 $\varphi(\overline{2}) = \overline{2} \in \mathbb{Z}/3\mathbb{Z}$ 的阶也是 3（整除关系中恰好相等）。$\overline{3} \in \mathbb{Z}/6\mathbb{Z}$ 的阶是 2，但 $\varphi(\overline{3}) = \overline{0}$ 的阶是 1（严格整除）。
:::

## 核与像

::: definition 核与像 {#def-kernel-image}
设 $\varphi \colon G \to H$ 为群同态。

1. $\varphi$ 的**核** $\ker \varphi = \{g \in G : \varphi(g) = e_H\}$。
2. $\varphi$ 的**像** $\operatorname{im} \varphi = \varphi(G) = \{\varphi(g) : g \in G\}$。
:::

::: example 核与像的计算 {#ex-kernel-image}

1. $\operatorname{sgn} \colon S_n \to \{\pm 1\}$：$\ker(\operatorname{sgn}) = A_n$，$\operatorname{im}(\operatorname{sgn}) = \{\pm 1\}$（$n \geq 2$）。

2. $\det \colon GL_2(\mathbb{R}) \to \mathbb{R}^*$：$\ker(\det) = SL_2(\mathbb{R})$，$\operatorname{im}(\det) = \mathbb{R}^*$（$\det$ 是满射）。

3. $\varphi \colon \mathbb{Z} \to \mathbb{Z}/5\mathbb{Z}$，$n \mapsto \overline{n}$：$\ker\varphi = 5\mathbb{Z}$，$\operatorname{im}\varphi = \mathbb{Z}/5\mathbb{Z}$（满射）。

4. $\varphi \colon S_3 \to S_3$，$\sigma \mapsto (1\,2\,3)\sigma(1\,2\,3)^{-1}$（共轭作用）。这是一个自同构（内自同构）。$\ker\varphi = \{e\}$，$\operatorname{im}\varphi = S_3$。

5. $\varphi \colon \mathbb{Z} \to \mathbb{Z}$，$n \mapsto 2n$。$\ker\varphi = \{0\}$，$\operatorname{im}\varphi = 2\mathbb{Z}$（不是满射——$1 \notin 2\mathbb{Z}$）。
:::

::: proposition 核是正规子群 {#prop-kernel-normal}
设 $\varphi \colon G \to H$ 为群同态。则 $\ker \varphi \trianglelefteq G$。
:::

<ProofToggle>

::: proof
由 {lem:hom-properties}(5)，$\ker \varphi = \varphi^{-1}(\{e_H\}) \leq G$。

正规性：对 $k \in \ker \varphi$，$g \in G$，

$$\varphi(gkg^{-1}) = \varphi(g)\varphi(k)\varphi(g)^{-1} = \varphi(g) \cdot e_H \cdot \varphi(g)^{-1} = e_H$$

故 $gkg^{-1} \in \ker \varphi$。由 {lem:normal-criteria}(2)，$\ker \varphi \trianglelefteq G$。
:::

</ProofToggle>

::: info 核是正规子群——这意味着什么？
这个结论比表面看起来更有力量：**它给了我们构造正规子群的系统方法**。

反过来，[§1.3](1.3-normal-subgroups) 告诉我们每个正规子群 $N \trianglelefteq G$ 都是某个同态的核——自然投射 $\pi \colon G \to G/N$ 的核就是 $N$。

因此：**正规子群 = 同态的核**。这是群论中一个深刻的基本对应。
:::

::: lemma 单射判据 {#lem-injective-criterion}
群同态 $\varphi \colon G \to H$ 是单射当且仅当 $\ker \varphi = \{e_G\}$。
:::

<ProofToggle>

::: proof
($\Rightarrow$) 若 $\varphi$ 单射，$\varphi(k) = e_H = \varphi(e_G)$ 推出 $k = e_G$。

($\Leftarrow$) 若 $\varphi(a) = \varphi(b)$，则 $\varphi(ab^{-1}) = \varphi(a)\varphi(b)^{-1} = e_H$，故 $ab^{-1} \in \ker \varphi = \{e_G\}$，即 $a = b$。
:::

</ProofToggle>

::: remark 单射判据的实用价值
单射判据是验证同态是否为单射的最方便方法：只需计算核。例如，要验证包含映射 $\iota \colon H \hookrightarrow G$ 是单射，只需观察 $\ker\iota = \{e\}$（显然）。

在 [域论](/chapters/03-fields/) 中，域同态 $\varphi \colon K \to L$ 总是单射，因为 $\ker\varphi$ 是 $K$ 的理想，而域的理想只有 $(0)$ 和 $K$ 本身（如果 $\varphi \neq 0$，则 $\ker\varphi = (0)$）。
:::

## 群同态基本定理

::: theorem 群同态基本定理（第一同构定理） {#thm-first-isomorphism}
设 $\varphi \colon G \to H$ 为群同态。则

$$G / \ker \varphi \cong \operatorname{im} \varphi$$

具体地，映射 $\overline{\varphi} \colon G/\ker \varphi \to \operatorname{im} \varphi$，$\overline{\varphi}(g \ker \varphi) = \varphi(g)$ 是良定义的群同构。
:::

<ProofToggle>

::: proof
记 $K = \ker \varphi$。

**良定义性**：设 $gK = g'K$，即 $g^{-1}g' \in K$。则 $\varphi(g^{-1}g') = e_H$，即 $\varphi(g)^{-1}\varphi(g') = e_H$，故 $\varphi(g) = \varphi(g')$。✓

**同态性**：$\overline{\varphi}(gK \cdot g'K) = \overline{\varphi}(gg'K) = \varphi(gg') = \varphi(g)\varphi(g') = \overline{\varphi}(gK) \cdot \overline{\varphi}(g'K)$。✓

**满射**：对 $h \in \operatorname{im} \varphi$，存在 $g \in G$ 使 $\varphi(g) = h$，故 $\overline{\varphi}(gK) = h$。✓

**单射**：若 $\overline{\varphi}(gK) = e_H$，则 $\varphi(g) = e_H$，$g \in K$，$gK = K$（$G/K$ 的单位元）。由 {lem:injective-criterion}（应用于 $\overline{\varphi}$），$\overline{\varphi}$ 单射。✓
:::

</ProofToggle>

::: example 应用第一同构定理 {#ex-first-iso-applications}

**例 1.** $\operatorname{sgn} \colon S_n \to \{\pm 1\}$。$\ker(\operatorname{sgn}) = A_n$。由第一同构定理，$S_n/A_n \cong \{\pm 1\} \cong \mathbb{Z}/2\mathbb{Z}$。所以 $[S_n : A_n] = 2$，$|A_n| = n!/2$。

**例 2.** $\varphi \colon \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$。$\ker\varphi = n\mathbb{Z}$。由第一同构定理，$\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}/n\mathbb{Z}$（验证了自然投射的正确性）。更深刻的应用：$\mathbb{Z}$ 的**每个**商群都同构于某个 $\mathbb{Z}/n\mathbb{Z}$（$n \geq 0$）。

**例 3.** 计算 $(\mathbb{Z}/12\mathbb{Z})^*$（模 12 的单位群）。$\varphi \colon \mathbb{Z}/12\mathbb{Z} \to \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$（通过 CRT）。$\ker\varphi = \{\overline{0}\}$。$(\mathbb{Z}/12\mathbb{Z})^* \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$（Klein 四元群）。这不是第一同构定理的直接应用，但展示了同态如何简化群的结构分析。

**例 4.** 设 $\varphi \colon \mathbb{Z}/6\mathbb{Z} \to S_3$，$\varphi(\overline{1}) = (1\,2\,3)$。则 $\varphi(\overline{k}) = (1\,2\,3)^k$。$\operatorname{im}\varphi = \langle (1\,2\,3) \rangle \cong \mathbb{Z}/3\mathbb{Z}$，$\ker\varphi = \{\overline{0}, \overline{3}\} = 2\mathbb{Z}/6\mathbb{Z} \cong \mathbb{Z}/2\mathbb{Z}$。由第一同构定理，$(\mathbb{Z}/6\mathbb{Z})/(2\mathbb{Z}/6\mathbb{Z}) \cong \mathbb{Z}/3\mathbb{Z}$。
:::

::: intuition 这个定理为什么重要？
这个定理是整个 Galois 理论的原型模式：**同态的像同构于定义域模去核**。

具体地：
- 每当我们有一个"信息损失"的映射 $\varphi: G \to H$，核 $\ker\varphi$ 精确地度量了损失了多少信息。
- 商群 $G/\ker\varphi$ "压缩掉"被 $\varphi$ 破坏的结构，剩余部分和 $\operatorname{im}\varphi$ 完全相同。

在域论中，域同态总是单射（因为域没有非平凡理想），所以群同态基本定理将在 [环同态基本定理](/chapters/02-rings/) 中找到更精确的类比，而 Galois 对应本身就是将群论同态基本定理反复应用于域的自同构群。
:::

## 第二和第三同构定理

::: theorem 第二同构定理（钻石同构定理） {#thm-second-isomorphism}
设 $H \leq G$，$N \trianglelefteq G$。则 $HN = \{hn : h \in H, n \in N\} \leq G$，$H \cap N \trianglelefteq H$，且

$$H / (H \cap N) \cong HN / N$$
:::

<ProofToggle>

::: proof
**$HN \leq G$**：对 $h_1 n_1, h_2 n_2 \in HN$，$(h_1 n_1)(h_2 n_2)^{-1} = h_1 n_1 n_2^{-1} h_2^{-1}$。由 $N$ 正规，$h_2^{-1} N = N h_2^{-1}$，故 $n_1 n_2^{-1} h_2^{-1} = h_2^{-1} n'$ 对某 $n' \in N$。故原式 $= h_1 h_2^{-1} n' \in HN$。由 {lem:subgroup-criterion}(2)，$HN \leq G$。

**$H \cap N \trianglelefteq H$**：对 $h \in H$，$k \in H \cap N$，$hkh^{-1} \in H$（因 $h, k \in H$）且 $hkh^{-1} \in N$（因 $N \trianglelefteq G$）。故 $hkh^{-1} \in H \cap N$。

**同构**：定义 $\varphi \colon H \to HN/N$，$\varphi(h) = hN$。$\varphi$ 是同态（$\varphi(h_1 h_2) = h_1 h_2 N = (h_1 N)(h_2 N)$）。$\varphi$ 满射（$HN$ 中元素为 $hn$，$hnN = hN = \varphi(h)$）。$\ker \varphi = \{h \in H : hN = N\} = \{h \in H : h \in N\} = H \cap N$。由 {thm-first-isomorphism}，$H/(H \cap N) \cong HN/N$。
:::

</ProofToggle>

::: example 第二同构定理的应用 {#ex-second-iso}

在 $S_4$ 中，设 $H = \langle (1\,2\,3\,4) \rangle \cong \mathbb{Z}/4\mathbb{Z}$，$N = V_4 = \{e, (1\,2)(3\,4), (1\,3)(2\,4), (1\,4)(2\,3)\}$（Klein 四元群，$N \trianglelefteq S_4$）。

- $H \cap N = \{e, (1\,3)(2\,4)\} = \langle (1\,3)(2\,4) \rangle \cong \mathbb{Z}/2\mathbb{Z}$。
- $HN$ 有 $|H||N|/|H \cap N| = 4 \cdot 4/2 = 8$ 个元素，$HN \cong D_4$（二面体群）。
- 由第二同构定理，$H/(H \cap N) \cong HN/N$。$H/(H \cap N) \cong \mathbb{Z}/4\mathbb{Z}/(\mathbb{Z}/2\mathbb{Z}) \cong \mathbb{Z}/2\mathbb{Z}$。
- 所以 $HN/N \cong \mathbb{Z}/2\mathbb{Z}$，$|HN/N| = 2$。
:::

::: theorem 第三同构定理 {#thm-third-isomorphism}
设 $N \trianglelefteq G$，$K \trianglelefteq G$，$N \subseteq K$。则 $K/N \trianglelefteq G/N$，且

$$(G/N) / (K/N) \cong G/K$$
:::

<ProofToggle>

::: proof
定义 $\varphi \colon G/N \to G/K$，$\varphi(gN) = gK$。这是良定义的（$gN = g'N \Rightarrow g^{-1}g' \in N \subseteq K \Rightarrow gK = g'K$），是满同态，$\ker \varphi = \{gN : g \in K\} = K/N$。由 {thm-first-isomorphism}，$(G/N)/(K/N) \cong G/K$。
:::

</ProofToggle>

::: info 第三同构定理的直觉
第三同构定理说：**商群的商群还是商群**。如果你先"压缩"掉 $N$，再"压缩"掉 $K/N$（其中 $N \subseteq K$），最终效果等价于一步压缩掉 $K$。

这个定理在 Galois 理论中的应用：如果 $K \subseteq L \subseteq M$ 是域扩张塔，$\operatorname{Gal}(M/L) \trianglelefteq \operatorname{Gal}(M/K)$，则 $\operatorname{Gal}(L/K) \cong \operatorname{Gal}(M/K)/\operatorname{Gal}(M/L)$。
:::

::: example 第三同构定理的应用 {#ex-third-iso}

设 $G = \mathbb{Z}$，$N = 12\mathbb{Z}$，$K = 4\mathbb{Z}$。则 $N \subseteq K$，$K/N = 4\mathbb{Z}/12\mathbb{Z} \cong \mathbb{Z}/3\mathbb{Z}$。

由第三同构定理：$(\mathbb{Z}/12\mathbb{Z})/(4\mathbb{Z}/12\mathbb{Z}) \cong \mathbb{Z}/4\mathbb{Z}$。

验证：$\mathbb{Z}/12\mathbb{Z} = \{0, 1, \ldots, 11\}$，$4\mathbb{Z}/12\mathbb{Z} = \{0, 4, 8\}$。商群有 4 个陪集：$\{0, 4, 8\}, \{1, 5, 9\}, \{2, 6, 10\}, \{3, 7, 11\}$，确实同构于 $\mathbb{Z}/4\mathbb{Z}$。
:::

## 对应定理

::: theorem 子群对应定理 {#thm-correspondence}
设 $N \trianglelefteq G$，$\pi \colon G \to G/N$ 为自然投射。则映射

$$H \mapsto H/N$$

建立了 $\{H \leq G : N \subseteq H\}$ 与 $\{H' \leq G/N\}$ 之间的一一对应。此对应保持包含关系、正规性，且指数 $[G : H] = [G/N : H/N]$。
:::

<ProofToggle>

::: proof
$\pi$ 诱导的子群对应（子群的原像和像互为逆映射）是标准的集合论事实。保持包含关系由原像/像的单调性得到。保持正规性：$H \trianglelefteq G$ 当且仅当 $gHg^{-1} = H$ 对所有 $g$，这等价于 $(gN)(H/N)(gN)^{-1} = H/N$ 对所有 $gN$。指数：$[G:H]$ 是 $G$ 到 $H$ 的陪集数，等于 $G/N$ 到 $H/N$ 的陪集数 $[G/N : H/N]$。
:::

</ProofToggle>

::: example 对应定理的具体应用 {#ex-correspondence}

**例 1.** $G = S_4$，$N = V_4$（Klein 四元群）。$S_4/V_4 \cong S_3$（$|S_4|/|V_4| = 24/4 = 6 = |S_3|$）。$S_4$ 中包含 $V_4$ 的子群对应 $S_3$ 的子群。$S_3$ 有 6 个子群（$\{e\}$，三个 2 阶子群，一个 3 阶子群，$S_3$ 自身），所以 $S_4$ 有 6 个包含 $V_4$ 的子群。

**例 2.** $G = \mathbb{Z}$，$N = 6\mathbb{Z}$。$\mathbb{Z}/6\mathbb{Z}$ 的子群：$\{\overline{0}\}$，$\langle \overline{2} \rangle = \{0, 2, 4\}$，$\langle \overline{3} \rangle = \{0, 3\}$，$\mathbb{Z}/6\mathbb{Z}$。对应 $\mathbb{Z}$ 中包含 $6\mathbb{Z}$ 的子群：$6\mathbb{Z}$，$2\mathbb{Z}$，$3\mathbb{Z}$，$\mathbb{Z}$。

**例 3.** 在 Galois 理论中：设 $L/K$ 是 Galois 扩张，$N = \operatorname{Gal}(L/L) = \{e\}$。则对应定理给出了 $\operatorname{Gal}(L/K)$ 的**所有**子群与 $L/K$ 的**所有**中间域之间的一一对应。这就是 [§8 Galois 对应](/chapters/08-galois-correspondence/) 的核心内容。
:::

::: remark
对应定理是 Galois 对应的直接原型。在 [§8 Galois 对应](/chapters/08-galois-correspondence/) 中，$G = \operatorname{Gal}(L/K)$，$N = \operatorname{Gal}(L/L)$ = $\{e\}$ 时，子群对应恰好给出中间域与子群之间的反序一一对应。更一般地，无穷 Galois 理论中的 Krull 拓扑 ({def-krull-topology}) 将这个对应推广到无穷 Galois 群。
:::

## 常见误区 {#misconceptions}

::: warning 误区一："同态基本定理要求 $\varphi$ 满射"
**不需要！** 第一同构定理对**任何**同态都成立。如果 $\varphi$ 不满射，定理给出 $G/\ker\varphi \cong \operatorname{im}\varphi$（而不是 $\cong H$）。只有当 $\varphi$ 是满同态时，才有 $G/\ker\varphi \cong H$。
:::

::: warning 误区二："$HN$ 是直积"
**不一定！** $HN = \{hn : h \in H, n \in N\}$ 不一定同构于 $H \times N$。$HN \cong H \times N$ 当且仅当 $H \cap N = \{e\}$ 且 $H, N$ 都是正规的。一般情况下 $|HN| = |H||N|/|H \cap N|$。
:::

::: warning 误区三："第三同构定理中 $N$ 必须是 $K$ 的正规子群"
$N$ 是 $G$ 的正规子群（$N \trianglelefteq G$），$K$ 也是 $G$ 的正规子群（$K \trianglelefteq G$），并且 $N \subseteq K$。条件是关于 $G$ 的正规性，不是关于 $K$ 的。但由 $N \trianglelefteq G$ 可以推出 $N \trianglelefteq K$。
:::

::: warning 误区四："对应定理说 $G$ 的所有子群与 $G/N$ 的所有子群一一对应"
**不对！** 只有 $G$ 中**包含 $N$** 的子群才与 $G/N$ 的子群一一对应。不包含 $N$ 的子群不出现在对应中。

例如 $G = S_3$，$N = A_3$。$S_3$ 中包含 $A_3$ 的子群只有 $A_3$ 和 $S_3$ 自身。$S_3/A_3 \cong \mathbb{Z}/2\mathbb{Z}$ 只有两个子群（$\{\overline{0}\}$ 和 $\mathbb{Z}/2\mathbb{Z}$），一一对应。但 $S_3$ 的其他子群（三个 2 阶子群 $\langle (1\,2) \rangle$ 等）不包含 $A_3$，不出现在对应中。
:::

## 自测问题 {#self-test}

::: question 自测
1. **核的计算**：计算以下同态的核和像：
   - (a) $\varphi \colon \mathbb{Z}/8\mathbb{Z} \to \mathbb{Z}/4\mathbb{Z}$，$\varphi(\overline{n}) = \overline{n}$
   - (b) $\varphi \colon S_4 \to S_3$（通过 $S_4/V_4 \cong S_3$ 的复合）
   - (c) $\varphi \colon D_4 \to \mathbb{Z}/2\mathbb{Z}$，$\varphi(r^i s^j) = \overline{j}$（$r$ 为旋转，$s$ 为反射）

2. **第一同构定理的应用**：设 $\varphi \colon G \to H$ 是满同态，$|G| = 60$，$|H| = 12$。$\ker\varphi$ 的阶是多少？$G/\ker\varphi$ 同构于什么？

3. **第二同构定理**：在 $S_3$ 中，设 $H = \langle (1\,2) \rangle$，$N = A_3$。$H \cap N$ 是什么？$HN$ 是什么？$H/(H \cap N) \cong HN/N$ 同构于什么？

4. **概念辨析**：为什么域同态总是单射？用核和理想的语言解释。
:::

::: details 答案
1. (a) $\ker\varphi = \{\overline{0}, \overline{4}\} = \langle \overline{4} \rangle \cong \mathbb{Z}/2\mathbb{Z}$，$\operatorname{im}\varphi = \mathbb{Z}/4\mathbb{Z}$（满射）。验证：$(\mathbb{Z}/8\mathbb{Z})/\langle \overline{4} \rangle \cong \mathbb{Z}/4\mathbb{Z}$。(b) $\ker = V_4$，$\operatorname{im} = S_3$。(c) $\ker = \langle r \rangle \cong \mathbb{Z}/4\mathbb{Z}$，$\operatorname{im} = \mathbb{Z}/2\mathbb{Z}$。

2. $|\ker\varphi| = |G|/|H| = 60/12 = 5$。$G/\ker\varphi \cong H$（由第一同构定理，因为 $\varphi$ 满射）。

3. $H \cap N = \{e\}$（$H = \{e, (1\,2)\}$，$A_3 = \{e, (1\,2\,3), (1\,3\,2)\}$，只有 $e$ 在两个集合中）。$HN = S_3$（$|HN| = 2 \cdot 3/1 = 6$）。$H/\{e\} \cong H \cong \mathbb{Z}/2\mathbb{Z}$，$HN/N = S_3/A_3 \cong \mathbb{Z}/2\mathbb{Z}$。✓

4. 域同态 $\varphi \colon K \to L$ 的核 $\ker\varphi$ 是 $K$ 的理想（因为 $\varphi$ 是环同态）。但域 $K$ 的理想只有 $(0)$ 和 $K$ 本身。如果 $\varphi \neq 0$（即 $\varphi(1) = 1 \neq 0$），则 $\ker\varphi = (0)$，$\varphi$ 单射。
:::
