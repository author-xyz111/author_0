# §7.2 Galois 群的计算 {#sec-computing-galois-groups}

::: tip 📖 学习目标
完成本节后，你应该能够：
1. 使用判别式法判定不可约三次多项式的 Galois 群（$S_3$ 或 $A_3$）
2. 运用 Dedekind 定理（模 $p$ 约化）从多项式的分解型推断 Galois 群中包含的置换类型
3. 对不可约四次多项式，综合判别式和三次预解式确定 Galois 群（$S_4$、$A_4$、$D_4$ 或 $V_4$）
4. 通过不动域和子群格结构辅助判断 Galois 群
5. 理解为什么计算 Galois 群是一个"逐步缩小可能性"的过程
:::

::: intuition 计算策略
计算 Galois 群的核心策略是**逐步缩小可能性**：
1. 利用 $|\operatorname{Gal}| \leq [L:K]$ 确定阶的上界。
2. 利用 Galois 群嵌入 $S_n$ 确定候选群。
3. 利用判别式、模 $p$ 约化、不动域等工具进一步排除。
:::

::: warning 计算 Galois 群 ≠ 列出所有自同构
初学者常犯的错误是试图"直接构造"所有 $K$-自同构。对于高次多项式，这几乎不可能——正确的方法是**间接推断**：通过判别式、约化、预解式等工具逐步缩小候选群，最终确定 Galois 群的抽象同构类型。
:::

## 判别式法 {#discriminant}

::: definition 判别式 {#def-discriminant}
设 $f(x) = a_n x^n + \cdots + a_0 \in K[x]$ 有根 $\alpha_1, \ldots, \alpha_n$（在分裂域中）。$f$ 的**判别式**（discriminant）定义为
$$
\Delta(f) = a_n^{2n-2} \prod_{1 \leq i < j \leq n} (\alpha_i - \alpha_j)^2.
$$
判别式可以表为 $f$ 的系数的多项式（通过结式或 Newton 恒等式）。
:::

::: intuition 判别式的含义
判别式衡量的是多项式的根之间的"分离程度"：
- $\Delta \neq 0$：所有根互不相同（可分多项式）。
- $\Delta > 0$（对实系数多项式）：实根的"分散程度"。
- $\Delta = 0$：至少有两个根重合。

对 Galois 理论而言，关键在于 $\Delta$ 是否为 $K$ 中的**平方元**——这决定了 Galois 群是否包含在交错群 $A_n$ 中。
:::

::: proposition 判别式与 Galois 群 {#prop-discriminant-galois}
设 $f \in K[x]$ 是不可约 $n$ 次多项式，$\operatorname{char} K \neq 2$。则：

**(i)** $\Delta(f) \in K$（判别式是 $K$ 的元素）。

**(ii)** $\Delta(f)$ 在 $K$ 中是平方元当且仅当 $\operatorname{Gal}(f/K) \subseteq A_n$（交错群）。
:::

<ProofToggle>

**证明.**

**(i)** 对 $\sigma \in \operatorname{Gal}(L/K)$（$L$ 是分裂域），$\sigma$ 置换根 $\alpha_1, \ldots, \alpha_n$。设 $\delta = \prod_{i<j}(\alpha_i - \alpha_j)$，则 $\sigma(\delta) = \pm \delta$（取决于 $\sigma$ 的置换是偶置换还是奇置换）。故 $\delta^2 = \Delta(f)$ 被所有 $\sigma$ 固定，$\Delta(f) \in K$。

**(ii)** $\sigma(\delta) = \operatorname{sgn}(\sigma) \cdot \delta$。若 $\Delta(f) = d^2$ 对某 $d \in K$，则 $\delta = \pm d$，$\sigma(\delta) = \delta$（因为 $d \in K$ 被 $\sigma$ 固定），故 $\operatorname{sgn}(\sigma) = 1$ 对所有 $\sigma$，即 $\operatorname{Gal} \subseteq A_n$。

反之若 $\operatorname{Gal} \subseteq A_n$，则 $\delta$ 被所有 $\sigma \in \operatorname{Gal}$ 固定，故 $\delta \in K$（由 Galois 对应，§8.2），$\Delta(f) = \delta^2$ 是 $K$ 中的平方元。$\blacksquare$

</ProofToggle>

### 具体计算：二次和三次的判别式

::: remark 常用判别式公式
- **二次** $f(x) = ax^2 + bx + c$：$\Delta = b^2 - 4ac$。
- **三次** $f(x) = x^3 + px + q$（缺项形式）：$\Delta = -4p^3 - 27q^2$。
- **一般三次** $f(x) = ax^3 + bx^2 + cx + d$：$\Delta = b^2c^2 - 4ac^3 - 4b^3d - 27a^2d^2 + 18abcd$。

对二次，$\Delta$ 是平方元 $\iff$ $f$ 在 $K$ 中有根 $\iff$ $\operatorname{Gal}$ 平凡。对三次，$\Delta$ 是平方元 $\iff$ $\operatorname{Gal} \subseteq A_3$（但不可约 $\Rightarrow$ $\operatorname{Gal}$ 平凡或 $A_3$ 或 $S_3$，$A_3$ 是唯一既非平凡又 $\subseteq A_3$ 的可能）。
:::

::: example 三次多项式的 Galois 群 {#ex-cubic-galois}
设 $f(x) \in \mathbb{Q}[x]$ 是不可约三次多项式。$\operatorname{Gal}(f/\mathbb{Q})$ 只有两种可能：$S_3$（阶 6）或 $A_3 \cong \mathbb{Z}/3\mathbb{Z}$（阶 3）。

判别式决定是哪一个：
- 若 $\Delta(f)$ 不是 $\mathbb{Q}$ 中的平方元，则 $\operatorname{Gal} \cong S_3$。
- 若 $\Delta(f)$ 是 $\mathbb{Q}$ 中的平方元，则 $\operatorname{Gal} \cong A_3$。

**具体例子：** $f(x) = x^3 - 3x + 1$。判别式 $\Delta = -4(-3)^3 - 27(1)^2 = 108 - 27 = 81 = 9^2$。$\Delta$ 是平方元，故 $\operatorname{Gal} \cong A_3 \cong \mathbb{Z}/3\mathbb{Z}$。

**对比：** $g(x) = x^3 - 2$。$\Delta = -27 \cdot 4 = -108$。$-108$ 不是 $\mathbb{Q}$ 中的平方元，故 $\operatorname{Gal} \cong S_3$。
:::

::: warning $\Delta$ 是平方元不意味着 $\Delta > 0$
"$\Delta$ 是 $\mathbb{Q}$ 中的平方元"意味着 $\Delta = r^2$ 对某个 $r \in \mathbb{Q}$。由于 $r^2 \geq 0$，这确实要求 $\Delta \geq 0$。但反之不成立：$\Delta > 0$ 不保证 $\Delta$ 是有理数的平方（例如 $\Delta = 2$）。必须检查 $\sqrt{\Delta} \in \mathbb{Q}$。
:::

## 模 $p$ 约化法（Dedekind 定理） {#mod-p-reduction}

::: theorem Dedekind {#thm-dedekind}
设 $f(x) \in \mathbb{Z}[x]$ 是首一多项式，$p$ 是素数且 $p \nmid \operatorname{disc}(f)$。设 $\bar{f}$ 是 $f$ 在 $\mathbb{F}_p[x]$ 中的约化，且 $\bar{f}$ 在 $\mathbb{F}_p[x]$ 中分解为不可约因子：
$$
\bar{f} = \bar{g}_1 \cdots \bar{g}_r,
$$
其中 $\deg \bar{g}_i = d_i$。则 $\operatorname{Gal}(f/\mathbb{Q})$ 包含一个置换 $\sigma$，其循环类型为 $(d_1, \ldots, d_r)$。
:::

<ProofToggle>

**证明.** 设 $\mathfrak{p}$ 是 $\mathbb{Z}[\alpha]$ 中在 $p$ 之上的素理想（$\alpha$ 是 $f$ 的根）。Frob 自同构 $\operatorname{Frob}_{\mathfrak{p}} \in \operatorname{Gal}(f/\mathbb{Q})$（在 $p \nmid \operatorname{disc}$ 条件下，$\mathfrak{p}$ 不分歧），其在根上的作用恰好对应于 $\bar{f}$ 的因子 $\bar{g}_i$ 给出的循环 $(d_1, \ldots, d_r)$。

更初等地：设 $\alpha_1, \ldots, \alpha_n$ 是 $f$ 在 $\overline{\mathbb{Q}}$ 中的根，$\sigma \in \operatorname{Gal}(f/\mathbb{Q})$ 的循环类型 $(d_1, \ldots, d_r)$ 对应于 $\sigma$ 分解为不相交循环之积时各循环的长度。设 $\mathfrak{p}$ 为 $\mathbb{Z}[\alpha_1, \ldots, \alpha_n]$ 中 $p$ 之上的素理想。约化 $\bmod\, \mathfrak{p}$ 给出 $\mathbb{F}_p$ 上的 Frobenius 元素，其循环类型由 $\bar{f}$ 的分解型给出。$\blacksquare$

</ProofToggle>

::: intuition Dedekind 定理的含义
Dedekind 定理说的是：**多项式模 $p$ 的分解型反映了 Galois 群中置换的循环结构**。例如：
- 若 $\bar{f}$ 在 $\mathbb{F}_p$ 中完全分解为线性因子（循环型 $(1,1,\ldots,1)$），则 $\operatorname{Gal}$ 包含恒等置换——这总是成立的。
- 若 $\bar{f}$ 在 $\mathbb{F}_p$ 中不可约（循环型 $(n)$），则 $\operatorname{Gal}$ 包含一个 $n$-循环。
- 若 $\bar{f}$ 分解为一个二次和一个线性因子（循环型 $(2,1)$），则 $\operatorname{Gal}$包含一个对换。

通过在多个素数 $p$ 上约化，我们可以积累关于 $\operatorname{Gal}$ 中包含哪些置换类型的信息，从而缩小候选群。
:::

### 完整工作示例

::: example 用 Dedekind 定理计算 $\operatorname{Gal}(x^3 - 2/\mathbb{Q})$ {#ex-dedekind-cubic}
$f(x) = x^3 - 2 \in \mathbb{Z}[x]$。$\operatorname{disc}(f) = -108 = -2^2 \cdot 3^3$。

**$p = 5$：** $\bar{f} = x^3 - 2 \in \mathbb{F}_5[x]$。检验：$0^3 = 0$，$1^3 = 1$，$2^3 = 8 \equiv 3$，$3^3 = 27 \equiv 2$ ✓。故 $x = 3$ 是根，$\bar{f} = (x - 3)(x^2 + 3x + 4) \in \mathbb{F}_5[x]$。$x^2 + 3x + 4$ 在 $\mathbb{F}_5$ 中无根（检验 $0,1,2,3,4$），故不可约。分解型：$(1, 2)$。Dedekind 定理 $\Rightarrow$ $\operatorname{Gal}$ 包含一个循环型为 $(1,2)$ 的置换，即一个**对换**。

**$p = 7$：** $\bar{f} = x^3 - 2 \in \mathbb{F}_7[x]$。检验：$3^3 = 27 \equiv 6$，$5^3 = 125 \equiv 6$... 实际上 $0^3=0, 1^3=1, 2^3=8\equiv 1, 3^3=27\equiv 6, 4^3=64\equiv 1, 5^3=125\equiv 6, 6^3=216\equiv 6$。$x^3 \equiv 2$ 在 $\mathbb{F}_7$ 中无解。故 $\bar{f}$ 在 $\mathbb{F}_7$ 中不可约。分解型：$(3)$。Dedekind 定理 $\Rightarrow$ $\operatorname{Gal}$ 包含一个 **3-循环**。

**结论：** $\operatorname{Gal}(f/\mathbb{Q})$ 包含一个对换和一个 3-循环。$S_3$ 由对换和 3-循环生成，故 $\operatorname{Gal} = S_3$。✓（与判别式法一致：$\Delta = -108$ 不是平方元。）
:::

::: example 用 Dedekind 定理计算 $\operatorname{Gal}(x^4 + 1/\mathbb{Q})$ {#ex-dedekind-quartic}
$f(x) = x^4 + 1 \in \mathbb{Z}[x]$。这是第 8 个分圆多项式 $\Phi_8(x)$，根为 $\zeta_8^k$（$k = 1, 3, 5, 7$），其中 $\zeta_8 = e^{2\pi i/8}$。$[L:\mathbb{Q}] = 4$，故 $\operatorname{Gal} \leq S_4$ 且 $|\operatorname{Gal}| = 4$。

$S_4$ 中阶为 4 的子群有两类：$\mathbb{Z}/4\mathbb{Z}$ 和 $V_4$。判别式 $\Delta = 256 = 16^2$ 是平方元，故 $\operatorname{Gal} \subseteq A_4$。$A_4$ 中阶为 4 的子群只有 $V_4$。故 $\operatorname{Gal} \cong V_4$。

**用 Dedekind 验证：** $p = 3$：$x^4 + 1 = x^4 - 2 \equiv (x^2 + x + 2)(x^2 + 2x + 2) \pmod{3}$（两个不可约二次因子）。循环型 $(2,2)$——这正是 $V_4$ 中的非平凡元素 $(12)(34)$ 的类型。✓
:::

::: remark Chebotarev 密度定理
Dedekind 定理的推广是 **Chebotarev 密度定理**：$\operatorname{Gal}(f/\mathbb{Q})$ 的每个共轭类 $C$，满足 $p$ 的 Frobenius 元在 $C$ 中的素数 $p$ 的集合具有 Dirichlet 密度 $|C|/|\operatorname{Gal}|$。这给出了 Galois 群的**统计刻画**，是代数数论的深刻结果。

直觉上：如果 $\operatorname{Gal} = S_4$（阶 24），那么"约化后得到 4-循环"的素数的密度是 $6/24 = 1/4$（因为 $S_4$ 中有 6 个 4-循环）。
:::

## 不动域法 {#fixed-field-method}

::: proposition Galois 群与不动域 {#prop-galois-fixed-field}
设 $L/K$ 是有限 Galois 扩张，$H \leq \operatorname{Gal}(L/K)$。定义 $H$ 的**不动域**：
$$
L^H = \{a \in L : \sigma(a) = a \text{ 对所有 } \sigma \in H\}.
$$
则 $[L : L^H] = |H|$（这需要 Galois 对应定理，见 [§8.1](/chapters/08-galois-correspondence/)）。
:::

::: example 用不动域判断 Galois 群 {#ex-fixed-field}
$f(x) = x^4 - 2 \in \mathbb{Q}[x]$，分裂域 $L = \mathbb{Q}(\sqrt[4]{2}, i)$。已知 $\operatorname{Gal}(L/\mathbb{Q}) \cong D_4$。

$D_4$ 的子群格包括：$\{e\}, \langle\sigma^2\rangle, \langle\tau\rangle, \langle\sigma\tau\rangle, \langle\sigma^2, \tau\rangle, \langle\sigma\rangle, D_4$ 等。

每个子群 $H$ 对应一个中间域 $L^H$：
- $L^{D_4} = \mathbb{Q}$（不动域就是基域）
- $L^{\langle\sigma\rangle} = \mathbb{Q}(i)$（旋转群的不动域）
- $L^{\langle\tau\rangle} = \mathbb{Q}(\sqrt[4]{2})$（反射的不动域）
- $L^{\langle\sigma^2\rangle} = \mathbb{Q}(\sqrt{2}, i)$（180°旋转的不动域）

这展示了 Galois 对应（第八章的核心内容）。完整的中间域分类需要第八章的工具，但即使在现阶段，我们也可以用"固定哪些元素"来直觉理解 Galois 群的结构。
:::

## 三次和四次方程的 Galois 群完整分类 {#classification-cubic-quartic}

### 三次情形 {#cubic}

::: theorem 不可约三次多项式的 Galois 群 {#thm-cubic-galois}
设 $f \in K[x]$ 是不可约三次多项式（$\operatorname{char} K \neq 2, 3$）。则：
$$
\operatorname{Gal}(f/K) \cong \begin{cases} A_3 \cong \mathbb{Z}/3\mathbb{Z} & \text{若 } \Delta(f) \text{ 是 } K \text{ 中的平方元} \\ S_3 & \text{否则} \end{cases}
$$
:::

::: warning $A_3$ 的 Galois 群意味着什么
若 $\operatorname{Gal} \cong A_3$，则 $|\operatorname{Gal}| = 3 = [L:K]$，故分裂域 $L$ 就是 $K(\alpha)$（单扩张）——$f$ 的**一个根**已经生成了整个分裂域！这意味着 $f$ 的所有根都可以用 $K(\alpha)$ 中的元素表示。

这在计算上的意义是：不需要显式地添加 $\omega = e^{2\pi i/3}$ 之类的辅助元素。
:::

### 四次情形 {#quartic}

::: theorem 不可约四次多项式的 Galois 群 {#thm-quartic-galois}
设 $f(x) = x^4 + ax^2 + bx + c \in K[x]$（$\operatorname{char} K \neq 2, 3$）不可约，$\alpha_1, \alpha_2, \alpha_3, \alpha_4$ 为其根。设：
- $\Delta = \operatorname{disc}(f)$（判别式）
- $r = \alpha_1\alpha_2 + \alpha_3\alpha_4$，$s = \alpha_1\alpha_3 + \alpha_2\alpha_4$，$t = \alpha_1\alpha_4 + \alpha_2\alpha_3$
- $g(x) = (x - r)(x - s)(x - t)$（**三次预解式**，resolvent cubic）

则 $\operatorname{Gal}(f/K)$ 完全由以下数据确定：

| $\Delta$ | $g$ 在 $K$ 上 | $\operatorname{Gal}(f/K)$ | 阶 |
|:---:|:---:|:---:|:---:|
| 非平方 | 不可约 | $S_4$ | 24 |
| 非平方 | 有根在 $K$ 中 | $D_4$ | 8 |
| 平方 | 不可约 | $A_4$ | 12 |
| 平方 | 有根在 $K$ 中 | $V_4$ | 4 |
:::

::: intuition 三次预解式的直觉
三次预解式的三个根 $r, s, t$ 对应于将四个根 $\alpha_i$ 分成两对的三种方式。Galois 群作用在 $\{r, s, t\}$ 上：$S_4$ 传递地作用，$A_4$ 也传递，$D_4$ 固定一个（对应于"相邻配对"），$V_4$ 固定全部三个。
:::

::: example 完整计算：$f(x) = x^4 - 2$ {#ex-quartic-full}
**第一步：判别式。** $\Delta(x^4 - 2) = -27 \cdot (-2)^4 \cdot 4^4 = -27 \cdot 16 \cdot 256 = -110592$。这不是 $\mathbb{Q}$ 中的平方元（负数），故 $\operatorname{Gal} \not\subseteq A_4$。候选：$S_4$ 或 $D_4$。

**第二步：三次预解式。** $f(x) = x^4 - 2$（$a = 0, b = 0, c = -2$）。$g(x) = x^3 + 8x = x(x^2 + 8)$。$g$ 在 $\mathbb{Q}$ 中有根 $x = 0$。

**第三步：查表。** $\Delta$ 非平方，$g$ 有根在 $\mathbb{Q}$ 中 $\Rightarrow$ $\operatorname{Gal} \cong D_4$（阶 8）。

**验证：** 由 [§7.1 例子 {ex-galois-x4-2}](7.1-definition-and-examples#ex-galois-x4-2)，已知 $\operatorname{Gal}(\mathbb{Q}(\sqrt[4]{2}, i)/\mathbb{Q}) \cong D_4$。✓
:::

::: warning 预解式法的适用范围
三次预解式法只适用于**首一四次**多项式。对于非首一多项式，需要先归一化。此外，判别式和预解式的计算可能很繁琐——实际中常用计算机代数系统（如 SageMath、PARI/GP）辅助。
:::

## 用 Galois 群分类域扩张 {#classifying-extensions}

::: theorem 正规扩张的 Galois 群结构 {#thm-normal-galois}
设 $L/K$ 是有限正规扩张。则 $\operatorname{Gal}(L/K)$ 的结构反映了 $L$ 的内部结构：

**(i)** 若 $L = L_1 \otimes_K L_2$（线性不交的张量积），则 $\operatorname{Gal}(L/K) \cong \operatorname{Gal}(L_1/K) \times \operatorname{Gal}(L_2/K)$。

**(ii)** 若 $L/K$ 有子扩张链 $K = K_0 \subset K_1 \subset \cdots \subset K_r = L$，则 $\operatorname{Gal}(L/K)$ 有对应的正规子群链。
:::

<ProofToggle>

**证明.**

**(i)** 若 $L_1$ 和 $L_2$ 在 $K$ 上线性不交（即 $L_1 \cap L_2 = K$ 且 $[L_1L_2 : K] = [L_1 : K][L_2 : K]$），则每个 $\sigma_1 \in \operatorname{Gal}(L_1/K)$ 和 $\sigma_2 \in \operatorname{Gal}(L_2/K)$ 唯一地确定一个 $\sigma \in \operatorname{Gal}(L/K)$ 满足 $\sigma|_{L_1} = \sigma_1$，$\sigma|_{L_2} = \sigma_2$。这给出同构 $\operatorname{Gal}(L/K) \cong \operatorname{Gal}(L_1/K) \times \operatorname{Gal}(L_2/K)$。

**(ii)** 是 Galois 对应的直接推论，详见 [§8.1](/chapters/08-galois-correspondence/)。$\blacksquare$

</ProofToggle>

::: example $\mathbb{Q}(\sqrt{2}, \sqrt{3}, \sqrt{5})/\mathbb{Q}$ 的 Galois 群 {#ex-triple-sqrt}
$L_1 = \mathbb{Q}(\sqrt{2})$，$L_2 = \mathbb{Q}(\sqrt{3})$，$L_3 = \mathbb{Q}(\sqrt{5})$。每对交为 $\mathbb{Q}$，故
$$
\operatorname{Gal}(\mathbb{Q}(\sqrt{2}, \sqrt{3}, \sqrt{5})/\mathbb{Q}) \cong (\mathbb{Z}/2\mathbb{Z})^3 = V_4 \times \mathbb{Z}/2\mathbb{Z},
$$
阶为 8。一般地，$\operatorname{Gal}(\mathbb{Q}(\sqrt{p_1}, \ldots, \sqrt{p_r})/\mathbb{Q}) \cong (\mathbb{Z}/2\mathbb{Z})^r$（$p_i$ 为不同的素数）。
:::

## 策略总结：计算 Galois 群的流程图 {#strategy-summary}

::: remark 实用计算策略
对于 $\mathbb{Q}$ 上的不可约 $n$ 次多项式 $f$：

**$n = 2$：** $\operatorname{Gal} \cong \mathbb{Z}/2\mathbb{Z}$（总是）。

**$n = 3$：** 计算 $\Delta$。
- $\Delta = r^2 \in \mathbb{Q}^2$ $\Rightarrow$ $A_3 \cong \mathbb{Z}/3\mathbb{Z}$
- 否则 $\Rightarrow$ $S_3$

**$n = 4$：** 计算 $\Delta$ 和三次预解式 $g$。查四行表。

**$n = 5$：** $S_5$ 有 5 个传递子群。需要更多工具（判别式、预解式、模 $p$ 约化、不动域）的组合。

**一般 $n$：** 这是一个活跃的研究领域。对于 $n \geq 5$，没有简单的分类表，需要使用群论和代数数论的深层工具。
:::

## 常见误区 {#misconceptions}

::: warning 误区一：Dedekind 定理给出的是必要条件，不是充分条件
Dedekind 定理说：若 $f$ 模 $p$ 分解为不相交循环 $(d_1)(d_2)\cdots$ 的乘积，则 $\operatorname{Gal}$ 包含一个循环类型为 $(d_1, d_2, \ldots)$ 的置换。但**不能反过来说**：$\operatorname{Gal}$ 中的每个置换类型都能通过某个模 $p$ 约化检测到。

实际上，对于大多数多项式，"大多数"素数 $p$ 给出的分解型只覆盖 $\operatorname{Gal}$ 的一部分共轭类。Chebotarev 密度定理（[§10.2](/chapters/10-finite-fields/10.2-frobenius)）精确量化了这一点：每个共轭类被 $(\text{其大小}/|\operatorname{Gal}|) \cdot 100\%$ 的素数检测到。
:::

::: warning 误区二：判别式为完全平方 ⟹ $f$ 可约
判别式 $\Delta$ 是完全平方元只说明 $\operatorname{Gal} \subseteq A_n$，与 $f$ 是否可约**完全无关**。例如：
- $f = x^3 - 3x + 1$：$\Delta = 81 = 9^2$，故 $\operatorname{Gal} \cong A_3 \cong \mathbb{Z}/3\mathbb{Z}$，但 $f$ 在 $\mathbb{Q}$ 上**不可约**。
- $f = (x-1)(x-2)(x-3)$：$\Delta = 4$（平方元），但 $f$ 显然可约。

判别式法的正确用法是：**先验证不可约性**（用 Eisenstein 或其他判据），**然后**用判别式缩小 Galois 群的候选范围。
:::

::: warning 误区三：$n = 4$ 时只看判别式就够了
四次多项式的情况比三次复杂得多。判别式只能区分 $\operatorname{Gal} \subseteq A_4$ 还是 $\operatorname{Gal} \not\subseteq A_4$，但 $A_4$ 有两个传递子群（$A_4$ 本身和 $V_4$），$S_4 \setminus A_4$ 也有两个（$S_4$ 本身和 $D_4$）。必须**同时计算三次预解式**才能最终确定。
:::

## 本节小结 {#summary}

| 方法 | 适用范围 | 能判断什么 |
|:---|:---|:---|
| 判别式法 | 不可约 $n$ 次（$\operatorname{char} \neq 2$） | $\operatorname{Gal} \subseteq A_n$？ |
| Dedekind 定理 | $\mathbb{Z}[x]$ 中首一多项式 | $\operatorname{Gal}$ 中包含哪些循环类型 |
| 三次预解式 | 不可约四次 | 区分 $S_4, A_4, D_4, V_4$ |
| 不动域法 | 已知 Galois 群结构 | 中间域 ↔ 子群的对应 |

**核心思想：** 计算 Galois 群不是直接列出所有自同构，而是通过**间接工具**（判别式、约化、预解式）逐步缩小候选群。

## 自测题 {#self-test}

1. **[基础]** 计算以下多项式在 $\mathbb{Q}$ 上的 Galois 群：
   - (a) $x^2 - 5$
   - (b) $x^3 - 3x + 1$（提示：$\Delta = 81$）
   - (c) $x^3 + x + 1$（提示：$\Delta = -31$）

2. **[计算]** 用 Dedekind 定理（模 $p = 2, 3, 5$）确定 $f(x) = x^3 + x^2 - 2x - 1$ 的 Galois 群。（提示：$f$ 在 $\mathbb{F}_2$ 中不可约，在 $\mathbb{F}_3$ 中分解为 $(x-1)(x^2+2x+2)$。）

3. **[综合]** 设 $f(x) = x^4 + x + 1 \in \mathbb{Q}[x]$（不可约，由模 2 约化验证）。计算 $\Delta(f)$ 和三次预解式 $g(x)$，确定 $\operatorname{Gal}(f/\mathbb{Q})$。

4. **[理解]** 为什么 Dedekind 定理需要 $p \nmid \operatorname{disc}(f)$ 这个条件？如果 $p \mid \operatorname{disc}(f)$ 会发生什么？（提示：考虑 $f(x) = x^3 - 2$ 和 $p = 2$ 或 $p = 3$。）

5. **[深入]** 设 $f(x) = x^5 - 4x + 2 \in \mathbb{Q}[x]$（不可约，由 Eisenstein 判据）。证明 $\operatorname{Gal}(f/\mathbb{Q}) \cong S_5$。（提示：先用 Dedekind 定理找到一个 5-循环和一个对换。）
