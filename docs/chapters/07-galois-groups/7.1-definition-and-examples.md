# §7.1 Galois 群的定义与基本性质 {#sec-galois-group-definition}

::: intuition 核心直觉
Galois 群是域扩张 $L/K$ 上保持 $K$ 中元素不动的**自同构群**。它编码了 $L$ 相对于 $K$ 的**内在对称性**：$L$ 的元素可以在不"破坏"域结构、不移动 $K$ 的前提下互相交换的那些方式。

当我们有一个多项式 $f \in K[x]$ 和它的分裂域 $L$ 时，$\operatorname{Gal}(L/K)$ 的每个元素会将 $f$ 的根进行置换——而且这些置换受到代数关系的严格约束。Galois 的天才洞察就是：**多项式的根的代数关系恰好由群的结构来编码**。
:::

---

## 自同构群 {#automorphism-group}

::: definition 域自同构 {#def-field-automorphism}
设 $L$ 为域。$L$ 的一个**自同构**（automorphism）是双射域同态 $\sigma: L \to L$。$L$ 的全体自同构在复合运算下构成一个群 $\operatorname{Aut}(L)$。
:::

::: definition $K$-自同构 {#def-k-automorphism}
设 $L/K$ 为域扩张。一个**$K$-自同构**是满足 $\sigma|_K = \operatorname{id}_K$ 的自同构 $\sigma \in \operatorname{Aut}(L)$，即对所有 $a \in K$，$\sigma(a) = a$。

$L$ 上所有 $K$-自同构构成 $\operatorname{Aut}(L)$ 的子群，记作 $\operatorname{Aut}(L/K)$。
:::

::: definition Galois 群 {#def-galois-group}
设 $L/K$ 为域扩张。$L$ 在 $K$ 上的 **Galois 群**（Galois group）定义为
$$
\operatorname{Gal}(L/K) := \operatorname{Aut}(L/K) = \{\sigma \in \operatorname{Aut}(L) : \sigma|_K = \operatorname{id}_K\}.
$$
对于 $f \in K[x]$，定义 $f$ 在 $K$ 上的 Galois 群为 $\operatorname{Gal}(f/K) := \operatorname{Gal}(L/K)$，其中 $L$ 是 $f$ 在 $K$ 上的分裂域。
:::

::: remark Galois 群的良定义性
由于分裂域在 $K$-同构意义下唯一（{thm-splitting-field-unique}），$\operatorname{Gal}(f/K)$ 在同构意义下不依赖于分裂域 $L$ 的具体选择。然而，当我们在不同分裂域之间更换时，Galois 群只是**共轭**的，因此我们通常固定一个分裂域。
:::

## Galois 群的基本性质 {#basic-properties}

::: proposition Galois 群作用在根上 {#prop-galois-permutes-roots}
设 $L/K$ 是 $f \in K[x]$ 的分裂域，$\alpha \in L$ 是 $f$ 的根。则对任意 $\sigma \in \operatorname{Gal}(L/K)$，$\sigma(\alpha)$ 也是 $f$ 的根。

因此 Galois 群忠实地作用在 $f$ 的根的集合上：
$$
\operatorname{Gal}(L/K) \hookrightarrow \operatorname{Sym}(\operatorname{Roots}(f, L)).
$$
:::

<ProofToggle>

**证明.** 设 $f(x) = a_n x^n + \cdots + a_0$，$f(\alpha) = 0$。对 $f(\alpha) = \sum a_i \alpha^i = 0$ 两边施加 $\sigma$：
$$
\sigma\Bigl(\sum a_i \alpha^i\Bigr) = \sum \sigma(a_i) \sigma(\alpha)^i = \sum a_i \sigma(\alpha)^i = f(\sigma(\alpha)) = 0,
$$
其中 $\sigma(a_i) = a_i$ 因为 $a_i \in K$ 且 $\sigma \in \operatorname{Gal}(L/K)$。故 $\sigma(\alpha)$ 是 $f$ 的根。

映射 $\sigma \mapsto \sigma|_{\operatorname{Roots}(f,L)}$ 给出了群同态 $\operatorname{Gal}(L/K) \to \operatorname{Sym}(\operatorname{Roots}(f,L))$。由于 $L = K(\alpha_1, \ldots, \alpha_n)$（其中 $\alpha_i$ 跑遍 $f$ 的根），$\sigma$ 由它在根上的作用唯一确定，故此同态是单射。$\blacksquare$

</ProofToggle>

::: proposition Galois 群的阶 {#prop-galois-group-order}
设 $L/K$ 是有限扩张。则 $|\operatorname{Gal}(L/K)| \leq [L : K]$，等号成立当且仅当 $L/K$ 是 Galois 扩张（将在 §8.2 精确定义）。
:::

<ProofToggle>

**证明.** 设 $[L : K] = n$，选取 $K$-基 $\{e_1, \ldots, e_n\}$。每个 $\sigma \in \operatorname{Gal}(L/K)$ 是 $K$-线性映射，由 $\sigma(e_1), \ldots, \sigma(e_n)$ 完全决定。然而，并非每个 $K$-基的选择都能扩展为域自同构——代数约束（如 $e_i e_j = \sum c_{ij}^k e_k$）限制了可能性。

更精确地，固定本原元 $\alpha$（若存在），则 $L = K(\alpha)$，$\sigma$ 由 $\sigma(\alpha)$ 完全决定。$\sigma(\alpha)$ 必须是 $\alpha$ 的极小多项式的根，最多 $n$ 个选择。故 $|\operatorname{Gal}(L/K)| \leq n$。

等号成立的条件将在 §8.2（Galois 扩张）中完整刻画。$\blacksquare$

</ProofToggle>

## 具体计算 {#computations}

::: example $\operatorname{Gal}(\mathbb{C}/\mathbb{R})$ {#ex-galois-c-r}
$\mathbb{C} = \mathbb{R}(i)$，$i$ 的极小多项式为 $x^2 + 1$，根为 $\pm i$。因此 $\operatorname{Gal}(\mathbb{C}/\mathbb{R})$ 的每个元素由 $i$ 的像确定，而 $i$ 只能映射到 $i$ 或 $-i$。

- $\operatorname{id}: i \mapsto i$（恒等）
- $\sigma: i \mapsto -i$（复共轭）

故 $\operatorname{Gal}(\mathbb{C}/\mathbb{R}) \cong \mathbb{Z}/2\mathbb{Z}$。
:::

::: example $\operatorname{Gal}(\mathbb{Q}(\sqrt{2})/\mathbb{Q})$ {#ex-galois-q-sqrt2}
$\sqrt{2}$ 的极小多项式为 $x^2 - 2$，根为 $\pm\sqrt{2}$。故 $\operatorname{Gal}(\mathbb{Q}(\sqrt{2})/\mathbb{Q}) = \{\operatorname{id}, \sigma\}$，其中 $\sigma(\sqrt{2}) = -\sqrt{2}$，$\operatorname{Gal} \cong \mathbb{Z}/2\mathbb{Z}$。
:::

::: example $\operatorname{Gal}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q})$ {#ex-galois-q-cbrt2}
$\sqrt[3]{2}$ 的极小多项式为 $x^3 - 2$，其三个根为 $\sqrt[3]{2}$，$\omega\sqrt[3]{2}$，$\omega^2\sqrt[3]{2}$，其中 $\omega = e^{2\pi i/3}$。

但 $\mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$，而 $\omega\sqrt[3]{2} \notin \mathbb{R}$。因此 $\sqrt[3]{2}$ 不能映射到 $\omega\sqrt[3]{2}$（像不在域内）。唯一的 $K$-自同构是恒等映射。

$$\operatorname{Gal}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}) = \{\operatorname{id}\}.$$

这说明 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ **不是 Galois 扩张**——域扩张太"小"，无法容纳多项式的全部根的对称性。
:::

::: example $\operatorname{Gal}(f/\mathbb{Q})$ 其中 $f = x^4 - 2$ {#ex-galois-x4-2}
$f$ 的分裂域为 $L = \mathbb{Q}(\sqrt[4]{2}, i)$，$[L : \mathbb{Q}] = 8$。

$f$ 的四个根为 $\alpha, -\alpha, i\alpha, -i\alpha$（其中 $\alpha = \sqrt[4]{2}$）。每个 $\sigma \in \operatorname{Gal}(L/\mathbb{Q})$ 由 $\sigma(\alpha)$ 和 $\sigma(i)$ 完全决定。

约束条件：
- $\sigma(\alpha)$ 必须是 $x^4 - 2$ 的根，故 $\sigma(\alpha) \in \{\alpha, -\alpha, i\alpha, -i\alpha\}$（4 个选择）。
- $\sigma(i)$ 必须是 $x^2 + 1$ 的根，故 $\sigma(i) \in \{i, -i\}$（2 个选择）。
- 但并不是 $4 \times 2 = 8$ 种组合都给出自同构——需要验证它们是否兼容域运算。

可以验证全部 $8$ 种组合都给出自同构，故 $|\operatorname{Gal}(L/\mathbb{Q})| = 8 = [L : \mathbb{Q}]$，这是 Galois 扩张。

$\operatorname{Gal}(L/\mathbb{Q})$ 同构于**二面体群** $D_4$（正方形的对称群），生成元为：
$$\sigma: \alpha \mapsto i\alpha,\; i \mapsto i \quad \text{（旋转）}$$
$$\tau: \alpha \mapsto \alpha,\; i \mapsto -i \quad \text{（反射）}$$

验证：$\sigma^4 = \operatorname{id}$，$\tau^2 = \operatorname{id}$，$\tau\sigma\tau^{-1} = \sigma^{-1}$。这正是 $D_4 = \langle \sigma, \tau \mid \sigma^4 = \tau^2 = \operatorname{id},\, \tau\sigma\tau = \sigma^{-1} \rangle$ 的展示。
:::

## Galois 群作为置换群 {#galois-as-permutation}

::: theorem Galois 群嵌入对称群 {#thm-galois-embeds-symmetric}
设 $f \in K[x]$ 是不可约 $n$ 次多项式，$L$ 是 $f$ 在 $K$ 上的分裂域。则
$$
\operatorname{Gal}(L/K) \hookrightarrow S_n,
$$
即 Galois 群可以视为 $n$ 个根的置换群。且 $\operatorname{Gal}(L/K)$ 在根上是**传递的**。
:::

<ProofToggle>

**证明.** 由 {prop-galois-permutes-roots}，$\operatorname{Gal}(L/K)$ 忠实地作用在 $f$ 的 $n$ 个根上，故 $\operatorname{Gal}(L/K) \hookrightarrow S_n$。

**传递性：** 设 $\alpha, \beta$ 是 $f$ 的任意两个根。由于 $f$ 不可约，$K(\alpha) \cong K[x]/(f) \cong K(\beta)$（由 {thm-algebraic-simple-extension}）。这个 $K$-同构 $\tau: K(\alpha) \xrightarrow{\sim} K(\beta)$ 满足 $\tau(\alpha) = \beta$。

由嵌入扩张引理（{lem-embedding-extension}），$\tau$ 可以扩张为 $L$ 上的 $K$-自同构 $\tilde{\tau} \in \operatorname{Gal}(L/K)$，满足 $\tilde{\tau}(\alpha) = \beta$。故 Galois 群在根上是传递的。$\blacksquare$

</ProofToggle>

::: remark 可迁子群的分类
$S_n$ 的可迁子群的分类是群论中的一个重要问题。对于 $n \leq 5$，已知完整的分类。这直接对应于不可约多项式的 Galois 群的可能类型。特别地：
- $n = 2$：$\operatorname{Gal} \cong S_2 \cong \mathbb{Z}/2\mathbb{Z}$（唯一的可迁子群）。
- $n = 3$：$\operatorname{Gal} \cong S_3$ 或 $\operatorname{Gal} \cong A_3 \cong \mathbb{Z}/3\mathbb{Z}$。
- $n = 4$：$\operatorname{Gal}$ 可以是 $S_4$、$A_4$、$D_4$、$\mathbb{Z}/4\mathbb{Z}$ 或 $\operatorname{Klein}$ 四元群 $V_4$。
- $n = 5$：$\operatorname{Gal}$ 可以是 $S_5$、$A_5$、$F_{20}$（Frobenius 群）、$D_5$ 或 $\mathbb{Z}/5\mathbb{Z}$。
:::

## Galois 群的函子性 {#functoriality}

::: proposition 限制与提升 {#prop-restriction}
设 $K \subseteq L \subseteq M$ 为域扩张。

**(i)** 存在**限制同态**：
$$
\operatorname{Gal}(M/K) \twoheadrightarrow \operatorname{Gal}(L/K), \quad \sigma \mapsto \sigma|_L,
$$
当 $L/K$ 是 Galois 扩张时（即 $L$ 在 $K$ 上的 Galois 群恰好等于限制的像）。

**(ii)** 存在**包含同态**：
$$
\operatorname{Gal}(M/K) \hookrightarrow \operatorname{Gal}(M/L), \quad \sigma \mapsto \sigma,
$$
其中 $M/L$ 的 Galois 群是 $M$ 上固定 $L$ 的自同构。
:::

<ProofToggle>

**证明.**

**(i)** 对 $\sigma \in \operatorname{Gal}(M/K)$，$\sigma|_L$ 固定 $K$ 中的元素（因为 $\sigma$ 固定 $K$），且 $\sigma(L) \subseteq L$（当 $L/K$ 是正规扩张时）。因此 $\sigma|_L \in \operatorname{Gal}(L/K)$。

映射 $\sigma \mapsto \sigma|_L$ 显然是群同态。当 $L/K$ 是 Galois 扩张时，它是满射——这需要额外论证，将在 §8.2 中完成。

**(ii)** 注意 $\operatorname{Gal}(M/L) = \{\sigma \in \operatorname{Aut}(M) : \sigma|_L = \operatorname{id}_L\}$，而 $\operatorname{Gal}(M/K) = \{\sigma \in \operatorname{Aut}(M) : \sigma|_K = \operatorname{id}_K\}$。由于 $K \subseteq L$，若 $\sigma|_L = \operatorname{id}_L$ 则自动 $\sigma|_K = \operatorname{id}_K$。因此 $\operatorname{Gal}(M/L) \subseteq \operatorname{Gal}(M/K)$ 作为集合，包含映射是群同态。$\blacksquare$

</ProofToggle>
