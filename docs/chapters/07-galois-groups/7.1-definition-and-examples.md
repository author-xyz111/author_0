# §7.1 Galois 群的定义与基本性质 {#sec-galois-group-definition}

::: tip 📖 学习目标
完成本节后，你应该能够：
1. 给出 $\operatorname{Gal}(L/K)$ 的严格定义，并解释它为什么是域扩张的"对称群"
2. 证明 Galois 群忠实地作用在多项式的根上，且作用是传递的（对不可约多项式）
3. 计算至少五类基本例子的 Galois 群：$\mathbb{C}/\mathbb{R}$、$\mathbb{Q}(\sqrt{d})/\mathbb{Q}$、$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$、分圆域、$\mathbb{Q}(\sqrt[4]{2}, i)/\mathbb{Q}$
4. 解释 $|\operatorname{Gal}(L/K)| \leq [L:K]$ 以及等号成立的条件
5. 理解限制同态和包含同态的函子性
:::

::: intuition 核心直觉
Galois 群是域扩张 $L/K$ 上保持 $K$ 中元素不动的**自同构群**。它编码了 $L$ 相对于 $K$ 的**内在对称性**：$L$ 的元素可以在不"破坏"域结构、不移动 $K$ 的前提下互相交换的那些方式。

当我们有一个多项式 $f \in K[x]$ 和它的分裂域 $L$ 时，$\operatorname{Gal}(L/K)$ 的每个元素会将 $f$ 的根进行置换——而且这些置换受到代数关系的严格约束。Galois 的天才洞察就是：**多项式的根的代数关系恰好由群的结构来编码**。
:::

---

## 自同构群 {#automorphism-group}

::: definition 域自同构 {#def-field-automorphism}
设 $L$ 为域。$L$ 的一个**自同构**（automorphism）是双射域同态 $\sigma: L \to L$。$L$ 的全体自同构在复合运算下构成一个群 $\operatorname{Aut}(L)$。
:::

::: definition $K$-自同构 {#def-k-automorphism}
设 $L/K$ 为域扩张。一个**$K$-自同构**是满足 $\sigma|_K = \operatorname{id}_K$ 的自同构 $\sigma \in \operatorname{Aut}(L)$，即对所有 $a \in K$，$\sigma(a) = a$。

$L$ 上所有 $K$-自同构构成 $\operatorname{Aut}(L)$ 的子群，记作 $\operatorname{Aut}(L/K)$。
:::

::: definition Galois 群 {#def-galois-group}
设 $L/K$ 为域扩张。$L$ 在 $K$ 上的 **Galois 群**（Galois group）定义为
$$
\operatorname{Gal}(L/K) := \operatorname{Aut}(L/K) = \{\sigma \in \operatorname{Aut}(L) : \sigma|_K = \operatorname{id}_K\}.
$$
对于 $f \in K[x]$，定义 $f$ 在 $K$ 上的 Galois 群为 $\operatorname{Gal}(f/K) := \operatorname{Gal}(L/K)$，其中 $L$ 是 $f$ 在 $K$ 上的分裂域。
:::

::: remark Galois 群的良定义性
由于分裂域在 $K$-同构意义下唯一（{thm-splitting-field-unique}），$\operatorname{Gal}(f/K)$ 在同构意义下不依赖于分裂域 $L$ 的具体选择。然而，当我们在不同分裂域之间更换时，Galois 群只是**共轭**的，因此我们通常固定一个分裂域。
:::

## Galois 群的基本性质 {#basic-properties}

::: proposition Galois 群作用在根上 {#prop-galois-permutes-roots}
设 $L/K$ 是 $f \in K[x]$ 的分裂域，$\alpha \in L$ 是 $f$ 的根。则对任意 $\sigma \in \operatorname{Gal}(L/K)$，$\sigma(\alpha)$ 也是 $f$ 的根。

因此 Galois 群忠实地作用在 $f$ 的根的集合上：
$$
\operatorname{Gal}(L/K) \hookrightarrow \operatorname{Sym}(\operatorname{Roots}(f, L)).
$$
:::

<ProofToggle>

**证明.** 设 $f(x) = a_n x^n + \cdots + a_0$，$f(\alpha) = 0$。对 $f(\alpha) = \sum a_i \alpha^i = 0$ 两边施加 $\sigma$：
$$
\sigma\Bigl(\sum a_i \alpha^i\Bigr) = \sum \sigma(a_i) \sigma(\alpha)^i = \sum a_i \sigma(\alpha)^i = f(\sigma(\alpha)) = 0,
$$
其中 $\sigma(a_i) = a_i$ 因为 $a_i \in K$ 且 $\sigma \in \operatorname{Gal}(L/K)$。故 $\sigma(\alpha)$ 是 $f$ 的根。

映射 $\sigma \mapsto \sigma|_{\operatorname{Roots}(f,L)}$ 给出了群同态 $\operatorname{Gal}(L/K) \to \operatorname{Sym}(\operatorname{Roots}(f,L))$。由于 $L = K(\alpha_1, \ldots, \alpha_n)$（其中 $\alpha_i$ 跑遍 $f$ 的根），$\sigma$ 由它在根上的作用唯一确定，故此同态是单射。$\blacksquare$

</ProofToggle>

::: warning 嵌入对称群 ≠ Galois 群就等于某个置换群
$\operatorname{Gal}(L/K) \hookrightarrow S_n$ 只说明 Galois 群**可以视为**$S_n$ 的子群。它不一定是整个 $S_n$。例如 $\operatorname{Gal}(\mathbb{Q}(\sqrt{2})/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z}$ 虽然嵌入 $S_2$，但 $\operatorname{Gal}(\mathbb{Q}(\sqrt[3]{2}, \omega)/\mathbb{Q}) \cong S_3$ 才等于 $S_3$。关键在于 $f$ 的根之间有没有**额外的代数关系**（如 $\omega^3 = 1$）限制了对称性。
:::

::: proposition Galois 群的阶 {#prop-galois-group-order}
设 $L/K$ 是有限扩张。则 $|\operatorname{Gal}(L/K)| \leq [L : K]$，等号成立当且仅当 $L/K$ 是 Galois 扩张（将在 §8.2 精确定义）。
:::

<ProofToggle>

**证明.** 设 $[L : K] = n$，选取 $K$-基 $\{e_1, \ldots, e_n\}$。每个 $\sigma \in \operatorname{Gal}(L/K)$ 是 $K$-线性映射，由 $\sigma(e_1), \ldots, \sigma(e_n)$ 完全决定。然而，并非每个 $K$-基的选择都能扩展为域自同构——代数约束（如 $e_i e_j = \sum c_{ij}^k e_k$）限制了可能性。

更精确地，固定本原元 $\alpha$（若存在），则 $L = K(\alpha)$，$\sigma$ 由 $\sigma(\alpha)$ 完全决定。$\sigma(\alpha)$ 必须是 $\alpha$ 的极小多项式的根，最多 $n$ 个选择。故 $|\operatorname{Gal}(L/K)| \leq n$。

等号成立的条件将在 §8.2（Galois 扩张）中完整刻画。$\blacksquare$

</ProofToggle>

::: remark 等号不成立的典型例子
$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 是 3 次扩张，但 $\operatorname{Gal} = \{id\}$，只有 1 个元素。这是因为 $x^3 - 2$ 的另外两个根不在 $\mathbb{Q}(\sqrt[3]{2})$ 中，域"太小"了——它无法容纳多项式的全部对称性。Galois 扩张的定义恰恰排除了这种情况。
:::

## 具体计算 {#computations}

::: example $\operatorname{Gal}(\mathbb{C}/\mathbb{R})$ {#ex-galois-c-r}
$\mathbb{C} = \mathbb{R}(i)$，$i$ 的极小多项式为 $x^2 + 1$，根为 $\pm i$。因此 $\operatorname{Gal}(\mathbb{C}/\mathbb{R})$ 的每个元素由 $i$ 的像确定，而 $i$ 只能映射到 $i$ 或 $-i$。

- $\operatorname{id}: i \mapsto i$（恒等）
- $\sigma: i \mapsto -i$（复共轭）

故 $\operatorname{Gal}(\mathbb{C}/\mathbb{R}) \cong \mathbb{Z}/2\mathbb{Z}$。

**注意：** 复共轭是唯一的非平凡 $\mathbb{R}$-自同构。这并不是显然的——复数域作为一个"大"的代数闭域，只有 2 个 $\mathbb{R}$-自同构，而不是很多。
:::

::: example $\operatorname{Gal}(\mathbb{Q}(\sqrt{2})/\mathbb{Q})$ {#ex-galois-q-sqrt2}
$\sqrt{2}$ 的极小多项式为 $x^2 - 2$，根为 $\pm\sqrt{2}$。故 $\operatorname{Gal}(\mathbb{Q}(\sqrt{2})/\mathbb{Q}) = \{\operatorname{id}, \sigma\}$，其中 $\sigma(\sqrt{2}) = -\sqrt{2}$，$\operatorname{Gal} \cong \mathbb{Z}/2\mathbb{Z}$。

一般地，对 $d \in \mathbb{Q}$ 不是完全平方数，$\operatorname{Gal}(\mathbb{Q}(\sqrt{d})/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z}$，非平凡元为 $\sqrt{d} \mapsto -\sqrt{d}$。
:::

::: example $\operatorname{Gal}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q})$——Galois 群可以很小 {#ex-galois-q-cbrt2}
$\sqrt[3]{2}$ 的极小多项式为 $x^3 - 2$，其三个根为 $\sqrt[3]{2}$，$\omega\sqrt[3]{2}$，$\omega^2\sqrt[3]{2}$，其中 $\omega = e^{2\pi i/3}$。

但 $\mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$，而 $\omega\sqrt[3]{2} \notin \mathbb{R}$。因此 $\sqrt[3]{2}$ 不能映射到 $\omega\sqrt[3]{2}$（像不在域内）。唯一的 $K$-自同构是恒等映射。

$$\operatorname{Gal}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}) = \{\operatorname{id}\}.$$

这说明 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ **不是 Galois 扩张**——域扩张太"小"，无法容纳多项式的全部根的对称性。要得到完整的对称性，必须到达分裂域 $\mathbb{Q}(\sqrt[3]{2}, \omega)$。
:::

::: example $\operatorname{Gal}(f/\mathbb{Q})$ 其中 $f = x^4 - 2$——二面体群的出现 {#ex-galois-x4-2}
$f$ 的分裂域为 $L = \mathbb{Q}(\sqrt[4]{2}, i)$，$[L : \mathbb{Q}] = 8$。

$f$ 的四个根为 $\alpha, -\alpha, i\alpha, -i\alpha$（其中 $\alpha = \sqrt[4]{2}$）。每个 $\sigma \in \operatorname{Gal}(L/\mathbb{Q})$ 由 $\sigma(\alpha)$ 和 $\sigma(i)$ 完全决定。

约束条件：
- $\sigma(\alpha)$ 必须是 $x^4 - 2$ 的根，故 $\sigma(\alpha) \in \{\alpha, -\alpha, i\alpha, -i\alpha\}$（4 个选择）。
- $\sigma(i)$ 必须是 $x^2 + 1$ 的根，故 $\sigma(i) \in \{i, -i\}$（2 个选择）。
- 但并不是 $4 \times 2 = 8$ 种组合都给出自同构——需要验证它们是否兼容域运算。

可以验证全部 $8$ 种组合都给出自同构，故 $|\operatorname{Gal}(L/\mathbb{Q})| = 8 = [L : \mathbb{Q}]$，这是 Galois 扩张。

$\operatorname{Gal}(L/\mathbb{Q})$ 同构于**二面体群** $D_4$（正方形的对称群），生成元为：
$$\sigma: \alpha \mapsto i\alpha,\; i \mapsto i \quad \text{（旋转）}$$
$$\tau: \alpha \mapsto \alpha,\; i \mapsto -i \quad \text{（反射）}$$

验证：$\sigma^4 = \operatorname{id}$，$\tau^2 = \operatorname{id}$，$\tau\sigma\tau^{-1} = \sigma^{-1}$。这正是 $D_4 = \langle \sigma, \tau \mid \sigma^4 = \tau^2 = \operatorname{id},\, \tau\sigma\tau = \sigma^{-1} \rangle$ 的展示。

**为什么是 $D_4$？** 直观地，$x^4 - 2$ 的四个根 $\alpha, i\alpha, -\alpha, -i\alpha$ 在复平面上构成正方形的四个顶点。Galois 群的每个元素恰好将正方形映射到自身，保持代数关系——这正是二面体群的几何意义。
:::

::: example 分圆扩张的 Galois 群 {#ex-galois-cyclotomic}
设 $p$ 是奇素数，$\zeta_p = e^{2\pi i/p}$ 是 $p$ 次本原单位根。则分圆扩张 $\mathbb{Q}(\zeta_p)/\mathbb{Q}$ 的 Galois 群为：
$$\operatorname{Gal}(\mathbb{Q}(\zeta_p)/\mathbb{Q}) \cong (\mathbb{Z}/p\mathbb{Z})^\times \cong \mathbb{Z}/(p-1)\mathbb{Z}.$$

**证明.** $\zeta_p$ 的极小多项式是 $p$ 次分圆多项式 $\Phi_p(x) = x^{p-1} + x^{p-2} + \cdots + x + 1$（由 {thm-cyclotomic-irreducible}，$\Phi_p$ 在 $\mathbb{Q}$ 上不可约）。故 $[\mathbb{Q}(\zeta_p) : \mathbb{Q}] = p - 1$。

每个 $\sigma_a \in \operatorname{Gal}(\mathbb{Q}(\zeta_p)/\mathbb{Q})$ 由 $\sigma_a(\zeta_p)$ 完全决定。$\sigma_a(\zeta_p)$ 必须是 $\Phi_p$ 的根，即某个 $\zeta_p^a$（$a \in (\mathbb{Z}/p\mathbb{Z})^\times$）。映射 $a \mapsto \sigma_a$ 给出群同态
$$(\mathbb{Z}/p\mathbb{Z})^\times \to \operatorname{Gal}(\mathbb{Q}(\zeta_p)/\mathbb{Q}), \quad a \mapsto (\zeta_p \mapsto \zeta_p^a).$$

这是群同态（因为 $\sigma_a \circ \sigma_b(\zeta_p) = \sigma_a(\zeta_p^b) = \zeta_p^{ab} = \sigma_{ab}(\zeta_p)$），且是双射（因为两边都是 $p - 1$ 阶，且 $\sigma_a = \operatorname{id}$ 仅当 $\zeta_p^a = \zeta_p$ 即 $a = 1$）。$\blacksquare$

**一般化.** 对任意正整数 $n$，$\operatorname{Gal}(\mathbb{Q}(\zeta_n)/\mathbb{Q}) \cong (\mathbb{Z}/n\mathbb{Z})^\times$（分圆扩张的 Galois 群同构定理），阶为 $\varphi(n)$。分圆扩张是**阿贝尔扩张**，其 Galois 群结构完全由初等数论决定。

**代数数论意义.** 分圆域是类域论的原型。Kronecker-Weber 定理断言 $\mathbb{Q}$ 的每个有限阿贝尔扩张都包含在某个分圆域中，这是 abelian Galois 理论的完整答案。
:::

::: example 复合扩张与 Galois 群的积结构 {#ex-composite-galois}
设 $L_1 = \mathbb{Q}(\sqrt{2})$，$L_2 = \mathbb{Q}(\sqrt{3})$。则：
- $\operatorname{Gal}(L_1/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z}$，$\operatorname{Gal}(L_2/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z}$。
- 复合域 $L = L_1 L_2 = \mathbb{Q}(\sqrt{2}, \sqrt{3})$，$[L : \mathbb{Q}] = 4$（因为 $\sqrt{3} \notin \mathbb{Q}(\sqrt{2})$，用 {thm-tower-law} 验证）。
- $\operatorname{Gal}(L/\mathbb{Q}) \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z} \cong V_4$（Klein 四元群）。

生成元：$\sigma: \sqrt{2} \mapsto -\sqrt{2}, \sqrt{3} \mapsto \sqrt{3}$ 和 $\tau: \sqrt{2} \mapsto \sqrt{2}, \sqrt{3} \mapsto -\sqrt{3}$。

一般地，若 $L_1, L_2$ 是 $K$ 的 Galois 扩张且 $L_1 \cap L_2 = K$，则 $\operatorname{Gal}(L_1 L_2/K) \cong \operatorname{Gal}(L_1/K) \times \operatorname{Gal}(L_2/K)$。
:::

## Galois 群作为置换群 {#galois-as-permutation}

::: theorem Galois 群嵌入对称群 {#thm-galois-embeds-symmetric}
设 $f \in K[x]$ 是不可约 $n$ 次多项式，$L$ 是 $f$ 在 $K$ 上的分裂域。则
$$
\operatorname{Gal}(L/K) \hookrightarrow S_n,
$$
即 Galois 群可以视为 $n$ 个根的置换群。且 $\operatorname{Gal}(L/K)$ 在根上是**传递的**。
:::

<ProofToggle>

**证明.** 由 {prop-galois-permutes-roots}，$\operatorname{Gal}(L/K)$ 忠实地作用在 $f$ 的 $n$ 个根上，故 $\operatorname{Gal}(L/K) \hookrightarrow S_n$。

**传递性：** 设 $\alpha, \beta$ 是 $f$ 的任意两个根。由于 $f$ 不可约，$K(\alpha) \cong K[x]/(f) \cong K(\beta)$（由 {thm-algebraic-simple-extension}）。这个 $K$-同构 $\tau: K(\alpha) \xrightarrow{\sim} K(\beta)$ 满足 $\tau(\alpha) = \beta$。

由嵌入扩张引理（{lem-embedding-extension}），$\tau$ 可以扩张为 $L$ 上的 $K$-自同构 $\tilde{\tau} \in \operatorname{Gal}(L/K)$，满足 $\tilde{\tau}(\alpha) = \beta$。故 Galois 群在根上是传递的。$\blacksquare$

</ProofToggle>

::: intuition 传递性的含义
传递性说的是：$f$ 的所有根在 Galois 群看来都是"平等的"——任何两个根之间都有一个自同构把一个变成另一个。这就是为什么不可约多项式的根是"代数不可区分的"：在 $K$ 的视角下，没有任何代数性质能区分两个不同的根。
:::

::: remark 可迁子群的分类
$S_n$ 的可迁子群的分类是群论中的一个重要问题。对于 $n \leq 5$，已知完整的分类。这直接对应于不可约多项式的 Galois 群的可能类型。特别地：
- $n = 2$：$\operatorname{Gal} \cong S_2 \cong \mathbb{Z}/2\mathbb{Z}$（唯一的可迁子群）。
- $n = 3$：$\operatorname{Gal} \cong S_3$ 或 $\operatorname{Gal} \cong A_3 \cong \mathbb{Z}/3\mathbb{Z}$。
- $n = 4$：$\operatorname{Gal}$ 可以是 $S_4$、$A_4$、$D_4$、$\mathbb{Z}/4\mathbb{Z}$ 或 $\operatorname{Klein}$ 四元群 $V_4$。
- $n = 5$：$\operatorname{Gal}$ 可以是 $S_5$、$A_5$、$F_{20}$（Frobenius 群）、$D_5$ 或 $\mathbb{Z}/5\mathbb{Z}$。
:::

## Galois 群的函子性 {#functoriality}

::: proposition 限制与提升 {#prop-restriction}
设 $K \subseteq L \subseteq M$ 为域扩张。

**(i)** 存在**限制同态**：
$$
\operatorname{Gal}(M/K) \twoheadrightarrow \operatorname{Gal}(L/K), \quad \sigma \mapsto \sigma|_L,
$$
当 $L/K$ 是 Galois 扩张时（即 $L$ 在 $K$ 上的 Galois 群恰好等于限制的像）。

**(ii)** 存在**包含同态**：
$$
\operatorname{Gal}(M/L) \hookrightarrow \operatorname{Gal}(M/K),
$$
其中 $\operatorname{Gal}(M/L)$ 自然地作为 $\operatorname{Gal}(M/K)$ 的子群。
:::

<ProofToggle>

**证明.**

**(i)** 对 $\sigma \in \operatorname{Gal}(M/K)$，$\sigma|_L$ 固定 $K$ 中的元素（因为 $\sigma$ 固定 $K$），且 $\sigma(L) \subseteq L$（当 $L/K$ 是正规扩张时）。因此 $\sigma|_L \in \operatorname{Gal}(L/K)$。

映射 $\sigma \mapsto \sigma|_L$ 显然是群同态。当 $L/K$ 是 Galois 扩张时，它是满射——这需要额外论证，将在 §8.2 中完成。

**(ii)** 注意 $\operatorname{Gal}(M/L) = \{\sigma \in \operatorname{Aut}(M) : \sigma|_L = \operatorname{id}_L\}$，而 $\operatorname{Gal}(M/K) = \{\sigma \in \operatorname{Aut}(M) : \sigma|_K = \operatorname{id}_K\}$。由于 $K \subseteq L$，若 $\sigma|_L = \operatorname{id}_L$ 则自动 $\sigma|_K = \operatorname{id}_K$。因此 $\operatorname{Gal}(M/L) \subseteq \operatorname{Gal}(M/K)$ 作为集合，包含映射是群同态。$\blacksquare$

</ProofToggle>

::: intuition 函子性的意义
(ii) 的直觉是：更大的"固定要求"给出更小的群。$\operatorname{Gal}(M/L)$ 要固定 $L$（比 $K$ 更大的集合），所以约束更强，群更小。这正是 Galois 对应中反序性的体现：$K \subseteq L \subseteq M$ 给出 $\operatorname{Gal}(M/K) \supseteq \operatorname{Gal}(M/L)$。

(i) 的限制同态将在第八章中发挥关键作用：它是建立 Galois 对应（正规子群 ↔ 正规扩张，商群 ↔ 限制 Galois 群）的主要工具。
:::

## 常见误区 {#misconceptions}

::: warning 误区一：Galois 群小 ≠ 扩张"简单"
$\operatorname{Gal}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}) = \{id\}$ 是平凡群，但这不意味着 $\mathbb{Q}(\sqrt[3]{2})$ 是"简单的"扩张。恰恰相反，正是因为扩张"太小"（不能容纳所有共轭根），Galois 群才小。Galois 群的大小反映的是**对称性**的丰富程度，不是扩张的复杂度。

对比：$\operatorname{Gal}(\mathbb{Q}(\sqrt[3]{2}, \omega)/\mathbb{Q}) \cong S_3$，阶为 6。同一个多项式 $X^3 - 2$，到达分裂域后 Galois 群变大了。
:::

::: warning 误区二：$|\operatorname{Gal}| < [L:K]$ 意味着什么？
$|\operatorname{Gal}(L/K)| \leq [L:K]$ 总是成立。等号成立 ⟺ $L/K$ 是 Galois 扩张（即正规 + 可分）。

当 $|\operatorname{Gal}| < [L:K]$ 时，说明扩张**不是 Galois 的**——要么不正规（缺少共轭根），要么不可分（特征 $p > 0$ 下的病态情况）。在特征 0 的情形下，$|\operatorname{Gal}| < [L:K]$ 等价于不正规。
:::

::: warning 误区三：不可约多项式的 Galois 群不一定是 $S_n$
一个常见误解是"不可约 $n$ 次多项式的 Galois 群一定是 $S_n$"。这是错误的！

反例：
- $X^4 + 1$ 在 $\mathbb{Q}$ 上不可约，但 $\operatorname{Gal}(X^4+1/\mathbb{Q}) \cong V_4$（Klein 四元群），不是 $S_4$。
- $X^p - 2$（$p$ 素数）在 $\mathbb{Q}$ 上不可约，但其 Galois 群同构于 $\mathbb{Z}/p\mathbb{Z} \rtimes (\mathbb{Z}/p\mathbb{Z})^\times$，阶为 $p(p-1)$，不是 $S_p$（阶为 $p!$）。

Galois 群是 $S_n$ 的**可迁子群**，但不一定是 $S_n$ 本身。判定 Galois 群是否为 $S_n$ 是 Galois 理论中的一个核心计算问题（[§7.2](7.2-computation)）。
:::

- Galois 群阶与扩张次数的关系见 [§8.2 Galois 扩张](/chapters/08-galois-correspondence/)。
- Galois 群作为 $S_n$ 的可迁子群，决定了 [§7.2](/chapters/07-galois-groups/7.2-computation) 中的计算策略。

## 本节小结 {#summary}

| 例子 | 扩张 | Galois 群 | 阶 | Galois 扩张？ |
|:---|:---|:---|:---|:---|
| $\mathbb{C}/\mathbb{R}$ | $\mathbb{R}(i)$ | $\mathbb{Z}/2\mathbb{Z}$ | 2 | ✓ |
| $\mathbb{Q}(\sqrt{2})/\mathbb{Q}$ | 二次 | $\mathbb{Z}/2\mathbb{Z}$ | 2 | ✓ |
| $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ | 三次 | $\{id\}$ | 1 | ✗ |
| $\mathbb{Q}(\sqrt[4]{2}, i)/\mathbb{Q}$ | 8 次 | $D_4$ | 8 | ✓ |
| $\mathbb{Q}(\zeta_p)/\mathbb{Q}$ | $p-1$ 次 | $(\mathbb{Z}/p\mathbb{Z})^\times$ | $p-1$ | ✓ |
| $\mathbb{Q}(\sqrt{2},\sqrt{3})/\mathbb{Q}$ | 4 次 | $V_4$ | 4 | ✓ |

**核心公式：** $|\operatorname{Gal}(L/K)| \leq [L:K]$，等号当且仅当 $L/K$ 是 Galois 扩张。

## 自测题 {#self-test}

1. **[基础]** 计算 $\operatorname{Gal}(\mathbb{Q}(\sqrt{6})/\mathbb{Q})$ 和 $\operatorname{Gal}(\mathbb{Q}(\sqrt{2}+\sqrt{3})/\mathbb{Q})$。
2. **[理解]** 为什么 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 不是 Galois 扩张，但 $\mathbb{Q}(\sqrt[3]{2}, \omega)/\mathbb{Q}$ 是？从 Galois 群的阶来解释。
3. **[计算]** 设 $f(x) = x^4 + 1$。$f$ 在 $\mathbb{Q}$ 上不可约（用分圆多项式理论）。$f$ 的分裂域是什么？$\operatorname{Gal}(f/\mathbb{Q})$ 同构于什么群？
4. **[深入]** 设 $L_1/\mathbb{Q}$ 和 $L_2/\mathbb{Q}$ 都是 Galois 扩张，$L_1 \cap L_2 = \mathbb{Q}$。证明 $\operatorname{Gal}(L_1 L_2/\mathbb{Q}) \cong \operatorname{Gal}(L_1/\mathbb{Q}) \times \operatorname{Gal}(L_2/\mathbb{Q})$。（提示：构造限制映射的乘积。）
5. **[证明]** 设 $f \in \mathbb{Q}[x]$ 是不可约三次多项式，判别式 $\Delta$ 为完全平方。证明 $\operatorname{Gal}(f/\mathbb{Q}) \cong A_3 \cong \mathbb{Z}/3\mathbb{Z}$。（提示：完全平方 $\implies$ $\operatorname{Gal} \subseteq A_3$，但不可约 $\implies$ $3 \mid |\operatorname{Gal}|$。）
