# §5.2 正规扩张 {#sec-normal-extensions}

::: tip 本节学习目标
1. 掌握**正规扩张**的定义：不可约多项式有一根 ⇒ 所有根都在扩张中。
2. 理解正规性的四种等价刻画（定义 / 嵌入像封闭 / 分裂域 / 极小多项式判据），以及每种刻画的适用场景。
3. 掌握正规性的**判定方法**：通过极小多项式分裂性来验证。
4. 理解正规性在域塔中的**传递规律**：$M/K$ 正规 $\Rightarrow$ $M/L$ 正规，但反之不成立。
5. 掌握**正规闭包**的构造：给定非正规扩张，如何"补全"为正规扩张。
6. 理解正规性在 **Galois 理论**中的核心地位。
:::

---

## 什么是正规扩张？ {#motivation}

[§5.1](5.1-splitting-fields) 证明了每个多项式都有分裂域。反过来的问题是：给定一个域扩张 $L/K$，它是否恰好是某个多项式的分裂域？

这个"反过来的问题"引出了**正规扩张**的概念。正规扩张在 Galois 理论中扮演核心角色：Galois 对应（第八章）只在正规扩张上完美运作。

::: intuition 为什么要关心正规性？
正规性是一个扩张是否"对称"的衡量标准。考虑以下对比：

- $\mathbb{Q}(\sqrt{2})/\mathbb{Q}$：极小多项式 $X^2 - 2$ 的两个根 $\pm\sqrt{2}$ 都在扩张中。"对称性完整"。✓
- $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$：极小多项式 $X^3 - 2$ 有三个根，但只有 $\sqrt[3]{2}$ 在扩张中。$\omega\sqrt[3]{2}$ 和 $\omega^2\sqrt[3]{2}$ 缺失。"对称性不完整"。✗

正规性要求**所有共轭元素**都在扩张中——这正是 Galois 理论能够建立"对称群 ↔ 子域"对应的条件。
:::

---

## 正规扩张的定义 {#def-normal}

::: definition 正规扩张 {#def-normal-extension}
设 $L/K$ 是代数扩张。我们说 $L/K$ 是**正规的**（normal），如果满足以下条件：

> 对每个在 $K$ 上不可约的多项式 $f \in K[X]$，若 $f$ 在 $L$ 中至少有一个根，则 $f$ 在 $L$ 上完全分裂。

等价地说：$L$ 对 $K$ 上的不可约多项式是"封闭的"——只要一个不可约多项式在 $L$ 中有一根，它的所有根都在 $L$ 中。
:::

::: warning 正规性是扩张的性质，不是域的性质
正规性是**扩张 $L/K$** 的性质，不是域 $L$ 本身的性质。同一个域 $L$ 对不同的基域 $K$ 可能有不同的正规性。

**例子**：$L = \mathbb{Q}(\sqrt{2})$。
- $L/\mathbb{Q}$ 是正规扩张 ✓（$X^2 - 2$ 的两个根 $\pm\sqrt{2}$ 都在 $L$ 中）。
- $L/\mathbb{Q}(\sqrt[4]{2})$ 不是正规扩张 ✗（因为 $\mathbb{Q}(\sqrt{2}) \subset \mathbb{Q}(\sqrt[4]{2})$，这不是一个扩张……实际上 $L \subset \mathbb{Q}(\sqrt[4]{2})$）。

更准确的例子：$L = \mathbb{Q}(\sqrt[3]{2})$。
- $L/\mathbb{Q}$ 不是正规扩张 ✗（$X^3 - 2$ 有共轭根不在 $L$ 中）。
- $L/L$ 当然是正规扩张 ✓（平凡扩张总是正规的）。
:::

## 正规扩张的例子 {#sec-normal-examples}

::: example 正规扩张 {#ex-normal-examples}
**例 1.** $\mathbb{C}/\mathbb{R}$ 是正规扩张。$\mathbb{R}[X]$ 中的不可约多项式要么是一次（根已含于 $\mathbb{R}$），要么是二次（$X^2 + bX + c$，$\Delta < 0$）。$\mathbb{C}$ 包含所有二次不可约多项式的根（$(-b \pm \sqrt{\Delta})/2$），且完全分裂。✓

**例 2.** $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ 是正规扩张。极小多项式为 $(X^2-2)(X^2-3)$，根为 $\pm\sqrt{2}, \pm\sqrt{3}$，全在 $L$ 中。✓

**例 3.** $\mathbb{Q}(\sqrt{2} + \sqrt{3})/\mathbb{Q}$ 也是正规扩张！这是因为 $\mathbb{Q}(\sqrt{2} + \sqrt{3}) = \mathbb{Q}(\sqrt{2}, \sqrt{3})$（可以验证 $\sqrt{2} = \frac{(\sqrt{2}+\sqrt{3})^3 - 9(\sqrt{2}+\sqrt{3})}{2}$）。虽然生成元不同，但扩域相同。✓

**例 4.** **分圆扩张** $\mathbb{Q}(\zeta_n)/\mathbb{Q}$ 总是正规扩张，其中 $\zeta_n = e^{2\pi i/n}$。$\zeta_n$ 的极小多项式是分圆多项式 $\Phi_n(X)$，它的所有根是 $\zeta_n^k$（$k$ 与 $n$ 互素），都在 $\mathbb{Q}(\zeta_n)$ 中。✓

**例 5.** **有限域的扩张** $\mathbb{F}_{q^n}/\mathbb{F}_q$ 总是正规扩张。$\mathbb{F}_{q^n}$ 是 $X^{q^n} - X$ 的分裂域。✓

**例 6.** 任意**分裂域**都是正规扩张（这由定义直接得出）。
:::

::: example 重要的非正规扩张 {#ex-non-normal}
**例 1.** $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ **不是**正规扩张。$f(X) = X^3 - 2$ 在 $\mathbb{Q}$ 上不可约，且在 $\mathbb{Q}(\sqrt[3]{2})$ 中有根 $\sqrt[3]{2}$。但 $f$ 的另外两个根 $\omega\sqrt[3]{2}$ 和 $\omega^2\sqrt[3]{2}$ 不在 $\mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$ 中。所以 $f$ 不在 $\mathbb{Q}(\sqrt[3]{2})$ 上分裂。✗

**例 2.** $\mathbb{Q}(\sqrt[4]{2})/\mathbb{Q}$ **不是**正规扩张。$X^4 - 2$ 的根 $\pm\sqrt[4]{2}, \pm i\sqrt[4]{2}$ 中，$i\sqrt[4]{2} \notin \mathbb{Q}(\sqrt[4]{2}) \subset \mathbb{R}$。

$f$ 在 $\mathbb{Q}$ 上的分裂域是 $\mathbb{Q}(\sqrt[4]{2}, i)$（[§5.1 例 {ex-x4-2}](5.1-splitting-fields#ex-x4-2)），维度为 $8$，大于 $[\mathbb{Q}(\sqrt[4]{2}) : \mathbb{Q}] = 4$。

**例 3.** $\mathbb{Q}(\sqrt{1+\sqrt{2}})/\mathbb{Q}$ 不是正规扩张。$\alpha = \sqrt{1+\sqrt{2}}$ 的极小多项式是 $X^4 - 2X^2 - 1$（可通过 $\alpha^2 = 1+\sqrt{2}$ 推出 $\alpha^2-1 = \sqrt{2}$，再平方得 $(\alpha^2-1)^2 = 2$）。这个多项式的四个根为 $\pm\sqrt{1 \pm \sqrt{2}}$，其中 $\sqrt{1-\sqrt{2}}$ 是虚数，不在实扩张中。✗
:::

::: remark 为什么非正规扩张也重要？
非正规扩张在 Galois 理论中不是"废品"，而是有重要角色：

1. **正规闭包**：每个非正规扩张 $L/K$ 都有正规闭包 $N/K$（{thm-normal-closure}），$N$ 是包含 $L$ 的最小正规扩张。
2. **Galois 群的部分信息**：即使 $L/K$ 不正规，$\operatorname{Aut}(L/K)$ 仍有意义，只是不能直接使用 Galois 对应。
3. **构造正规扩张的跳板**：很多正规扩张是从非正规扩张逐步"补全"得到的。
:::

## 正规性的等价刻画 {#characterizations}

正规性有多种等价表述，每一种都有其用途。

::: definition $K$-嵌入 {#def-embedding-into-algebraic-closure}
设 $L/K$ 是代数扩张，$\bar{K}$ 是 $K$ 的一个代数闭包（或任何包含 $L$ 的扩域）。$K$-**嵌入**是指域嵌入 $\sigma: L \hookrightarrow \bar{K}$，满足 $\sigma|_K = \mathrm{id}_K$。
:::

::: intuition 为什么需要 $K$-嵌入？
$K$-嵌入 $\sigma: L \hookrightarrow \bar{K}$ 是 $L$ 到 $\bar{K}$ 的"对称操作"——它固定 $K$ 的每个元素，但可以"重排" $L$ 中不在 $K$ 里的元素。

例如，$\mathbb{Q}(\sqrt{2})$ 到 $\bar{\mathbb{Q}}$ 有两个 $K$-嵌入：恒等映射和 $\sqrt{2} \mapsto -\sqrt{2}$。这两个嵌入的像都是 $\mathbb{Q}(\sqrt{2})$，反映了 $X^2 - 2$ 的两个根的对称性。

对于 $\mathbb{Q}(\sqrt[3]{2})$，有三个 $K$-嵌入（对应 $X^3-2$ 的三个根），但它们的像各不相同：只有恒等映射的像在 $\mathbb{R}$ 中。这反映了 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 的非正规性。
:::

::: theorem 正规性的等价条件 {#thm-normal-characterizations}
设 $L/K$ 是有限代数扩张。则以下条件等价：

**(N1)** $L/K$ 是正规扩张。

**(N2)** 对每个 $K$-嵌入 $\sigma: L \hookrightarrow \bar{K}$（其中 $\bar{K}$ 是 $K$ 的代数闭包），有 $\sigma(L) = L$。

**(N3)** $L$ 是 $K$ 上某族多项式的分裂域。

**(N4)** 设 $L = K(\alpha_1, \ldots, \alpha_n)$，$f_i$ 是 $\alpha_i$ 在 $K$ 上的极小多项式。则 $L$ 是 $f = f_1 f_2 \cdots f_n$ 在 $K$ 上的分裂域。
:::

::: remark 各条件的意义
- **(N1)** 是定义：从多项式角度出发。
- **(N2)** 是嵌入判据：从对称性角度出发。"$L$ 对所有 $K$-嵌入封闭"——这是最便于验证的条件之一。
- **(N3)** 是分裂域判据：揭示了正规扩张的本质就是分裂域。
- **(N4)** 是构造性判据：给出了如何找到 $L$ 所分裂的多项式——取所有生成元的极小多项式之积。
:::

<ProofToggle>

**证明.** 我们依次证明 (N4) $\Rightarrow$ (N3) $\Rightarrow$ (N1) $\Rightarrow$ (N2) $\Rightarrow$ (N4)。

---

**(N4) $\Rightarrow$ (N3)：** 若 $L$ 是 $f = f_1 \cdots f_n$ 的分裂域，则 $L$ 是 $K$ 上多项式族 $\{f_1, \ldots, f_n\}$ 的分裂域。取 $\mathcal{F} = \{f\}$ 即得 (N3)。✓

**(N3) $\Rightarrow$ (N1)：** 设 $L$ 是某族多项式 $\mathcal{F} \subseteq K[X]$ 的分裂域。设 $g \in K[X]$ 不可约且在 $L$ 中有根 $\alpha$。我们要证 $g$ 在 $L$ 上完全分裂。

取 $\mathcal{F}' = \mathcal{F} \cup \{g\}$。设 $L'$ 是 $\mathcal{F}'$ 的分裂域。则 $L \subseteq L'$，且 $\alpha \in L$。另一方面，$L'$ 由 $L$ 和 $g$ 的所有根生成。

设 $\beta$ 是 $g$ 在 $L'$ 中的任意根。因为 $g$ 在 $K$ 上不可约且 $\alpha, \beta$ 都是 $g$ 的根，由 [§3.3 {prop-conjugate-criteria}](/chapters/03-fields/3.3-algebraic-elements#prop-conjugate-criteria)，存在 $K$-同构 $\tau: K(\alpha) \xrightarrow{\sim} K(\beta)$，满足 $\tau(\alpha) = \beta$，$\tau|_K = \mathrm{id}_K$。

因为 $L$ 是 $\mathcal{F}$ 的分裂域，可以将 $\tau$ 从 $K(\alpha)$ 扩张到 $L'$ 的某个子域（更精确地，$\tau$ 扩张为 $L$ 到 $L'$ 的一个 $K$-嵌入 $\tilde{\tau}: L \hookrightarrow L'$）。由 {lem-embedding-extension} 和 $L$ 是 $\mathcal{F}$ 的分裂域，$\tilde{\tau}(L) \subseteq L'$。

因为 $\alpha \in L$，$\tilde{\tau}(\alpha) = \beta$，所以 $\beta \in \tilde{\tau}(L)$。我们需要证明 $\beta \in L$。

关键观察：$\tilde{\tau}$ 是 $K$-嵌入 $\sigma: L \hookrightarrow L' \subseteq \bar{K}$。若我们能证明所有 $K$-嵌入 $L \hookrightarrow \bar{K}$ 的像等于 $L$，则 $\beta \in L$。

这正是 (N2) 的内容。但我们可以直接证明 (N1) 如下：

设 $\beta_1, \ldots, \beta_r$ 是 $g$ 在 $\bar{K}$ 中的所有根。每个 $\beta_j$ 都是 $g$ 的根，$g$ 在 $K$ 上不可约。所以对每个 $j$，存在 $K$-同构 $\tau_j: K(\alpha) \xrightarrow{\sim} K(\beta_j)$，将 $\alpha$ 映射到 $\beta_j$。每个 $\tau_j$ 都可以扩张为某个 $K$-嵌入 $\sigma_j: L \hookrightarrow \bar{K}$。

$L$ 作为 $\mathcal{F}$ 的分裂域，是某个多项式 $h \in K[X]$ 的分裂域。设 $h$ 在 $L$ 中的根为 $\gamma_1, \ldots, \gamma_s$。则 $L = K(\gamma_1, \ldots, \gamma_s)$。

对每个 $K$-嵌入 $\sigma_j: L \hookrightarrow \bar{K}$，$\sigma_j(\gamma_i)$ 是 $h$ 的某个根。所以 $\sigma_j$ 将 $h$ 的根集合 $\{\gamma_1, \ldots, \gamma_s\}$ 置换。因此 $\sigma_j(L) = K(\sigma_j(\gamma_1), \ldots, \sigma_j(\gamma_s)) \subseteq K(\gamma_1, \ldots, \gamma_s) = L$（因为 $h$ 的所有根在 $L$ 中）。更精确地，$\sigma_j$ 在 $h$ 的根集上诱导一个置换，所以 $\sigma_j(L) = L$。

特别地，$\beta_j = \sigma_j(\alpha) \in \sigma_j(L) = L$。所以 $g$ 的所有根都在 $L$ 中，$g$ 在 $L$ 上分裂。✓

**(N1) $\Rightarrow$ (N2)：** 设 $L/K$ 是正规扩张。设 $\sigma: L \hookrightarrow \bar{K}$ 是 $K$-嵌入。设 $\alpha \in L$，$f = m_{\alpha,K}$ 是 $\alpha$ 在 $K$ 上的极小多项式。则 $\sigma(\alpha)$ 也是 $f$ 的根（因为 $\sigma|_K = \mathrm{id}_K$ 保持 $f$ 的系数不变）。由正规性，$f$ 在 $L$ 上完全分裂，$f$ 的所有根都在 $L$ 中。所以 $\sigma(\alpha) \in L$。

这证明了 $\sigma(L) \subseteq L$。因为 $L/K$ 是有限扩张，$\sigma$ 是单射，$[L : K] = [\sigma(L) : K]$。所以 $\sigma(L) \subseteq L$ 且 $[\sigma(L) : K] = [L : K]$ 迫使 $\sigma(L) = L$。✓

**(N2) $\Rightarrow$ (N4)：** 设 $L = K(\alpha_1, \ldots, \alpha_n)$。设 $f_i$ 是 $\alpha_i$ 在 $K$ 上的极小多项式。设 $f = f_1 \cdots f_n$。设 $L_f$ 是 $f$ 在 $K$ 上的分裂域。则 $L \subseteq L_f$（因为每个 $\alpha_i$ 都是 $f$ 的根）。

我们要证 $L = L_f$，即 $f$ 在 $L$ 上已完全分裂。

设 $\beta$ 是某个 $f_i$ 的根。则存在 $K$-同构 $\tau: K(\alpha_i) \xrightarrow{\sim} K(\beta)$，满足 $\tau(\alpha_i) = \beta$。由 {lem-embedding-extension}，$\tau$ 可以扩张为 $K$-嵌入 $\sigma: L \hookrightarrow \bar{K}$。由 (N2)，$\sigma(L) = L$。所以 $\beta = \sigma(\alpha_i) \in L$。

这证明了每个 $f_i$ 的所有根都在 $L$ 中，即 $f$ 在 $L$ 上完全分裂。所以 $L_f \subseteq L$，从而 $L_f = L$。✓

这完成了 (N4) $\Rightarrow$ (N3) $\Rightarrow$ (N1) $\Rightarrow$ (N2) $\Rightarrow$ (N4) 的循环。 $\blacksquare$

</ProofToggle>

::: warning 证明中的关键洞察
**(N3) ⇒ (N1)** 的证明是最微妙的一步。关键洞察是：如果 $L$ 是 $\mathcal{F}$ 的分裂域，那么 $L$ 的 $K$-嵌入只能**置换** $\mathcal{F}$ 中多项式的根——因此嵌入的像一定包含在 $L$ 中。

这个论证依赖于分裂域的**刚性**：分裂域由多项式的根生成，而 $K$-嵌入只能重排这些根（保持它们满足相同的多项式关系）。这种"刚性"正是正规扩张的核心特征。
:::

## 正规性的判定 {#how-to-check}

::: corollary 判定正规性 {#cor-check-normal}
要判定 $L = K(\alpha_1, \ldots, \alpha_n)/K$ 是否正规：

1. 计算每个 $\alpha_i$ 的极小多项式 $f_i \in K[X]$。
2. 计算 $f = f_1 \cdots f_n$。
3. 判定 $f$ 是否在 $L$ 上完全分裂（即 $f$ 的所有根是否都在 $L$ 中）。

若 $f$ 在 $L$ 上分裂，则 $L/K$ 正规；否则不正规。

**特别地**：若 $L = K(\alpha)$ 是单扩张，则只需检查 $\alpha$ 的极小多项式 $f$ 是否在 $L$ 上分裂。
:::

::: example 用判定法验证正规性 {#ex-check-normal}
**验证 $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ 是正规扩张。**

$\alpha_1 = \sqrt{2}$，极小多项式 $f_1 = X^2 - 2$，根为 $\pm\sqrt{2}$。
$\alpha_2 = \sqrt{3}$，极小多项式 $f_2 = X^2 - 3$，根为 $\pm\sqrt{3}$。

$f = f_1 f_2 = (X^2 - 2)(X^2 - 3)$。根为 $\pm\sqrt{2}, \pm\sqrt{3}$。

$\sqrt{2} \in L$ ✓；$-\sqrt{2} \in L$ ✓；$\sqrt{3} \in L$ ✓；$-\sqrt{3} \in L$ ✓。

所有根都在 $L$ 中，所以 $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ 是正规扩张。✓

事实上，$L$ 是 $f = (X^2 - 2)(X^2 - 3)$ 的分裂域。
:::

::: example 非正规扩张的验证 {#ex-check-non-normal}
**验证 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 不是正规扩张。**

$\alpha = \sqrt[3]{2}$，极小多项式 $f = X^3 - 2$，根为 $\sqrt[3]{2}, \omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}$。

$\sqrt[3]{2} \in L$ ✓。但 $\omega\sqrt[3]{2} \notin \mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$。✗

$f$ 不在 $L$ 上完全分裂，所以 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 不是正规扩张。

**注意**：$\operatorname{Aut}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}) = \{1\}$（只有恒等自同构），而 $[L:\mathbb{Q}] = 3$。$|\operatorname{Aut}| < [L:K]$，这是非正规扩张的典型信号。
:::

::: example 分圆扩张的正规性 {#ex-cyclotomic-normal}
**验证 $\mathbb{Q}(\zeta_5)/\mathbb{Q}$ 是正规扩张。**

$\zeta_5 = e^{2\pi i/5}$，极小多项式是分圆多项式 $\Phi_5(X) = X^4 + X^3 + X^2 + X + 1$。

$\Phi_5$ 的四个根是 $\zeta_5, \zeta_5^2, \zeta_5^3, \zeta_5^4$。因为 $\mathbb{Q}(\zeta_5)$ 在乘法下封闭，$\zeta_5^k \in \mathbb{Q}(\zeta_5)$ 对所有 $k$。所以 $\Phi_5$ 在 $\mathbb{Q}(\zeta_5)$ 上完全分裂。✓

$[\mathbb{Q}(\zeta_5) : \mathbb{Q}] = \deg \Phi_5 = 4 = \phi(5)$。

$|\operatorname{Aut}(\mathbb{Q}(\zeta_5)/\mathbb{Q})| = 4$（由 $\sigma_k: \zeta_5 \mapsto \zeta_5^k$ 给出，$k = 1,2,3,4$）。

$|\operatorname{Aut}| = [L:K]$，这是正规扩张的典型信号。
:::

## 正规扩张的塔性质 {#tower}

::: remark 正规性在塔中不传递
正规性在一般域塔中**不传递**：$L/K$ 和 $M/L$ 都正规 $\not\Rightarrow$ $M/K$ 正规。

**反例：** 取 $K = \mathbb{Q}$，$L = \mathbb{Q}(\sqrt{2})$，$M = \mathbb{Q}(\sqrt[4]{2})$。

- $L/K$ 正规 ✓（$L$ 是 $X^2 - 2$ 的分裂域）。
- $M/L$ 正规 ✓（$M$ 是 $X^2 - \sqrt{2}$ 在 $L$ 上的分裂域）。
- $M/K$ **不正规** ✗（$X^4 - 2$ 不在 $\mathbb{Q}(\sqrt[4]{2})$ 上分裂）。

**为什么会失败？** 因为 $M/L$ 正规性只保证 $L$ 上的不可约多项式在 $M$ 中分裂。但 $M/K$ 正规性需要 $K$ 上的不可约多项式在 $M$ 中分裂。$X^4 - 2$ 在 $\mathbb{Q}$ 上不可约，但它在 $L$ 上可约（$X^4-2 = (X^2-\sqrt{2})(X^2+\sqrt{2})$），所以 $M/L$ 正规性的条件和 $M/K$ 正规性的条件涉及不同的多项式集合。
:::

::: proposition 正规扩张塔的正确判据 {#prop-normal-tower}
设 $K \subseteq L \subseteq M$。

**(a)** 若 $M/K$ 正规，则 $M/L$ 正规。

**(b)** 若 $L/K$ 和 $M/K$ 都正规，则 $M/L$ 正规。
:::

<ProofToggle>

**证明.**

**(a)** 设 $M/K$ 正规，$f \in L[X]$ 不可约且在 $M$ 中有根 $\alpha$。设 $g$ 是 $\alpha$ 在 $K$ 上的极小多项式。则 $f \mid g$（在 $L[X]$ 中，因为 $g(\alpha) = 0$ 且 $f$ 是 $L$ 上的极小多项式）。由 $M/K$ 正规，$g$ 在 $M$ 上完全分裂。因为 $f \mid g$，$f$ 的每个根也是 $g$ 的根，从而在 $M$ 中。所以 $f$ 在 $M$ 上完全分裂。✓

**(b)** 这是 (a) 的直接推论（$M/K$ 正规 $\Rightarrow$ $M/L$ 正规），因为 $L/K$ 正规的条件在 (a) 的证明中没有用到。

或者直接证明：设 $f \in L[X]$ 不可约且在 $M$ 中有根 $\alpha$。设 $\sigma: M \hookrightarrow \bar{K}$ 是 $L$-嵌入。则 $\sigma|_K = \mathrm{id}_K$（因为 $L$-嵌入自动是 $K$-嵌入）。由 $M/K$ 正规，$\sigma(M) = M$。所以 $M/L$ 是正规的。 $\blacksquare$

</ProofToggle>

::: warning 塔性质的"方向"
**正确**：$M/K$ 正规 $\Rightarrow$ $M/L$ 正规（大扩张正规则子扩张正规）。"正规性向下传递"。

**错误**：$L/K$ 正规 $\Rightarrow$ $M/K$ 正规。"正规性不向上传递"。

**也错误**：$L/K$ 和 $M/L$ 都正规 $\Rightarrow$ $M/K$ 正规。"正规性不逐级传递"。

**记忆法**：正规性是"分裂"的性质。如果大扩张 $M/K$ 已经分裂了所有 $K$-多项式，那么它当然也分裂了所有 $L$-多项式（$L$-多项式的根也是 $K$-多项式的根的子集）。反之不行。
:::

## 正规闭包 {#normal-closure}

::: definition 正规闭包 {#def-normal-closure}
设 $L/K$ 是有限代数扩张。$L$ 在 $K$ 上的**正规闭包**（normal closure）是包含 $L$ 的最小正规扩张 $N/K$。即：

1. $N/K$ 是正规扩张；
2. $L \subseteq N$；
3. 若 $N'/K$ 是正规扩张且 $L \subseteq N'$，则 $N \subseteq N'$。
:::

::: intuition 正规闭包的直觉
正规闭包是把 $L/K$ "补全"为正规扩张的最小操作。它把 $L$ 中所有元素的共轭根都"补进去"。

类比：如果 $L$ 是画了一半的圆，正规闭包就是补全成完整的圆。
:::

::: theorem 正规闭包的存在与构造 {#thm-normal-closure}
设 $L = K(\alpha_1, \ldots, \alpha_n)$ 是有限代数扩张，$f_i$ 是 $\alpha_i$ 在 $K$ 上的极小多项式。则 $f = f_1 \cdots f_n$ 在 $K$ 上的分裂域是 $L$ 在 $K$ 上的正规闭包。
:::

<ProofToggle>

**证明.** 设 $N$ 是 $f = f_1 \cdots f_n$ 的分裂域。则 $L \subseteq N$（因为每个 $\alpha_i$ 是 $f_i$ 的根，从而是 $f$ 的根）。

$N/K$ 正规：$N$ 是多项式 $f$ 的分裂域，所以 $N/K$ 正规。

最小性：设 $N'/K$ 是正规扩张且 $L \subseteq N'$。对每个 $i$，$\alpha_i \in N'$，$f_i$ 不可约且在 $N'$ 中有根 $\alpha_i$。由正规性，$f_i$ 在 $N'$ 上完全分裂。所以 $f$ 在 $N'$ 上完全分裂，$f$ 的所有根都在 $N'$ 中。因此 $N \subseteq N'$。 $\blacksquare$

</ProofToggle>

::: example 正规闭包的计算 {#ex-normal-closure}
**例 1.** $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 的正规闭包是 $\mathbb{Q}(\sqrt[3]{2}, \omega)$，它是 $X^3 - 2$ 的分裂域，$[\cdot : \mathbb{Q}] = 6$。

**例 2.** $\mathbb{Q}(\sqrt[4]{2})/\mathbb{Q}$ 的正规闭包是 $\mathbb{Q}(\sqrt[4]{2}, i)$，它是 $X^4 - 2$ 的分裂域，$[\cdot : \mathbb{Q}] = 8$。

**例 3.** $\mathbb{Q}(\sqrt{2})/\mathbb{Q}$ 的正规闭包就是 $\mathbb{Q}(\sqrt{2})$ 自身——它已经是正规扩张。

**例 4.** $\mathbb{Q}(\sqrt{1+\sqrt{2}})/\mathbb{Q}$ 的正规闭包是 $X^4 - 2X^2 - 1$ 的分裂域，包含 $\pm\sqrt{1+\sqrt{2}}$ 和 $\pm\sqrt{1-\sqrt{2}}$。
:::

## 正规性的 0-K-嵌入计数 {#counting-embeddings}

::: proposition 正规扩张与 $K$-嵌入数 {#prop-normal-embedding-count}
设 $L/K$ 是有限扩张。则：

**(a)** $|\operatorname{Hom}_K(L, \bar{K})| \leq [L:K]$（$K$-嵌入数不超过扩张次数），等号成立当且仅当 $L/K$ 是可分扩张。

**(b)** 若 $L/K$ 是正规扩张，则每个 $K$-嵌入 $\sigma: L \hookrightarrow \bar{K}$ 满足 $\sigma(L) = L$（即嵌入是 $K$-**自同构**）。因此 $\operatorname{Hom}_K(L, \bar{K}) = \operatorname{Aut}(L/K)$。
:::

::: remark 正规 + 可分 = Galois
**(a)** 和 **(b)** 结合给出：
$$L/K \text{ 是 Galois 扩张} \iff L/K \text{ 是正规可分扩张} \iff |\operatorname{Aut}(L/K)| = [L:K]$$

这是 Galois 理论的基石：Galois 扩张恰好是那些"自同构数等于扩张次数"的扩张。
:::

## 常见误区 {#misconceptions}

::: warning 误区一：正规性不等于自同构群大
$\mathbb{Q}(\sqrt{2})/\mathbb{Q}$ 是正规扩张，$|\operatorname{Aut}| = 2 = [L:K]$。✓

但 $\mathbb{Q}(\sqrt[3]{2}, \omega)/\mathbb{Q}$ 也是正规扩张（它是 $X^3-2$ 的分裂域），$|\operatorname{Aut}| = 6 = [L:K]$。✓

**误区**：认为正规扩张的自同构群一定"小"或"大"。实际上，正规性只保证 $|\operatorname{Aut}| = [L:K]$（当也满足可分性时），不指定群的具体结构。
:::

::: warning 误区二：$L/K$ 正规不意味着 $L$ 中的每个元素的极小多项式都在 $L$ 上分裂
正规性的条件是：**$K$ 上**的不可约多项式在 $L$ 中有一根 ⇒ 所有根在 $L$ 中。

这和说"$L$ 中每个元素的极小多项式（在 $K$ 上）都在 $L$ 上分裂"是等价的。但要注意基域是 $K$，不是 $L$。

**反例考虑**：设 $L = \mathbb{Q}(\sqrt{2}, \sqrt{3})$。$L/\mathbb{Q}$ 正规。取 $\alpha = \sqrt{2} + \sqrt{3} \in L$，其极小多项式在 $\mathbb{Q}$ 上为 $X^4 - 10X^2 + 1$，根为 $\pm\sqrt{2} \pm \sqrt{3}$，全在 $L$ 中。✓

但如果考虑 $L/\mathbb{Q}(\sqrt{2})$（不正规），$\sqrt{3}$ 在 $\mathbb{Q}(\sqrt{2})$ 上的极小多项式 $X^2 - 3$ 的根 $\pm\sqrt{3}$ 都在 $L$ 中——但这只是因为 $X^2-3$ 是二次多项式，不是因为 $L/\mathbb{Q}(\sqrt{2})$ 正规。
:::

::: warning 误区三：分裂域的唯一性不意味着正规闭包的唯一性
分裂域在 $K$-同构意义下唯一，但作为 $\bar{K}$ 的子域不唯一（取决于嵌入选择）。

正规闭包也有同样的情况：在 $K$-同构意义下唯一，但作为 $\bar{K}$ 的子域可能有不同的实现。
:::

---

::: tip 本节知识检验

**自测题：**

1. 判断 $\mathbb{Q}(\sqrt{2}+\sqrt{3})/\mathbb{Q}$ 是否是正规扩张。

2. 设 $L = \mathbb{Q}(\sqrt[3]{2})$。列出 $L$ 到 $\bar{\mathbb{Q}}$ 的所有 $K$-嵌入。哪些嵌入的像等于 $L$？

3. 为什么 $M/K$ 正规 $\Rightarrow$ $M/L$ 正规，但 $L/K$ 和 $M/L$ 都正规 $\not\Rightarrow$ $M/K$ 正规？用具体的反例解释。

4. 计算 $\mathbb{Q}(\sqrt{1+\sqrt{2}})/\mathbb{Q}$ 的正规闭包及其扩张次数。

5. 证明：若 $L/K$ 正规且 $L = K(\alpha)$，则 $L$ 是 $\alpha$ 的极小多项式的分裂域。

**答案要点：**

1. 是。$\mathbb{Q}(\sqrt{2}+\sqrt{3}) = \mathbb{Q}(\sqrt{2},\sqrt{3})$（可以验证 $\sqrt{2} = \frac{(\sqrt{2}+\sqrt{3})^3 - 9(\sqrt{2}+\sqrt{3})}{2}$）。$X^2-2$ 和 $X^2-3$ 的根都在 $L$ 中。

2. 三个嵌入：$\sigma_1: \sqrt[3]{2} \mapsto \sqrt[3]{2}$（像 $= L$），$\sigma_2: \sqrt[3]{2} \mapsto \omega\sqrt[3]{2}$（像 $= \mathbb{Q}(\omega\sqrt[3]{2}) \neq L$），$\sigma_3: \sqrt[3]{2} \mapsto \omega^2\sqrt[3]{2}$（像 $\neq L$）。只有 $\sigma_1$ 的像等于 $L$，反映非正规性。

3. 反例：$\mathbb{Q} \subset \mathbb{Q}(\sqrt{2}) \subset \mathbb{Q}(\sqrt[4]{2})$。$\mathbb{Q}(\sqrt{2})/\mathbb{Q}$ 和 $\mathbb{Q}(\sqrt[4]{2})/\mathbb{Q}(\sqrt{2})$ 都正规，但 $\mathbb{Q}(\sqrt[4]{2})/\mathbb{Q}$ 不正规。原因：$X^4-2$ 在 $\mathbb{Q}$ 上不可约但在 $\mathbb{Q}(\sqrt{2})$ 上可约为 $(X^2-\sqrt{2})(X^2+\sqrt{2})$。

4. 正规闭包是 $X^4-2X^2-1$ 的分裂域。$X^4-2X^2-1 = (X^2-1-\sqrt{2})(X^2-1+\sqrt{2})$。根为 $\pm\sqrt{1+\sqrt{2}}, \pm\sqrt{1-\sqrt{2}}$。正规闭包 $= \mathbb{Q}(\sqrt{1+\sqrt{2}}, \sqrt{1-\sqrt{2}})$，$[\cdot:\mathbb{Q}] = 8$。

5. 设 $f$ 是 $\alpha$ 的极小多项式。$L$ 包含 $\alpha$，所以 $L$ 包含 $f$ 的一个根。由正规性，$f$ 在 $L$ 上分裂。所以 $L$ 包含 $f$ 的所有根，即 $L$ 包含 $f$ 的分裂域 $L_f$。但 $L = K(\alpha) \subseteq L_f$（$L_f$ 由 $\alpha$ 和其他根生成）。所以 $L = L_f$。
:::
