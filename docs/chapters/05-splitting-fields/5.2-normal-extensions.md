# §5.2 正规扩张 {#sec-normal-extensions}

::: theorem 核心问题
哪些代数扩张恰好是某个多项式的分裂域？如何判定一个扩张是否"正规"？正规性在域的塔中如何传递？
:::

## 什么是正规扩张？ {#motivation}

[§5.1](5.1-splitting-fields) 证明了每个多项式都有分裂域。反过来的问题是：给定一个域扩张 $L/K$，它是否恰好是某个多项式的分裂域？

这个"反过来的问题"引出了**正规扩张**的概念。正规扩张在 Galois 理论中扮演核心角色：Galois 对应（第七章）只在正规扩张上完美运作。

---

## 正规扩张的定义 {#def-normal}

::: definition 正规扩张 {#def-normal-extension}
设 $L/K$ 是代数扩张。我们说 $L/K$ 是**正规的**（normal），如果满足以下条件：

> 对每个在 $K$ 上不可约的多项式 $f \in K[X]$，若 $f$ 在 $L$ 中至少有一个根，则 $f$ 在 $L$ 上完全分裂。

等价地说：$L$ 对 $K$ 上的不可约多项式是"封闭的"——只要一个不可约多项式在 $L$ 中有一根，它的所有根都在 $L$ 中。
:::

::: intuition 正规性的直觉
正规扩张是"对称性完整"的扩张。如果 $L$ 包含某个不可约多项式的一个根，那么正规性要求 $L$ 也包含该多项式的所有其他根——即所有共轭元素都在场。

非正规的扩张"破坏了对称性"：它包含一个根，但缺少某些共轭根。
:::

::: example 正规扩张的例子 {#ex-normal-examples}
**例 1.** $\mathbb{C}/\mathbb{R}$ 是正规扩张。$\mathbb{R}[X]$ 中的不可约多项式要么是一次（根已含于 $\mathbb{R}$），要么是二次（$X^2 + bX + c$，$\Delta < 0$）。$\mathbb{C}$ 包含所有二次不可约多项式的根（$\pm\sqrt{\Delta}$），且完全分裂。✓

**例 2.** $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ **不是**正规扩张。$f(X) = X^3 - 2$ 在 $\mathbb{Q}$ 上不可约，且在 $\mathbb{Q}(\sqrt[3]{2})$ 中有根 $\sqrt[3]{2}$。但 $f$ 的另外两个根 $\omega\sqrt[3]{2}$ 和 $\omega^2\sqrt[3]{2}$ 不在 $\mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$ 中。所以 $f$ 不在 $\mathbb{Q}(\sqrt[3]{2})$ 上分裂。✗

**例 3.** $\mathbb{Q}(\sqrt[3]{2}, \omega)/\mathbb{Q}$ 是正规扩张——它是 $X^3 - 2$ 的分裂域。

**例 4.** 任意**分裂域**都是正规扩张（这由定义直接得出）。
:::

::: example 重要的非正规扩张 {#ex-non-normal}
**$\mathbb{Q}(\sqrt[4]{2})/\mathbb{Q}$ 不是正规扩张。**

$f(X) = X^4 - 2$ 在 $\mathbb{Q}$ 上不可约（Eisenstein），在 $\mathbb{Q}(\sqrt[4]{2})$ 中有根 $\sqrt[4]{2}$。但 $f$ 的根 $\pm\sqrt[4]{2}, \pm i\sqrt[4]{2}$ 中，$i\sqrt[4]{2} \notin \mathbb{Q}(\sqrt[4]{2}) \subset \mathbb{R}$。

$f$ 在 $\mathbb{Q}$ 上的分裂域是 $\mathbb{Q}(\sqrt[4]{2}, i)$（[§5.1 例 {ex-x4-2}](5.1-splitting-fields#ex-x4-2)），维度为 $8$，大于 $[\mathbb{Q}(\sqrt[4]{2}) : \mathbb{Q}] = 4$。
:::

## 正规性的等价刻画 {#characterizations}

正规性有多种等价表述，每一种都有其用途。

::: definition $K$-嵌入 {#def-embedding-into-algebraic-closure}
设 $L/K$ 是代数扩张，$\bar{K}$ 是 $K$ 的一个代数闭包（或任何包含 $L$ 的扩域）。$K$-**嵌入**是指域嵌入 $\sigma: L \hookrightarrow \bar{K}$，满足 $\sigma|_K = \mathrm{id}_K$。
:::

::: theorem 正规性的等价条件 {#thm-normal-characterizations}
设 $L/K$ 是有限代数扩张。则以下条件等价：

**(N1)** $L/K$ 是正规扩张。

**(N2)** 对每个 $K$-嵌入 $\sigma: L \hookrightarrow \bar{K}$（其中 $\bar{K}$ 是 $K$ 的代数闭包），有 $\sigma(L) = L$。

**(N3)** $L$ 是 $K$ 上某族多项式的分裂域。

**(N4)** 设 $L = K(\alpha_1, \ldots, \alpha_n)$，$f_i$ 是 $\alpha_i$ 在 $K$ 上的极小多项式。则 $L$ 是 $f = f_1 f_2 \cdots f_n$ 在 $K$ 上的分裂域。
:::

<ProofToggle>

**证明.** 我们依次证明 (N4) $\Rightarrow$ (N3) $\Rightarrow$ (N1) $\Rightarrow$ (N2) $\Rightarrow$ (N4)。

---

**(N4) $\Rightarrow$ (N3)：** 若 $L$ 是 $f = f_1 \cdots f_n$ 的分裂域，则 $L$ 是 $K$ 上多项式族 $\{f_1, \ldots, f_n\}$ 的分裂域。取 $\mathcal{F} = \{f\}$ 即得 (N3)。✓

**(N3) $\Rightarrow$ (N1)：** 设 $L$ 是某族多项式 $\mathcal{F} \subseteq K[X]$ 的分裂域。设 $g \in K[X]$ 不可约且在 $L$ 中有根 $\alpha$。我们要证 $g$ 在 $L$ 上完全分裂。

取 $\mathcal{F}' = \mathcal{F} \cup \{g\}$。设 $L'$ 是 $\mathcal{F}'$ 的分裂域。则 $L \subseteq L'$，且 $\alpha \in L$。另一方面，$L'$ 由 $L$ 和 $g$ 的所有根生成。

设 $\beta$ 是 $g$ 在 $L'$ 中的任意根。因为 $g$ 在 $K$ 上不可约且 $\alpha, \beta$ 都是 $g$ 的根，由 [§3.3 {thm-conjugate-roots}](/chapters/03-fields/3.3-algebraic-elements#thm-conjugate-roots)，存在 $K$-同构 $\tau: K(\alpha) \xrightarrow{\sim} K(\beta)$，满足 $\tau(\alpha) = \beta$，$\tau|_K = \mathrm{id}_K$。

因为 $L$ 是 $\mathcal{F}$ 的分裂域，可以将 $\tau$ 从 $K(\alpha)$ 扩张到 $L'$ 的某个子域（更精确地，$\tau$ 扩张为 $L$ 到 $L'$ 的一个 $K$-嵌入 $\tilde{\tau}: L \hookrightarrow L'$）。由 {lem-embedding-extension} 和 $L$ 是 $\mathcal{F}$ 的分裂域，$\tilde{\tau}(L) \subseteq L'$。

因为 $\alpha \in L$，$\tilde{\tau}(\alpha) = \beta$，所以 $\beta \in \tilde{\tau}(L)$。我们需要证明 $\beta \in L$。

关键观察：$\tilde{\tau}$ 是 $K$-嵌入 $\sigma: L \hookrightarrow L' \subseteq \bar{K}$。若我们能证明所有 $K$-嵌入 $L \hookrightarrow \bar{K}$ 的像等于 $L$，则 $\beta \in L$。

这正是 (N2) 的内容。但我们可以直接证明 (N1) 如下：

设 $\beta_1, \ldots, \beta_r$ 是 $g$ 在 $\bar{K}$ 中的所有根。每个 $\beta_j$ 都是 $g$ 的根，$g$ 在 $K$ 上不可约。所以对每个 $j$，存在 $K$-同构 $\tau_j: K(\alpha) \xrightarrow{\sim} K(\beta_j)$，将 $\alpha$ 映射到 $\beta_j$。每个 $\tau_j$ 都可以扩张为某个 $K$-嵌入 $\sigma_j: L \hookrightarrow \bar{K}$。

$L$ 作为 $\mathcal{F}$ 的分裂域，是某个多项式 $h \in K[X]$ 的分裂域。设 $h$ 在 $L$ 中的根为 $\gamma_1, \ldots, \gamma_s$。则 $L = K(\gamma_1, \ldots, \gamma_s)$。

对每个 $K$-嵌入 $\sigma_j: L \hookrightarrow \bar{K}$，$\sigma_j(\gamma_i)$ 是 $h$ 的某个根。所以 $\sigma_j$ 将 $h$ 的根集合 $\{\gamma_1, \ldots, \gamma_s\}$ 置换。因此 $\sigma_j(L) = K(\sigma_j(\gamma_1), \ldots, \sigma_j(\gamma_s)) \subseteq K(\gamma_1, \ldots, \gamma_s) = L$（因为 $h$ 的所有根在 $L$ 中）。更精确地，$\sigma_j$ 在 $h$ 的根集上诱导一个置换，所以 $\sigma_j(L) = L$。

特别地，$\beta_j = \sigma_j(\alpha) \in \sigma_j(L) = L$。所以 $g$ 的所有根都在 $L$ 中，$g$ 在 $L$ 上分裂。✓

**(N1) $\Rightarrow$ (N2)：** 设 $L/K$ 是正规扩张。设 $\sigma: L \hookrightarrow \bar{K}$ 是 $K$-嵌入。设 $\alpha \in L$，$f = m_{\alpha,K}$ 是 $\alpha$ 在 $K$ 上的极小多项式。则 $\sigma(\alpha)$ 也是 $f$ 的根（因为 $\sigma|_K = \mathrm{id}_K$ 保持 $f$ 的系数不变）。由正规性，$f$ 在 $L$ 上完全分裂，$f$ 的所有根都在 $L$ 中。所以 $\sigma(\alpha) \in L$。

这证明了 $\sigma(L) \subseteq L$。因为 $L/K$ 是有限扩张，$\sigma$ 是单射，$[L : K] = [\sigma(L) : K]$。所以 $\sigma(L) \subseteq L$ 且 $[\sigma(L) : K] = [L : K]$ 迫使 $\sigma(L) = L$。✓

**(N2) $\Rightarrow$ (N4)：** 设 $L = K(\alpha_1, \ldots, \alpha_n)$。设 $f_i$ 是 $\alpha_i$ 在 $K$ 上的极小多项式。设 $f = f_1 \cdots f_n$。设 $L_f$ 是 $f$ 在 $K$ 上的分裂域。则 $L \subseteq L_f$（因为每个 $\alpha_i$ 都是 $f$ 的根）。

我们要证 $L = L_f$，即 $f$ 在 $L$ 上已完全分裂。

设 $\beta$ 是某个 $f_i$ 的根。则存在 $K$-同构 $\tau: K(\alpha_i) \xrightarrow{\sim} K(\beta)$，满足 $\tau(\alpha_i) = \beta$。由 {lem-embedding-extension}，$\tau$ 可以扩张为 $K$-嵌入 $\sigma: L \hookrightarrow \bar{K}$。由 (N2)，$\sigma(L) = L$。所以 $\beta = \sigma(\alpha_i) \in L$。

这证明了每个 $f_i$ 的所有根都在 $L$ 中，即 $f$ 在 $L$ 上完全分裂。所以 $L_f \subseteq L$，从而 $L_f = L$。✓

这完成了 (N4) $\Rightarrow$ (N3) $\Rightarrow$ (N1) $\Rightarrow$ (N2) $\Rightarrow$ (N4) 的循环。 $\blacksquare$

</ProofToggle>

## 正规扩张的判定 {#how-to-check}

::: 推论 判定正规性 {#cor-check-normal}
要判定 $L = K(\alpha_1, \ldots, \alpha_n)/K$ 是否正规：

1. 计算每个 $\alpha_i$ 的极小多项式 $f_i \in K[X]$。
2. 计算 $f = f_1 \cdots f_n$。
3. 判定 $f$ 是否在 $L$ 上完全分裂（即 $f$ 的所有根是否都在 $L$ 中）。

若 $f$ 在 $L$ 上分裂，则 $L/K$ 正规；否则不正规。
:::

::: example 用判定法验证 {#ex-check-normal}
**验证 $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ 是正规扩张。**

$\alpha_1 = \sqrt{2}$，极小多项式 $f_1 = X^2 - 2$，根为 $\pm\sqrt{2}$。
$\alpha_2 = \sqrt{3}$，极小多项式 $f_2 = X^2 - 3$，根为 $\pm\sqrt{3}$。

$f = f_1 f_2 = (X^2 - 2)(X^2 - 3)$。根为 $\pm\sqrt{2}, \pm\sqrt{3}$。

$\sqrt{2} \in L$ ✓；$-\sqrt{2} \in L$ ✓；$\sqrt{3} \in L$ ✓；$-\sqrt{3} \in L$ ✓。

所有根都在 $L$ 中，所以 $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ 是正规扩张。✓

事实上，$L$ 是 $f = (X^2 - 2)(X^2 - 3)$ 的分裂域。
:::

::: example 非正规扩张的验证 {#ex-check-non-normal}
**验证 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 不是正规扩张。**

$\alpha = \sqrt[3]{2}$，极小多项式 $f = X^3 - 2$，根为 $\sqrt[3]{2}, \omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}$。

$\sqrt[3]{2} \in L$ ✓。但 $\omega\sqrt[3]{2} \notin \mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$。✗

$f$ 不在 $L$ 上完全分裂，所以 $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 不是正规扩张。
:::

## 正规扩张的塔性质 {#tower}

::: remark 正规性在塔中不传递
正规性在一般域塔中**不传递**：$L/K$ 和 $M/L$ 都正规 $\not\Rightarrow$ $M/K$ 正规。

**反例：** 取 $K = \mathbb{Q}$，$L = \mathbb{Q}(\sqrt{2})$，$M = \mathbb{Q}(\sqrt[4]{2})$。

- $L/K$ 正规 ✓（$L$ 是 $X^2 - 2$ 的分裂域）。
- $M/L$ 正规 ✓（$M$ 是 $X^2 - \sqrt{2}$ 在 $L$ 上的分裂域）。
- $M/K$ **不正规** ✗（$X^4 - 2$ 不在 $\mathbb{Q}(\sqrt[4]{2})$ 上分裂）。
:::

::: proposition 正规扩张塔的正确判据 {#prop-normal-tower}
设 $K \subseteq L \subseteq M$。

**(a)** 若 $M/K$ 正规，则 $M/L$ 正规。

**(b)** 若 $L/K$ 和 $M/K$ 都正规，则 $M/L$ 正规。
:::

<ProofToggle>

**证明.**

**(a)** 设 $M/K$ 正规，$f \in L[X]$ 不可约且在 $M$ 中有根 $\alpha$。设 $g$ 是 $\alpha$ 在 $K$ 上的极小多项式。则 $f \mid g$（在 $L[X]$ 中，因为 $g(\alpha) = 0$ 且 $f$ 是 $L$ 上的极小多项式）。由 $M/K$ 正规，$g$ 在 $M$ 上完全分裂。因为 $f \mid g$，$f$ 的每个根也是 $g$ 的根，从而在 $M$ 中。所以 $f$ 在 $M$ 上完全分裂。✓

**(b)** 这是 (a) 的直接推论（$M/K$ 正规 $\Rightarrow$ $M/L$ 正规），因为 $L/K$ 正规的条件在 (a) 的证明中没有用到。

或者直接证明：设 $f \in L[X]$ 不可约且在 $M$ 中有根 $\alpha$。设 $\sigma: M \hookrightarrow \bar{K}$ 是 $L$-嵌入。则 $\sigma|_K = \mathrm{id}_K$（因为 $L$-嵌入自动是 $K$-嵌入）。由 $M/K$ 正规，$\sigma(M) = M$。所以 $M/L$ 是正规的。 $\blacksquare$

</ProofToggle>

## 正规闭包 {#normal-closure}

::: definition 正规闭包 {#def-normal-closure}
设 $L/K$ 是有限代数扩张。$L$ 在 $K$ 上的**正规闭包**（normal closure）是包含 $L$ 的最小正规扩张 $N/K$。即：

1. $N/K$ 是正规扩张；
2. $L \subseteq N$；
3. 若 $N'/K$ 是正规扩张且 $L \subseteq N'$，则 $N \subseteq N'$。
:::

::: theorem 正规闭包的存在与构造 {#thm-normal-closure}
设 $L = K(\alpha_1, \ldots, \alpha_n)$ 是有限代数扩张，$f_i$ 是 $\alpha_i$ 在 $K$ 上的极小多项式。则 $f = f_1 \cdots f_n$ 在 $K$ 上的分裂域是 $L$ 在 $K$ 上的正规闭包。
:::

<ProofToggle>

**证明.** 设 $N$ 是 $f = f_1 \cdots f_n$ 的分裂域。则 $L \subseteq N$（因为每个 $\alpha_i$ 是 $f_i$ 的根，从而是 $f$ 的根）。

$N/K$ 正规：$N$ 是多项式 $f$ 的分裂域，所以 $N/K$ 正规。

最小性：设 $N'/K$ 是正规扩张且 $L \subseteq N'$。对每个 $i$，$\alpha_i \in N'$，$f_i$ 不可约且在 $N'$ 中有根 $\alpha_i$。由正规性，$f_i$ 在 $N'$ 上完全分裂。所以 $f$ 在 $N'$ 上完全分裂，$f$ 的所有根都在 $N'$ 中。因此 $N \subseteq N'$。 $\blacksquare$

</ProofToggle>

::: example 正规闭包的计算 {#ex-normal-closure}
$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 的正规闭包是 $\mathbb{Q}(\sqrt[3]{2}, \omega) = \mathbb{Q}(\sqrt[3]{2}, \omega)$，它是 $X^3 - 2$ 的分裂域，$[\cdot : \mathbb{Q}] = 6$。

$\mathbb{Q}(\sqrt[4]{2})/\mathbb{Q}$ 的正规闭包是 $\mathbb{Q}(\sqrt[4]{2}, i)$，它是 $X^4 - 2$ 的分裂域，$[\cdot : \mathbb{Q}] = 8$。
:::

## 正规扩张与 Galois 理论 {#connection-galois}

::: intuition 正规性为何重要
正规性是 Galois 理论两个核心条件之一（另一个是可分性）。Galois 对应定理说：

> **有限 Galois 扩张 $\Leftrightarrow$ 有限正规可分扩张**

正规性确保了 $K$-自同构群 $\operatorname{Gal}(L/K)$ 的子群与 $L$ 和 $K$ 之间的中间域之间存在**完美的一一对应**。

没有正规性，这个对应就有"漏洞"——某些自同构群无法对应到中间域。
:::

## 正规扩张的总结 {#summary}

| 性质 | 陈述 |
|------|------|
| 正规性定义 | 不可约多项式有一根 $\Rightarrow$ 完全分裂 |
| 嵌入判据 | $L/K$ 正规 $\Leftrightarrow$ 每个 $K$-嵌入 $\sigma: L \hookrightarrow \bar{K}$ 满足 $\sigma(L) = L$ |
| 分裂域判据 | $L/K$ 正规 $\Leftrightarrow$ $L$ 是某族多项式的分裂域 |
| 塔传递 | $M/K$ 正规 $\Rightarrow$ $M/L$ 正规（反过来不成立） |
| 正规闭包 | $L = K(\alpha_1, \ldots, \alpha_n)$ 的正规闭包是 $f_1 \cdots f_n$ 的分裂域 |
